# 第2章：幻灯片基础——搭建路演PPT的骨架 🦴

*小林终于搞清楚了PowerPoint的界面长什么样，但他面对空白的幻灯片还是不知道从何下手。他心想："投资人想听什么？我应该先说什么后说什么？每一页放什么内容？"他决定先把路演PPT的整体结构想清楚——就像盖房子，得先把钢筋骨架搭好，再考虑刷什么颜色的墙漆。*

## 2.1 新建幻灯片与选择版式

新建幻灯片是你在做PPT时最高频的操作之一。

**方法一：使用"开始"选项卡**

操作路径：`开始 > 新建幻灯片`，点击按钮下方的箭头可以展开版式选择菜单。

**方法二：快捷键**

按 `Ctrl + M` 可以快速新建一张幻灯片（使用默认版式）。

**方法三：在缩略图窗格中**

在左侧缩略图窗格中右键单击，选择"新建幻灯片"。

> 💡 **提示**：新建幻灯片时，建议直接选择合适的版式，而不是先新建空白页再手动添加文本框。使用内置版式的好处是格式统一、排版规范，后面调整主题时所有页面会自动更新。

## 2.2 常用版式详解

PowerPoint默认提供9种版式，但日常使用中，以下4种就覆盖了80%以上的场景：

**① 标题幻灯片**

结构：一个居中大标题 + 一个副标题

适用场景：PPT的封面页（第一页）和结尾页（最后一页）

小林的路演PPT封面就可以用这个版式，写上"账本精灵——让记账变简单"，副标题写自己的名字和日期。

**② 标题和内容**

结构：顶部一个标题 + 下方一个大的内容区域

适用场景：最常用的版式，适合放文字要点、图片、图表等内容

比如"市场规模"这一页，标题写"巨大的市场机会"，内容区放一张市场数据图表。

**③ 两栏内容**

结构：顶部一个标题 + 下方左右两个内容区

适用场景：对比展示（如"传统方式 vs 账本精灵"）、图文并茂（左图右文）

竞品分析页就特别适合用这个版式——左边放竞品，右边放自己的优势。

**④ 空白**

结构：什么都没有

适用场景：自由排版、全屏图片页、创意设计页

> 💡 **提示**：新手常常执着于"用哪种版式最好看"，其实不用纠结。先用"标题和内容"把内容填好，后期想怎么调都行。内容永远是第一位的，形式是服务于内容的。

## 2.3 移动、复制、删除幻灯片

**移动幻灯片**

在左侧缩略图窗格中，鼠标左键按住一张幻灯片，拖动到目标位置松手即可。你会看到一条水平线指示插入位置。

**复制幻灯片**

方法一：选中幻灯片，按 `Ctrl + C` 复制，然后在目标位置按 `Ctrl + V` 粘贴。

方法二：选中幻灯片，按住 `Ctrl` 键的同时拖动到新位置。

方法三：右键单击幻灯片，选择"复制幻灯片"。

> 💡 **提示**：复制幻灯片特别适合做结构相似的页面。比如小林的路演PPT里，"问题"和"方案"两页的版式差不多，就可以先做好一页，复制一份再改内容，省去重新排版的时间。

**删除幻灯片**

选中幻灯片，按 `Delete` 键或右键选择"删除幻灯片"。

如果误删了，赶紧按 `Ctrl + Z` 撤销！

## 2.4 分节管理：把PPT分成清晰的章节

当你的PPT超过10页时，左侧的缩略图列表会变得很长，翻来翻去找某一张很麻烦。这时候**分节功能**就派上用场了。

分节就像给一本书分章节——你可以把相关的幻灯片归到一个"节"里，给每节取个名字，还能折叠/展开。

**操作步骤：**

1. 在缩略图窗格中，右键单击某两张幻灯片之间的位置
2. 选择"添加节"
3. 右键点击节标题，选择"重命名节"
4. 输入节的名称（如"产品部分""市场部分""团队部分"）

小林可以这样给路演PPT分节：

| 节名称 | 包含的幻灯片 |
| -------- | ------------- |
| 开场 | 封面、痛点问题 |
| 产品 | 解决方案、产品展示 |
| 市场 | 市场规模、商业模式 |
| 竞争 | 竞品分析 |
| 团队与融资 | 团队介绍、融资需求 |
| 结尾 | 联系方式、Q&A |

折叠/展开节：点击节标题左侧的三角箭头，可以把该节的幻灯片折叠起来，只显示节标题。这样在编辑某个部分时，可以把其他部分折叠掉，减少干扰。

## 2.5 幻灯片排序：拖拽调整顺序

做PPT的过程中，调整页面顺序是常有的事。可能你做着做着发现，"哎，团队介绍应该放在竞品分析前面"。

**在幻灯片浏览视图中排序**（推荐）

切换到幻灯片浏览视图（`视图 > 幻灯片浏览`），所有幻灯片会以网格方式平铺展示。这时候拖拽排序特别直观，就像整理桌面上的扑克牌。

**在普通视图中排序**

在左侧缩略图窗格中直接拖拽即可。

**批量移动多张幻灯片**

按住 `Ctrl` 键选择多张不连续的幻灯片，或按住 `Shift` 键选择连续的多张幻灯片，然后一起拖拽到新位置。

## 2.6 实战：为小林的路演PPT搭建10页骨架

好，现在让我们把前面学的知识用起来，帮小林搭建路演PPT的骨架。

一份标准的创业路演PPT通常包含以下结构（共10页）：

**第1页：封面**

- 版式：标题幻灯片
- 内容：产品名称"账本精灵"、一句话定位、演讲者姓名和日期

**第2页：痛点/问题**

- 版式：标题和内容
- 内容：描述目标用户面临的核心问题（年轻人不想记账但管不住钱）

**第3页：解决方案**

- 版式：标题和内容
- 内容：账本精灵如何解决这个问题（AI自动记账、智能分析）

**第4页：产品展示**

- 版式：标题和内容
- 内容：App截图、核心功能演示

**第5页：市场规模**

- 版式：标题和内容
- 内容：目标市场规模数据（TAM/SAM/SOM）

**第6页：商业模式**

- 版式：标题和内容
- 内容：怎么赚钱（免费+付费会员、广告等）

**第7页：竞品分析**

- 版式：两栏内容
- 内容：与主要竞品的对比优势

**第8页：团队介绍**

- 版式：标题和内容
- 内容：核心团队成员和背景

**第9页：融资需求**

- 版式：标题和内容
- 内容：融资金额、资金用途、预期目标

**第10页：结尾/联系方式**

- 版式：标题幻灯片
- 内容：感谢语、联系方式、Q&A

**操作步骤：**

1. 新建空白演示文稿
2. 第1页选择"标题幻灯片"版式
3. 按 `Ctrl + M` 新建后续9页，分别选择对应版式
4. 在左侧缩略图中，按上述内容给每一页的标题写上占位文字（先写标题就行，具体内容后面章节再填充）
5. 添加分节，把10页分成"开场""产品""市场""竞争""团队与融资""结尾"六个节
6. 保存文件

做完这步，你就有了一份结构清晰的PPT骨架。虽然页面还是空白的，但整体框架已经搭好了，接下来就是一步步往里面填肉。

> 💡 **提示**：先搭骨架再填内容，是高效做PPT的核心方法。很多新手一上来就死磕第一页的配色和字体，结果后面九页还没开始做。正确的做法是：**先确定结构（骨架），再填充内容（血肉），最后美化设计（化妆）**。

## 本章小结

| 知识点 | 核心要点 |
| -------- | ---------- |
| 新建幻灯片 | `开始 > 新建幻灯片`或 `Ctrl + M`，新建时选好版式 |
| 四种常用版式 | 标题幻灯片（封面）、标题和内容（最常用）、两栏（对比）、空白（自由） |
| 移动/复制/删除 | 拖拽移动、`Ctrl+C/V`复制、`Delete`删除，误删用 `Ctrl + Z` |
| 分节管理 | 右键添加节，按主题分组，可折叠展开 |
| 排序 | 浏览视图下拖拽最直观，支持批量选择移动 |
| 实战骨架 | 10页标准路演结构：封面→痛点→方案→产品→市场→模式→竞品→团队→融资→结尾 |

## 练习题

1. **基础**：新建一个演示文稿，添加8张幻灯片，分别使用不同的版式，保存文件。
2. **进阶**：按照本章2.6节的10页结构，搭建路演PPT的完整骨架，添加分节管理，给每一页写上标题文字。
3. **挑战**：在骨架PPT中，尝试把"竞品分析"页移动到"团队介绍"后面，再把分节重新调整为"开场""核心内容""收尾"三个大节。
