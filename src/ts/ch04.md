# 第四章：数组、元组与对象类型

## 数组

TypeScript 有两种声明数组的方式：

```ts
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ["Alice", "Bob"];
```

两种写法等价，`number[]` 更常见。

如果要声明只读数组，用 `readonly`：

```ts
let readonlyNumbers: readonly number[] = [1, 2, 3];
readonlyNumbers.push(4); // 错误
```

## 元组

元组是固定长度、固定类型的数组。

```ts
let point: [number, number] = [10, 20];
let user: [string, number, boolean] = ["Alice", 25, true];
```

元组在需要表达"一组有序且类型各异的数据"时很有用，比如坐标、数据库记录等。

但要注意：TypeScript 对元组长度的检查只在初始化时比较严格。如果你用 `push` 等方法，编译器可能不会报错。

```ts
let point: [number, number] = [10, 20];
point.push(30); // 编译通过，但逻辑上可能不是你想要的
```

如果你需要完全不可变的元组，可以加上 `readonly`：

```ts
let point: readonly [number, number] = [10, 20];
```

## 对象类型

对象类型描述一个对象有哪些属性，以及属性的类型。

```ts
let user: {
  name: string;
  age: number;
  isAdmin?: boolean; // 可选属性
} = {
  name: "Alice",
  age: 25,
};
```

`?` 表示可选属性。可选属性的类型实际上是 `boolean | undefined`。

## 接口 interface

当对象结构需要复用时，用 `interface`：

```ts
interface User {
  name: string;
  age: number;
  isAdmin?: boolean;
}

function greet(user: User): string {
  return `Hello, ${user.name}`;
}
```

`interface` 是 TypeScript 中描述对象形状的主要工具。它支持继承、实现、合并等高级特性。

## 类型别名 type

`type` 也可以定义对象类型，它和 `interface` 在很多场景下可以互换：

```ts
type User = {
  name: string;
  age: number;
};
```

那 `interface` 和 `type` 有什么区别？简单说：

- `interface` 更适合描述对象的结构，支持声明合并。
- `type` 更灵活，可以定义联合类型、交叉类型、元组、原始类型别名等。

```ts
// interface 支持同名合并
type Status = "success" | "error"; // type 可以定义联合类型
```

在描述对象时，优先用 `interface`；在需要联合类型、交叉类型或更复杂类型操作时，用 `type`。
