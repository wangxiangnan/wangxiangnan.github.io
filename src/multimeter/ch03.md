# 第3章 电的三个基本量：电压、电流与电阻

认识完万用表的长相，小王开始琢磨一个更深的问题：电，到底是个什么东西？他盯着墙上的插座出神——那里面明明什么都没有，没水流出来，没气冒出来，怎么插上插头，封口机就能轰轰地干活？

他想起小学自然课老师说“电是电荷的定向移动”，可“电荷”又是什么？看不见摸不着，比店里的芝士奶盖还抽象。小王查资料查到半夜，越查越晕：电子、电场、电势，每个词都认识，连起来却像天书。

直到他看到一句话：“把电想象成水。”一瞬间，世界清晰了——水塔、水管、水流，全是他能“看见”的东西。本章就用“水”这把万能钥匙打开电学大门，把电压、电流、电阻讲得明明白白。这三个词会在本书后面反复出现，吃透了它们，万用表的操作就懂了一半。

## 3.1 电是什么：先认识“看不见的搬运工”

先说结论：电，是电荷的流动。电荷是什么？可以理解为一种极其微小的带电粒子，小到肉眼永远看不见，却真实存在。当这些粒子沿着导线集体奔跑，就形成电流，把能量从发电厂一路“搬运”到你店里的封口机上。

为什么用水来类比电？因为两者的行为惊人地相似：水在水管里流，电荷在导线里跑；水从高处往低处流，电荷从“电位高”的地方往“电位低”的地方跑；水管粗，水流得畅，导线粗，电走得顺；水管堵了水流变小，电路里加了电阻电流也变小。

这里顺便交代两个重要概念：直流和交流。直流电的流动方向始终不变，像一条单向流动的河，干电池、手机电池、充电器输出的都是直流；交流电的流动方向周期性来回变化，像潮汐，家用市电就是交流电——所以万用表测这两种电要用不同挡位，旋钮上才有“V⎓”和“V~”之分。

## 3.2 电压：水位差决定水流

想象两座水塔，一座高，一座矮，中间用水管连通。水会从高塔流向矮塔——为什么？因为存在“水位差”。水位差越大，水压越大，水流越急。

电压，就是电学世界里的“水位差”，学名叫“电位差”。它的单位是伏特，简称伏，符号V。一节干电池标称1.5V，意思是它正负两端之间“推”电荷的能力，相当于1.5米水位差的水压；手机充电器输出5V；家用市电220V，这个“水压”就大得多了，足以致命——这也解释了为什么测干电池可以心平气和，测市电必须打起十二分精神。

有了电压的概念，就能理解万用表测电压的本质是“测两点之间的水位差”：红黑表笔分别搭在电路的两个点上，表显示的就是这两点之间的“水位差”。如果两点电位相同（比如同一根导线的两头），电压就是0，就像水平面上没有水位差，水不会流。

生活中常见的电压值，建议背下来，以后测电压时心里就有数：

| 对象 | 电压 |
| --- | --- |
| 干电池 | 1.5V |
| 手机锂电池 | 约3.7V |
| USB接口 | 5V |
| 汽车电瓶 | 12V |
| 电动车电瓶 | 48V/60V |
| 家用市电 | 220V |

记住这些“水位标尺”有什么用？测电池时，读数明显偏低，就说明“水位”不足了：比如1.5V的电池测出来只有1.2V，就是电量告急的信号。电压测量，是你将来最常用的“体检项目”。

## 3.3 电流：水管里流过的水量

水位差有了，水开始流。怎么描述“流得多猛”？看单位时间里流过水管的水量，这就是“水流大小”。

电流，是电荷流动的“流量”，指单位时间里通过导线的电荷数量。它的单位是安培，简称安，符号A。1安的电流有多大？相当于1秒内有约625亿亿个电子穿过导线截面——数字大到没朋友，所以日常常用毫安（mA），1安=1000毫安。手机充电电流约1到2安，LED小灯珠只要20毫安，而空调、热水器这类大功率电器工作时，电流可能达到十几安。

电流对万用表操作的意义格外重大：测电流，是三个基本量里最“麻烦”的一个。为什么？回到水的类比就清楚了。测水位差（电压），在管壁外装个压力表就行，不用动水管；测水流大小（电流），却必须把水管剪断，把流量计接到断口中间，让全部水流穿过流量计，才能数清有多少水。

对应到电学，这是全书最重要的两条操作原理，请务必吃透：

- 测电压用并联：表笔搭在元件两端，电路不被断开，万用表与元件“共享同一份水位差”，所以它读到的就是元件的电压。就像在河边立一根水位标尺，水位是多少，标尺就显示多少。
- 测电流用串联：必须断开电路，把万用表接进断口，让全部电流从表里穿过，表才能数清流量。就像把流量计接进水管中间，一滴水都不能从旁边溜走。

这两句话现在可能还只是“道理”，等你第4章亲手测一次电压、后面章节亲手测一次电流，就会变成手上的“直觉”。记住八个字：测电压是“搭上去看”，测电流是“切进去量”。

## 3.4 电阻：水管的粗细与堵塞

同样水位差的两座水塔，接上粗水管，水流哗哗的；接上细水管，水流细成一条线。水管的粗细与内部堵塞程度，决定了水流通过的难易。

电阻，就是电路对电流的“阻碍”能力，就像水管对水流的阻碍。它的单位是欧姆，简称欧，符号Ω。电阻越大，电流越难通过。导线是“粗水管”，电阻极小，接近0；空气、塑料、橡胶是“堵死的水管”，电阻极大，几乎不让电流通过，所以叫绝缘体；各种电阻元件则是工程师故意造出来的“特定粗细的水管”，用来精确控制电路里的电流。

万用表的电阻挡测什么？就是测两点之间“这条路有多难走”。测一根导线，电阻应接近0，说明路很通畅；测一个烧断的保险丝，电阻是无穷大（屏幕显示超量程的“1”或“OL”），说明路彻底断了；测发热丝，能测出一个正常范围内的数值，太大或太小都可能说明元件有问题。

这里有个关键细节，呼应第1章的“边界二”：测电阻时，万用表会自己送出一点点电流去“试探”这段路好不好走。如果此时电路还通着电，外面的电流会冲进来干扰，甚至烧坏仪表。所以铁律：测电阻前，必须先断电。

## 3.5 三兄弟的关系：欧姆定律直觉版

电压、电流、电阻不是三个孤立的词，它们之间有着严格的数量关系，由一个叫欧姆的科学家发现，所以叫欧姆定律。用公式写是：电压=电流×电阻（V=I×R）。看着吓人，用水的语言翻译一下就简单了：

水位差（电压）=水流大小（电流）×水管阻力（电阻）。

意思是：同样的水管，水压越大，水流越大；同样的水压，水管越堵，水流越小。反过来，如果水管堵得厉害（电阻大），还想保持原来的水流，就得加大水压（电压）——这就是为什么远距离输电要用几十万伏的高压：路太长、阻力太大，必须把“水压”提到极高。

欧姆定律对万用表使用者有两个实用价值。第一，理解测电阻为什么必须断电：万用表测电阻时，自己输出一个已知的“小水压”，看“水流”多大，反推出“水管有多堵”；外部有电，等于别人也在往管子里注水，结果全乱，还可能冲垮仪表。第二，理解超量程警告：被测电压太高，流过表内的“水”太多，表就显示超载（OL）自我保护。公式不必背，直觉必须建立：电压、电流、电阻三者互相牵制，像一家三兄弟，谁也离不开谁。

## 3.6 常见错误与注意事项

- 错误一：把单位搞混。220V市电说成“220安”、电池说成“1.5欧”，单位一混，就说明概念没分清。伏（V）是电压、安（A）是电流、欧（Ω）是电阻，三个单位对应三个量，就像米、斤、秒不能混用。
- 错误二：以为“有电压就一定有电流”。断开的插座孔里有220V电压，却没有电流流出，因为电路没接通，就像关掉阀门的水管：水位差还在，水却不流。
- 错误三：用手摸电路“试试有没有电”。人体是导体，摸市电等于把自己接进电路。永远别用身体当检测工具——万用表才是你的“替身”，让它去，别自己去。
- 错误四：对“测电流要串联”只背口诀不理解。不理解“切进去量”的道理，实操时就会把表笔并到电路上测电流——这是烧保险丝甚至烧表的头号操作错误。

## 3.7 本章小结

电是电荷的流动，用水来类比电：电压就是水位差，电流就是水流大小，电阻就是水管的粗细与堵塞。电压的单位是伏（V），电流的单位是安（A），电阻的单位是欧（Ω），三者由欧姆定律“电压=电流×电阻”联系在一起。测电压要“搭上去看”（并联），测电流要“切进去量”（串联），测电阻必须先断电。这三个直觉是后面所有万用表操作的根基，值得反复咀嚼。

## 3.8 练习题

1. 用自己的话说说，电压、电流、电阻分别对应“水”的什么？
2. 一节标称1.5V的干电池，实测电压1.18V，说明什么？
3. 为什么测电流必须把电路断开、把万用表串进去，而不能像测电压那样搭在旁边？
4. 为什么测电阻前必须先断电？
5. 手机充电器上写着“5V/2A”，这里的5V和2A分别指什么？

参考答案：

1. 电压对应水位差（水压），电流对应水流大小，电阻对应水管的粗细与堵塞程度。
2. 电池电量已严重不足。1.5V的干电池电压降到1.2V以下通常就该更换了，1.18V说明“水位”已经见底。
3. 电流是“流过导线”的量，只有让全部电流从表内穿过，表才能数清流量；搭在旁边只能测到两点间电压，测不出电流，还可能烧坏表内保险丝。
4. 电阻挡靠万用表自己输出小电流来“试探”线路，外部通电会干扰测量结果，而且外部大电流灌入表内会烧坏仪表。
5. 5V指输出电压，相当于“水位差”是5伏；2A指最大输出电流，相当于每秒最多能送出2安的“水流”。
