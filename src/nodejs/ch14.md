## 14.1 http.createServer的本质：TCP之上的应用层

### 14.1.1 先来点网络基础

在深入代码之前，让我们花30秒回顾一下网络分层（别跑，真的只要30秒）：

```
应用层 (HTTP/HTTPS)  ← 我们今天的主角
传输层 (TCP/UDP)      ← net模块住在这里
网络层 (IP)           ← 操作系统管
链路层 (以太网/WiFi)  ← 网卡说了算
```

HTTP协议本质上就是在TCP连接上传输的**纯文本协议**。没错，纯文本！当浏览器请求一个网页时，发送的数据长这样：

```
GET /index.html HTTP/1.1\r\n
Host: example.com\r\n
User-Agent: Mozilla/5.0\r\n
\r\n
```

就是一堆文本，用 `\r\n` 分隔，空行表示头部结束。服务器回复的也是文本：

```
HTTP/1.1 200 OK\r\n
Content-Type: text/html\r\n
Content-Length: 13\r\n
\r\n
Hello, World!
```

所以 `http.createServer()` 做的事情，本质上就是：

1. 创建一个TCP服务器（用net模块）
2. 监听连接上的数据
3. 按HTTP协议格式解析请求
4. 把解析结果包装成方便使用的Request对象
5. 提供Response对象让你方便地按HTTP格式回复

### 14.1.2 最简Web服务器

```typescript
import http, { IncomingMessage, ServerResponse } from 'node:http';

const server = http.createServer(
  (req: IncomingMessage, res: ServerResponse) => {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('你好，世界！这是我的第一个Web服务器 🎉');
  }
);

server.listen(3000, () => {
  console.log('服务器启动了！访问 http://localhost:3000');
});
```

这五行代码（去掉花括号的话）就是一个完整的Web服务器。就像泡面只需要开水一样简单。

### 14.1.3 深入 createServer 的内部

让我们看看 `http.createServer` 背后到底发生了什么：

```typescript
import http from 'node:http';
import net from 'node:net';

// http.createServer 内部大致等价于：
const server = net.createServer((socket) => {
  socket.on('data', (data) => {
    // 1. 解析HTTP请求文本
    const requestText = data.toString();
    const [requestLine, ...headerLines] = requestText.split('\r\n');
    const [method, url, httpVersion] = requestLine.split(' ');

    // 2. 解析请求头
    const headers: Record<string, string> = {};
    for (const line of headerLines) {
      if (line === '') break; // 空行 = 头部结束
      const [key, value] = line.split(': ');
      headers[key.toLowerCase()] = value;
    }

    // 3. 构造响应（简化版）
    const responseBody = 'Hello from raw TCP!';
    const response = [
      'HTTP/1.1 200 OK',
      `Content-Length: ${Buffer.byteLength(responseBody)}`,
      'Content-Type: text/plain',
      '',  // 空行分隔头部和体
      responseBody,
    ].join('\r\n');

    socket.write(response);
    socket.end();
  });
});

server.listen(3000);
```

看到没？HTTP服务器的本质就是一个TCP服务器 + 文本解析器。当然，真正的实现比这复杂得多（要处理分块传输、Keep-Alive、管道化请求等），但核心思想就是这么简单。

**Node.js 使用的 HTTP 解析器是 llhttp**（之前是 http_parser），它是用C语言写的，性能极高。这也是为什么Node.js处理HTTP请求这么快的原因之一。

## 14.2 Request对象解析

`IncomingMessage` 对象（通常叫 `req`）承载了客户端发来的所有信息。让我们逐一拆解：

### 14.2.1 基础属性

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  // 请求方法：GET, POST, PUT, DELETE, PATCH...
  console.log('Method:', req.method);

  // 请求URL（注意：不包含协议和主机名！）
  // 如果请求 http://localhost:3000/api/users?page=1
  // req.url 的值是 '/api/users?page=1'
  console.log('URL:', req.url);

  // HTTP版本
  console.log('HTTP Version:', req.httpVersion); // '1.1'

  // 请求头（全部小写化的键）
  console.log('Headers:', req.headers);
  console.log('Content-Type:', req.headers['content-type']);
  console.log('User-Agent:', req.headers['user-agent']);

  // 客户端IP地址
  console.log('Client IP:', req.socket.remoteAddress);

  res.end('OK');
});

server.listen(3000);
```

### 14.2.2 URL解析

`req.url` 只是一个字符串，要提取路径、查询参数等信息，需要用 `URL` 类来解析：

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  // Node.js 内置的 URL 类（WHATWG标准）
  const url = new URL(req.url!, `http://${req.headers.host}`);

  console.log('pathname:', url.pathname);     // '/api/users'
  console.log('search:', url.search);          // '?page=1&limit=10'
  console.log('searchParams:', url.searchParams); // URLSearchParams对象

  // 获取单个查询参数
  const page = url.searchParams.get('page');   // '1' (字符串！)
  const limit = url.searchParams.get('limit'); // '10'

  // 获取所有同名参数
  // URL: /api?tag=node&tag=js
  const tags = url.searchParams.getAll('tag'); // ['node', 'js']

  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ pathname: url.pathname, page, limit }));
});

server.listen(3000);
```

> **小贴士**：很多老教程用 `require('url').parse()`，那是Node.js遗留API。现在请一律使用 `new URL()`，它遵循WHATWG标准，和浏览器中的URL API完全一致。

### 14.2.3 读取请求体（Body）

这是新手最容易困惑的地方。`req.body` 在原生http模块中**不存在**！请求体是通过流（Stream）到达的，你需要手动收集：

```typescript
import http from 'node:http';

// 通用的body解析函数
function parseBody(req: http.IncomingMessage): Promise<string> {
  return new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];

    req.on('data', (chunk: Buffer) => {
      chunks.push(chunk);
    });

    req.on('end', () => {
      const body = Buffer.concat(chunks).toString('utf-8');
      resolve(body);
    });

    req.on('error', reject);
  });
}

// 更优雅的写法（Node.js 18+ 支持 ReadableStream）
async function parseBodyModern(req: http.IncomingMessage): Promise<string> {
  const chunks: Buffer[] = [];
  for await (const chunk of req) {
    chunks.push(chunk as Buffer);
  }
  return Buffer.concat(chunks).toString('utf-8');
}

const server = http.createServer(async (req, res) => {
  if (req.method === 'POST') {
    const rawBody = await parseBody(req);

    // 根据Content-Type决定如何解析
    const contentType = req.headers['content-type'] || '';

    if (contentType.includes('application/json')) {
      try {
        const jsonBody = JSON.parse(rawBody);
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ received: jsonBody }));
      } catch {
        res.writeHead(400);
        res.end('Invalid JSON');
      }
    } else if (contentType.includes('application/x-www-form-urlencoded')) {
      const params = new URLSearchParams(rawBody);
      const formData = Object.fromEntries(params);
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ received: formData }));
    } else {
      res.writeHead(200);
      res.end(`Received raw body: ${rawBody}`);
    }
  } else {
    res.writeHead(405);
    res.end('Method Not Allowed');
  }
});

server.listen(3000);
```

**为什么请求体要用流？** 因为请求体可能非常大（想象一下上传一个1GB的文件）。如果Node.js把整个body都读到内存里再给你，那内存早就爆了。流式处理让你可以边读边处理，或者在发现body太大时提前终止。

## 14.3 Response对象操作

`ServerResponse` 对象（通常叫 `res`）是你回复客户端的通道。

### 14.3.1 状态码与响应头

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  // 方式1：分别设置状态码和头部
  res.statusCode = 200;
  res.setHeader('Content-Type', 'application/json');
  res.setHeader('X-Powered-By', 'Node.js From Scratch');
  res.setHeader('Cache-Control', 'public, max-age=3600');

  // 方式2：一次性设置（writeHead会覆盖之前的setHeader）
  res.writeHead(200, {
    'Content-Type': 'application/json',
    'X-Request-Id': crypto.randomUUID(),
  });

  // 获取已设置的头部
  console.log(res.getHeaders());

  // 检查头部是否已发送（一旦发送就不能修改了！）
  console.log('Headers sent?', res.headersSent); // false

  res.end(JSON.stringify({ message: 'OK' }));

  console.log('Headers sent?', res.headersSent); // true
});

server.listen(3000);
```

### 14.3.2 write() 与 end()

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });

  // write() 可以调用多次，数据会分块发送
  res.write('<html><body>');
  res.write('<h1>正在加载...</h1>');
  res.write('<p>第一部分数据</p>');

  // 模拟延迟发送
  setTimeout(() => {
    res.write('<p>第二部分数据（1秒后到达）</p>');
    res.end('</body></html>'); // end() 表示响应结束
  }, 1000);

  // 注意：end() 之后不能再write！会报错
});

server.listen(3000);
```

**重要概念：Transfer-Encoding: chunked**

当你多次调用 `write()` 且没有设置 `Content-Length` 时，Node.js会自动使用分块传输编码（chunked transfer encoding）。这意味着浏览器可以边接收边渲染，不用等所有数据到齐。这就是为什么有些网页内容是"跳出来"的而不是一次性全部出现。

### 14.3.3 流式响应

结合Stream，我们可以高效地发送大文件：

```typescript
import http from 'node:http';
import { createReadStream } from 'node:fs';
import { stat } from 'node:fs/promises';
import path from 'node:path';

const server = http.createServer(async (req, res) => {
  const filePath = path.join(process.cwd(), 'big-file.zip');

  try {
    const stats = await stat(filePath);

    res.writeHead(200, {
      'Content-Type': 'application/octet-stream',
      'Content-Length': stats.size,
      'Content-Disposition': 'attachment; filename="big-file.zip"',
    });

    // 用管道直接把文件流接到响应流上
    // 内存占用极低，即使文件有10GB也没问题
    const fileStream = createReadStream(filePath);
    fileStream.pipe(res);

    fileStream.on('error', (err) => {
      console.error('文件读取错误:', err);
      res.end();
    });
  } catch {
    res.writeHead(404);
    res.end('File not found');
  }
});

server.listen(3000);
```

## 14.4 路由实现：从if/else到简易路由器

### 14.4.1 最原始的方式——if/else地狱

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  const url = new URL(req.url!, `http://${req.headers.host}`);
  const { pathname } = url;
  const method = req.method!;

  // 这就是没有框架的日子...
  if (method === 'GET' && pathname === '/') {
    res.end('Home Page');
  } else if (method === 'GET' && pathname === '/about') {
    res.end('About Page');
  } else if (method === 'GET' && pathname === '/api/users') {
    res.end(JSON.stringify([{ id: 1, name: 'Alice' }]));
  } else if (method === 'POST' && pathname === '/api/users') {
    // 处理创建用户...
    res.end('User created');
  } else if (method === 'GET' && pathname.startsWith('/api/users/')) {
    const id = pathname.split('/')[3];
    res.end(`User ${id}`);
  } else {
    res.writeHead(404);
    res.end('Not Found');
  }
});

server.listen(3000);
```

当路由超过10个时，这种代码会让你想砸键盘。让我们来构建一个简单的路由器：

### 14.4.2 构建简易路由器

```typescript
import http from 'node:http';

// 类型定义
type HttpMethod = 'GET' | 'POST' | 'PUT' | 'DELETE' | 'PATCH';

interface RouteParams {
  [key: string]: string;
}

interface RouteContext {
  req: http.IncomingMessage;
  res: http.ServerResponse;
  params: RouteParams;
  query: URLSearchParams;
}

type RouteHandler = (ctx: RouteContext) => void | Promise<void>;

interface Route {
  method: HttpMethod;
  pattern: RegExp;
  paramNames: string[];
  handler: RouteHandler;
}

class Router {
  private routes: Route[] = [];

  // 将路径模式转换为正则表达式
  // '/users/:id/posts/:postId' → /^\/users\/([^/]+)\/posts\/([^/]+)$/
  private pathToRegex(path: string): { pattern: RegExp; paramNames: string[] } {
    const paramNames: string[] = [];

    const regexStr = path
      .replace(/:([a-zA-Z_]\w*)/g, (_, paramName) => {
        paramNames.push(paramName);
        return '([^/]+)';
      })
      .replace(/\//g, '\\/');

    return {
      pattern: new RegExp(`^${regexStr}$`),
      paramNames,
    };
  }

  // 注册路由的通用方法
  private addRoute(method: HttpMethod, path: string, handler: RouteHandler): void {
    const { pattern, paramNames } = this.pathToRegex(path);
    this.routes.push({ method, pattern, paramNames, handler });
  }

  // HTTP方法快捷方式
  get(path: string, handler: RouteHandler): void {
    this.addRoute('GET', path, handler);
  }

  post(path: string, handler: RouteHandler): void {
    this.addRoute('POST', path, handler);
  }

  put(path: string, handler: RouteHandler): void {
    this.addRoute('PUT', path, handler);
  }

  delete(path: string, handler: RouteHandler): void {
    this.addRoute('DELETE', path, handler);
  }

  patch(path: string, handler: RouteHandler): void {
    this.addRoute('PATCH', path, handler);
  }

  // 处理请求
  async handle(req: http.IncomingMessage, res: http.ServerResponse): Promise<void> {
    const url = new URL(req.url!, `http://${req.headers.host}`);
    const method = req.method as HttpMethod;

    for (const route of this.routes) {
      if (route.method !== method) continue;

      const match = url.pathname.match(route.pattern);
      if (match) {
        // 提取路径参数
        const params: RouteParams = {};
        route.paramNames.forEach((name, index) => {
          params[name] = decodeURIComponent(match[index + 1]);
        });

        const ctx: RouteContext = { req, res, params, query: url.searchParams };

        try {
          await route.handler(ctx);
        } catch (error) {
          console.error('Route handler error:', error);
          res.writeHead(500, { 'Content-Type': 'application/json' });
          res.end(JSON.stringify({ error: 'Internal Server Error' }));
        }
        return;
      }
    }

    // 没有匹配的路由
    res.writeHead(404, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ error: 'Not Found' }));
  }
}

// 使用我们的路由器
const router = new Router();

router.get('/', ({ res }) => {
  res.end('Home Page');
});

router.get('/api/users', ({ res, query }) => {
  const page = parseInt(query.get('page') || '1');
  const limit = parseInt(query.get('limit') || '10');
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ page, limit, users: [] }));
});

router.get('/api/users/:id', ({ res, params }) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ id: params.id, name: 'Alice' }));
});

router.post('/api/users', ({ res }) => {
  res.writeHead(201, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ message: 'User created' }));
});

router.get('/api/users/:userId/posts/:postId', ({ res, params }) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({
    userId: params.userId,
    postId: params.postId,
  }));
});

// 启动服务器
const server = http.createServer((req, res) => router.handle(req, res));
server.listen(3000, () => {
  console.log('Router server running on http://localhost:3000');
});
```

恭喜！你刚刚实现了Express路由器的核心功能（Express的实现更复杂，但原理就是这样）。

## 14.5 静态文件服务器实现

让我们构建一个能托管静态文件的服务器，这可是很多Web开发的基础需求：

```typescript
import http from 'node:http';
import { createReadStream } from 'node:fs';
import { stat, readdir } from 'node:fs/promises';
import path from 'node:path';
import { pipeline } from 'node:stream/promises';
import { createGzip, createBrotliCompress } from 'node:zlib';

// MIME类型映射
const MIME_TYPES: Record<string, string> = {
  '.html': 'text/html; charset=utf-8',
  '.css': 'text/css',
  '.js': 'application/javascript',
  '.json': 'application/json',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
  '.jpeg': 'image/jpeg',
  '.gif': 'image/gif',
  '.svg': 'image/svg+xml',
  '.ico': 'image/x-icon',
  '.woff': 'font/woff',
  '.woff2': 'font/woff2',
  '.mp4': 'video/mp4',
  '.pdf': 'application/pdf',
  '.zip': 'application/zip',
  '.txt': 'text/plain; charset=utf-8',
};

function getMimeType(filePath: string): string {
  const ext = path.extname(filePath).toLowerCase();
  return MIME_TYPES[ext] || 'application/octet-stream';
}

// 静态文件服务器
class StaticServer {
  private root: string;

  constructor(rootDir: string) {
    this.root = path.resolve(rootDir);
  }

  async handle(req: http.IncomingMessage, res: http.ServerResponse): Promise<void> {
    // 只处理 GET 和 HEAD 请求
    if (req.method !== 'GET' && req.method !== 'HEAD') {
      res.writeHead(405);
      res.end('Method Not Allowed');
      return;
    }

    const url = new URL(req.url!, `http://${req.headers.host}`);
    let filePath = path.join(this.root, decodeURIComponent(url.pathname));

    // 安全检查：防止目录遍历攻击
    // 比如请求 /../../../etc/passwd
    if (!filePath.startsWith(this.root)) {
      res.writeHead(403);
      res.end('Forbidden');
      return;
    }

    try {
      const stats = await stat(filePath);

      // 如果是目录，尝试返回 index.html
      if (stats.isDirectory()) {
        filePath = path.join(filePath, 'index.html');
        const indexStats = await stat(filePath).catch(() => null);
        if (!indexStats) {
          // 没有index.html，返回目录列表
          await this.serveDirectory(url.pathname, filePath, res);
          return;
        }
      }

      await this.serveFile(filePath, req, res);
    } catch (err: any) {
      if (err.code === 'ENOENT') {
        res.writeHead(404, { 'Content-Type': 'text/plain' });
        res.end('404 Not Found');
      } else {
        res.writeHead(500);
        res.end('Internal Server Error');
      }
    }
  }

  private async serveFile(
    filePath: string,
    req: http.IncomingMessage,
    res: http.ServerResponse,
  ): Promise<void> {
    const stats = await stat(filePath);
    const mimeType = getMimeType(filePath);

    // ETag（基于文件大小和修改时间）
    const etag = `"${stats.size.toString(16)}-${stats.mtimeMs.toString(16)}"`;
    const lastModified = stats.mtime.toUTCString();

    // 条件请求处理（304 Not Modified）
    if (req.headers['if-none-match'] === etag ||
        req.headers['if-modified-since'] === lastModified) {
      res.writeHead(304);
      res.end();
      return;
    }

    // 响应头
    const headers: Record<string, string | number> = {
      'Content-Type': mimeType,
      'Content-Length': stats.size,
      'ETag': etag,
      'Last-Modified': lastModified,
      'Cache-Control': 'public, max-age=86400', // 缓存1天
    };

    // 内容压缩
    const acceptEncoding = req.headers['accept-encoding'] || '';
    let encoding: string | null = null;

    if (acceptEncoding.includes('br') && stats.size > 1024) {
      encoding = 'br';
      headers['Content-Encoding'] = 'br';
      delete headers['Content-Length']; // 压缩后长度变了
    } else if (acceptEncoding.includes('gzip') && stats.size > 1024) {
      encoding = 'gzip';
      headers['Content-Encoding'] = 'gzip';
      delete headers['Content-Length'];
    }

    res.writeHead(200, headers);

    if (req.method === 'HEAD') {
      res.end();
      return;
    }

    const fileStream = createReadStream(filePath);

    if (encoding === 'br') {
      await pipeline(fileStream, createBrotliCompress(), res);
    } else if (encoding === 'gzip') {
      await pipeline(fileStream, createGzip(), res);
    } else {
      await pipeline(fileStream, res);
    }
  }

  private async serveDirectory(
    urlPath: string,
    dirPath: string,
    res: http.ServerResponse,
  ): Promise<void> {
    const actualDir = path.dirname(dirPath); // 去掉尾部的 index.html
    const entries = await readdir(actualDir, { withFileTypes: true });

    const html = `
<!DOCTYPE html>
<html>
<head><title>Index of ${urlPath}</title></head>
<body>
  <h1>Index of ${urlPath}</h1>
  <ul>
    ${urlPath !== '/' ? '<li><a href="../">../</a></li>' : ''}
    ${entries
      .map((entry) => {
        const name = entry.isDirectory() ? `${entry.name}/` : entry.name;
        return `<li><a href="${name}">${name}</a></li>`;
      })
      .join('\n    ')}
  </ul>
</body>
</html>`;

    res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    res.end(html);
  }
}

// 使用
const staticServer = new StaticServer('./public');
const server = http.createServer((req, res) => staticServer.handle(req, res));
server.listen(3000, () => {
  console.log('Static file server: http://localhost:3000');
});
```

这个静态文件服务器具备了：

- MIME类型识别
- 目录遍历攻击防护
- ETag/Last-Modified 条件请求（304）
- Gzip/Brotli 压缩
- 目录列表展示
- HEAD 请求支持

## 14.6 HTTP/2模块入门

HTTP/2 带来了多路复用、头部压缩、服务器推送等特性。Node.js通过 `http2` 模块提供支持：

```typescript
import http2 from 'node:http2';
import { readFileSync } from 'node:fs';

// HTTP/2 通常需要TLS（浏览器要求HTTPS）
const server = http2.createSecureServer({
  key: readFileSync('./certs/server.key'),
  cert: readFileSync('./certs/server.crt'),
});

server.on('stream', (stream, headers) => {
  const method = headers[':method'];
  const path = headers[':path'];

  console.log(`${method} ${path}`);

  // HTTP/2 使用stream而不是req/res
  stream.respond({
    ':status': 200,
    'content-type': 'text/html; charset=utf-8',
  });

  stream.end('<h1>Hello HTTP/2!</h1>');

  // 服务器推送（Server Push）
  // 在客户端请求HTML时，主动推送CSS和JS
  if (path === '/index.html') {
    stream.pushStream({ ':path': '/style.css' }, (err, pushStream) => {
      if (err) return;
      pushStream.respond({
        ':status': 200,
        'content-type': 'text/css',
      });
      pushStream.end('body { color: red; }');
    });
  }
});

server.listen(8443, () => {
  console.log('HTTP/2 server running on https://localhost:8443');
});
```

> **注意**：HTTP/2 Server Push已被Chrome等浏览器逐步弃用（因为在实践中收益不大，还增加了复杂性）。但了解它的存在仍然有价值。

### 14.6.1 兼容模式

如果你想同时支持HTTP/1.1和HTTP/2，可以使用兼容模式：

```typescript
import http2 from 'node:http2';
import { readFileSync } from 'node:fs';

const server = http2.createSecureServer(
  {
    key: readFileSync('./certs/server.key'),
    cert: readFileSync('./certs/server.crt'),
    allowHTTP1: true, // 允许HTTP/1.1降级
  },
  (req, res) => {
    // 这个回调的API和http模块一模一样！
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end(`Hello! You're using HTTP/${req.httpVersion}`);
  }
);

server.listen(8443);
```

## 14.7 Keep-Alive与连接管理

### 14.7.1 什么是Keep-Alive？

HTTP/1.0时代，每个请求都要建立一个新的TCP连接：三次握手 → 发请求 → 收响应 → 四次挥手。如果一个网页有50个资源（HTML + CSS + JS + 图片），就要建立50次TCP连接，效率极低。

HTTP/1.1默认启用Keep-Alive：一个TCP连接上可以发送多个请求/响应，复用连接。

```typescript
import http from 'node:http';

const server = http.createServer((req, res) => {
  // Node.js的HTTP/1.1服务器默认Keep-Alive
  // 但你可以控制超时时间
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello');
});

// Keep-Alive超时：空闲连接保持多久后关闭
server.keepAliveTimeout = 5000; // 5秒（默认值）

// 头部解析超时：防止慢速攻击
server.headersTimeout = 60000; // 60秒

// 请求超时
server.requestTimeout = 300000; // 5分钟（Node.js 18+）

// 最大连接数
server.maxConnections = 1000;

server.listen(3000);
```

### 14.7.2 连接池（客户端侧）

当Node.js作为HTTP客户端时，也需要管理连接：

```typescript
import http from 'node:http';

// 自定义Agent管理连接池
const agent = new http.Agent({
  keepAlive: true,         // 保持空闲连接
  keepAliveMsecs: 1000,   // Keep-Alive探测间隔
  maxSockets: 50,          // 每个主机最大连接数
  maxTotalSockets: 200,    // 总最大连接数
  maxFreeSockets: 10,      // 最大空闲连接数
});

// 使用自定义agent
http.get('http://example.com/api', { agent }, (res) => {
  // ...
});

// 或者使用全局默认agent（Node.js 19+ 默认启用Keep-Alive）
console.log(http.globalAgent.options);
```

## 14.8 实战：纯HTTP模块构建REST API

让我们不用任何框架，构建一个完整的待办事项（Todo）REST API：

```typescript
import http from 'node:http';
import crypto from 'node:crypto';

// ============ 类型定义 ============
interface Todo {
  id: string;
  title: string;
  completed: boolean;
  createdAt: string;
  updatedAt: string;
}

interface ApiResponse<T = unknown> {
  success: boolean;
  data?: T;
  error?: string;
  meta?: Record<string, unknown>;
}

// ============ 数据存储（内存） ============
const todos: Map<string, Todo> = new Map();

// 预填充一些数据
const seedTodo = (title: string): void => {
  const id = crypto.randomUUID();
  todos.set(id, {
    id,
    title,
    completed: false,
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString(),
  });
};
seedTodo('学习Node.js HTTP模块');
seedTodo('构建REST API');

// ============ 工具函数 ============
async function parseJSON(req: http.IncomingMessage): Promise<unknown> {
  const chunks: Buffer[] = [];
  for await (const chunk of req) {
    chunks.push(chunk as Buffer);
  }
  const raw = Buffer.concat(chunks).toString('utf-8');
  if (!raw) return null;
  return JSON.parse(raw);
}

function sendJSON<T>(
  res: http.ServerResponse,
  statusCode: number,
  data: ApiResponse<T>,
): void {
  const json = JSON.stringify(data, null, 2);
  res.writeHead(statusCode, {
    'Content-Type': 'application/json; charset=utf-8',
    'Content-Length': Buffer.byteLength(json),
    'Access-Control-Allow-Origin': '*',
  });
  res.end(json);
}

// ============ 路由处理器 ============
async function handleGetTodos(
  req: http.IncomingMessage,
  res: http.ServerResponse,
  query: URLSearchParams,
): Promise<void> {
  const page = parseInt(query.get('page') || '1');
  const limit = parseInt(query.get('limit') || '10');
  const completed = query.get('completed');

  let todoList = Array.from(todos.values());

  // 过滤
  if (completed !== null) {
    todoList = todoList.filter((t) => t.completed === (completed === 'true'));
  }

  // 分页
  const total = todoList.length;
  const start = (page - 1) * limit;
  const paginatedList = todoList.slice(start, start + limit);

  sendJSON(res, 200, {
    success: true,
    data: paginatedList,
    meta: { page, limit, total, totalPages: Math.ceil(total / limit) },
  });
}

async function handleGetTodo(
  res: http.ServerResponse,
  id: string,
): Promise<void> {
  const todo = todos.get(id);
  if (!todo) {
    sendJSON(res, 404, { success: false, error: 'Todo not found' });
    return;
  }
  sendJSON(res, 200, { success: true, data: todo });
}

async function handleCreateTodo(
  req: http.IncomingMessage,
  res: http.ServerResponse,
): Promise<void> {
  const body = (await parseJSON(req)) as { title?: string } | null;

  if (!body?.title || typeof body.title !== 'string' || body.title.trim() === '') {
    sendJSON(res, 400, { success: false, error: 'Title is required' });
    return;
  }

  const id = crypto.randomUUID();
  const todo: Todo = {
    id,
    title: body.title.trim(),
    completed: false,
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString(),
  };

  todos.set(id, todo);
  sendJSON(res, 201, { success: true, data: todo });
}

async function handleUpdateTodo(
  req: http.IncomingMessage,
  res: http.ServerResponse,
  id: string,
): Promise<void> {
  const todo = todos.get(id);
  if (!todo) {
    sendJSON(res, 404, { success: false, error: 'Todo not found' });
    return;
  }

  const body = (await parseJSON(req)) as Partial<Pick<Todo, 'title' | 'completed'>> | null;
  if (!body) {
    sendJSON(res, 400, { success: false, error: 'Request body is empty' });
    return;
  }

  if (body.title !== undefined) todo.title = body.title;
  if (body.completed !== undefined) todo.completed = body.completed;
  todo.updatedAt = new Date().toISOString();

  sendJSON(res, 200, { success: true, data: todo });
}

async function handleDeleteTodo(
  res: http.ServerResponse,
  id: string,
): Promise<void> {
  if (!todos.has(id)) {
    sendJSON(res, 404, { success: false, error: 'Todo not found' });
    return;
  }
  todos.delete(id);
  sendJSON(res, 204, { success: true });
}

// ============ 主路由 ============
const server = http.createServer(async (req, res) => {
  const url = new URL(req.url!, `http://${req.headers.host}`);
  const { pathname } = url;
  const method = req.method!;

  // CORS预检请求处理
  if (method === 'OPTIONS') {
    res.writeHead(204, {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, PUT, PATCH, DELETE, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization',
      'Access-Control-Max-Age': '86400',
    });
    res.end();
    return;
  }

  // 请求日志
  const startTime = Date.now();
  res.on('finish', () => {
    const duration = Date.now() - startTime;
    console.log(`${method} ${pathname} ${res.statusCode} - ${duration}ms`);
  });

  try {
    // 路由匹配
    if (pathname === '/api/todos' && method === 'GET') {
      await handleGetTodos(req, res, url.searchParams);
    } else if (pathname === '/api/todos' && method === 'POST') {
      await handleCreateTodo(req, res);
    } else if (pathname.match(/^\/api\/todos\/[\w-]+$/) && method === 'GET') {
      const id = pathname.split('/')[3];
      await handleGetTodo(res, id);
    } else if (pathname.match(/^\/api\/todos\/[\w-]+$/) && (method === 'PUT' || method === 'PATCH')) {
      const id = pathname.split('/')[3];
      await handleUpdateTodo(req, res, id);
    } else if (pathname.match(/^\/api\/todos\/[\w-]+$/) && method === 'DELETE') {
      const id = pathname.split('/')[3];
      await handleDeleteTodo(res, id);
    } else {
      sendJSON(res, 404, { success: false, error: 'Endpoint not found' });
    }
  } catch (error) {
    console.error('Unhandled error:', error);
    sendJSON(res, 500, { success: false, error: 'Internal Server Error' });
  }
});

server.listen(3000, () => {
  console.log('🚀 Todo API running on http://localhost:3000');
  console.log('Endpoints:');
  console.log('  GET    /api/todos');
  console.log('  POST   /api/todos');
  console.log('  GET    /api/todos/:id');
  console.log('  PUT    /api/todos/:id');
  console.log('  DELETE /api/todos/:id');
});
```

## 14.9 fetch()：Node.js内置HTTP客户端

从Node.js 18开始，全局 `fetch()` 函数终于来了！再也不需要 `node-fetch` 或 `axios` 做简单的HTTP请求了：

```typescript
// Node.js 18+ 内置fetch（基于undici）

// GET请求
async function getUsers(): Promise<void> {
  const response = await fetch('https://jsonplaceholder.typicode.com/users');

  console.log('Status:', response.status);
  console.log('Headers:', Object.fromEntries(response.headers));

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${response.statusText}`);
  }

  const users = await response.json();
  console.log('Users:', users);
}

// POST请求
async function createPost(): Promise<void> {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer my-token',
    },
    body: JSON.stringify({
      title: 'Hello from Node.js fetch!',
      body: 'This is amazing',
      userId: 1,
    }),
  });

  const result = await response.json();
  console.log('Created:', result);
}

// 带超时的请求
async function fetchWithTimeout(): Promise<void> {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), 5000); // 5秒超时

  try {
    const response = await fetch('https://httpbin.org/delay/10', {
      signal: controller.signal,
    });
    const data = await response.json();
    console.log(data);
  } catch (error: any) {
    if (error.name === 'AbortError') {
      console.log('请求超时了！');
    } else {
      throw error;
    }
  } finally {
    clearTimeout(timeoutId);
  }
}

// 流式读取响应体
async function streamResponse(): Promise<void> {
  const response = await fetch('https://example.com/large-file');
  const reader = response.body!.getReader();

  let receivedBytes = 0;
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    receivedBytes += value.length;
    console.log(`已接收: ${receivedBytes} bytes`);
  }
}

// 并发请求
async function parallelFetch(): Promise<void> {
  const urls = [
    'https://jsonplaceholder.typicode.com/posts/1',
    'https://jsonplaceholder.typicode.com/posts/2',
    'https://jsonplaceholder.typicode.com/posts/3',
  ];

  const results = await Promise.all(
    urls.map(async (url) => {
      const res = await fetch(url);
      return res.json();
    })
  );

  console.log('All results:', results);
}
```

> **fetch vs http.request vs axios vs got**
>
> - `fetch()`：标准API，适合大多数场景，Node.js 18+内置
> - `http.request()`：最底层，控制力最强，适合需要精细控制的场景
> - `undici`：fetch的底层实现，性能最好，适合高并发场景
> - `axios`：功能丰富（拦截器、取消、进度），适合复杂业务场景

## 14.10 常见坑点

1. **忘记调用 `res.end()`**：请求会一直挂着，浏览器转圈圈，直到超时。
2. **多次调用 `res.end()`**：第二次会报错 `write after end`。
3. **异步操作中忘记错误处理**：未捕获的错误会导致连接中断。
4. **不设置 Content-Type**：浏览器可能无法正确显示内容。
5. **请求体大小不限制**：恶意请求可以发送超大body耗尽内存。

```typescript
// 限制请求体大小
function parseBodyWithLimit(
  req: http.IncomingMessage,
  maxSize: number = 1024 * 1024, // 默认1MB
): Promise<string> {
  return new Promise((resolve, reject) => {
    let size = 0;
    const chunks: Buffer[] = [];

    req.on('data', (chunk: Buffer) => {
      size += chunk.length;
      if (size > maxSize) {
        req.destroy(); // 立即断开连接
        reject(new Error('Payload too large'));
        return;
      }
      chunks.push(chunk);
    });

    req.on('end', () => resolve(Buffer.concat(chunks).toString()));
    req.on('error', reject);
  });
}
```

1. **目录遍历攻击**：用户请求 `/../../../etc/passwd` 时，你的文件服务器可能泄露系统文件。务必校验路径。

## 14.11 本章小结

| 概念 | 关键点 |
| ------ | -------- |
| HTTP本质 | TCP上的文本协议，Node.js用llhttp解析器 |
| Request | method, url, headers, body(流式读取) |
| Response | statusCode, setHeader, write, end |
| 路由 | URL模式匹配 + 方法匹配 → 路由器 |
| 静态文件 | Stream传输 + MIME类型 + ETag缓存 + 压缩 |
| HTTP/2 | 多路复用，stream API，需TLS |
| Keep-Alive | 连接复用，减少TCP握手开销 |
| fetch() | Node.js 18+内置，基于undici |

**记住**：HTTP模块就像是手动挡汽车——掌握它，你就真正理解了Web服务器的运作方式。框架只是帮你换成了自动挡，但方向盘还是你在掌控。
