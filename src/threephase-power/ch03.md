# 第3章 星形与三角形接法：Y/Δ的原理与应用

小王第一次打开电机接线盒的时候，整个人都懵了。盒子里面整整齐齐排列着六个接线端子，上面分别标着U1、V1、W1和U2、V2、W2，旁边还有三块铜质的连接片。他本以为电机就跟家里的灯泡一样，接两根线就能亮——结果这里有六个端子，他完全不知道该把三根电源线接到哪三个上面。

师傅老张走过来，看了一眼接线盒说："这是Y接还是Δ接？"小王一脸茫然："Y接？Δ接？这不是英文字母吗？"老张笑了一声："这是两种最基本的三相电机接线方式。同一个电机，Y接和Δ接的性能完全不同——启动电流、运行功率、转矩特性都不一样。你要是在工厂干电气，这个是必修课。"

小王后来才知道，那六个端子对应的是电机内部三组绕组的首尾端。U1-U2是A相绕组的首尾，V1-V2是B相绕组的首尾，W1-W2是C相绕组的首尾。三块铜片的不同连接方式，就能把三组独立绕组组成星形（Y）或三角形（Δ），而这两种接法背后，隐藏着电压和电流的深层数学关系。

## 3.1 星形接法（Y接）

星形接法的做法是：将三组绕组的一个端（通常是尾端U2、V2、W2）连接在一起，形成一个公共节点，叫做**中性点**（用字母N表示）。三根电源线分别接到三组绕组的另一端（首端U1、V1、W1）。连接片把U2、V2、W2短接在一起，形如字母"Y"——三组绕组从中心向外呈放射状展开。

在Y接中，有两个关键的电压和电流关系：

**电压关系：线电压是相电压的√3倍。** 线电压是两根相线之间的电压（如UAB），相电压是每相绕组两端的电压（即相线与中性点之间的电压，如UAN）。根据第1章的推导，UAB = UA - UB，两个幅值相等、相位差120°的相量之差，幅值是原来的√3倍。所以UL = √3 × UP。例如相电压为220V时，线电压为220×√3≈380V。

**电流关系：线电流等于相电流。** 因为在Y接中，每根相线直接串联在对应相的绕组上（相线→绕组→中性点），流过相线的电流就是流过绕组的电流，没有分支。所以IL = IP。

## 3.2 三角形接法（Δ接）

三角形接法的做法是：将三组绕组首尾相接，形成一个闭合的三角形回路。具体接法是U1接W2、V1接U2、W1接V2，然后从三个连接点（U1-W2、V1-U2、W1-V2）分别引出三根电源线。

在Δ接中，电压和电流的关系与Y接恰好相反：

**电压关系：线电压等于相电压。** 因为每相绕组直接接在两根相线之间，绕组两端的电压就是线电压。所以UL = UP。

**电流关系：线电流是相电流的√3倍。** 在Δ接的每个节点处（例如U1-W2节点），一根相线的电流分为两路流入两相绕组。根据基尔霍夫电流定律（KCL），线电流等于两相电流之差（矢量差）。三相平衡时，两个幅值相等、相位差120°的相电流之差，幅值是原来的√3倍（与Y接中电压的√3关系数学上完全相同）。所以IL = √3 × IP。

## 3.3 Y接与Δ接的对比

| 比较项目 | 星形接法（Y接） | 三角形接法（Δ接） |
| --------- | --------------- | ----------------- |
| 线电压与相电压 | UL = √3 × UP | UL = UP |
| 线电流与相电流 | IL = IP | IL = √3 × IP |
| 同一电源下绕组承受电压 | UP = UL/√3（较低） | UP = UL（较高） |
| 同一电源下绕组电流 | IP = IL（较低） | IP = IL/√3（较高） |
| 总功率（同一电源同一电机） | P_Y = √3×UL×IL×cosφ（较小） | P_Δ = 3×P_Y（较大） |
| 启动电流 | 较小（约为Δ接的1/3） | 较大 |

**核心规律：** 同一台电机在同一电源（如380V）下，Δ接时每相绕组承受380V全压，Y接时只承受380/√3≈220V。绕组电压降低了√3倍，电流也降低√3倍，功率降低为原来的1/3（电压降√3，电流降√3，功率=电压×电流，降为1/3）。这就是为什么Y接启动电流小但功率也小，Δ接启动电流大但功率足。

## 3.4 Y-Δ启动的原理

大功率三相电机（通常7.5kW以上）直接Δ接全压启动时，启动电流可达额定电流的5-7倍。一台30kW电机额定电流约56A，直接启动电流可达280-392A！这么大的电流冲击会导致：供电线路电压骤降，影响同一电网上其他设备正常运行；电机绕组受到巨大的电动力冲击；断路器需要很大的分断能力。

Y-Δ启动就是为了解决这个问题而设计的启动方式：启动时先把电机接成Y形，运行时切换为Δ形。

**启动阶段（Y接）：** 每相绕组承受的电压为线电压的1/√3（即220V），启动电流为全压启动的1/3，启动转矩也降为全压启动的1/3（因为转矩与电压的平方成正比）。

**运行阶段（Δ接）：** 当电机转速接近额定转速后（通常经过几秒到十几秒的延时），通过时间继电器自动切换为Δ接法，每相绕组承受全压380V，电机输出额定功率。

用水管类比：Y接启动就像先用细水管给水池灌水（水流小、冲击小），等水池灌到一定水位后，再换成粗水管全速灌满——既避免了水压冲击管道，又能在需要时获得最大流量。

## 3.5 中性线的作用

在Y接三相四线制系统中，中性线（零线）的角色极为关键。当三相负载完全对称时（如三相电机），三相电流之和为零，中性线上没有电流流过——理论上中性线可以省略，变成三相三线制。

但在实际配电系统中，负载几乎不可能完全对称。工厂里A相接了一批照明灯，B相接了几台小型设备，C相接了空调——各相负载阻抗不同，三相电流不相等，它们的矢量和不为零。这时，不平衡电流必须通过中性线回流到电源中性点。

如果没有中性线（或者中性线断了），不平衡电流无处可去，就会导致**中性点偏移**——负载侧的中性点电位不再为零，各相负载上的电压不再相等。负载阻抗大的那一相，电压会升高；负载阻抗小的那一相，电压会降低。极端情况下，轻载相的电压可能接近线电压380V，接在这一相上的220V设备（如照明灯）就会被烧毁。这就是为什么电气规范严格要求：中性线必须有足够的截面积，且严禁在中性线上安装开关或熔断器。

## 3.6 常见错误与注意事项

**错误一：同一台电机接错了Y/Δ。** 额定"380V Δ接"的电机如果误接成Y接，绕组电压只有220V，电机出力不足，长时间轻载运行可能导致过热。额定"220/380V（Δ/Y）"的电机，在380V电源下应该Y接，如果误接成Δ接，绕组承受380V全压（超过额定220V），电流剧增，电机很快就会烧毁。

**错误二：Y-Δ启动时间设置不当。** 如果从Y切换到Δ的时机太早（电机还没加速到足够转速），切换瞬间的电流冲击几乎等于直接启动，失去了降压启动的意义；如果切换太晚，电机长时间运行在低压状态同样会过热。通常由时间继电器设定3-15秒的延时。

**错误三：忽视电机铭牌上的接法标注。** 电机铭牌上标注的"接法"一栏（如Δ/Y 380/660V）是必须严格遵守的。它告诉你：在380V电源下用Δ接，在660V电源下用Y接——因为两种接法下绕组承受的电压相同（都是380V）。不读铭牌就接线，等于闭眼开车。

## 3.7 本章小结

星形接法中，线电压是相电压的√3倍，线电流等于相电流；三角形接法中，线电压等于相电压，线电流是相电流的√3倍。同一台电机在同一电源下，Y接功率是Δ接的1/3，Y接启动电流也是Δ接的1/3。Y-Δ启动利用Y接降压启动、Δ接全压运行，是大功率电机最常用的启动方式。中性线在三相不平衡负载中承担不平衡电流，其完整性和截面积至关重要。

## 3.8 练习题

**第1题：** 一台三相异步电机铭牌标注"380V/660V，Δ/Y接"。现在电源电压是380V，请问应该采用哪种接法？如果误接成另一种接法会发生什么？

**第2题：** 一台额定功率15kW的三相电机（额定电压380V，功率因数0.85），在Δ接法下运行时的线电流是多少？如果改为Y接法（同一电源），绕组上的电压和电流各变为多少？电机输出功率变为多少？

**第3题：** 某工厂三相四线制供电系统中，A相接了10kW照明负载，B相接了5kW负载，C相接了2kW负载。试分析如果此时中性线断开，会发生什么现象？

**参考答案**

**第1题：** 380V电源应采用Δ接法（铭牌标注380V对应Δ接），此时每相绕组承受380V额定电压。如果误接成Y接，每相绕组电压降为380/√3≈220V，电机出力不足。反过来，如果660V电源下误接成Δ接，每相绕组承受660V（远超380V额定值），电流激增，电机烧毁。铭牌标注的核心原则是：无论哪种接法，绕组实际承受的电压应等于其设计值380V。

**第2题：** Δ接运行时：IL=P/(√3×UL×cosφ)=15000/(1.732×380×0.85)≈26.8A。IP=IL/√3≈15.5A，每相绕组电压380V。改为Y接后：每相绕组电压=380/√3≈220V，每相绕组电流=220V/Z（Z为绕组阻抗）。因为绕组阻抗不变，电压降为原来的1/√3，电流也降为原来的1/√3。所以相电流=15.5/√3≈8.95A，线电流=相电流=8.95A。功率=3×220×8.95×0.85≈5kW，约为原来的1/3。

**第3题：** 中性线断开后，三相不平衡负载的中性点发生偏移。由于A相负载最重（阻抗最小），B相次之，C相最轻（阻抗最大），中性点电位向阻抗最大的C相偏移。结果是C相负载上的电压升高（可能远超220V，接近线电压380V），C相上的2kW设备可能被烧毁；A相负载上的电压降低（可能只有100多伏），照明灯变暗甚至不亮。这就是中性线断线事故的典型后果——三相越不平衡，中性点偏移越严重，危害越大。
