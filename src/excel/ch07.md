# 第7章：条件格式——让数据自己"说话" 🌈

*小王盯着30天的销售数据表看了半天，想找出哪些天卖得特别好、哪些天惨淡，但黑白的数字看得他眼花。他问小李："有没有办法让好的数据自动变绿色，差的数据自动变红色？"小李一拍大腿："条件格式啊！它就是你要的。"*

## 7.1 条件格式是什么？为什么重要

**条件格式**就是根据你设定的规则，自动给单元格"上色"或添加格式。满足条件的单元格会自动变色、加粗、加边框等，让你的数据一眼就能看出重点。

你可以把它理解为**数据的"红绿灯"**：

- 卖得好的日子 → 绿色（看起来就开心）
- 卖得一般的日子 → 黄色（还需要努力）
- 卖得差的日子 → 红色（警报！）

为什么重要？因为人眼对颜色的敏感度远高于对数字的敏感度。一张密密麻麻的数据表，加上条件格式后，关键信息立刻"跳"出来。

## 7.2 内置规则：突出显示、前N项、高于/低于平均值

Excel内置了很多条件格式规则，操作非常简单。

**操作方法**

选中数据区域 → "开始"选项卡 → "条件格式" → 选择规则类型。

**① 突出显示单元格规则**

- **大于**：选中金额列 → 条件格式 → 突出显示单元格规则 → 大于 → 输入 `400` → 选择"浅红填充色深红色文本" → 确定。这样金额超过400的单元格就会自动变红。
- **小于**：同理，金额小于200的自动标记。
- **介于**：金额在300到400之间的标记为黄色。
- **等于**：找出特定值。
- **文本包含**：包含特定文字的高亮。
- **重复值**：标记重复的数据。

**② 项目选取规则（前N项/后N项）**

- 条件格式 → 项目选取规则 → 前10项 → 自动高亮销售额最高的10天
- 也可以选"前10%"、"后10项"等

**③ 高于/低于平均值**

- 条件格式 → 项目选取规则 → 高于平均值 → 高于平均营业额的天数自动高亮
- 低于平均值 → 低于平均营业额的天数自动高亮

> 💡 **提示**：条件格式是"动态"的——数据变了，格式也会自动跟着变。比如你今天新输入了一天的销售数据，如果它超过了400，就会自动变成红色，不需要重新设置。

## 7.3 数据条、色阶、图标集

这三个是条件格式中的"可视化三件套"，能让数据直接在单元格里展示视觉效果。

**① 数据条**

条件格式 → 数据条 → 选择一种颜色。

效果：每个单元格内会出现一条水平的"进度条"，数值越大条越长。一眼就能看出谁大谁小。

| 商品 | 金额 | 效果 |
| ------ | ------ | ------ |
| 珍珠奶茶 | 480 | ████████████ |
| 红豆奶茶 | 336 | ████████ |
| 芒果冰沙 | 270 | ██████ |

> 💡 **提示**：数据条特别适合展示排名和大小对比。它相当于在单元格内嵌了一个迷你柱形图。

**② 色阶**

条件格式 → 色阶 → 选择一种配色方案。

常见配色：

- **绿-黄-红**：高值绿色、中间黄色、低值红色（适合表示好坏）
- **红-白-蓝**：高值红色、中间白色、低值蓝色（适合表示温度或差异）
- **绿-白**：高值绿色、低值白色（适合只关注高值）

效果：单元格背景色根据数值大小渐变，数值接近的颜色也接近。非常适合看数据的分布和趋势。

**③ 图标集**

条件格式 → 图标集 → 选择图标样式。

- 箭头（上升/持平/下降）
- 交通灯（绿/黄/红）
- 旗帜（三种颜色）
- 星级（1-3星）
- 等等

效果：在单元格值旁边添加一个小图标，直观表示数据属于哪个等级。

> 💡 **提示**：图标集的默认分界点是按百分比分的（前33%、中33%、后33%）。你可以在"条件格式"→"管理规则"→"编辑规则"中自定义分界点，比如改成"≥400绿箭头，≥300黄箭头，<300红箭头"。

## 7.4 自定义公式条件格式

如果内置规则不能满足你的需求，可以用**自定义公式**来创建条件格式。这是条件格式最强大的功能。

**操作方法**

选中数据区域 → 条件格式 → 新建规则 → "使用公式确定要设置格式的单元格" → 输入公式 → 设置格式。

**公式规则**：公式返回 `TRUE` 时，格式生效；返回 `FALSE` 时，格式不生效。

**实例一：高亮整行**

小王想让销售额超过400的那一整行都变色（而不只是金额那一格）：

1. 选中整个数据区域（比如A2:D31）
2. 条件格式 → 新建规则 → 使用公式
3. 输入：`=$D2>400`（注意：D列用绝对引用 `$D`，行号不锁）
4. 设置格式：浅绿填充色
5. 确定

原理：Excel会对每一行检查这个公式，`$D2` 锁定了D列但行号随当前行变化。当D2>400时，A2:D2整行都变绿。

**实例二：标记周末**

小王想标记出周六周日的销售数据行：

```
=WEEKDAY($A2,2)>5
```

`WEEKDAY` 函数返回值1-7（周一=1，周日=7），`>5` 就是周六周日。

**实例三：标记即将过期的库存**

假设B列是保质期，想标记出7天内过期的：

```
=B2-TODAY()<=7
```

> 💡 **提示**：自定义公式条件格式的关键是搞清楚"相对引用和绝对引用"。如果你选中了一个区域，公式中的引用是相对于区域左上角的。通常列用 `$` 锁定（`$D`），行不锁（`2`），这样公式对每一行都生效但始终引用同一列。

## 7.5 管理和清除条件格式规则

设置多了条件格式后，可能需要修改或删除某些规则。

**管理规则**

"开始" → "条件格式" → "管理规则" → 弹出管理器窗口：

- 查看当前工作表中的所有条件格式规则
- 修改规则的公式、格式、应用范围
- 调整规则的优先级（优先级高的规则先执行）
- 勾选"如果为真则停止"（满足某条规则后不再检查后续规则）
- 删除单条规则

**清除规则**

- 清除选中区域的规则：条件格式 → 清除规则 → "清除所选单元格的规则"
- 清除整个工作表的规则：条件格式 → 清除规则 → "清除整个工作表的规则"

> 💡 **提示**：条件格式设太多会让表格变卡（尤其是大数据量时）。建议只用必要的条件格式，不要给整个工作表都加上花哨的规则。

## 7.6 实战：用条件格式制作销售热力图

让我们综合运用条件格式，为小王的奶茶店制作一份"销售热力图"——一眼就能看出哪些天卖得好、哪些天惨淡。

**数据准备**

"日销售记录"工作表：

- A列：日期（1月1日~1月31日）
- B列：珍珠奶茶销量
- C列：红豆奶茶销量
- D列：芒果冰沙销量
- E列：总营业额

**Step 1：给总营业额添加色阶**

选中E2:E32 → 条件格式 → 色阶 → 绿-黄-红色阶。

- 高值（绿色）：营业额好的日子
- 低值（红色）：营业额差的日子

**Step 2：给每种商品添加数据条**

选中B2:B32 → 条件格式 → 数据条 → 蓝色。
同样对C列和D列也添加数据条。

**Step 3：标记销售异常日**

选中A2:E32（整个数据区域） → 条件格式 → 新建规则 → 使用公式：

```
=$E2<1000
```

格式设置为：浅红填充色。效果是营业额低于1000元的日子，整行变红。

**Step 4：标记周末**

再加一条规则：

```
=WEEKDAY($A2,2)>5
```

格式设置为：浅灰背景 + 加粗。效果是周末的行用灰色底纹标记。

**Step 5：标记销量冠军商品**

给每种商品的销量列添加图标集（旗帜）：

- 选中B2:D32 → 条件格式 → 图标集 → 旗帜
- 编辑规则：绿旗 ≥ 30，黄旗 ≥ 20，红旗 < 20

**效果**

现在小王一眼扫过去：

- 绿色行 = 好日子，开心！
- 红色行 = 差日子，需要分析原因
- 灰色行 = 周末（通常客流量不同）
- 数据条 = 每种商品的销量对比
- 旗帜图标 = 每种商品的表现等级

这就是条件格式的力量——**让数据自己开口说话，你只需要看颜色就够了。**
