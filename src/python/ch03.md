# 第 3 章 数据类型与变量

你去超市买东西，水果论斤称，饮料论瓶买，鸡蛋论盒卖——不同的东西有不同的"度量方式"。编程也是如此：整数和浮点数处理方式不同，文字和真假值的存储方式也不同。**数据类型**就是 Python 给数据贴的"标签"，告诉系统："这个数据是什么种类，应该怎么处理它。"

为什么数据类型这么重要？想象你在做一个记账程序。如果你把金额存成了字符串 `"100.50"` 而不是数字 `100.50`，当你试图计算总金额时，Python 不知道怎么做字符串的加法（字符串拼接和数字加法是两回事），程序就会报错。再比如，你想判断用户年龄是否满 18 岁，如果年龄存成了字符串 `"25"`，比较 `"25" >= 18` 会报类型错误。所以，理解数据类型，本质上就是理解"计算机是如何看待和处理数据的"。

Python 内置了几种基本数据类型，每种类型都有自己独特的行为和规则。这一章我们会逐一介绍它们，并且学会如何在不同类型之间进行转换。

## 3.1 数字类型：整数和浮点数

Python 中的数字主要分为两种：**整数**（`int`）和**浮点数**（`float`）。整数就是没有小数点的数，浮点数就是有小数点的数。

```python
# 整数（int）
count = 100
temperature = -5
big_number = 10_000_000  # 可以用下划线分隔，增加可读性，等于 10000000

# 浮点数（float）
price = 19.99
pi = 3.14159
scientific = 2.5e6  # 科学计数法，等于 2500000.0
```

Python 的整数有一个很酷的特性：**不会溢出**。在 C 或 Java 中，整数有上限（比如 32 位整数最大约 21 亿），超过就会溢出出错。但 Python 的整数理论上没有大小限制——你的内存有多大，它就能存多大的数：

```python
# Python 可以处理超大整数
huge = 2 ** 100
print(huge)
# 输出：1267650600228229401496703205376
```

你可以用 `type()` 函数查看任何数据的类型：

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
```

### 浮点数的"精度陷阱"

计算机用二进制存储浮点数，有些十进制小数在二进制中无法精确表示——就像 1/3 在十进制中是 0.3333... 永远写不完一样。这导致了一个经典现象：

```python
print(0.1 + 0.2)
# 输出：0.30000000000000004 （不是 0.3！）

print(0.1 + 0.2 == 0.3)
# 输出：False
```

这不是 Python 的 bug，而是几乎所有编程语言的共性问题。如果需要精确的十进制计算（比如金融场景），可以使用 `decimal` 模块：

```python
from decimal import Decimal

a = Decimal("0.1")
b = Decimal("0.2")
print(a + b)  # 输出：0.3
```

### 复数（complex）

Python 还内置了复数类型，虽然初学者不太常用，但在科学计算和信号处理中会用到：

```python
# 复数由实部和虚部组成，虚部用 j 表示
z = 3 + 4j
print(type(z))      # <class 'complex'>
print(z.real)       # 3.0（实部）
print(z.imag)       # 4.0（虚部）
print(abs(z))       # 5.0（模，即 sqrt(3^2 + 4^2)）
```

### 不同进制的数字

Python 支持直接用前缀表示不同进制的数字，这在处理底层编程或网络协议时很有用：

```python
# 二进制（前缀 0b）
print(0b1010)       # 10
print(bin(42))      # 0b101010（将十进制转为二进制字符串）

# 八进制（前缀 0o）
print(0o17)         # 15
print(oct(15))      # 0o17

# 十六进制（前缀 0x）
print(0xFF)         # 255
print(hex(255))     # 0xff

# 实际用途：颜色代码（RGB）
red = 0xFF0000
green = 0x00FF00
blue = 0x0000FF
print(f"红色：{red}，绿色：{green}，蓝色：{blue}")
```

## 3.2 字符串：文字的容器

字符串（`str`）是 Python 中表示文本的方式。你可以用单引号、双引号、三引号来创建字符串：

```python
# 单引号和双引号效果一样
name1 = 'Alice'
name2 = "Bob"

# 字符串中包含引号
sentence1 = "他说：'你好'"       # 双引号里放单引号
sentence2 = '他说："你好"'       # 单引号里放双引号
sentence3 = "他说：\"你好\""     # 用反斜杠转义

# 三引号：多行字符串
poem = """静夜思
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。"""
print(poem)
```

### 字符串操作

字符串是编程中最常打交道的数据类型之一。Python 提供了丰富的字符串操作：

```python
text = "Hello, Python World!"

# 长度
print(len(text))           # 20

# 大小写转换
print(text.upper())        # HELLO, PYTHON WORLD!
print(text.lower())        # hello, python world!
print(text.title())        # Hello, Python World!

# 查找和替换
print(text.find("Python")) # 7（"Python"从索引 7 开始）
print(text.replace("World", "Universe"))  # Hello, Python Universe!

# 分割和连接
words = text.split(", ")   # ['Hello', 'Python World!']
joined = "-".join(["a", "b", "c"])  # "a-b-c"

# 去除空白
messy = "  hello world  "
print(messy.strip())       # "hello world"
print(messy.lstrip())      # "hello world  "
print(messy.rstrip())      # "  hello world"
```

### 字符串索引和切片

字符串中的每个字符都有一个位置编号（索引），从 0 开始。你可以用索引取出单个字符，或用切片取出一段子串：

```python
s = "Python"

# 索引（从 0 开始）
print(s[0])    # P
print(s[1])    # y
print(s[-1])   # n（-1 表示最后一个字符）
print(s[-2])   # o（-2 表示倒数第二个）

# 切片 [起始:结束]（包含起始，不包含结束）
print(s[0:3])  # Pyt
print(s[2:])   # thon（从索引 2 到末尾）
print(s[:4])   # Pyth（从开头到索引 3）
print(s[::2])  # Pto（每隔一个字符取一个）
print(s[::-1]) # nohtyP（反转字符串）
```

切片是 Python 的一大特色，语法简洁但功能强大。记住口诀：**"左闭右开"**——包含起始位置，不包含结束位置。

### 字符串是不可变的

字符串一旦创建就不能修改单个字符。如果你想"改变"一个字符串，实际上是创建了一个新的字符串：

```python
word = "hello"
# word[0] = "H"  # 这行会报错：TypeError: 'str' object does not support item assignment

# 正确做法：创建新字符串
new_word = "H" + word[1:]
print(new_word)  # Hello
```

### 常用字符串方法速查

字符串方法非常多，这里列出日常开发中最常用的：

```python
text = "  Hello, Python World!  "

# 判断类方法（返回布尔值）
print(text.strip().startswith("Hello"))   # True
print(text.strip().endswith("!"))         # True
print("123abc".isalnum())                 # True（全是字母或数字）
print("123".isdigit())                    # True（全是数字）
print("abc".isalpha())                    # True（全是字母）
print("hello".islower())                  # True（全是小写）
print("Hello".istitle())                  # True（首字母大写）
print("   ".isspace())                    # True（全是空白字符）

# 计数和查找
s = "abracadabra"
print(s.count("a"))       # 5（"a" 出现的次数）
print(s.find("cad"))      # 4（"cad" 第一次出现的起始索引）
print(s.rfind("a"))       # 10（"a" 最后一次出现的索引）
print(s.index("cad"))     # 4（同 find，但找不到会报 ValueError）

# 格式化和对齐
name = "Python"
print(name.center(20, "-"))   # -------Python-------
print(name.ljust(20, "."))    # Python..............
print(name.rjust(20, "."))    # ..............Python
print("42".zfill(5))          # 00042

# 编码相关（处理中文时可能用到）
chinese = "你好世界"
encoded = chinese.encode("utf-8")
print(encoded)               # b'\xe4\xbd\xa0\xe5\xa5\xbd\xe4\xb8\x96\xe7\x95\x8c'
print(encoded.decode("utf-8"))  # 你好世界
```

掌握这些方法不需要死记硬背——在实际编程中多用几次就自然记住了。遇到不确定的方法，可以在 Python 交互式环境中用 `help(str)` 或 `help("".方法名)` 查看文档。

## 3.3 布尔值：True 和 False

布尔类型（`bool`）只有两个值：`True`（真）和 `False`（假）。它看起来简单，却是所有逻辑判断的基础——后面学条件判断和循环时，你会频繁和它打交道。

```python
is_raining = True
is_cold = False

print(type(is_raining))  # <class 'bool'>
print(is_raining)        # True
```

布尔值经常出现在比较运算中：

```python
print(5 > 3)     # True
print(5 < 3)     # False
print(5 == 5)    # True（注意是两个等号，表示"等于"）
print(5 != 3)    # True（不等于）
```

### 真值判断（Truthy 和 Falsy）

在 Python 中，不仅仅是 `True` 和 `False` 有"真假"之分。以下值在条件判断中被视为 `False`（称为"falsy"值）：

- `False`、`None`
- 数字 `0`、`0.0`
- 空字符串 `""`、空列表 `[]`、空字典 `{}`、空元组 `()`

其他所有值都被视为 `True`（称为"truthy"值）。这个特性让代码可以更简洁：

```python
name = ""
if name:
    print(f"你好，{name}")
else:
    print("名字为空")  # 这行会执行

numbers = [1, 2, 3]
if numbers:
    print("列表不为空")  # 这行会执行
```

## 3.4 None：什么都没有

`None` 是 Python 中一个特殊的值，表示"什么都没有"或"空值"。它不等于 0，也不等于空字符串——它是一个独立的值。你可以把它理解成一个"空的快递盒"——盒子存在，但里面什么都没装。

`None` 在很多场景中都会遇到。函数没有 `return` 语句时默认返回 `None`；字典查询不存在的键时可以用 `dict.get(key)` 返回 `None`；数据库查询没有结果时返回 `None`。理解 `None` 的语义，能帮你避免很多"为什么我的变量是 None"的困惑。

```python
result = None
print(result)       # None
print(type(result)) # <class 'NoneType'>

# None 不等于 0 或空字符串
print(None == 0)    # False
print(None == "")   # False
print(None == False) # False

# 判断是否为 None，推荐用 is
print(result is None)  # True
```

`None` 常用于函数的默认返回值、表示"尚未赋值"的状态，或表示"没有找到结果"。

## 3.5 类型转换：给数据"换装"

有时候你需要把一种类型的数据转换成另一种类型。Python 提供了几个内置函数来做这件事：

```python
# 字符串转整数
age_str = "25"
age_int = int(age_str)
print(age_int + 1)  # 26

# 字符串转浮点数
price_str = "19.99"
price_float = float(price_str)
print(price_float * 2)  # 39.98

# 数字转字符串
num = 42
text = str(num)
print("数字是：" + text)  # 数字是：42

# 浮点数转整数（直接截断小数部分，不四舍五入）
print(int(3.9))    # 3
print(int(-2.7))   # -2

# 其他类型转布尔值
print(bool(0))      # False
print(bool(""))     # False
print(bool("hello")) # True
print(bool(42))     # True
print(bool([]))     # False
print(bool([1]))    # True
```

### 转换失败的错误

如果字符串的内容不能合理地转换为目标类型，Python 会报错：

```python
# int("hello")   # ValueError: invalid literal for int()
# float("abc")   # ValueError: could not convert string to float
# int("3.14")    # ValueError: 不能直接把带小数点的字符串转为整数
# 正确做法：先转 float，再转 int
print(int(float("3.14")))  # 3
```

## 3.6 动态类型：变量"不挑食"

Python 是**动态类型**语言，意思是变量的类型由赋给它的值决定，而且可以随时改变：

```python
x = 42          # 此时 x 是 int
print(type(x))  # <class 'int'>

x = "hello"     # 现在 x 变成了 str
print(type(x))  # <class 'str'>

x = [1, 2, 3]   # 现在 x 又变成了 list
print(type(x))  # <class 'list'>
```

这和 Java、C++ 等**静态类型**语言不同——在那些语言中，你声明变量时必须指定类型，而且类型一旦确定就不能变。动态类型让 Python 代码更灵活、更简洁，但也带来了一个风险：你可能不小心给变量赋了错误类型的值，而程序直到运行时才报错。

举个例子：你写了一个函数 `calculate_total(price, quantity)`，期望 `price` 是数字。但某天你不小心传了一个字符串 `"10.5"` 进去。在静态类型语言中，编译器会在你写代码时就提醒"类型不对"；而在 Python 中，错误要到程序运行到那一行时才会暴露。这就是为什么单元测试在 Python 项目中格外重要——它能帮你在代码上线之前就捕获这类类型错误。

### 类型提示（Type Hints）

Python 3.5 引入了类型提示，允许你在代码中标注期望的类型。这些提示不会被 Python 解释器强制执行，但可以帮助 IDE 和类型检查工具（如 mypy）发现潜在错误：

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

age: int = 25
# age = "twenty"  # IDE 会提示类型不匹配，但 Python 不会报错
```

对于初学者来说，类型提示不是必须学的，但了解一下有好处——你在看别人的代码时经常会遇到它。

## 3.7 多重赋值与交换技巧

Python 提供了一些优雅的赋值方式，在其他语言中可能需要好几行才能实现：

```python
# 同时给多个变量赋同一个值
a = b = c = 0
print(a, b, c)  # 0 0 0

# 同时给多个变量赋不同的值
x, y, z = 1, 2, 3
print(x, y, z)  # 1 2 3

# 交换两个变量的值（Python 独有的优雅写法）
x, y = 1, 2
x, y = y, x  # 交换！
print(x, y)  # 2 1

# 在其他语言中，交换需要借助临时变量：
# temp = x
# x = y
# y = temp
```

## 3.8 实战：数据类型处理的常见场景

在实际编程中，数据类型的处理无处不在。这里总结几个你会反复遇到的场景：

```python
# 场景 1：安全地转换用户输入
def safe_int(value, default=0):
    """安全地将值转换为整数，转换失败时返回默认值"""
    try:
        return int(value)
    except (ValueError, TypeError):
        return default

print(safe_int("42"))       # 42
print(safe_int("hello"))    # 0（转换失败，返回默认值）
print(safe_int(None))       # 0
print(safe_int("3.14"))     # 0（不能直接转，需要先转 float）
```

```python
# 场景 2：检查数据类型
def process_data(data):
    """根据数据类型执行不同的处理"""
    if isinstance(data, int):
        print(f"整数：{data}，平方：{data ** 2}")
    elif isinstance(data, float):
        print(f"浮点数：{data:.2f}")
    elif isinstance(data, str):
        print(f"字符串：'{data}'，长度：{len(data)}")
    elif isinstance(data, bool):
        print(f"布尔值：{data}")
    else:
        print(f"未知类型：{type(data)}")

process_data(42)         # 整数：42，平方：1764
process_data(3.14)       # 浮点数：3.14
process_data("Python")   # 字符串：'Python'，长度：6
process_data(True)       # 布尔值：True
```

注意一个细节：`isinstance(True, int)` 的结果是 `True`！因为 `bool` 是 `int` 的子类（`True` 等价于 `1`，`False` 等价于 `0`）。所以在类型检查时，如果你想区分布尔值和整数，应该先检查 `bool`。

```python
# 场景 3：字符串与数字之间的常见转换
# 格式化数字为带千位分隔符的字符串
big_number = 1234567890
print(f"{big_number:,}")       # 1,234,567,890
print(f"{big_number:,.2f}")    # 1,234,567,890.00

# 百分比格式
ratio = 0.8756
print(f"{ratio:.1%}")          # 87.6%

# 科学计数法
avogadro = 602200000000000000000000
print(f"{avogadro:.2e}")       # 6.02e+23

# 固定宽度填充
for i in range(1, 6):
    print(f"第 {i:03d} 号选手")  # 001, 002, 003, 004, 005
```

## 3.9 小结

- Python 的基本数据类型包括：`int`（整数）、`float`（浮点数）、`str`（字符串）、`bool`（布尔值）、`NoneType`（空值）。
- 浮点数存在精度问题，需要精确计算时用 `decimal.Decimal`。
- 字符串支持索引和切片，语法为 `[起始:结束:步长]`，左闭右开。
- 布尔值有 `True` 和 `False`，空值、零、空容器在条件判断中视为 `False`。
- 类型转换用 `int()`、`float()`、`str()`、`bool()` 等内置函数。
- Python 是动态类型语言，变量类型由值决定；类型提示可以增加代码可读性。

## 3.12 常见错误与避坑

- **浮点数比较**：`0.1 + 0.2 == 0.3` 结果是 `False`。比较浮点数时应使用 `math.isclose()` 或 `abs(a - b) < epsilon`。
- **字符串和数字混用**：`"年龄：" + 25` 会报 `TypeError`，因为不能把字符串和数字直接拼接。要么用 `str(25)` 转换，要么用 f-string。
- **int() 不四舍五入**：`int(3.9)` 的结果是 `3`，不是 `4`。如果需要四舍五入，用 `round(3.9)`。
- **可变与不可变类型混淆**：字符串是不可变的，`s[0] = "X"` 会报错。列表是可变的，`lst[0] = "X"` 不会报错。
- **变量覆盖内置名称**：如果你写 `str = "hello"`，就把内置的 `str()` 函数覆盖了，后面再调用 `str(42)` 会报错。避免使用内置函数名作为变量名。
