# 第三章：基础类型系统

TypeScript 的类型系统可以分成几个层次：基础类型、复合类型、函数类型、对象类型、泛型、高级类型。我们从最基础的开始。

## 原始类型

JavaScript 有七种原始类型：`string`、`number`、`boolean`、`bigint`、`symbol`、`null`、`undefined`。TypeScript 都支持。

```ts
let userName: string = "Alice";
let age: number = 25;
let isAdmin: boolean = false;
let bigNumber: bigint = 9007199254740991n;
let uniqueKey: symbol = Symbol("key");
```

注意：

- `number` 包含整数和浮点数，也包含 `NaN` 和 `Infinity`。
- TypeScript 没有单独的 `int`、`float`、`double` 类型。

## any：类型的"逃兵"

`any` 是 TypeScript 中最特殊的类型。它可以被赋值为任何类型，也可以赋值给任何类型。换句话说，它**完全绕过了类型检查**。

```ts
let anything: any = 42;
anything = "hello";
anything.toFixed(); // 编译不报错，但运行时会崩溃
```

`any` 的存在是为了兼容旧的 JavaScript 代码。但在新代码中，应该**尽量避免使用 `any`**。一旦你用了 `any`，TypeScript 就失去了保护你的能力。

可以把它理解为类型系统的"逃兵"：你告诉编译器"别管这个变量了"，那编译器就真的不管了。

## unknown：更安全的 any

`unknown` 和 `any` 类似，也表示"任意类型"，但它更安全。

```ts
let something: unknown = 42;
something = "hello";

// 错误：不能对 unknown 类型的值直接调用方法
something.toUpperCase();
```

使用 `unknown` 时，你必须先通过类型检查（类型收窄），才能安全地操作它。

```ts
if (typeof something === "string") {
  console.log(something.toUpperCase());
}
```

**原则**：如果你不知道一个值的类型，先用 `unknown` 而不是 `any`。

## void、null 和 undefined

- `void`：表示没有返回值，通常用于函数。

```ts
function logMessage(message: string): void {
  console.log(message);
}
```

- `null` 和 `undefined`：分别表示"空值"和"未定义"。

在 TypeScript 中，`null` 和 `undefined` 是两种独立的类型。开启 `strictNullChecks` 后，它们不能随意赋值给其他类型。

```ts
let name: string;
name = undefined; // 错误：strictNullChecks 开启时不能赋值
```

如果想允许为空，需要用联合类型：

```ts
let name: string | null = null;
```

## never：不可能存在的类型

`never` 表示"永远不可能发生的值"。它通常出现在两种场景：

1. 函数永远不会返回（比如抛出异常或死循环）。

```ts
function throwError(message: string): never {
  throw new Error(message);
}
```

1. 穷尽类型检查后的剩余分支。

```ts
type Shape = "circle" | "square";

function getArea(shape: Shape): number {
  switch (shape) {
    case "circle":
      return 3.14;
    case "square":
      return 4;
    default:
      const _exhaustiveCheck: never = shape;
      return _exhaustiveCheck;
  }
}
```

如果后面你给 `Shape` 增加了新的值，但 `switch` 没处理，`default` 分支就会报错，因为 `shape` 的类型不是 `never` 了。这是一种很实用的防御性编程技巧。

## 类型推断

TypeScript 不强制你每个变量都写类型，它会根据赋值自动推断：

```ts
let name = "Alice"; // 推断为 string
let age = 25;       // 推断为 number
let isAdmin = true; // 推断为 boolean
```

这种推断非常可靠，所以很多情况下你可以省略类型注解。但函数参数、函数返回值、复杂对象结构等场景，显式声明类型仍然是个好习惯了。

```ts
// 推荐：明确函数的输入输出
function add(a: number, b: number): number {
  return a + b;
}
```
