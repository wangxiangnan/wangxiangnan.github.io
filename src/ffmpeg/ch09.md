# 第9章：视频剪辑——不用PR也能剪

不是所有剪辑都需要打开一个几十 GB 的专业剪辑软件。很多时候，你只是想截取视频中的一段、做个慢动作、或者把片头去掉——这些用 FFmpeg 一行命令就能搞定。本章教你用命令行完成最常见的剪辑任务。

## 9.1 时间裁剪：-ss 和 -to/-t

**截取从第 10 秒到第 30 秒的片段：**

```bash
ffmpeg -i input.mp4 -ss 00:00:10 -to 00:00:30 -c copy output.mp4
```

参数说明：

- `-ss 00:00:10`：起始时间（时:分:秒）
- `-to 00:00:30`：结束时间
- `-c copy`：不重新编码（快速模式）

**也可以用 `-t` 指定持续时间：**

```bash
# 从第 10 秒开始，持续 20 秒（即到第 30 秒）
ffmpeg -i input.mp4 -ss 00:00:10 -t 00:00:20 -c copy output.mp4
```

**时间格式支持多种写法：**

```bash
# 以下写法等价
-ss 00:01:30     # 1分30秒
-ss 90           # 90秒
-ss 01:30        # 1分30秒（省略小时）
-ss 1.5          # 1.5秒
```

## 9.2 关键帧对齐问题

这是 FFmpeg 裁剪中最容易踩的坑！

**`-ss` 放在 `-i` 前面（快速模式）：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -to 00:02:00 -c copy output.mp4
```

FFmpeg 会快速跳转到第 1:30 之前的最近关键帧，然后开始复制。这意味着实际起始点可能不是精确的 1:30，而是附近的关键帧位置。优点是速度极快。

**`-ss` 放在 `-i` 后面（精确模式）：**

```bash
ffmpeg -i input.mp4 -ss 00:01:30 -to 00:02:00 output.mp4
```

FFmpeg 会从文件开头逐帧解码到 1:30，起始点非常精确。缺点是如果起始时间靠后，需要较长的解码时间。

> 💡 提示：如果不需要精确到帧，用快速模式（`-ss` 在前）配合 `-c copy`，处理速度快到飞起。如果精确度很重要（比如截取特定台词），把 `-ss` 放在 `-i` 后面并重新编码。

**最佳实践——兼顾速度和精度：**

```bash
ffmpeg -ss 00:01:00 -i input.mp4 -ss 00:00:30 -to 00:01:00 -c copy output.mp4
```

第一个 `-ss`（在 `-i` 前）快速跳到 1:00 附近，第二个 `-ss`（在 `-i` 后）再精确前进 30 秒。

## 9.3 快速裁剪 vs 精确裁剪

**快速裁剪（不重编码，可能不精确）：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -t 00:00:20 -c copy output.mp4
```

- 速度：几秒
- 精度：关键帧级别（可能差几秒）
- 质量：零损失

**精确裁剪（重新编码，完全精确）：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -t 00:00:20 -c:v libx264 -crf 23 -c:a aac output.mp4
```

- 速度：取决于片段长度
- 精度：帧级别（完全精确）
- 质量：由 CRF 控制

> 💡 提示：如果你裁剪后发现输出视频的开头多了几秒不想要的画面，就是因为关键帧对齐问题。此时换用精确裁剪即可。

## 9.4 倒放视频

```bash
# 视频和音频都倒放
ffmpeg -i input.mp4 -vf reverse -af areverse output.mp4
```

- `-vf reverse`：视频帧倒序
- `-af areverse`：音频倒序

> ⚠️ 注意：`reverse` 滤镜会将整个视频加载到内存中。视频太长（超过几分钟）可能会导致内存不足。建议先裁剪出短片段再倒放。

**只倒放视频，去掉音频：**

```bash
ffmpeg -i input.mp4 -vf reverse -an output.mp4
```

## 9.5 变速播放

**视频变速：使用 setpts 滤镜**

```bash
# 2倍速播放（时间戳除以2）
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -an output_fast.mp4

# 0.5倍速播放（慢动作，时间戳乘以2）
ffmpeg -i input.mp4 -vf "setpts=2.0*PTS" -an output_slow.mp4
```

PTS = Presentation Time Stamp（显示时间戳）。乘以 0.5 意味着时间戳间距缩小一半，播放速度翻倍。

**音频变速：使用 atempo 滤镜**

```bash
# 音频2倍速
ffmpeg -i input.mp4 -af "atempo=2.0" output_fast.mp4

# 音频0.5倍速
ffmpeg -i input.mp4 -af "atempo=0.5" output_slow.mp4
```

> ⚠️ 注意：`atempo` 的有效范围是 0.5 到 100.0。如果需要更极端的变速，可以链式使用：`atempo=0.5,atempo=0.5` 等效于 0.25 倍速。

**视频 + 音频同步变速：**

```bash
# 2倍速（视频 + 音频）
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -af "atempo=2.0" output.mp4

# 0.5倍速慢动作（视频 + 音频）
ffmpeg -i input.mp4 -vf "setpts=2.0*PTS" -af "atempo=0.5" output.mp4

# 1.5倍速（视频 + 音频）
ffmpeg -i input.mp4 -vf "setpts=PTS/1.5" -af "atempo=1.5" output.mp4
```

**变速速查表：**

| 效果 | setpts | atempo |
| ------ | -------- | -------- |
| 0.25x（极慢） | `setpts=4.0*PTS` | `atempo=0.5,atempo=0.5` |
| 0.5x（慢动作） | `setpts=2.0*PTS` | `atempo=0.5` |
| 1.5x（略快） | `setpts=PTS/1.5` | `atempo=1.5` |
| 2x（快进） | `setpts=0.5*PTS` | `atempo=2.0` |
| 4x（极快） | `setpts=0.25*PTS` | `atempo=2.0,atempo=2.0` |

## 9.6 片头片尾处理

**去掉片头（前 15 秒）：**

```bash
ffmpeg -ss 00:00:15 -i input.mp4 -c copy output.mp4
```

**去掉片尾（保留前 25 分钟）：**

```bash
ffmpeg -i input.mp4 -to 00:25:00 -c copy output.mp4
```

**给视频添加片头：**

先准备好片头视频（确保与主视频编码、分辨率、帧率一致），然后使用 concat demuxer：

```text
# filelist.txt
file 'intro.mp4'
file 'main.mp4'
```

```bash
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4
```

> 💡 提示：concat 要求所有文件的视频编码、分辨率和帧率一致。如果片头是单独制作的，可能需要先把它转码成和主视频一样的参数。

## 9.7 循环播放

**循环输入文件 3 次：**

```bash
ffmpeg -stream_loop 3 -i input.mp4 -c copy output.mp4
```

`-stream_loop 3` 表示循环 3 次（总共播放 4 次）。`-stream_loop -1` 表示无限循环。

> ⚠️ 注意：`-stream_loop` 必须放在 `-i` 前面。

**使用 loop 滤镜循环视频（指定循环次数）：**

```bash
ffmpeg -i input.mp4 -vf "loop=3:150:0" -t 30 output.mp4
```

`loop=次数:帧数:起始帧`。这种方式更精确但会重新编码。

## 9.8 慢动作和快进效果实战

**案例：制作一个 5 秒慢动作片段**

```bash
# 1. 先截取 2.5 秒原始片段（慢放后变成 5 秒）
ffmpeg -ss 00:01:00 -i input.mp4 -t 00:00:02.5 -c:v libx264 -crf 18 temp.mp4

# 2. 慢放 2 倍（0.5x 速度）
ffmpeg -i temp.mp4 -vf "setpts=2.0*PTS" -af "atempo=0.5" slowmotion.mp4
```

**案例：制作延时效果（快速跳过无聊部分）**

```bash
# 将 10 分钟的内容压缩到 30 秒（20倍速）
ffmpeg -i input.mp4 -vf "setpts=PTS/20" -af "atempo=2.0,atempo=2.0,atempo=2.0,atempo=2.5" timelapse.mp4
```

> 💡 提示：atempo 范围是 0.5-100，所以 20 倍速可以用 `atempo=2.0` 链式叠加 4 次再加 `atempo=1.25`，或者直接用 `atempo=20`。

## 本章小结

- `-ss` 在 `-i` 前 = 快速但不精确；`-ss` 在 `-i` 后 = 慢但精确
- `-c copy` 裁剪秒完成，但受关键帧限制；重新编码则完全精确
- `setpts` 控制视频速度，`atempo` 控制音频速度，两者需要同步使用
- `reverse` 滤镜受内存限制，只适合短片段
