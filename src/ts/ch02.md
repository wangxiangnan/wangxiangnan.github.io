# 第二章：环境搭建与第一个 TypeScript 程序

## 安装 TypeScript

TypeScript 可以通过 npm 全局或局部安装。推荐局部安装，这样不同项目可以用不同版本：

```bash
# 创建项目目录
mkdir hello-ts
cd hello-ts

# 初始化 package.json
npm init -y

# 局部安装 TypeScript
npm install --save-dev typescript
```

安装完成后，你可以用 `npx tsc` 调用 TypeScript 编译器。

## 初始化 tsconfig.json

`tsconfig.json` 是 TypeScript 项目的配置文件，它告诉编译器如何检查和处理代码。用以下命令生成默认配置：

```bash
npx tsc --init
```

生成的文件内容很多，但核心配置其实就几个。先不用管全部，我们先做一个最小化修改：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "outDir": "./dist"
  },
  "include": ["src/**/*"]
}
```

这些配置的含义后面会详细讲，现在只需要知道：

- `target`：编译后 JS 的版本。
- `module`：模块系统。
- `strict`：开启所有严格类型检查。
- `outDir`：编译输出目录。

## 写第一个程序

创建 `src/index.ts`：

```ts
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("TypeScript"));
```

编译并运行：

```bash
npx tsc
node dist/index.js
```

如果一切正常，你会看到输出：

```
Hello, TypeScript!
```

恭喜你，第一个 TypeScript 程序跑起来了。

## 小提示：tsx 和 Vite

如果只是学习，不想每次先编译再运行，可以用 `tsx`（基于 esbuild，零配置、速度快）：

```bash
npm install --save-dev tsx
npx tsx src/index.ts
```

老牌方案 `ts-node` 也可以用，但它对 ES Module 的支持比较绕，新项目更推荐 `tsx`。

如果你做前端项目，直接用 Vite 创建 TypeScript 项目会更方便：

```bash
npm create vite@latest my-app -- --template vanilla-ts
```
