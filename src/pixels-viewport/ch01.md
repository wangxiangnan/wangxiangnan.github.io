# 第1章 物理世界：屏幕的基本事实

> **本章回答的问题**：屏幕上的"像素"是什么？460 PPI 这种参数是怎么算出来的？

## 1.1 物理像素：发光的最小单位

**物理像素（physical pixel / device pixel）**是屏幕上真实存在的发光点，由硬件决定，出厂即固定，软件无法改变其数量。

以 iPhone 16 Pro Max 为例：屏幕横向排布 1320 个发光点、纵向 2868 个，即物理分辨率 1320×2868。注意约定俗成的写法顺序——屏幕厂商习惯"宽×高"（1320×2868），而相机传感器习惯"高×宽"（2868×1320），看参数时先分清哪个是宽。

物理像素的两个关键性质：

1. **不可变**：无论系统怎么设置、页面怎么缩放，1320 就是 1320。
2. **尺寸极小且均匀**：每个点约 0.055mm 见方，肉眼无法分辨单点，且所有点物理尺寸一致——这一点是后面用勾股定理算 PPI 的前提。

## 1.2 PPI：密度的度量

屏幕上发光点排得有多密，用 **PPI（Pixels Per Inch，像素每英寸）** 度量：屏幕每英寸长度内容纳多少个物理像素。

由于像素是均匀方格网格，密度沿任何方向都一致，所以可以用对角线计算：

```
PPI = 对角线物理像素数 ÷ 对角线英寸数
    = √(宽² + 高²) ÷ 对角线英寸数
```

**iPhone 16 Pro Max 实算：**

```
对角线像素数 = √(1320² + 2868²)
             = √(1,742,400 + 8,225,424)
             = √9,967,824
             ≈ 3157 px

PPI ≈ 3157 ÷ 6.9 ≈ 458
```

官方标称是 460 PPI，差异来自 6.9 英寸是四舍五入的宣传值，实际对角线约 6.86 英寸：3157 ÷ 6.86 ≈ 460。

PPI 越高，单点越小、画面越细腻。90 PPI 的老显示器近看能看到颗粒，460 PPI 的手机屏达到"视网膜屏"标准——正常观看距离下人眼分辨不出像素点。

**动手验证：PPI 计算器**——把下面代码保存为 `ppi.html`，浏览器打开即用（已预填 iPhone 16 Pro Max 参数，改动数字即可验证勾股定理）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>PPI 计算器</title>
<style>
  body { font: 16px/1.8 system-ui, sans-serif; max-width: 420px; margin: 40px auto; padding: 0 16px; }
  label { display: block; margin-top: 12px; }
  input { width: 100%; padding: 6px; font-size: 16px; box-sizing: border-box; }
  .result { margin-top: 20px; padding: 16px; background: #f0f7ff; border-radius: 8px; }
  b { font-size: 24px; }
</style>
</head>
<body>
  <h2>PPI 计算器</h2>
  <label>横向物理像素 <input id="iw" type="number" value="1320"></label>
  <label>纵向物理像素 <input id="ih" type="number" value="2868"></label>
  <label>对角线尺寸（英寸）<input id="inch" type="number" step="0.01" value="6.86"></label>
  <div class="result">
    对角线像素数 ≈ <b id="outDiag"></b><br>
    PPI ≈ <b id="outPpi"></b>
  </div>
<script>
  const $ = id => document.getElementById(id);
  function calc() {
    const diag = Math.hypot(+$('iw').value, +$('ih').value);
    $('outDiag').textContent = diag.toFixed(0);
    $('outPpi').textContent = +$('inch').value > 0 ? (diag / +$('inch').value).toFixed(0) : '—';
  }
  ['iw', 'ih', 'inch'].forEach(id => $(id).addEventListener('input', calc));
  calc();
</script>
</body>
</html>
```

## 1.3 DPI：印刷出身，为何常与 PPI 混用

**DPI（Dots Per Inch，点每英寸）**源自印刷业，指打印机每英寸喷墨/着色的点数。打印 300 DPI 意味着每英寸 300 个墨点，墨点越密印刷越精细。严格来说它是打印术语。

屏幕行业早期借用了这个词，Windows 的显示设置至今叫 "DPI 缩放"，于是日常语境里两者常被当同义词。准确的区分：

| 术语 | 领域 | 度量对象 | 典型值 |
| ------ | ------ | ---------- | -------- |
| PPI | 屏幕 | 物理像素密度 | 手机 400–500 |
| DPI | 打印 | 墨点密度 | 印刷 300 |
| DPI | Windows | 逻辑缩放基准 | 96 = 100% |

记住一句话：**屏幕用 PPI，打印用 DPI，Windows 里的 "DPI" 实际是缩放系数的别称**（[第 6 章](/pixels-viewport/ch06)展开）。

## 1.4 小结

- 物理像素是硬件事实，数量出厂固定，是整个体系的"地基"。
- PPI 描述物理像素的密度，用勾股定理从分辨率和尺寸算出。
- DPI 严格属于印刷，在屏幕语境下是历史遗留的混用。

## 1.5 练习题

1. 某手机屏幕物理分辨率 1080×1920，对角线 5.0 英寸，求 PPI。
2. 打印机标称 300 DPI、手机屏幕 460 PPI，这两个数字各度量什么？
3. 把显示器分辨率从原生 2560×1440 改成 1920×1080 后画面发虚，为什么？

## 1.6 参考答案

> 1. 对角线像素数 = √(1080² + 1920²) = √4,852,800 ≈ 2203，PPI = 2203 ÷ 5.0 ≈ 441。
> 2. 300 DPI 是打印术语，度量每英寸墨点数；460 PPI 是屏幕的物理像素密度。严格说屏幕该用 PPI，Windows 设置里的 "DPI" 是历史混用的缩放基准（见[第 6 章](/pixels-viewport/ch06)）。
> 3. 非原生分辨率下，GPU 用较少的物理像素渲染再拉伸填满整个屏幕，插值导致发虚。
