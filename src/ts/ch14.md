# 第十四章：常见错误与调试技巧

学 TypeScript 的过程中，报错是不可避免的。下面我们看几个最常见的错误，以及怎么理解它们。

## "Type 'X' is not assignable to type 'Y'"

这是最常见的类型错误。意思是：你试图把一个类型为 `X` 的值赋给类型为 `Y` 的变量，但 `X` 不能兼容 `Y`。

解决思路：检查两个类型的结构差异，看是少了字段、字段类型不对，还是联合类型没有收窄。

## "Property 'X' does not exist on type 'Y'"

你访问了一个对象上不存在的属性。可能是拼写错误，也可能是对象类型定义不完整。

## "Argument of type 'X' is not assignable to parameter of type 'Y'"

函数调用时参数类型不匹配。检查参数列表和函数签名。

## "Cannot find module 'X' or its corresponding type declarations"

模块找不到声明文件。可能是没安装 `@types/X`，或者模块路径写错了。

## 调试技巧

1. **把鼠标悬停上去**：VS Code 里把鼠标停在变量上，可以看到推断出的类型。
2. **用 `typeof` 看类型**：

   ```ts
   const user = { name: "Alice", age: 25 };
   type UserType = typeof user;
   ```

3. **用 `satisfies` 检查类型**：

   ```ts
   const config = {
     host: "localhost",
     port: 3000,
   } satisfies { host: string; port: number };
   ```

4. **逐步简化复杂类型**：如果一个复杂类型报错，把它拆成几个小类型，逐个排查。
