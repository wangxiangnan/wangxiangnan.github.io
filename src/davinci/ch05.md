## 第5章：字幕与文字——Vlog的信息层 📝

> [!TIP] Part 2：视听增强
> *如果说Part 1是"学会走路"，那Part 2就是"学会打扮自己"。视频剪好了、转场加好了，但还缺少一些让它"看起来更专业"的元素——比如文字和字幕、比如颜色和影调。从这一章开始，我们将为Vlog添加信息层和视觉层，让你的视频从"能看"变成"好看"。*

*小陈的Vlog做得越来越像样了，但他发现一个问题：有时候他在视频里推荐了一家店，朋友看完问"这家店叫什么名字？在哪儿？"他不得不在微信里打字告诉对方。*

*"要是视频里直接显示店名和地址就好了。"*

*他又去看了一些头部UP主的Vlog，发现人家都有精心设计的标题、字幕条、地点标注。一个漂亮的开场标题能立刻抓住观众注意力，一个简洁的字幕条能在不打断画面的情况下传递关键信息。*

*"看来文字也是视频的重要组成部分啊。"小陈打开了DaVinci Resolve的文字工具。*

## 5.1 添加文字：Text+ 工具

DaVinci Resolve提供了两种文字工具：

- **Text（基础文字）**：简单易用，参数较少
- **Text+（增强文字）**：功能更强大，支持更多特效和动画

**我们推荐直接用Text+**，因为它功能全面，而且用起来也不比基础Text复杂多少。

**添加文字的方法：**

1. 打开效果面板（`Shift + 5`）
2. 找到 `工具箱 > 标题`（Toolbox > Titles）
3. 找到 `Text+`（在免费版中可能显示为"Text+"或"Fusion Title"）
4. 把Text+拖到时间线的 **V2轨道**上（放在视频上方）

> 💡 **提示**：文字本质上也是一个"视频片段"，它放在视频上方的轨道上，叠在画面上显示。所以记得把它放在V2或更高的轨道上，不要放到V1和视频抢位置。

**编辑文字内容：**

1. 选中时间线上的文字片段
2. 打开右侧检查器（Inspector）
3. 在"文本"（Text）输入框中输入你想要的文字内容
4. 文字会实时显示在监视器中

**调整文字片段的持续时间：**

- 拖动文字片段的边缘来延长或缩短显示时间
- 比如你希望标题在前3秒显示，就把文字片段长度调整为3秒

## 5.2 字体选择与排版：Vlog字幕的设计原则

文字加上去容易，但怎么让它"好看"就有讲究了。

**字体选择原则：**

1. **标题用粗体、有设计感的字体**：比如思源黑体Bold、站酷快乐体、阿里巴巴普惠体
2. **正文/字幕用清晰易读的字体**：比如思源黑体Regular、微软雅黑
3. **一条视频中字体不要超过2种**：标题一种、正文一种，太多了显得杂乱
4. **慎用花哨的手写体**：看起来有个性，但手机上往往显示不清楚

> 💡 **提示**：DaVinci Resolve使用的是系统已安装的字体。如果你想用更多字体，先在电脑上安装字体文件（.ttf 或 .otf），重启DaVinci Resolve后就能在字体列表中看到。推荐去"字由"、"猫啃网"等网站下载免费商用字体。

**排版设计原则：**

| 原则 | 说明 |
| ------ | ------ |
| 大小适中 | 标题约占画面宽度的60-70%，字幕不要小于24pt |
| 位置统一 | 标题通常在画面中央或三分之一处，字幕条固定在左下角或右下角 |
| 颜色对比 | 文字颜色要和背景画面有足够对比度，白色文字配深色描边/阴影是万能方案 |
| 留白 | 文字周围留出空间，不要紧贴画面边缘 |
| 信息精简 | 字幕条上的文字控制在15个字以内，只放最关键的信息 |

**检查器中的文字参数：**

- **Font**（字体）：选择字体
- **Size**（大小）：字号大小
- **Color**（颜色）：文字颜色，推荐白色或浅黄色
- **Tracking**（字间距）：字与字之间的间距
- **Leading**（行间距）：多行文字时的行间距
- **Stroke**（描边）：给文字加描边，推荐1-2像素深色描边增强可读性
- **Drop Shadow**（阴影）：给文字加投影，增强层次感

## 5.3 文字动画：让标题更生动

静态文字有时候显得死板，加上简单的动画会让标题更有活力。

**方法一：用Text+内置的动画预设**

部分Text+模板自带入场/出场动画效果，选中后在检查器中可以调整动画参数。

**方法二：用关键帧做自定义动画**

和第3章学的一样，文字的各种参数都可以加关键帧：

**淡入效果（最常用）：**

1. 选中文字片段
2. 在检查器中找到 `不透明度`（Blend > Opacity）
3. 在文字出现的第一帧，设关键帧，不透明度设为0
4. 在后移10-15帧的位置，不透明度设为100
5. 文字就会用约0.5秒的时间渐渐出现

**从下方滑入：**

1. 找到 `位置 > Y`（Position Y）参数
2. 第一帧：Y值比正常位置偏低一些（比如 -0.1）
3. 后移10-15帧：Y值恢复到正常位置（0）
4. 文字就会从下方轻轻滑入

**缩放弹出：**

1. 找到 `大小`（Size）参数
2. 第一帧：大小设为0.8
3. 后移8帧：大小设为1.05（稍微弹大一点）
4. 再后移5帧：大小设为1.0（回弹到正常）
5. 文字会有一个"弹出"的弹性效果

> 💡 **提示**：文字动画的关键是"快且克制"。好的文字动画通常在0.3-0.8秒内完成，观众感受到"有动效"但不会觉得"怎么还没出来"。超过1秒的文字入场动画，在短视频中会显得拖沓。

## 5.4 字幕条（Lower Third）：人物介绍和地点标注

字幕条（Lower Third）是指出现在画面下方三分之一区域的文字信息条，通常用来标注人名、地点、时间等信息。它是Vlog中最实用的文字元素之一。

**自己制作简单字幕条：**

1. 在V2轨道添加Text+
2. 输入文字内容（比如"厦门 · 鼓浪屿"）
3. 在检查器中调整：
   - 位置：移到画面左下角或右下角
   - 字体：选择简洁的无衬线字体
   - 大小：适中，不要太大
   - 描边：加1-2像素黑色描边
   - 阴影：加轻微投影

**进阶版：给字幕条加背景条**

纯文字有时候和背景画面混在一起不好辨认，可以加一个半透明的背景条：

1. 在V2轨道放一个 `纯色背景`（Solid Color），颜色选深色
2. 在检查器中把纯色背景裁剪成细长的条状
3. 降低不透明度到70-80%
4. 在V3轨道放文字，位置对准背景条

或者更简单的方式：在效果面板中搜索 `Lower Third` 相关模板，有些预设直接包含了背景条+文字的组合。

**字幕条的使用时机：**

- 第一次出现某个地点时（"北京 · 三里屯"）
- 出现人物时标注名字和身份
- 展示食物时标注菜名和价格
- 时间信息（"Day 2"、"下午3:00"）

## 5.5 自动字幕功能

> ⚠️ **注意**：DaVinci Resolve的自动语音转字幕功能（Auto Subtitles / 自动字幕）是 **Studio版（付费版）** 独有的功能。免费版无法使用此功能。

如果你使用的是Studio版，自动字幕功能可以自动识别视频中的语音并生成字幕：

1. 在剪辑页，选择菜单 `时间线 > 基于字幕创建`（Timeline > Create Subtitles from Audio）
2. 选择语言和参数
3. 点击生成
4. 软件会自动分析音频并生成可编辑的字幕

**免费版替代方案：**

- 使用"剪映"等App的自动字幕功能生成SRT字幕文件，然后导入DaVinci Resolve
- 手动添加字幕：用Text+在需要字幕的时间点添加文字（适合字幕量不大的短视频Vlog）

> 💡 **提示**：对于Vlog来说，通常不需要像电视剧那样的全屏对白字幕。更常见的做法是只在关键信息处加字幕条或简短的文字说明，工作量小很多。

## 5.6 水印与Logo叠加

给你的Vlog加上个人水印或Logo，既能提升品牌感，也能防止被盗用。

**添加图片水印/Logo：**

1. 准备好你的Logo文件（推荐PNG格式，透明背景）
2. 把Logo文件导入媒体池
3. 把Logo拖到时间线的最高轨道上（比如V3），放在整个视频的最前面
4. 选中Logo片段，在检查器中调整：
   - 缩放：缩小到合适大小（比如0.1-0.2）
   - 位置：移到角落（比如右下角 X: 0.7, Y: -0.4）
   - 不透明度：降到50-70%，做成半透明水印效果

**让Logo贯穿整个视频：**

把Logo片段的边缘拖拽拉长，使其与整个视频等长。这样从头到尾都会显示Logo。

> 💡 **提示**：水印不宜太大太显眼——它应该是一个"在就行、不碍事"的存在。推荐放在右下角或左下角，不透明度50%左右，大小占画面的5-8%。

## 5.7 文字模板的使用与保存

如果你经常在视频中使用同一种风格的字幕条或标题，可以把它保存为模板，下次直接调用。

**保存为模板：**

1. 在时间线上调好一个文字片段的所有参数（字体、颜色、大小、位置等）
2. 右键该片段 → `保存为预设`（Save as Preset）或在效果面板中保存

**使用DaVinci Resolve内置的标题模板：**

效果面板中的"标题"分类下有很多预设模板：

- **Simple Titles**：简洁标题模板
- **Call Out**：标注型标题
- **Lower Thirds**：字幕条模板（⚠️ 部分模板可能需要Studio版）

直接拖到时间线上，然后在检查器中修改文字内容和颜色即可。

**自定义标题模板的建议：**

为你的Vlog建立一套统一的文字风格：

- 开场标题：固定字体、大小、动画方式
- 字幕条：固定位置、颜色、字体
- 结尾信息：固定样式

这样每条Vlog看起来都有"品牌一致性"，观众一看就知道是你的视频。

## 5.8 实战：为Vlog制作开场标题和信息字幕条

小陈要为他的厦门旅行Vlog制作一套完整的文字元素：

**1）开场标题（视频前3秒）**

内容："厦门 · 一个人的周末旅行"

- 字体：思源黑体 Bold
- 大小：适中，占画面宽度60%
- 颜色：白色 + 2像素黑色描边
- 位置：画面中央
- 动画：淡入（0.5秒） + 轻微从下方滑入

**2）地点字幕条（3处）**

- "Day 1 · 鼓浪屿"：出现在到达鼓浪屿时，持续3秒
- "日光岩 · 最高点"：出现在爬日光岩时，持续2秒
- "中山路步行街"：出现在逛中山路时，持续3秒

样式统一：

- 字体：思源黑体 Regular
- 大小：18pt
- 位置：左下角固定位置
- 背景：半透明黑色条

**3）食物标注（2处）**

- "沙茶面 · 15元"
- "海蛎煎 · 12元"

样式：简洁白字+黑色描边，出现在美食特写时。

**4）结尾水印**

小陈用Canva做了一个简单的Logo（其实就是他的名字"陈的Vlog"加一个小相机图标），导出为透明PNG，放在视频右下角，不透明度60%，贯穿全片。

**制作流程：**

1. 在V2轨道依次放置各个文字片段，对齐到对应的视频时间点
2. 在V3轨道放置Logo水印，拉长到和视频等长
3. 逐个检查每个文字的显示时间和位置
4. 全屏预览一遍，确认所有文字清晰可读、不与画面冲突
5. 调整细节：某个字幕条时间太短读不完 → 延长；某个标题和背景混在一起 → 加描边

完成之后，小陈的Vlog第一次有了"成品感"——有开场标题、有地点标注、有食物信息、有个人Logo。这些文字元素虽然简单，但让整条视频看起来"专业"了不少。

他发现，**好的字幕设计不是越花哨越好，而是清晰、统一、恰到好处。** 这和之前学转场时的道理一样——克制，是高级感的来源。
