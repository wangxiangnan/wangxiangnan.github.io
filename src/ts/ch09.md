# 第九章：类与面向对象

TypeScript 全面支持 ES6 类，并增加了类型注解、访问修饰符、抽象类、接口实现等特性。

## 基础类

```ts
class Animal {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  move(distance: number): void {
    console.log(`${this.name} moved ${distance}m`);
  }
}

const dog = new Animal("Buddy");
dog.move(10);
```

## 访问修饰符

- `public`：默认，任何地方可访问。
- `private`：只能在类内部访问。
- `protected`：只能在类内部和子类中访问。

```ts
class Person {
  public name: string;
  private age: number;
  protected id: string;

  constructor(name: string, age: number, id: string) {
    this.name = name;
    this.age = age;
    this.id = id;
  }
}
```

TypeScript 4.3 之后还引入了 `private` 字段的 ECMAScript 原生支持：`#privateField`。

## readonly 属性

```ts
class User {
  readonly id: number;

  constructor(id: number) {
    this.id = id;
  }
}
```

`readonly` 属性只能在初始化时赋值，之后不能修改。

## 参数属性

TypeScript 提供了一种简化写法：

```ts
class User {
  constructor(public name: string, private age: number) {}
}
```

这等价于先声明属性再在构造函数里赋值。

## 静态成员与存取器

```ts
class Counter {
  static total = 0; // 静态成员挂在类本身上，通过 Counter.total 访问

  static increment(): void {
    Counter.total++;
  }

  private _value = 0;

  get value(): number {
    return this._value;
  }

  set value(v: number) {
    this._value = Math.max(0, v); // 写入时可以插入校验逻辑
  }
}
```

TypeScript 4.3 起允许 getter 和 setter 声明不同的类型，比如写入时接受 `string | number`、读取时返回 `number`。

## 接口实现

```ts
interface CanFly {
  fly(): void;
}

class Bird implements CanFly {
  fly() {
    console.log("Flying");
  }
}
```

`implements` 让类承诺实现某个接口。如果类缺少接口中的成员，TypeScript 会报错。

## 抽象类

```ts
abstract class Shape {
  abstract getArea(): number;

  printArea(): void {
    console.log(`Area is ${this.getArea()}`);
  }
}

class Circle extends Shape {
  constructor(private radius: number) {
    super();
  }

  getArea(): number {
    return Math.PI * this.radius ** 2;
  }
}
```

抽象类不能被直接实例化，只能被继承。子类必须实现抽象方法。

## override 关键字

子类覆写父类方法时，建议显式加上 `override`：

```ts
class Dog extends Animal {
  override move(distance: number): void {
    console.log(`Dog ran ${distance}m`);
  }
}
```

如果父类上并没有这个方法（比如父类重构后方法改名了），`override` 会让编译器立刻报错，避免"以为在覆写、实际在新增"的事故。再配合 `noImplicitOverride` 编译选项，可以强制所有覆写都必须写 `override`。

## 类的类型

类在 TypeScript 中同时有两种含义：

1. 构造函数类型：用 `typeof ClassName` 表示。
2. 实例类型：直接用 `ClassName` 表示。

```ts
class User {
  name: string = "";
}

let user: User = new User();        // 实例类型
let UserConstructor: typeof User = User; // 构造函数类型
```

这个区别在依赖注入、工厂模式等场景中很重要。
