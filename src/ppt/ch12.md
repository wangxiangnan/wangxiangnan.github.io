# 第12章：演示技巧——从制作到上台演讲 🎤

*路演倒计时三天。小林在出租屋里对着镜子练习演讲，手里举着笔记本电脑。他发现自己遇到了一个新问题：PPT做好了，但演示的时候怎么操作？全屏放映之后，他自己要看的备注在哪里？翻页翻快了怎么办？万一路演当天投影仪连不上怎么办？更可怕的是——他一想到要站在投资人面前讲话，就紧张得手心冒汗。"PPT做好了是第一步，"小林对自己说，"但怎么把PPT讲好，才是真正的考验。"*

## 12.1 放映模式：从头开始、从当前页、自定义放映

做好了PPT，下一步就是"放"出来看。PowerPoint提供了多种放映模式：

**从头开始放映**：

- 快捷键：`F5`
- 从第1页开始全屏放映，这是最常用的方式
- 也通过 `幻灯片放映 > 从头开始`

**从当前页放映**：

- 快捷键：`Shift + F5`
- 从你当前正在编辑的那一页开始放映
- 非常适合调试某一页的动画效果
- 也可以通过 `幻灯片放映 > 从当前幻灯片开始`

**自定义放映**：

- 路径：`幻灯片放映 > 自定义幻灯片放映 > 自定义放映`
- 可以创建多个放映方案，每个方案选择不同的页面组合
- 适用场景：同一个PPT，给不同观众看不同内容。比如小林的路演PPT有15页，但如果投资人只给了10分钟，他可以创建一个"精简版"放映方案，只包含核心的8页

**浏览者模式**：

- 路径：`幻灯片放映 > 设置幻灯片放映`，选择"在展台浏览"
- PPT会自动循环播放，观众可以自己点击翻页
- 适合展会摊位、产品体验区等场景

> 💡 **提示**：按 `Esc` 键随时退出放映模式。放映时右键可以看到更多选项菜单。

## 12.2 演示者视图：演讲者的秘密武器

演示者视图（Presenter View）是PPT为演讲者量身打造的功能，也是很多新手不知道的神器。

**普通放映 vs 演示者视图**：

- **普通放映**：你的屏幕和投影屏幕显示完全相同的内容
- **演示者视图**：投影屏幕上显示全屏幻灯片，而你的笔记本屏幕上显示更多信息

**演示者视图显示什么**：

1. **当前幻灯片**——和投影屏幕一样的画面
2. **下一张幻灯片**——让你提前知道下一页是什么，从容过渡
3. **演讲者备注**——你为每一页写的提示词、关键数据、要说的话
4. **计时器**——已经讲了多久，帮你控制时间
5. **幻灯片缩略图**——快速找到并跳转到任意一页
6. **工具按钮**——画笔、激光笔、放大镜等

**开启演示者视图**：

1. 确保你的电脑连接了投影仪或第二屏幕
2. 进入 `幻灯片放映` 选项卡
3. 勾选 **"使用演示者视图"**
4. 按 `F5` 开始放映

> 💡 **提示**：在放映过程中，你也可以按 `Alt + F5` 直接切换出演示者视图，即使一开始没有连接第二屏幕。

**添加演讲者备注**：

在普通视图中，每张幻灯片底部有一个"备注"区域（如果看不到，拖动底部边缘展开，或点击状态栏的"备注"按钮）。在这里写下你演讲时要说的要点、关键数据或提醒自己。这些备注只有你自己能看到，观众看不到。

## 12.3 演讲中的操作：翻页、跳转、黑屏/白屏、画笔标注

站在台上演讲时，你需要掌握以下操作：

**翻页**：

- 下一页：`空格键`、`回车键`、`右箭头`、`下箭头`、`Page Down`、鼠标左键
- 上一页：`左箭头`、`上箭头`、`Page Up`、`Backspace`

> 💡 **提示**：翻页笔（演示器）是演讲必备工具，通常只有两个按钮——上一页和下一页。花几十块钱买一个，会让你在台上显得专业很多，而且不用被电脑绑住。

**跳转到指定页**：

- 输入页码 + `Enter`：比如输入 `5` 然后按回车，直接跳到第5页
- 按 `G` 键也可以打开跳转对话框
- 在演示者视图中，可以直接点击缩略图跳转

**黑屏与白屏**：

- 按 `B` 键：屏幕变黑（黑屏），再按一次恢复。适合你想让观众集中注意力听你说话，而不是看PPT的时候
- 按 `W` 键：屏幕变白（白屏），效果同上
- 这是一个高级技巧，能让观众从"看PPT"模式切换到"听你讲"模式

**画笔标注**：

- 按 `Ctrl + P`：鼠标变成画笔，可以在幻灯片上写字、画线
- 按 `E`：橡皮擦，清除标注
- 按 `Ctrl + A`：恢复为箭头指针
- 也可以右键 > 指针选项 > 选择笔的颜色和粗细

**激光笔效果**：

- 按住 `Ctrl + 鼠标左键`：出现红色激光点，可以指引屏幕上的内容
- 在演示者视图中直接用鼠标就能模拟激光笔

## 12.4 排练计时：自动演练并记录时间

**排练计时**功能可以帮你做两件事：练习演讲节奏 + 记录每页的停留时间。

**操作方法**：

1. `幻灯片放映 > 排练计时`
2. PPT进入全屏放映模式，左上角出现一个计时器
3. 你像真正演讲一样翻页、讲解
4. 每翻一页，计时器会记录你在该页停留的时间
5. 全部结束后，PPT会问你是否保存排练时间
6. 保存后，PPT可以按照你排练的节奏自动翻页

**为什么这很有用**：

- **控制时间**：如果投资人给了你15分钟，排练计时能帮你精确知道每页该花多少时间
- **发现节奏问题**：如果你发现某一页停留了3分钟，说明那页内容太多，需要精简
- **自动播放**：保存时间后，可以设置PPT自动播放（无人操控），适合展台循环播放

> 💡 **提示**：排练计时至少做3次。第一次通常偏快（紧张），第二次会调整，第三次才能稳定在目标时间内。

## 12.5 录制幻灯片：录制带旁白的演示

如果你不能到场演讲，或者想把演示录成视频发给别人，可以使用录制功能。

**录制幻灯片演示**：

1. `幻灯片放映 > 录制幻灯片演示`
2. 选择"从头开始录制"或"从当前幻灯片开始录制"
3. 进入录制界面，你的声音会被录为旁白
4. 你可以边讲边翻页，翻页时间和动画触发时间都会被记录
5. 录制完成后，每张幻灯片右下角会出现一个小喇叭图标（表示有旁白）

**录制的内容包括**：

- 你的语音旁白
- 翻页时机
- 动画和切换的时间
- 激光笔和画笔标注（如果使用了）

> 💡 **提示**：录制前确保麦克风正常，找一个安静的环境。录制过程中如果某一页讲错了，可以右键该页选择"清除该幻灯片上的计时和旁白"，然后重新录制那一页。

## 12.6 多显示器设置：投影/投屏配置

路演当天，你需要把PPT投射到大屏幕上。这里涉及多显示器设置。

**连接投影仪后**：

1. Windows系统：按 `Win + P` 打开投影选项
   - **复制**：两个屏幕显示相同内容（适合调试）
   - **扩展**：两个屏幕合为一个大的工作区（演示者视图需要此模式）
   - **仅第二屏幕**：只在投影仪上显示（适合播放视频）

2. 选择 **"扩展"** 模式——这是演示者视图的前提

3. 在PPT中确认：`幻灯片放映 > 设置幻灯片放映`
   - "监视器"下拉框中选择投影仪
   - 勾选"使用演示者视图"

**常见问题排查**：

| 问题 | 解决方案 |
| ------ | --------- |
| 投影仪无信号 | 检查线缆连接，按 `Win + P` 重新选择投影模式 |
| 分辨率不对/画面变形 | 右键桌面 > 显示设置 > 调整投影仪分辨率 |
| 演示者视图显示反了 | 在演示者视图中点击"显示设置" > "交换演示者视图和幻灯片" |
| 画面比例不对 | 确认PPT的幻灯片大小（16:9或4:3）与投影仪一致 |

> 💡 **提示**：路演前一定要提前到现场测试设备！不要假设现场的投影仪和接口都正常工作。带一根HDMI线和一根VGA线（老式投影仪可能只有VGA），再加一个Type-C转HDMI的转接头。

## 12.7 远程演示：在线共享PPT演示

2024年以后，远程路演越来越常见。如果你需要在线给投资人演示PPT：

**方案一：会议软件共享屏幕**

- 使用腾讯会议、Zoom、飞书等软件
- 共享屏幕时选择PPT窗口
- 开启演示者视图，确保共享的是"幻灯片放映"窗口而不是"演示者视图"窗口

**方案二：PPT Live（Microsoft 365）**

- PowerPoint内置的在线演示功能
- 路径：`幻灯片放映 > Live Present`
- 生成一个链接，观众通过手机或电脑实时观看你的演示
- 观众还可以发送实时反馈和表情

**方案三：导出视频发送**

- 如果不需要实时互动，可以录制演示视频发给对方
- 好处是投资人可以在方便的时间观看
- 坏处是缺少互动感，不能即时回答问题

> 💡 **提示**：远程演示时，网络稳定性是第一要素。建议使用有线网络而不是WiFi，关闭其他占带宽的程序。演示前测试一遍共享屏幕功能是否正常。

## 12.8 演讲心态与技巧：紧张怎么办、眼神交流、肢体语言

PPT做得再好，最终还是要靠"人"来讲好。这一节不谈软件，只谈你。

**关于紧张**

紧张不是你的敌人，是你的朋友。适度的紧张会让你注意力集中、表现更好。但过度紧张需要一些方法来调节：

1. **"4-7-8"呼吸法**：吸气4秒 → 屏住7秒 → 呼气8秒。上台前做3次，能有效降低心率
2. **提前到场**：至少提前30分钟到路演现场，熟悉环境、测试设备、站在台上感受一下
3. **最坏预想**：问自己"最坏能怎样？"——无非是没融到钱，你的App还在，你还在，太阳明天还会升起
4. **前30秒最关键**：背熟你的开场白，前30秒顺利了，后面就顺了
5. **手握翻页笔**：手里有个东西握着，比双手不知道放哪里好得多

**眼神交流**

- 不要看PPT屏幕——观众是来看你的，不是来看你回头看PPT的
- 不要看地板或天花板
- **"一个人一句话"技巧**：每次讲一个完整的句子时，看着一个观众的眼睛。讲完这句话后，转向另一个观众。这样每个人都有被"对话"的感觉
- 如果投资人只有3-5个人，可以每个人停留5-8秒

**肢体语言**

- **站姿**：双脚与肩同宽，不要来回晃动
- **手势**：讲到数字时用手比划（"我们的用户增长了3倍"时可以伸出手势），但不要过度
- **移动**：可以在台上小范围移动，但不要像踱步一样不停走动
- **不要背对观众**：需要指向PPT时，侧身指，不要完全转过身去

**声音控制**

- **语速**：紧张时人会不自觉地加速。有意识地放慢，比正常说话速度慢10-20%
- **停顿**：讲完一个重要观点后，停顿2-3秒。停顿不是尴尬，是让观众消化信息
- **音量**：讲到关键数据时稍微提高音量，讲背景故事时可以降低音量，制造对比

**互动技巧**

- 可以提问："在座各位有没有算过自己每个月到底花了多少钱？"（引出产品痛点）
- 可以讲故事："去年我辞职那天，打开银行App看到余额……"（个人故事最能打动人）
- 可以幽默自嘲："我当时做的第一版PPT丑到什么程度呢——我妈看了都说'儿子你是不是该换个方向'"

## 12.9 实战：小林路演前的最后排练

路演前一天晚上，小林进行了最后一次完整排练：

**准备阶段**：

1. 连接外接显示器，设置为"扩展"模式
2. 开启演示者视图，确认备注已写好（每页2-3行关键数据提醒）
3. 准备翻页笔，确认电池有电
4. 手机计时器放在一旁作为备用计时

**排练过程**：

| 时间段 | 页面 | 内容 | 备注重点 |
| -------- | ------ | ------ | --------- |
| 0:00-1:00 | 封面 | 自我介绍 | 名字、背景、一句话引出问题 |
| 1:00-3:00 | 痛点页 | 年轻人不会记账 | 调研数据：78%的年轻人没有记账习惯 |
| 3:00-5:30 | 产品页 | 账本精灵功能展示 | 三大功能：AI识别、自动分类、消费建议 |
| 5:30-7:30 | 市场页 | 市场规模和机会 | TAM 2000亿，SAM 200亿 |
| 7:30-9:30 | 商业模式 | 怎么赚钱 | 订阅制：月费12元，年费98元 |
| 9:30-11:00 | 数据页 | 已有数据 | 内测用户5000+，月活68%，次月留存72% |
| 11:00-12:30 | 团队页 | 核心团队介绍 | 3人背景简述 |
| 12:30-14:00 | 财务页 | 财务预测 | 18个月内达到盈亏平衡 |
| 14:00-15:00 | 融资页 | 需要多少钱、怎么花 | 融资300万，产品开发40%、市场推广35%、运营25% |

**排练结束**：

小林看了一眼计时器：14分48秒，刚好在15分钟以内。他发现自己讲到"商业模式"那页时容易超时，于是精简了一些细节。他还注意到自己在讲到团队背景时习惯性地低头看电脑屏幕，于是特意练习了那一段的眼神交流。

他又练了两遍。第二遍14分15秒，第三遍13分50秒。每次都比上一次更流畅。

"好了，"小林合上电脑，深吸一口气，"明天，就是检验的时候了。"

## 练习题

1. **基础题**：打开你的PPT，给每一页添加演讲者备注（至少写2-3个关键词）。然后按 `F5` 放映，用键盘操作翻页，练习从头到尾讲一遍。

2. **进阶题**：连接一个外接显示器（或用电视代替），设置演示者视图。进行一次完整的排练计时，记录总时间和每页的平均停留时间。

3. **挑战题**：用手机录制自己演讲PPT的视频（可以对着镜子，或让朋友帮你拍），回看视频，找出3个可以改进的肢体语言或声音控制问题。
