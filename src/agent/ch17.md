# 第17章 持久化与Checkpointer —— 让Agent记住一切

## 17.1 开篇：Agent的"失忆症"

到目前为止，我们的Agent有一个严重的问题：**每次运行都是从零开始。**

```python
# 场景：用户和DocMind对话
# 第一轮
user: "帮我搜索Agent架构的文档"
agent: "找到了3篇相关文档..."

# 第二轮（刷新页面后）
user: "继续刚才的话题"
agent: "什么话题？我不记得了..."  # 失忆了！
```

这在开发调试阶段还能忍受，但在生产环境中完全不可接受。想象一下：

- 用户关闭浏览器后重新打开，所有对话历史丢失
- Agent执行到一半崩溃了，无法从中断处恢复
- 想回滚到对话的某个历史节点，做不到

> 用编程的话说：Agent现在就像一个没有数据库的Web应用——每次请求都是全新的，没有Session、没有持久化、没有回滚能力。我们需要给Agent加一个"数据库"。

**Checkpointer**就是Agent的"数据库"——它保存Agent在每一步的完整状态，就像一个不断做commit的Git仓库。

## 17.2 Checkpointer的概念

Checkpointer的核心思想非常简单：**在图的每个节点执行完毕后，自动保存当前的完整State。**

```
START -> agent (保存state_1) -> tools (保存state_2) -> agent (保存state_3) -> END (保存state_4)

每个保存点包含：
- 完整的消息历史
- 所有State字段的当前值
- 时间戳
- 父节点信息（用于回溯）
```

> 类比：Checkpointer就像Git——每次节点执行完就像做一次`git commit`。你可以查看历史（`git log`）、回退到某个版本（`git checkout`）、甚至分叉（`git branch`）。

## 17.3 内置Checkpointer

LangGraph提供了三种内置的Checkpointer：

### 17.3.1 MemorySaver（内存保存）

```python
"""
MemorySaver：最简单的Checkpointer
状态保存在内存中，程序结束就丢失
适合：开发调试、快速原型
"""
from langgraph.checkpoint.memory import MemorySaver

# 创建checkpointer
checkpointer = MemorySaver()

# 编译时传入
app = graph.compile(checkpointer=checkpointer)

# 调用时必须指定thread_id
config = {"configurable": {"thread_id": "conversation-1"}}
result = app.invoke(
    {"messages": [HumanMessage(content="你好")]},
    config=config
)
```

### 17.3.2 SqliteSaver（本地文件持久化）

```python
"""
SqliteSaver：状态保存在SQLite数据库文件中
程序重启后状态仍然存在
适合：单机部署、中小规模应用
"""
from langgraph.checkpoint.sqlite import SqliteSaver
import sqlite3

# 创建SQLite连接
conn = sqlite3.connect("docmind_checkpoints.db", check_same_thread=False)

# 创建checkpointer
checkpointer = SqliteSaver(conn)

# 第一次使用时创建表
checkpointer.setup()

# 编译时传入
app = graph.compile(checkpointer=checkpointer)

# 使用和MemorySaver完全一样
config = {"configurable": {"thread_id": "conversation-1"}}
result = app.invoke(
    {"messages": [HumanMessage(content="你好")]},
    config=config
)

# 程序重启后，状态仍然在！
# 重新连接数据库，之前的对话历史完好无损
```

### 17.3.3 PostgresSaver（生产级持久化）

```python
"""
PostgresSaver：状态保存在PostgreSQL数据库中
适合：生产环境、多实例部署
"""
from langgraph.checkpoint.postgres import PostgresSaver
import psycopg2

# 创建PostgreSQL连接
conn = psycopg2.connect(
    host="localhost",
    database="docmind",
    user="admin",
    password="password"
)

# 创建checkpointer
checkpointer = PostgresSaver(conn)
checkpointer.setup()

# 编译和使用方式完全相同
app = graph.compile(checkpointer=checkpointer)
```

### 三种Checkpointer对比

| 特性 | MemorySaver | SqliteSaver | PostgresSaver |
| ------ | ------------- | ------------- | --------------- |
| 持久性 | 内存（重启丢失） | 文件（重启保留） | 数据库（重启保留） |
| 性能 | 最快 | 中等 | 取决于网络 |
| 并发 | 不支持 | 有限 | 完整支持 |
| 部署 | 单机开发 | 单机生产 | 分布式生产 |
| 依赖 | 无 | sqlite3(内置) | psycopg2 |

## 17.4 Thread管理

### 17.4.1 什么是Thread？

Thread（线程）是Checkpointer的核心概念——**每个对话对应一个独立的thread_id，不同thread的状态完全隔离。**

> 类比：Thread就像HTTP Session。每个用户有一个Session ID，服务器通过Session ID区分不同用户的状态。Thread_id就是Agent世界的Session ID。

```python
"""
Thread管理：多对话隔离
"""
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)

# 用户A的对话
config_a = {"configurable": {"thread_id": "user-A-session"}}
app.invoke(
    {"messages": [HumanMessage(content="我是用户A")]},
    config=config_a
)

# 用户B的对话（完全独立）
config_b = {"configurable": {"thread_id": "user-B-session"}}
app.invoke(
    {"messages": [HumanMessage(content="我是用户B")]},
    config=config_b
)

# 用户A继续对话——能看到之前的历史
app.invoke(
    {"messages": [HumanMessage(content="我之前说了什么？")]},
    config=config_a
)
# Agent会记得"我是用户A"

# 用户B继续对话——看不到用户A的历史
app.invoke(
    {"messages": [HumanMessage(content="用户A说了什么？")]},
    config=config_b
)
# Agent不知道用户A的存在
```

### 17.4.2 Thread的最佳实践

```python
"""
Thread ID的最佳实践
"""
import uuid

# 方案1：使用UUID（最通用）
thread_id = str(uuid.uuid4())

# 方案2：基于用户ID（方便查找）
thread_id = f"user_{user_id}_conversation_{conversation_id}"

# 方案3：基于场景（方便管理）
thread_id = f"docmind_{user_id}_{date}_{session_number}"

# 不要做的事：
# 1. 不要让所有用户共用一个thread_id（状态会互相污染）
# 2. 不要每次对话都生成新的thread_id（无法延续上下文）
# 3. 不要在thread_id中包含敏感信息（它会出现在数据库键中）
```

## 17.5 时间旅行(Time Travel)

这是Checkpointer最酷的功能——**回到Agent执行历史的任意时刻**。

### 17.5.1 查看历史状态

```python
"""
时间旅行：查看Agent的执行历史
"""
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)
config = {"configurable": {"thread_id": "time-travel-demo"}}

# 进行几轮对话
app.invoke({"messages": [HumanMessage(content="搜索Agent架构")]}, config=config)
app.invoke({"messages": [HumanMessage(content="搜索RAG")]}, config=config)
app.invoke({"messages": [HumanMessage(content="搜索LangGraph")]}, config=config)

# 查看完整历史
history = list(app.get_state_history(config))

print(f"共有 {len(history)} 个历史状态\n")

for i, state_snapshot in enumerate(history):
    print(f"--- 状态 #{i} ---")
    print(f"  配置: {state_snapshot.config}")
    print(f"  消息数: {len(state_snapshot.values.get('messages', []))}")
    print(f"  下一个节点: {state_snapshot.next}")
    print()
```

### 17.5.2 回溯到特定状态

```python
"""
时间旅行：回溯到历史状态
实际用途：撤销错误操作、重新尝试不同的回答路径
"""

# 获取历史
history = list(app.get_state_history(config))

# 假设我们想回到第2个状态（搜索RAG之后）
target_state = history[2]  # 选择目标状态

# 方法1：使用update_state回溯
# 这会"覆盖"当前状态，让Agent从目标状态继续
app.update_state(
    config,
    target_state.values,
    as_node=target_state.next[0] if target_state.next else None
)

# 从回溯点继续对话
result = app.invoke(
    {"messages": [HumanMessage(content="换一个方向，帮我搜索Function Calling")]},
    config=config
)
print(f"从回溯点继续的回答: {result['messages'][-1].content[:200]}")
```

### 17.5.3 时间旅行的实际用途

```python
# 用途1：撤销错误操作
# Agent不小心删除了错误的文档，回退到删除之前的状态

# 用途2：A/B测试
# 从同一个历史节点分叉两条路径，比较哪种回答更好
# 分叉方式：复制thread_id，在新thread上继续

# 用途3：调试
# Agent在第5步出错了，回退到第4步，修改prompt后重新执行

# 用途4：分支对话
# "如果当时我问了另一个问题会怎样？"
# 从历史节点分叉，探索不同的对话路径
```

## 17.6 多轮对话的完整实现

有了Checkpointer，我们终于可以实现一个真正的多轮对话系统了：

```python
"""
完整的多轮对话系统
支持：上下文记忆、对话历史、状态恢复
"""
from typing import TypedDict, Annotated
import json

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode
from langgraph.checkpoint.memory import MemorySaver
# 生产环境使用：
# from langgraph.checkpoint.sqlite import SqliteSaver

from langchain_core.messages import (
    HumanMessage, AIMessage, SystemMessage
)
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# ============================================================
# 工具定义
# ============================================================

@tool
def search_documents(query: str, top_k: int = 3) -> str:
    """搜索文档知识库。
    
    Args:
        query: 搜索关键词
        top_k: 返回结果数量
    """
    knowledge = {
        "agent": "AI Agent = LLM + Memory + Tools。三者缺一不可。",
        "rag": "RAG = 检索 + 生成。用外部知识增强LLM的回答能力。",
        "langgraph": "LangGraph = 状态图编排。支持循环、条件分支、人机协作。",
        "function_calling": "Function Calling = LLM调用工具的标准协议。",
    }
    results = [v for k, v in knowledge.items() if k in query.lower()]
    return "\n".join(results) if results else f"未找到'{query}'相关文档"


@tool
def calculate(expression: str) -> str:
    """执行数学计算。
    
    Args:
        expression: Python数学表达式
    """
    try:
        safe = {"abs": abs, "round": round, "min": min, "max": max, "sum": sum}
        result = eval(expression, {"__builtins__": safe}, {})
        return f"{expression} = {result}"
    except Exception as e:
        return f"计算错误: {str(e)}"


tools = [search_documents, calculate]
tool_map = {t.name: t for t in tools}


# ============================================================
# State定义
# ============================================================

class ChatState(TypedDict):
    messages: Annotated[list, add_messages]


# ============================================================
# Agent节点
# ============================================================

def chat_agent(state: ChatState) -> dict:
    """对话Agent"""
    llm = ChatOpenAI(model="gpt-4o", temperature=0)
    llm_with_tools = llm.bind_tools(tools)
    
    messages = state["messages"]
    if not messages or not isinstance(messages[0], SystemMessage):
        messages = [SystemMessage(content="""你是DocMind智能文档助手。
你正在与用户进行多轮对话。请利用之前的对话上下文来回答新问题。
优先使用工具获取准确信息。使用中文回答。""")] + messages
    
    response = llm_with_tools.invoke(messages)
    return {"messages": [response]}


def should_continue(state: ChatState) -> str:
    last_msg = state["messages"][-1]
    if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
        return "tools"
    return "__end__"


# ============================================================
# 构建图
# ============================================================

def build_chat_graph():
    """构建多轮对话Agent"""
    
    graph = StateGraph(ChatState)
    
    graph.add_node("agent", chat_agent)
    graph.add_node("tools", ToolNode(tools))
    
    graph.add_edge(START, "agent")
    graph.add_edge("tools", "agent")
    graph.add_conditional_edges("agent", should_continue)
    
    # 使用Checkpointer实现持久化
    checkpointer = MemorySaver()
    # 生产环境替换为：
    # checkpointer = SqliteSaver(conn)
    
    return graph.compile(checkpointer=checkpointer)


# ============================================================
# 多轮对话管理器
# ============================================================

class ConversationManager:
    """对话管理器：管理多个对话会话"""
    
    def __init__(self, app):
        self.app = app
        self.sessions = {}  # thread_id -> 会话元数据
    
    def create_session(self, session_name: str) -> str:
        """创建新的对话会话"""
        import uuid
        thread_id = str(uuid.uuid4())[:8]
        self.sessions[thread_id] = {
            "name": session_name,
            "message_count": 0
        }
        print(f"创建会话: {session_name} (thread_id: {thread_id})")
        return thread_id
    
    def chat(self, thread_id: str, user_input: str) -> str:
        """在指定会话中发送消息"""
        config = {"configurable": {"thread_id": thread_id}}
        
        result = self.app.invoke(
            {"messages": [HumanMessage(content=user_input)]},
            config=config
        )
        
        # 更新消息计数
        self.sessions[thread_id]["message_count"] = len(result["messages"])
        
        # 返回最后一条AI消息
        return result["messages"][-1].content
    
    def get_history(self, thread_id: str) -> list:
        """获取对话历史"""
        config = {"configurable": {"thread_id": thread_id}}
        state = self.app.get_state(config)
        
        history = []
        for msg in state.values.get("messages", []):
            msg_type = msg.__class__.__name__
            if msg_type == "HumanMessage":
                history.append({"role": "user", "content": msg.content})
            elif msg_type == "AIMessage" and msg.content:
                history.append({"role": "assistant", "content": msg.content})
        
        return history
    
    def list_sessions(self):
        """列出所有会话"""
        print("\n当前会话列表:")
        for tid, meta in self.sessions.items():
            print(f"  [{tid}] {meta['name']} - {meta['message_count']}条消息")
    
    def rollback(self, thread_id: str, steps_back: int = 1):
        """回滚到N步之前"""
        config = {"configurable": {"thread_id": thread_id}}
        history = list(self.app.get_state_history(config))
        
        if len(history) > steps_back:
            target = history[steps_back]
            self.app.update_state(config, target.values)
            print(f"已回滚 {steps_back} 步")
        else:
            print(f"历史记录不足（只有{len(history)}个状态）")


# ============================================================
# 完整演示
# ============================================================

def demo_full_conversation():
    """完整的多轮对话演示"""
    
    app = build_chat_graph()
    manager = ConversationManager(app)
    
    # 创建会话
    session_1 = manager.create_session("技术学习")
    session_2 = manager.create_session("项目讨论")
    
    # 会话1：多轮对话
    print("\n--- 会话1：技术学习 ---")
    
    print(f"\n用户: 什么是AI Agent？")
    reply = manager.chat(session_1, "什么是AI Agent？")
    print(f"DocMind: {reply[:200]}")
    
    print(f"\n用户: 它的Memory部分是怎么工作的？")
    reply = manager.chat(session_1, "它的Memory部分是怎么工作的？")
    print(f"DocMind: {reply[:200]}")
    
    print(f"\n用户: 那和我们现在用的Checkpointer有什么关系？")
    reply = manager.chat(session_1, "那和我们现在用的Checkpointer有什么关系？")
    print(f"DocMind: {reply[:200]}")
    
    # 会话2：独立对话
    print("\n--- 会话2：项目讨论 ---")
    
    print(f"\n用户: DocMind项目用了哪些技术？")
    reply = manager.chat(session_2, "DocMind项目用了哪些技术？")
    print(f"DocMind: {reply[:200]}")
    
    # 列出所有会话
    manager.list_sessions()
    
    # 查看会话1的历史
    print("\n--- 会话1的对话历史 ---")
    history = manager.get_history(session_1)
    for entry in history:
        print(f"  [{entry['role']}] {entry['content'][:100]}")
    
    # 回滚会话1到2步之前
    print("\n--- 回滚会话1 ---")
    manager.rollback(session_1, steps_back=2)
    
    # 从回滚点继续
    print(f"\n用户: 换个话题，帮我算一下 256 * 1024")
    reply = manager.chat(session_1, "换个话题，帮我算一下 256 * 1024")
    print(f"DocMind: {reply[:200]}")


if __name__ == "__main__":
    demo_full_conversation()
```

## 17.7 实操：为DocMind实现完整的对话持久化

```python
"""
DocMind完整持久化实现
支持：关闭重开、回溯历史、多会话管理
"""
import os
import json
import sqlite3
from typing import TypedDict, Annotated
from datetime import datetime

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode
from langgraph.checkpoint.memory import MemorySaver

from langchain_core.messages import HumanMessage, SystemMessage
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# ============================================================
# 持久化配置
# ============================================================

class PersistenceConfig:
    """持久化配置管理"""
    
    def __init__(self, use_sqlite: bool = False, db_path: str = "docmind.db"):
        self.use_sqlite = use_sqlite
        self.db_path = db_path
    
    def get_checkpointer(self):
        """根据配置创建对应的Checkpointer"""
        if self.use_sqlite:
            from langgraph.checkpoint.sqlite import SqliteSaver
            conn = sqlite3.connect(self.db_path, check_same_thread=False)
            checkpointer = SqliteSaver(conn)
            checkpointer.setup()
            print(f"使用SQLite持久化: {self.db_path}")
            return checkpointer
        else:
            print("使用内存Checkpointer（重启后数据丢失）")
            return MemorySaver()


# ============================================================
# DocMind持久化Agent
# ============================================================

class PersistentDocMind:
    """
    带持久化的DocMind Agent
    
    功能：
    - 对话历史自动保存
    - 支持关闭后重新打开
    - 支持回溯到历史状态
    - 支持多会话管理
    """
    
    def __init__(self, use_sqlite: bool = False):
        # 工具定义
        self.tools = self._create_tools()
        self.tool_map = {t.name: t for t in self.tools}
        
        # LLM
        self.llm = ChatOpenAI(model="gpt-4o", temperature=0)
        self.llm_with_tools = self.llm.bind_tools(self.tools)
        
        # 构建图
        self.app = self._build_graph(use_sqlite)
        
        # 当前会话
        self.current_thread_id = None
    
    def _create_tools(self):
        """创建工具集"""
        
        @tool
        def search_documents(query: str, top_k: int = 3) -> str:
            """搜索文档知识库。
            
            Args:
                query: 搜索关键词
                top_k: 返回结果数量
            """
            return f"关于'{query}'的搜索结果：找到{top_k}条相关文档..."
        
        @tool
        def calculate(expression: str) -> str:
            """数学计算。
            
            Args:
                expression: 数学表达式
            """
            try:
                safe = {"abs": abs, "round": round, "min": min, "max": max}
                result = eval(expression, {"__builtins__": safe}, {})
                return f"{expression} = {result}"
            except Exception as e:
                return f"计算错误: {str(e)}"
        
        return [search_documents, calculate]
    
    def _agent_node(self, state):
        """Agent节点"""
        messages = state["messages"]
        if not messages or not isinstance(messages[0], SystemMessage):
            messages = [SystemMessage(content="""你是DocMind智能文档助手。
利用对话上下文提供连贯的回答。优先使用工具获取准确信息。用中文回答。""")] + messages
        
        response = self.llm_with_tools.invoke(messages)
        return {"messages": [response]}
    
    def _should_continue(self, state):
        last_msg = state["messages"][-1]
        if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
            return "tools"
        return "__end__"
    
    def _build_graph(self, use_sqlite: bool):
        """构建LangGraph"""
        
        class ChatState(TypedDict):
            messages: Annotated[list, add_messages]
        
        graph = StateGraph(ChatState)
        graph.add_node("agent", self._agent_node)
        graph.add_node("tools", ToolNode(self.tools))
        
        graph.add_edge(START, "agent")
        graph.add_edge("tools", "agent")
        graph.add_conditional_edges("agent", self._should_continue)
        
        # 持久化
        config = PersistenceConfig(use_sqlite=use_sqlite)
        checkpointer = config.get_checkpointer()
        
        return graph.compile(checkpointer=checkpointer)
    
    def new_session(self, name: str = "default") -> str:
        """创建新会话"""
        import uuid
        self.current_thread_id = f"{name}_{uuid.uuid4().hex[:8]}"
        print(f"新会话: {self.current_thread_id}")
        return self.current_thread_id
    
    def load_session(self, thread_id: str):
        """加载已有会话"""
        self.current_thread_id = thread_id
        print(f"加载会话: {thread_id}")
        
        # 显示历史消息数
        config = {"configurable": {"thread_id": thread_id}}
        state = self.app.get_state(config)
        msg_count = len(state.values.get("messages", []))
        print(f"历史消息: {msg_count} 条")
    
    def chat(self, user_input: str) -> str:
        """发送消息"""
        if not self.current_thread_id:
            self.new_session()
        
        config = {"configurable": {"thread_id": self.current_thread_id}}
        
        result = self.app.invoke(
            {"messages": [HumanMessage(content=user_input)]},
            config=config
        )
        
        return result["messages"][-1].content
    
    def get_history(self) -> list:
        """获取当前会话历史"""
        config = {"configurable": {"thread_id": self.current_thread_id}}
        state = self.app.get_state(config)
        
        history = []
        for msg in state.values.get("messages", []):
            msg_type = msg.__class__.__name__
            if msg_type == "HumanMessage":
                history.append(f"[用户] {msg.content}")
            elif msg_type == "AIMessage" and msg.content:
                history.append(f"[DocMind] {msg.content}")
        return history
    
    def rollback(self, steps: int = 1):
        """回滚到N步之前"""
        config = {"configurable": {"thread_id": self.current_thread_id}}
        history = list(self.app.get_state_history(config))
        
        if len(history) > steps:
            target = history[steps]
            self.app.update_state(config, target.values)
            print(f"已回滚 {steps} 步")
        else:
            print(f"历史不足（共{len(history)}个状态）")
    
    def time_travel_info(self):
        """显示时间旅行信息"""
        config = {"configurable": {"thread_id": self.current_thread_id}}
        history = list(self.app.get_state_history(config))
        
        print(f"\n时间线（共 {len(history)} 个状态点）:")
        for i, snapshot in enumerate(history):
            msg_count = len(snapshot.values.get("messages", []))
            next_nodes = snapshot.next
            marker = " <-- 当前" if i == 0 else ""
            print(f"  [{i}] 消息数:{msg_count} 下一步:{next_nodes}{marker}")
```

## 17.8 本章小结

Checkpointer让Agent从"无状态"变为"有状态"：

| 概念 | 类比 | 作用 |
| ------ | ------ | ------ |
| Checkpointer | Git仓库 | 保存每个节点的完整状态 |
| Thread | HTTP Session | 隔离不同对话的状态 |
| thread_id | Session ID | 标识特定对话 |
| get_state_history | git log | 查看历史状态 |
| update_state | git checkout | 回溯到特定状态 |
| MemorySaver | 内存缓存 | 开发调试用 |
| SqliteSaver | 本地数据库 | 单机持久化 |
| PostgresSaver | 生产数据库 | 分布式持久化 |

### 关键收获

1. **Checkpointer是Agent的"Git"**——自动在每一步保存状态快照
2. **Thread是Agent的"Session"**——不同对话完全隔离
3. **时间旅行是可能的**——查看历史、回溯状态、分叉对话
4. **三种Checkpointer适应不同场景**——开发用Memory，生产用Postgres
5. **多轮对话终于完整了**——关闭重开、历史恢复、状态回滚
