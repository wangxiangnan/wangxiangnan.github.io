## 贯穿项目：DocMind

本教程以一个贯穿始终的实战项目驱动学习。DocMind是一个智能文档问答助手，帮开发者管理和查询技术文档。随着教程推进，DocMind会逐步演进：

| 阶段 | 章节 | 能力 |
| ------ | ------ | ------ |
| 基础版 | Ch01-Ch06 | 概念理解，不涉及实现 |
| RAG版 | Ch07-Ch12 | 文档加载 + 向量搜索 + Memory |
| Agent版 | Ch13-Ch18 | Function Calling + ReAct + LangGraph |
| 多Agent版 | Ch19-Ch20 | 多Agent协作 + 高级Tool |
| 生产版 | Ch21-Ch25 | RAG优化 + LCEL + 评估 + 安全 + 部署 |
