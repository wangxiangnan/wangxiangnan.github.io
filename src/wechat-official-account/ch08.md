# 第八章：互动设计——让粉丝留下来

## 核心观点

**关注是开始，互动是留存。**

## 8.1 关键词回复的三层设计

| 层级 | 关键词示例 | 目的 |
| --- | --- | --- |
| 导航层 | 目录 / 菜单 / 帮助 | 让用户知道能做什么 |
| 内容层 | 01 / 02 / 03… | 直接获取某期内容 |
| 彩蛋层 | undefined / 404 / null | 惊喜感，促传播 |

**匹配规则：**

- 核心关键词用**全匹配**（避免误触发）
- 资源类关键词用**半匹配**（命中更多变体）
- 彩蛋关键词用**全匹配**（制造惊喜感）

**回复内容：** 导航层给分类目录，内容层直接送回对应文章，彩蛋层给一句梗 + 一个资源链接。每条回复都带"回复目录查看全部"。

## 8.2 用户旅程自动回复

把用户从关注到回访的每个节点都设计好：

| 节点 | 触发方式 | 回复目标 | 示例（英语404） |
| --- | --- | --- | --- |
| 关注 | 被关注 | 欢迎 + 价值 + 下一步 | 见第 3 章公式 |
| 找内容 | 回复"目录" | 分类导航 | 按报错类型列出 5 个合集 |
| 拿资源 | 回复"词汇表" | 交付资料 + 使用说明 | 发送报错高频词表 |
| 提问 | 回复"提问" | 收集问题 + 承诺回复时间 | "收到，周五统一回答" |

**注意：** 订阅号不能主动私信用户。沉默读者的召回只能靠内容本身——在推送标题和文末体现"连续剧感"，比如"第 12 期：上次那个 CORS 报错，今天收尾"。

## 8.3 互动活动设计

| 活动 | 频率 | 目的 |
| --- | --- | --- |
| 打卡 | 每周 | 培养习惯，提升留存 |
| 投稿 | 长期 | 选题来源，用户参与 |
| 测验 | 每期 | 检验学习，增加趣味 |
| 投票 | 适时 | 了解偏好，制造话题 |

活动设计三要素：门槛低（一句话能参与）、反馈快（当周有回应）、有沉淀（结果能变成下期内容）。

## 8.4 留言区运营

**前提：** 2018 年 2 月之后新注册的公众号默认没有留言功能，是否开放以后台实际权限为准。以下分成"有留言"和"没留言"两套做法。

**有留言功能：**

- 每期精选 3-5 条留言
- 作者回复每条精选留言
- 置顶最有价值的留言
- 留言区提问，下期文章集中回答

**没有留言功能：**

- 文末放问卷（腾讯问卷 / 金数据），每周收集一次
- 用关键词"提问"收集后台消息，承诺周五统一回答
- 引导到读者群接龙，群内讨论后整理成文
- 把高频问题做成"读者问答"栏目，形成固定互动位

**通用原则：** 互动不是求点赞，是让读者感到"我说的话有人接"。每条反馈都要有可见的回应。
