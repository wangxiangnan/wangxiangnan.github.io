# 第18章 Human-in-the-Loop —— 人机协作与中断机制

## 18.1 开篇：为什么需要人类介入？

在前面的章节中，我们的Agent完全是自主运行的——它自己决定调用什么工具、怎么回答。这在大多数场景下没问题，但有些情况你需要"踩一脚刹车"：

- **高风险操作**：Agent要删除一个文件、发送一封邮件、执行一笔交易——你确定不需要人类确认一下？
- **质量审查**：Agent生成了法律文档或医疗建议——你敢不经审核就发出去？
- **权限控制**：Agent想访问敏感数据——当前用户有这个权限吗？
- **纠偏**：Agent的推理走偏了——人类想中途纠正它

> 用编程的话说：Human-in-the-Loop就像Git的Pull Request——代码（Agent的行动方案）写好了，但在合并（执行）之前，需要Reviewer（人类）看一眼。

这种"人类审批"的模式在LangGraph中有原生支持，叫做**中断机制（Interrupt）**。

## 18.2 LangGraph的中断机制

LangGraph提供了两种中断方式：

```python
# interrupt_before：在指定节点执行前暂停
# 适合：在执行前审查Agent的计划
app = graph.compile(
    interrupt_before=["tools"]  # 在执行工具之前暂停
)

# interrupt_after：在指定节点执行后暂停
# 适合：在执行后审查结果
app = graph.compile(
    interrupt_after=["agent"]  # Agent回复后暂停
)
```

### 工作流程

```
正常流程：  START -> agent -> tools -> agent -> END

interrupt_before=["tools"]时：
  START -> agent -> [暂停，等待人类确认] -> tools -> agent -> END
  
  人类可以：
  1. 批准（approve）-> 继续执行tools
  2. 拒绝（reject）  -> 修改状态后重新规划
  3. 修改（edit）    -> 改变工具参数后继续
```

## 18.3 审批模式实现

让我们实现一个完整的审批模式——Agent在执行敏感操作前需要人类确认：

```python
"""
Human-in-the-Loop：审批模式
Agent在执行工具前需要人类确认
"""
from typing import TypedDict, Annotated
import json

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode
from langgraph.checkpoint.memory import MemorySaver

from langchain_core.messages import (
    HumanMessage, AIMessage, SystemMessage, ToolMessage
)
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# ============================================================
# 工具定义（包含敏感操作）
# ============================================================

@tool
def search_documents(query: str) -> str:
    """搜索文档。这是安全操作，不需要审批。
    
    Args:
        query: 搜索关键词
    """
    return f"搜索结果：找到关于'{query}'的3篇相关文档..."


@tool
def send_email(to: str, subject: str, body: str) -> str:
    """发送邮件。这是敏感操作，需要人类审批！
    
    Args:
        to: 收件人邮箱
        subject: 邮件主题
        body: 邮件正文
    """
    return f"邮件已发送给 {to}，主题：{subject}"


@tool
def delete_document(doc_id: str) -> str:
    """删除文档。这是高风险操作，需要人类审批！
    
    Args:
        doc_id: 要删除的文档ID
    """
    return f"文档 {doc_id} 已被删除"


@tool
def update_knowledge_base(doc_id: str, content: str) -> str:
    """更新知识库中的文档。中等风险操作。
    
    Args:
        doc_id: 文档ID
        content: 新的文档内容
    """
    return f"文档 {doc_id} 已更新"


tools = [search_documents, send_email, delete_document, update_knowledge_base]
tool_map = {t.name: t for t in tools}


# ============================================================
# 定义需要审批的工具列表
# ============================================================

# 高风险工具：必须审批
SENSITIVE_TOOLS = {"send_email", "delete_document", "update_knowledge_base"}

# 安全工具：自动通过
SAFE_TOOLS = {"search_documents"}


# ============================================================
# State定义
# ============================================================

class ApprovalState(TypedDict):
    """审批系统状态"""
    messages: Annotated[list, add_messages]
    pending_approval: bool        # 是否有待审批的操作
    pending_tool_calls: list      # 待审批的工具调用
    approval_result: str          # 审批结果 (approved/rejected/modified)


# ============================================================
# 节点定义
# ============================================================

def agent_node(state: ApprovalState) -> dict:
    """Agent节点"""
    llm = ChatOpenAI(model="gpt-4o", temperature=0)
    llm_with_tools = llm.bind_tools(tools)
    
    messages = state["messages"]
    if not messages or not isinstance(messages[0], SystemMessage):
        messages = [SystemMessage(content="""你是DocMind助手。
你可以搜索文档、发送邮件、删除文档、更新知识库。
对于敏感操作（发邮件、删除、更新），系统会要求用户确认。
请用中文回答。""")] + messages
    
    response = llm_with_tools.invoke(messages)
    return {"messages": [response]}


def check_sensitivity(state: ApprovalState) -> dict:
    """
    敏感度检查节点
    检查Agent请求的工具调用是否需要人类审批
    """
    last_message = state["messages"][-1]
    
    if not hasattr(last_message, "tool_calls") or not last_message.tool_calls:
        return {
            "pending_approval": False,
            "pending_tool_calls": [],
            "approval_result": "auto_approved"
        }
    
    # 检查是否包含敏感工具
    sensitive_calls = []
    safe_calls = []
    
    for tc in last_message.tool_calls:
        if tc["name"] in SENSITIVE_TOOLS:
            sensitive_calls.append(tc)
        else:
            safe_calls.append(tc)
    
    if sensitive_calls:
        print(f"\n[需要审批] 以下操作需要人类确认：")
        for tc in sensitive_calls:
            print(f"  - {tc['name']}({json.dumps(tc['args'], ensure_ascii=False)})")
        
        return {
            "pending_approval": True,
            "pending_tool_calls": sensitive_calls,
            "approval_result": "pending"
        }
    
    return {
        "pending_approval": False,
        "pending_tool_calls": [],
        "approval_result": "auto_approved"
    }


def execute_approved_tools(state: ApprovalState) -> dict:
    """执行已批准的工具"""
    tool_messages = []
    
    # 获取最后一个AIMessage的tool_calls
    last_ai = None
    for msg in reversed(state["messages"]):
        if isinstance(msg, AIMessage):
            last_ai = msg
            break
    
    if not last_ai or not last_ai.tool_calls:
        return {"messages": []}
    
    for tc in last_ai.tool_calls:
        tool_name = tc["name"]
        tool_args = tc["args"]
        tool_id = tc["id"]
        
        try:
            if tool_name in tool_map:
                result = tool_map[tool_name].invoke(tool_args)
            else:
                result = f"错误：工具 {tool_name} 不存在"
        except Exception as e:
            result = f"工具执行失败: {str(e)}"
        
        tool_messages.append(ToolMessage(
            content=str(result),
            tool_call_id=tool_id,
            name=tool_name
        ))
    
    return {
        "messages": tool_messages,
        "pending_approval": False,
        "approval_result": "executed"
    }


# ============================================================
# 条件路由
# ============================================================

def route_after_agent(state: ApprovalState) -> str:
    """Agent之后的路由：是否需要工具"""
    last_message = state["messages"][-1]
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "check"  # 有工具调用，先检查敏感度
    return "__end__"    # 没有工具调用，结束


def route_after_check(state: ApprovalState) -> str:
    """敏感度检查后的路由"""
    if state.get("pending_approval"):
        return "wait_approval"  # 需要审批
    return "execute"           # 不需要审批，直接执行


# ============================================================
# 构建图
# ============================================================

def build_approval_graph():
    """构建带审批流程的Agent图"""
    
    graph = StateGraph(ApprovalState)
    
    # 添加节点
    graph.add_node("agent", agent_node)
    graph.add_node("check", check_sensitivity)
    graph.add_node("execute", execute_approved_tools)
    graph.add_node("wait_approval", lambda state: state)  # 占位节点
    
    # 添加边
    graph.add_edge(START, "agent")
    
    # Agent之后：检查是否有工具调用
    graph.add_conditional_edges("agent", route_after_agent, {
        "check": "check",
        "__end__": END
    })
    
    # 检查之后：是否需要审批
    graph.add_conditional_edges("check", route_after_check, {
        "wait_approval": "wait_approval",
        "execute": "execute"
    })
    
    # 执行完后回到Agent
    graph.add_edge("execute", "agent")
    graph.add_edge("wait_approval", END)  # 等待审批时暂停
    
    # 编译，使用checkpointer保存状态
    checkpointer = MemorySaver()
    return graph.compile(
        checkpointer=checkpointer,
        interrupt_before=["wait_approval"]  # 在等待审批前中断
    )


# ============================================================
# 使用带审批的Agent
# ============================================================

def demo_approval_flow():
    """演示审批流程"""
    
    app = build_approval_graph()
    
    # 使用固定的thread_id来追踪对话
    config = {"configurable": {"thread_id": "approval-demo-1"}}
    
    # 测试1：安全操作（不需要审批）
    print("\n--- 测试1：搜索文档（安全操作）---")
    result = app.invoke(
        {"messages": [HumanMessage(content="搜索关于Agent架构的文档")],
         "pending_approval": False, "pending_tool_calls": [], "approval_result": ""},
        config=config
    )
    print(f"结果: {result['messages'][-1].content[:200]}")
    
    # 测试2：敏感操作（需要审批）
    print("\n--- 测试2：发送邮件（敏感操作）---")
    result = app.invoke(
        {"messages": [HumanMessage(
            content="帮我给 zhangsan@example.com 发一封邮件，主题是项目进度，内容是本周已完成80%"
        )],
         "pending_approval": False, "pending_tool_calls": [], "approval_result": ""},
        config=config
    )
    
    # 此时图会在wait_approval节点前中断
    # 检查当前状态
    current_state = app.get_state(config)
    print(f"\n图已中断，当前状态:")
    print(f"  pending_approval: {current_state.values.get('pending_approval')}")
    print(f"  pending_tool_calls: {current_state.values.get('pending_tool_calls')}")
    
    # 模拟人类审批
    print("\n--- 人类审批 ---")
    user_decision = input("是否批准这个操作？(y/n): ").strip().lower()
    
    if user_decision == 'y':
        # 批准：修改状态，让工具执行
        print("人类批准了操作")
        app.update_state(config, {
            "pending_approval": False,
            "approval_result": "approved"
        })
        # 继续执行
        result = app.invoke(None, config=config)
        print(f"执行结果: {result['messages'][-1].content[:200]}")
    else:
        # 拒绝：告诉Agent用户拒绝了
        print("人类拒绝了操作")
        app.update_state(config, {
            "pending_approval": False,
            "approval_result": "rejected",
            "messages": [HumanMessage(content="用户拒绝了这个操作，请不要发送邮件。")]
        })
        result = app.invoke(None, config=config)
        print(f"Agent回复: {result['messages'][-1].content[:200]}")


if __name__ == "__main__":
    demo_approval_flow()
```

## 18.4 状态修改(Edit State)

Human-in-the-Loop不只是"批准/拒绝"——人类还可以**修改Agent的中间状态**：

```python
"""
状态修改：人类纠正Agent的中间结果
"""

def demo_state_editing():
    """演示状态修改"""
    
    app = build_approval_graph()
    config = {"configurable": {"thread_id": "edit-demo-1"}}
    
    # Agent想要搜索"Agent"但搜索词太模糊
    print("--- Agent搜索'Agent' ---")
    result = app.invoke(
        {"messages": [HumanMessage(content="搜索Agent相关内容")],
         "pending_approval": False, "pending_tool_calls": [], "approval_result": ""},
        config=config
    )
    
    # 假设Agent搜索了"Agent"但结果太多
    # 人类可以修改搜索词让它更精确
    
    # 获取当前状态
    current_state = app.get_state(config)
    print(f"\n当前消息数: {len(current_state.values['messages'])}")
    
    # 修改状态：注入一条额外的上下文
    app.update_state(config, {
        "messages": [HumanMessage(
            content="补充信息：我说的Agent是指AI Agent，不是普通代理人。请搜索'AI Agent architecture'。"
        )]
    })
    
    # 继续执行，Agent会看到新的上下文
    result = app.invoke(None, config=config)
    print(f"\nAgent的改进回答: {result['messages'][-1].content[:200]}")
```

### 状态修改的常见用途

```python
# 1. 修改工具参数
# Agent想删除doc_001，但人类说应该删除doc_002
app.update_state(config, {
    "messages": [HumanMessage(content="请删除doc_002而不是doc_001")]
})

# 2. 注入额外上下文
# Agent缺少某个信息，人类补充
app.update_state(config, {
    "messages": [HumanMessage(content="补充：这个项目的截止日期是下周五")]
})

# 3. 撤销上一步操作
# Agent做错了，人类想回退
# （更完整的回退功能见下一章Checkpointer的时间旅行）
```

## 18.5 断点(Breakpoint)的使用

断点是调试Agent的强大工具——就像IDE里的断点一样，让图在指定位置暂停：

```python
"""
断点调试：逐步执行Agent图
"""

def demo_breakpoint_debugging():
    """使用断点调试Agent"""
    
    # 编译时在多个节点设置中断
    app = build_approval_graph()
    # 也可以在编译后动态设置
    # app.interrupt_before = ["check", "execute"]
    
    config = {"configurable": {"thread_id": "debug-demo"}}
    
    # 第一次执行——会在第一个中断点暂停
    print("--- 开始执行 ---")
    result = app.invoke(
        {"messages": [HumanMessage(content="搜索RAG文档，然后发邮件给boss汇报进度")],
         "pending_approval": False, "pending_tool_calls": [], "approval_result": ""},
        config=config
    )
    
    # 查看当前状态
    state = app.get_state(config)
    print(f"\n当前在哪个节点暂停: {state.next}")
    print(f"消息历史: {len(state.values['messages'])} 条")
    
    # 继续执行到下一个中断点
    print("\n--- 继续执行 ---")
    result = app.invoke(None, config=config)
    
    state = app.get_state(config)
    print(f"下一个暂停点: {state.next}")
    
    # 再次继续
    print("\n--- 再次继续 ---")
    result = app.invoke(None, config=config)
    
    print(f"\n最终回答: {result['messages'][-1].content[:200]}")
```

## 18.6 实操：为DocMind添加人类审核环节

让我们把所有Human-in-the-Loop的知识应用到DocMind项目中：

```python
"""
DocMind with Human-in-the-Loop
为DocMind添加人类审核：
- 删除操作需确认
- 敏感信息过滤
- 外部操作（发邮件、调API）需审批
"""
from typing import TypedDict, Annotated, Literal
import json
import re

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.memory import MemorySaver
from langchain_core.messages import (
    HumanMessage, AIMessage, SystemMessage, ToolMessage
)
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# ============================================================
# 工具定义
# ============================================================

@tool
def search_documents(query: str, top_k: int = 3) -> str:
    """搜索文档知识库。安全操作，无需审批。
    
    Args:
        query: 搜索关键词
        top_k: 返回结果数
    """
    return f"找到关于'{query}'的{top_k}条结果：\n1. AI Agent架构概述...\n2. RAG技术详解...\n3. LangGraph实战..."


@tool
def delete_document(doc_id: str, reason: str = "") -> str:
    """删除指定文档。高风险操作！需要用户确认。
    
    Args:
        doc_id: 文档ID
        reason: 删除原因
    """
    return f"文档 {doc_id} 已删除。原因：{reason}"


@tool
def export_report(query: str, format: str = "pdf") -> str:
    """导出分析报告。涉及外部操作，需要确认。
    
    Args:
        query: 报告主题
        format: 导出格式 (pdf/csv/json)
    """
    return f"报告已导出为{format}格式：report_{query}.{format}"


@tool
def notify_admin(message: str, priority: str = "normal") -> str:
    """向管理员发送通知。需要确认。
    
    Args:
        message: 通知内容
        priority: 优先级 (low/normal/high/critical)
    """
    return f"通知已发送（优先级:{priority}）: {message}"


# 工具分类
SAFE_TOOLS = {"search_documents"}
SENSITIVE_TOOLS = {"delete_document", "export_report", "notify_admin"}

all_tools = [search_documents, delete_document, export_report, notify_admin]
tool_map = {t.name: t for t in all_tools}


# ============================================================
# State定义
# ============================================================

class DocMindHITLState(TypedDict):
    messages: Annotated[list, add_messages]
    needs_approval: bool
    pending_actions: list  # [{"tool": "name", "args": {...}}]


# ============================================================
# 节点定义
# ============================================================

def docmind_agent(state: DocMindHITLState) -> dict:
    """DocMind Agent节点"""
    llm = ChatOpenAI(model="gpt-4o", temperature=0)
    llm_with_tools = llm.bind_tools(all_tools)
    
    messages = state["messages"]
    if not messages or not isinstance(messages[0], SystemMessage):
        messages = [SystemMessage(content="""你是DocMind智能文档助手。

你可以：
- search_documents: 搜索文档（安全）
- delete_document: 删除文档（需确认）
- export_report: 导出报告（需确认）
- notify_admin: 发送通知（需确认）

重要规则：
1. 搜索类操作可以直接执行
2. 删除、导出、通知等操作，系统会先请求用户确认
3. 使用中文回答
""")] + messages
    
    response = llm_with_tools.invoke(messages)
    return {"messages": [response]}


def sensitivity_checker(state: DocMindHITLState) -> dict:
    """敏感度检查节点"""
    last_msg = state["messages"][-1]
    
    if not hasattr(last_msg, "tool_calls") or not last_msg.tool_calls:
        return {"needs_approval": False, "pending_actions": []}
    
    sensitive_actions = []
    for tc in last_msg.tool_calls:
        if tc["name"] in SENSITIVE_TOOLS:
            sensitive_actions.append({
                "tool": tc["name"],
                "args": tc["args"],
                "id": tc["id"]
            })
    
    if sensitive_actions:
        action_descriptions = []
        for action in sensitive_actions:
            args_str = json.dumps(action["args"], ensure_ascii=False)
            action_descriptions.append(f"  - {action['tool']}({args_str})")
        
        print(f"\n[需要确认] 以下敏感操作等待审批：")
        print("\n".join(action_descriptions))
        
        return {
            "needs_approval": True,
            "pending_actions": sensitive_actions
        }
    
    return {"needs_approval": False, "pending_actions": []}


def execute_tools(state: DocMindHITLState) -> dict:
    """执行工具节点（只执行安全的或已审批的工具）"""
    last_ai = None
    for msg in reversed(state["messages"]):
        if isinstance(msg, AIMessage):
            last_ai = msg
            break
    
    if not last_ai or not last_ai.tool_calls:
        return {"messages": []}
    
    tool_messages = []
    for tc in last_ai.tool_calls:
        name, args, tid = tc["name"], tc["args"], tc["id"]
        try:
            result = tool_map[name].invoke(args) if name in tool_map else f"工具不存在: {name}"
        except Exception as e:
            result = f"执行失败: {str(e)}"
        
        tool_messages.append(ToolMessage(
            content=str(result), tool_call_id=tid, name=name
        ))
    
    return {"messages": tool_messages}


def human_review_node(state: DocMindHITLState) -> dict:
    """人类审核节点（占位，实际通过interrupt实现）"""
    # 这个节点本身不做事
    # interrupt_before会让图在执行它之前暂停
    # 人类审批后通过update_state修改状态并继续
    return {"needs_approval": False}


# ============================================================
# 条件路由
# ============================================================

def route_after_agent(state: DocMindHITLState) -> Literal["check", "__end__"]:
    last_msg = state["messages"][-1]
    if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
        return "check"
    return "__end__"


def route_after_check(state: DocMindHITLState) -> Literal["review", "execute"]:
    if state.get("needs_approval"):
        return "review"
    return "execute"


# ============================================================
# 构建图
# ============================================================

def build_docmind_hitl():
    """构建带人类审核的DocMind"""
    
    graph = StateGraph(DocMindHITLState)
    
    graph.add_node("agent", docmind_agent)
    graph.add_node("check", sensitivity_checker)
    graph.add_node("execute", execute_tools)
    graph.add_node("review", human_review_node)
    
    graph.add_edge(START, "agent")
    
    graph.add_conditional_edges("agent", route_after_agent)
    graph.add_conditional_edges("check", route_after_check)
    
    graph.add_edge("execute", "agent")   # 执行完工具回到Agent
    graph.add_edge("review", "execute")  # 审核通过后执行
    
    checkpointer = MemorySaver()
    return graph.compile(
        checkpointer=checkpointer,
        interrupt_before=["review"]  # 在审核节点前中断
    )


# ============================================================
# 交互式使用
# ============================================================

def interactive_docmind():
    """交互式DocMind（带人类审核）"""
    
    app = build_docmind_hitl()
    thread_id = "interactive-session-1"
    config = {"configurable": {"thread_id": thread_id}}
    
    print("DocMind (带人类审核) 已启动")
    print("输入问题，输入 'quit' 退出\n")
    
    while True:
        user_input = input("你: ").strip()
        
        if user_input.lower() in ['quit', 'exit']:
            break
        
        if not user_input:
            continue
        
        # 发送消息
        result = app.invoke(
            {"messages": [HumanMessage(content=user_input)],
             "needs_approval": False, "pending_actions": []},
            config=config
        )
        
        # 检查是否中断（等待审批）
        state = app.get_state(config)
        
        if state.next:  # 图被中断了
            print(f"\n[审核请求] Agent想要执行敏感操作")
            actions = state.values.get("pending_actions", [])
            for action in actions:
                print(f"  操作: {action['tool']}({json.dumps(action['args'], ensure_ascii=False)})")
            
            decision = input("\n批准？(y=批准/n=拒绝/m=修改): ").strip().lower()
            
            if decision == 'y':
                print("[已批准] 继续执行...")
                app.update_state(config, {"needs_approval": False})
                result = app.invoke(None, config=config)
                
            elif decision == 'n':
                print("[已拒绝]")
                app.update_state(config, {
                    "needs_approval": False,
                    "messages": [HumanMessage(content="我拒绝了这个操作，请用其他方式完成任务。")]
                })
                result = app.invoke(None, config=config)
                
            elif decision == 'm':
                modification = input("请输入修改意见: ").strip()
                app.update_state(config, {
                    "needs_approval": False,
                    "messages": [HumanMessage(content=f"用户修改了操作要求：{modification}")]
                })
                result = app.invoke(None, config=config)
        
        # 显示最终回答
        final = result["messages"][-1]
        if hasattr(final, "content") and final.content:
            print(f"\nDocMind: {final.content}\n")


if __name__ == "__main__":
    interactive_docmind()
```

## 18.7 本章小结

Human-in-the-Loop让Agent从"完全自主"变为"人机协作"：

| 机制 | 用途 | LangGraph实现 |
| ------ | ------ | ------------- |
| interrupt_before | 执行前审查 | `compile(interrupt_before=["node"])` |
| interrupt_after | 执行后审查 | `compile(interrupt_after=["node"])` |
| update_state | 人类修改中间状态 | `app.update_state(config, {...})` |
| get_state | 查看当前状态 | `app.get_state(config)` |

### 设计原则

```
1. 安全操作自动通过（不要让用户审批每个搜索请求）
2. 高风险操作必须审批（删除、发送、支付）
3. 给用户提供清晰的审批信息（不是"是否继续"，而是"是否删除doc_001"）
4. 允许用户修改而不只是批准/拒绝
5. 使用checkpointer保持状态，支持中断恢复
```

## 18.8 思考题

1. **概念题**：interrupt_before和interrupt_after有什么区别？各自适合什么场景？
2. **设计题**：设计一个"分级审批系统"——低风险自动通过，中风险需要主管审批，高风险需要管理员审批。
3. **实践题**：为审批流程添加超时机制——如果30秒内人类没有响应，自动拒绝操作。
4. **思考题**：Human-in-the-Loop会降低用户体验（每次都问"确认吗？"很烦）。你怎么设计才能既保证安全又不打扰用户？
5. **挑战题**：实现一个"批量审批"功能——Agent同时请求5个操作，人类可以逐个批准/拒绝，也可以一键全部批准。
