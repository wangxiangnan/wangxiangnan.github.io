# 第8章：导出设置——让你的视频出现在每个屏幕上 📤

*小陈终于完成了他的第一条精心制作的Vlog。调色、音乐、字幕，样样到位。他兴奋地点击导出，然后面对弹出的几十个参数选项傻眼了："H.264是什么？码率设多少？分辨率选1080p还是4K？发抖音和发B站参数一样吗？"他随便选了些参数导出，上传后发现画面颜色和在软件里看到的不一样，文件大小还超过了平台限制……导出这个"最后一公里"，差点毁了他前面所有的努力。*

## 8.1 交付页(Deliver)详解

导出视频在DaVinci Resolve的**交付页（Deliver Page）**完成——就是底部那个火箭图标🚀。

交付页界面分为几个区域：

- **左侧——渲染设置（Render Settings）**：选择导出预设或自定义参数
- **中间——预览区域**：可以预览导出范围和效果
- **右侧——渲染队列（Render Queue）**：管理待导出的任务

DaVinci Resolve内置了一些快捷预设：YouTube、Vimeo、H.264、H.265等。对于国内平台，我们通常需要自定义设置。

**导出的基本流程：**

1. 在时间线上设置入点和出点（标记导出范围）——按 `I` 设置入点，按 `O` 设置出点
2. 在左侧选择或配置导出参数
3. 设置文件名和保存路径
4. 点击**添加到渲染队列（Add to Render Queue）**
5. 在右侧渲染队列中点击**全部渲染（Render All）**

## 8.2 视频编码基础：H.264 vs H.265 vs ProRes

视频编码是把你的剪辑"压缩打包"成一个视频文件的过程。打个快递的比方：

- **H.264** 就像一个**标准快递箱**——压缩效率不错，兼容性最好（任何设备都能打开），是目前最常用的编码格式。就像顺丰快递，到哪都能送。
- **H.265（HEVC）** 就像一个**压缩黑科技收纳袋**——比H.264压缩效率高一倍（同样画质文件体积减半），但老设备可能打不开。就像最新款的真空压缩袋，省空间但需要特定工具才能打开。
- **ProRes / DNxHR** 就像一个**不压缩的保险箱**——文件巨大但品质完美，通常用于后期制作中间环节，不适合直接上传平台。就像你把东西原封不动装进大箱子，占地方但零损伤。

**新手建议：日常导出用H.264，需要小文件用H.265，需要后续再编辑用ProRes。**

## 8.3 分辨率与帧率选择

**分辨率：**

| 分辨率 | 像素尺寸 | 适用场景 |
| ------- | --------- | --------- |
| 720p | 1280×720 | 低带宽环境、老旧设备 |
| 1080p | 1920×1080 | **主流平台标准**，推荐默认选择 |
| 2K | 2560×1440 | 高端展示，B站支持 |
| 4K | 3840×2160 | 需要极高画质、素材本身就是4K |

> 💡 **提示**：如果你的素材是1080p拍的，导出4K并不会变清晰——只是把1080p画面拉大了，文件还更大。除非素材是4K的，否则导出1080p就够了。

**竖屏视频分辨率：**

- 竖屏9:16 → **1080×1920**（抖音、小红书、Instagram Reels）
- 正方形1:1 → **1080×1080**（Instagram帖子、部分社交平台）

**帧率：**

| 帧率 | 视觉效果 | 适用场景 |
| ----- | --------- | --------- |
| 24fps | 电影感，略有运动模糊 | 电影感Vlog、文艺短片 |
| 25fps | PAL制式标准 | 中国/欧洲电视标准 |
| 30fps | 流畅自然 | **Vlog日常推荐**、大部分网络视频 |
| 60fps | 极其流畅 | 游戏视频、慢动作（后期变速用） |

> 💡 **提示**：导出帧率应该和拍摄帧率一致。如果你拍摄时用的30fps，导出也用30fps。除非你有意要做变速效果。

## 8.4 码率设置：文件大小与画质的平衡

**码率（Bitrate）** 是决定画质和文件大小的关键参数——它表示每秒钟视频包含多少数据量。

比喻：码率就像水管的水流量。水管越粗（码率越高），流过去的水越多（画面信息越丰富、画质越好），但占用的空间也越大（文件越大）。

**推荐码率设置（2026年标准）：**

| 分辨率 | 平台推荐码率 | 文件预估大小（5分钟视频） |
| ------- | ------------ | ---------------------- |
| 1080p 30fps | 8-12 Mbps | 约 300-450 MB |
| 1080p 60fps | 12-16 Mbps | 约 450-600 MB |
| 4K 30fps | 20-35 Mbps | 约 750 MB - 1.3 GB |
| 4K 60fps | 35-50 Mbps | 约 1.3-1.9 GB |

在DaVinci Resolve中设置码率：

- 在交付页的**文件（File）**选项卡中
- 找到**质量（Quality）**设置
- 选择**限制为（Restrict to）**，输入目标码率值（单位是Kb/s）
- 例如设置10000 Kb/s = 10 Mbps

**编码模式选择：**

- **CBR（固定码率）**：全程保持同一码率，文件较大但稳定
- **VBR（可变码率）**：根据画面复杂度自动调整码率，文件更小。推荐日常使用

> 💡 **提示**：码率不是越高越好。超过平台推荐值太多，平台在接收你的视频后会强制"二次压缩"，可能压出来的效果还不如你直接按推荐码率导出。

## 8.6 音频导出设置

音频导出参数相对简单，但也很重要：

- **编码格式**：AAC（最通用）
- **采样率**：48kHz（视频标准）或 44.1kHz（CD标准）
- **比特率**：192kbps（日常）或 320kbps（高品质）
- **声道**：Stereo（立体声）

在交付页的**音频（Audio）**选项卡中设置。确保"导出音频"选项是开启的——别问我怎么知道有人会关掉它然后纳闷为什么视频没声音。

## 8.7 批量导出与渲染队列

如果你需要导出同一个项目的多个版本（比如横屏版和竖屏版），DaVinci的渲染队列可以帮你批量处理：

1. 设置好第一版的导出参数
2. 在时间线上设置对应的入点/出点
3. 点击"添加到渲染队列"
4. 修改参数设置第二版
5. 再次"添加到渲染队列"
6. 所有任务添加完毕后，点击**全部渲染（Render All）**

软件会按顺序依次渲染所有任务。你可以去喝杯咖啡，回来就都好了。

**渲染速度优化：**

- 如果你的电脑有NVIDIA显卡，在偏好设置中启用**GPU加速**，渲染速度会快很多
- 关闭不必要的后台程序
- 确保硬盘有足够空间（渲染中间文件也需要空间）

## 8.8 导出常见问题

**问题1：导出的视频颜色和在软件里看到的不一样**

- 原因：色彩空间不匹配。DaVinci默认使用DaVinci YRGB色彩空间，导出时要确认色彩空间设置正确
- 解决：在交付页的高级设置中，确认色彩空间为**Rec.709**（标准SDR）
- 如果是Mac用户，QuickTime播放器有自己的色彩管理，可能导致看起来偏色。用VLC播放器检查

**问题2：音频和画面不同步**

- 原因：可能是帧率不匹配或音频采样率问题
- 解决：确认导出帧率与项目帧率一致。如果使用了变速片段，检查音频是否跟随变速

**问题3：导出的文件太大**

- 原因：码率设置过高
- 解决：降低码率值，或改用H.265编码（同画质文件更小）
- 也可以用第三方工具（如HandBrake）对导出文件做二次压缩

**问题4：导出后画面有横纹/条纹**

- 原因：可能是隔行扫描素材没有做反隔行处理
- 解决：在剪辑页右键素材 > 片段属性 > 启用**反隔行（Deinterlace）**

**问题5：渲染失败/报错**

- 检查磁盘空间是否充足
- 尝试更换导出路径（避免中文路径或过长路径）
- 降低分辨率或码率试试
- 更新显卡驱动

> 💡 **提示**：每次导出后，一定要完整播放一遍检查！重点看：颜色是否正常、音画是否同步、字幕是否被裁切、文件大小是否在平台限制内。这个步骤不能省。

## 8.9 实战：为不同平台导出适配版本的Vlog

小陈要把他的探店Vlog同时发到抖音（竖屏）、B站（横屏）和小红书（竖屏），他需要导出三个版本。

**第1版：B站横屏版**

- 分辨率：1920×1080
- 帧率：30fps
- 编码：H.264
- 码率：12 Mbps
- 音频：AAC 48kHz 320kbps
- 格式：MP4

**第2版：抖音竖屏版**

- 在项目设置中调整时间线分辨率为 1080×1920
- 调整画面构图（可能需要重新裁切或缩放画面）
- 码率：8 Mbps
- 其余参数同上

**第3版：小红书竖屏版**

- 与抖音版类似，但可以导出方形 1080×1080 版本作为备选
- 码率可以稍低：6-8 Mbps

三个版本依次添加到渲染队列，一次性全部渲染。导出后分别在对应平台的预览模式下检查效果。

**本章小结：**

| 知识点 | 要点 |
| ------- | ------ |
| 编码格式 | H.264最通用，H.265更省空间，ProRes用于后期 |
| 分辨率 | 素材是什么分辨率就导什么，别"假4K" |
| 码率 | 影响文件大小和画质的关键参数 |
| 平台适配 | 每个平台的推荐参数不同，按需调整 |
| 音频 | AAC 48kHz 192-320kbps |
| 批量导出 | 渲染队列支持多任务排队 |
| 导出检查 | 每次导出后必须完整播放检查 |

**练习题：**

1. **【基础】** 按照B站推荐参数导出一段视频。导出后用手机播放检查画质和声音，确认音画同步。

2. **【进阶】** 为同一段视频导出两个版本：一个1080p高码率版（12Mbps）和一个1080p低码率版（4Mbps）。对比两者的画质差异和文件大小，理解码率对画质的影响。

3. **【挑战】** 导出竖屏版本（1080×1920），处理横屏素材转竖屏时的画面裁切和构图问题。确保主体在竖屏画面中位置合理。
