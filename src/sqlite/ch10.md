# 第10章：Flutter 集成（一）——sqflite 上手实战

## 10.1 开场白：Flutter 里怎么"抱住"SQLite？

Flutter 有很多本地存储方案：SharedPreferences（KV）、Hive（NoSQL）、Isar（对象数据库）、ObjectBox、Realm……但是有一类需求，只有 SQLite 能优雅胜任——**结构化的关系型数据**。购物车、聊天记录、离线笔记、财务记账，这些场景里"表 + JOIN + 事务"的组合拳还是无敌的。

Flutter 里访问 SQLite 有两大方案：

- **sqflite**：官方推荐、社区最流行、直接写 SQL 字符串。
- **drift**：类型安全 ORM、代码生成、更现代。

这一章我们先啃 sqflite。第 11 章讲 drift。

## 10.2 sqflite 架构剖析

sqflite 的架构不是"Dart 直接调 SQLite"，而是：

```
Flutter (Dart)
    ↓ MethodChannel
Native (iOS: FMDB / Android: SQLiteDatabase)
    ↓ JNI/OC
SQLite C 库
```

Dart 端拼 SQL 字符串，通过 MethodChannel 发到原生层，原生层调 SQLite C API 执行，结果返回来。

**优点**：

- 依托平台原生 SQLite，稳定成熟。
- iOS/Android 都用系统内置的 SQLite（版本随系统）。

**缺点**：

- 桥接开销：每次调用有 MethodChannel 序列化成本。
- 只支持移动端（iOS/Android）；桌面端要用 `sqflite_common_ffi`。
- SQL 字符串没有编译期检查——运行时才知道错。

## 10.3 sqflite vs sqflite_common_ffi 全家桶

| 包名                     | 目标平台               | 底层                    |
| ------------------------ | ---------------------- | ----------------------- |
| `sqflite`                | iOS / Android          | 平台原生 SQLite         |
| `sqflite_common_ffi`     | 桌面（Win/macOS/Linux）| dart:ffi 加载 SQLite    |
| `sqflite_common_ffi_web` | Web                    | WebAssembly SQLite      |
| `sqflite_sqlcipher`      | iOS/Android + 加密     | SQLCipher               |

**跨平台代码**：

```dart
import 'package:sqflite/sqflite.dart';
import 'package:sqflite_common_ffi/sqflite_ffi.dart';
import 'dart:io' show Platform;

Future<void> initSqflite() async {
  if (Platform.isWindows || Platform.isLinux) {
    sqfliteFfiInit();
    databaseFactory = databaseFactoryFfi;
  }
  // iOS/Android/macOS 直接用默认 databaseFactory
}
```

后续的所有 API（`openDatabase`、`db.query`）在两种模式下都一样。

## 10.5 数据库初始化：openDatabase 全参数解析

```dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

Future<Database> initDb() async {
  final appDir = await getApplicationDocumentsDirectory();
  final dbPath = p.join(appDir.path, 'my_app.db');

  return openDatabase(
    dbPath,
    version: 3,
    onConfigure: (db) async {
      // 在任何 onCreate/onUpgrade 之前执行
      await db.execute('PRAGMA foreign_keys = ON');
    },
    onCreate: (db, version) async {
      // 数据库第一次创建时调用
      await _createTables(db);
      await _seedInitialData(db);
    },
    onUpgrade: (db, oldVersion, newVersion) async {
      // 版本升级
      await _migrate(db, oldVersion, newVersion);
    },
    onDowngrade: (db, oldVersion, newVersion) async {
      // 版本降级（极少见）
      // 默认策略是 onDowngradeDelete（删库重建）
    },
    onOpen: (db) async {
      // 每次打开都会执行（onCreate/onUpgrade 之后）
      print('DB opened, version: ${await db.getVersion()}');
    },
    readOnly: false,
    singleInstance: true,    // 默认，同一路径返回同一 Database 实例
  );
}
```

**关键参数解读**：

- **`version`**：整数，用来判断是否要升级。首次打开 = onCreate；version 比上次大 = onUpgrade；比上次小 = onDowngrade。
- **`onConfigure`**：连接建立后、事务打开前调用。是开外键、设 WAL、设 encoding 的最佳位置。
- **`onCreate`**：数据库文件不存在时（首次创建）调用。
- **`onUpgrade(oldV, newV)`**：处理增量迁移。
- **`singleInstance: true`**：同一路径多次调用 openDatabase 返回同一个 Database（避免多连接锁问题）。

## 10.6 版本迁移策略：从 v1 到 v3

假设你的应用经历了这些版本演进：

- **v1**：只有 `todo` 表。
- **v2**：加了 `category` 表和 `todo.category_id` 外键。
- **v3**：给 `todo` 加了 `priority` 列。

迁移代码：

```dart
Future<void> _migrate(Database db, int oldVersion, int newVersion) async {
  final batch = db.batch();
  if (oldVersion < 2) {
    // v1 → v2
    batch.execute('''
      CREATE TABLE category(
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL UNIQUE
      )
    ''');
    batch.execute('ALTER TABLE todo ADD COLUMN category_id INTEGER REFERENCES category(id)');
  }
  if (oldVersion < 3) {
    // v2 → v3
    batch.execute("ALTER TABLE todo ADD COLUMN priority INTEGER NOT NULL DEFAULT 0");
  }
  await batch.commit(noResult: true);
}
```

**为什么用 `if (oldVersion < X)` 而不是 `switch`？** 允许用户从 v1 直接跳到 v3（比如很久没更新的用户），每一步 migration 都会依次执行。

**ALTER TABLE 的限制**：

SQLite 的 ALTER 很弱：

- ✅ `ADD COLUMN`
- ✅ `RENAME TO`
- ✅ `RENAME COLUMN`（3.25+）
- ✅ `DROP COLUMN`（3.35+）
- ❌ 修改列类型
- ❌ 添加/删除约束
- ❌ 添加 UNIQUE

想改列类型？**三步走**：

```sql
BEGIN;
CREATE TABLE new_table(...);
INSERT INTO new_table SELECT ... FROM old_table;
DROP TABLE old_table;
ALTER TABLE new_table RENAME TO old_table;
COMMIT;
```

sqflite 里：

```dart
await db.transaction((txn) async {
  await txn.execute('CREATE TABLE todo_new(...)');
  await txn.execute('INSERT INTO todo_new SELECT ... FROM todo');
  await txn.execute('DROP TABLE todo');
  await txn.execute('ALTER TABLE todo_new RENAME TO todo');
});
```

**迁移最佳实践**：

1. **每个 version 只增加**：从不修改历史 migration 代码。
2. **测试迁移**：写单元测试，用旧版本 schema 建库，然后调用 migrate，验证结果。
3. **备份先行**：正式的 migration 操作前，`File(dbPath).copy('$dbPath.bak')`。

## 10.7 CRUD 基础 API

**Insert**：

```dart
final id = await db.insert(
  'todo',
  {
    'title': '学 sqflite',
    'completed': 0,
    'created_at': DateTime.now().toIso8601String(),
  },
  conflictAlgorithm: ConflictAlgorithm.replace,
);
```

`conflictAlgorithm` 处理主键冲突：`replace`/`ignore`/`abort`/`fail`/`rollback`。

**Query**：

```dart
final rows = await db.query(
  'todo',
  columns: ['id', 'title', 'completed'],
  where: 'completed = ? AND category_id = ?',
  whereArgs: [0, categoryId],
  orderBy: 'created_at DESC',
  limit: 20,
  offset: 0,
);
// rows: List<Map<String, Object?>>
```

**Update**：

```dart
final count = await db.update(
  'todo',
  {'completed': 1, 'updated_at': DateTime.now().toIso8601String()},
  where: 'id = ?',
  whereArgs: [id],
);
```

**Delete**：

```dart
final count = await db.delete('todo', where: 'id = ?', whereArgs: [id]);
```

## 10.8 rawQuery vs query

`query` 是封装好的构造器（帮你拼 SQL），`rawQuery` 是让你直接写 SQL：

```dart
// query
await db.query('todo', where: 'completed = ?', whereArgs: [0]);

// rawQuery
await db.rawQuery('SELECT * FROM todo WHERE completed = ?', [0]);
```

**什么时候用 rawQuery？**

- JOIN 多表
- 子查询、CTE
- 聚合、窗口函数
- 用视图

```dart
final rows = await db.rawQuery('''
  WITH stats AS (
    SELECT user_id, COUNT(*) AS cnt FROM post GROUP BY user_id
  )
  SELECT u.name, s.cnt
  FROM user u
  JOIN stats s ON s.user_id = u.id
  WHERE s.cnt > ?
  ORDER BY s.cnt DESC
''', [10]);
```

`rawQuery` 的返回值同样是 `List<Map<String, Object?>>`。

**永远用参数化查询 `?`，不要字符串拼接**——防 SQL 注入。

## 10.9 事务与批量

**Transaction**：

```dart
await db.transaction((txn) async {
  final userId = await txn.insert('user', {'name': 'Alice'});
  await txn.insert('post', {'user_id': userId, 'title': 'hello'});
});
```

事务里必须用 `txn.xxx`，不能用外层 `db.xxx`（会死锁）。任何异常自动 ROLLBACK。

**Batch**（前面章节讲过，这里再强调）：

```dart
final batch = db.batch();
for (final todo in todos) {
  batch.insert('todo', todo.toMap());
}
await batch.commit(noResult: true);
```

`noResult: true` 让 Batch 不返回每条 SQL 的结果，减少内存和序列化开销，插万条时提速非常明显。

**Batch 在事务里**：

```dart
await db.transaction((txn) async {
  final batch = txn.batch();
  batch.insert(...);
  batch.insert(...);
  await batch.commit(noResult: true);
});
```

这就是"事务原子性 + 批量高性能"的组合。

### 10.10.1 Model 层

```dart
// lib/models/todo.dart
class Todo {
  final int? id;
  final String title;
  final String? description;
  final bool completed;
  final int? categoryId;
  final int priority;
  final DateTime createdAt;
  final DateTime? completedAt;

  Todo({
    this.id,
    required this.title,
    this.description,
    this.completed = false,
    this.categoryId,
    this.priority = 0,
    DateTime? createdAt,
    this.completedAt,
  }) : createdAt = createdAt ?? DateTime.now();

  Map<String, Object?> toMap() => {
    if (id != null) 'id': id,
    'title': title,
    'description': description,
    'completed': completed ? 1 : 0,
    'category_id': categoryId,
    'priority': priority,
    'created_at': createdAt.toUtc().toIso8601String(),
    'completed_at': completedAt?.toUtc().toIso8601String(),
  };

  factory Todo.fromMap(Map<String, Object?> m) => Todo(
    id: m['id'] as int?,
    title: m['title'] as String,
    description: m['description'] as String?,
    completed: (m['completed'] as int) == 1,
    categoryId: m['category_id'] as int?,
    priority: m['priority'] as int? ?? 0,
    createdAt: DateTime.parse(m['created_at'] as String).toLocal(),
    completedAt: m['completed_at'] == null
      ? null
      : DateTime.parse(m['completed_at'] as String).toLocal(),
  );

  Todo copyWith({
    int? id, String? title, String? description,
    bool? completed, int? categoryId, int? priority,
    DateTime? createdAt, DateTime? completedAt,
  }) => Todo(
    id: id ?? this.id,
    title: title ?? this.title,
    description: description ?? this.description,
    completed: completed ?? this.completed,
    categoryId: categoryId ?? this.categoryId,
    priority: priority ?? this.priority,
    createdAt: createdAt ?? this.createdAt,
    completedAt: completedAt ?? this.completedAt,
  );
}

class Category {
  final int? id;
  final String name;
  final String? colorHex;

  Category({this.id, required this.name, this.colorHex});

  Map<String, Object?> toMap() => {
    if (id != null) 'id': id,
    'name': name,
    'color_hex': colorHex,
  };

  factory Category.fromMap(Map<String, Object?> m) => Category(
    id: m['id'] as int?,
    name: m['name'] as String,
    colorHex: m['color_hex'] as String?,
  );
}
```

### 10.10.2 数据库管理单例

```dart
// lib/db/app_database.dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart' as p;
import 'package:path_provider/path_provider.dart';

class AppDatabase {
  static final AppDatabase instance = AppDatabase._();
  AppDatabase._();

  Database? _db;

  Future<Database> get database async {
    if (_db != null) return _db!;
    _db = await _open();
    return _db!;
  }

  Future<Database> _open() async {
    final dir = await getApplicationDocumentsDirectory();
    final path = p.join(dir.path, 'todo_app.db');
    return openDatabase(
      path,
      version: 1,
      onConfigure: (db) async {
        await db.execute('PRAGMA foreign_keys = ON');
        await db.execute('PRAGMA journal_mode = WAL');   // 提高并发
      },
      onCreate: (db, v) async {
        await db.execute('''
          CREATE TABLE category(
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL UNIQUE,
            color_hex TEXT
          )
        ''');
        await db.execute('''
          CREATE TABLE todo(
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            description TEXT,
            completed INTEGER NOT NULL DEFAULT 0 CHECK(completed IN (0,1)),
            category_id INTEGER REFERENCES category(id) ON DELETE SET NULL,
            priority INTEGER NOT NULL DEFAULT 0,
            created_at TEXT NOT NULL,
            completed_at TEXT
          )
        ''');
        await db.execute('CREATE INDEX idx_todo_category ON todo(category_id)');
        await db.execute('CREATE INDEX idx_todo_completed ON todo(completed, created_at DESC)');

        // 触发器：completed 变为 1 时自动填 completed_at
        await db.execute('''
          CREATE TRIGGER auto_complete_time
          AFTER UPDATE OF completed ON todo
          WHEN NEW.completed = 1 AND OLD.completed = 0
          BEGIN
            UPDATE todo SET completed_at = datetime('now') WHERE id = NEW.id;
          END
        ''');
      },
    );
  }

  Future<void> close() async {
    await _db?.close();
    _db = null;
  }
}
```

### 10.10.3 DAO 层（Repository 模式）

```dart
// lib/db/todo_dao.dart
class TodoDao {
  final AppDatabase _appDb;
  TodoDao(this._appDb);

  Future<Database> get _db => _appDb.database;

  Future<int> insert(Todo todo) async {
    final db = await _db;
    return db.insert('todo', todo.toMap());
  }

  Future<int> update(Todo todo) async {
    final db = await _db;
    return db.update('todo', todo.toMap(),
      where: 'id = ?', whereArgs: [todo.id]);
  }

  Future<int> delete(int id) async {
    final db = await _db;
    return db.delete('todo', where: 'id = ?', whereArgs: [id]);
  }

  Future<Todo?> findById(int id) async {
    final db = await _db;
    final rows = await db.query('todo', where: 'id = ?', whereArgs: [id]);
    if (rows.isEmpty) return null;
    return Todo.fromMap(rows.first);
  }

  Future<List<Todo>> findAll({
    bool? completed,
    int? categoryId,
    int limit = 50,
    int offset = 0,
  }) async {
    final db = await _db;
    final where = <String>[];
    final args = <Object>[];
    if (completed != null) {
      where.add('completed = ?');
      args.add(completed ? 1 : 0);
    }
    if (categoryId != null) {
      where.add('category_id = ?');
      args.add(categoryId);
    }
    final rows = await db.query(
      'todo',
      where: where.isEmpty ? null : where.join(' AND '),
      whereArgs: args.isEmpty ? null : args,
      orderBy: 'priority DESC, created_at DESC',
      limit: limit,
      offset: offset,
    );
    return rows.map(Todo.fromMap).toList();
  }

  Future<int> countByCategory(int categoryId) async {
    final db = await _db;
    final r = await db.rawQuery(
      'SELECT COUNT(*) AS c FROM todo WHERE category_id = ? AND completed = 0',
      [categoryId],
    );
    return (r.first['c'] as int?) ?? 0;
  }

  Future<void> bulkInsert(List<Todo> todos) async {
    final db = await _db;
    await db.transaction((txn) async {
      final batch = txn.batch();
      for (final t in todos) {
        batch.insert('todo', t.toMap());
      }
      await batch.commit(noResult: true);
    });
  }

  Future<void> toggleCompleted(int id) async {
    final db = await _db;
    await db.transaction((txn) async {
      final rows = await txn.query('todo',
        columns: ['completed'], where: 'id = ?', whereArgs: [id]);
      if (rows.isEmpty) return;
      final current = rows.first['completed'] as int;
      await txn.update('todo',
        {'completed': current == 1 ? 0 : 1},
        where: 'id = ?', whereArgs: [id]);
    });
  }
}
```

### 10.10.4 Service 层（业务逻辑）

```dart
// lib/services/todo_service.dart
class TodoService {
  final TodoDao _dao;
  final CategoryDao _categoryDao;

  TodoService(this._dao, this._categoryDao);

  Future<Todo> createTodo({
    required String title,
    String? description,
    int? categoryId,
    int priority = 0,
  }) async {
    // 业务校验
    if (title.trim().isEmpty) throw ArgumentError('标题不能为空');
    if (categoryId != null) {
      final cat = await _categoryDao.findById(categoryId);
      if (cat == null) throw StateError('分类不存在');
    }
    final todo = Todo(
      title: title.trim(),
      description: description,
      categoryId: categoryId,
      priority: priority,
    );
    final id = await _dao.insert(todo);
    return todo.copyWith(id: id);
  }

  Future<List<Todo>> loadTodos({int? categoryId}) async {
    return _dao.findAll(categoryId: categoryId);
  }

  Future<void> completeTodo(int id) => _dao.toggleCompleted(id);
}
```

## 10.12 sqflite 的常见坑

**坑 1：Database 对象跨 isolate 传递**

sqflite 的 Database 对象**绑定当前 isolate**，传给别的 isolate 用会出错。要么在每个 isolate 独立 `openDatabase`（但注意并发锁问题），要么用 `compute` 时把 SQL 和参数序列化传过去，isolate 里查完把结果传回来。**更好的方案：用 drift**。

**坑 2：主 isolate 上做重查询卡 UI**

sqflite 的所有查询默认在主 isolate 上。10 万行的 SELECT 会让 UI 卡 500ms+。解决方案：

- 分页
- 后台 isolate 处理数据加工
- 换 drift（自带 isolate 支持）

**坑 3：多个 openDatabase**

如果同一路径 openDatabase 多次（`singleInstance: false`），会得到多个 Database 对象，多个连接会互相 BUSY。**默认 `singleInstance: true` 就行，别改**。

**坑 4：conflictAlgorithm 用错**

```dart
await db.insert('user', {'id': 1, 'name': 'x'},
  conflictAlgorithm: ConflictAlgorithm.replace);
```

`REPLACE` 会**先 DELETE 再 INSERT**，触发外键 CASCADE、trigger 等。想 UPSERT 更好的方式是 SQL 层的 `INSERT ... ON CONFLICT ... DO UPDATE`（3.24+）：

```dart
await db.execute('''
  INSERT INTO user(id, name) VALUES (?, ?)
  ON CONFLICT(id) DO UPDATE SET name = excluded.name
''', [1, 'x']);
```

**坑 5：数据库迁移错误没测试**

迁移写错、上线才发现 = 老用户 App 直接崩溃。**每次改 schema 必须写迁移测试**。

**坑 6：忘了关数据库**

严格来说 sqflite 不需要显式关闭（App 退出 OS 会清理），但重启数据库时（比如切换用户）要 `db.close()`。忘了会锁着 WAL 文件不释放。

**坑 7：并发写入 SQLITE_BUSY**

多个操作同时写同一张表可能 BUSY。设置 busy_timeout + WAL 模式 + 应用层重试。

**坑 8：SQL 拼字符串**

```dart
// ❌ 绝对不要这样
await db.rawQuery("SELECT * FROM user WHERE name = '$name'");

// ✅ 参数化
await db.rawQuery("SELECT * FROM user WHERE name = ?", [name]);
```

前者是 SQL 注入教科书案例。参数化不仅安全，还能让 SQLite 复用 prepared statement 缓存，更快。

## 10.13 本章小结

- sqflite = Dart 拼 SQL → MethodChannel → Native SQLite。
- 桌面用 `sqflite_common_ffi`，加密用 `sqflite_sqlcipher`。
- `openDatabase` 三大回调：`onConfigure`（开 FK/WAL）、`onCreate`（首次建表）、`onUpgrade`（增量迁移）。
- 迁移用 `if (oldVersion < N)` 累加式写，每个版本只增加不修改。
- CRUD 用 `query/insert/update/delete`；复杂 SQL 用 `rawQuery`。
- **永远用参数化查询**，永远不要拼字符串。
- 批量插入用 `transaction + batch + noResult: true`。
- 分层结构：Model → DAO → Service → UI。
- 主 isolate 长查询会卡 UI；跨 isolate 传 Database 不行。
- **金句**：sqflite 是"信任你 SQL 功底"的库——功底强就飞，功底弱就翻。
