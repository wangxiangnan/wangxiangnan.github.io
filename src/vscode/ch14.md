# 第14章：自定义代码片段与模板

> 如果编程是一种语言，那代码片段（Snippet）就是你的"快捷短语"——就像手机输入法的联想词库，只不过联想出来的不是"你好吗"，而是一整个函数。

每次写一个新组件都要敲一遍模板代码？每次写 API 路由都要复制粘贴？是时候让这些重复劳动消失了。VSCode 的代码片段系统比你想象的要强大得多——它不仅仅是"文本替换"，而是一套完整的模板引擎。

## Snippet 语法详解

### 基本结构

打开命令面板（`Ctrl+Shift+P` / `⌘+Shift+P`），搜索 `Snippets: Configure Snippets`，你可以选择创建全局片段或语言片段。

一个 Snippet 的 JSON 结构如下：

```json
{
  "Print to console": {
    "prefix": "clg",
    "body": [
      "console.log('$1');",
      "$2"
    ],
    "description": "Log output to console"
  }
}
```

三个字段各有职责：

| 字段 | 作用 | 示例 |
| ------ | ------ | ------ |
| `prefix` | 触发片段的关键词 | `clg` — 输入 clg 按 Tab 触发 |
| `body` | 展开后的代码内容（数组，每行一个字符串） | `["console.log('$1');", "$2"]` |
| `description` | 片段描述，在建议列表中显示 | `"Log output to console"` |

### 多前缀触发

`prefix` 可以是字符串，也可以是数组：

```json
{
  "React Functional Component": {
    "prefix": ["rfc", "rfcomponent", "function-component"],
    "body": [
      "import React from 'react';",
      "",
      "interface ${1:ComponentName}Props {",
      "  $2",
      "}",
      "",
      "const ${1:ComponentName}: React.FC<${1:ComponentName}Props> = ({$3}) => {",
      "  return (",
      "    <div>",
      "      $0",
      "    </div>",
      "  );",
      "};",
      "",
      "export default ${1:ComponentName};"
    ],
    "description": "React functional component with TypeScript props interface"
  }
}
```

输入 `rfc`、`rfcomponent` 或 `function-component` 中的任何一个，都能触发这个片段。

## 占位符和变量：Snippet 的魔法

### 基本占位符

```
$1       → 第一个 Tab 停点
$2       → 第二个 Tab 停点
$0       → 最终光标位置（按完所有 Tab 停后光标所在位置）
${1:default}  → 带默认值的占位符
```

**Tab 顺序示例：**

```json
{
  "For loop": {
    "prefix": "fori",
    "body": [
      "for (let ${1:i} = 0; ${1:i} < ${2:length}; ${1:i}++) {",
      "  $0",
      "}"
    ],
    "description": "For loop with index"
  }
}
```

注意 `${1:i}` 出现了三次——它们会同步更新。你在第一个位置把 `i` 改成 `index`，其他两处也会变成 `index`。

### 同名占位符的镜像

```json
{
  "CSS class with variable": {
    "prefix": "cssvar",
    "body": [
      ".${1:className} {",
      "  ${2:property}: ${3:value};",
      "}",
      "",
      "// Usage: <div className=\"${1:className}\">"
    ]
  }
}
```

输入 `cssvar` 展开后，当你编辑第一个 `className` 时，注释中的 `className` 也会同步变化。这就是"镜像"——同一编号的所有占位符保持同步。

### 带选项的占位符（Choice）

让使用者在一组预定义值中选择：

```json
{
  "HTTP Method Route": {
    "prefix": "route",
    "body": [
      "router.${1|get,post,put,delete,patch|}('${2:/api/resource}', ${3:handler});"
    ],
    "description": "Express route with HTTP method selection"
  }
}
```

触发后，第一个 Tab 停会弹出下拉菜单，让你在 `get`、`post`、`put`、`delete`、`patch` 中选择。

### 正则转换（Transform）：Snippet 的终极武器

这是 Snippet 语法中最强大（也最复杂）的部分。格式为：

```
${变量/正则/替换格式/选项}
```

**示例 1：文件名转类名**

```json
{
  "React component from filename": {
    "prefix": "rfcn",
    "body": [
      "import React from 'react';",
      "",
      "const ${TM_FILENAME_BASE/(.*)/${1:/capitalize}/} = () => {",
      "  return (",
      "    <div>$0</div>",
      "  );",
      "};",
      "",
      "export default ${TM_FILENAME_BASE/(.*)/${1:/capitalize}/};"
    ],
    "description": "React component with name derived from filename"
  }
}
```

如果你正在编辑 `userProfile.tsx`，`${TM_FILENAME_BASE/(.*)/${1:/capitalize}/}` 会自动转换为 `UserProfile`。

**示例 2：驼峰转 kebab-case**

```json
{
  "Convert camelCase to kebab": {
    "prefix": "kebab",
    "body": "${CLIPBOARD/([A-Z])/-${1:/downcase}/g}"
  }
}
```

如果剪贴板内容是 `myComponentName`，展开后会变成 `my-component-name`。

## 内置变量大全

VSCode 提供了丰富的内置变量，让你的 Snippet 能够感知当前编辑环境：

```
// 文件相关
${TM_FILENAME}          → 当前文件名（含扩展名），如 "index.tsx"
${TM_FILENAME_BASE}     → 当前文件名（不含扩展名），如 "index"
${TM_DIRECTORY}         → 当前文件所在目录
${TM_FILEPATH}          → 当前文件完整路径
${RELATIVE_FILEPATH}    → 相对于工作区的路径

// 选择相关
${TM_SELECTED_TEXT}     → 当前选中的文本
${TM_CURRENT_LINE}      → 当前行内容
${TM_CURRENT_WORD}      → 光标所在单词

// 日期时间
${CURRENT_YEAR}         → 2025
${CURRENT_YEAR_SHORT}   → 25
${CURRENT_MONTH}        → 03
${CURRENT_DATE}         → 15
${CURRENT_HOUR}         → 14
${CURRENT_MINUTE}       → 30
${CURRENT_SECOND}       → 45
${CURRENT_SECONDS_UNIX} → Unix 时间戳

// 其他
${CLIPBOARD}            → 剪贴板内容
${WORKSPACE_NAME}       → 工作区名称
${WORKSPACE_FOLDER}     → 工作区路径
${LINE_INDEX}           → 当前行索引（0-based）
${LINE_NUMBER}          → 当前行号（1-based）
${CURSOR_INDEX}         → 光标位置索引
${CURSOR_NUMBER}        → 光标位置编号
${RANDOM}               → 6位随机数
${RANDOM_HEX}           → 6位随机十六进制数
${UUID}                 → UUID（如 a1b2c3d4-e5f6-7890）
```

### 使用内置变量的实战示例

```json
{
  "File Header Comment": {
    "prefix": "header",
    "body": [
      "/**",
      " * @file ${TM_FILENAME}",
      " * @description $1",
      " * @author $2",
      " * @created ${CURRENT_YEAR}-${CURRENT_MONTH}-${CURRENT_DATE}",
      " * @copyright (c) ${CURRENT_YEAR} $2. All rights reserved.",
      " */",
      "$0"
    ],
    "description": "File header with auto date and filename"
  },
  "Console log with context": {
    "prefix": "clog",
    "body": [
      "console.log('[${TM_FILENAME}:${LINE_NUMBER}] ${1:message}:', ${2:variable});"
    ],
    "description": "Console log with filename and line number context"
  }
}
```

展开 `header` 会自动生成：

```javascript
/**
 * @file userService.ts
 * @description [你输入的描述]
 * @author [你输入的作者名]
 * @created 2025-03-15
 * @copyright (c) 2025 [你输入的作者名]. All rights reserved.
 */
```

## 全局片段 vs 项目片段 vs 语言片段

VSCode 有三种级别的 Snippet：

| 类型 | 位置 | 适用范围 |
| ------ | ------ | ---------- |
| **全局片段** | `~/.config/Code/User/snippets/global.code-snippets` | 所有项目、所有语言 |
| **语言片段** | `~/.config/Code/User/snippets/typescript.json` | 所有项目中的特定语言文件 |
| **项目片段** | `.vscode/snippets/*.code-snippets` | 当前工作区 |

### 全局片段

适合存放你在任何项目中都会用的个人常用片段：

```json
{
  "Quick debug log": {
    "prefix": "dl",
    "body": "console.log('🔍 ${1:debug}:', ${2:variable});",
    "scope": "javascript,typescript,javascriptreact,typescriptreact",
    "description": "Quick debug log with emoji prefix"
  }
}
```

注意 `scope` 字段——即使在全局片段文件中，你也可以通过 `scope` 限制片段只在特定语言中生效。

### 项目片段

放在 `.vscode/snippets/` 目录下，随项目一起提交到 Git：

```
.vscode/
  snippets/
    react.code-snippets
    api.code-snippets
    tests.code-snippets
```

**`.vscode/snippets/react.code-snippets`：**

```json
{
  "React Hook useState": {
    "prefix": "us",
    "body": [
      "const [${1:state}, set${1/(.*)/${1:/capitalize}/}] = useState<${2:type}>(${3:initialValue});"
    ],
    "description": "useState hook with auto-capitalized setter"
  },
  "React Hook useEffect": {
    "prefix": "ue",
    "body": [
      "useEffect(() => {",
      "  $1",
      "",
      "  return () => {",
      "    $2",
      "  };",
      "}, [${3:dependencies}]);"
    ],
    "description": "useEffect hook with cleanup"
  },
  "React Custom Hook": {
    "prefix": "uch",
    "body": [
      "import { useState, useEffect } from 'react';",
      "",
      "export function use${1:HookName}(${2:params}) {",
      "  const [${3:state}, set${3/(.*)/${3:/capitalize}/}] = useState<${4:type}>(${5:initial});",
      "",
      "  useEffect(() => {",
      "    $6",
      "  }, []);",
      "",
      "  return { ${3:state} };",
      "}"
    ],
    "description": "Custom React hook template"
  }
}
```

## 实用片段示例

### Express 路由模板

```json
{
  "Express CRUD Routes": {
    "prefix": "crudroutes",
    "body": [
      "const express = require('express');",
      "const router = express.Router();",
      "const ${1:resource}Controller = require('../controllers/${1:resource}Controller');",
      "",
      "// GET /${2:api/${1:resource}}",
      "router.get('/', ${1:resource}Controller.getAll);",
      "",
      "// GET /${2:api/${1:resource}}/:id",
      "router.get('/:id', ${1:resource}Controller.getById);",
      "",
      "// POST /${2:api/${1:resource}}",
      "router.post('/', ${1:resource}Controller.create);",
      "",
      "// PUT /${2:api/${1:resource}}/:id",
      "router.put('/:id', ${1:resource}Controller.update);",
      "",
      "// DELETE /${2:api/${1:resource}}/:id",
      "router.delete('/:id', ${1:resource}Controller.remove);",
      "",
      "module.exports = router;"
    ],
    "description": "Express CRUD routes boilerplate"
  }
}
```

## 实战：创建一套个人代码片段库

让我们创建一个完整的个人 Snippet 库。

### 步骤 1：规划片段结构

```
~/.config/Code/User/snippets/     (Linux/macOS)
%APPDATA%\Code\User\snippets\     (Windows)
├── global.code-snippets     # 全局通用片段
├── javascript.code-snippets # JS 专用
├── typescript.code-snippets # TS 专用
├── react.code-snippets      # React 专用
└── markdown.code-snippets   # Markdown 写作专用
```

### 步骤 2：创建 `global.code-snippets`

```json
{
  "Log with separator": {
    "prefix": "logsep",
    "body": [
      "console.log('='.repeat(50));",
      "console.log('${1:message}');",
      "console.log('='.repeat(50));"
    ],
    "description": "Console log with visual separator"
  },
  "Try-Catch with logging": {
    "prefix": "trylog",
    "body": [
      "try {",
      "  $1",
      "} catch (${2:error}) {",
      "  console.error('[${TM_FILENAME}] Error:', ${2:error});",
      "  $3",
      "}"
    ],
    "description": "Try-catch block with error logging"
  },
  "Performance timer": {
    "prefix": "timer",
    "body": [
      "console.time('${1:operation}');",
      "$2",
      "console.timeEnd('${1:operation}');"
    ],
    "description": "Console time measurement"
  },
  "Section comment": {
    "prefix": "section",
    "body": [
      "// ${1:=}".repeat(1)",
      "// ${2:Section Title}",
      "// ${1:=}".repeat(1)",
      "$0"
    ],
    "description": "Section divider comment"
  },
  "Quick TODO": {
    "prefix": "todo",
    "body": "// TODO(${CURRENT_YEAR}-${CURRENT_MONTH}-${CURRENT_DATE}): $1",
    "description": "TODO comment with auto date"
  }
}
```

### 步骤 3：创建 `typescript.code-snippets`

```json
{
  "TypeScript Interface": {
    "prefix": "iface",
    "body": [
      "export interface ${1:IName} {",
      "  ${2:property}: ${3:type};",
      "}"
    ],
    "description": "Export TypeScript interface"
  },
  "TypeScript Type Alias": {
    "prefix": "talias",
    "body": [
      "export type ${1:TypeName} = ${2:type};"
    ],
    "description": "Export type alias"
  },
  "Async function with return type": {
    "prefix": "afn",
    "body": [
      "export async function ${1:functionName}(${2:params}): Promise<${3:ReturnType}> {",
      "  $0",
      "}"
    ],
    "description": "Async function with explicit return type"
  },
  "Enum": {
    "prefix": "enum",
    "body": [
      "export enum ${1:EnumName} {",
      "  ${2:Member} = '${3:value}',",
      "}"
    ],
    "description": "String enum"
  },
  "Generic Function": {
    "prefix": "gfn",
    "body": [
      "function ${1:name}<${2:T}>(${3:arg}: ${2:T}): ${2:T} {",
      "  $0",
      "}"
    ],
    "description": "Generic function"
  }
}
```

### 步骤 4：验证和使用

1. 保存文件后，片段立即可用（无需重启 VSCode）
2. 在对应语言的编辑器中输入 `prefix`，按 Tab 触发
3. 如果片段没有出现在建议列表中，按 `Ctrl+Space`（`⌘+Space`）手动触发 IntelliSense

> **小技巧：** 在 `settings.json` 中设置 `"editor.snippetSuggestions": "top"` 可以让代码片段在建议列表中优先显示。

## 进阶：用扩展 API 提供动态 Snippet

到目前为止，我们的 Snippet 都是静态的——它们在 JSON 文件中定义好，展开结果就是确定的。但如果你需要**动态生成**内容呢？比如根据当前 Git 分支名生成环境变量，或者从远程 API 拉取数据填充模板？

这就需要 VSCode 扩展 API 中的 `CompletionItemProvider` 了：

```typescript
// extension.ts（概念代码，不需要立即实现）
import * as vscode from 'vscode';

export function activate(context: vscode.ExtensionContext) {
  const provider: vscode.CompletionItemProvider = {
    provideCompletionItems(document, position) {
      const snippet = new vscode.CompletionItem('dyncomp', 
        vscode.CompletionItemKind.Snippet);
      
      // 动态生成片段内容
      const gitBranch = getGitBranch(); // 你的自定义函数
      snippet.insertText = new vscode.SnippetString(
        `// Component for branch: ${gitBranch}\n` +
        `const Component = () => {\n` +
        `  const branch = '${gitBranch}';\n` +
        `  $0\n` +
        `};`
      );
      
      return [snippet];
    }
  };

  context.subscriptions.push(
    vscode.languages.registerCompletionItemProvider(
      { scheme: 'file', language: 'typescript' },
      provider,
      '.'
    )
  );
}
```

这就是 AI 辅助编程插件（如 Copilot）和各类智能补全插件的底层原理——它们本质上都是 `CompletionItemProvider` 的实现。

**推荐了解的扩展：**

- **Snippet Generator**（`wenfangdu.snippet-generator`）：一个可视化工具，帮你生成 Snippet JSON，省去手写转义的麻烦
- **VSCode 扩展开发文档**：如果你想开发自己的 Snippet 扩展，从 [Extension API](https://code.visualstudio.com/api) 入手

---

📋 **本章小结**

- Snippet 由 `prefix`（触发词）、`body`（内容）和 `description`（描述）组成
- 占位符 `$1`、`${1:default}` 支持 Tab 跳转和默认值，同名占位符会同步更新
- 选项占位符 `${1|a,b,c|}` 提供下拉选择，正则转换 `${var/regex/format/g}` 实现文本变换
- 内置变量（如 `TM_FILENAME`、`CURRENT_YEAR`）让 Snippet 感知编辑环境
- 全局片段放个人通用模板，项目片段放团队共享模板，语言片段放特定语言的模板
- 高级场景可以用扩展 API 实现动态 Snippet
