# 第 9 章 字符串深入

在上一章，你学会了用模块和包来组织代码。现在让我们回到 Python 中最常用的数据类型之一——字符串。你可能觉得字符串没什么好讲的，不就是用引号包起来的文字嘛。

但字符串的世界比你想象的丰富得多。想象你是一个厨师，字符串就是你的食材。切丝、切丁、腌制、翻炒——同样的食材，不同的加工方式，出来的菜品完全不同。这一章，我们就来掌握 Python 字符串的各种"烹饪技巧"：从格式化输出到文本处理，从字符编码到正则表达式，让你真正驾驭字符串。

## 9.1 字符串基础回顾

先快速回顾你已经知道的：

```python
# 创建字符串
s1 = "Hello"
s2 = 'World'
s3 = """这是
多行
字符串"""
s4 = r"C:\new\test"  # 原始字符串，\不会被转义

# 基本操作
print(len("Hello"))         # 5，长度
print("Hello" + " World")   # Hello World，拼接
print("Hi" * 3)             # HiHiHi，重复
print("World"[1])           # o，索引

print("xyz" not in "Hello") # True
```

这些都是基础操作。接下来的内容会让你看到字符串更多面的能力。

## 9.2 常用字符串方法

Python 的字符串对象自带了几十个实用方法。下面挑最常用的讲。

### 9.2.1 查找与替换

```python
text = "Python is awesome, Python is fun, Python is the best"

# find：返回子串首次出现的索引，找不到返回 -1
print(text.find("Python"))      # 0
print(text.find("Java"))        # -1

# count：统计子串出现次数
print(text.count("Python"))     # 3

# replace：替换子串
print(text.replace("Python", "Java"))
# Java is awesome, Java is fun, Java is the best

# startswith / endswith：前缀/后缀检测
filename = "report_2024.pdf"
print(filename.startswith("report"))  # True
print(filename.endswith(".pdf"))      # True
```

### 9.2.2 大小写与空白处理

```python
# 大小转换
print("hello world".upper())        # HELLO WORLD
print("HELLO WORLD".lower())        # hello world
print("hello world".title())        # Hello World
print("hello world".capitalize())   # Hello world
print("Hello World".swapcase())     # hELLO wORLD

# 去除空白
messy = "  \t  Hello World  \n  "
print(messy.strip())    # "Hello World"（去两端空白）
print(messy.lstrip())   # "Hello World  \n  "（去左边）
print(messy.rstrip())   # "  \t  Hello World"（去右边）
```

### 9.2.3 拆分与拼接

```python
# split：按分隔符拆分成列表
csv_line = "Alice,25,Engineer,Beijing"
parts = csv_line.split(",")
print(parts)  # ['Alice', '25', 'Engineer', 'Beijing']

# 按空白拆分（默认行为，很智能）
sentence = "Python   is  a great\tlanguage"
words = sentence.split()  # 自动处理多个空白
print(words)  # ['Python', 'is', 'a', 'great', 'language']

# join：用指定分隔符把列表拼成字符串（split 的反操作）
words = ["Python", "is", "awesome"]
result = " ".join(words)
print(result)  # "Python is awesome"

# 用换行符拼接
lines = ["第一行", "第二行", "第三行"]
print("\n".join(lines))
# 第一行
# 第二行
# 第三行

# 路径拼接（也可以用 os.path.join 或 pathlib）
parts = ["usr", "local", "bin"]
path = "/".join(parts)
print(path)  # usr/local/bin
```

### 9.2.4 判断类方法

```python
# 各种"是不是"的判断
print("12345".isdigit())       # True，全是数字
print("12.5".isdigit())        # False，有小数点

print("Hello123".isalnum())    # True，字母+数字
print("  ".isspace())          # True，全是空白
print("Hello World".istitle()) # True，每个单词首字母大写
```

这些方法在做输入验证时特别有用：

def get_valid_age():

## 9.3 f-string：字符串格式化的终极方案

Python 有多种格式化方式（`%` 格式化、`.format()` 方法、f-string），但 **f-string 是目前最推荐的写法**——它简洁、可读、性能也好。

### 9.3.1 基础用法

```python
name = "小明"
age = 25
city = "北京"

# f-string 的基本语法：f"..."，花括号内放表达式
print(f"我叫{name}，今年{age}岁，来自{city}")
# 我叫小明，今年25岁，来自北京

# 花括号内可以放任意 Python 表达式
print(f"2 + 3 = {2 + 3}")
print(f"{'hello'.upper()}")
print(f"圆周率前5位：{3.14159265:.4f}")
```

### 9.3.2 格式控制

f-string 的格式控制非常强大：

```python
price = 1234567.891

# 数字格式化
print(f"价格：{price:.2f}")        # 价格：1234567.89
print(f"价格：{price:,.2f}")       # 价格：1,234,567.89（千位分隔符）
print(f"百分比：{0.856:.1%}")      # 百分比：85.6%
print(f"科学计数法：{price:.2e}")   # 科学计数法：1.23e+06

# 对齐与宽度
for item, price in [("苹果", 5), ("香蕉", 12), ("榴莲", 88)]:
    print(f"{item:<6} ¥{price:>6.2f}")
# 苹果     ¥  5.00
# 香蕉     ¥ 12.00
# 榴莲     ¥ 88.00

# 进制转换
num = 255
print(f"十进制：{num}")       # 255
print(f"十六进制：{num:#x}")  # 0xff
print(f"八进制：{num:#o}")    # 0o377
print(f"二进制：{num:#b}")    # 0b11111111

# 日期格式化
from datetime import datetime
now = datetime.now()
print(f"现在是 {now:%Y年%m月%d日 %H:%M:%S}")
# 现在是 2024年01月15日 14:30:00
```

### 9.3.3 f-string 进阶技巧

```python
# = 号：同时显示表达式和结果（调试利器！）
x = 10
y = 20
print(f"{x + y = }")      # x + y = 30
print(f"{x * y = }")      # x * y = 200
print(f"{len('hello') = }")  # len('hello') = 5

# 嵌套 f-string（不常用，但可以实现动态格式）
width = 20
align = "^"
text = "Python"
print(f"{text:{align}{width}}")  # =======Python=======

# 在 f-string 中使用字典
person = {"name": "小红", "age": 22}
# 注意：如果外层用双引号，字典键要用单引号
print(f"{person['name']}今年{person['age']}岁")

# 条件表达式
score = 85
print(f"成绩：{'及格' if score >= 60 else '不及格'}")  # 成绩：及格
```

### 9.3.4 为什么选 f-string

| 方式 | 示例 | 特点 |
| ------ | ------ | ------ |
| `%` 格式化 | `"Hello %s" % name` | 老旧，容易出错，不推荐 |
| `.format()` | `"Hello {}".format(name)` | 功能强但语法冗长 |
| f-string | `f"Hello {name}"` | 简洁直观，Python 3.6+ |

f-string 在运行时求值，性能比 `.format()` 更好，而且代码一目了然。除非你需要兼容 Python 3.5 以下版本，否则一律用 f-string。

## 9.4 字符编码：Unicode 与 UTF-8

你有没有遇到过这种情况：打开一个文件，里面全是乱码——`ä½ å¥½`、`\u4f60\u597d`、`锟斤拷`？这些都是编码问题。

### 9.4.1 什么是编码

计算机只认识数字（0 和 1），所以每个字符都必须对应一个数字。**编码（encoding）就是字符与数字之间的映射规则**。

- **ASCII**：最早的编码标准，用 1 个字节表示 128 个字符（英文字母、数字、标点）
- **GBK / GB2312**：中文编码标准，用 2 个字节表示汉字
- **Unicode**：统一编码标准，给世界上每个字符分配一个唯一的编号（code point）
- **UTF-8**：Unicode 的一种实现方式，用 1-4 个字节表示一个字符，英文 1 字节，中文通常 3 字节

**关键结论：Python 3 的字符串是 Unicode 字符串，内部用 Unicode 表示所有字符。** 你在 Python 中写的 `"你好"` 在内存中就是 Unicode，不需要关心底层用什么字节表示。只有在存储到文件或通过网络传输时，才需要编码成字节。

### 9.4.2 编码与解码

```python
# 字符串 -> 字节：encode（编码）
text = "你好世界"
utf8_bytes = text.encode("utf-8")
print(utf8_bytes)          # b'\xe4\xbd\xa0\xe5\xa5\xbd\xe4\xb8\x96\xe7\x95\x8c'
print(len(utf8_bytes))     # 12（每个汉字 3 字节，共 4 个字）

gbk_bytes = text.encode("gbk")
print(gbk_bytes)           # b'\xc4\xe3\xba\xc3\xca\xc0\xbd\xe7'
print(len(gbk_bytes))      # 8（每个汉字 2 字节，共 4 个字）

# 字节 -> 字符串：decode（解码）
decoded = utf8_bytes.decode("utf-8")
print(decoded)             # 你好世界
print(decoded == text)     # True
```

记住这个口诀：**encode 是打包（字符串->字节），decode 是拆包（字节->字符串）**。用什么编码打包，就要用什么编码拆包，否则就会乱码。

```python
# 常见错误：编码和解码不匹配
utf8_bytes = "你好".encode("utf-8")
# 用 gbk 去解 utf-8 的字节会报错
# utf8_bytes.decode("gbk")  # UnicodeDecodeError!
```

### 9.4.3 Unicode 转义

```python
# \u 后跟 4 位十六进制，表示一个 Unicode 字符
print("\u4f60\u597d")     # 你好
print("\u0041")           # A

# \U 后跟 8 位十六进制（用于超出基本平面的字符）
print("\U0001F600")       # (emoji grinning face)

# 用 ord() 获取字符的 Unicode 编号
print(ord("A"))           # 65
print(ord("你"))          # 20320
print(ord("\U0001F600"))  # 128512

# 用 chr() 把编号转回字符
print(chr(65))            # A
print(chr(20320))         # 你
```

### 9.4.4 处理编码错误的策略

```python
# 当你不确定文件编码时，可以用 errors 参数容错
text = "Hello 你好 World"

# strict（默认）：遇到无法编码的字符就报错
# text.encode("ascii")  # UnicodeEncodeError!

# ignore：忽略无法编码的字符
print(text.encode("ascii", errors="ignore"))  # b'Hello  World'

# replace：用 ? 替换无法编码的字符
print(text.encode("ascii", errors="replace"))  # b'Hello ?? World'

# xmlcharrefreplace：用 XML 实体替换
print(text.encode("ascii", errors="xmlcharrefreplace"))
# b'Hello &#20320;&#22909; World'
```

## 9.5 正则表达式入门

字符串方法（`find`、`replace`、`split`）处理的是固定模式。但如果你想找"所有手机号"、"所有邮箱地址"、"符合某种格式的日期"——这些没有固定的字符串，只有固定的**格式**——就需要**正则表达式**（Regular Expression，简称 regex）。

正则表达式就像一种"文本搜索的公式"，你用一套特殊语法来描述文本的模式。

### 9.5.1 re 模块基础

Python 用内置的 `re` 模块来处理正则表达式：

```python
import re

text = "我的邮箱是 alice@example.com，电话是 13812345678"

# re.search：搜索第一个匹配
match = re.search(r"[\w.]+@[\w.]+", text)
if match:
    print(f"找到邮箱：{match.group()}")  # alice@example.com

# re.findall：找到所有匹配
numbers = re.findall(r"\d+", text)
print(numbers)  # ['13812345678']
```

### 9.5.2 常用正则语法

```python
import re

# . 匹配任意一个字符（除换行符外）
print(re.findall(r"ca.e", "cake cafe care"))  # ['cake', 'care']

# \d 匹配数字，\D 匹配非数字
print(re.findall(r"\d{3,4}", "区号010，邮编100000"))  # ['010', '10000']

# \w 匹配字母、数字、下划线，\W 匹配非字母数字
print(re.findall(r"\w+", "hello_world 你好 test123"))
# ['hello_world', '你', 'test123']  注意：\w 也匹配中文

# \s 匹配空白字符（空格、Tab、换行）
print(re.findall(r"\S+", "hello  world\tPython"))  # ['hello', 'world', 'Python']

# ^ 匹配字符串开头，$ 匹配字符串结尾
print(re.findall(r"^Hello", "Hello World"))  # ['Hello']
print(re.findall(r"World$", "Hello World"))  # ['World']

# [] 字符集合
print(re.findall(r"[aeiou]", "Hello World"))  # ['e', 'o', 'o']
print(re.findall(r"[0-9A-F]+", "FF00CC"))     # ['FF00CC']

# | 或者
print(re.findall(r"cat|dog", "I have a cat and a dog"))  # ['cat', 'dog']

# () 分组
pattern = r"(\d{4})-(\d{2})-(\d{2})"
match = re.search(pattern, "今天是 2024-01-15")
if match:
    print(f"年：{match.group(1)}")  # 2024
    print(f"月：{match.group(2)}")  # 01
    print(f"日：{match.group(3)}")  # 15
    print(f"完整日期：{match.group(0)}")  # 2024-01-15

# {n,m} 量词：匹配 n 到 m 次
print(re.findall(r"\d{2,4}", "a1b23c456d7890"))  # ['23', '456', '7890']

# * 零次或多次，+ 一次或多次，? 零次或一次
print(re.findall(r"ab*c", "ac abc abbc abbbc"))  # ['ac', 'abc', 'abbc', 'abbbc']
print(re.findall(r"ab+c", "ac abc abbc abbbc"))  # ['abc', 'abbc', 'abbbc']
print(re.findall(r"ab?c", "ac abc abbc"))         # ['ac', 'abc']
```

### 9.5.3 re 模块常用函数

```python
import re

text = "价格：100元，折扣价：80元，会员价：60元"

# re.search：找第一个匹配
match = re.search(r"\d+元", text)
print(match.group())   # 100元

# re.findall：找所有匹配
prices = re.findall(r"\d+元", text)
print(prices)          # ['100元', '80元', '60元']

# re.sub：替换
result = re.sub(r"\d+", "XX", text)
print(result)          # 价格：XX元，折扣价：XX元，会员价：XX元

# re.split：按正则拆分
parts = re.split(r"[，,]", "苹果，香蕉,橘子，西瓜")
print(parts)           # ['苹果', '香蕉', '橘子', '西瓜']

# re.match：从字符串开头匹配（等价于在 pattern 前加 ^）
print(re.match(r"\d+", "123abc"))   # 匹配成功
print(re.match(r"\d+", "abc123"))   # None（不是从开头）
```

### 9.5.4 分组与命名分组

```python
import re

# 命名分组：(?P<name>pattern)
pattern = r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})"
match = re.search(pattern, "日期：2024-01-15")

if match:
    print(match.group("year"))    # 2024
    print(match.group("month"))   # 01
    print(match.group("day"))     # 15
    print(match.groupdict())      # {'year': '2024', 'month': '01', 'day': '15'}

# 用分组做格式化替换
text = "2024-01-15"
# 把 YYYY-MM-DD 转成 DD/MM/YYYY
result = re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", text)
print(result)  # 15/01/2024
```

### 9.5.5 编译正则表达式

如果你需要对同一文本反复使用同一个正则，可以先编译它，提高效率：

```python
import re

# 编译正则表达式（一次编译，多次使用）
email_pattern = re.compile(r"[\w.+-]+@[\w-]+\.[\w.]+")

texts = [
    "联系我：alice@gmail.com",
    "客服邮箱：support@example.com",
    "没有邮箱的一段文字",
]

for text in texts:
    match = email_pattern.search(text)
    if match:
        print(f"找到：{match.group()}")
    else:
        print(f"未找到邮箱")
```

### 9.5.6 实战示例

```python
import re

# 示例1：提取网页中的所有链接
html = '''
<a href="https://www.python.org">Python</a>
<a href="https://github.com">GitHub</a>
<a href="https://stackoverflow.com">Stack Overflow</a>

# ['https://www.python.org', 'https://github.com', 'https://stackoverflow.com']

# 示例2：验证手机号格式（简单版）
def is_valid_phone(phone):
    """验证中国大陆手机号（简单版）"""
    pattern = r"^1[3-9]\d{9}$"
    return bool(re.match(pattern, phone))

print(is_valid_phone("13812345678"))  # True
print(is_valid_phone("12345"))        # False
print(is_valid_phone("138123456789")) # False（多了1位）

# 示例3：文本清理
messy_text = "   Hello   World!!!   This  is   Python...   "
# 把多个空白替换成单个空格，去掉首尾空白
clean = re.sub(r"\s+", " ", messy_text).strip()
print(clean)  # "Hello World!!! This is Python..."
```

## 9.6 小结

- 字符串拥有几十个内置方法，涵盖查找、替换、拆分、拼接、大小写转换、判断等功能
- **f-string** 是目前最推荐的格式化方式：简洁、直观、功能强大，别忘了 `=` 调试技巧
- Python 3 的字符串是 Unicode 字符串；`encode()` 把字符串变成字节，`decode()` 把字节变回字符串
- **正则表达式**用特殊语法描述文本模式，`re` 模块提供了 `search`、`findall`、`sub`、`split` 等函数
- 编译正则表达式 `re.compile()` 可以在反复使用时提高效率
- 正则很强大但不是万能的：简单任务用字符串方法就够，复杂验证才用正则

**第 1 题：**

```python
import re

def clean_text(text):
    """清理文本：去首尾空白、合并多余空白、单词首字母大写"""
    text = text.strip()
    text = re.sub(r"\s+", " ", text)
    text = text.title()
    return text

print(clean_text("   hello   world   python   "))
# "Hello World Python"
```

**第 7 题：**

```python
def caesar_encrypt(text, shift=3):
    """凯撒加密：字母后移 shift 位"""
    result = []
    for char in text:
        if char.isalpha():
            base = ord("A") if char.isupper() else ord("a")
            new_char = chr((ord(char) - base + shift) % 26 + base)
            result.append(new_char)
        else:
            result.append(char)
    return "".join(result)

def caesar_decrypt(text, shift=3):
    """凯撒解密"""
    return caesar_encrypt(text, -shift)

encrypted = caesar_encrypt("Hello World! Python")
print(encrypted)  # Khoor Zruog! Sbwkrq

decrypted = caesar_decrypt(encrypted)
print(decrypted)  # Hello World! Python
```

## 9.9 常见错误与避坑

**1. 混淆 str 和 bytes**

```python
# 字符串和字节是两种不同类型，不能混用
text = "你好"
data = b"hello"

# 错误做法：直接拼接
# text + data  # TypeError!

# 正确做法：统一类型
print(text + data.decode("utf-8"))    # 都转成字符串
print(text.encode("utf-8") + data)    # 都转成字节
```

**2. 正则表达式忘记用原始字符串**

```python
# 错误：\n 会被 Python 解释为换行符，而不是正则的"匹配 n"
# re.search("\name", "my name is Alice")  # 可能不是你想要的

# 正确：正则表达式一律用 r"" 原始字符串
re.search(r"\name", "my name is Alice")
```

**3. f-string 中忘记处理引号冲突**

```python
d = {"key": "value"}
# 如果 f-string 外层用双引号，字典键要用单引号
print(f"{d['key']}")  # 正确
# print(f"{d["key"]}")  # SyntaxError!
```

**4. 用 `is` 比较字符串**

```python
a = "hello"
b = "hel" + "lo"
print(a == b)  # True（值相等）
# print(a is b)  # 可能是 True，也可能是 False，取决于 Python 的内部优化

# 字符串比较永远用 ==，不要用 is
# is 比较的是身份（内存地址），不是值
```

**5. 正则表达式过度使用**

简单的字符串操作用字符串方法就够了，不要一上来就写正则：

```python
text = "Hello World"

# 杀鸡用牛刀
import re
result = re.sub(r"World", "Python", text)  # 太夸张了

# 简单直接
result = text.replace("World", "Python")   # 这才是正解
```

**6. 文件读写时忘记指定编码**

```python
# 危险：在不同操作系统上默认编码可能不同
# open("data.txt", "w")

# 安全：始终明确指定编码
# open("data.txt", "w", encoding="utf-8")
```
