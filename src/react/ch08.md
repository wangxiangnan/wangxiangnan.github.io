# 第8章：表单处理 — 受控组件的艺术

![第8章封面](./images/ch08.png)

## 8.1 引言：表单——Web 开发中绕不开的"老伙计"

如果你打开世界上任何一个网站，几乎都能看到表单的身影：登录框、搜索框、注册页、评论区、购物车结算……表单是用户和网站"对话"的最主要方式。

在前面的章节中，你已经学会了用 `useState` 管理状态。处理表单，本质上就是：**把用户在输入框里输入的内容，同步到 React 的 state 中**。

React 为表单处理提供了一种独特的模式——**受控组件（Controlled Components）**。这跟传统的 HTML 表单处理方式不太一样，一开始可能会有点别扭，但一旦掌握了，你会发现它非常强大和可靠。

> **比喻**：受控组件就像一个乖宝宝——输入框的值完全听 React（state）的话，React 说什么值就是什么值。用户输入 → 触发 onChange → 更新 state → state 的新值传回给输入框。一切都在 React 的掌控之中。

---

## 8.2 受控组件 vs 非受控组件

在 React 中，表单元素有两种处理方式：

### 非受控组件（Uncontrolled）

表单数据由 DOM 自己管理，React 不管。就像放养的孩子——自己想干嘛干嘛。

```jsx
// 非受控组件：用 defaultValue 设初始值，DOM 自己管理
function UncontrolledInput() {
  const handleSubmit = (e) => {
    e.preventDefault();
    // 需要通过 ref 来获取值（后面章节会讲 useRef）
    const formData = new FormData(e.target);
    alert('你的名字是: ' + formData.get('name'));
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" defaultValue="张三" />
      <button type="submit">提交</button>
    </form>
  );
}
```

### 受控组件（Controlled）

表单数据由 React 的 state 管理。就像乖巧的孩子——一切听爸妈（state）的安排。

```jsx
// 受控组件：value 由 state 决定，onChange 更新 state
function ControlledInput() {
  const [name, setName] = useState('张三');

  const handleSubmit = (e) => {
    e.preventDefault();
    alert('你的名字是: ' + name); // 直接从 state 获取
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={name}                    // 值来自 state
        onChange={(e) => setName(e.target.value)}  // 输入时更新 state
      />
      <button type="submit">提交</button>
    </form>
  );
}
```

**React 官方推荐使用受控组件**，原因如下：

| 特性 | 受控组件 | 非受控组件 |
|------|---------|-----------|
| **值的来源** | React state | DOM |
| **实时验证** | 容易 | 困难 |
| **条件禁用按钮** | 容易 | 困难 |
| **格式化输入** | 容易 | 困难 |
| **代码复杂度** | 稍多 | 较少 |
| **React 推荐度** | ⭐⭐⭐⭐⭐ | ⭐⭐ |

> **Tip**: 简单场景（比如一个搜索框）用非受控组件也行，但大多数情况下受控组件更可控、更可靠。就像开车——手动挡（受控）虽然操作多一点，但你对车的控制力更强。

## 8.3 处理各种表单元素

让我们逐一学习如何用受控组件处理各种常见的表单元素。

### 复选框（checkbox）和单选按钮（radio）

```jsx
import { useState } from 'react';

function CheckboxRadioDemo() {
  // 单个复选框：布尔值
  const [agree, setAgree] = useState(false);

  // 多个复选框：数组
  const [fruits, setFruits] = useState(['apple']);

  // 单选按钮：字符串
  const [gender, setGender] = useState('');

  // 处理多个复选框的通用函数
  const handleFruitChange = (e) => {
    const { value, checked } = e.target;
    if (checked) {
      // 选中：添加到数组
      setFruits(prev => [...prev, value]);
    } else {
      // 取消：从数组中移除
      setFruits(prev => prev.filter(f => f !== value));
    }
  };

  return (
    <div>
      <h2>复选框和单选按钮示例</h2>

      {/* 单个复选框 */}
      <div style={{ marginBottom: '16px' }}>
        <label>
          <input
            type="checkbox"
            checked={agree}
            onChange={(e) => setAgree(e.target.checked)}
          />
          我同意用户协议
        </label>
        <p>状态：{agree ? '已同意' : '未同意'}</p>
      </div>

      {/* 多个复选框 */}
      <div style={{ marginBottom: '16px' }}>
        <p>选择你喜欢的水果：</p>
        {['apple', 'banana', 'orange', 'grape'].map(fruit => (
          <label key={fruit} style={{ marginRight: '12px' }}>
            <input
              type="checkbox"
              value={fruit}
              checked={fruits.includes(fruit)}
              onChange={handleFruitChange}
            />
            {{ apple: '苹果', banana: '香蕉', orange: '橘子', grape: '葡萄' }[fruit]}
          </label>
        ))}
        <p>已选择: {fruits.join(', ') || '无'}</p>
      </div>

      {/* 单选按钮 */}
      <div style={{ marginBottom: '16px' }}>
        <p>选择性别：</p>
        {['male', 'female', 'other'].map(value => (
          <label key={value} style={{ marginRight: '12px' }}>
            <input
              type="radio"
              name="gender"        // 相同的 name 保证互斥
              value={value}
              checked={gender === value}
              onChange={(e) => setGender(e.target.value)}
            />
            {{ male: '男', female: '女', other: '其他' }[value]}
          </label>
        ))}
        <p>已选择: {gender || '未选择'}</p>
      </div>
    </div>
  );
}

export default CheckboxRadioDemo;
```

> **Warning**: 注意 checkbox 和 radio 的区别：checkbox 用 `checked` 属性配合 `e.target.checked`（布尔值），而 radio 用 `checked` 属性配合 `e.target.value`（字符串值）。很多人在这上面犯迷糊！

## 8.4 多输入框的统一处理

当一个表单有很多输入框时，为每个输入框写一个 `onChange` 函数太啰嗦了。我们可以用一个小技巧：**给每个输入框加一个 `name` 属性，用一个 state 对象统一管理**。

```jsx
import { useState } from 'react';

function MultiInputForm() {
  // 用一个对象管理所有字段
  const [form, setForm] = useState({
    username: '',
    email: '',
    phone: '',
    address: '',
  });

  // 通用的 onChange 处理函数
  const handleChange = (e) => {
    const { name, value } = e.target;
    setForm(prevForm => ({
      ...prevForm,       // 保留其他字段
      [name]: value,     // 更新当前字段
    }));
  };

  return (
    <div>
      <h2>统一表单处理</h2>

      <div style={{ marginBottom: '12px' }}>
        <label>用户名：</label>
        <input
          name="username"
          value={form.username}
          onChange={handleChange}
          placeholder="请输入用户名"
        />
      </div>

      <div style={{ marginBottom: '12px' }}>
        <label>邮箱：</label>
        <input
          name="email"
          type="email"
          value={form.email}
          onChange={handleChange}
          placeholder="请输入邮箱"
        />
      </div>

      <div style={{ marginBottom: '12px' }}>
        <label>手机号：</label>
        <input
          name="phone"
          value={form.phone}
          onChange={handleChange}
          placeholder="请输入手机号"
        />
      </div>

      <div style={{ marginBottom: '12px' }}>
        <label>地址：</label>
        <input
          name="address"
          value={form.address}
          onChange={handleChange}
          placeholder="请输入地址"
        />
      </div>

      <hr />
      <h3>表单数据预览：</h3>
      <pre>{JSON.stringify(form, null, 2)}</pre>
    </div>
  );
}

export default MultiInputForm;
```

这个模式的精髓在于 `handleChange` 函数：

1. 从 `e.target` 中取出 `name` 和 `value`
2. 用 `[name]: value` 的动态属性名来更新对应的字段
3. 用展开运算符 `...prevForm` 保留其他字段的值

> **Tip**: 这个模式在大型表单中非常实用，可以避免写一堆几乎一样的 onChange 函数。不过如果你的表单非常复杂（比如字段之间有联动逻辑），可以考虑使用 `useReducer` 或者表单库（如 React Hook Form）。

## 8.5 表单提交与验证

光有输入还不够，表单还需要**提交**和**验证**。让我们看看怎么做：

```jsx
import { useState } from 'react';

function LoginForm() {
  const [form, setForm] = useState({
    username: '',
    password: '',
  });
  const [errors, setErrors] = useState({});
  const [submitted, setSubmitted] = useState(false);

  const handleChange = (e) => {
    const { name, value } = e.target;
    setForm(prev => ({ ...prev, [name]: value }));

    // 用户输入时清除对应字段的错误
    if (errors[name]) {
      setErrors(prev => ({ ...prev, [name]: '' }));
    }
  };

  // 验证函数
  const validate = () => {
    const newErrors = {};

    if (!form.username.trim()) {
      newErrors.username = '用户名不能为空';
    } else if (form.username.length < 3) {
      newErrors.username = '用户名至少 3 个字符';
    }

    if (!form.password) {
      newErrors.password = '密码不能为空';
    } else if (form.password.length < 6) {
      newErrors.password = '密码至少 6 个字符';
    }

    return newErrors;
  };

  const handleSubmit = (e) => {
    e.preventDefault(); // 阻止默认的页面刷新！

    const newErrors = validate();
    setErrors(newErrors);

    // 如果没有错误，提交表单
    if (Object.keys(newErrors).length === 0) {
      setSubmitted(true);
      console.log('提交数据:', form);
      // 这里可以调用 API 提交
    }
  };

  if (submitted) {
    return (
      <div style={{ textAlign: 'center', padding: '40px' }}>
        <h2>🎉 登录成功！</h2>
        <p>欢迎回来，{form.username}！</p>
        <button onClick={() => {
          setSubmitted(false);
          setForm({ username: '', password: '' });
        }}>
          重新登录
        </button>
      </div>
    );
  }

  return (
    <form onSubmit={handleSubmit} style={{ maxWidth: '400px', margin: '0 auto' }}>
      <h2>登录</h2>

      <div style={{ marginBottom: '16px' }}>
        <label style={{ display: 'block', marginBottom: '4px' }}>用户名：</label>
        <input
          name="username"
          value={form.username}
          onChange={handleChange}
          style={{
            width: '100%',
            padding: '8px',
            border: errors.username ? '2px solid red' : '1px solid #ccc',
            borderRadius: '4px',
            boxSizing: 'border-box',
          }}
        />
        {errors.username && (
          <p style={{ color: 'red', fontSize: '12px', margin: '4px 0' }}>
            {errors.username}
          </p>
        )}
      </div>

      <div style={{ marginBottom: '16px' }}>
        <label style={{ display: 'block', marginBottom: '4px' }}>密码：</label>
        <input
          name="password"
          type="password"
          value={form.password}
          onChange={handleChange}
          style={{
            width: '100%',
            padding: '8px',
            border: errors.password ? '2px solid red' : '1px solid #ccc',
            borderRadius: '4px',
            boxSizing: 'border-box',
          }}
        />
        {errors.password && (
          <p style={{ color: 'red', fontSize: '12px', margin: '4px 0' }}>
            {errors.password}
          </p>
        )}
      </div>

      <button
        type="submit"
        style={{
          padding: '10px 24px',
          background: '#007bff',
          color: 'white',
          border: 'none',
          borderRadius: '4px',
          cursor: 'pointer',
        }}
      >
        登录
      </button>
    </form>
  );
}

export default LoginForm;
```

> **Warning**: 别忘了 `e.preventDefault()`！HTML 表单默认提交时会刷新页面，这会让你的 React 应用整个重新加载。在 React 中，我们始终用 `e.preventDefault()` 阻止默认行为，然后用 JavaScript 来处理提交逻辑。

## 8.6 实战：完整的注册表单

让我们把本章所有知识融合在一起，做一个完整的注册表单：

```jsx
import { useState } from 'react';

function RegistrationForm() {
  // 表单数据
  const [form, setForm] = useState({
    username: '',
    email: '',
    password: '',
    confirmPassword: '',
    gender: '',
    hobby: [],
    agree: false,
  });

  // 错误信息
  const [errors, setErrors] = useState({});
  // 是否提交成功
  const [isSuccess, setIsSuccess] = useState(false);

  // 通用输入处理
  const handleChange = (e) => {
    const { name, value, type, checked } = e.target;

    if (type === 'checkbox' && name === 'agree') {
      // 协议复选框
      setForm(prev => ({ ...prev, agree: checked }));
    } else if (type === 'checkbox' && name === 'hobby') {
      // 爱好复选框（多个）
      if (checked) {
        setForm(prev => ({ ...prev, hobby: [...prev.hobby, value] }));
      } else {
        setForm(prev => ({
          ...prev,
          hobby: prev.hobby.filter(h => h !== value),
        }));
      }
    } else {
      // 普通输入
      setForm(prev => ({ ...prev, [name]: value }));
    }

    // 清除当前字段错误
    if (errors[name]) {
      setErrors(prev => ({ ...prev, [name]: '' }));
    }
  };

  // 表单验证
  const validate = () => {
    const errs = {};

    // 用户名验证
    if (!form.username.trim()) {
      errs.username = '请输入用户名';
    } else if (form.username.length < 3 || form.username.length > 20) {
      errs.username = '用户名长度应在 3-20 个字符之间';
    } else if (!/^[a-zA-Z0-9_]+$/.test(form.username)) {
      errs.username = '用户名只能包含字母、数字和下划线';
    }

    // 邮箱验证
    if (!form.email.trim()) {
      errs.email = '请输入邮箱';
    } else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email)) {
      errs.email = '请输入有效的邮箱地址';
    }

    // 密码验证
    if (!form.password) {
      errs.password = '请输入密码';
    } else if (form.password.length < 8) {
      errs.password = '密码至少 8 个字符';
    }

    // 确认密码验证
    if (form.password !== form.confirmPassword) {
      errs.confirmPassword = '两次输入的密码不一致';
    }

    // 性别
    if (!form.gender) {
      errs.gender = '请选择性别';
    }

    // 协议
    if (!form.agree) {
      errs.agree = '请阅读并同意用户协议';
    }

    return errs;
  };

  // 提交处理
  const handleSubmit = (e) => {
    e.preventDefault();
    const newErrors = validate();
    setErrors(newErrors);

    if (Object.keys(newErrors).length === 0) {
      setIsSuccess(true);
      console.log('注册成功！用户数据:', {
        ...form,
        password: '***', // 不打印密码
        confirmPassword: '***',
      });
    }
  };

  // 密码强度指示器
  const getPasswordStrength = () => {
    const pwd = form.password;
    if (!pwd) return { text: '', color: '#ccc', width: '0%' };

    let score = 0;
    if (pwd.length >= 8) score++;
    if (/[A-Z]/.test(pwd)) score++;
    if (/[a-z]/.test(pwd)) score++;
    if (/[0-9]/.test(pwd)) score++;
    if (/[^A-Za-z0-9]/.test(pwd)) score++;

    const levels = [
      { text: '非常弱', color: '#dc3545', width: '20%' },
      { text: '弱', color: '#fd7e14', width: '40%' },
      { text: '一般', color: '#ffc107', width: '60%' },
      { text: '强', color: '#28a745', width: '80%' },
      { text: '非常强', color: '#20c997', width: '100%' },
    ];

    return levels[score - 1] || levels[0];
  };

  // 成功页面
  if (isSuccess) {
    return (
      <div style={{ textAlign: 'center', padding: '40px' }}>
        <h2 style={{ color: '#28a745' }}>🎉 注册成功！</h2>
        <p>欢迎你，{form.username}！</p>
        <p>一封确认邮件已发送到 {form.email}</p>
        <button onClick={() => {
          setIsSuccess(false);
          setForm({
            username: '', email: '', password: '',
            confirmPassword: '', gender: '', hobby: [], agree: false,
          });
          setErrors({});
        }}>
          返回注册页
        </button>
      </div>
    );
  }

  const strength = getPasswordStrength();

  // 输入框样式辅助函数
  const inputStyle = (fieldName) => ({
    width: '100%',
    padding: '8px 12px',
    border: errors[fieldName] ? '2px solid #dc3545' : '1px solid #ced4da',
    borderRadius: '6px',
    fontSize: '14px',
```

## 8.7 简单了解 useRef 在非受控组件中的用法

虽然我们推荐使用受控组件，但有时候你确实需要直接操作 DOM 元素（比如获取文件上传的值）。这时可以使用 `useRef`：

```jsx
import { useRef } from 'react';

function FileUpload() {
  const fileInputRef = useRef(null);

  const handleSubmit = (e) => {
    e.preventDefault();
    // 通过 ref 直接获取 DOM 元素
    const file = fileInputRef.current.files[0];
    if (file) {
      alert(`选择了文件: ${file.name}，大小: ${(file.size / 1024).toFixed(1)} KB`);
    } else {
      alert('请先选择一个文件');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <h3>文件上传（非受控组件）</h3>
      {/* file 类型的 input 无法被受控，因为它的值只能由用户选择 */}
      <input type="file" ref={fileInputRef} />
      <button type="submit">上传</button>
    </form>
  );
}

export default FileUpload;
```

> **Tip**: `<input type="file">` 是一个特殊的表单元素——它的值只能由用户通过文件选择器设置，不能通过 JavaScript 的 `value` 属性设置。所以它**必须**使用非受控组件 + useRef。下一章我们会深入学习 useRef。

## 8.8 本章小结

表单处理是 React 开发中最常见的需求之一。让我们来总结关键知识点：

| 概念 | 核心要点 |
|------|---------|
| **受控组件** | 表单值由 React state 管理，通过 value + onChange 实现双向绑定 |
| **非受控组件** | 表单值由 DOM 管理，通过 ref 获取值 |
| **统一处理** | 用 name 属性 + 一个 handleChange 函数管理多个输入框 |
| **各种元素** | text/textarea/select 用 value，checkbox 用 checked，radio 用 checked + value |
| **表单提交** | 用 onSubmit + e.preventDefault()，在 JS 中处理逻辑 |
| **验证** | 在提交时调用 validate 函数，把错误信息存到 errors state |

**比喻回顾**：受控组件就像一个乖宝宝——输入框的值完全听 React（state）的话。用户输入的内容经过 onChange 传到 state，state 的新值又通过 value 传回给输入框，形成一个完美的闭环。
