# 第 13 章 面向对象编程（上）

想象你要造汽车。你不会直接拿锤子叮叮当当地敲打金属——你会先画一张**设计图纸**，上面写着车的尺寸、颜色、发动机型号、轮胎规格。然后，工厂根据这张图纸，可以造出成千上万辆一模一样的车。每一辆车都是独立的实体，可以有不同的颜色和配置，但它们都来自同一张图纸。

这就是面向对象编程（OOP）的核心思想：**类（class）是图纸，实例（instance）是按图纸造出的产品**。Python 中的一切皆对象——数字、字符串、列表都是对象——但之前你只是"使用"别人画好的图纸。这一章，你要学会自己画图纸。

## 13.1 定义类与创建实例

```python
# 定义一个类（图纸）
class Dog:
    """狗的类"""

    # __init__ 是初始化方法，创建实例时自动调用
    def __init__(self, name, breed, age):
        self.name = name      # 实例属性
        self.breed = breed
        self.age = age

    # 实例方法
    def bark(self):
        return f"{self.name}：汪汪汪！"

    def info(self):
        return f"{self.name}，{self.breed}，{self.age}岁"

# 创建实例（按图纸造产品）
dog1 = Dog("旺财", "金毛", 3)
dog2 = Dog("小黑", "哈士奇", 2)

print(dog1.bark())   # 旺财：汪汪汪！
print(dog2.info())   # 小黑，哈士奇，2岁
print(dog1.name)     # 旺财（访问属性）
print(type(dog1))    # <class '__main__.Dog'>
```

### 13.1.1 理解 `__init__` 和 `self`

- **`__init__`**：初始化方法（不是构造函数），在创建实例时自动调用。它负责设置实例的初始状态。
- **`self`**：代表实例本身。调用方法时，Python 自动把实例传进去，你不需要手动传。

```python
# 这两行是等价的
dog1.bark()      # Python 自动传入 dog1 作为 self
Dog.bark(dog1)   # 手动传入，效果相同
```

`self` 就像每个实例的"身份证号"——它让方法知道自己操作的是哪个实例。

## 13.2 实例属性 vs 类属性

```python
class Dog:
    # 类属性：所有实例共享
    species = "犬科"
    count = 0  # 用于统计创建了多少只狗

    def __init__(self, name):
        # 实例属性：每个实例独有
        self.name = name
        Dog.count += 1  # 每创建一只狗，计数器加一

dog1 = Dog("旺财")
dog2 = Dog("小黑")

# 类属性：所有实例共享同一个值
print(dog1.species)  # 犬科
print(dog2.species)  # 犬科
print(Dog.species)   # 犬科（也可以通过类访问）

# 实例属性：每个实例各自值
print(dog1.name)  # 旺财
print(dog2.name)  # 小黑

# 类属性计数
print(Dog.count)  # 2（创建了两只狗）
```

### 13.2.1 小心类属性的坑

```python
class Cat:
    tricks = []  # 可变类属性——所有实例共享同一个列表！

    def __init__(self, name):
        self.name = name

    def add_trick(self, trick):
        self.tricks.append(trick)

cat1 = Cat("咪咪")
cat2 = Cat("花花")

cat1.add_trick("翻跟斗")
print(cat2.tricks)  # ['翻跟斗']  糟糕！花花也会"翻跟斗"了？

# 正确做法：在 __init__ 中初始化可变属性
class CatFixed:
    def __init__(self, name):
        self.name = name
        self.tricks = []  # 每个实例各自一个列表

    def add_trick(self, trick):
        self.tricks.append(trick)

cat1 = CatFixed("咪咪")
cat2 = CatFixed("花花")
cat1.add_trick("翻跟斗")
print(cat2.tricks)  # []  花花的列表是空的，正确
```

**规则：可变对象（列表、字典、集合）不要在类属性中定义，应该在 `__init__` 中定义。**

## 13.3 方法

Python 类中有三种方法，各自适用于不同场景。

### 13.3.1 实例方法（最常用）

```python
class Calculator:
    def __init__(self):
        self.history = []

    # 实例方法：第一个参数是 self，操作实例数据
    def add(self, a, b):
        result = a + b
        self.history.append(f"{a} + {b} = {result}")
        return result

    def show_history(self):
        for entry in self.history:
            print(entry)

calc = Calculator()
calc.add(3, 5)
calc.add(10, 20)
calc.show_history()
# 3 + 5 = 8
# 10 + 20 = 30
```

### 13.3.2 类方法（@classmethod）

```python
class Date:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    # 类方法：第一个参数是 cls（类本身），不依赖实例
    @classmethod
    def from_string(cls, date_str):
        """从字符串创建日期：'2024-01-15'"""
        year, month, day = map(int, date_str.split("-"))
        return cls(year, month, day)  # 等价于 Date(year, month, day)

    @classmethod
    def today(cls):
        """创建今天的日期"""
        from datetime import date
        d = date.today()
        return cls(d.year, d.month, d.day)

    def __str__(self):
        return f"{self.year}-{self.month:02d}-{self.day:02d}"

# 使用类方法创建实例（工厂方法模式）
d1 = Date.from_string("2024-01-15")
print(d1)  # 2024-01-15

d2 = Date.today()
print(d2)  # 今天的日期
```

### 13.3.3 静态方法（@staticmethod）

```python
class MathUtils:
    # 静态方法：不需要 self 也不需要 cls
    # 逻辑上属于这个类，但不需要访问类或实例的数据
    @staticmethod
    def is_even(n):
        return n % 2 == 0

    @staticmethod
    def clamp(value, min_val, max_val):
        """限制值在范围内"""
        return max(min_val, min(value, max_val))

    @staticmethod
    def fibonacci(n):
        """计算第 n 个斐波那契数"""
        if n <= 1:
            return n
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, a + b
        return b

print(MathUtils.is_even(42))        # True
print(MathUtils.clamp(15, 0, 10))   # 10
print(MathUtils.fibonacci(10))      # 55

# 也可以通过实例调用
utils = MathUtils()
print(utils.is_even(7))  # False
```

### 13.3.4 三种方法的选择

| 方法类型 | 第一个参数 | 使用场景 |
| --------- | ----------- | --------- |
| 实例方法 | `self` | 需要访问或修改实例属性 |
| 类方法 | `cls` | 需要访问类属性，或作为替代构造函数 |
| 静态方法 | 无 | 不需要访问类或实例，逻辑上属于该类 |

## 13.4 继承

继承让你基于已有的类创建新类——新类自动拥有父类的所有属性和方法，还可以添加新功能或修改旧行为。

```python
# 父类（基类）
class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        return f"{self.name}说：{self.sound}！"

    def __str__(self):
        return f"Animal({self.name})"

# 子类（派生类）
class Dog(Animal):
    def __init__(self, name, breed):
        # 调用父类的 __init__
        super().__init__(name, sound="汪汪")
        self.breed = breed

    # 新增方法
    def fetch(self, item):
        return f"{self.name}捡回了{item}"

    # 重写父类方法
    def __str__(self):
        return f"Dog({self.name}, {self.breed})"

class Cat(Animal):
    def __init__(self, name, indoor=True):
        super().__init__(name, sound="喵喵")
        self.indoor = indoor

    def purr(self):
        return f"{self.name}发出了满足的呼噜声"

# 使用
dog = Dog("旺财", "金毛")
print(dog.speak())     # 旺财说：汪汪！（继承自 Animal）
print(dog.fetch("球")) # 旺财捡回了球（Dog 自己的方法）
print(dog)             # Dog(旺财, 金毛)（重写了 __str__）

cat = Cat("咪咪")
print(cat.speak())     # 咪咪说：喵喵！
print(cat.purr())      # 咪咪发出了满足的呼噜声

# isinstance 检查类型
print(isinstance(dog, Dog))     # True
print(isinstance(dog, Animal))  # True（Dog 是 Animal 的子类）
print(isinstance(dog, Cat))     # False

# issubclass 检查继承关系
print(issubclass(Dog, Animal))  # True
print(issubclass(Cat, Dog))     # False
```

### 13.4.1 super() 的正确用法

`super()` 返回父类的代理对象，让你在子类中调用父类的方法：

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def info(self):
        return f"姓名：{self.name}，薪资：{self.salary}"

class Manager(Employee):
    def __init__(self, name, salary, department):
        super().__init__(name, salary)  # 调用父类 __init__
        self.department = department    # 子类自己的属性

    def info(self):
        # 调用父类方法并扩展
        base_info = super().info()
        return f"{base_info}，部门：{self.department}"

mgr = Manager("张经理", 20000, "技术部")
print(mgr.info())  # 姓名：张经理，薪资：20000，部门：技术部
```

### 13.4.2 多层继承

```python
class Creature:
    def __init__(self, name):
        self.name = name

class Animal(Creature):
    def __init__(self, name, species):
        super().__init__(name)
        self.species = species

class Pet(Animal):
    def __init__(self, name, species, owner):
        super().__init__(name, species)
        self.owner = owner

    def info(self):
        return f"{self.name}（{self.species}），主人是{self.owner}"

pet = Pet("旺财", "狗", "小明")
print(pet.info())  # 旺财（狗），主人是小明
print(pet.name)    # 旺财（继承自 Creature）
```

## 13.5 多继承与 MRO

Python 支持多继承——一个子类可以有多个父类。这很强大，但也容易复杂。

```python
class Flyable:
    def fly(self):
        return f"{self.name}在天上飞"

class Swimmable:
    def swim(self):
        return f"{self.name}在水里游"

class Duck(Animal, Flyable, Swimmable):
    def __init__(self, name):
        super().__init__(name, sound="嘎嘎")

duck = Duck("唐老鸭")
print(duck.speak())  # 唐老鸭说：嘎嘎！（来自 Animal）
print(duck.fly())    # 唐老鸭在天上飞（来自 Flyable）
print(duck.swim())   # 唐老鸭在水里游（来自 Swimmable）
```

### 13.5.1 MRO（方法解析顺序）

当多个父类有同名方法时，Python 按什么顺序查找？答案在 **MRO**（Method Resolution Order）中：

```python
class A:
    def who(self):
        return "A"

class B(A):
    def who(self):
        return "B"

class C(A):
    def who(self):
        return "C"

class D(B, C):
    pass

d = D()
print(d.who())  # "B"（B 在 C 前面）

# 查看 MRO
print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)
# 搜索顺序：D -> B -> C -> A -> object
```

Python 使用 **C3 线性化算法**来确定 MRO，保证：

1. 子类在父类前面
2. 多个父类按声明顺序排列
3. 不会出现矛盾的顺序

**实践建议**：尽量避免复杂的多继承。如果一定要用，优先使用 **Mixin** 模式（后面会讲到）。

## 13.6 组合优于继承

继承表示"是一个"（is-a）关系，组合表示"有一个"（has-a）关系。有时候组合比继承更合适。

```python
# 不太好的设计：过度继承
class AnimalBase:
    def eat(self):
        return "吃东西"

class FlyingAnimal(AnimalBase):
    def fly(self):
        return "飞"

class SwimmingAnimal(AnimalBase):
    def swim(self):
        return "游"

# 既会飞又会游泳的动物怎么办？多重继承？

# 更好的设计：组合
class Engine:
    def start(self):
        return "引擎启动"
    def stop(self):
        return "引擎关闭"

class GPS:
    def locate(self):
        return "当前位置：北纬39.9，东经116.4"

class Car:
    def __init__(self, brand):
        self.brand = brand
        self.engine = Engine()   # 组合：Car 有一个 Engine
        self.gps = GPS()         # 组合：Car 有一个 GPS

    def drive(self):
        self.engine.start()
        pos = self.gps.locate()
        print(f"{self.brand}出发，{pos}")

    def park(self):
        self.engine.stop()
        print(f"{self.brand}已停车")

car = Car("特斯拉")
car.drive()   # 特斯拉出发，当前位置：北纬39.9，东经116.4
car.park()    # 特斯拉已停车
```

组合的好处：

- **灵活性更高**：可以运行时替换组件
- **避免继承层次过深**
- **更容易测试**：可以单独测试每个组件

## 13.7 实战：设计一个简单的待办事项系统

```python
class Task:
    """单个待办任务"""
    def __init__(self, title, priority="medium"):
        self.title = title
        self.priority = priority
        self.done = False

    def complete(self):
        self.done = True

    def __str__(self):
        status = "OK" if self.done else "TODO"
        return f"[{status}] {self.title} ({self.priority})"

class TodoList:
    """待办事项列表"""
    def __init__(self, name):
        self.name = name
        self.tasks = []

    def add_task(self, title, priority="medium"):
        task = Task(title, priority)
        self.tasks.append(task)
        return task

    def complete_task(self, title):
        for task in self.tasks:
            if task.title == title and not task.done:
                task.complete()
                return True
        return False

    def get_pending(self):
        return [t for t in self.tasks if not t.done]

    def get_completed(self):
        return [t for t in self.tasks if t.done]

    def __str__(self):
        lines = [f"== {self.name} =="]
        for task in self.tasks:
            lines.append(f"  {task}")
        return "\n".join(lines)

# 使用
todo = TodoList("今日任务")
todo.add_task("写周报", "high")
todo.add_task("买咖啡", "low")
todo.add_task("代码审查", "high")
todo.add_task("回复邮件", "medium")

todo.complete_task("买咖啡")

print(todo)
# == 今日任务 ==
#   [TODO] 写周报 (high)
#   [OK] 买咖啡 (low)
#   [TODO] 代码审查 (high)
#   [TODO] 回复邮件 (medium)

print(f"\n待完成：{len(todo.get_pending())} 项")  # 3 项
print(f"已完成：{len(todo.get_completed())} 项")  # 1 项
```

## 13.8 小结

- **类**是创建对象的蓝图，**实例**是按蓝图创建的具体对象
- `__init__` 是初始化方法，`self` 代表实例本身
- **实例属性**属于单个实例，**类属性**被所有实例共享（可变对象慎用类属性）
- 三种方法：实例方法（`self`）、类方法（`@classmethod`，`cls`）、静态方法（`@staticmethod`）
- **继承**让子类复用父类代码，`super()` 调用父类方法
- Python 支持多继承，**MRO** 决定方法查找顺序
- **组合优于继承**：不是所有关系都适合继承，有时候"有一个"比"是一个"更合适

from datetime import datetime

class Logger:
    def __init__(self):
        self.logs = []

## 13.11 常见错误与避坑

**1. 忘记调用 `super().__init__()`**

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        # 忘记调用 super().__init__(name)
        self.breed = breed
        # 此时 self.name 不存在！

dog = Dog("旺财", "金毛")
# print(dog.name)  # AttributeError!
```

**2. 在类属性中放可变对象**

参见 13.2.1 节的 `Cat` 例子。列表、字典等可变对象作为类属性会被所有实例共享。

**3. 类方法中用了 `self`**

```python
class MyClass:
    count = 0

    # 错误：类方法应该用 cls 而不是 self
    # @classmethod
    # def increment(self):  # self 是实例，但类方法不一定有实例
    #     self.count += 1

    # 正确
    @classmethod
    def increment(cls):
        cls.count += 1
```

**4. 过度继承**

```python
# 继承层次太深，难以理解和维护
class A: ...
class B(A): ...
class C(B): ...
class D(C): ...
class E(D): ...  # 到底继承了什么？很难说清

# 保持继承层次扁平，一般不超过 2-3 层
```

**5. 用继承解决"代码复用"问题**

```python
# 不好：为了复用代码而继承
class Logger:
    def log(self, msg):
        print(f"[LOG] {msg}")

class UserService(Logger):  # 用户服务"是一个"日志器？不合理
    def create_user(self, name):
        self.log(f"创建用户：{name}")

# 好：用组合
class UserService:
    def __init__(self):
        self.logger = Logger()  # 用户服务"有一个"日志器

    def create_user(self, name):
        self.logger.log(f"创建用户：{name}")
```
