# 第2章：文档基本操作——从输入到编辑 ✏️

*小王终于决定用Word重写员工手册了。他打开Word，深吸一口气，开始敲字……十分钟后，他发现打错了一个字，于是用鼠标一个字母一个字母地删，删完又重新打。旁边的实习生小刘看了一眼说："王哥，你知道有种东西叫'查找替换'吗？"小王愣住了。接着小刘又演示了复制粘贴和撤销功能，小王看完沉默了五秒，然后说了一句："我这几年Word都白用了。"这一章，我们帮你把小王踩过的坑全部避开。*

## 2.1 文字输入：中文输入法配合、特殊符号输入

Word的文字输入没什么特别的——打开输入法，直接打字就行。但有几个小技巧值得注意：

**中文输入法配合**：

- Word对主流中文输入法（微软拼音、搜狗、微信输入法等）兼容性都很好
- 输入中文时，标点默认是中文全角标点（，。！？），这是正确的
- 输入英文或数字时，建议切换到英文半角模式，否则数字和字母会占两个字符宽度，排版会错位

**中英文混排的小窍门**：

- 输入完英文后，Word会自动在英文和中文之间加一点间距，这是正常的，不需要手动加空格
- 如果需要输入连续英文（如网址、邮箱），建议先设为英文输入法再输入

**特殊符号输入**：
奶茶店的菜单上经常需要用到特殊符号，比如 ¥、℃、★、→ 等。输入方法有：

- **方法一**：`插入 > 符号 > 其他符号`，在弹出的对话框中选择
- **方法二**：输入法自带——大多数中文输入法输入"du"可以打出"°"，输入"rmb"可以打出"¥"
- **方法三**：快捷键——比如 `Ctrl + Alt + T` 可以输入 ™

> 💡 **提示**：如果你经常用某些特殊符号，可以在 `插入 > 符号 > 其他符号` 里点击"快捷键"按钮，给它们设置自定义快捷键。比如小王经常要打 ¥，他就设了一个 `Alt + Y`。

## 2.2 选择文本：单词、句子、段落、全选的各种技巧

第1章我们已经介绍了基本的选择方法，这里再补充几个实用技巧：

**纵向选择（列选择）**：
按住 `Alt` 键，然后用鼠标从上往下拖动——你会发现可以选一个"矩形区域"！这在处理表格数据或者对齐的文字时特别有用。

比如小王从网上复制了一堆奶茶配方文字，每行开头都有编号，他只想选文字不要编号——纵向选择就派上用场了。

**使用键盘精确选择**：

- `F8` 键是"扩展选择"模式——按一次进入扩展选择，然后用方向键扩展选区，再按一次 `F8` 退出。适合鼠标不太好精确控制的场景。

**在状态栏查看选中的字数**：
选中一段文字后，看状态栏左下角，会显示类似"选中 128 个字"。写报告需要统计特定章节字数时很方便。

## 2.3 复制、剪切、粘贴（以及"只粘贴文本"的重要性）

这三个操作可能是电脑里用得最多的功能了，但Word里的粘贴远比你想象的复杂。

**基本操作**：

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 复制 | `Ctrl + C` | 复制选中内容到剪贴板 |
| 剪切 | `Ctrl + X` | 剪切选中内容到剪贴板（原文消失） |
| 粘贴 | `Ctrl + V` | 将剪贴板内容粘贴到光标处 |

**粘贴选项——重点来了！**

粘贴后，文字右下角会出现一个小图标（粘贴选项按钮），点开你会看到几个选项：

- **保留源格式**：粘贴过来的文字保持原来的格式（字体、颜色、大小全部保留）
- **合并格式**：保留基本格式（加粗、斜体），但字体和字号会匹配目标文档
- **只保留文本**：❗**这个最重要**❗——丢掉所有格式，只留纯文字

**为什么"只保留文本"如此重要？**

举个例子：小王从网上复制了一段奶茶行业报告的文字，粘贴到自己的方案里。结果——字体不一样、字号不一样、行距不一样、甚至还带着蓝色超链接和灰色背景。整个文档看起来像拼凑的（事实上也确实是拼凑的）。

正确做法：使用 `Ctrl + Shift + V`（部分版本支持）或粘贴后选"只保留文本"，然后再统一设置格式。

> 💡 **提示**：养成一个好习惯——从外部来源（网页、PDF、其他文档）复制内容到Word时，永远先"只保留文本"粘贴，再手动排版。这能避免90%的格式混乱问题。

**Office剪贴板**：
Word有一个增强版剪贴板，可以保存最近复制的24项内容。打开方法：`开始 > 剪贴板` 分组右下角的小箭头。这样你可以连续复制多段内容，然后选择性粘贴——做资料整理时非常好用。

## 2.4 撤销与重做：Word的"后悔药"

这可能是Word里最伟大的功能了——**撤销**。

- **撤销**：`Ctrl + Z`——撤销上一步操作
- **重做**：`Ctrl + Y` 或 `F4`——撤销过头了，再恢复回来

Word默认可以撤销**20步**操作（实际上根据内存可以更多），这意味着你可以"后悔"很久之前的操作。

> 💡 **提示**：如果你做了太多修改，想回到"今天刚打开文件时的状态"，不要一步一步撤销——直接关闭文件，弹出提示时选"不保存"，然后重新打开就好了。简单粗暴但有效。

**一个常见惨剧的预防**：
有些人不小心按了 `Ctrl + A`（全选）然后按了一个字母，结果整个文档内容被一个字母替换了。这时候别慌——立刻按 `Ctrl + Z`，文档就恢复了。**千万不要慌慌张张地又去按保存！**

## 2.5 查找与替换：快速定位和批量修改

查找与替换是小王"相见恨晚"的功能之一。

**打开方式**：`Ctrl + H`（替换）或 `Ctrl + F`（查找/导航）

**基本用法**：
在"查找内容"框中输入要找的文字，点击"查找下一处"即可定位。在"替换为"框中输入新文字，点击"替换"即可逐一替换，或点"全部替换"一次性搞定。

**实战场景**：
小王写了一份5000字的奶茶店营销方案，里面把"珍珠奶茶"写成了"珍珠奶荼"（"茶"打成了"荼"），一共出现了38次。如果要一个一个改，眼睛都要看花了。用查找替换？10秒钟搞定。

**高级用法**：
点击"更多"按钮，可以展开高级选项：

- **区分大小写**：查找英文时有用
- **全字匹配**：只匹配完整的词，不匹配词的一部分
- **使用通配符**：可以用 `*`（任意多个字符）和 `?`（任意单个字符）进行模糊查找
- **查找格式**：可以查找特定格式的内容（比如所有红色文字、所有加粗文字）
- **替换格式**：可以批量修改格式（比如把所有"宋体"替换为"微软雅黑"）

> 💡 **提示**：替换操作要谨慎！建议先用"查找下一处"确认找到的内容是对的，再点替换。"全部替换"虽然快，但可能会误伤——比如你想把"奶"替换成"鲜奶"，结果"奶奶"变成了"鲜奶鲜奶"（虽然这个例子有点搞笑，但确实会发生）。

## 2.6 拼写与语法检查

Word自带拼写和语法检查功能，默认开启。你会看到文字下面有波浪线：

- **红色波浪线**：拼写错误（Word觉得这个词拼错了）
- **蓝色双下划线**：语法问题（Word觉得这句话语法有问题）
- **绿色波浪线**（老版本）：语法问题

处理方式：右键点击带波浪线的文字，Word会给出修改建议。

**对中文的支持**：
Word的中文拼写检查比较基础，能发现一些常见的同音字错误（比如"帐号"vs"账号"），但不如专业的中文校对工具。建议：

- 重要文档用Word检查一遍，再人工通读一遍
- 对于输入法造成的同音字错误（"在"和"再"、"的"和"地"），人工检查仍是主力

> 💡 **提示**：如果你觉得波浪线很烦（尤其是写中文时经常出现误报），可以在 `文件 > 选项 > 校对` 中关闭"键入时检查拼写"。但建议在完成文档后重新开启，做最后一遍检查。

## 2.7 实战：为奶茶店撰写一份开业公告

学了这么多基本功，我们来实战演练！帮小王写一份"茶里茶气"奶茶店的开业公告。

**步骤一：新建文档，输入内容**
新建空白文档，快速输入以下文字（不用管格式，先把内容写完）：

```
茶里茶气 盛大开业公告

亲爱的街坊邻居们：

经过精心筹备，"茶里茶气"奶茶店将于2025年3月1日正式开业！

开业期间，我们为大家准备了超值优惠：
全场饮品8折
买二送一
会员注册即送10元优惠券

我们的招牌饮品：
招牌珍珠奶茶 —— 15元
芝士奶盖绿茶 —— 18元
鲜芒椰椰 —— 20元

地址：幸福路88号
营业时间：每天 10:00 - 22:00
联系电话：138-xxxx-xxxx

茶里茶气，用一杯好茶温暖你的每一天！
```

**步骤二：保存文件**
按 `Ctrl + S`，保存为"开业公告.docx"。

**步骤三：检查修改**
通读一遍，用查找功能（`Ctrl + F`）确认有没有错别字。

现在这份公告还没有排版，看起来很"朴素"——没关系，下一章我们就给它"化妆"！

## 本章小结

| 知识点 | 要点 |
| -------- | ------ |
| 文字输入 | 中英文切换注意全角/半角，特殊符号用插入菜单或输入法快捷 |
| 选择文本 | 纵向选择用Alt，扩展选择用F8 |
| 复制粘贴 | 外部内容粘贴用"只保留文本"，避免格式污染 |
| 撤销重做 | Ctrl+Z撤销，Ctrl+Y重做，误操作别慌 |
| 查找替换 | Ctrl+H打开，慎用"全部替换"，先逐一确认 |
| 拼写检查 | 红色=拼写，蓝色=语法，中文检查仅供参考 |

## 练习题

1. **【基础】** 把2.7实战中的开业公告完整输入一遍，练习中文输入法与Word的配合，注意中英文标点切换。

2. **【进阶】** 在开业公告中故意写错3个字（比如"开业"写成"开夜"），然后用"查找与替换"功能一次性修改。再试试把"茶里茶气"全部替换为"茶气茶里"，看看效果，最后用撤销恢复。
