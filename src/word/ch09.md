## 9.1 什么是邮件合并？一个模板+一份数据=批量文档

邮件合并，名字听着像是发邮件用的，其实它是Word里最被低估的"黑科技"之一。简单来说，它做的事情就是：

**一份模板文档 + 一份数据表格 = 批量生成N份个性化文档**

打个比方：你要给全班50个同学写期末评语。传统做法是写50遍"XX同学本学期表现……"，每次都改名字和评语内容。而邮件合并的做法是——你只写一封模板信，把需要变化的地方（姓名、评语、成绩）标记成"占位符"，然后用一份Excel表格存好50个同学的数据，Word会自动帮你"填充"出50份完整的文档。

> 💡 **提示**：邮件合并不只是用来做"邮件"的。邀请函、工资条、录取通知书、快递单、准考证……只要你需要"同样的格式+不同的数据"批量生成文档，它都能搞定。

邮件合并的核心概念只有三个：

- **主文档**（模板）：就是你设计好的"骨架"，格式是固定的
- **数据源**（表格）：存放所有个性化数据的Excel表或CSV文件
- **合并域**（占位符）：模板里那些"等着被数据填充"的位置

## 9.2 邮件合并的三种输出：信函、信封、邮件

打开 `邮件` 选项卡，点击 `开始邮件合并`，你会看到几种输出类型：

| 输出类型 | 适用场景 | 说明 |
| --------- | --------- | ------ |
| **信函** | 邀请函、通知书、工资条 | 每页一份文档，最常用 |
| **信封** | 批量打印信封 | 自动排版收件人地址和寄件人地址 |
| **邮件** | 批量发送电子邮件 | 通过Outlook发送，每封邮件内容个性化 |
| **目录** | 通讯录、花名册 | 所有数据汇到一个文档里，每条一段 |
| **标签** | 快递单、产品标签 | 在一页上排列多个相同尺寸的标签 |

小王要做邀请函，当然选"信函"。

## 9.3 准备数据源：用Excel表格做数据源

数据源是整个邮件合并的"灵魂"。最方便的数据源就是Excel表格。

小王打开了Excel，创建了这样一张表：

| 姓名 | 会员等级 | 积分余额 | 优惠码 | 手机号 |
| ------ | --------- | --------- | -------- | -------- |
| 张三 | 黄金会员 | 2680 | VIP-GOLD-001 | 138****1234 |
| 李四 | 白银会员 | 1520 | VIP-SILV-002 | 139****5678 |
| 王五 | 钻石会员 | 5200 | VIP-DIAM-003 | 137****9012 |
| …… | …… | …… | …… | …… |

做数据源有几个要点：

1. **第一行必须是标题行**：每一列的名称，比如"姓名""会员等级"。这些名称之后会变成合并域的名字。
2. **不要有合并单元格**：数据源必须是一张"干净"的表，不能有合并单元格或空行。
3. **数据要准确**：合并后的文档完全取决于数据源，如果Excel里写错了名字，生成的邀请函也会是错的。
4. **保存并关闭Excel**：这一点很重要！如果Excel文件没关闭，Word可能无法读取它。

> 💡 **提示**：建议把数据源Excel和Word模板放在同一个文件夹里，方便管理，也避免路径问题。

## 9.4 创建主文档：设计模板

接下来，小王开始在Word里设计邀请函的模板。

模板设计的关键是：**只设计固定不变的部分，需要变化的地方先留空。**

比如邀请函的模板可能是这样的：

```
茶里茶气·周年庆邀请函

亲爱的____：

感谢您一直以来的支持！作为我们的____，
您目前累计积分____分。

周年庆专属福利：凭优惠码____，
可享全场饮品8折优惠！

活动时间：2026年7月1日-7月15日
活动地点：茶里茶气·全城门店

期待您的光临！

茶里茶气
2026年6月
```

那些下划线的地方，就是之后要用合并域替换的位置。

操作步骤：

1. 正常打开Word，设计好邀请函的版式、字体、颜色等
2. 点击 `邮件 > 开始邮件合并 > 信函`
3. 点击 `选择收件人 > 使用现有列表`，找到刚才做好的Excel文件
4. Word会问你要用哪个工作表（Sheet），选对的那一个，勾选"数据首行包含列标题"

完成这几步后，Word就已经把数据源和模板"连上线"了。

## 9.5 插入合并域：把数据"嵌入"文档

这是邮件合并最核心的一步！

把光标放在需要插入数据的位置，然后点击 `邮件 > 插入合并域`，你会看到数据源的所有列名都列在这里：

- «姓名»
- «会员等级»
- «积分余额»
- «优惠码»
- «手机号»

小王把光标放在"亲爱的"后面，选择了"姓名"；把光标放在"作为我们的"后面，选择了"会员等级"……以此类推。

完成后的模板看起来是这样的：

```
亲爱的«姓名»：

感谢您一直以来的支持！作为我们的«会员等级»，
您目前累计积分«积分余额»分。

周年庆专属福利：凭优惠码«优惠码»，
可享全场饮品8折优惠！
```

那些被书名号包起来的就是**合并域**——它们现在还显示的是"字段名"，等合并执行后，就会变成每个会员的真实数据。

> 💡 **提示**：合并域和普通文字一样，可以设置字体、颜色、大小。你可以把"«姓名»"设置成红色加粗，合并后每个人的名字都会是红色加粗的。

## 9.6 预览与检查：确保每份文档正确

别急着合并！先预览一下效果。

点击 `邮件 > 预览结果`，模板中的合并域会立刻变成第一条数据的真实内容：

```
亲爱的张三：

感谢您一直以来的支持！作为我们的黄金会员，
您目前累计积分2680分。
```

用旁边的 `◀` `▶` 按钮可以切换查看第1条、第2条、第3条……建议至少检查前5条和最后2条数据，确认：

- 名字有没有乱码或错位
- 数字格式对不对（比如积分余额有没有多出奇怪的小数点）
- 整体排版有没有因为某个名字特别长而撑坏版面

> 💡 **提示**：如果发现某条数据有问题，回到Excel去修改数据源，然后在Word里点击"刷新"，预览结果就会更新。

## 9.7 合并输出：打印或保存为单独文件

预览没问题？那就执行最终合并！

点击 `邮件 > 完成并合并`，有三个选项：

| 选项 | 说明 | 适用场景 |
| ------ | ------ | --------- |
| **编辑单个文档** | 生成一个新的Word文件，里面包含所有合并后的文档 | 想再检查一遍或需要保存电子版 |
| **打印文档** | 直接发送到打印机 | 已经确认无误，直接打印 |
| **发送电子邮件** | 通过Outlook批量发邮件 | 电子邀请函 |

小王选了"编辑单个文档"。Word弹出一个对话框问他要合并哪些记录——选"全部"就好。

点击确定后，一个崭新的Word文档出现了，里面有300页——每一页就是一封完整的邀请函，每个人的名字、等级、积分、优惠码都不一样！

> 💡 **提示**：如果你想把每份文档保存为单独的文件（比如"张三.docx""李四.docx"），Word本身不直接支持这个功能，但可以用VBA宏来实现。网上搜索"邮件合并拆分单个文件 VBA"就能找到现成代码。

## 9.8 高级技巧：条件合并（IF域）、图片合并

**条件合并（IF域）**

有时候你想根据不同条件显示不同内容。比如，钻石会员多送一杯奶茶，其他等级不送。

在模板中需要插入一个IF规则：`邮件 > 规则 > 如果…那么…否则…`

设置逻辑为：

- 如果"会员等级"等于"钻石会员"
- 那么显示"额外赠送：招牌奶茶一杯🎁"
- 否则显示""（空着，什么都不显示）

这样，只有钻石会员的邀请函上才会出现那行赠品信息。

**图片合并**

如果你还想给每个会员印上专属头像？可以这样做：

1. 在数据源Excel中加一列"头像路径"，填入每个人头像图片的完整文件路径
2. 在模板中插入一个 `IncludePicture` 域，把域代码中的路径参数替换为合并域"«头像路径»"
3. 合并后，每份文档就会自动显示对应的头像

> 💡 **提示**：图片合并是邮件合并中最"坑"的功能。合并后可能需要按 `Ctrl + A` 全选再按 `F9` 刷新域，图片才会正确显示。建议先用5条数据测试一下。

## 9.9 实战：批量生成奶茶店300名会员的周年庆邀请函

让我们把整个流程串一遍，帮小王完成这次周年庆邀请函的批量生成：

**第一步：准备数据**

- 打开Excel，创建包含"姓名、会员等级、积分余额、优惠码、手机号"五列的表格
- 录入300名会员的数据
- 保存为"会员数据.xlsx"，关闭Excel

**第二步：设计模板**

- 打开Word，设计好邀请函的版式：店名用艺术字体、正文用宋体、配上周年庆的装饰边框
- 写好固定内容（活动时间、地点、祝福语等）

**第三步：连接数据源**

- `邮件 > 开始邮件合并 > 信函`
- `选择收件人 > 使用现有列表 > 选择"会员数据.xlsx"`

**第四步：插入合并域**

- 在对应位置插入"姓名""会员等级""积分余额""优惠码"
- 插入IF规则：钻石会员额外显示赠品信息

**第五步：预览检查**

- 点击"预览结果"，逐条检查前10条和最后5条
- 确认数据正确、排版美观

**第六步：合并输出**

- `完成并合并 > 编辑单个文档 > 全部`
- 生成300页的完整文档
- 检查无误后，发送到打印机批量打印

整个过程，真正操作的时间不超过15分钟。而小王之前手动改了23份就崩溃了……

> 💡 **提示**：邮件合并最花时间的其实不是操作，而是**准备数据源**。Excel里的数据质量直接决定了最终文档的质量。所以做数据表的时候，仔细一点，后面会省很多事。

## 本章小结

| 知识点 | 核心要点 |
| -------- | --------- |
| 邮件合并原理 | 模板（主文档）+ 数据源 = 批量文档 |
| 数据源要求 | Excel表格，首行为标题，无合并单元格 |
| 插入合并域 | `邮件 > 插入合并域`，选择对应字段 |
| 预览检查 | 用预览结果按钮逐条检查 |
| 合并输出 | 编辑单个文档 / 打印 / 发邮件 |
| 条件合并 | IF规则，根据条件显示不同内容 |
