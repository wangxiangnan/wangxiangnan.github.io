# 第7章 电气图纸的基本要素：图例、符号与文字标注

> [!TIP] Part II
> 电气识图

小王奶茶店装修进行到第三天，电工师傅老张甩过来一卷蓝晒图纸："小王，你看看图纸，确认一下插座位置。"小王满怀信心地展开图纸——然后整个人愣住了。满纸的线条、圆圈、三角、方框，像极了一锅煮糊的粉条。他指着图上一个带叉的圆圈问："张师傅，这是啥？"老张头也不抬："灯具。"小王又指一个方块加斜线："那这个呢？""插座。"小王心里默默感叹：这电气图纸简直就是另一门语言，没有字典根本读不了！

其实小王的困惑，每个初学者都经历过。电气图纸是电气工程师的"通用语言"，就像乐谱之于音乐家、棋谱之于棋手。要读懂这门语言，第一步就是掌握它的"字母""单词"和"语法"——也就是图例、符号和文字标注。本章我们就来逐一拆解这些基本要素。

## 7.1 电气图纸的分类：五种图纸各司其职

电气施工图并不是"一张图打天下"，而是由多种图纸组成的一个"家族"。按照功能不同，常见的电气图纸分为五大类。用水的类比来说：系统图就像供水管网的总览图，让你看清从水厂到每户的水管粗细和阀门位置；平面图就像管道在楼层里的实际走向布置图；原理图就像水龙头开关的控制逻辑图；接线图就像每个接头处的具体接线方式；安装图就像设备的安装大样图。

**系统图（也叫配电系统图）** 反映的是整个配电系统的层级关系和电气参数，是"鸟瞰全局"的图纸。它不关心设备装在哪儿、线管怎么走，只关心"谁给谁供电、用什么规格的保护器件"。

**平面图** 反映的是电气设备在建筑平面上的实际位置和线路走向。你可以把它理解为"俯视图"——站在天花板往下看，所有灯具、插座、开关、配电箱的位置一目了然。

**原理图（也叫电气原理图或控制原理图）** 表达的是电气控制逻辑。它不关心设备的物理位置，只关心"按下按钮A，接触器B吸合，电机C启动"这种因果关系。

**接线图** 是指导现场接线的详细图纸，标明每根导线接在端子排的哪个端子上。对于复杂的控制柜，接线图是电工师傅的"施工图"。

**安装图（大样图）** 针对某些特殊安装节点（如配电箱内部布置、电缆桥架安装方式）进行放大详表示。

对于初学者来说，最常打交道的是系统图和平面图，其次是原理图。接线图和安装图通常在较复杂的工程中才会出现。

## 7.2 图例表：图纸的"字典"

每张正规的电气图纸，都会在图纸的右上角或附页放一张**图例表**。图例表的作用相当于"字典"——它告诉你这张图纸里用到的每一个图形符号代表什么设备或元件。

为什么需要图例表？因为国家标准虽然规定了统一的电气符号（见GB/T 4728《电气简图用图形符号》），但实际工程中，不同设计院可能会在国标基础上做一些变通或补充。比如同样是灯具，国标符号是一个圆圈加叉，但有的设计院会在圆圈旁标注灯具型号来区分吸顶灯、筒灯和射灯。图例表的作用就是消除歧义——"在这张图纸里，这个符号就是这个意思，没有第二种解释。"

读图的第一步，永远是先看图例表。拿到一套图纸，不要急着看线条走向，先把图例表通读一遍，把每个符号"认脸"。这就像看一本外文书之前先翻翻词汇表，效率反而更高。

## 7.3 常用电气符号速查

下面是工程中最常见的一些电气符号，建议初学者反复记忆，做到"看到符号就知道是什么器件"：

| 符号描述 | 代表器件 | 记忆方法 |
| --------- | --------- | --------- |
| 长方形内标"QF" | 断路器（微型断路器MCB） | Q=开关，F=保护 |
| 长方形内标"QF"加一个圆圈 | 漏电保护断路器（RCBO） | 圆圈代表零序互感器，检测漏电 |
| 两个交叉的线段 | 接触器主触点 | 触点闭合=接通电路 |
| 长方形内标"KM" | 接触器线圈 | KM=Kontaktor（德语接触器） |
| 长方形内标"KA"或"K" | 中间继电器 | A=Auxiliary辅助 |
| 圆圈加叉 | 灯具 | 像灯泡发光 |
| 半圆加一竖线 | 插座 | 半圆像插座面板 |
| 斜线加一点 | 开关 | 像扳动开关的动作 |
| 圆圈加"M" | 电动机 | M=Motor |
| 波浪线 | 电缆/导线 | 像电线的形状 |

除了设备符号，还有一类**线路符号**需要注意：粗实线通常表示电力线路（强电），细实线或虚线表示控制线路或弱电线路，点划线表示线路的预留或规划部分。

## 7.4 文字标注规范：给图纸"贴标签"

光有图形符号还不够，图纸还需要大量的文字标注来传递具体参数。电气工程中的文字标注有一套严格的"语法"，主要包括以下几个方面。

**回路编号**：每个回路（可以理解为一个独立的"供电支路"，就像一根水管支路给一个水龙头供水）都有一个唯一编号。照明回路通常以"L"开头（Lighting），如L1、L2、L3；插座回路通常以"N"或"W"开头，如N1、N2、N3；空调等动力回路可能以"K"或"D"开头。编号的目的是方便施工和检修时快速定位——"二楼的N3回路跳闸了"，一看编号就知道是哪个插座回路。

**线径标注**：导线的截面积是核心参数。标注格式通常为"BV-3×2.5"，含义是：BV（铜芯聚氯乙烯绝缘导线）、3根（火线+零线+地线）、每根截面积2.5平方毫米。如果是电缆则可能标注为"YJV-5×10"，表示交联聚乙烯绝缘铜芯电缆，5芯，每芯10平方毫米。线径直接决定了导线能承载多大的电流——就像水管的粗细决定了能通过多大的水流量。

**管径标注**：导线穿管敷设时，需要标注线管的材质和直径。例如"PC20"表示直径20mm的PVC线管，"SC25"表示直径25mm的焊接钢管。管径必须与穿入的导线总截面积匹配——管子里穿太多线就像水管里塞太多东西，散热不好容易出事故。

**设备编号**：配电箱通常编号为"AL-1"（照明配电箱1号）、"AP-1"（动力配电箱1号）等。灯具可能编号为"1-G1"（一楼第一个灯具）。统一编号体系是施工管理和后期维护的基础。

## 7.5 图纸比例与图框

电气平面图通常与建筑平面图采用相同的比例，住宅工程最常用的是1:100（图上1厘米代表实际1米）。有些复杂节点会采用1:50的放大图。看图时务必注意比例尺——同样长度的一条线，在1:100图上代表1米，在1:50图上只代表0.5米。

每张图纸的外围都有一圈**图框**，图框内右下角是**标题栏**（又称图签），包含：项目名称、图纸名称、图纸编号、设计单位、设计人、审核人、日期、比例等信息。标题栏就像图纸的"身份证"，拿到图纸第一件事就是看标题栏，确认这是哪个项目、哪张图、什么版本。工程图纸最怕拿错版本——设计院改了好几版，施工队手里拿的还是旧版，那就麻烦了。

## 7.6 常见错误与注意事项

**错误一：不看图例就开始读图。** 这是最常见的新手错误。拿到图纸直接从线条开始看，结果把灯具符号认成接线盒，把开关符号认成插座。一定要养成"先看标题栏、再看图例表、最后看内容"的三步习惯。

**错误二：混淆不同图纸的符号体系。** 系统图和平面图中，同一个设备的表示方式可能不同。例如断路器在系统图中画一个完整的方框加文字标注，但在平面图中可能只用一个简化符号。不要用平面图的标准去读系统图，反之亦然。

**错误三：忽视文字标注。** 图形符号告诉你"这是什么"，文字标注告诉你"具体参数是多少"。只看符号不看标注，等于只知其一不知其二——知道那里有个断路器，但不知道它是16A还是32A、带不带漏保，施工时照样抓瞎。

**错误四：不同版本图纸混用。** 施工过程中图纸可能会出变更（设计变更通知单），如果只看原图不看变更单，很可能做错。现场一定要确认手中的图纸是最新有效版本。

## 本章小结

电气图纸分为系统图、平面图、原理图、接线图和安装图五大类，各有分工。图例表是图纸的"字典"，读图第一步就是看图例。常用电气符号需要反复记忆，文字标注（回路编号、线径、管径、设备编号）是读懂参数的关键。图纸比例和标题栏看似不起眼，却是最容易出错的细节。

## 练习题

1. 电气施工图通常分为哪五类？请分别说明它们的主要功能。

2. 图纸上标注"BV-3×4 PC25 FC"，请解释每个部分的含义。

3. 为什么说"先看图例表再看图纸内容"是正确的读图习惯？如果不看图例直接读图，可能出现什么问题？

4. 一张图纸的标题栏中写着"比例1:50"，图上量得某段线管长度为6厘米，请计算其实际长度。

5. 回路编号"L2"和"N3"分别代表什么类型的回路？这种编号方式有什么好处？

**参考答案**

1. 五类分别是：系统图（反映配电层级关系和电气参数）、平面图（反映设备在建筑中的实际位置和线路走向）、原理图（表达电气控制逻辑）、接线图（指导现场接线，标明端子号）、安装图（设备安装的详细大样图）。

2. BV表示铜芯聚氯乙烯绝缘导线；3×4表示3根导线，每根截面积4平方毫米；PC25表示穿直径25mm的PVC线管；FC表示地板暗敷（Floor Concealed）。

3. 因为不同设计院可能对国标符号做变通或补充，图例表是消除歧义的唯一依据。不查图例可能把不同器件搞混（如将灯具误认为接线盒），导致施工错误。

4. 实际长度 = 6cm × 50 = 300cm = 3米。

5. L2代表第二个照明回路（Lighting），N3代表第三个插座回路。编号方式的好处是便于施工定位和后期检修，一说编号就知道是哪个回路。
