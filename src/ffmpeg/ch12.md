# 第12章：截图与GIF——视频的另一面

一张好的截图胜过千言万语，一个恰到好处的 GIF 能让聊天氛围瞬间活跃起来。FFmpeg 不仅能处理视频，还是制作截图和 GIF 的利器。本章教你从视频中提取静态图片和动态 GIF。

## 12.1 单帧截图

**截取指定时间的单帧：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -frames:v 1 screenshot.jpg
```

- `-ss 00:01:30`：跳转到 1 分 30 秒
- `-frames:v 1`：只输出 1 帧

> 💡 提示：`-ss` 放在 `-i` 前面可以快速跳转，适合截图场景。如果需要精确到特定帧，把 `-ss` 放在 `-i` 后面。

**高质量截图（使用 PNG 格式）：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -frames:v 1 screenshot.png
```

**指定输出分辨率：**

```bash
ffmpeg -ss 00:01:30 -i input.mp4 -vf "scale=1920:-2" -frames:v 1 screenshot_hd.png
```

**截取视频第一帧（封面图）：**

```bash
ffmpeg -i input.mp4 -frames:v 1 -q:v 2 cover.jpg
```

`-q:v 2` 表示高质量 JPEG（范围 2-31，越小越好）。

## 12.2 批量截图

**每隔 N 秒截一张图：**

```bash
# 每 5 秒截一张
ffmpeg -i input.mp4 -vf "fps=1/5" screenshots/frame_%04d.jpg
```

`fps=1/5` 表示每 5 秒 1 帧。`%04d` 表示 4 位数字编号（0001, 0002, ...）。

**每 10 秒截一张高清 PNG：**

```bash
ffmpeg -i input.mp4 -vf "fps=1/10" screenshots/frame_%04d.png
```

**截取每一秒的帧（1fps）：**

```bash
ffmpeg -i input.mp4 -vf "fps=1" screenshots/frame_%04d.jpg
```

**每隔 N 帧截一张：**

```bash
# 每 30 帧截一张（假设 30fps 视频，即每秒截一张）
ffmpeg -i input.mp4 -vf "select=not(mod(n\,30))" -vsync vfr screenshots/frame_%04d.jpg
```

> 💡 提示：批量截图前记得先创建输出目录 `screenshots/`，否则 FFmpeg 会报错。

**生成视频缩略图网格（场景预览图）：**

```bash
# 每 30 秒截一张，排成 4x4 的网格
ffmpeg -i input.mp4 -vf "fps=1/30,scale=320:-2,tile=4x4" -frames:v 1 preview_grid.jpg
```

`tile=4x4` 将多张截图拼成一张 4 列 4 行的网格图。非常适合快速预览视频内容。

## 12.3 视频转 GIF 基础命令

**最简命令（但不推荐）：**

```bash
ffmpeg -i input.mp4 output.gif
```

这条命令能用，但生成的 GIF 通常又大又糊。原因是 GIF 只支持 256 色调色板，而 FFmpeg 默认使用通用调色板，无法针对你的视频内容优化。

**限制时间和尺寸的基本版本：**

```bash
ffmpeg -ss 00:00:10 -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" output.gif
```

- `-ss 00:00:10`：从第 10 秒开始
- `-t 5`：持续 5 秒
- `fps=15`：15 帧每秒（GIF 不需要 30fps）
- `scale=480:-1`：宽度 480px

## 12.4 GIF 质量优化：palettegen + paletteuse 二步法

这是制作高质量 GIF 的关键技术！核心思路：先分析视频内容生成最优调色板，再用这个调色板生成 GIF。

**第一步：生成调色板**

```bash
ffmpeg -ss 00:00:10 -i input.mp4 -t 5 -vf "fps=15,scale=480:-1,palettegen" palette.png
```

`palettegen` 滤镜分析视频内容，生成一个包含 256 种最优颜色的调色板图片。

**第二步：使用调色板生成 GIF**

```bash
ffmpeg -ss 00:00:10 -i input.mp4 -i palette.png -t 5 -lavfi "fps=15,scale=480:-1 [x]; [x][1:v] paletteuse" output.gif
```

`paletteuse` 滤镜使用我们生成的调色板来映射颜色，画质比默认方式好得多。

**一步到位的写法（使用 filter_complex）：**

```bash
ffmpeg -ss 00:00:10 -i input.mp4 -t 5 -filter_complex "fps=15,scale=480:-1,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" output.gif
```

`split` 滤镜将视频流分成两路，一路去生成调色板，另一路配合调色板生成 GIF。

> 💡 提示：二步法 vs 一步法效果相同。二步法的优势是你可以检查/手动编辑调色板图片，或者用同一个调色板处理多段视频保持色彩一致。

**调色板生成的进阶参数：**

```bash
# 使用 dithering（抖动）提升渐变效果
ffmpeg -i input.mp4 -i palette.png -lavfi "fps=15,scale=480:-1 [x]; [x][1:v] paletteuse=dither=sierra2_4a" output.gif

# 为每一帧生成独立的调色板（文件更大但质量更好）
ffmpeg -i input.mp4 -i palette.png -lavfi "fps=15,scale=480:-1 [x]; [x][1:v] paletteuse=new=1" output.gif
```

## 12.5 控制 GIF 尺寸、帧率、时长

| 参数 | 效果 | 推荐值 |
| ------ | ------ | -------- |
| fps | 帧率 | 10-15（GIF 不需要高帧率） |
| scale | 尺寸 | 宽度 320-480px |
| -t | 时长 | 3-10 秒 |

**不同场景的推荐参数：**

```bash
# 社交媒体分享（小文件，快速加载）
ffmpeg -i input.mp4 -t 5 -vf "fps=10,scale=320:-1,palettegen" palette.png
ffmpeg -i input.mp4 -i palette.png -t 5 -lavfi "fps=10,scale=320:-1 [x]; [x][1:v] paletteuse" social.gif

# 高质量展示（文件较大，画质好）
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=640:-1,palettegen" palette.png
ffmpeg -i input.mp4 -i palette.png -t 5 -lavfi "fps=15,scale=640:-1 [x]; [x][1:v] paletteuse" hq.gif

# 超小表情包
ffmpeg -i input.mp4 -t 3 -vf "fps=8,scale=200:-1,palettegen" palette.png
ffmpeg -i input.mp4 -i palette.png -t 3 -lavfi "fps=8,scale=200:-1 [x]; [x][1:v] paletteuse" emoji.gif
```

## 12.6 循环次数控制

```bash
# 无限循环（默认行为）
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" -loop 0 output.gif

# 循环 3 次后停止
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" -loop 3 output.gif

# 只播放一次（不循环）
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" -loop -1 output.gif
```

> 💡 提示：`-loop 0` 是无限循环（大多数 GIF 的默认行为），`-loop N` 循环 N 次，`-loop -1` 不循环。注意 `-loop` 参数要放在输出文件前面。

## 12.7 动态缩略图生成

**生成 GIF 预览（从视频中均匀取帧）：**

```bash
# 从 60 秒视频中均匀取 20 帧做成 GIF 预览
ffmpeg -i input.mp4 -vf "select='not(mod(n\,90))',setpts=N/20/TB,scale=320:-1,fps=2" -t 10 preview.gif
```

**生成 WebP 动图（比 GIF 更小更清晰）：**

```bash
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" -loop 0 -lossless 0 -quality 75 output.webp
```

**生成 APNG 动图（比 GIF 质量更高）：**

```bash
ffmpeg -i input.mp4 -t 5 -vf "fps=15,scale=480:-1" -plays 0 output.apng
```

## 12.8 GIF vs APNG vs WebP 动图对比

| 特性 | GIF | APNG | WebP |
| ------ | ----- | ------ | ------ |
| 文件大小 | 大 | 中 | 小 |
| 颜色数量 | 256 色 | 全彩 | 全彩 |
| 透明度 | 1-bit（全有/全无） | 完整 alpha | 完整 alpha |
| 浏览器兼容 | 全部 | 现代浏览器 | 现代浏览器 |
| 聊天软件支持 | 全部 | 部分 | 部分 |

**选择建议：**

- 社交平台/聊天：GIF（兼容性最好）
- 网页嵌入：WebP（文件小、质量高）
- 需要高质量透明动画：APNG

## 12.9 从 GIF 转回视频

```bash
# GIF 转 MP4
ffmpeg -i input.gif -c:v libx264 -pix_fmt yuv420p output.mp4
```

`-pix_fmt yuv420p` 确保像素格式兼容大多数播放器。

**GIF 转 MP4 并循环播放：**

```bash
# 将 GIF 循环 5 次后输出为 MP4
ffmpeg -stream_loop 4 -i input.gif -c:v libx264 -pix_fmt yuv420p output.mp4
```

**GIF 转 WebM：**

```bash
ffmpeg -i input.gif -c:v libvpx-vp9 output.webm
```

> 💡 提示：将 GIF 转成 MP4 后上传到社交平台，文件大小通常能减少 80% 以上，而且画质更好。很多平台（如 Twitter/X）实际上就是这么做的——你上传 GIF，它们自动转成视频。

## 本章小结

- 截图用 `-frames:v 1` 提取单帧，`fps=1/N` 批量截图
- GIF 制作必须用二步法（palettegen + paletteuse）才能保证画质
- 控制 GIF 大小的三个杠杆：降低帧率（fps）、缩小尺寸（scale）、缩短时长（-t）
- WebP 动图是 GIF 的现代替代品，更小更清晰但兼容性稍差
- GIF 转 MP4 可以大幅减小文件体积
