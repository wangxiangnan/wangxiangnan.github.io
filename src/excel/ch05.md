*小王的奶茶店开了三个月，数据越来越多了。他现在不只是要算总数，还想做更复杂的分析——"这个月销售额超过500元的有几天？""珍珠奶茶和芒果冰沙哪个卖得更好？""VIP客户的消费总额是多少？"小李说："你需要更多函数，它们就像瑞士军刀上的各种工具，各有各的用处。"*

## 5.1 条件判断：IF函数（含嵌套IF）

IF函数是Excel中最常用的逻辑函数，它的意思是：**"如果满足某个条件，就做一个事；不满足，就做另一个事。"**

**基本语法**

```
=IF(条件, 条件为真时的值, 条件为假时的值)
```

**例子**

假设小王给今天的每种商品定了一个标准：金额超过300元算"畅销"，否则算"一般"。

在E2输入：`=IF(D2>300,"畅销","一般")`

| 商品 | 金额 | 评价 |
| ------ | ------ | ------ |
| 珍珠奶茶 | 480 | 畅销 |
| 红豆奶茶 | 336 | 畅销 |
| 芒果冰沙 | 270 | 一般 |
| 抹茶拿铁 | 440 | 畅销 |
| 椰汁西米露 | 288 | 一般 |
| 黑糖鲜奶 | 350 | 畅销 |

**嵌套IF（多重条件）**

小王想分三个等级：金额 ≥ 400 为"爆款"，≥ 300 为"畅销"，< 300 为"一般"。

```
=IF(D2>=400,"爆款",IF(D2>=300,"畅销","一般"))
```

执行逻辑：

1. 先判断 D2 ≥ 400？是 → "爆款"；否 → 进入下一层
2. 再判断 D2 ≥ 300？是 → "畅销"；否 → "一般"

> 💡 **提示**：嵌套IF的层数不宜太多（超过3层就很难读了）。如果条件很多，可以考虑用IFS函数（Excel 2019+）：`=IFS(D2>=400,"爆款",D2>=300,"畅销",TRUE,"一般")`，更加清晰。

## 5.2 条件计数：COUNTIF、COUNTIFS

**COUNTIF —— 单条件计数**

```
=COUNTIF(区域, 条件)
```

例子：统计"畅销"的商品有几种？

```
=COUNTIF(E2:E7, "畅销")
```

→ 结果：`4`

统计金额超过300的有几种？

```
=COUNTIF(D2:D7, ">300")
```

→ 结果：`4`

> 💡 **提示**：条件中的比较运算符需要用双引号包裹，如 `">300"`、`"<>"`（不等于）。如果条件是引用某个单元格，写法是 `">"&A1`（用 `&` 连接运算符和单元格值）。

**COUNTIFS —— 多条件计数**

```
=COUNTIFS(区域1, 条件1, 区域2, 条件2, ...)
```

例子：统计"珍珠奶茶"在1月份销售超过30杯的天数？

```
=COUNTIFS(A2:A31, "珍珠奶茶", C2:C31, ">30")
```

## 5.3 条件求和：SUMIF、SUMIFS

**SUMIF —— 单条件求和**

```
=SUMIF(条件区域, 条件, 求和区域)
```

例子：计算所有"畅销"商品的总销售额？

```
=SUMIF(E2:E7, "畅销", D2:D7)
```

→ 480 + 336 + 440 + 350 = `1606`

**SUMIFS —— 多条件求和**

```
=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, ...)
```

例子：计算"珍珠奶茶"在1月1日到1月15日之间的总销售额？

```
=SUMIFS(D2:D31, A2:A31, "珍珠奶茶", B2:B31, ">="&DATE(2024,1,1), B2:B31, "<="&DATE(2024,1,15))
```

> 💡 **提示**：注意SUMIF和SUMIFS参数顺序不同！SUMIF是"条件区域→条件→求和区域"，SUMIFS是"求和区域→条件区域1→条件1→……"。很多人因此踩坑，记住"SUMIFS把求和区域放最前面"就好。

## 5.4 查找之王：VLOOKUP（精确匹配+近似匹配）

VLOOKUP可能是职场中使用频率最高的函数之一。它的作用是：**在一个表格中，根据某个关键字，查找对应的其他信息。**

**基本语法**

```
=VLOOKUP(查找值, 查找区域, 返回第几列, 匹配模式)
```

- **查找值**：你要找什么（比如商品名称）
- **查找区域**：在哪里找（必须是一个区域，且查找值在第一列）
- **返回第几列**：找到后返回该区域的第几列数据
- **匹配模式**：`FALSE` 或 `0` = 精确匹配；`TRUE` 或 `1` = 近似匹配

**精确匹配实例**

小王有一个价目表（在F1:G6）：

| F | G |
| --- | --- |
| 商品编码 | 单价 |
| P001 | 15 |
| P002 | 12 |
| P003 | 18 |
| P004 | 20 |
| P005 | 16 |

在销售记录中，他输入了商品编码"A列"，想让"B列"自动显示单价：

```
=VLOOKUP(A2, $F$2:$G$6, 2, FALSE)
```

如果A2是"P003"，函数会在F2:F6中查找"P003"，找到后返回同行的第2列（G列）的值 → `18`。

> 💡 **提示**：查找区域用绝对引用 `$F$2:$G$6` 锁定，这样公式往下拖时查找范围不会变。第四个参数写 `FALSE` 或 `0` 表示精确匹配（找不到就报错），写 `TRUE` 或 `1` 表示近似匹配（找不到精确值时返回最接近的较小值）。

**近似匹配实例**

小王给顾客设了会员等级：

| 累计消费 | 等级 |
| ---------- | ------ |
| 0 | 普通会员 |
| 500 | 银卡会员 |
| 1000 | 金卡会员 |
| 2000 | 钻石会员 |

某顾客累计消费了1350元，他的等级是？

```
=VLOOKUP(1350, $A$2:$B$5, 2, TRUE)
```

→ 返回"金卡会员"（1350在1000和2000之间，取1000对应的等级）

> ⚠️ **注意**：近似匹配要求查找区域的第一列必须**从小到大排序**，否则结果会出错。

## 5.5 VLOOKUP的常见问题与替代方案（XLOOKUP简介）

VLOOKUP虽然好用，但有一些"臭毛病"：

1. **只能从左往右查**：查找值必须在查找区域的第一列，不能反向查找。
2. **插入列会导致错误**：如果查找区域中间插入了一列，"返回第几列"的数字就不对了。
3. **默认近似匹配**：忘记写第四个参数 `FALSE` 时，默认是近似匹配，容易出错。

**XLOOKUP——新一代查找函数（Excel 2021 / Microsoft 365）**

```
=XLOOKUP(查找值, 查找列, 返回列, [找不到时的值], [匹配模式])
```

优点：

- 可以**从左往右或从右往左**查
- 不需要数"第几列"，直接指定返回列
- 默认**精确匹配**
- 找不到时可以自定义返回值

例子（等价于上面的VLOOKUP）：

```
=XLOOKUP(A2, $F$2:$F$6, $G$2:$G$6, "未找到")
```

> 💡 **提示**：如果你的Excel版本支持XLOOKUP，强烈建议用它替代VLOOKUP。但如果你的文件需要分享给用老版本Excel的人，VLOOKUP仍然是更安全的选择。

## 5.6 文本函数：LEFT、RIGHT、MID、LEN、CONCATENATE

Excel不仅能处理数字，也能处理文本。以下是最常用的文本函数：

**LEFT、RIGHT、MID —— 截取文本**

```
=LEFT("珍珠奶茶", 2)    → "珍珠"（从左取2个字符）
=RIGHT("2024-01-15", 2) → "15"（从右取2个字符）
=MID("2024-01-15", 6, 2) → "01"（从第6位开始取2个字符）
```

**LEN —— 文本长度**

```
=LEN("珍珠奶茶")  → 4
=LEN("Hello")     → 5
```

**CONCATENATE / & —— 文本连接**

```
=CONCATENATE(A1, "-", B1)  等价于  =A1 & "-" & B1
```

如果A1是"珍珠奶茶"，B1是"大杯"，结果就是"珍珠奶茶-大杯"。

**TEXT —— 格式化文本**

```
=TEXT(1234.5, "¥#,##0.00") → "¥1,234.50"
=TEXT(TODAY(), "yyyy年mm月dd日") → "2024年01月15日"
```

**奶茶店实例**

小王有一列订单编号，格式为"DD-20240115-001"（DD开头-日期-序号），他想拆分出日期部分：

```
=MID(A2, 4, 8)  → "20240115"
```

再转换成日期：

```
=DATE(MID(A2,4,4), MID(A2,8,2), MID(A2,10,2))  → 2024/1/15
```

## 5.7 日期函数：TODAY、NOW、DATEDIF、YEAR/MONTH/DAY

**TODAY 和 NOW**

```
=TODAY()  → 今天的日期（如 2024/1/15），每次打开文件自动更新
=NOW()    → 今天的日期和时间（如 2024/1/15 14:30），精确到秒
```

**YEAR、MONTH、DAY —— 提取日期部分**

```
=YEAR("2024/1/15")   → 2024
=MONTH("2024/1/15")  → 1
=DAY("2024/1/15")    → 15
```

**DATEDIF —— 计算两个日期之间的差**

```
=DATEDIF(开始日期, 结束日期, "单位")
```

单位可以是：

- `"Y"`：相差的完整年数
- `"M"`：相差的完整月数
- `"D"`：相差的天数

例子：某员工入职日期是2023年3月15日，算他工作了多久？

```
=DATEDIF("2023/3/15", TODAY(), "M")  → 大约10个月
```

> 💡 **提示**：DATEDIF是一个"隐藏函数"——Excel不会在自动补全中提示它，但它确实存在并且非常好用。你需要手动完整输入函数名。

## 5.8 实战：奶茶店月度销售分析（综合运用多个函数）

让我们综合运用本章学到的函数，帮小王做一份月度销售分析。

**数据基础**

假设"日销售记录"工作表有1月份30天的数据，每天记录了多种商品的销售额。我们来做以下分析：

**分析一：给每天的营业额评级**

```
=IF(日销售记录!D9>=2000, "优秀", IF(日销售记录!D9>=1500, "良好", "需改进"))
```

**分析二：统计各等级的天数**

```
=COUNTIF(F2:F31, "优秀")     → 优秀天数
=COUNTIF(F2:F31, "良好")     → 良好天数
=COUNTIF(F2:F31, "需改进")   → 需改进天数
```

**分析三：计算"珍珠奶茶"的月度总销售额**

```
=SUMIF(日销售记录!A2:A200, "珍珠奶茶", 日销售记录!D2:D200)
```

**分析四：用VLOOKUP查找某商品的详细信息**

```
=VLOOKUP("珍珠奶茶", 商品价目表!A2:C10, 2, FALSE)  → 返回单价
```

**分析五：计算本月已过天数和剩余天数**

```
已过天数：=DAY(TODAY())
本月总天数：=DAY(EOMONTH(TODAY(),0))
剩余天数：=DAY(EOMONTH(TODAY(),0)) - DAY(TODAY())
```

**分析六：拼接生成报告标题**

```
="小王奶茶店" & TEXT(TODAY(),"yyyy年m月") & "销售分析报告"
```

→ "小王奶茶店2024年1月销售分析报告"

> 💡 **提示**：真正的数据分析往往是多个函数组合使用的。不要怕公式长——把它拆解成一小步一小步来想，每一步做什么都清楚，组合起来就不难了。
