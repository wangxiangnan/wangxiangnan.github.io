# 第6章：结构体与方法

Part II：核心数据结构

## 从"名片"到"结构体"

想象你要设计一个用户系统。在 Python 里你可能用字典：`{"name": "张三", "age": 25, "email": "zhang@example.com"}`。在 Java 里你用 class。Rust 的方案是 **struct（结构体）**——它比字典更安全，比 class 更简洁。

## 定义结构体

```rust
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    // 创建实例
    let user1 = User {
        name: String::from("张三"),
        email: String::from("zhang@example.com"),
        age: 25,
        active: true,
    };

    // 访问字段
    println!("姓名: {}", user1.name);
    println!("邮箱: {}", user1.email);
}
```

## 修改字段

```rust
struct Point {
    x: f64,
    y: f64,
}

fn main() {
    let mut p = Point { x: 0.0, y: 0.0 };  // 需要 mut 才能修改
    p.x = 3.0;
    p.y = 4.0;
    println!("点: ({}, {})", p.x, p.y);
}
```

## 字段初始化简写

当变量名和字段名相同时，可以简写：

```rust
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

fn create_user(name: String, email: String, age: u32) -> User {
    User {
        name,      // 等同于 name: name
        email,     // 等同于 email: email
        age,       // 等同于 age: age
        active: true,
    }
}

fn main() {
    let user = create_user(
        String::from("李四"),
        String::from("li@example.com"),
        30,
    );
    println!("{}: {}", user.name, user.email);
}
```

## 结构体更新语法

```rust
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    let user1 = User {
        name: String::from("张三"),
        email: String::from("zhang@example.com"),
        age: 25,
        active: true,
    };

    // 基于 user1 创建 user2，只修改部分字段
    let user2 = User {
        name: String::from("李四"),
        email: String::from("li@example.com"),
        ..user1   // 其余字段从 user1 复制（注意：String 字段是移动，不是复制！）
    };

    println!("{} / {}", user2.name, user2.age);
    // println!("{}", user1.name);  // 编译错误！name 已移动到 user2
}
```

## 元组结构体

没有字段名的结构体，适合简单封装：

```rust
struct Color(u8, u8, u8);      // RGB颜色
struct Point(f64, f64, f64);    // 三维坐标
struct Meters(f64);             // 单位封装（Newtype模式）

fn main() {
    let red = Color(255, 0, 0);
    let origin = Point(0.0, 0.0, 0.0);
    let distance = Meters(42.5);

    println!("红色: ({}, {}, {})", red.0, red.1, red.2);
    println!("距离: {} 米", distance.0);
}
```

## 单元结构体

没有任何字段的结构体，主要用于 trait 实现（后续章节会用到）：

```rust
struct Marker;  // 单元结构体

fn main() {
    let _m = Marker;
    println!("单元结构体实例已创建");
}
```

## impl 块：方法

Rust 没有 class 关键字，但通过 `impl`（implementation）块给结构体添加方法：

```rust
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    // 方法：第一个参数是 self 的某种形式
    fn area(&self) -> f64 {
        self.width * self.height
    }

    fn perimeter(&self) -> f64 {
        2.0 * (self.width + self.height)
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }

    // 可变方法：修改自身
    fn scale(&mut self, factor: f64) {
        self.width *= factor;
        self.height *= factor;
    }
}

fn main() {
    let mut rect = Rectangle { width: 10.0, height: 5.0 };

    println!("面积: {}", rect.area());
    println!("周长: {}", rect.perimeter());
    println!("是正方形吗？{}", rect.is_square());

    rect.scale(2.0);
    println!("缩放后面积: {}", rect.area());
}
```

## self、&self、&mut self 的区别

| 签名 | 含义 | 类比 |
| ------ | ------ | ------ |
| `fn method(&self)` | 不可变借用 | Python 的 `def method(self)` |
| `fn method(&mut self)` | 可变借用 | 需要 `mut` 实例 |
| `fn method(self)` | 获取所有权（消费自身） | 调用后实例不可用 |

```rust
struct Counter {
    count: u32,
}

impl Counter {
    // &self：只读
    fn display(&self) {
        println!("计数: {}", self.count);
    }

    // &mut self：可修改
    fn increment(&mut self) {
        self.count += 1;
    }

    // self：消耗自身，调用后 counter 不再可用
    fn into_count(self) -> u32 {
        self.count
    }
}

fn main() {
    let mut counter = Counter { count: 0 };
    counter.increment();
    counter.increment();
    counter.display();

    let final_count = counter.into_count();
    println!("最终计数: {final_count}");
    // counter.display();  // 编译错误！counter 已被消费
}
```

## 关联函数（没有 self 的函数）

不需要实例就能调用的函数，类似其他语言的静态方法：

```rust
struct Circle {
    radius: f64,
}

impl Circle {
    // 关联函数：用 :: 调用
    fn new(radius: f64) -> Self {
        Circle { radius }
    }

    // 另一个构造函数
    fn unit_circle() -> Self {
        Circle { radius: 1.0 }
    }

    fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }
}

fn main() {
    let c1 = Circle::new(5.0);       // :: 调用关联函数
    let c2 = Circle::unit_circle();

    println!("c1 面积: {:.2}", c1.area());
    println!("c2 面积: {:.2}", c2.area());
}
```

## 与 OOP 语言的类对比

| 特性 | Java/Python class | Rust struct |
| ------ | ------------------- | ------------- |
| 数据+方法 | 在一起 | 分开（struct + impl） |
| 继承 | 有 | 无（用组合和 trait 替代） |
| 访问控制 | public/private/protected | pub（默认私有） |
| 构造函数 | `new()` / `__init__` | 约定俗成用 `new` 关联函数 |

## 常见陷阱

1. **忘记 `&self`**：方法第一个参数不写 self 会变成关联函数
2. **`..` 更新语法会移动所有权**：String 字段会被移动，原结构体部分字段失效
3. **Debug 打印**：`println!("{:?}", rect)` 会报错，需要在 struct 上加 `#[derive(Debug)]`

```rust
#[derive(Debug)]
struct Rectangle {
    width: f64,
    height: f64,
}

fn main() {
    let rect = Rectangle { width: 10.0, height: 5.0 };
    println!("{:?}", rect);    // Rectangle { width: 10.0, height: 5.0 }
    println!("{:#?}", rect);   // 格式化多行输出
}
```

## 小结

- `struct` 定义结构体，是数据和行为的载体
- `impl` 块定义方法和关联函数
- `&self` 只读，`&mut self` 可写，`self` 消费
- 关联函数用 `::` 调用，通常用于构造函数
- Rust 没有继承，用组合和 trait 实现多态
