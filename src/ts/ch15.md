# 第十五章：最佳实践与总结

## 最佳实践

1. **开启 `strict: true`**：这是最值得开启的选项，没有之一。
2. **避免 `any`**：尽量用 `unknown`、泛型或更精确的类型替代。
3. **优先用 `interface` 描述对象**：需要联合类型、交叉类型时用 `type`。
4. **函数返回值尽量显式声明**：这会让你的函数契约更清晰。
5. **善用内置工具类型**：`Partial`、`Pick`、`Omit`、`ReturnType` 等能节省大量代码。
6. **类型导入导出用 `type` 修饰**：在 `isolatedModules` 模式下这是必须的。
7. **写测试的同时做类型检查**：`tsc --noEmit` 应该成为 CI 的一部分。

## 学习路线建议

如果你刚学完这篇文章，可以按照下面的路线继续深入：

1. 先在你自己的项目里把 `strict` 打开，把报错逐个修复。
2. 学习泛型的高级用法：泛型约束、条件类型、`infer`、映射类型。
3. 尝试为一个纯 JavaScript 库写 `.d.ts` 声明文件。
4. 阅读 TypeScript 官方文档的 "Handbook" 和 "Reference" 部分。
5. 关注 TypeScript 的 release notes，了解新特性。

## 写在最后

TypeScript 不是银弹，它不会自动让你的代码变优雅。但它提供了一套强大的工具，帮助你在写代码时思考得更清楚。

刚开始用 TypeScript 时，你可能会觉得类型系统是一种束缚。但用久了你会发现，**类型不是枷锁，而是护栏**。它让你在安全的道路上开得更快，而不是把你困在原地。

希望这篇教程能帮你跨过 TypeScript 的入门门槛，走向更可靠的工程化开发。
