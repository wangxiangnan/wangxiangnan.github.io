# 第7章：枚举与模式匹配

## 状态机的天然表达

想象你要表示交通灯：红、黄、绿三种状态。在 Java 里你会用 `enum`，但它只是整数常量。在 Python 里你可能用字符串 `"red"`、`"yellow"`、`"green"`，但拼错了也不会报错。

Rust 的枚举不仅类型安全，而且**每个变体可以携带不同类型的数据**——这是其他语言里几乎找不到的超能力。

## 定义枚举

```rust
// 简单枚举
enum Direction {
    North,
    South,
    East,
    West,
}

// 携带数据的枚举
enum IpAddress {
    V4(u8, u8, u8, u8),             // 变体携带四个 u8
    V6(String),                       // 变体携带一个 String
}

// 混合类型
enum Message {
    Quit,                            // 无数据
    Move { x: i32, y: i32 },         // 匿名结构体
    Write(String),                   // 一个 String
    ChangeColor(u8, u8, u8),         // 三个 u8
}

fn main() {
    let dir = Direction::North;
    let home = IpAddress::V4(127, 0, 0, 1);
    let loopback = IpAddress::V6(String::from("::1"));

    let msg1 = Message::Quit;
    let msg2 = Message::Move { x: 10, y: 20 };
    let msg3 = Message::Write(String::from("Hello"));

    println!("方向和地址已创建");
}
```

## 在枚举上定义方法

```rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

impl Coin {
    fn value_in_cents(&self) -> u32 {
        match self {
            Coin::Penny => 1,
            Coin::Nickel => 5,
            Coin::Dime => 10,
            Coin::Quarter => 25,
        }
    }

    fn describe(&self) -> &str {
        match self {
            Coin::Penny => "一分",
            Coin::Nickel => "五分",
            Coin::Dime => "一角",
            Coin::Quarter => "两角五",
        }
    }
}

fn main() {
    let coin = Coin::Quarter;
    println!("{} = {} 分", coin.describe(), coin.value_in_cents());
}
```

## `Option<T>`：消灭 null 的设计

Tony Hoare 在1965年发明了 null 引用，后来称之为"价值十亿美元的错误"。Rust 没有 null，取而代之的是 `Option<T>`：

```rust
// Option 的定义（标准库中已定义，你不需要自己写）
// enum Option<T> {
//     Some(T),
//     None,
// }

fn find_user(id: u32) -> Option<String> {
    if id == 1 {
        Some(String::from("张三"))
    } else {
        None
    }
}

fn main() {
    let user = find_user(1);
    match user {
        Some(name) => println!("找到用户: {name}"),
        None => println!("用户不存在"),
    }

    let missing = find_user(99);
    match missing {
        Some(name) => println!("找到: {name}"),
        None => println!("用户不存在"),
    }

    // 使用 unwrap_or 提供默认值
    let name = find_user(99).unwrap_or(String::from("匿名用户"));
    println!("{name}");
}
```

> **核心理念**：在 Python/Java/JS 中，任何引用都可能是 null，你必须时刻警惕空指针。在 Rust 中，如果一个值可能是"不存在的"，必须用 `Option<T>` 显式表达，编译器强制你处理 `None` 的情况。

## match 表达式详解

`match` 是 Rust 最强大的控制流工具：

```rust
#[derive(Debug)]
enum PaymentMethod {
    Cash,
    CreditCard(String),    // 卡号
    MobilePay {
        platform: String,
        discount: f64,
    },
}

fn process_payment(method: &PaymentMethod, amount: f64) {
    match method {
        PaymentMethod::Cash => {
            println!("现金支付: {} 元", amount);
        }
        PaymentMethod::CreditCard(card) => {
            println!("信用卡 {} 支付: {} 元", card, amount);
        }
        PaymentMethod::MobilePay { platform, discount } => {
            let final_amount = amount * (1.0 - discount);
            println!("{platform} 支付: {final_amount:.2} 元（折扣 {discount}）");
        }
    }
}

fn main() {
    let cash = PaymentMethod::Cash;
    let card = PaymentMethod::CreditCard(String::from("6222****1234"));
    let mobile = PaymentMethod::MobilePay {
        platform: String::from("支付宝"),
        discount: 0.1,
    };

    process_payment(&cash, 100.0);
    process_payment(&card, 200.0);
    process_payment(&mobile, 300.0);
}
```

### match 中的模式

```rust
fn describe_number(n: i32) -> &'static str {
    match n {
        0 => "零",
        1..=9 => "个位数",
        10 | 20 | 30 => "整十",
        x if x < 0 => "负数",          // 匹配守卫（guard）
        100..=999 => "三位数",
        _ => "其他",                     // 通配符
    }
}

fn main() {
    for n in [-5, 0, 3, 10, 50, 200, 1000] {
        println!("{n}: {}", describe_number(n));
    }
}
```

## if let 与 while let

当只关心一种匹配情况时，`match` 有点啰嗦。`if let` 是简化版：

```rust
fn main() {
    let config_max: Option<u32> = Some(100);

    // 用 match
    match config_max {
        Some(max) => println!("最大值设为 {max}"),
        None => {}  // 什么都不做——很丑
    }

    // 用 if let（简洁！）
    if let Some(max) = config_max {
        println!("最大值设为 {max}");
    }

    // if let 也可以有 else
    let name: Option<String> = None;
    if let Some(n) = name {
        println!("名字: {n}");
    } else {
        println!("没有名字");
    }

    // while let：循环直到模式不匹配
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("弹出: {top}");
    }
    println!("栈已空");
}
```

## 用枚举实现链表（预览）

```rust
enum List {
    Cons(i32, Box<List>),  // Box 是堆上分配的指针
    Nil,                    // 链表结束
}

use List::{Cons, Nil};

fn main() {
    let list = Cons(1,
        Box::new(Cons(2,
            Box::new(Cons(3,
                Box::new(Nil))))));

    // 打印链表
    let mut current = &list;
    loop {
        match current {
            Cons(val, next) => {
                print!("{val} -> ");
                current = next;
            }
            Nil => {
                println!("Nil");
                break;
            }
        }
    }
}
```

> `Box<T>` 是在堆上分配数据的智能指针，这里用它是因为链表节点的大小在编译时不确定（递归类型）。

## 常见陷阱

1. **match 不覆盖所有情况**：编译器会强制报错，不要试图用 `_` 偷懒
2. **Option 的 unwrap()**：在 None 上调用 unwrap() 会 panic，只在确定有值时使用
3. **忘记 Box**：递归枚举必须用 `Box` 包装，否则编译器算不出大小
4. **match 中的变量遮蔽**：match 臂中的变量会创建新绑定

## 小结

- 枚举变体可以携带任意类型的数据，这是 Rust 枚举的杀手级特性
- `Option<T>` 替代了 null，编译器强制处理"值不存在"的情况
- `match` 必须穷尽所有可能，支持解构、守卫、通配符
- `if let` 和 `while let` 是 match 的简化写法
