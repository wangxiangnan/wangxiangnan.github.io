# 第 1 章 Python 的安装与环境配置

想象你要学做蛋糕，第一件事不是研究配方，而是先买一个烤箱。编程也一样——在写出第一行代码之前，你得先把 Python 装到电脑上，再准备好一个顺手的编辑器。这一章，我们手把手带你搞定"厨房"的全部准备工作。

很多新手会觉得"安装软件"这个步骤太简单了，不值得专门用一章来讲。但实际上，环境配置是最容易出问题、也最容易浪费时间的环节之一。不同的操作系统有不同的坑，不同的编辑器有不同的配置方式，虚拟环境的概念对新手来说更是全新的。所以，我们宁愿在这一章多花点时间，把可能遇到的问题提前讲清楚，也不希望你后面因为环境问题卡住而失去学习的热情。

## 1.1 下载并安装 Python

Python 的官方"家"在 [python.org](https://www.python.org)。打开网站，点击首页那个醒目的黄色按钮 **Download Python 3.x.x**，浏览器会自动帮你选择适合当前操作系统的安装包。

**Windows 用户**需要注意一个"经典坑"：运行安装程序时，安装界面底部有一个复选框写着 **Add Python to PATH**，默认是**不勾选**的。请务必勾上它。如果不勾，你在命令行输入 `python` 时，系统会说"找不到这个命令"，然后你会花半小时在各种论坛里找答案——其实就一个勾的事。

勾选之后点 **Install Now**，等待安装完成即可。安装完成后，打开命令提示符（按 `Win + R`，输入 `cmd`，回车），输入：

```python
python --version
```

如果看到类似 `Python 3.12.x` 的输出，恭喜你，Python 已经成功入住你的电脑了。

**macOS 用户**从 python.org 下载 `.pkg` 安装包，双击安装即可。安装完成后打开终端（Terminal），同样输入 `python3 --version` 验证。macOS 自带的 `python3` 可能版本较旧，建议始终使用官网安装的最新版本。

**Linux 用户**通常系统已经预装了 Python。打开终端输入 `python3 --version` 查看。如果需要更新，可以用包管理器：

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install python3

# Fedora
sudo dnf install python3
```

## 1.2 选择你的"武器"：编辑器与 IDE

Python 代码本质上是纯文本文件，理论上用记事本就能写。但好的编辑器能让你的效率翻好几倍——语法高亮、自动补全、错误提示、一键运行，这些功能就像游戏里的辅助装备，让你少走弯路。

### VS Code：轻量全能选手

[Visual Studio Code](https://code.visualstudio.com)（简称 VS Code）是微软出品的免费编辑器，轻量、快速、插件生态极其丰富。安装 VS Code 后，打开扩展商店（左侧方块图标），搜索 **Python**，安装微软官方的 Python 扩展即可。装好后，VS Code 会自动识别你安装的 Python 解释器，提供智能补全（IntelliSense）、代码格式化、调试等功能。

VS Code 的优点是启动快、占用内存小、对多种语言都有良好支持。如果你以后还要学前端、Go、Rust 等语言，VS Code 可以一站式搞定。

### PyCharm：Python 专业 IDE

[PyCharm](https://www.jetbrains.com/pycharm/) 是 JetBrains 公司专门为 Python 打造的集成开发环境（IDE）。它的社区版（Community Edition）是免费的，对初学者来说完全够用。PyCharm 的优势在于"开箱即用"——不用折腾插件，Python 开发需要的功能它全都有：智能补全、代码检查、重构工具、内置终端、数据库管理等等。

如果你确定自己会长期深入学习 Python，PyCharm 是更好的选择。缺点是启动稍慢、内存占用比 VS Code 大一些。

### 本书的建议

如果你是编程新手，推荐先用 **VS Code**——它更轻量，配置过程本身也是一种学习。如果你有一定经验，或者喜欢"全家桶"式的体验，**PyCharm** 会让你更省心。无论你选哪个，本书的代码示例都可以在任何一个编辑器中运行。

### Jupyter Notebook：边写边看的"实验笔记本"

除了 VS Code 和 PyCharm，还有一个工具值得介绍：**Jupyter Notebook**。它让你在一个网页界面中编写代码、运行代码、查看结果，并且支持在代码之间插入文字说明和图表。Jupyter 在数据分析和数据科学领域特别流行，因为你可以一段一段地运行代码，实时看到每一步的结果——就像在实验室里做实验，一边操作一边记录。

安装 Jupyter 非常简单：

```bash
pip install jupyter
```

安装完成后，在终端输入 `jupyter notebook`，浏览器会自动打开一个本地页面，你可以在里面创建和编辑笔记本文件（`.ipynb` 格式）。对于初学者来说，Jupyter 是一个很好的学习工具——你可以逐个代码块运行，不用担心一次跑完整个程序。不过本书的主要示例还是以 `.py` 文件为主，因为这是实际开发中最常用的形式。

### 命令行基础：程序员的"驾驶舱"

不管你选哪个编辑器，你都需要学会一些基本的命令行操作。命令行（也叫终端、控制台）是程序员最常用的工具之一，你可以用它来运行程序、安装软件包、管理文件等。

**Windows 用户**：按 `Win + R`，输入 `cmd` 回车打开命令提示符；或者搜索 "PowerShell" 打开更强大的终端。

**macOS 用户**：按 `Command + 空格`，搜索 "Terminal" 打开终端。

**常用命令**：

```bash
# 查看当前目录
# Windows:
cd
# macOS/Linux:
pwd

# 切换目录
cd 路径名

# 列出当前目录下的文件
# Windows:
dir
# macOS/Linux:
ls

# 返回上一级目录
cd ..

# 创建新目录
mkdir my_project

# 进入新创建的目录
cd my_project
```

这些命令看起来简单，但你以后会反复用到它们。建议现在就在终端里练习几下——创建一个文件夹，进去，再退出来，感受一下"用键盘操作电脑"的感觉。

## 1.3 虚拟环境：给项目一个独立的"房间"

假设你在做两个项目：项目 A 需要某个库的 1.0 版本，项目 B 需要同一个库的 2.0 版本，而这两个版本不兼容——怎么办？

答案是**虚拟环境**（Virtual Environment）。你可以把它理解为给每个项目分配一个独立的"房间"，房间里装什么工具（库）完全由你自己决定，互不干扰。

Python 自带了 `venv` 模块，用起来非常简单。打开终端，进入你的项目目录，输入：

```bash
# 创建虚拟环境，文件夹名为 venv
python -m venv myenv

# 激活虚拟环境
# Windows:
myenv\Scripts\activate
# macOS / Linux:
source myenv/bin/activate
```

激活后，你的命令行提示符前面会出现 `(myenv)` 字样，表示当前处于这个虚拟环境中。此时用 `pip install` 安装的任何库都只会装在这个环境里，不影响全局。

退出虚拟环境只需输入：

```bash
deactivate
```

养成好习惯：每开始一个新项目，先创建一个虚拟环境。这就像做饭前先把砧板擦干净——防止上次的"残留"污染这次的"菜品"。

## 1.4 pip：Python 的"应用商店"

pip 是 Python 的包管理工具（Package Installer for Python），用来安装和管理第三方库。安装 Python 时 pip 会自动附带，无需单独安装。

常用命令：

```bash
# 安装一个库
pip install requests

# 安装指定版本
pip install requests==2.31.0

# 卸载
pip uninstall requests

# 查看已安装的库
pip list

# 升级 pip 自身（建议定期执行）
python -m pip install --upgrade pip
```

如果你在国内，默认的安装源可能比较慢。可以配置国内镜像源加速：

```bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

常用的国内镜像有清华源、中科大源、阿里云源等，速度差异不大，选一个离你近的就行。

## 1.5 运行你的第一行 Python 代码

一切准备就绪，让我们来验证一下。在开始之前，先简单了解一下 Python 是怎么"读懂"你的代码的。

当你运行一个 `.py` 文件时，Python 实际上经历了两个步骤：首先，它把你的源代码（人类可读的文本）编译成一种叫做**字节码**（bytecode）的中间格式；然后，由 Python 虚拟机（PVM，Python Virtual Machine）逐条执行字节码。这个过程对你来说是透明的——你不需要手动编译，Python 会自动处理。这就是 Python 被称为"解释型语言"的原因：虽然底层有编译步骤，但用户感知到的体验是"写完就能跑"。

另外，当你用 `import` 导入一个模块时，Python 会生成一个 `__pycache__` 文件夹，里面存放编译好的 `.pyc` 文件（字节码缓存）。下次导入同一模块时，Python 可以直接加载 `.pyc` 文件，跳过编译步骤，加快启动速度。你不需要关心这些文件，但如果在项目目录里看到 `__pycache__` 文件夹，不要惊慌——它是正常产物，可以安全删除（下次导入时会自动重新生成）。

现在打开命令行，输入 `python`（macOS/Linux 用 `python3`），进入 Python 的交互式环境（REPL）：

```python
>>> 1 + 1
2
>>> print("你好，Python！")
你好，Python！
>>> 3 * 7
21
```

在这个环境里，你输入一行代码，Python 立刻给你结果。输入 `exit()` 或按 `Ctrl + Z`（Windows）/ `Ctrl + D`（macOS/Linux）退出。

这个交互式环境特别适合快速验证想法——比如你不确定 `2 ** 10` 等于多少，直接敲进去就知道了。很多有经验的程序员也经常用它来做"草稿纸"。

当然，写正式程序的时候，我们会把代码保存在 `.py` 文件里。创建一个文件 `hello.py`，写入：

```python
# 我的第一个 Python 文件
print("Hello, World!")
print("Python，我来了！")
```

然后在终端中运行：

```bash
python hello.py
```

屏幕上会依次打印出两行文字。就这么简单——你已经迈出了编程的第一步。

## 1.6 选择 Python 版本与编辑器配置小贴士

Python 目前有 Python 2 和 Python 3 两大版本，Python 2 已于 2020 年正式停止维护，所有新项目都应该使用 **Python 3**。但 Python 3 本身也在不断迭代，从 3.6 到 3.12 再到未来的 3.13，每个版本都会引入新特性。本书基于 **Python 3.11+** 编写，其中涉及的大部分语法在 3.8 以上版本都能运行。如果你使用的是更老的版本（如 3.7、3.6），某些特性（如 `match-case`、海象运算符 `:=`）可能不可用。

### VS Code 的实用配置

如果你选择了 VS Code，以下配置能显著提升你的开发体验：

1. **设置 Python 解释器**：按 `Ctrl + Shift + P`，搜索 "Python: Select Interpreter"，选择你安装的 Python 版本。
2. **安装推荐扩展**：除了官方 Python 扩展，还可以安装 Pylance（更智能的代码分析）、autopep8（自动代码格式化）和 Python Debugger。
3. **创建运行配置**：打开设置（`Ctrl + ,`），搜索 "Run Code"，勾选 "Run In Terminal"，这样运行代码时会在终端中显示输出，方便调试。
4. **开启自动保存**：在设置中搜索 "Auto Save"，选择 "afterDelay"，省去频繁按 `Ctrl + S` 的麻烦。

### PyCharm 的快速上手

如果你选择了 PyCharm，首次打开时会看到欢迎界面。创建一个新项目时，PyCharm 会自动帮你创建虚拟环境（也可以手动选择已有的解释器）。项目创建后，你可以直接右键点击 `.py` 文件选择 "Run"，或者使用快捷键 `Shift + F10` 运行当前文件。PyCharm 底部的 "Terminal" 标签可以直接打开内置终端，不用切换到外面的命令行窗口。

## 1.7 小结

- Python 从 python.org 下载安装，Windows 用户务必勾选 **Add Python to PATH**。
- 编辑器推荐 VS Code（轻量灵活）或 PyCharm（功能全面），选择取决于你的使用习惯。
- 虚拟环境（`venv`）为每个项目创建独立的依赖空间，避免库版本冲突。
- pip 是 Python 的包管理工具，用来安装第三方库。
- `python`（或 `python3`）命令可以进入交互式环境，也可以用来运行 `.py` 文件。

## 1.10 常见错误与避坑

- **`python` 命令找不到**：99% 是因为安装时没有勾选 Add Python to PATH。解决方法：重新运行安装程序，选 Modify，勾上 PATH 选项；或者手动添加环境变量。
- **macOS 上 `python` 和 `python3` 搞混**：macOS 可能自带旧版 Python 2，用 `python3` 明确调用 Python 3。
- **虚拟环境激活失败**：Windows 下如果用 PowerShell，可能需要先修改执行策略：`Set-ExecutionPolicy Unrestricted -Scope CurrentUser`。
- **pip 安装很慢或超时**：换用国内镜像源（如清华源），不要死等默认源。
- **多个 Python 版本冲突**：如果电脑上装了多个 Python，用 `where python`（Windows）或 `which python3`（macOS/Linux）确认当前使用的是哪个版本。
