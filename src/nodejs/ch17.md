# 第17章：Fastify——极速框架的秘密

## 引言：当速度成为信仰

在Web框架的世界里，如果Express是"稳重的老大哥"，Koa是"文艺的二哥"，那Fastify就是那个"刚从赛车场回来的小弟"——带着风驰电掣的速度和一身黑科技。

Fastify号称是"最快的Node.js Web框架之一"。但更重要的是——它快得有道理。不是靠牺牲功能换速度，而是通过**聪明的架构设计**做到了"既要又要"：既要极致性能，又要丰富功能。

你可能会问："快那么一点有什么用？" 当你的服务每秒处理数万请求时，每一毫秒都意味着更少的服务器、更低的成本、更好的用户体验。而且，理解Fastify为什么快，本身就是一堂精彩的计算机科学课。

## 17.1 为什么Fastify比Express快？

### 17.1.1 秘密武器一：Schema-based序列化

Express返回JSON时是怎么做的？`JSON.stringify(obj)`。简单粗暴，但慢。因为 `JSON.stringify` 需要在运行时检查每个属性的类型来决定如何序列化。

Fastify的做法是：如果你提前告诉我响应的结构（通过JSON Schema），我就能**生成一个定制的序列化函数**，比通用的 `JSON.stringify` 快2-5倍。

```typescript
import Fastify from 'fastify';

const app = Fastify({ logger: true });

// 定义响应Schema
const getUserSchema = {
  response: {
    200: {
      type: 'object',
      properties: {
        id: { type: 'number' },
        name: { type: 'string' },
        email: { type: 'string' },
        createdAt: { type: 'string', format: 'date-time' },
      },
      // 只序列化这些字段，其他的自动忽略！
      // 这意味着即使你的数据库对象有20个字段，也只会序列化这4个
      // 既快又安全（不会泄露敏感字段如password）
    },
  },
};

app.get('/users/:id', { schema: getUserSchema }, async (request, reply) => {
  const user = await db.getUser(request.params.id);
  // Fastify内部使用 fast-json-stringify 而不是 JSON.stringify
  // 它根据schema在启动时生成了一个定制的序列化函数
  return user;
});
```

**fast-json-stringify** 做了什么？它在启动时分析Schema，生成类似这样的代码：

```javascript
// 自动生成的序列化函数（简化版）
function serialize(obj) {
  let json = '{"id":' + obj.id;     // 直接拼接，不需要类型检查
  json += ',"name":"' + obj.name + '"';
  json += ',"email":"' + obj.email + '"';
  json += ',"createdAt":"' + obj.createdAt + '"';
  json += '}';
  return json;
}
// 比JSON.stringify快2-5倍！因为省去了所有运行时类型检查和属性遍历
```

### 17.1.2 秘密武器二：find-my-way路由算法

Express用的是线性匹配——注册了100个路由，最坏情况要比较100次。

Fastify用的是 **Radix Tree**（基数树）路由算法，时间复杂度是 O(路径长度)，和注册了多少路由无关！

```
路由注册：
  /api/users
  /api/users/:id
  /api/posts
  /api/posts/:id
  /api/comments

基数树结构：
  /api/
    ├── users
    │    └── /:id
    ├── posts
    │    └── /:id
    └── comments

匹配 /api/posts/123：
  /api/ → posts → /:id → 命中！只需3步
  无论你有100还是10000个路由，路径相同长度的路由匹配速度都一样
```

### 17.1.3 秘密武器三：更少的中间件开销

Express每个请求都要经过整个中间件链，即使某些中间件对当前路由没用。Fastify的插件封装系统让你可以精确控制哪些路由需要哪些功能。

## 17.2 插件系统(Plugin)：封装与装饰器

Fastify的插件系统是它最强大也最独特的特性。每个插件有自己的**封装上下文**：

```typescript
import Fastify from 'fastify';

const app = Fastify({ logger: true });

// 插件就是一个async函数
async function myPlugin(fastify: typeof app, options: { prefix?: string }) {
  // 装饰器：给fastify实例添加功能
  fastify.decorate('utility', () => 'I am a utility function');

  // 给请求对象添加属性
  fastify.decorateRequest('user', null);

  // 注册钩子（只在这个插件上下文中生效）
  fastify.addHook('onRequest', async (request, reply) => {
    request.user = { id: 1, name: 'Alice' }; // 模拟认证
  });

  // 注册路由
  fastify.get('/hello', async (request, reply) => {
    return { message: 'Hello from plugin!', user: request.user };
  });
}

// 注册插件
app.register(myPlugin, { prefix: '/api' });

// 封装性演示：在外层无法访问插件内部的装饰器
// app.utility; // ❌ undefined，因为封装在plugin内部

app.listen({ port: 3000 });
```

### 17.2.1 封装(Encapsulation)原理

```typescript
import Fastify from 'fastify';
import fp from 'fastify-plugin';

const app = Fastify();

// 普通插件 → 封装的（有自己的上下文）
async function scopedPlugin(fastify: any) {
  fastify.decorate('scoped', true);
  // 只有这个插件内部和它的子插件能访问 'scoped'
}

// 使用fastify-plugin包装 → 不封装（共享父级上下文）
const sharedPlugin = fp(async function (fastify: any) {
  fastify.decorate('shared', true);
  // 父级和所有兄弟插件都能访问 'shared'
});

// 典型用法：
// - 数据库连接：用fp()暴露给全局
// - 业务路由：用普通插件封装

app.register(sharedPlugin); // 暴露给所有
app.register(scopedPlugin); // 封装在内部

app.listen({ port: 3000 });
```

## 17.3 Schema验证与序列化

Fastify的Schema不仅用于序列化优化，还用于请求验证：

```typescript
import Fastify from 'fastify';

const app = Fastify();

const createUserSchema = {
  // 请求体验证
  body: {
    type: 'object',
    required: ['name', 'email'],
    properties: {
      name: { type: 'string', minLength: 2, maxLength: 50 },
      email: { type: 'string', format: 'email' },
      age: { type: 'integer', minimum: 0, maximum: 150 },
    },
    additionalProperties: false, // 不允许多余字段
  },

  // 查询参数验证
  querystring: {
    type: 'object',
    properties: {
      notify: { type: 'boolean', default: true },
    },
  },

  // URL参数验证
  params: {
    type: 'object',
    properties: {
      id: { type: 'string', pattern: '^[0-9a-f]{24}$' }, // MongoDB ObjectId
    },
  },

  // 请求头验证
  headers: {
    type: 'object',
    required: ['x-api-key'],
    properties: {
      'x-api-key': { type: 'string' },
    },
  },

  // 响应Schema（用于序列化优化+文档生成）
  response: {
    201: {
      type: 'object',
      properties: {
        success: { type: 'boolean' },
        data: {
          type: 'object',
          properties: {
            id: { type: 'string' },
            name: { type: 'string' },
            email: { type: 'string' },
          },
        },
      },
    },
    400: {
      type: 'object',
      properties: {
        success: { type: 'boolean' },
        error: { type: 'string' },
      },
    },
  },
};

app.post('/users', { schema: createUserSchema }, async (request, reply) => {
  const { name, email, age } = request.body as any;

  // 如果验证失败，Fastify自动返回400错误
  // 不需要手动验证！

  const user = { id: 'generated-id', name, email, age };
  reply.code(201);
  return { success: true, data: user };
});

// 自定义验证错误格式
app.setErrorHandler((error, request, reply) => {
  if (error.validation) {
    reply.status(400).send({
      success: false,
      error: 'Validation failed',
      details: error.validation.map((v: any) => ({
        field: v.instancePath || v.params?.missingProperty,
        message: v.message,
      })),
    });
    return;
  }
  reply.status(error.statusCode || 500).send({
    success: false,
    error: error.message,
  });
});

app.listen({ port: 3000 });
```

## 17.4 钩子(Hooks)生命周期

Fastify有丰富的生命周期钩子，让你精确控制请求处理的每个阶段：

```typescript
import Fastify from 'fastify';

const app = Fastify();

// ============ 请求生命周期钩子 ============

// 1. onRequest - 请求到达时（body还没解析）
app.addHook('onRequest', async (request, reply) => {
  console.log('1. onRequest - 请求开始');
  request.startTime = Date.now();
});

// 2. preParsing - body解析之前（可以修改payload）
app.addHook('preParsing', async (request, reply, payload) => {
  console.log('2. preParsing - 即将解析body');
  return payload; // 可以返回修改后的payload
});

// 3. preValidation - 验证之前（body已解析）
app.addHook('preValidation', async (request, reply) => {
  console.log('3. preValidation - body已解析，即将验证');
});

// 4. preHandler - 路由处理器之前（验证已通过）
app.addHook('preHandler', async (request, reply) => {
  console.log('4. preHandler - 验证通过，即将处理');
});

// 5. preSerialization - 序列化之前（可以修改响应数据）
app.addHook('preSerialization', async (request, reply, payload) => {
  console.log('5. preSerialization - 即将序列化响应');
  return payload; // 可以修改
});

// 6. onSend - 响应发送前（payload已是字符串/Buffer）
app.addHook('onSend', async (request, reply, payload) => {
  console.log('6. onSend - 响应即将发送');
  return payload;
});

// 7. onResponse - 响应发送后
app.addHook('onResponse', async (request, reply) => {
  const duration = Date.now() - (request as any).startTime;
  console.log(`7. onResponse - 完成 ${duration}ms`);
});

// 8. onError - 发生错误时
app.addHook('onError', async (request, reply, error) => {
  console.error('Error hook:', error.message);
});

// ============ 应用生命周期钩子 ============

// 所有插件加载完成后
app.addHook('onReady', async () => {
  console.log('App is ready!');
});

// 服务器关闭时
app.addHook('onClose', async (instance) => {
  console.log('App is closing, cleanup...');
  // 关闭数据库连接等
});

app.get('/', async () => ({ hello: 'world' }));
app.listen({ port: 3000 });
```

## 17.5 TypeScript原生支持

Fastify对TypeScript的支持是一流的：

```typescript
import Fastify, { FastifyRequest, FastifyReply } from 'fastify';

// 定义类型
interface CreateUserBody {
  name: string;
  email: string;
  age?: number;
}

interface UserParams {
  id: string;
}

interface UserQuery {
  include?: string;
}

interface UserResponse {
  id: string;
  name: string;
  email: string;
}

const app = Fastify();

// 类型安全的路由
app.post<{
  Body: CreateUserBody;
  Reply: { success: boolean; data: UserResponse };
}>('/users', {
  schema: {
    body: {
      type: 'object',
      required: ['name', 'email'],
      properties: {
        name: { type: 'string' },
        email: { type: 'string', format: 'email' },
        age: { type: 'integer' },
      },
    },
  },
}, async (request, reply) => {
  // request.body 的类型是 CreateUserBody ✅
  const { name, email } = request.body;

  return {
    success: true,
    data: { id: 'generated', name, email },
  };
});

app.get<{
  Params: UserParams;
  Querystring: UserQuery;
}>('/users/:id', async (request) => {
  const { id } = request.params; // string ✅
  const { include } = request.query; // string | undefined ✅

  return { id, include };
});

// 带类型的装饰器
declare module 'fastify' {
  interface FastifyRequest {
    user: { id: string; role: string } | null;
  }
}

app.decorateRequest('user', null);

app.addHook('preHandler', async (request) => {
  // request.user 现在有正确的类型 ✅
  request.user = { id: '1', role: 'admin' };
});

app.listen({ port: 3000 });
```

```
Fastify快的原因总结：

4. 底层使用优化的HTTP解析
5. 更少的对象创建和GC压力
```

## 17.8 实战：用Fastify构建高性能API

```typescript
import Fastify from 'fastify';
import swagger from '@fastify/swagger';
import swaggerUi from '@fastify/swagger-ui';
import cors from '@fastify/cors';
import crypto from 'node:crypto';

const app = Fastify({
  logger: {
    level: 'info',
    transport: {
      target: 'pino-pretty',
      options: { colorize: true },
    },
  },
});

// ============ 插件注册 ============
await app.register(cors);
await app.register(swagger, {
  openapi: {
    info: {
      title: 'Book Store API',
      version: '1.0.0',
      description: 'A high-performance bookstore API built with Fastify',
    },
    tags: [
      { name: 'books', description: 'Book operations' },
      { name: 'health', description: 'Health check' },
    ],
  },
});
await app.register(swaggerUi, { routePrefix: '/docs' });

// ============ 数据层 ============
interface Book {
  id: string;
  title: string;
  author: string;
  isbn: string;
  price: number;
  stock: number;
  createdAt: string;
}

const books = new Map<string, Book>();

// 预填充数据
function seedBooks() {
  const seed = [
    { title: 'Node.js设计模式', author: 'Mario Casciaro', isbn: '978-1-78588-587-8', price: 59.9, stock: 100 },
    { title: '深入浅出Node.js', author: '朴灵', isbn: '978-7-115-33550-4', price: 79.0, stock: 50 },
  ];
  for (const s of seed) {
    const id = crypto.randomUUID();
    books.set(id, { ...s, id, createdAt: new Date().toISOString() });
  }
}
seedBooks();

// ============ Schema定义 ============
const bookSchema = {
  type: 'object',
  properties: {
    id: { type: 'string', format: 'uuid' },
    title: { type: 'string' },
    author: { type: 'string' },
    isbn: { type: 'string' },
    price: { type: 'number' },
    stock: { type: 'integer' },
    createdAt: { type: 'string', format: 'date-time' },
  },
};

const errorSchema = {
  type: 'object',
  properties: {
    success: { type: 'boolean' },
    error: { type: 'string' },
  },
};

// ============ 路由插件 ============
async function bookRoutes(fastify: typeof app) {
  // GET /books - 获取所有图书
  fastify.get('/books', {
    schema: {
      tags: ['books'],
      summary: '获取图书列表',
      querystring: {
        type: 'object',
        properties: {
          search: { type: 'string', description: '搜索关键词' },
          minPrice: { type: 'number' },
          maxPrice: { type: 'number' },
          page: { type: 'integer', default: 1, minimum: 1 },
          limit: { type: 'integer', default: 10, minimum: 1, maximum: 100 },
        },
      },
      response: {
        200: {
          type: 'object',
          properties: {
            success: { type: 'boolean' },
            data: { type: 'array', items: bookSchema },
            pagination: {
              type: 'object',
              properties: {
                page: { type: 'integer' },
                limit: { type: 'integer' },
                total: { type: 'integer' },
              },
            },
          },
        },
      },
    },
  }, async (request) => {
    const { search, minPrice, maxPrice, page = 1, limit = 10 } = request.query as any;

    let result = Array.from(books.values());

    if (search) {
      const keyword = search.toLowerCase();
      result = result.filter(
        (b) => b.title.toLowerCase().includes(keyword) || b.author.toLowerCase().includes(keyword)
      );
    }
    if (minPrice !== undefined) result = result.filter((b) => b.price >= minPrice);
    if (maxPrice !== undefined) result = result.filter((b) => b.price <= maxPrice);

    const total = result.length;
    const paged = result.slice((page - 1) * limit, page * limit);

    return { success: true, data: paged, pagination: { page, limit, total } };
  });

  // GET /books/:id - 获取单本图书
  fastify.get('/books/:id', {
    schema: {
      tags: ['books'],
      summary: '获取图书详情',
      params: {
        type: 'object',
        properties: { id: { type: 'string', format: 'uuid' } },
        required: ['id'],
      },
      response: {
        200: { type: 'object', properties: { success: { type: 'boolean' }, data: bookSchema } },
        404: errorSchema,
      },
    },
  }, async (request, reply) => {
    const { id } = request.params as { id: string };
    const book = books.get(id);
    if (!book) {
      reply.code(404);
      return { success: false, error: 'Book not found' };
    }
    return { success: true, data: book };
  });

  // POST /books - 创建图书
  fastify.post('/books', {
    schema: {
      tags: ['books'],
      summary: '创建新图书',
      body: {
        type: 'object',
        required: ['title', 'author', 'isbn', 'price'],
        properties: {
          title: { type: 'string', minLength: 1, maxLength: 200 },
          author: { type: 'string', minLength: 1, maxLength: 100 },
          isbn: { type: 'string', pattern: '^[0-9-]+$' },
          price: { type: 'number', minimum: 0 },
          stock: { type: 'integer', minimum: 0, default: 0 },
        },
      },
      response: {
        201: { type: 'object', properties: { success: { type: 'boolean' }, data: bookSchema } },
      },
    },
  }, async (request, reply) => {
    const body = request.body as any;
    const id = crypto.randomUUID();
    const book: Book = { ...body, id, createdAt: new Date().toISOString() };
    books.set(id, book);
    reply.code(201);
    return { success: true, data: book };
  });

  // PUT /books/:id - 更新图书
  fastify.put('/books/:id', {
    schema: {
      tags: ['books'],
      summary: '更新图书信息',
      params: { type: 'object', properties: { id: { type: 'string' } }, required: ['id'] },
      body: {
        type: 'object',
        properties: {
          title: { type: 'string', minLength: 1 },
          author: { type: 'string', minLength: 1 },
          price: { type: 'number', minimum: 0 },
          stock: { type: 'integer', minimum: 0 },
        },
      },
      response: {
        200: { type: 'object', properties: { success: { type: 'boolean' }, data: bookSchema } },
        404: errorSchema,
      },
    },
  }, async (request, reply) => {
    const { id } = request.params as { id: string };
    const book = books.get(id);
    if (!book) {
      reply.code(404);
      return { success: false, error: 'Book not found' };
    }
    const updates = request.body as Partial<Book>;
    Object.assign(book, updates);
    return { success: true, data: book };
  });

  // DELETE /books/:id - 删除图书
  fastify.delete('/books/:id', {
    schema: {
      tags: ['books'],
      summary: '删除图书',
      params: { type: 'object', properties: { id: { type: 'string' } }, required: ['id'] },
      response: { 204: { type: 'null' }, 404: errorSchema },
    },
  }, async (request, reply) => {
    const { id } = request.params as { id: string };
    if (!books.delete(id)) {
      reply.code(404);
      return { success: false, error: 'Book not found' };
    }
    reply.code(204);
  });
}

// 健康检查
app.get('/health', {
  schema: { tags: ['health'], response: { 200: { type: 'object', properties: { status: { type: 'string' } } } } },
}, async () => ({ status: 'ok', uptime: process.uptime() }));

// 注册路由插件
app.register(bookRoutes, { prefix: '/api' });

// 启动
app.listen({ port: 3000 }, (err) => {
  if (err) {
    app.log.error(err);
    process.exit(1);
  }
  console.log('Swagger docs: http://localhost:3000/docs');
});
```

## 17.9 常见坑点

1. **忘记 `return`**：Fastify的处理器需要return值作为响应，不写return则没有响应体。
2. **reply.send() vs return**：两种方式都行，但不要混用。推荐用return。
3. **async函数中使用reply.send()**：如果用了async，必须await或return reply.send()。
4. **Schema不匹配**：响应数据和Schema不一致时，字段会被静默忽略（不会报错）。
5. **插件注册顺序**：依赖关系必须正确，先注册被依赖的插件。

```typescript
// 坑：async + reply.send() 的问题
app.get('/bad', async (request, reply) => {
  reply.send({ hello: 'world' }); // 没有return！
  // async函数默认return undefined → Fastify可能发送两次响应
});

// 正确做法
app.get('/good1', async (request, reply) => {
  return { hello: 'world' }; // 推荐
});

app.get('/good2', async (request, reply) => {
  return reply.send({ hello: 'world' }); // 也行
});
```
