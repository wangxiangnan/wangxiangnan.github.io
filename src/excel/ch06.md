# 第6章：数据整理——从杂乱到有序 🗂️

*小王的一个供应商给他发了一份Excel库存清单，打开一看差点晕倒——商品名称有的叫"珍珠奶茶"有的叫"珍珠奶荼"（打错字了），同一商品出现了三次，价格也不一样，日期格式有"2024/1/5"也有"2024.01.05"还有"1月5号"……简直是一锅粥。小李说："别急，Excel有专门整理数据的工具，学完这章你就是数据整理大师。"*

## 6.1 排序：单条件排序、多条件排序、自定义排序

排序是最基本的数据整理操作——把数据按照某种规则重新排列。

**单条件排序**

选中数据区域 → "数据"选项卡 → 点击"升序"（A→Z）或"降序"（Z→A）按钮。

比如：把所有商品按照销售额从高到低排序——选中数据区域 → "数据" → "降序" → 选择按"金额"列排序。

> ⚠️ **重要**：排序前务必选中**完整的数据区域**（包括所有列），否则只有选中的那一列会排序，其他列不动——数据就全错位了！这是新手最常犯的错误之一。

**多条件排序**

"数据" → "排序"按钮（大的那个）→ 弹出排序对话框：

- 第一条件：按"商品类别"升序
- 第二条件（点击"添加条件"）：按"销售额"降序

这样同类商品会排在一起，同类内部按销售额从高到低排。

**自定义排序**

如果你不想按字母或数字顺序排，可以自定义排序列表。比如按照"大杯、中杯、小杯"的顺序排（不是按字母排序），就需要自定义。

"排序"对话框 → "次序"下拉 → "自定义列表" → 输入你想要的顺序。

## 6.2 筛选：自动筛选、文本/数字/日期筛选

筛选的功能是：**只显示满足条件的数据行，把不需要的行暂时隐藏起来。**

**开启筛选**

选中表头行 → "数据"选项卡 → "筛选"按钮。表头的每个列标题右边会出现一个下拉箭头。

**自动筛选**

点击下拉箭头，会弹出筛选菜单：

- **勾选/取消勾选**：直接勾选你想看的值。比如只看"珍珠奶茶"。
- **文本筛选**：包含、开头是、结尾是、等于……
  - 例：商品名称"包含"奶茶 → 只显示名字里有"奶茶"的商品
- **数字筛选**：大于、小于、介于、前10项、高于平均值……
  - 例：金额"大于"300 → 只显示金额超过300的记录
- **日期筛选**：在今天之前、在本月、在下周、自定义日期范围……

> 💡 **提示**：筛选只是"隐藏"了不符合条件的行，并没有删除它们。取消筛选后所有数据又会显示出来。

**清除筛选**

- 点击"数据" → "清除"按钮（清除所有筛选条件）
- 或者再次点击列标题的筛选箭头 → "从XXX中清除筛选"

## 6.3 查找与替换：精确查找、通配符查找

**查找**

快捷键 `Ctrl + F` → 弹出查找对话框。

- 输入要查找的内容，点"查找下一个"逐个定位
- 点"查找全部"可以列出所有匹配的结果
- 点"选项"可以展开更多设置：区分大小写、全字匹配、按行/列搜索等

**替换**

快捷键 `Ctrl + H` → 弹出替换对话框。

例子：小王发现库存清单里所有的"珍珠奶荼"都应该改成"珍珠奶茶"：

- 查找内容：`珍珠奶荼`
- 替换为：`珍珠奶茶`
- 点"全部替换"

> ⚠️ **注意**：替换前请三思！建议先用"查找全部"看看有多少匹配项，确认无误再替换。一不小心替换错了可以用 `Ctrl + Z` 撤销。

**通配符查找**

- `*`（星号）：代表任意多个字符
  - 查找 `奶*` → 匹配"奶茶"、"牛奶"、"奶油奶盖"等
- `?`（问号）：代表一个字符
  - 查找 `?杯` → 匹配"大杯"、"中杯"、"小杯"
- 如果要查找星号或问号本身，在前面加 `~`：查找 `~*` 就是找星号字符

## 6.4 删除重复值

数据中经常会有重复的记录（可能是多次录入导致的）。Excel可以一键删除重复行。

**操作方法**

选中数据区域 → "数据"选项卡 → "删除重复值" → 选择哪些列作为判断重复的依据 → 确定。

比如：如果两行数据的"商品名称"和"日期"都相同，就认为是重复记录。那就只勾选"商品名称"和"日期"两列。

> ⚠️ **注意**：删除重复值会**永久删除**多余的数据行。建议操作前先复制一份数据备份，或者确保你可以 `Ctrl + Z` 撤销。

## 6.5 数据验证（下拉菜单）：防止录入错误

**数据验证**可以限制某个单元格只能输入特定类型的数据，是防止录入错误的利器。

**制作下拉菜单**

这是数据验证最常用的场景：

1. 选中要设置下拉菜单的单元格区域
2. "数据"选项卡 → "数据验证"（或"数据有效性"）
3. "允许"选择"序列"
4. "来源"输入选项，用逗号分隔：`珍珠奶茶,红豆奶茶,芒果冰沙,抹茶拿铁,椰汁西米露,黑糖鲜奶`
5. 确定

现在这些单元格右边会出现一个下拉箭头，点击就能选择商品名称，不能再手动输入其他值了。

> 💡 **提示**：下拉菜单的选项也可以引用某个区域的单元格。比如在"设置"工作表的A1:A6列出了所有商品名，"来源"可以写 `=设置!$A$1:$A$6`。这样以后增减商品只需要改"设置"表就行了。

**其他验证规则**

- 只允许输入整数：允许 → "整数"，介于1到100
- 只允许输入日期：允许 → "日期"，大于某个日期
- 只允许输入特定长度的文本：允许 → "文本长度"，等于11（比如手机号）
- 设置输入提示信息和错误警告信息

## 6.6 实战：整理奶茶店混乱的库存清单

现在让我们用本章学到的所有工具，帮小王整理那份混乱的库存清单！

**原始数据的问题**

1. 商品名称有错别字（"珍珠奶荼"、"芒菓冰沙"）
2. 同一种商品出现了多行（重复录入）
3. 日期格式不统一
4. 没有排序，杂乱无章
5. 有的单元格是空的（漏填了）

**整理步骤**

**Step 1：修正错别字**

`Ctrl + H` 打开替换：

- "珍珠奶荼" → "珍珠奶茶"
- "芒菓冰沙" → "芒果冰沙"

**Step 2：删除重复值**

选中全部数据 → "数据" → "删除重复值" → 勾选"商品名称"和"日期"列作为判断依据 → 确定。假设有5条重复记录被删除。

**Step 3：统一日期格式**

选中日期列 → `Ctrl + 1` → "数字"选项卡 → "日期" → 选择 `2024/1/15` 格式 → 确定。

**Step 4：排序**

"数据" → "排序"：

- 第一条件：商品名称（升序）
- 第二条件：日期（升序）

**Step 5：添加数据验证**

给"商品名称"列添加下拉菜单，防止以后再输入错别字。给"数量"列设置验证规则：只允许正整数。

**Step 6：用筛选检查异常数据**

- 筛选"数量"列为空或为0的行 → 补充或标记
- 筛选"单价"列低于10或高于50的行 → 检查是否录入错误

**整理完成！** 现在库存清单干净整齐，数据一致，还有下拉菜单防止以后再出错。小王看着整理后的表格，感动得快哭了。
