# 第四章：视觉系统——让人一眼记住你

## 核心观点

**视觉不是美化，是降低认知成本。让用户一眼认出是你。**

## 4.1 封面设计原则

**尺寸规则：**

- 上传 2.35:1（750×320），系统按 2.35:1 裁切展示
- 转发到聊天和朋友圈时按 1:1 显示，核心内容放在中间 1:1 安全区
- 头条和次条尺寸不同，模板里预留两种版式

**设计原则：**

- 只用 1 种字体（推荐思源黑体，技术内容可用等宽字体）
- 只用 3 种字号（大/中/小）
- 只用 2 种颜色（主色 + 强调色，灰色系不计）
- 留白 > 填满

## 4.2 封面模板

**不要每期重新设计。** 做一套模板，只换内容：

```
固定元素：
- 背景色
- 字体
- 栏目标题位置
- 期号位置
- 底部信息

可变元素：
- 本期报错 / 主题
- 关键词高亮
```

**示例：英语404 的封面结构**

```
┌──────────────────────────────┐
│ 英语404               第 12 期 │
│                              │
│  Cannot read properties      │
│  of undefined                │
│                              │
│  周五 · 一条报错一个语法点      │
└──────────────────────────────┘
```

固定：左上角账号名、右上角期号、底部栏目说明。
可变：中间的报错原文，等宽字体，最多两行，超长就截断并加省略号。

**工具推荐：**

- Figma（专业，可协作，适合长期维护模板）
- Canva（模板多，上手快）
- SVG 手写（最灵活，适合技术人）

## 4.3 品牌色

| 角色 | 示例色值（英语404） | 用法 |
| --- | --- | --- |
| 主色 | #1E293B 深蓝灰 | 封面底色、标题 |
| 强调色 | #F97316 橙 | 关键词高亮、期号 |
| 中性色 | #E2E8F0 / #64748B | 分割线、辅助信息 |

"两色原则"指主色加一个强调色，不是限制整个视觉里只能出现两种颜色。中性灰不参与计数。

## 4.4 视觉一致性检查

- 头像、封面、文内头图使用同一套色值和字体
- 期号、栏目名、账号名在每期的位置不变
- 至少连续 3 期使用同一模板，再去判断效果
- 正文排版、代码块、文中图片的规范见第 7 章

## 检查清单

- [ ] 封面模板完成（2.35:1 + 1:1 安全区）
- [ ] 确定主色、强调色各 1 个
- [ ] 字体、字号数量符合限制
- [ ] 至少 3 期封面用同一模板
