# 第 11 章 文件操作与路径

程序不总是和屏幕打交道的。想象你在一家公司做数据分析，老板丢给你一个 Excel 表格说"帮我统计一下"，你得能读取文件；分析完了，你得把结果写到新文件里发给老板。从读配置文件到处理日志，从保存用户数据到导出报告，文件操作是编程中最"接地气"的技能。

这一章，你将学会用 Python 打开、读取、写入各种文件，用 `pathlib` 优雅地处理文件路径，以及处理 CSV、JSON 这些常见的数据格式。

## 11.1 打开文件：open 函数

Python 用内置的 `open()` 函数打开文件。它返回一个**文件对象**，你通过它来读写内容。

```python
# 最基本的用法
# f = open("example.txt", "r", encoding="utf-8")
# content = f.read()
# f.close()  # 千万别忘了关闭！
```

`open()` 的关键参数：

| 参数 | 说明 | 示例 |
| ------ | ------ | ------ |
| `file` | 文件路径 | `"data.txt"` |
| `mode` | 打开模式 | `"r"`（读）、`"w"`（写）、`"a"`（追加） |
| `encoding` | 文本编码 | `"utf-8"` |

常用打开模式：

| 模式 | 含义 |
| ------ | ------ |
| `"r"` | 只读（默认），文件不存在则报错 |
| `"w"` | 写入，文件存在则清空覆盖，不存在则创建 |
| `"a"` | 追加写入，在文件末尾添加内容 |
| `"x"` | 独占创建，文件已存在则报错 |
| `"b"` | 二进制模式（和其他模式组合，如 `"rb"`、`"wb"`） |
| `"t"` | 文本模式（默认，通常省略） |
| `"+"` | 读写模式（如 `"r+"` 可读可写） |

## 11.2 with 语句：自动管理资源

手动调用 `f.close()` 容易忘记，尤其在代码中间出了异常时，`close()` 可能被跳过。**`with` 语句**（上下文管理器）帮你自动关闭文件，不管中间有没有出错。

```python
# 推荐写法：用 with 打开文件
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 离开 with 块时，文件自动关闭，即使中间抛了异常

# 等价于：
# f = open("example.txt", "r", encoding="utf-8")
# try:
#     content = f.read()
#     print(content)
# finally:
#     f.close()
```

**永远用 `with` 打开文件。** 这是 Python 社区的共识，没有例外。

## 11.3 读取文件

```python
# 假设 example.txt 内容如下：
# 第一行：Hello World
# 第二行：Python is great
# 第三行：文件操作真方便

# 方式1：一次读取全部内容
with open("example.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
    # Hello World
    # Python is great
    # 文件操作真方便

# 方式2：逐行读取（内存友好，适合大文件）
with open("example.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())  # strip 去掉行末换行符

# 方式3：读取所有行到列表
with open("example.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)
    # ['Hello World\n', 'Python is great\n', '文件操作真方便\n']

# 方式4：读取一行
with open("example.txt", "r", encoding="utf-8") as f:
    first_line = f.readline()
    second_line = f.readline()
    print(first_line.strip())   # Hello World
    print(second_line.strip())  # Python is great
```

**大文件读取的建议**：如果文件有几百 MB 甚至几个 GB，千万不要用 `f.read()` 一次读完（会爆内存），应该用 `for line in f:` 逐行处理。

## 11.4 写入文件

```python
# 写入文本（"w" 模式会清空原文件！）
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello World\n")
    f.write("Python is great\n")
    f.write("文件操作真方便\n")

# 追加写入（"a" 模式不会清空原文件）
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("追加的新内容\n")

# writelines：写入多行（注意不会自动加换行符）
lines = ["第一行\n", "第二行\n", "第三行\n"]
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)

# print 函数也可以写入文件
with open("output.txt", "w", encoding="utf-8") as f:
    print("Hello", file=f)
    print("World", file=f)
```

## 11.5 文本编码与读写模式

### 11.5.1 编码的重要性

```python
# 始终指定 encoding！不指定的话，Windows 默认用 GBK，macOS/Linux 默认用 UTF-8
# 这会导致你的代码在不同系统上表现不同

# 好习惯：永远写 encoding

    print(f.read())  # 你好世界
```

### 11.5.2 二进制模式

处理图片、音频、视频等非文本文件时，需要用二进制模式：

```python
# 读取图片（二进制模式）
with open("photo.jpg", "rb") as f:
    data = f.read()
    print(f"文件大小：{len(data)} 字节")
    print(f"前 4 个字节：{data[:4]}")  # JPEG 文件以 FF D8 FF 开头

# 复制文件
with open("photo.jpg", "rb") as src:
    with open("photo_copy.jpg", "wb") as dst:
        dst.write(src.read())

# 大文件分块复制（不占内存）
with open("big_file.zip", "rb") as src:
    with open("big_file_copy.zip", "wb") as dst:
        while chunk := src.read(8192):  # 每次读 8KB
            dst.write(chunk)
```

## 11.6 pathlib：现代路径处理

`os.path` 模块是旧式的路径操作方式，用字符串拼接路径容易出错（不同操作系统分隔符不同）。**`pathlib`** 是 Python 3.4+ 引入的现代路径库，用面向对象的方式操作路径，更直观也更安全。

```python
from pathlib import Path

# 创建路径对象
p = Path("documents/report.txt")
print(p)           # documents/report.txt（自动适配操作系统）
print(type(p))     # <class 'pathlib.PurePosixPath'> 或 PureWindowsPath

# 当前目录
current = Path(".")
print(current.resolve())  # 绝对路径

# 用户主目录
home = Path.home()
print(home)  # /home/user 或 C:\Users\user

# 路径拼接（用 / 运算符，最优雅的方式）
config_path = Path.home() / ".config" / "myapp" / "settings.json"
print(config_path)

# 路径组成部分
p = Path("/home/user/documents/report.txt")
print(p.parent)    # /home/user/documents（父目录）
print(p.name)      # report.txt（文件名）
print(p.stem)      # report（不含后缀的文件名）
print(p.suffix)    # .txt（后缀）
print(p.parts)     # ('/', 'home', 'user', 'documents', 'report.txt')
```

### 11.6.1 路径信息查询

```python
from pathlib import Path

p = Path("example.txt")

# 检查路径是否存在
print(p.exists())       # True 或 False

# 判断类型
print(p.is_file())      # True（是文件）
print(p.is_dir())       # False（不是目录）

# 获取文件信息
if p.exists():
    print(f"大小：{p.stat().st_size} 字节")
    print(f"最后修改时间：{p.stat().st_mtime}")

# 修改后缀
new_p = p.with_suffix(".md")
print(new_p)  # example.md

# 修改文件名
new_p = p.with_name("new_report.txt")
print(new_p)  # new_report.txt（保持目录不变）
```

### 11.6.2 目录操作

```python
from pathlib import Path

# 创建目录
new_dir = Path("my_project/src/utils")
new_dir.mkdir(parents=True, exist_ok=True)  # 递归创建，已存在不报错

# 列出目录内容
for item in Path(".").iterdir():
    if item.is_file():
        print(f"文件：{item.name}")
    elif item.is_dir():
        print(f"目录：{item.name}/")

# 用 glob 模式搜索文件
for py_file in Path(".").glob("*.py"):
    print(py_file)

# 递归搜索（** 代表任意层子目录）
for txt_file in Path(".").rglob("*.txt"):
    print(txt_file)

# 等价写法
for txt_file in Path(".").glob("**/*.txt"):
    print(txt_file)
```

### 11.6.3 用 pathlib 读写文件

`pathlib` 提供了快捷的读写方法，简单场景下不需要 `open()`：

```python
from pathlib import Path

p = Path("hello.txt")

# 写入文本（自动创建/覆盖文件）
p.write_text("Hello, pathlib!", encoding="utf-8")

# 读取全部文本
content = p.read_text(encoding="utf-8")
print(content)  # Hello, pathlib!

# 读写二进制数据
p.write_bytes(b"\x89PNG\r\n")  # 写入字节
data = p.read_bytes()             # 读取字节
```

注意：`read_text()` / `write_text()` 适合小文件。大文件仍然应该用 `open()` 逐行处理。

## 11.7 CSV 文件处理

CSV（Comma-Separated Values）是最简单的表格数据格式——纯文本，每行一条记录，字段间用逗号分隔。

### 11.7.1 用 csv 模块读写

```python
import csv

# 写入 CSV
students = [
    ["姓名", "年龄", "成绩"],
    ["小明", 20, 85],
    ["小红", 21, 92],
    ["小刚", 19, 78],
]

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(students)  # 一次写入多行

# 读取 CSV
with open("students.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)  # 读取表头
    print(f"表头：{header}")
    for row in reader:
        name, age, score = row
        print(f"{name}，{age}岁，成绩{score}")
```

### 11.7.2 用 DictReader / DictWriter

当 CSV 有表头时，用字典方式读写更方便：

```python
import csv

# 用 DictWriter 写入
fieldnames = ["name", "age", "score"]
students = [
    {"name": "小明", "age": 20, "score": 85},
    {"name": "小红", "age": 21, "score": 92},
    {"name": "小刚", "age": 19, "score": 78},
]

with open("students.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()  # 写入表头
    writer.writerows(students)

# 用 DictReader 读取
with open("students.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"{row['name']}的成绩是{row['score']}")
        # 小明的成绩是85
        # 小红的成绩是92
        # 小刚的成绩是78
```

### 11.7.3 处理特殊分隔符

```python
import csv

# 有些 CSV 用 Tab 或其他字符分隔（TSV 文件）
with open("data.tsv", "r", encoding="utf-8") as f:
    reader = csv.reader(f, delimiter="\t")
    for row in reader:
        print(row)

# 自定义分隔符
with open("data.psv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, delimiter="|")
    writer.writerow(["Name", "Age", "City"])
    writer.writerow(["Alice", 25, "Beijing"])
```

## 11.8 JSON 文件处理

JSON（JavaScript Object Notation）是目前最流行的数据交换格式。Python 的字典和 JSON 几乎一一对应。

### 11.8.1 json 模块

```python
import json

# Python 字典 -> JSON 字符串（序列化）
data = {
    "name": "小明",
    "age": 25,
    "hobbies": ["编程", "读书", "游泳"],
    "address": {
        "city": "北京",
        "district": "海淀"
    }
}

# dumps：字典 -> JSON 字符串
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)
# {
#   "name": "小明",
#   "age": 25,
#   "hobbies": [
#     "编程",
#     "读书",
#     "游泳"
#   ],
#   "address": {
#     "city": "北京",
#     "district": "海淀"
#   }
# }

# loads：JSON 字符串 -> 字典（反序列化）
parsed = json.loads(json_str)
print(parsed["name"])       # 小明
print(parsed["hobbies"][0]) # 编程
```

### 11.8.2 读写 JSON 文件

```python
import json

data = {"name": "小明", "scores": [85, 92, 78]}

# 写入 JSON 文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取 JSON 文件
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
    print(loaded)  # {'name': '小明', 'scores': [85, 92, 78]}
```

### 11.8.3 JSON 与 Python 类型对照

| Python | JSON |
| -------- | ------ |
| `dict` | `{}` 对象 |
| `list` / `tuple` | `[]` 数组 |
| `str` | 字符串 |
| `int` / `float` | 数字 |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

注意：JSON 不支持 Python 的 `set`、`datetime`、自定义对象等类型。如果需要序列化这些类型，要写自定义编码器。

### 11.8.4 处理不支持的类型

```python
import json
from datetime import datetime

data = {
    "event": "会议",
    "time": datetime(2024, 1, 15, 14, 30),
}

# 默认会报错：datetime 不能序列化为 JSON
# json.dumps(data)  # TypeError!

# 解决方案1：自定义 default 函数
def json_serializer(obj):
    if isinstance(obj, datetime):
        return obj.isoformat()
    raise TypeError(f"Object of type {type(obj)} is not JSON serializable")

json_str = json.dumps(data, default=json_serializer, ensure_ascii=False)
print(json_str)  # {"event": "会议", "time": "2024-01-15T14:30:00"}

# 解决方案2：手动转换
data["time"] = data["time"].strftime("%Y-%m-%d %H:%M")
json_str = json.dumps(data, ensure_ascii=False)
```

## 11.9 Pickle：Python 专属序列化

`pickle` 可以把几乎任何 Python 对象（包括自定义类的实例）保存为二进制文件。但注意：**pickle 文件只能在 Python 中使用，而且有安全风险——不要加载来源不明的 pickle 文件**。

```python
import pickle

# 保存 Python 对象
data = {
    "name": "小明",
    "scores": [85, 92, 78],
    "active": True,
}

# 序列化到文件
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

# 从文件反序列化
with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)
    print(loaded)  # {'name': '小明', 'scores': [85, 92, 78], 'active': True}

# 序列化到字节
data_bytes = pickle.dumps(data)
restored = pickle.loads(data_bytes)
print(restored == data)  # True
```

### Pickle vs JSON 的选择

| 特性 | JSON | Pickle |
| ------ | ------ | -------- |
| 跨语言 | 可以（通用格式） | 不可以（Python 专用） |
| 可读性 | 人类可读 | 二进制，不可读 |
| 安全性 | 安全 | 不安全（可执行任意代码） |
| 支持类型 | 基本类型 | 几乎所有 Python 对象 |
| 用途 | 数据交换、配置文件 | 缓存、模型保存 |

**日常开发优先用 JSON**。只有当你需要保存 Python 特有对象（如自定义类实例、函数）时，才考虑 pickle。

## 11.11 上下文管理器深入

`with` 语句不仅用于文件操作。任何需要"获取资源-使用-释放资源"的场景都可以用上下文管理器。

```python
# 自定义上下文管理器（用类实现）
class Timer:
    """计时上下文管理器"""
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.elapsed = time.time() - self.start
        print(f"耗时：{self.elapsed:.4f} 秒")
        return False  # 不吞掉异常

# 使用
with Timer():
    total = sum(range(1000000))
# 输出类似：耗时：0.0234 秒

# 用 contextlib 简化写法
from contextlib import contextmanager

@contextmanager
def temp_directory():
    """创建临时目录，使用完毕后自动删除"""
    import tempfile
    import shutil
    tmpdir = tempfile.mkdtemp()
    try:
        yield tmpdir  # yield 的值赋给 as 后面的变量
    finally:
        shutil.rmtree(tmpdir)

with temp_directory() as tmpdir:
    print(f"临时目录：{tmpdir}")
    # 在这里操作临时目录
# 离开 with 块时自动删除
```

## 11.12 小结

- 用 `with open(...)` 打开文件，自动管理资源，永远不要忘记指定 `encoding`
- 读取大文件用 `for line in f:` 逐行读取，不要 `f.read()` 一次性读完
- `pathlib` 是现代 Python 路径处理的首选，用 `/` 运算符拼接路径
- `csv` 模块处理表格数据，`DictReader` / `DictWriter` 比 `reader` / `writer` 更好用
- `json` 模块处理 JSON 数据，`dump` / `load` 处理文件，`dumps` / `loads` 处理字符串
- `pickle` 可以序列化任意 Python 对象，但只能用于 Python 内部，且有安全风险
- 上下文管理器（`with` 语句）适用于任何需要资源清理的场景

```python
def count_lines(filepath):
    """统计文件行数"""
    count = 0
    with open(filepath, "r", encoding="utf-8") as f:
        for _ in f:
            count += 1
    return count

# 或者更简洁的写法：
def count_lines_v2(filepath):
    with open(filepath, "r", encoding="utf-8") as f:
        return sum(1 for _ in f)
```

```python
import csv

def merge_csv(file1, file2, output):
    """合并两个 CSV 文件"""
    rows = []

    # 读取第一个文件（包含表头）
    with open(file1, "r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)
        fieldnames = reader.fieldnames
        rows.extend(reader)

    # 读取第二个文件（跳过表头，DictReader 自动处理）
    with open(file2, "r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)
        rows.extend(reader)

    # 写入合并后的文件
    with open(output, "w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(rows)
```

```python
from datetime import datetime

class FileLogger:
    """文件日志上下文管理器"""
    def __init__(self, filepath):
        self.filepath = filepath
        self.file = None

    def __enter__(self):
        self.file = open(self.filepath, "a", encoding="utf-8")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()
        return False

    def log(self, message):
        """写一条日志"""
        timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        self.file.write(f"[{timestamp}] {message}\n")

# 使用
with FileLogger("app.log") as logger:
    logger.log("程序启动")
    logger.log("处理数据中...")
    logger.log("程序结束")
```

```python
from collections import Counter

def count_extensions(directory="."):
    """统计目录下各文件后缀的数量"""
    counter = Counter()
    for path in Path(directory).rglob("*"):
        if path.is_file():
            suffix = path.suffix.lower() or "(无后缀)"
            counter[suffix] += 1

    for ext, count in counter.most_common():
```

## 11.15 常见错误与避坑

**1. 忘记用 `with` 或忘记 `close()`**

```python
# 危险：如果中间出异常，文件永远不会关闭，可能导致数据丢失
f = open("data.txt", "w")
f.write("hello")
# 如果这里出了异常...
f.close()  # 永远不会执行

# 安全：用 with 保证文件一定被关闭
with open("data.txt", "w") as f:
    f.write("hello")
```

**2. 写入 CSV 时忘记 `newline=""`**

```python
# 在 Windows 上，不加 newline="" 会导致每行之间多一个空行
# 错误
with open("data.csv", "w", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["a", "b"])

# 正确
with open("data.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["a", "b"])
```

**3. 用 "w" 模式打开了已有文件（内容被清空）**

```python
# 危险：如果文件已存在，"w" 模式会清空它！
# with open("important_data.txt", "w") as f:
#     f.write("新内容")  # 旧内容全没了！

# 如果只是想追加，用 "a" 模式
with open("important_data.txt", "a", encoding="utf-8") as f:
    f.write("追加内容\n")
```

**4. 路径拼接用字符串拼接**

```python
import os
# 危险：不同操作系统分隔符不同
path = "documents" + "/" + "report.txt"  # Windows 上可能出问题

# 安全做法1：pathlib
from pathlib import Path
path = Path("documents") / "report.txt"

# 安全做法2：os.path.join
path = os.path.join("documents", "report.txt")
```

**6. 读取文件后忘记重置文件指针**

```python
with open("data.txt", "r", encoding="utf-8") as f:
    first_read = f.read()
    second_read = f.read()  # 空字符串！指针已在文件末尾

# 如果需要重新读取，用 seek(0) 回到开头
with open("data.txt", "r", encoding="utf-8") as f:
    first_read = f.read()
    f.seek(0)  # 回到文件开头
    second_read = f.read()  # 这次能读到内容
```
