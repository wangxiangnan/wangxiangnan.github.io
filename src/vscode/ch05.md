# 第5章：内置终端与命令行集成

> [!TIP] Part II: 核心工作流精通
> 在VSCode之前，开发者的日常是这样的：左边一个编辑器窗口，右边一个终端窗口，`Alt+Tab`（`⌘+Tab`）在两者之间疯狂切换。VSCode的内置终端不是简单地把一个终端塞进编辑器里——它与编辑器深度集成，形成了"所见即所得"的开发闭环。这一章，我们要把这个内置终端调教成你最喜欢的命令行环境。

## 终端配置：基础设定

### 默认Shell配置

VSCode默认使用系统的默认shell，但你完全可以自定义：

```jsonc
// settings.json - 终端基础配置
{
  // Windows上的终端配置
  "terminal.integrated.defaultProfile.windows": "PowerShell",
  "terminal.integrated.profiles.windows": {
    "PowerShell": {
      "source": "PowerShell",
      "icon": "terminal-powershell",
      "args": ["-NoLogo"]    // 不显示启动横幅
    },
    "Command Prompt": {
      "path": "C:\\Windows\\System32\\cmd.exe",
      "icon": "terminal-cmd"
    },
    "Git Bash": {
      "source": "Git Bash",
      "icon": "terminal-bash",
      "args": ["--login"]
    },
    "WSL": {
      "path": "C:\\Windows\\System32\\wsl.exe",
      "args": ["-d", "Ubuntu"],
      "icon": "terminal-ubuntu"
    }
  },

  // macOS上的终端配置
  "terminal.integrated.defaultProfile.osx": "zsh",
  "terminal.integrated.profiles.osx": {
    "zsh": {
      "path": "/bin/zsh",
      "args": ["-l"],
      "icon": "terminal-zsh"
    },
    "bash": {
      "path": "/bin/bash",
      "args": ["-l"]
    }
  },

  // Linux上的终端配置
  "terminal.integrated.defaultProfile.linux": "zsh",
  "terminal.integrated.profiles.linux": {
    "zsh": {
      "path": "/usr/bin/zsh",
      "args": ["-l"]
    },
    "bash": {
      "path": "/usr/bin/bash"
    }
  },

  // 通用终端外观
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.fontFamily": "'JetBrains Mono', 'Cascadia Code', Consolas",
  "terminal.integrated.lineHeight": 1.2,
  "terminal.integrated.cursorBlinking": true,
  "terminal.integrated.cursorStyle": "line",
  "terminal.integrated.scrollback": 10000,
  "terminal.integrated.smoothScrolling": true,
  "terminal.integrated.rightClickBehavior": "default",
  "terminal.integrated.copyOnSelection": false
}
```

### 终端分屏和布局

VSCode终端支持灵活的分屏：

```
快捷键                                    说明
────────────────────────────────────────────────────────────
Ctrl+` (⌃+`)                           切换终端面板显示/隐藏
Ctrl+Shift+` (⌃+Shift+`)              创建新终端
Ctrl+Shift+5 (⌘+Shift+5)              分屏（拆分终端）
Ctrl+PageUp/PageDown                    切换终端标签页
Alt+←/→ (⌘+Option+←/→)               在分屏终端间切换焦点
Ctrl+Shift+PageUp/PageDown              调整终端面板大小
```

终端可以放在编辑器底部（默认）或侧边：

```jsonc
{
  "terminal.integrated.defaultLocation": "view",  // "view"放在侧边面板
  "workbench.panel.defaultLocation": "right"       // 面板默认在右侧
}
```

## Shell集成（Shell Integration）

Shell集成是VSCode终端的杀手级功能——它让你的终端"更聪明"。开启后，VSCode能理解你终端中的每一条命令，提供命令装饰、快速跳转、命令重运行等功能。

### 开启Shell集成

Shell集成默认开启（VSCode 1.70+）。如果需要手动配置：

```jsonc
{
  "terminal.integrated.shellIntegration.enabled": true,
  "terminal.integrated.shellIntegration.decorationsEnabled": true
}
```

### Shell集成提供的功能

开启后，你会在终端每条命令旁边看到小装饰图标：

```
  ● $ npm install                    ← 成功命令（绿色圆点）
  ● $ npm run build                  ← 失败命令（红色圆点）
  ○ $ ls -la                         ← 正在运行的命令（空心圆点）
```

**命令导航**：

```
快捷键                          说明
──────────────────────────────────────────────
Ctrl+↑ (⌘+↑)                 跳到上一条命令
Ctrl+↓ (⌘+↓)                 跳到下一条命令
```

**命令菜单**：右键点击命令装饰图标，可以：

- 重新运行该命令
- 复制命令文本
- 复制命令输出
- 跳到上一条/下一条命令

**命令输出跳转**：点击命令输出区域的任何位置，可以快速滚动到该命令的起始位置。

### 命令检测与智能提示

Shell集成还能检测你的命令意图：

```bash
# 当你在终端输入一个文件路径，VSCode会把它变成可点击的链接
$ cat src/utils/helpers.ts          # Ctrl+Click 打开文件

# 当命令失败时，VSCode可能提供修复建议
$ node server.js
Error: Cannot find module 'express'
# → VSCode 可能提示你运行 npm install express
```

## 终端环境变量和配置继承

### 自定义终端环境变量

```jsonc
{
  "terminal.integrated.env.windows": {
    "NODE_ENV": "development",
    "EDITOR": "code --wait"
  },
  "terminal.integrated.env.osx": {
    "NODE_ENV": "development",
    "EDITOR": "code --wait",
    "PATH": "${env:PATH}:/usr/local/bin"
  },
  "terminal.integrated.env.linux": {
    "NODE_ENV": "development",
    "EDITOR": "code --wait"
  }
}
```

### 环境变量继承控制

```jsonc
{
  // 控制是否继承系统环境变量（默认true）
  "terminal.integrated.environmentChangesRevert": "prompt",
  "terminal.integrated.environmentChangesIndicator": "on"
}
```

## 终端链接和路径点击

VSCode的终端会自动检测文件路径和URL，并让它们可点击：

```bash
# 文件路径（Ctrl+Click 在编辑器中打开）
$ Error in src/components/Button.tsx:42

# URL（Ctrl+Click 在浏览器中打开）
$ Server running at http://localhost:3000

# Git引用（配合Git插件可以跳转）
$ commit abc1234 (HEAD -> main)

# 行号和列号（精确跳转）
$ at Object.<anonymous> (src/app.js:15:8)   # 点击后跳到第15行第8列
```

### 终端链接配置

```jsonc
{
  // 控制终端链接检测
  "terminal.integrated.enableFileLinks": "on",  // "on" | "off" | "notRemote"
}
```

## 实战：配置一个适合前端开发的终端环境

让我们一步步配置一个完美的前端开发终端。

### 步骤1：安装推荐Shell工具

```bash
# Windows用户推荐安装：
# 1. Windows Terminal（Microsoft Store）
# 2. Git for Windows（提供Git Bash）
# 3. Oh My Posh（PowerShell美化）
winget install --id JanDeDobbeleer.OhMyPosh

# macOS用户推荐安装：
# 1. iTerm2（可选，VSCode内置终端已经够用）
# 2. Oh My Zsh
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
# 3. Starship提示符（跨Shell）
brew install starship
```

### 步骤2：完整的终端配置

```jsonc
// settings.json - 前端开发终端配置
{
  // ===== 终端外观 =====
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.fontFamily": "'JetBrains Mono', 'Fira Code', Consolas",
  "terminal.integrated.lineHeight": 1.1,
  "terminal.integrated.letterSpacing": 0,
  "terminal.integrated.cursorBlinking": true,
  "terminal.integrated.cursorStyle": "line",
  "terminal.integrated.smoothScrolling": true,
  "terminal.integrated.scrollback": 20000,

  // ===== Shell集成 =====
  "terminal.integrated.shellIntegration.enabled": true,
  "terminal.integrated.shellIntegration.decorationsEnabled": true,

  // ===== 终端行为 =====
  "terminal.integrated.rightClickBehavior": "default",
  "terminal.integrated.copyOnSelection": false,
  "terminal.integrated.enableMultiLinePasteWarning": "always",
  "terminal.integrated.enableFileLinks": "on",
  "terminal.integrated.environmentChangesIndicator": "on",

  // ===== Windows Shell配置 =====
  "terminal.integrated.defaultProfile.windows": "PowerShell",
  "terminal.integrated.profiles.windows": {
    "PowerShell": {
      "source": "PowerShell",
      "icon": "terminal-powershell",
      "args": ["-NoLogo"],
      "env": {
        "NODE_ENV": "development"
      }
    },
    "Git Bash": {
      "source": "Git Bash",
      "icon": "terminal-bash"
    }
  }
}
```

### 步骤3：配合Tasks自动启动开发环境

```jsonc
// .vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "启动开发服务器",
      "type": "npm",
      "script": "dev",
      "isBackground": true,
      "problemMatcher": {
        "pattern": {
          "regexp": "^$"
        },
        "background": {
          "activeOnStart": true,
          "beginsPattern": "VITE|ready|started",
          "endsPattern": "Local:.*http"
        }
      },
      "presentation": {
        "echo": true,
        "reveal": "always",
        "focus": false,
        "panel": "dedicated",
        "showReuseMessage": false,
        "group": "dev-group"
      }
    },
    {
      "label": "启动测试监听",
      "type": "npm",
      "script": "test:watch",
      "isBackground": true,
      "problemMatcher": ["$vitest"],
      "presentation": {
        "panel": "dedicated",
        "group": "dev-group"
      }
    },
    {
      "label": "启动全栈开发",
      "dependsOn": ["启动开发服务器", "启动测试监听"],
      "dependsOrder": "parallel",
      "group": {
        "kind": "build",
        "isDefault": true
      }
    }
  ]
}
```

运行 `Ctrl+Shift+B`（`⌘+Shift+B`）即可一键启动所有开发服务，每个服务在独立的终端面板中运行。

## 📋 本章小结

- VSCode内置终端不是简单的终端模拟器，它与编辑器**深度集成**
- **Shell集成**让终端变智能：命令装饰、命令导航、输出跳转
- 终端支持**多配置（Profiles）**，可以为不同场景设置不同Shell
- **终端分屏**让你在一个面板中同时查看多个终端
- 终端中的**文件路径和URL自动可点击**，实现终端与编辑器的无缝跳转
- 配合**Tasks**可以一键启动完整的开发环境
- `terminal.integrated.env.*` 可以为终端注入自定义环境变量
