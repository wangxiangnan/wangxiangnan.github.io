# 第8章：个人所得税——合法少交税的正确方法 🧾

*三月底的一天，小王刷手机看到一条热搜：#年度汇算清缴开始了#。他一脸茫然地问老陈："汇算清缴是什么？跟我有什么关系？"老陈反问："你去年除了工资，是不是还有奶茶店的收入？"小王点点头。"那就跟你有关。赶紧去个人所得税APP看看，说不定还能退一笔钱呢。"小王半信半疑地下载了APP，一打开，发现上面显示他可以退税 `1200` 元。他眼睛一亮："退税？这钱是我的？"*

> [!WARNING] 注意
> ⚠️ 本章内容仅为知识科普，不构成任何投资建议。投资有风险，决策需谨慎。

## 8.1 个税是什么？谁需要交

个人所得税（简称"个税"）就是国家对你的收入征收的税。简单说：**你赚了钱，需要拿出一部分交给国家。**

在中国，以下类型的收入需要缴纳个税（截至2026年）：

- 工资薪金（你的月薪、年终奖等）
- 劳务报酬（兼职、自由职业收入）
- 稿酬（写文章、出书的收入）
- 特许权使用费（专利、商标授权收入）
- 经营所得（像小王开奶茶店的收入）
- 利息、股息、红利
- 财产租赁和转让所得

前四项合称为**"综合所得"**，按年合并计税。

## 8.2 综合所得与累进税率

中国对综合所得实行**七级超额累进税率**（截至2026年）：

| 全年应纳税所得额 | 税率 | 速算扣除数 |
| ---------------- | ------ | ----------- |
| 不超过 `36,000` 元 | `3%` | `0` |
| `36,000` ~ `144,000` 元 | `10%` | `2,520` |
| `144,000` ~ `300,000` 元 | `20%` | `16,920` |
| `300,000` ~ `420,000` 元 | `25%` | `31,920` |
| `420,000` ~ `660,000` 元 | `30%` | `52,920` |
| `660,000` ~ `960,000` 元 | `35%` | `85,920` |
| 超过 `960,000` 元 | `45%` | `181,920` |

"超额累进"的意思是：**不是你赚到了高税率区间，所有收入都按高税率交税，而是只有超出部分按更高的税率交。**

举个例子：假设小王全年应纳税所得额是 `50,000` 元。其中 `36,000` 元按 `3%` 交税（`1,080` 元），剩下的 `14,000` 元按 `10%` 交税（`1,400` 元），总共 `2,480` 元。用速算扣除数计算也一样：`50,000 × 10% - 2,520 = 2,480` 元。

## 8.3 起征点与专项扣除

**起征点（基本减除费用）**：每年 `60,000` 元（即每月 `5,000` 元，截至2026年）。也就是说，年收入低于 `6` 万的部分不用交税。

但 `6` 万不是唯一的扣除项。在计算应纳税所得额时，还可以扣除：

**应纳税所得额 = 年收入 - 60,000元 - 五险一金个人缴纳部分 - 专项附加扣除**

五险一金的个人缴纳部分（第五章讲过）是可以全额在税前扣除的。这意味着你交的社保和公积金，本身就不用交税。

## 8.4 专项附加扣除

这是2019年个税改革后新增的福利，让税负更加公平。截至2026年，有以下七项专项附加扣除：

| 扣除项目 | 每月标准 | 适用条件 |
| --------- | --------- | --------- |
| 子女教育 | 每个子女 `2,000` 元 | 子女满3岁至博士毕业 |
| 继续教育 | 学历教育 `400` 元/月 | 或职业资格取证当年 `3,600` 元 |
| 住房贷款利息 | `1,000` 元 | 首套房贷，最长240个月 |
| 住房租金 | `800~1,500` 元 | 根据城市级别不同 |
| 赡养老人 | `3,000` 元 | 父母年满60岁（独生子女全额，非独分摊） |
| 大病医疗 | 据实扣除，上限 `80,000` 元/年 | 医保目录内自付部分超 `15,000` 元 |
| 3岁以下婴幼儿照护 | 每个婴幼儿 `2,000` 元 | 出生当月至满3岁前一个月 |

> 💡 **提示**：房贷利息和住房租金**只能选一个**扣除。如果你在一线城市租房（每月可扣 `1,500` 元），同时老家有首套房贷（每月可扣 `1,000` 元），那选租房扣除更划算。

## 8.5 年度汇算清缴：为什么每年3-6月要做

公司给你发工资时，每个月会**预扣预缴**个税。但预扣预缴不一定准确，因为：

- 你可能年中换了工作，两家公司各自预扣导致重复计算起征点
- 你可能有专项附加扣除没在平时申报
- 你可能有多处收入（比如工资+兼职劳务报酬）

**年度汇算清缴**就是把全年的收入加在一起，重新算一遍你到底该交多少税，然后多退少补。时间是次年的 **3月1日至6月30日**。

> 💡 **提示**：很多人可以通过汇算清缴获得退税，因为平时预扣的税可能多了。但也有可能需要补税（比如有多处收入的人）。不管退还是补，**都应该按时申报**，不申报可能面临罚款。

## 8.6 年终奖计税方式

年终奖有两种计税方式（截至2026年的过渡期政策）：

1. **单独计税**：年终奖单独按一个月度税率表计算，不并入工资。
2. **并入综合所得**：年终奖加到全年工资里一起算。

哪种更划算？取决于你的收入水平。**一般来说，如果你的日常工资不高、年终奖较高，单独计税可能更省税；如果日常工资已经很高，并入可能更合适。** 在个税APP里，两种方式可以分别试算，选退税多（或补税少）的那种。

## 8.7 个体工商户的税务：小王奶茶店怎么交税

小王的奶茶店是个体工商户，这属于**"经营所得"**，和综合所得分开计税。

经营所得适用五级超额累进税率（`5%~35%`）。不过，很多地方对小规模个体工商户实行**核定征收**——税务局根据你的经营规模直接给你一个固定的税额，省去了复杂的账目核算。

此外，小王作为个体户，还可以享受一些税收优惠，比如小规模纳税人增值税减免等。

> 💡 **提示**：如果你也是个体经营者，建议咨询当地税务局或专业税务顾问，了解自己适用的具体政策和申报方式。不同地区、不同规模的差异很大。

## 8.8 合法节税 ≠ 偷税漏税

合法节税是**在法律允许的框架内，合理安排自己的财务，减少税负**。偷税漏税是**隐瞒收入、虚报信息，逃避纳税义务**——这是违法的。

几个合规的税务优化思路：

1. **充分利用专项附加扣除**：很多人忘了申报，白白多交了税。
2. **合理分配年终奖比例**：在允许的情况下，和公司商量年终奖的发放方式。
3. **善用个人养老金账户**：截至2026年，个人养老金账户每年可缴纳 `12,000` 元，这部分可以在税前扣除。相当于国家补贴你一部分来为养老储蓄。
4. **公益捐赠扣除**：通过合规渠道的公益捐赠，可以在应纳税所得额 `30%` 以内扣除。
5. **保留好发票和凭证**：特别是自由职业者和个体经营者，合理的成本支出可以抵减收入。

## 8.9 实战：小王第一次做汇算清缴

小王打开个人所得税APP，跟着流程操作：

1. **确认基本信息**：手机号、银行卡号（退税用的）
2. **确认收入数据**：APP自动显示了他去年在公司的工资收入
3. **核对扣除信息**：
   - 五险一金扣除 ✅（公司已经代扣）
   - 住房租金扣除：小王在二线城市租房，每月可扣 `1,100` 元，全年 `13,200` 元——他之前忘了申报！
   - 赡养老人扣除：小王是独生子，父母都超过60岁，每月可扣 `3,000` 元，全年 `36,000` 元——也忘了！
4. **试算年终奖**：小王年终奖 `2` 万元，试了两种方式，单独计税更划算
5. **提交申报**：结果显示可退税 `1,200` 元，绑定银行卡，等待到账

小王高兴地说："原来报税还能退钱！"老陈在旁边提醒："这是因为你平时多交了。以后记得年初就把专项附加扣除填好，这样每月预扣就更准确，不用等到年底再退。"

### 本章小结

| 知识点 | 核心要点 |
| -------- | --------- |
| 个税基础 | 对收入征税，综合所得（工资、劳务、稿酬、特许权）按年合并计税 |
| 累进税率 | 收入越高税率越高（`3%~45%`），但只有超出部分适用更高税率 |
| 起征点 | 每年 `60,000` 元（每月 `5,000` 元），截至2026年 |
| 专项附加扣除 | 7项，务必在个税APP中及时申报 |
| 汇算清缴 | 每年3-6月，多退少补，必须申报 |
| 年终奖 | 可选单独计税或并入综合所得，试算后选更优方案 |
| 合法节税 | 充分利用扣除项和优惠政策，绝不触碰法律红线 |

### 练习题

**基础题**：小李全年综合所得收入 `15` 万元，五险一金个人缴纳 `2` 万元，专项附加扣除合计 `3` 万元。请问他的应纳税所得额是多少？适用哪一级税率？应缴多少个税？

**进阶题**：小张年终奖 `6` 万元，全年工资扣除各项后应纳税所得额 `8` 万元。请比较年终奖"单独计税"和"并入综合所得"两种方式，哪种更省税？（提示：单独计税时，`6` 万除以12得 `5,000` 元，对应税率 `10%`，速算扣除数 `210`）

**挑战题**：有人认为"避税就是不交税，所以我不申报汇算清缴也没关系"。请从法律和财务两个角度，分析这种想法的危险性。
