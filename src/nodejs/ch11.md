# 第11章：网络编程——TCP/UDP 从零实现

## 引言：互联网就是一堆管道

如果你把互联网想象成一个城市的供水系统：

- **TCP** 就像自来水管——可靠、有顺序、不漏水（丢包重传）
- **UDP** 就像消防栓洒水——快、但不保证每滴水都到了
- **HTTP** 就像你家水龙头——建立在 TCP 管道之上的"应用层协议"

大多数开发者直接用 HTTP 框架（Express、Koa），从来不碰底层的 TCP/UDP。但理解网络底层，就像厨师理解食材的化学成分——你不需要每天用，但关键时刻能救命。

## 11.1 net 模块：TCP 编程

### 创建 TCP 服务器

```javascript
import { createServer } from 'node:net';

const server = createServer((socket) => {
  // 每个新的 TCP 连接都会触发这个回调
  const clientAddr = `${socket.remoteAddress}:${socket.remotePort}`;
  console.log(`新连接: ${clientAddr}`);

  // socket 是一个 Duplex Stream（可读可写）
  socket.write('欢迎连接到我的服务器！\n');

  // 接收客户端数据
  socket.on('data', (data) => {
    console.log(`[${clientAddr}] 说: ${data.toString().trim()}`);
    // 回显（Echo）
    socket.write(`你说了: ${data}`);
  });

  // 连接关闭
  socket.on('end', () => {
    console.log(`${clientAddr} 断开连接`);
  });

  // 错误处理
  socket.on('error', (err) => {
    console.error(`${clientAddr} 错误:`, err.message);
  });
});

server.listen(8080, '0.0.0.0', () => {
  console.log('TCP 服务器监听在 0.0.0.0:8080');
});

// 服务器级别的错误
server.on('error', (err) => {
  if (err.code === 'EADDRINUSE') {
    console.error('端口 8080 已被占用！');
  }
});
```

### 创建 TCP 客户端

```javascript
import { connect } from 'node:net';

const client = connect({ port: 8080, host: '127.0.0.1' }, () => {
  console.log('已连接到服务器');
  client.write('你好，服务器！\n');
});

client.on('data', (data) => {
  console.log('服务器回复:', data.toString());
});

client.on('end', () => {
  console.log('连接已关闭');
});

client.on('error', (err) => {
  console.error('连接错误:', err.message);
});

// 5秒后断开
setTimeout(() => {
  client.end('再见！\n'); // end() 发送数据后关闭连接
}, 5000);
```

### Socket 的重要属性和方法

```typescript
import { Socket } from 'node:net';

// Socket 是 Duplex Stream 的子类
```

## 11.2 TCP 粘包/拆包问题

### 什么是粘包？

TCP 是**字节流**协议，它不关心你的"消息边界"。就像往水管里倒了三杯水，到了另一头，它分不清哪一杯是哪一杯。

```javascript
// 客户端发送三条消息
client.write('消息1');
client.write('消息2');
client.write('消息3');

// 服务端可能收到：
// 情况1（正常）：'消息1' + '消息2' + '消息3'（三次 data 事件）
// 情况2（粘包）：'消息1消息2消息3'（一次 data 事件）
// 情况3（拆包）：'消息1消' + '息2消息3'（两次 data 事件，消息被切断）
// 情况4（混合）：'消息1消息2' + '消息3'（一次粘包 + 正常）
```

### 解决方案1：固定长度

```javascript
// 每条消息固定 100 字节，不够补空格
const MSG_LENGTH = 100;

// 发送
function send(socket, msg) {
  const padded = msg.padEnd(MSG_LENGTH, ' ');
  socket.write(padded);
}

// 接收
let buffer = '';
socket.on('data', (data) => {
  buffer += data.toString();
  while (buffer.length >= MSG_LENGTH) {
    const message = buffer.slice(0, MSG_LENGTH).trim();
    buffer = buffer.slice(MSG_LENGTH);
    console.log('收到:', message);
  }
});
```

### 解决方案2：分隔符

```javascript
// 用换行符 \n 分隔消息
const DELIMITER = '\n';

// 发送
function send(socket, msg) {
  socket.write(msg + DELIMITER);
}

// 接收
let buffer = '';
socket.on('data', (data) => {
  buffer += data.toString();
  let delimiterIndex;
  while ((delimiterIndex = buffer.indexOf(DELIMITER)) !== -1) {
    const message = buffer.slice(0, delimiterIndex);
    buffer = buffer.slice(delimiterIndex + DELIMITER.length);
    console.log('收到:', message);
  }
});
```

### 解决方案3：长度前缀（最推荐）

```typescript
// 消息格式：[4字节长度][消息内容]
// 这是最常用的方案

class LengthPrefixProtocol {
  private buffer: Buffer = Buffer.alloc(0);
  private onMessage: (msg: Buffer) => void;

  constructor(onMessage: (msg: Buffer) => void) {
    this.onMessage = onMessage;
  }

  /**
   * 编码消息：添加4字节长度前缀
   */
  static encode(data: string | Buffer): Buffer {
    const body = typeof data === 'string' ? Buffer.from(data, 'utf8') : data;
    const header = Buffer.alloc(4);
    header.writeUInt32BE(body.length, 0);
    return Buffer.concat([header, body]);
  }

  /**
   * 喂入从 socket 收到的数据
   */
  feed(data: Buffer): void {
    this.buffer = Buffer.concat([this.buffer, data]);

    while (this.buffer.length >= 4) {
      const bodyLength = this.buffer.readUInt32BE(0);

      // 数据还没收全
      if (this.buffer.length < 4 + bodyLength) {
        break;
      }

      // 提取完整消息
      const message = this.buffer.subarray(4, 4 + bodyLength);
      this.buffer = this.buffer.subarray(4 + bodyLength);

      this.onMessage(message);
    }
  }
}

// 使用
const protocol = new LengthPrefixProtocol((msg) => {
  console.log('收到完整消息:', msg.toString());
});

socket.on('data', (data) => {
  protocol.feed(data);
});

// 发送
socket.write(LengthPrefixProtocol.encode('Hello World'));
socket.write(LengthPrefixProtocol.encode('这是一条完整的消息'));
```

## 11.3 dgram 模块：UDP 通信

UDP 是"发了就忘"的协议——不建立连接、不保证送达、不保证顺序。但它**快**，适合：

- 实时音视频
- 游戏状态同步
- DNS 查询
- 服务发现（广播/组播）

### UDP 服务端

```javascript
import { createSocket } from 'node:dgram';

const server = createSocket('udp4');

server.on('message', (msg, rinfo) => {
  console.log(`收到来自 ${rinfo.address}:${rinfo.port} 的消息: ${msg}`);

  // 回复
  const reply = Buffer.from(`收到: ${msg}`);
  server.send(reply, rinfo.port, rinfo.address);
});

server.on('listening', () => {
  const addr = server.address();
  console.log(`UDP 服务器监听在 ${addr.address}:${addr.port}`);
});

server.on('error', (err) => {
  console.error('UDP 错误:', err);
  server.close();
});

server.bind(41234);
```

### UDP 客户端

```javascript
import { createSocket } from 'node:dgram';

const client = createSocket('udp4');

const message = Buffer.from('你好 UDP！');
client.send(message, 41234, '127.0.0.1', (err) => {
  if (err) {
    console.error('发送失败:', err);
    client.close();
    return;
  }
  console.log('消息已发送');
});

// 接收回复
client.on('message', (msg) => {
  console.log('服务器回复:', msg.toString());
  client.close();
});
```

### UDP 广播

```javascript
import { createSocket } from 'node:dgram';

// 广播发送者
const broadcaster = createSocket('udp4');
broadcaster.bind(() => {
  broadcaster.setBroadcast(true); // 启用广播

  setInterval(() => {
    const msg = Buffer.from(JSON.stringify({
      service: 'my-app',
      port: 3000,
      timestamp: Date.now(),
    }));
    broadcaster.send(msg, 41235, '255.255.255.255');
  }, 3000);
});

// 广播接收者
const listener = createSocket('udp4');
listener.on('message', (msg, rinfo) => {
  const data = JSON.parse(msg.toString());
  console.log(`发现服务: ${data.service} at ${rinfo.address}:${data.port}`);
});
listener.bind(41235);
```

## 11.4 TLS/SSL：安全连接

```javascript
import { createServer, connect } from 'node:tls';
import { readFileSync } from 'node:fs';

// TLS 服务器（需要证书）
const tlsServer = createServer(
  {
    key: readFileSync('./server-key.pem'),
    cert: readFileSync('./server-cert.pem'),
    // 客户端证书验证（双向认证）
    // ca: [readFileSync('./ca-cert.pem')],
    // requestCert: true,
  },
  (socket) => {
    console.log('TLS 连接建立');
    console.log('客户端证书:', socket.getPeerCertificate());
    socket.write('安全的 Hello!\n');
    socket.pipe(socket); // Echo
  }
);

tlsServer.listen(8443, () => {
  console.log('TLS 服务器监听在 8443');
});

// TLS 客户端
const tlsClient = connect(
  {
    port: 8443,
    host: 'localhost',
    // 开发环境可以跳过证书验证（生产环境不要！）
    rejectUnauthorized: false,
  },
  () => {
    console.log('TLS 连接成功');
    console.log('协议:', tlsClient.getProtocol()); // 'TLSv1.3'
    tlsClient.write('加密的消息\n');
  }
);

tlsClient.on('data', (data) => {
  console.log('收到:', data.toString());
});
```

## 11.5 DNS 模块

```javascript
import { promises as dns } from 'node:dns';

// 解析域名
const addresses = await dns.resolve4('google.com');
console.log('IPv4:', addresses); // ['142.250.xx.xx', ...]

const ipv6 = await dns.resolve6('google.com');
console.log('IPv6:', ipv6);

// 反向解析
const hostnames = await dns.reverse('8.8.8.8');
console.log('主机名:', hostnames); // ['dns.google']

// MX 记录（邮件服务器）
const mx = await dns.resolveMx('gmail.com');
console.log('邮件服务器:', mx);
// [{ exchange: 'gmail-smtp-in.l.google.com', priority: 5 }, ...]

// CNAME 记录
const cname = await dns.resolveCname('www.github.com');
console.log('CNAME:', cname);

// TXT 记录（SPF、域名验证等）
const txt = await dns.resolveTxt('google.com');
console.log('TXT:', txt);

// lookup vs resolve
// lookup：使用操作系统的 DNS 缓存（调用 getaddrinfo）
const result = await dns.lookup('localhost');
console.log(result); // { address: '127.0.0.1', family: 4 }

// resolve：直接发送 DNS 查询到 DNS 服务器
const resolved = await dns.resolve4('example.com');
```

**lookup vs resolve 的区别**：

- `lookup` 走操作系统（读 /etc/hosts，用系统 DNS 缓存），在 libuv 线程池中执行
- `resolve` 直接发 UDP 包到 DNS 服务器，纯异步，不走线程池

## 11.6 实战案例

### 实战1：简易聊天室（TCP）

```typescript
import { createServer, Socket } from 'node:net';

interface Client {
  socket: Socket;
  nickname: string;
}

const clients: Map<Socket, Client> = new Map();

const server = createServer((socket) => {
  const client: Client = {
    socket,
    nickname: `用户${clients.size + 1}`,
  };
  clients.set(socket, client);

  broadcast(`[系统] ${client.nickname} 加入了聊天室（当前 ${clients.size} 人）`);
  socket.write(`欢迎 ${client.nickname}！输入 /nick <名字> 修改昵称，/quit 退出\n`);

  socket.on('data', (data) => {
    const msg = data.toString().trim();
    if (!msg) return;

    // 命令处理
    if (msg.startsWith('/nick ')) {
      const oldName = client.nickname;
      client.nickname = msg.slice(6).trim();
      broadcast(`[系统] ${oldName} 改名为 ${client.nickname}`);
    } else if (msg === '/quit') {
      socket.end('再见！\n');
    } else if (msg === '/list') {
      const list = [...clients.values()]
        .map(c => c.nickname)
        .join(', ');
      socket.write(`在线用户: ${list}\n`);
    } else {
      broadcast(`[${client.nickname}] ${msg}`, socket);
    }
  });

  socket.on('end', () => {
    clients.delete(socket);
    broadcast(`[系统] ${client.nickname} 离开了聊天室`);
  });

  socket.on('error', (err) => {
    clients.delete(socket);
    console.error(`客户端错误: ${err.message}`);
  });
});

function broadcast(message: string, exclude?: Socket): void {
  for (const [sock, _] of clients) {
    if (sock !== exclude && !sock.destroyed) {
      sock.write(message + '\n');
    }
  }
}

server.listen(9000, () => {
  console.log('聊天室启动，使用 telnet 127.0.0.1 9000 连接');
});
```

### 实战2：从 TCP 层理解 HTTP

```typescript
import { createServer } from 'node:net';

/**
 * 手写一个极简 HTTP 服务器（从 TCP 层实现）
 * 目的：理解 HTTP 协议的本质就是文本格式的 TCP 通信
 */
const httpServer = createServer((socket) => {
  socket.on('data', (data) => {
    const request = data.toString();

    // 解析 HTTP 请求
    const [requestLine, ...headerLines] = request.split('\r\n');
    const [method, path, version] = requestLine.split(' ');

    // 解析请求头
    const headers: Record<string, string> = {};
    for (const line of headerLines) {
      if (line === '') break; // 空行表示头部结束
      const [key, ...valueParts] = line.split(': ');
      headers[key.toLowerCase()] = valueParts.join(': ');
    }

    console.log(`${method} ${path} ${version}`);
    console.log('Headers:', headers);

    // 路由处理
    let statusCode = 200;
    let statusText = 'OK';
    let body = '';
    let contentType = 'text/html; charset=utf-8';

    if (path === '/') {
      body = '<h1>Hello from raw TCP!</h1><p>This HTTP response was crafted byte by byte.</p>';
    } else if (path === '/json') {
      contentType = 'application/json';
      body = JSON.stringify({ message: 'Hello', timestamp: Date.now() });
    } else {
      statusCode = 404;
      statusText = 'Not Found';
      body = '<h1>404 Not Found</h1>';
    }

    // 构造 HTTP 响应（纯文本格式！）
    const response = [
      `HTTP/1.1 ${statusCode} ${statusText}`,
      `Content-Type: ${contentType}`,
      `Content-Length: ${Buffer.byteLength(body)}`,
      `Connection: close`,
      `Date: ${new Date().toUTCString()}`,
      `Server: MyRawHTTP/1.0`,
      '',  // 空行分隔头部和正文
      body,
    ].join('\r\n');

    socket.write(response);
    socket.end();
  });
});

httpServer.listen(8080, () => {
  console.log('手写 HTTP 服务器运行在 http://localhost:8080');
  console.log('试试 curl http://localhost:8080');
  console.log('试试 curl http://localhost:8080/json');
});
```

### 实战3：UDP 服务发现

```typescript
import { createSocket, Socket as DgramSocket } from 'node:dgram';
import { networkInterfaces } from 'node:os';

interface ServiceInfo {
  name: string;
  port: number;
  host: string;
  metadata?: Record<string, string>;
}

const DISCOVERY_PORT = 41234;
const MULTICAST_ADDR = '239.255.255.250'; // 局域网组播地址

/**
 * 服务注册者：定期广播自己的存在
 */
class ServiceAnnouncer {
  private socket: DgramSocket;
  private interval: NodeJS.Timeout | null = null;
  private serviceInfo: ServiceInfo;

  constructor(serviceInfo: ServiceInfo) {
    this.serviceInfo = serviceInfo;
    this.socket = createSocket({ type: 'udp4', reuseAddr: true });
  }

  start(): void {
    this.socket.bind(() => {
      this.socket.setBroadcast(true);
      this.socket.addMembership(MULTICAST_ADDR);

      // 每 3 秒广播一次
      this.interval = setInterval(() => {
        const msg = Buffer.from(JSON.stringify({
          type: 'announce',
          service: this.serviceInfo,
          timestamp: Date.now(),
        }));
        this.socket.send(msg, DISCOVERY_PORT, MULTICAST_ADDR);
      }, 3000);

      console.log(`[Announcer] 开始广播服务: ${this.serviceInfo.name}`);
    });
  }

  stop(): void {
    if (this.interval) {
      clearInterval(this.interval);
    }
    this.socket.close();
  }
}

/**
 * 服务发现者：监听广播，发现可用服务
 */
class ServiceDiscoverer {
  private socket: DgramSocket;
  private services: Map<string, ServiceInfo & { lastSeen: number }> = new Map();

  constructor() {
    this.socket = createSocket({ type: 'udp4', reuseAddr: true });
  }

  start(): void {
    this.socket.on('message', (msg, rinfo) => {
      try {
        const data = JSON.parse(msg.toString());
        if (data.type === 'announce') {
          const key = `${data.service.name}@${rinfo.address}:${data.service.port}`;
          const isNew = !this.services.has(key);

          this.services.set(key, {
            ...data.service,
            host: rinfo.address,
            lastSeen: Date.now(),
          });

          if (isNew) {
            console.log(`[Discovery] 发现新服务: ${key}`);
          }
        }
      } catch (e) {
        // 忽略无法解析的消息
      }
    });

    this.socket.bind(DISCOVERY_PORT, () => {
      this.socket.addMembership(MULTICAST_ADDR);
      console.log('[Discovery] 开始监听服务广播...');
    });

    // 定期清理过期服务（超过 10 秒没有广播的视为下线）
    setInterval(() => {
      const now = Date.now();
      for (const [key, service] of this.services) {
        if (now - service.lastSeen > 10000) {
          this.services.delete(key);
          console.log(`[Discovery] 服务下线: ${key}`);
        }
      }
    }, 5000);
  }

  getServices(): ServiceInfo[] {
    return [...this.services.values()];
  }
}

// 使用示例
const announcer = new ServiceAnnouncer({
  name: 'my-api-server',
  port: 3000,
  metadata: { version: '1.0.0', env: 'production' },
  host: '',
});
announcer.start();

const discoverer = new ServiceDiscoverer();
discoverer.start();
```

## 11.7 常见坑点

### 坑1：忘记处理半关闭状态

```javascript
// TCP 连接是双向的，可以单独关闭一个方向
socket.end(); // 关闭写入方向（发送 FIN），但仍然可以读取
// socket 进入 "半关闭" 状态

// ❌ end 之后还能 write 吗？
socket.end();
socket.write('hello'); // 不会报错，但数据不会发出去！

// ✅ 监听 'end' 事件知道对方关闭了写入
socket.on('end', () => {
  console.log('对方不再发送数据了');
  socket.end(); // 我也关闭
});
```

### 坑2：地址已被占用 (EADDRINUSE)

```javascript
server.on('error', (err) => {
  if (err.code === 'EADDRINUSE') {
    console.error(`端口 ${port} 已被占用`);
    // 策略1：换一个端口
    server.listen(port + 1);
    // 策略2：等待后重试
    setTimeout(() => server.listen(port), 1000);
  }
});
```

### 坑3：没有设置超时

```javascript
// ❌ 客户端可能永远挂着不发数据，占用服务器资源
const server = createServer((socket) => {
  socket.on('data', handleData);
});

// ✅ 设置超时
const server = createServer((socket) => {
  socket.setTimeout(30000); // 30秒无数据则超时
  socket.on('timeout', () => {
    console.log('连接超时');
    socket.end('超时断开\n');
  });
  socket.on('data', handleData);
});
```

## 11.8 本章小结

| 模块 | 协议 | 特点 | 场景 |
| ------ | ------ | ------ | ------ |
| net | TCP | 可靠、有序、面向连接 | HTTP、数据库连接、RPC |
| dgram | UDP | 快速、无连接、不可靠 | 实时音视频、DNS、服务发现 |
| tls | TLS/SSL | TCP + 加密 | HTTPS、安全通信 |
| dns | DNS | 域名解析 | 地址查找 |

**核心原则**：

1. TCP 是字节流，需要自己处理消息边界
2. 长度前缀是最靠谱的粘包解决方案
3. UDP 快但不可靠，适合容忍丢包的场景
4. 生产环境一定要用 TLS 加密
5. 设置合理的超时时间
