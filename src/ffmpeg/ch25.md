# FFmpeg 高频命令速查库

> 所有命令中 `input` / `output` 请替换为实际文件名。质量参数按需微调。

---

## 格式转换与压缩

**通用转码（质量优先）**

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset medium output.mp4
```

> crf: 18 近无损 / 23 默认 / 28 明显压缩。preset 越慢压缩率越好。

**大幅压缩文件体积**

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 128k output.mp4
```

**转为 H.265（HEVC），体积更小**

```bash
ffmpeg -i input.mp4 -c:v libx265 -crf 28 -preset medium output.mp4
```

**只换容器不重编码（秒级完成）**

```bash
ffmpeg -i input.mkv -c copy output.mp4
```

## 音频操作

**提取音频（不重编码）**

```bash
ffmpeg -i input.mp4 -vn -c:a copy output.aac
```

**提取为 MP3**

```bash
ffmpeg -i input.mp4 -vn -c:a libmp3lame -b:a 192k output.mp3
```

**去掉音频（保留纯视频）**

```bash
ffmpeg -i input.mp4 -an -c:v copy output.mp4
```

**给视频换音频**

```bash
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 -shortest output.mp4
```

## 剪辑与拼接

**截取片段（快速，不重编码）**

```bash
ffmpeg -ss 00:01:00 -to 00:02:30 -i input.mp4 -c copy clip.mp4
```

> `-ss` 放在 `-i` 前面是快速定位（跳到关键帧），放在后面是精确逐帧定位。

**截取片段（精确到帧，会重编码）**

```bash
ffmpeg -i input.mp4 -ss 00:01:00 -to 00:02:30 -c:v libx264 -crf 23 clip.mp4
```

**拼接多个视频**

先创建 `list.txt`：

```
file 'part1.mp4'
file 'part2.mp4'
file 'part3.mp4'
```

然后：

```bash
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
```

## 分辨率与画面

**缩放分辨率**

```bash
ffmpeg -i input.mp4 -vf scale=1280:720 -c:a copy output.mp4
```

**等比缩放，宽度 1280，高度自动**

```bash
ffmpeg -i input.mp4 -vf "scale=1280:-2" -c:a copy output.mp4
```

**裁剪画面（从左上角 x=100, y=100 裁出 640x480）**

```bash
ffmpeg -i input.mp4 -vf "crop=640:480:100:100" output.mp4
```

**旋转 90 度（顺时针）**

```bash
ffmpeg -i input.mp4 -vf "transpose=1" output.mp4
```

> 0=逆时针90° / 1=顺时针90° / 2=逆时针90°+翻转 / 3=顺时针90°+翻转

**添加图片水印（右下角）**

```bash
ffmpeg -i input.mp4 -i logo.png -filter_complex "overlay=W-w-10:H-h-10" output.mp4
```

> W-w-10 = 右边缘留 10px，H-h-10 = 下边缘留 10px。

**添加文字水印**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='Copyright':fontsize=24:fontcolor=white:x=W-tw-10:y=H-th-10" output.mp4
```

## 帧率与速度

**改变输出帧率**

```bash
ffmpeg -i input.mp4 -r 30 -c:a copy output.mp4
```

**视频加速 2 倍**

```bash
ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=0.5*PTS[v];[0:a]atempo=2.0[a]" -map "[v]" -map "[a]" output.mp4
```

**视频减速 0.5 倍（慢动作）**

```bash
ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=2.0*PTS[v];[0:a]atempo=0.5[a]" -map "[v]" -map "[a]" output.mp4
```

## GIF 与图片

**视频转 GIF（控制质量和帧率）**

```bash
ffmpeg -i input.mp4 -vf "fps=15,scale=480:-1:flags=lanczos" output.gif
```

**视频转高质量 GIF（两遍调色板）**

```bash
ffmpeg -i input.mp4 -vf "fps=15,scale=480:-1,palettegen" palette.png
ffmpeg -i input.mp4 -i palette.png -filter_complex "fps=15,scale=480:-1[x];[x][1:v]paletteuse" output.gif
```

**每隔 N 秒截一张图**

```bash
ffmpeg -i input.mp4 -vf "fps=1/5" frame_%04d.png
```

> 每 5 秒截一帧。

**截取某一帧为图片**

```bash
ffmpeg -ss 00:00:05 -i input.mp4 -frames:v 1 screenshot.png
```

**图片合成视频（每张 3 秒）**

```bash
ffmpeg -framerate 1/3 -i img%04d.png -r 30 -c:v libx264 -pix_fmt yuv420p output.mp4
```

**视频导出为图片序列**

```bash
ffmpeg -i input.mp4 frame_%04d.png
```

## 字幕

**将字幕烧录进画面（硬字幕）**

```bash
ffmpeg -i input.mp4 -vf "subtitles=sub.srt" output.mp4
```

**将字幕嵌入为软字幕流（可开关）**

```bash
ffmpeg -i input.mp4 -i sub.srt -c copy -c:s mov_text output.mp4
```

**提取字幕**

```bash
ffmpeg -i input.mp4 -c:s copy output.srt
```

## 录屏与设备采集（Windows）

**录制全屏**

```bash
ffmpeg -f gdigrab -framerate 30 -i desktop -c:v libx264 -preset ultrafast output.mp4
```

**录制指定窗口**

```bash
ffmpeg -f gdigrab -framerate 30 -i title="窗口标题" output.mp4
```

**录制屏幕 + 麦克风**

```bash
ffmpeg -f gdigrab -framerate 30 -i desktop -f dshow -i audio="麦克风设备名" -c:v libx264 -c:a aac output.mp4
```

**查看可用设备**

```bash
ffmpeg -list_devices true -f dshow -i dummy
```

## 信息查询

**查看视频完整信息**

```bash
ffprobe -v quiet -print_format json -show_format -show_streams input.mp4
```

**查看编码格式和分辨率**

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height -of default=noprint_wrappers=1 input.mp4
```

**查看视频时长**

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 input.mp4
```

**查看 GOP 结构（帧类型序列）**

```bash
ffprobe -v error -select_streams v:0 -show_entries frame=pict_type -of csv=print_section=0 input.mp4
```

## 实用技巧

**预览效果（不输出文件，直接播放）**

```bash
ffplay -vf "hue=h=90" input.mp4
```

**批量转码（Windows CMD 循环）**

```cmd
for %i in (*.mp4) do ffmpeg -i "%i" -c:v libx265 -crf 28 "out_%i"
```

**限制输出文件大小（如 50MB）**

```bash
ffmpeg -i input.mp4 -c:v libx264 -fs 50M output.mp4
```

**设置视频封面/缩略图**

```bash
ffmpeg -i input.mp4 -i cover.jpg -map 0 -map 1 -c copy -disposition:v:1 attached_pic output.mp4
```
