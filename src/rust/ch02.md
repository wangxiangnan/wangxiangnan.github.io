# 第2章：变量、可变性与数据类型

## 从一杯咖啡说起

你去咖啡店点单，有两种模式：

- **写在纸杯上的名字**：可以擦掉重写（可变）
- **刻在奖杯上的名字**：一旦刻好就不能改（不可变）

Rust 里，变量默认是"刻在奖杯上的"——不可变。这是 Rust 安全哲学的第一道防线。

## let 与 let mut

```rust
fn main() {
    let x = 5;
    // x = 6;  // 编译错误！x 不可变

    let mut y = 5;
    y = 6;     // 没问题，y 是可变的
    println!("y = {}", y);
}
```

**与其他语言对比：**

| Rust | JavaScript | Python | Java |
| ------ | ----------- | -------- | ------ |
| `let x = 5;` | `const x = 5;` | `x = 5`（Python无const） | `final int x = 5;` |
| `let mut y = 5;` | `let y = 5;` | `y = 5` | `int y = 5;` |

Rust 选择了"默认不可变"——这是一个哲学选择。大多数变量在创建后不需要修改，显式标记 `mut` 能让人一眼看出哪些变量会变。

## 变量遮蔽（Shadowing）

Rust 允许用 `let` 重新声明同名变量，新变量会"遮蔽"旧变量：

```rust
fn main() {
    let x = 5;
    let x = x + 1;        // 新 x 遮蔽旧 x
    let x = x * 2;        // 又一个新 x
    println!("x = {}", x); // 输出 12

    // 甚至可以改变类型！
    let spaces = "   ";          // 字符串类型
    let spaces = spaces.len();   // 整数类型
    println!("spaces = {}", spaces); // 输出 3
}
```

> **Shadowing vs mut**：`let mut` 改变的是同一个变量的值；shadowing 是创建了一个全新的变量（只是名字相同），类型也可以不同。

## 标量类型

### 整数类型

Rust 的整数类型明确区分**有符号（signed）**和**无符号（unsigned）**，并精确指定位数：

| 位数 | 有符号 | 无符号 |
| ------ | -------- | -------- |
| 8位 | `i8` | `u8` |
| 16位 | `i16` | `u16` |
| 32位 | `i32`（默认） | `u32` |
| 64位 | `i64` | `u64` |
| 128位 | `i128` | `u128` |
| 平台相关 | `isize` | `usize` |

```rust
fn main() {
    let a: i32 = 42;           // 十进制
    let b: i32 = 0xff;         // 十六进制
    let c: i32 = 0o77;         // 八进制
    let d: i32 = 0b1111_0000;  // 二进制（可用下划线分隔）
    let e: u8 = b'A';          // 字节（仅u8）

    println!("a={a}, b={b}, c={c}, d={d}, e={e}");
}
```

> **整数溢出**：Debug 模式下溢出会 panic（崩溃），Release 模式下会环绕（wrap around）。比如 `u8` 最大值是 255，255+1=0。

### 浮点类型

```rust
fn main() {
    let x = 2.0;        // 默认 f64
    let y: f32 = 3.0;   // 显式指定 f32

    // 基本运算
    let sum = x + y as f64;  // 需要类型转换
    println!("sum = {sum}");
}
```

> **注意**：Rust 不会自动做数值类型转换，`i32` 和 `i64` 相加会编译错误，必须显式转换。这点和 Python/JS 完全不同。

### 布尔类型

```rust
fn main() {
    let t = true;
    let f: bool = false;  // 显式类型标注

    // 布尔没有"真值性"转换，if 必须接收 bool
    // if 1 { }      // 编译错误！
    // if "hello" { } // 编译错误！
}
```

> **Python 开发者注意**：在 Python 里 `if 1:` 是合法的，但在 Rust 里条件必须是 `bool` 类型，没有隐式转换。

### 字符类型

Rust 的 `char` 是 Unicode 标量值，占 4 字节，用单引号：

```rust
fn main() {
    let c = 'z';
    let z: char = 'ℤ';
    let heart = '💖';  // emoji 也是合法字符！

    println!("{c} {z} {heart}");
}
```

## 复合类型

### 元组（Tuple）

元组可以装不同类型的值：

```rust
fn main() {
    let tup: (i32, f64, bool) = (500, 6.4, true);

    // 解构（destructuring）
    let (x, y, z) = tup;
    println!("x={x}, y={y}, z={z}");

    // 通过索引访问
    let first = tup.0;
    let second = tup.1;
    println!("first={first}, second={second}");

    // 单元元组（空元组）
    let unit: () = ();  // 类似其他语言的 void/None
}
```

### 数组（Array）

数组是固定长度、同类型的集合：

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];           // 类型: [i32; 5]
    let b: [i32; 5] = [1, 2, 3, 4, 5]; // 显式标注

    // 快速初始化
    let zeros = [0; 5];  // [0, 0, 0, 0, 0]

    // 访问（从0开始）
    let first = a[0];
    let second = a[1];

    // 越界访问会 panic！
    // let oops = a[10];  // 运行时崩溃

    println!("first={first}, zeros={:?}", zeros);
}
```

> **数组 vs 向量**：数组长度固定（编译时确定），如果需要动态长度的集合，用 `Vec<T>`（第9章详细讲解）。

## 常量与静态变量

```rust
// 常量：编译时常量，必须有类型标注
const MAX_POINTS: u32 = 100_000;
const PI: f64 = 3.14159265358979;

// 静态变量：有固定内存地址（了解即可）
static HELLO: &str = "Hello, Rust!";

fn main() {
    println!("MAX_POINTS = {MAX_POINTS}");
    println!("PI = {PI}");
    println!("{HELLO}");
}
```

**const vs let 的区别：**

- `const` 不能有 `mut`，永远不可变
- `const` 必须有类型标注
- `const` 的值在编译时就要确定
- `const` 可以在任何作用域声明（包括全局）

## 常见陷阱

1. **忘记 `mut`**：新手最常犯的错误之一，变量默认不可变
2. **整数溢出**：`u8` 存 256 会 panic（Debug模式）
3. **数组越界**：Rust 运行时会检查数组边界，越界会 panic
4. **类型不匹配**：`i32 + f64` 不会自动转换，需要 `as` 显式转换

## 小结

- 变量默认不可变，`mut` 关键字开启可变性
- Shadowing 可以重新声明同名变量，类型也可以变
- Rust 的类型系统严格而明确，不会做隐式类型转换
- 元组装异类，数组装同类（且长度固定）

2. 用 shadowing 实现：将一个字符串 `"123"` 转换为整数 `123`，再转换为浮点数 `123.0`
3. 创建一个元组存储坐标 `(x, y, z)` 和对应标签，用解构取出每个值
4. 创建一个 `[i32; 10]` 的数组，初始值全为 1，打印第5个元素
5. 思考题：为什么 Rust 选择默认不可变，而不是像大多数语言那样默认可变？
