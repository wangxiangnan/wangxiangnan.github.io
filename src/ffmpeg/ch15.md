# 第15章：音频滤镜——声音整形师

很多人关注视频处理时会忽略音频，但你知道吗？研究表明，观众对视频质量的第一印象，**音频质量的影响力甚至超过画面质量**。一段画面精美但声音刺耳的视频，观众会在 5 秒内关闭；而一段画面普通但声音舒适的视频，观众会耐心看完。本章将教你用 FFmpeg 的音频滤镜，让声音焕然一新。

## 15.1 音量调整：volume 滤镜

`volume` 是最基础的音频滤镜，用于增益或衰减音量。

```bash
# 音量增益 6dB
ffmpeg -i input.mp4 -af "volume=6dB" output.mp4

# 音量衰减到原来的 50%
ffmpeg -i input.mp4 -af "volume=0.5" output.mp4

# 音量增益到 1.5 倍
ffmpeg -i input.mp4 -af "volume=1.5" output.mp4
```

**参数说明**：

- 可以传数字（倍数）：`volume=2` 表示音量翻倍
- 可以传 dB 值：`volume=6dB` 表示增加 6 分贝
- 负数 dB 表示衰减：`volume=-3dB`

**适用场景**：录制的声音太小需要放大、多段素材音量不统一需要调整、背景音乐太吵需要降低。

> **警告**：过度增益会导致削波（clipping），产生刺耳的失真。如果音量表显示超过 0dBFS，你就需要减小增益或使用动态压缩。

## 15.2 音量标准化：loudnorm——EBU R128 标准

`loudnorm` 是 FFmpeg 中最智能的音量处理滤镜，它按照 EBU R128 广播标准进行响度归一化。与普通音量调整不同，`loudnorm` 考虑的是**人耳感知的响度**，而非简单的峰值电平。

```bash
# 基本用法：归一化到 EBU R128 标准（-24 LUFS）
ffmpeg -i input.mp4 -af "loudnorm=I=-24:TP=-2:LRA=7" output.mp4
```

| 参数 | 默认值 | 说明 |
| ------ | -------- | ------ |
| `I` | -24 | 目标整合响度（LUFS），-24 是广播标准，-16 适合播客/YouTube |
| `TP` | -2 | 目标真峰值上限（dBTP），防止削波 |
| `LRA` | 7 | 响度范围目标（LU），控制动态范围 |
| `measured_I` | — | 测量到的整合响度（二遍法时使用） |
| `print_format` | — | 设为 `json` 输出测量结果 |

### 二遍法（更精确）

```bash
# 第一遍：分析并输出测量结果
ffmpeg -i input.mp4 -af "loudnorm=print_format=json" -f null -

# 从 JSON 输出中读取测量值，然后：
# 第二遍：使用测量值进行精确归一化
ffmpeg -i input.mp4 -af "loudnorm=I=-16:TP=-1.5:LRA=11:measured_I=-20.5:measured_TP=-3.2:measured_LRA=12.0:measured_thresh=-31.5:offset=0.5:linear=true" output.mp4
```

**适用场景**：播客制作、YouTube 视频上传前的音频标准化、多段音频素材的响度统一。YouTube 的标准大约是 -14 LUFS，Spotify 是 -14 LUFS，Apple Music 是 -16 LUFS。

## 15.3 动态压缩：acompressor

动态压缩器是音频后期处理中的"神器"——它能自动降低响亮的部分、提升安静的部分，让整体音量更均匀。

```bash
ffmpeg -i input.mp4 -af "acompressor=threshold=-20dB:ratio=4:attack=5:release=100:makeup=4" output.mp4
```

| 参数 | 默认值 | 说明 |
| ------ | -------- | ------ |
| `threshold` | -10dB | 阈值，超过此音量的信号会被压缩 |
| `ratio` | 2 | 压缩比，4:1 意味着超出阈值的信号被压缩到 1/4 |
| `attack` | 20ms | 压缩器启动的响应时间 |
| `release` | 250ms | 压缩器释放的恢复时间 |
| `makeup` | 0dB | 压缩后的增益补偿 |

**通俗解释**：想象一个自动音量控制器——当声音太大时，它赶紧把音量拧小；当声音恢复正常时，它慢慢松手。`threshold` 决定"多大声音算太大"，`ratio` 决定"拧小多少"，`attack` 和 `release` 决定"拧快还是拧慢"。

**适用场景**：演讲/播客中说话声音忽大忽小、人声录制中动态范围过大、想让音乐听起来更"紧凑有力"。

## 15.4 均衡器：equalizer 和 biquads

### equalizer：多段均衡

```bash
# 提升低频（增加"厚重感"）
ffmpeg -i input.mp4 -af "equalizer=f=100:t=q:w=1:g=5" output.mp4

# 削减中高频（减少"刺耳感"）
ffmpeg -i input.mp4 -af "equalizer=f=3000:t=q:w=1:g=-3" output.mp4

# 多段均衡：串联多个 equalizer
ffmpeg -i input.mp4 -af "equalizer=f=100:t=q:w=1:g=4,equalizer=f=1000:t=q:w=1:g=-2,equalizer=f=8000:t=q:w=1:g=3" output.mp4
```

| 参数 | 说明 |
| ------ | ------ |
| `f` | 中心频率（Hz） |
| `t` | 滤波器类型：`q`（Q 值）、`h`（Hz 带宽）、`o`（倍频程） |
| `w` | 带宽（取决于 t 的类型） |
| `g` | 增益（dB），正值提升、负值削减 |

**适用场景**：人声增强（提升 2-5kHz 增加清晰度）、去除低频隆隆声（削减 100Hz 以下）、让音乐更"温暖"或更"明亮"。

## 15.5 混音：amix、amerge 和 join

### amix：将多个音频流混合成一个

```bash
# 混合两个音频文件
ffmpeg -i voice.mp4 -i bgm.mp3 -filter_complex "amix=inputs=2:duration=longest:dropout_transition=2" output.mp4

# 混合时降低背景音乐音量
ffmpeg -i voice.mp4 -i bgm.mp3 \
  -filter_complex "[1:a]volume=0.3[bgm];[0:a][bgm]amix=inputs=2" output.mp4
```

| 参数 | 说明 |
| ------ | ------ |
| `inputs` | 输入数量 |
| `duration` | 输出长度策略：`longest`（最长）、`shortest`（最短）、`first`（第一个输入的长度） |
| `dropout_transition` | 当某个输入结束时，音量过渡时间（秒） |

### amerge：合并为多声道

```bash
# 将两个单声道合并为一个立体声
ffmpeg -i left.wav -i right.wav -filter_complex "amerge=inputs=2" output.wav
```

### join：选择性合并声道

```bash
# 从两个单声道创建一个立体声
ffmpeg -i left.wav -i right.wav -filter_complex "join=inputs=2:channel_layout=stereo" output.wav
```

## 15.6 音频淡入淡出：afade

与视频的 `fade` 对应，`afade` 用于音频的淡入淡出。

```bash
# 开头 3 秒淡入
ffmpeg -i input.mp4 -af "afade=t=in:st=0:d=3" output.mp4

# 最后 5 秒淡出（假设总长 120 秒）
ffmpeg -i input.mp4 -af "afade=t=out:st=115:d=5" output.mp4

# 使用余弦曲线淡入（更自然的听觉感受）
ffmpeg -i input.mp4 -af "afade=t=in:st=0:d=3:curve=cos" output.mp4
```

**可用的淡入淡出曲线**（`curve` 参数）：

- `tri`：三角曲线（默认，线性）
- `qsin`：四分之一正弦
- `hsin`：半正弦
- `cos`：余弦（推荐，听感最自然）
- `log`：对数
- `exp`：指数

**适用场景**：播客/视频开头音乐渐入、结尾音乐渐出、段落之间的平滑过渡。

## 15.7 音频变速：atempo

`atempo` 可以调整音频播放速度，同时保持音高不变（不会变成"花栗鼠"声音）。

```bash
# 1.5 倍速
ffmpeg -i input.mp4 -af "atempo=1.5" output.mp4

# 0.8 倍速（慢放）
ffmpeg -i input.mp4 -af "atempo=0.8" output.mp4
```

**重要限制**：`atempo` 的取值范围是 **0.5 到 100**。如果你需要更极端的速度，可以串联多个 `atempo`：

```bash
# 0.25 倍速 = 0.5 × 0.5
ffmpeg -i input.mp4 -af "atempo=0.5,atempo=0.5" output.mp4

# 4 倍速 = 2.0 × 2.0
ffmpeg -i input.mp4 -af "atempo=2.0,atempo=2.0" output.mp4
```

**音视频同步变速**：

```bash
# 同时变速视频和音频（保持同步）
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -af "atempo=2.0" output.mp4
```

注意 `setpts=0.5*PTS` 是 2 倍速，`atempo=2.0` 也是 2 倍速，两者匹配。

**适用场景**：播客/有声书加速收听、视频快进/慢放时保持音频正常、音乐练习时减速但不改变音高。

## 15.8 降噪：afftdn 和 anlmdns

### afftdn：基于 FFT 的降噪

```bash
# 自动噪声底噪估计 + 降噪
ffmpeg -i input.mp4 -af "afftdn=nr=20:nf=-25" output.mp4
```

| 参数 | 说明 |
|------|------|
| `nr` | 降噪强度（dB），范围 0.01-97，默认 12 |
| `nf` | 噪声底噪（dB），设为负值表示自动估计 |

### anlmdns：非局部均值降噪

```bash
ffmpeg -i input.mp4 -af "anlmdns=s=10:p=0.002:r=0.002" output.mp4
```

**选择建议**：一般场景用 `afftdn`（速度快、效果不错）；对质量要求高且不怕等待时用 `anlmdns`。

## 15.9 静音检测与去除

### silencedetect：检测静音段

```bash
# 检测低于 -30dB 且持续超过 2 秒的静音段
ffmpeg -i input.mp4 -af "silencedetect=noise=-30dB:d=2" -f null -
```

输出类似：

```
[silencedetect] silence_start: 5.234
[silencedetect] silence_end: 8.456 | silence_duration: 3.222
[silencedetect] silence_start: 25.100
[silencedetect] silence_end: 30.000 | silence_duration: 4.900
```

### 去除静音段

`silenceremove` 可以自动去除静音：

```bash
# 去除开头的静音
ffmpeg -i input.mp4 -af "silenceremove=start_periods=1:start_duration=0.5:start_threshold=-40dB" output.mp4

# 去除所有静音段（激进模式）
ffmpeg -i input.mp4 -af "silenceremove=start_periods=1:start_duration=0.5:start_threshold=-40dB:stop_periods=-1:stop_duration=0.5:stop_threshold=-40dB" output.mp4
```

**适用场景**：播客/演讲录音中的长时间停顿、监控录音中去除无声音时段、自动裁剪录音的空白开头/结尾。

## 15.10 声道处理：channelsplit、channelmap、pan

### channelsplit：拆分声道

```bash
# 从立体声中分离左声道和右声道
ffmpeg -i stereo.wav -filter_complex "channelsplit=channel_layout=stereo[left][right]" \
  -map "[left]" left.wav -map "[right]" right.wav
```

### channelmap：重新映射声道

```bash
# 交换左右声道
ffmpeg -i input.wav -af "channelmap=1-0|0-1" output.wav

# 只保留左声道
ffmpeg -i input.wav -af "channelmap=0-0" output.wav
```

### pan：灵活的声道混合

```bash
# 立体声转单声道（左右声道平均混合）
ffmpeg -i input.wav -af "pan=mono|c0=0.5*c0+0.5*c1" output.wav

# 创建"假立体声"效果（左右声道略有差异）
ffmpeg -i mono.wav -af "pan=stereo|c0=c0|c1=0.8*c0" output.wav
```

## 15.11 音频延迟与回声：adelay、aecho

### adelay：延迟音频

```bash
# 延迟 1000 毫秒（1 秒）
ffmpeg -i input.mp4 -af "adelay=1000|1000" output.mp4

# 左右声道不同延迟（创造空间感）
ffmpeg -i input.mp4 -af "adelay=100|300" output.mp4
```

### aecho：回声效果

```bash
# 简单的回声效果
ffmpeg -i input.mp4 -af "aecho=0.8:0.7:100|200:0.3|0.2" output.mp4
```

**参数格式**：`aecho=in_gain:out_gain:delays:decays`

- `in_gain`：输入信号增益（0-1）
- `out_gain`：输出信号增益（0-1）
- `delays`：各回声的延迟时间（毫秒），用 `|` 分隔
- `decays`：各回声的衰减系数（0-1），用 `|` 分隔

```bash
# 大厅回声效果
ffmpeg -i input.mp4 -af "aecho=0.8:0.6:500|1000:0.4|0.2" output.mp4

# 小房间回声
ffmpeg -i input.mp4 -af "aecho=0.8:0.7:50|100:0.5|0.3" output.mp4
```

## 15.12 实时响度监控：ebur128

`ebur128` 滤镜可以实时分析音频的响度信息，输出详细的响度报告。

```bash
# 分析音频响度（不输出文件，只输出分析报告）
ffmpeg -i input.mp4 -af "ebur128=peak=true:meter=18" -f null -
```

输出包含：

- **Integrated loudness**：整合响度（最重要的指标，单位 LUFS）
- **Loudness range**：响度范围（动态范围，单位 LU）
- **True peak**：真峰值（单位 dBTP）

**适用场景**：上传视频前检查响度是否符合平台标准、播客制作中确保多期节目响度一致、混音后验证最终输出电平。

## 本章小结

本章我们深入学习了 FFmpeg 的音频滤镜体系：

- **volume**：基础音量调整
- **loudnorm**：EBU R128 响度归一化，播客/视频必备
- **acompressor**：动态压缩，让声音更均匀
- **equalizer**：多段均衡，精细调节各频段
- **amix/amerge/join**：音频混合与声道合并
- **afade**：音频淡入淡出
- **atempo**：音频变速（保持音高）
- **afftdn/anlmdns**：音频降噪
- **silencedetect**：静音检测，配合 silenceremove 去除
- **adelay/aecho**：延迟与回声效果
- **ebur128**：专业响度分析

掌握了视频滤镜和音频滤镜，你已经拥有了 FFmpeg 的"左右手"。下一章，我们将把两者结合起来，学习叠加与合成——画中画、分屏、绿幕抠图等让人兴奋的技术。
