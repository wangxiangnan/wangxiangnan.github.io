# 第2章 认识你的万用表：旋钮、档位与表笔

快递终于到了。小王拆开包装，一块巴掌大的黑色仪器躺在泡沫垫里：一块屏幕、一个大旋钮、三个插孔、两根红黑表笔，外加一本薄薄的说明书。他把表翻来覆去看了十分钟，发现一个严重的问题——表上的每个符号，他都认识，又都不认识。

“V”他在英语单词里见过；“Ω”似曾相识，好像高中物理课本上出现过；“COM”倒是眼熟，像网址的后缀。可这些符号组合在一起，配上密密麻麻的档位刻度，小王觉得自己面前不是一块万用表，而是一架飞机的驾驶舱：仪表齐全，唯独缺个飞行员。

好在小王早有心理准备。他想起自己刚学Excel时，面对满屏工具栏也是这个状态，后来不也啃下来了？办法只有一个：一个符号一个符号地认，一个区域一个区域地拆。本章，我们就陪小王把这块表从上到下、从左到右，拆得明明白白。拆完之后你会发现，它不过是个“脾气直来直去”的家伙，一点都不神秘。

## 2.1 见面三分情：正面看全局

一块典型的数字万用表，正面可以分成三大区域：

- 显示屏：最上方，负责“说话”——把测量结果显示给你看。
- 旋钮档位区：中间，负责“接指令”——你把它转到哪里，它就执行什么任务。
- 表笔插孔区：下方，负责“接线”——通过红黑两根表笔，把表和被测对象连起来。

记住这个分工，整块表就清晰了：显示屏是嘴，旋钮是下达命令的开关，插孔和表笔是手和触角，三者配合，完成一次测量。

不同品牌、型号的表布局略有差异，但万变不离其宗，这三大区域一定都在。你手中的表和书里描述的不完全一样？对照着找一找就好，别怀疑自己买错了表。

## 2.2 显示屏上的符号逐一破译

打开万用表电源，屏幕上会亮起一堆符号。别慌，我们逐个破译。先认识几个最常见的：

- 数字与小数点：测量结果本身，比如“1.53”。读数时要连同小数点一起看，漏掉一个小数点，误差就是十倍。
- V：电压单位“伏特”的符号，测电压时出现，表示此刻读数的单位是“伏”，伏特是纪念物理学家伏打而命名的。mV是毫伏，1伏=1000毫伏。
- A：电流单位“安培”的符号，纪念法国物理学家安培。mA是毫安，1安=1000毫安。
- Ω：电阻单位“欧姆”的符号，纪念德国物理学家欧姆。kΩ是千欧，1千欧=1000欧；MΩ是兆欧，1兆欧=100万欧。
- 负号“-”：测电压、电流时出现负号，表示红黑表笔接反了，交换方向即可，表不会坏。
- 屏幕最左边的“1”或“OL”：这不是读数“1”，而是“超出量程”的提醒——要测的东西超过了当前挡位能显示的范围，该换更大的挡位。OL是英文over load（超载）的缩写。看到它，第一反应不是“表坏了”，而是“挡小了”。
- HOLD字样：按下HOLD键后出现，表示读数被“冻住”了。
- 电池符号：表内电池电量不足的提醒。此时测量结果可能不准，该给表换电池了。
- 蜂鸣符号：切到通断挡时出现，表示“线路通就发声”。

还有两个重要符号常常印在旋钮区：波浪线“~”代表交流，直线“⎓”代表直流，两者区别第3章细讲。

## 2.3 旋钮档位区：像汽车挡位一样理解

旋钮，是万用表的“挡位杆”，用汽车挡位来类比最贴切：挂一挡跑不动高速，挂倒挡往前开会出事。转错挡位，测量要么全错，要么有危险。我们逐一认识各个挡位：

- OFF：熄火挡。所有测量结束后旋钮回到这里，切断表内电源。
- V⎓：直流电压挡，测电池、充电器、手机充电线等直流电源的电压。通常分若干挡，如200mV、2V、20V、200V、1000V，数字代表这一挡能测的最大值，这就是“量程”。比如拨到20V挡，最多测20伏，测1.5伏的干电池正合适。量程可以理解为“尺子的长度”：20V挡就是一把20厘米的尺子，量1.5厘米的小东西，刻度清清楚楚；拿它量200厘米的大柜子，尺子就“爆表”了。
- V~：交流电压挡，测插座、市电等交流电的电压，常见750V、200V两挡。测家用220V市电用750V挡——量程必须大于被测值，750V是常见表里最接近且安全的一挡。
- Ω：电阻挡，测电阻、判断线路通断。同样分200Ω、2kΩ、20kΩ、200kΩ、2MΩ、20MΩ等挡位，数字代表该挡能测的最大电阻。
- 通断挡（蜂鸣挡）：电阻挡的“亲戚”。线路电阻很小（通常小于几十欧）时表会“嘀”一声，专门用来快速判断线路通不通，用耳朵听就行。
- A⎓：直流电流挡，测直流电流，通常有200mA和10A（或20A）两个位置。注意：测电流用的插孔与测电压不同，下一节细讲。
- 有些表还有hFE（测三极管）等特殊挡位，初学阶段当它不存在即可。

理解挡位的诀窍就一句话：旋钮转到的位置，是你对这块表下达的命令——“给我测20伏以内的直流电压”“给我测这条线的电阻”。命令下错，结果必然错；命令下对，表绝不偷懒。

## 2.4 表笔插孔：黑笔的家与红笔的三扇门

万用表下方通常有三到四个插孔。表笔插错孔，是新手最常见、也最危险的“事故源头”，这一节请重点看。

- COM孔：黑色表笔永远的家。COM是“公共端”的意思，所有测量中黑笔都插在这里，雷打不动。
- VΩmA孔：红色表笔的“日常住所”。测电压（V）、测电阻（Ω）、测小电流（mA）时，红笔都插这个孔。孔边印的三个字母，就是在告诉你它的职责范围。
- 10A或20A孔：红色表笔的“特殊通道”。只有测大电流（超出毫安挡范围）时才用，平时请让红笔好好待在家里。

为什么测电流要单独开一扇门？用水的语言讲：测电压和电阻时，表要“站在岸边观察”，内部走的是高电阻通道，几乎不参与电路；测电流时，表要“拦路截流”，让全部电流从自己身上穿过，必须走一条几乎无电阻的专用通道。两条通道通向表内不同的电路，所以各开一扇门。

两个典型事故，务必背下来：

- 红笔插在10A孔里却去测电压：此时表内部相当于一根粗铜线直通黑笔，等于把电路两点直接短路，轻则火花四溅、烧断表内保险丝，重则烧表伤人。
- 红笔插在VΩ孔里却去测大电流：电流没走专用通道，读数根本不是真实电流，还可能烧坏表内小电流回路的保险丝。

口诀：黑笔永远在COM；红笔测电压、电阻安家在VΩ，测大电流才去10A，测完立刻回家。

## 2.5 常用按键：HOLD与它的朋友们

除了旋钮，大多数数字表还配了几个按键：

- HOLD键（数据保持）：按下后，屏幕读数被“冻住”，表笔拿开数字也不变。有什么用？测量位置狭窄、眼睛看不到屏幕时，先测完，按下HOLD，再把表抽出来慢慢看；再按一次解除。这是新手用得最多的按键。
- 背光键：点亮屏幕背景灯，方便在光线暗的角落（比如柜台底下）读数，开关方式以说明书为准。
- SELECT键（部分型号）：同一挡位下的功能切换，比如在电阻挡位置切换电阻测量、通断测试、二极管测试。你的表如果没有这个键，说明这些功能被拆成了独立的旋钮挡位，反而更省事。

按键功能因型号而异，以你手中表的说明书为准。初学阶段，掌握HOLD就够用了，其余按键随用随学。

## 2.6 常见错误与注意事项

- 错误一：不看挡位直接测。旋钮停在电阻挡就去测电压，是最危险的错误之一，可能烧表。测量前必问自己一句：“现在我要测什么？挡位对吗？”
- 错误二：量程选错。测220V市电时拨到200V挡，屏幕显示超量程的“1”或“OL”；反过来，测1.5V电池却用750V挡，读数精度大打折扣。原则：已知大致范围就选刚好的挡，未知范围就从大挡往小挡试。
- 错误三：表笔插错孔。牢记口诀：黑笔永远COM，红笔平时VΩmA。插孔是安全的第一道闸门。
- 错误四：读数不看单位。屏幕显示“1.53”，是1.53伏还是1.53千欧？看屏幕上的单位符号，别只盯着数字。

## 2.7 本章小结

一块数字万用表由显示屏、旋钮档位区、表笔插孔区三大部分组成。显示屏上的每个符号都在传达信息：“1”或“OL”表示超量程，负号表示表笔接反，电池符号提醒换电池。旋钮像汽车挡位，转到哪里就执行什么任务：V是电压、A是电流、Ω是电阻，波浪线代表交流、直线代表直流。表笔插孔最需小心：黑笔永远插COM，红笔测电压、电阻插VΩmA，只有测大电流才去10A或20A孔。HOLD键能帮你冻住读数，方便看不见屏幕时使用。认识完长相，下一章我们钻进原理，看看电到底是什么。

## 2.8 练习题

1. 屏幕最左边显示“1”或“OL”，这是什么意思？应该怎么办？
2. 测1.5伏干电池，旋钮应该拨到哪个挡位？为什么？
3. 测电压时红表笔插哪个孔？测大电流时红表笔插哪个孔？黑表笔呢？
4. 用750V交流挡测1.5V电池，会有什么问题？
5. HOLD键的作用是什么？举一个使用场景。

参考答案：

1. 表示被测值超出当前量程，需要把旋钮拨到更大的挡位再测。
2. 直流电压挡的20V挡。因为量程要大于被测值（1.5V）且尽量接近，20V是常见表里最合适的一挡。
3. 测电压时红笔插VΩmA孔；测大电流时红笔插10A（或20A）孔；黑笔任何时候都插COM孔。
4. 读数精度极差。1.5V在750V量程下可能只显示“1”或极小的读数，几乎无法判断电池状态，就像用卷尺去量硬币的厚度。
5. 按下HOLD键后读数被保持不动。比如在狭窄空间里测完电压、看不到屏幕时，先按HOLD，再把表拿出来看读数。
