# Part 1 · 入门基础

# 引言 为什么要学 Python

1989 年的圣诞节，荷兰程序员 Guido van Rossum 为了打发假期无聊时光，决定写一门新的编程语言。他以自己深爱的英国喜剧团体 Monty Python 命名了这个项目——是的，Python 这个名字和蟒蛇没有半毛钱关系，纯粹是一个程序员对喜剧的致敬。Guido 的初衷很简单：他想要一门像 ABC 语言那样易读、但又像 C 语言那样强大的语言。三十多年后的今天，这门"假期项目"已经成为全世界最受欢迎的编程语言之一。

如果把编程语言比作交通工具，C 语言就像手动挡赛车——性能强悍但上手门槛高；Java 像一辆标准轿车——稳定可靠但有些繁琐；而 Python，更像是一辆自动挡电动车——坐上去就能开，但它跑起来一点也不慢。这种"低门槛、高上限"的特质，让 Python 在过去十年里几乎通吃了所有热门领域：数据分析、人工智能、Web 开发、自动化运维、科学计算、爬虫……你能想到的方向，Python 几乎都能胜任。

为什么适合零基础入门？因为 Python 的代码读起来太像英语了。同样是打印"Hello, World"，C 语言需要你写 `#include <stdio.h>`、写 `int main()`、写 `printf()` 再写 `return 0;`——新手还没搞懂什么是函数，就被一堆语法符号吓退了。而 Python 只需要一行：`print("Hello, World")`。这不是玩具级别的简化，而是 Python 设计哲学的体现：**代码是写给人读的，顺便让机器执行。**

在工业界，Python 的地位同样举足轻重。Google 是最早大规模使用 Python 的公司之一，YouTube 的核心后端就是用 Python 写的；Netflix 用它做推荐算法；Instagram 是全球最大的 Django（Python Web 框架）应用；NASA 用它处理航天数据。在国内，知乎、豆瓣、饿了么、字节跳动的很多基础服务都离不开 Python。学了 Python，你的职业选择面会非常宽——就算你不做程序员，用它处理 Excel 表格、批量重命名文件、自动发邮件，也能极大提升工作效率。

Python 还有一个常被忽视的优势：**社区**。Python 拥有一个极其活跃的全球社区，这意味着你遇到的几乎所有问题，都有人问过并且得到了解答。Stack Overflow 上关于 Python 的问答数以百万计，GitHub 上有无数开源的 Python 项目供你学习和使用。当你卡住了，不用担心——搜索引擎会帮你找到答案。另外，Python 的第三方库生态堪称"包罗万象"，PyPI（Python Package Index）上有超过 50 万个开源库，从发送邮件到训练神经网络，几乎什么都有现成的轮子可以用。

关于学习方法，我想提前说几句。编程不是"看懂了"就算学会了——你必须**动手写**。看教程的时候你觉得"嗯，我懂了"，但真正打开编辑器，大脑可能一片空白。这很正常，每个程序员都经历过这个阶段。本书的每个章节都配有练习题，请务必自己动手做一遍再看参考答案。另外，犯错是学习的一部分——遇到报错不要慌，仔细阅读错误信息，它通常会告诉你哪里出了问题。Python 的错误提示是出了名的友好，比很多编程语言都更容易理解。

本书分为六个部分，共 30 章，从零基础一路走到实战项目：

- **Part 1（第 1-6 章）入门基础**：安装环境、基本语法、数据类型、运算符、条件判断、循环。学完这部分，你就能写出有逻辑的小程序。
- **Part 2（第 7-10 章）数据结构与函数**：函数、列表/字典/集合/元组、文件操作、异常处理。这是从"能写代码"到"能写好代码"的关键跨越。
- **Part 3（第 11-15 章）进阶特性**：面向对象编程、继承与多态、装饰器、迭代器与生成器、上下文管理器。这些是 Python 的灵魂所在。
- **Part 4（第 16-20 章）实用技能**：正则表达式、多线程/多进程、网络编程、数据库操作、常用标准库。让你具备解决实际问题的能力。
- **Part 5（第 21-25 章）热门方向**：Web 开发、数据科学、机器学习、爬虫、自动化。选你感兴趣的方向深入。
- **Part 6（第 26-30 章）工程实践与项目**：代码规范、测试、打包发布、Git 版本控制，以及完整的项目实战。

这六个部分是一个循序渐进的过程。Part 1 是地基，Part 2 是框架，Part 3 是装修，Part 4 是水电，Part 5 是花园（选你喜欢的方向），Part 6 是把房子交付给业主。每一步都建立在前一步的基础上，所以建议按顺序阅读。当然，如果你已经有基础，也可以跳到感兴趣的部分——每章开头的"场景引入"会帮你快速进入状态。

你可能好奇：学完这本书到底能达到什么水平？简单来说——Part 1 和 Part 2 学完后，你能写一些实用的小脚本（批量重命名文件、自动整理下载文件夹、简单的数据处理）；Part 3 和 Part 4 学完后，你能参与正式的软件开发项目；Part 5 和 Part 6 学完后，你有能力独立完成一个完整的项目，无论是网站、数据分析工具还是自动化系统。

现在，打开你的电脑，我们出发。
