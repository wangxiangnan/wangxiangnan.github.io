# 第22章 多Agent系统 —— 当一个人搞不定时

## 22.1 开篇：为什么需要多Agent？

还记得你写第一个微服务的时候吗？一开始，你有一个单体应用，所有逻辑都塞在一个项目里，看起来也能跑。但随着业务越来越复杂，你发现：代码越来越难维护，一个模块的 bug 会拖垮整个系统，扩展性能更是无从谈起。于是你把单体拆成了微服务——每个服务各司其职，独立部署，通过 API 协作。

**多Agent系统（Multi-Agent System）的本质，就是这个逻辑的 AI 版本。**

在前面的章节中，我们构建的 DocMind Agent 是一个"全能选手"：它要负责检索文档、分析内容、总结报告、甚至和用户交互。对于简单场景，这完全够用。但当你面对以下需求时，单一 Agent 就力不从心了：

- **专业分工需求**：文档检索需要精准的 RAG 能力，深度分析需要强大的推理能力，总结报告需要精炼的表达能力——这三个任务的最佳 Prompt、最佳模型、甚至最佳 Temperature 都不同。
- **并行处理需求**：用户问了一个复杂问题，需要同时从多个数据源检索信息。串行处理太慢，并行才能提速。
- **对抗验证需求**：一个 Agent 生成的答案，让另一个 Agent 来挑刺、验证、补充。就像代码 Review 一样，"自己审自己"永远不够。
- **复杂度控制**：一个 Agent 塞太多逻辑，Prompt 会变得臃肿，推理链会变得混乱，调试会变成噩梦。

> 💡 **核心洞察**：多Agent不是"越多越好"，而是"该分则分"。就像微服务拆分的原则一样——当两个职责的变化频率不同时，它们就应该属于不同的服务（Agent）。

## 22.2 回顾：LangGraph基础

在深入多Agent之前，让我们快速回顾一下第14-15章学到的 LangGraph 核心概念：

- **State（状态）**：图中所有节点共享的数据结构，通过 `TypedDict` 定义
- **Node（节点）**：图中的处理单元，每个节点是一个函数，接收 State、返回 State 的部分更新
- **Edge（边）**：节点之间的连接，定义执行顺序
- **Conditional Edge（条件边）**：根据 State 的值动态选择下一个节点

这些概念在多Agent系统中会直接复用：

- 每个 **Worker Agent** 就是一个 **Node**
- **Supervisor 的路由决策**就是一个 **Conditional Edge**
- **共享状态**就是 **State**

## 22.3 多Agent架构模式详解

### 22.3.1 Supervisor模式：一个Boss分配任务

这是最常见也最容易理解的模式。想象一个项目经理（Supervisor）带领一个团队：

```
用户请求 → [Supervisor Agent] → 分析意图 → 分配给合适的 Worker
                                         ↓
                              [搜索Agent] [分析Agent] [总结Agent]
                                         ↓
                              [Supervisor Agent] → 整合结果 → 返回用户
```

**Supervisor 的核心职责**：

1. **意图理解**：理解用户到底想要什么
2. **Agent 选择**：决定哪个 Worker 最适合这个任务
3. **任务路由**：把任务分发出去
4. **结果整合**：收集 Worker 的输出，组合成最终答案

**优点**：

- 控制流清晰，容易理解和调试
- Supervisor 可以做全局优化决策
- 容易添加新的 Worker（只需注册即可）

**缺点**：

- Supervisor 是单点瓶颈（它挂了，整个系统就停了）
- Worker 之间不能直接通信（必须经过 Supervisor 中转）

### 22.3.2 Hierarchical Teams：多层级管理

当 Agent 数量增多时，一个 Supervisor 管不过来，就需要"中层管理"了：

```
用户请求 → [总Supervisor]
               ├── [研发经理Agent]
               │     ├── [代码Agent]
               │     └── [测试Agent]
               └── [文档经理Agent]
                     ├── [搜索Agent]
                     └── [总结Agent]
```

这就像公司的组织架构——CEO 不直接管每个员工，而是通过中层管理者来协调。

适用场景：Agent 数量超过 5-7 个，且 Agent 之间有明显的"组"的划分时。

### 22.3.3 直接协作（去中心化）

Agent 之间直接通信，没有中央调度者：

```
[Agent A] ←→ [Agent B]
   ↕              ↕
[Agent C] ←→ [Agent D]
```

**优点**：灵活、无单点故障
**缺点**：难以调试、可能出现死循环或决策冲突

> ⚠️ **实践建议**：在大多数生产场景中，**Supervisor 模式是最安全的选择**。它提供了清晰的控制流和可预测的行为，非常适合从单 Agent 向多 Agent 过渡。

## 22.4 Supervisor模式深入

### 22.4.1 共享状态 vs 消息传递

在 LangGraph 中，我们通常使用**共享状态**——State 就是那个"共享白板"。

| 方式 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 共享状态 | 所有Agent读写同一个State | 简单直接 | 需注意字段隔离 |
| 消息传递 | Agent间通过消息队列通信 | 解耦可扩展 | 复杂度高 |

### 22.4.2 Worker Agent设计原则

1. **单一职责**：一个 Worker 只做一件事，做到极致
2. **明确输入输出**：从 State 读什么、写什么要清晰
3. **无状态**：不在内部保存状态，所有状态通过 State 传递
4. **可替换**：可以被更好的实现替换，不影响其他组件

## 22.5 LangGraph实现Supervisor多Agent

### 22.5.1 定义共享状态

```python
from typing import TypedDict, Annotated, Sequence, Literal
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage
from langgraph.graph import StateGraph, END
from langgraph.graph.message import add_messages


class SupervisorState(TypedDict):
    """多Agent系统的共享状态"""
    # 消息历史（所有Agent共享）
    messages: Annotated[Sequence[BaseMessage], add_messages]
    # 用户原始查询
    original_query: str
    # 当前活跃Agent
    active_agent: str
    # 各Agent的输出结果
    search_results: str
    analysis_results: str
    summary_results: str
    # Supervisor的下一步决策
    next_step: Literal["search", "analyze", "summarize", "finish"]
    # 迭代计数器（防止无限循环）
    iteration_count: int
```

> 💡 **注意 `add_messages` 注解**：这确保了消息是追加而非覆盖的。多个 Agent 的输出消息会自动合并，就像 Git 的 merge 策略。

### 22.5.2 创建Worker Agent节点

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(model="gpt-4o", temperature=0)


def create_search_agent():
    """搜索Agent：专注于RAG检索"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是DocMind的搜索专家。你的唯一职责是从文档库中检索相关信息。
        规则：仔细分析查询意图，提取关键搜索词，返回结构化结果。
        不要分析结果，不要总结，只负责检索。"""),
        MessagesPlaceholder(variable_name="messages"),
        ("human", "请搜索相关信息：{query}")
    ])
    return prompt | llm | StrOutputParser()


def create_analysis_agent():
    """分析Agent：专注于深度分析"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是DocMind的分析专家。对检索结果进行深度分析。
        规则：识别关键信息和模式，进行逻辑推理，指出矛盾之处，给出分析结论。"""),
        MessagesPlaceholder(variable_name="messages"),
        ("human", "分析以下搜索结果：\n\n{search_results}\n\n原始问题：{query}")
    ])
    return prompt | llm | StrOutputParser()


def create_summary_agent():
    """总结Agent：生成面向用户的简洁总结"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是DocMind的总结专家。将分析结果转化为用户友好的回答。
        规则：通俗易懂，突出关键信息，不确定处明确说明，控制在300字以内。"""),
        MessagesPlaceholder(variable_name="messages"),
        ("human", "根据分析结果生成回答：\n\n{analysis_results}\n\n原始问题：{query}")
    ])
    return prompt | llm | StrOutputParser()


search_chain = create_search_agent()
analysis_chain = create_analysis_agent()
summary_chain = create_summary_agent()
```

### 22.5.3 Supervisor路由逻辑

```python
from pydantic import BaseModel, Field


class SupervisorDecision(BaseModel):
    next_agent: Literal["search", "analyze", "summarize", "finish"]
    reasoning: str


def create_supervisor_chain():
    """Supervisor决策链"""
    prompt = ChatPromptTemplate.from_messages([

协调三个Worker Agent：search(检索)、analyze(分析)、summarize(总结)。

决策规则：
1. 新问题先调用 search
2. 搜索完再调用 analyze
3. 分析完再调用 summarize
4. 总结完成则选择 finish"""),

    ])
    return prompt | llm.with_structured_output(SupervisorDecision)


supervisor_chain = create_supervisor_chain()
```

### 22.5.4 构建完整的LangGraph多Agent图

```python
def supervisor_node(state: SupervisorState) -> dict:
    decision = supervisor_chain.invoke({
        "messages": state["messages"],
        "search_status": "已完成" if state.get("search_results") else "未开始",
        "analysis_status": "已完成" if state.get("analysis_results") else "未开始",
        "summary_status": "已完成" if state.get("summary_results") else "未开始",
    })
    print(f"[Supervisor] {decision.next_agent} | {decision.reasoning}")
    return {
        "next_step": decision.next_agent,
        "iteration_count": state.get("iteration_count", 0) + 1,
        "messages": [AIMessage(content=f"[Supervisor] → {decision.next_agent}")]
    }


def search_node(state: SupervisorState) -> dict:
    result = search_chain.invoke({
        "messages": state["messages"][-5:],
        "query": state["original_query"]
    })
    return {
        "search_results": result,
        "messages": [AIMessage(content="[搜索Agent] 检索完成")],
        "active_agent": "search"
    }


def analyze_node(state: SupervisorState) -> dict:
    result = analysis_chain.invoke({
        "messages": state["messages"][-5:],
        "search_results": state.get("search_results", ""),
        "query": state["original_query"]
    })
    return {
        "analysis_results": result,
        "messages": [AIMessage(content="[分析Agent] 分析完成")],
        "active_agent": "analyze"
    }


def summarize_node(state: SupervisorState) -> dict:
    result = summary_chain.invoke({
        "messages": state["messages"][-5:],
        "analysis_results": state.get("analysis_results", ""),
        "query": state["original_query"]
    })
    return {
        "summary_results": result,
        "messages": [AIMessage(content="[总结Agent] 总结完成")],
        "active_agent": "summarize"
    }


def route_supervisor(state: SupervisorState) -> str:
    next_step = state.get("next_step", "finish")
    if state.get("iteration_count", 0) >= 10:
        return "finish"
    return "finish" if next_step == "finish" else next_step


# 构建图
builder = StateGraph(SupervisorState)
builder.add_node("supervisor", supervisor_node)
builder.add_node("search", search_node)
builder.add_node("analyze", analyze_node)
builder.add_node("summarize", summarize_node)
builder.set_entry_point("supervisor")
builder.add_conditional_edges("supervisor", route_supervisor, {
    "search": "search", "analyze": "analyze",
    "summarize": "summarize", "finish": END
})
builder.add_edge("search", "supervisor")
builder.add_edge("analyze", "supervisor")
builder.add_edge("summarize", "supervisor")
multi_agent_graph = builder.compile()
```

### 22.5.5 运行多Agent系统

```python
def run_multi_agent(query: str):
    """运行多Agent系统"""
    print(f"\n{'='*60}")
    print(f"用户问题: {query}")
    print(f"{'='*60}\n")
    
    initial_state = {
        "messages": [HumanMessage(content=query)],
        "original_query": query,
        "active_agent": "",
        "search_results": "",
        "analysis_results": "",
        "summary_results": "",
        "next_step": "",
        "iteration_count": 0

        for node_name, output in event.items():
            print(f"--- [{node_name}] ---")
            for msg in output.get("messages", []):
                print(f"  {msg.content}")
    
    result = multi_agent_graph.invoke(initial_state)
    print(f"\n最终回答:\n{result.get('summary_results', '无结果')}")
    return result
```

## 22.6 DocMind多Agent实操

```python
"""DocMind 多Agent版本 — 整合RAG检索 + 深度分析 + 智能总结"""

from typing import TypedDict, Annotated, Sequence
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_community.vectorstores import Chroma
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langgraph.graph import StateGraph, END
from langgraph.graph.message import add_messages


class DocMindMultiAgent:
    """DocMind 多Agent系统"""
    
    def __init__(self, vectorstore: Chroma):
        self.vectorstore = vectorstore
        self.retriever = vectorstore.as_retriever(search_kwargs={"k": 5})
        self.llm = ChatOpenAI(model="gpt-4o", temperature=0)
        self._build_graph()
    
    def _build_graph(self):
        class State(TypedDict):
            messages: Annotated[Sequence[BaseMessage], add_messages]
            original_query: str
            search_results: str
            analysis_results: str
            summary_results: str
            next_step: str
            iteration_count: int
        
        builder = StateGraph(State)
        
        def supervisor_node(state):
            iteration = state.get("iteration_count", 0)
            if not state.get("search_results"):
                ns, reason = "search", "尚未搜索"
            elif not state.get("analysis_results"):
                ns, reason = "analyze", "搜索完成，进行分析"
            elif not state.get("summary_results"):
                ns, reason = "summarize", "分析完成，生成总结"
            else:
                ns, reason = "finish", "所有步骤完成"
            if iteration >= 5:
                ns, reason = "finish", "达到最大迭代"
            return {
                "next_step": ns, "iteration_count": iteration + 1,
                "messages": [AIMessage(content=f"[Supervisor] {reason} → {ns}")]
            }
        
        def search_node(state):
            docs = self.retriever.invoke(state["original_query"])
            context = "\n---\n".join([
                f"[来源: {d.metadata.get('source','?')}]\n{d.page_content}" for d in docs
            ])
            prompt = ChatPromptTemplate.from_messages([
                ("system", "你是搜索专家。从文档片段中提取与用户问题最相关的信息。"),
                ("human", "问题：{query}\n\n文档片段：\n{context}")
            ])
            result = (prompt | self.llm | StrOutputParser()).invoke({
                "query": state["original_query"], "context": context
            })
            return {
                "search_results": result,
                "messages": [AIMessage(content=f"[搜索Agent] 检索到{len(docs)}个片段")]
            }
        
        def analyze_node(state):
            prompt = ChatPromptTemplate.from_messages([
                ("system", "你是分析专家。对搜索结果进行深度分析，识别关键信息和模式。"),
                ("human", "问题：{query}\n\n搜索结果：\n{search_results}")
            ])
            result = (prompt | self.llm | StrOutputParser()).invoke({
                "query": state["original_query"],
                "search_results": state["search_results"]
            })
            return {
                "analysis_results": result,
                "messages": [AIMessage(content="[分析Agent] 分析完成")]
            }
        
        def summarize_node(state):
            prompt = ChatPromptTemplate.from_messages([
                ("system", "你是总结专家。将分析结果转化为清晰易懂的用户回答。"),
                ("human", "问题：{query}\n\n分析结果：\n{analysis_results}")
            ])
            result = (prompt | self.llm | StrOutputParser()).invoke({
                "query": state["original_query"],
                "analysis_results": state["analysis_results"]
            })
            return {
                "summary_results": result,
                "messages": [AIMessage(content="[总结Agent] 总结完成")]
            }
        
        builder.add_node("supervisor", supervisor_node)
        builder.add_node("search", search_node)
        builder.add_node("analyze", analyze_node)
        builder.add_node("summarize", summarize_node)
        builder.set_entry_point("supervisor")
        builder.add_conditional_edges("supervisor",
            lambda s: s.get("next_step", "finish"),
            {"search": "search", "analyze": "analyze", "summarize": "summarize", "finish": END})
        builder.add_edge("search", "supervisor")
        builder.add_edge("analyze", "supervisor")
        builder.add_edge("summarize", "supervisor")
        self.graph = builder.compile()
    
    def ask(self, query: str) -> str:
        state = {
            "messages": [HumanMessage(content=query)], "original_query": query,
            "search_results": "", "analysis_results": "", "summary_results": "",
            "next_step": "", "iteration_count": 0
        }
        result = self.graph.invoke(state)
        return result.get("summary_results", "抱歉，无法回答。")
    
    def ask_with_trace(self, query: str) -> dict:
        state = {
            "messages": [HumanMessage(content=query)], "original_query": query,
            "search_results": "", "analysis_results": "", "summary_results": "",
            "next_step": "", "iteration_count": 0
        }
        print(f"\n{'='*60}\nDocMind多Agent追踪\n{'='*60}\n")
        for event in self.graph.stream(state):
            for name, output in event.items():
                print(f"[{name}]", *[m.content for m in output.get("messages", [])])
        final = self.graph.invoke(state)
        print(f"\n最终回答:\n{final.get('summary_results', '')}")
        return {"answer": final.get("summary_results", ""), "iterations": final["iteration_count"]}
```

## 22.7 智能路由

```python
from pydantic import BaseModel, Field

class RoutingDecision(BaseModel):
    next_agent: Literal["search", "analyze", "summarize", "finish", "retry_search"]
    confidence: float = Field(ge=0, le=1)
    reasoning: str

def create_intelligent_supervisor():
    """基于LLM的智能路由"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """智能任务调度器。可用Agent：search/analyze/summarize/finish/retry_search。
决策原则：新问题先搜索，搜索完分析，分析完总结。
搜索结果不好可retry_search，最多重试3次。总迭代不超过8次。"""),
        ("human", "状态：搜索={s}/分析={a}/总结={m}，迭代={i}，上一步={last}\n问题：{q}")
    ])
    return prompt | llm.with_structured_output(RoutingDecision)
```

> ⚠️ **生产经验**：固定工作流用规则路由更快更省钱。只在路径不可预测时才用LLM路由。

## 22.8 本章小结

| 概念 | 类比 | 核心要点 |
| ------ | ------ | ---------- |
| 多Agent系统 | 微服务架构 | 各司其职，协议协作 |
| Supervisor模式 | 项目经理 | 中央调度，控制流清晰 |
| Hierarchical Teams | 公司组织架构 | 多层级管理 |
| 直接协作 | P2P网络 | 灵活但不易控制 |
| 共享状态 | 共享数据库 | Agent通过State通信 |
| 智能路由 | API Gateway | LLM决定任务分配 |

**关键收获**：

1. 多Agent的核心是**分工与协作**
2. Supervisor模式最实用，控制流清晰
3. LangGraph天然适合多Agent：Node=Agent，Edge=通信，Conditional Edge=路由
4. 规则路由→LLM路由是渐进升级，不要过度设计

## 22.9.1 多Agent通信模式深入

在实际的多Agent系统中，Agent之间的通信方式是一个重要的架构决策：

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages


# 模式1: 共享黑板（Blackboard Pattern）
# 所有Agent读写同一个State，适合简单场景
class BlackboardState(TypedDict):
    messages: Annotated[list, add_messages]
    shared_data: dict  # 所有Agent共享的数据空间
    task_status: dict  # 各任务状态


# 模式2: 消息传递（Message Passing）
# Agent之间通过消息通信，适合复杂场景
class MessageState(TypedDict):
    messages: Annotated[list, add_messages]
    inbox: dict  # agent_name -> list of messages
    
    @staticmethod
    def send_message(state, from_agent: str, to_agent: str, content: str):
        """发送消息给另一个Agent"""
        inbox = dict(state.get("inbox", {}))
        if to_agent not in inbox:
            inbox[to_agent] = []
        inbox[to_agent].append({
            "from": from_agent,
            "content": content,
            "timestamp": time.time()
        })
        return {"inbox": inbox}


# 模式3: 事件驱动（Event-Driven）
```

## 22.9.2 多Agent的错误处理和恢复

```python
class FaultTolerantMultiAgent:
    """容错多Agent系统"""
    
    def __init__(self, graph, max_retries=2):
        self.graph = graph
        self.max_retries = max_retries
        self.error_handlers = {
            "search": self._handle_search_error,
            "analyze": self._handle_analyze_error,
            "summarize": self._handle_summarize_error,
        }
    
    def run_with_retry(self, initial_state: dict) -> dict:
        """带重试的执行"""
        for attempt in range(self.max_retries + 1):
            try:
                return self.graph.invoke(initial_state)
            except Exception as e:
                print(f"第{attempt+1}次执行失败: {e}")
                if attempt < self.max_retries:
                    # 尝试恢复
                    initial_state = self._recover_state(initial_state, e)
                else:
                    raise
    
    def _recover_state(self, state: dict, error: Exception) -> dict:
        """状态恢复"""
        # 重置失败的Agent输出
        active = state.get("active_agent", "")
        if active and active in self.error_handlers:
            state = self.error_handlers[active](state, error)
        # 重置迭代计数，让Supervisor重新决策
        state["iteration_count"] = max(0, state.get("iteration_count", 0) - 1)
        state["next_step"] = ""
        return state
    
    def _handle_search_error(self, state, error):
        """搜索Agent错误处理：使用降级搜索"""
        state["search_results"] = "搜索服务暂时不可用，将使用已有信息回答。"
        return state
    
    def _handle_analyze_error(self, state, error):
        """分析Agent错误处理：跳过分析，直接使用搜索结果"""
        state["analysis_results"] = state.get("search_results", "")
        return state
    
    def _handle_summarize_error(self, state, error):
        """总结Agent错误处理：使用分析结果作为最终回答"""
        state["summary_results"] = state.get("analysis_results", "抱歉，暂时无法回答。")
        return state
```
