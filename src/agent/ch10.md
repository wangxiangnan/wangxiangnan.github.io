# 第10章 Prompt模板 —— 工程化管理"指令"

## 10.1 开篇：从"手写 Prompt"到"工程化管理"

在第20章中，我们学习了 Prompt Engineering 的艺术——如何写出好的 System Prompt、如何使用 Few-shot 和 Chain-of-Thought。但当时我们是在"手工"构建 Prompt，就像用记事本写代码一样——能跑，但不好维护。

想象一下这些场景：

- 你有 10 种不同的 Prompt，每种都有不同的变量
- 你想测试不同版本的 Prompt 哪个效果更好
- 你的 Prompt 需要根据用户输入动态插入不同的示例
- 多个开发者在同一个项目中修改 Prompt，冲突不断

这些问题的根源是：**Prompt 被当作"字符串"而不是"代码"来管理**。

LangChain 的 Prompt 模板系统就是解决这个问题的——它让你像写组件化代码一样，把 Prompt 拆分为可复用、可组合、可版本管理的模块。

## 10.2 PromptTemplate：最基础的模板

### 10.2.1 从字符串到模板

```python
# 不好的做法：手动拼接字符串
question = "Python"
prompt = f"请解释{question}是什么，用3句话。"
# 问题：变量多了就很难维护，而且容易出错

# 好的做法：使用 PromptTemplate
from langchain_core.prompts import PromptTemplate

template = PromptTemplate.from_template(
    "请解释{topic}是什么，用{n}句话。"
)

# 填充变量
prompt = template.invoke({
    "topic": "Python",
    "n": 3,
})
# prompt 是一个 StringPromptValue 对象
print(prompt.to_string())
# 输出: "请解释Python是什么，用3句话。"
```

### 10.2.2 PromptTemplate 的核心 API

```python
from langchain_core.prompts import PromptTemplate

# 方式一：from_template() — 最简洁
template1 = PromptTemplate.from_template(
    "请用{language}写一个{feature}的示例代码。"
)

# 方式二：完整构造
template2 = PromptTemplate(
    input_variables=["language", "feature"],  # 声明变量
    template="请用{language}写一个{feature}的示例代码。",
)

# 查看变量列表
print(template1.input_variables)  # ['feature', 'language']

# 填充变量 — 两种方式
result1 = template1.invoke({"language": "Python", "feature": "排序"})
result2 = template1.format(language="Python", feature="排序")
# 两者结果相同
print(result1.to_string())
```

### 10.2.3 模板中嵌入"花括号"

有时候你的 Prompt 中需要包含 JSON 示例或代码块，里面也有花括号。这时需要用双花括号转义：

```python
from langchain_core.prompts import PromptTemplate

template = PromptTemplate.from_template(
    "请分析以下 JSON 数据：\n"
    '{{"name": "{name}", "age": {age}}}\n\n'
    "请以 JSON 格式返回分析结果：\n"
    '{{"analysis": "...", "category": "..."}}'
)

result = template.invoke({"name": "Alice", "age": 25})
print(result.to_string())
# {{ 和 }} 会被转义为单个 { 和 }
# 而 {name} 和 {age} 会被替换为实际值
```

## 10.3 ChatPromptTemplate：为对话而生

`PromptTemplate` 生成的是纯字符串，但在实际应用中，你几乎总是需要构建"消息列表"。`ChatPromptTemplate` 就是为这个场景设计的。

### 10.3.1 基本用法

```python
from langchain_core.prompts import ChatPromptTemplate

# 推荐使用 from_messages()
chat_template = ChatPromptTemplate.from_messages([
    ("system", "你是 DocMind，一个智能文档问答助手。你的回答应该{style}。"),
    ("human", "{question}"),
])

# 填充变量
messages = chat_template.invoke({
    "style": "简洁专业",
    "question": "什么是 Docker？",
})

# messages 是一个消息列表
for msg in messages.to_messages():
    print(f"[{msg.type}] {msg.content}")
# [system] 你是 DocMind，一个智能文档问答助手。你的回答应该简洁专业。
# [human] 什么是 Docker？
```

### 10.3.2 多轮对话的模板

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.messages import HumanMessage, AIMessage

# 包含对话历史的多轮模板
chat_template = ChatPromptTemplate.from_messages([
    ("system", "你是 DocMind，一个智能文档问答助手。"),
    ("placeholder", "{chat_history}"),  # 动态插入历史消息
    ("human", "{question}"),
])

# 使用
history = [
    HumanMessage(content="什么是微服务？"),
    AIMessage(content="微服务是一种将应用拆分为多个独立服务的架构风格。"),
]

messages = chat_template.invoke({
    "chat_history": history,
    "question": "它和单体架构有什么区别？",
})

for msg in messages.to_messages():
    print(f"[{msg.type}] {msg.content[:50]}...")
```

> ⚠️ **"placeholder" vs 普通变量**：`("placeholder", "{chat_history}")` 可以接受一个消息列表并将其展开到消息序列中。普通变量只能接受字符串。

### 10.3.3 带 Few-shot 示例的模板

```python
from langchain_core.prompts import ChatPromptTemplate

chat_template = ChatPromptTemplate.from_messages([
    ("system", """你是 DocMind，一个技术文档分析助手。

回答规范：
1. 先给出简短的定义
2. 然后用一个编程类比来解释
3. 最后给出一个实际应用场景

示例：
问题：什么是 API？
回答：API（应用程序编程接口）是软件组件之间交互的约定。
类比：就像餐厅的服务员——你不需要知道厨房怎么做菜，只需要通过菜单告诉服务员你想要什么。
场景：天气预报 App 通过 API 从气象服务器获取天气数据。

请用同样的格式回答用户的问题。"""),
    ("human", "{question}"),
])

messages = chat_template.invoke({"question": "什么是数据库索引？"})
```

## 10.4 FewShotPromptTemplate：动态选择最相关的示例

### 10.4.1 为什么需要"动态"示例？

在第20章中我们学过 Few-shot Prompting——给 LLM 看几个示例，让它学会回答的格式和风格。但如果你的示例库有 50 个示例，你不可能全部塞进 Prompt（会消耗太多 token）。

理想的做法是：**根据用户的问题，动态选择最相关的 2-3 个示例**。这就像搜索引擎——不是把所有结果都给你，而是给你最相关的几条。

### 10.4.2 实现动态 Few-shot

```python
from langchain_core.prompts import FewShotChatMessagePromptTemplate
from langchain_core.prompts import ChatPromptTemplate
from langchain_chroma import Chroma
from langchain_openai import OpenAIEmbeddings
from langchain_core.example_selectors import SemanticSimilarityExampleSelector

# 第一步：准备示例库
examples = [
    {"question": "什么是 REST API？",
     "answer": "REST API 是基于 HTTP 的 API 设计风格。\n"
               "类比：像邮局系统——你写好信，贴上地址，邮局帮你送到。"},
    {"question": "什么是 Docker？",
     "answer": "Docker 是容器化平台，把应用打包成独立单元。\n"
               "类比：像集装箱——不管里面装什么，外面尺寸标准。"},
    {"question": "什么是 Git？",
     "answer": "Git 是分布式版本控制系统。\n"
               "类比：像游戏存档系统——随时存档，出问题可以回档。"},
    {"question": "什么是 WebSocket？",
     "answer": "WebSocket 支持双向通信的网络协议。\n"
               "类比：HTTP 是发短信，WebSocket 是打电话。"},
    {"question": "什么是负载均衡？",
     "answer": "负载均衡是将请求分发到多台服务器的技术。\n"
               "类比：像超市多个收银台——引导员把顾客分配到排队最少的台。"},
]

# 第二步：创建示例选择器（基于向量相似度）
example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples,
    OpenAIEmbeddings(),
    Chroma,
    k=2,  # 选择最相关的2个示例
)

# 第三步：创建 Few-shot 模板
few_shot_prompt = FewShotChatMessagePromptTemplate(
    example_selector=example_selector,
    example_prompt=ChatPromptTemplate.from_messages([
        ("human", "{question}"),
        ("ai", "{answer}"),
    ]),
)

# 第四步：组合成完整模板
final_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是 DocMind。请参考以下示例的风格来回答问题。"),
    few_shot_prompt,
    ("human", "{input}"),
])

# 使用
messages = final_prompt.invoke({"input": "什么是消息队列？"})
for msg in messages.to_messages():
    print(f"[{msg.type}] {msg.content[:80]}...")
```

### 10.4.3 不依赖向量搜索的简单方式

```python
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate

examples = [
    {"input": "Python", "output": "一种解释型、面向对象的高级编程语言"},
    {"input": "JavaScript", "output": "一种主要用于Web开发的动态脚本语言"},
]

example_template = PromptTemplate(
    input_variables=["input", "output"],
    template="概念: {input}\n定义: {output}",
)

few_shot = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_template,
    prefix="请参考以下格式来解释技术概念：\n",
    suffix="\n概念: {input}\n定义:",
    input_variables=["input"],
)

result = few_shot.invoke({"input": "Rust"})
print(result.to_string())
```

## 10.5 Prompt 组合策略：像组件化开发一样拼装 Prompt

### 10.5.1 MessagesPlaceholder：动态插入消息列表

`MessagesPlaceholder` 是一个特殊的占位符，运行时可以动态插入任意数量的消息。这在处理对话历史时特别有用。

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage

template = ChatPromptTemplate.from_messages([
    ("system", "你是 DocMind。"),
    MessagesPlaceholder(variable_name="chat_history"),  # 占位符
    ("human", "{question}"),
])

history = [
    HumanMessage(content="什么是缓存？"),
    AIMessage(content="缓存是将常用数据临时存储在高速介质中的技术。"),
    HumanMessage(content="Redis 是什么？"),
    AIMessage(content="Redis 是一个开源的内存数据结构存储。"),
]

messages = template.invoke({
    "chat_history": history,
    "question": "它和 Memcached 有什么区别？",
})

# 最终消息列表包含：
# 1. SystemMessage: "你是 DocMind。"
# 2-5. 历史消息（自动展开）
# 6. HumanMessage: "它和 Memcached 有什么区别？"
for msg in messages.to_messages():
    print(f"[{msg.type}] {msg.content[:50]}...")
```

### 10.5.2 条件渲染：根据情况展示不同内容

LangChain 的模板不支持原生的条件逻辑，但你可以通过 Python 函数来实现：

```python
from langchain_core.prompts import ChatPromptTemplate
from typing import Optional

def build_docmind_prompt(
    question: str,
    context: Optional[str] = None,
    chat_history: Optional[list] = None,
    use_tools: bool = False,
):
    """根据场景动态构建 Prompt"""
    messages = []
    
    system_content = "你是 DocMind，一个智能文档问答助手。"
    
    if context:
        system_content += (
            "\n\n参考文档：\n{context}\n\n"
            "请基于参考文档回答问题。如果没有相关信息，请说明。"
        )
    
    if use_tools:
        system_content += (
            "\n\n你可以使用以下工具：\n"
            "- search_documents：搜索相关文档\n"
            "- analyze_code：分析代码片段\n"
            "- generate_summary：生成文档摘要"
        )
    
    messages.append(("system", system_content))
    if chat_history:
        messages.append(("placeholder", "{chat_history}"))
    messages.append(("human", "{question}"))
    
    template = ChatPromptTemplate.from_messages(messages)
    
    variables = {"question": question}
    if context:
        variables["context"] = context
    if chat_history:
        variables["chat_history"] = chat_history
    
    return template.invoke(variables)

# 场景1：简单问答
prompt1 = build_docmind_prompt("什么是 API？")

# 场景2：带上下文的问答
prompt2 = build_docmind_prompt(
    "这段代码有什么问题？",
    context="def process(data):\n    return data['key']",
)

# 场景3：带历史的问答
prompt3 = build_docmind_prompt(
    "能详细说说吗？",
    chat_history=[
        HumanMessage(content="什么是微服务？"),
        AIMessage(content="微服务是一种架构风格..."),
    ],
)
```

## 10.6 Prompt 版本管理和 Prompt Hub

### 10.6.1 为什么 Prompt 需要版本管理？

Prompt 是 AI 应用的"灵魂配置"——一个好的 Prompt 可以让模型表现翻倍，一个差的 Prompt 可以让模型胡言乱语。就像你对代码使用 Git 版本管理一样，Prompt 也需要版本管理：

- 记录每次修改
- 可以回滚到之前的版本
- 可以 A/B 测试不同版本

### 10.6.2 集中管理 Prompt 文件

```python
# config/prompts.py — DocMind Prompt 集中管理

# 基础 Prompt
DOCMIND_SYSTEM_PROMPT = """你是 DocMind，一个智能文档问答助手。

你的核心能力：
1. 帮助开发者理解技术文档
2. 解答编程和架构相关的问题
3. 提供代码示例和最佳实践

你的风格：
- 专业但不死板，适当使用编程类比
- 如果不确定答案，会诚实说明
- 回答简洁，除非用户要求详细解释

版本: 1.0.0
"""

# 带上下文的问答 Prompt（RAG 场景）
RAG_QA_PROMPT = """你是 DocMind，一个智能文档问答助手。

请基于以下参考文档来回答用户的问题。

参考文档：
{context}

回答规范：
1. 优先使用参考文档中的信息
2. 如果文档中没有相关信息，明确说明
3. 可以补充你自己的知识，但要标明"补充信息"
4. 引用文档内容时，注明出处

版本: 1.0.0
"""

# 代码分析 Prompt
CODE_ANALYSIS_PROMPT = """你是 DocMind 的代码分析模块。

请分析以下代码并给出专业评价。

代码语言：{language}
代码内容：
{code}

请从以下方面分析：
1. 代码功能概述
2. 潜在问题和风险
3. 性能优化建议
4. 代码风格评价
5. 改进后的代码示例

版本: 1.0.0
"""

# 文档摘要 Prompt
SUMMARY_PROMPT = """你是 DocMind 的文档摘要模块。

请为以下文档生成{summary_type}摘要。

文档标题：{title}
文档内容：
{content}

摘要要求：
- 长度：{length}
- 格式：{format}
- 目标读者：{audience}

版本: 1.0.0
"""

# Prompt 版本注册表
PROMPT_REGISTRY = {
    "system.default": DOCMIND_SYSTEM_PROMPT,
    "rag.qa_v1": RAG_QA_PROMPT,
    "tools.code_analysis_v1": CODE_ANALYSIS_PROMPT,
    "tools.summary_v1": SUMMARY_PROMPT,
}

def get_prompt(name: str) -> str:
    """通过名称获取 Prompt 模板"""
    if name not in PROMPT_REGISTRY:
        raise KeyError(
            f"未找到 Prompt: {name}。可用: {list(PROMPT_REGISTRY.keys())}"
        )
    return PROMPT_REGISTRY[name]
```

## 10.7 实战演练：DocMind 的多级 Prompt 系统

```python
# src/agent/prompts.py — DocMind 完整 Prompt 系统
"""DocMind Prompt 系统：支持多级 Prompt"""

from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

class DocMindPrompts:
    """DocMind Prompt 模板集合"""
    
    @staticmethod
    def basic_qa() -> ChatPromptTemplate:
        """基础问答 — 不依赖外部文档"""
        return ChatPromptTemplate.from_messages([
            ("system", """你是 DocMind，一个智能文档问答助手。

你的风格：
- 专业、友好
- 善用编程类比解释概念
- 回答简洁（除非用户要求详细）
- 不确定时诚实说明

当前处于"基础问答"模式。"""),
            MessagesPlaceholder(variable_name="chat_history", optional=True),
            ("human", "{question}"),
        ])
    
    @staticmethod
    def rag_qa() -> ChatPromptTemplate:
        """带文档上下文的问答 — RAG 模式"""
        return ChatPromptTemplate.from_messages([
            ("system", """你是 DocMind，一个智能文档问答助手。
当前处于"文档问答"模式。

请基于以下参考文档来回答用户的问题：

<context>
{context}
</context>

回答规范：
1. 优先使用参考文档中的信息
2. 如果文档中没有相关信息，明确说明
3. 可以补充自己的知识，但标明"补充信息"
4. 回答时引用文档来源"""),
            MessagesPlaceholder(variable_name="chat_history", optional=True),
            ("human", "{question}"),
        ])
    
    @staticmethod
    def tool_calling() -> ChatPromptTemplate:
        """支持工具调用的模板"""
        return ChatPromptTemplate.from_messages([
            ("system", """你是 DocMind，一个智能文档问答助手。
当前处于"工具辅助"模式。

你可以使用以下工具：
- search_documents：搜索相关文档
- analyze_code：分析代码片段
- generate_summary：生成文档摘要

使用工具的规范：
1. 只在需要时使用工具
2. 简单问题直接回答
3. 工具返回的结果需要消化后再呈现给用户
4. 不要暴露工具调用的技术细节"""),
            MessagesPlaceholder(variable_name="chat_history", optional=True),
            ("human", "{question}"),
        ])
    
    @staticmethod
    def code_analysis() -> ChatPromptTemplate:
        """代码分析专用模板"""
        return ChatPromptTemplate.from_messages([
            ("system", """你是 DocMind 的代码分析模块。
请分析以下 {language} 代码：

{code}

请从以下角度分析：
1. 功能概述（1-2句话）
2. 潜在问题（bug、安全风险、性能问题）
3. 改进建议（附代码示例）
4. 总体评价"""),
            ("human", "请分析上面的代码。{specific_focus}"),
        ])
    
    @staticmethod
    def summary() -> ChatPromptTemplate:
        """文档摘要生成模板"""
        return ChatPromptTemplate.from_messages([
            ("system", """你是 DocMind 的文档摘要模块。
请为以下文档生成摘要：

文档标题：{title}
文档内容：
{content}

摘要要求：
- 类型：{summary_type}
- 长度：约{length}字
- 格式：{format}"""),
            ("human", "请生成摘要。"),
        ])
    
    @staticmethod
    def select_prompt(has_context=False, has_tools=False):
        """根据场景自动选择合适的 Prompt"""
        if has_tools:
            return DocMindPrompts.tool_calling()
        elif has_context:
            return DocMindPrompts.rag_qa()
        else:
            return DocMindPrompts.basic_qa()

# 使用示例
if __name__ == "__main__":
    # 场景1：基础问答
    template = DocMindPrompts.select_prompt()
    messages = template.invoke({"question": "什么是微服务？"})
    print(f"基础问答模板生成了 {len(messages.to_messages())} 条消息\n")
    
    # 场景2：RAG 问答
    template = DocMindPrompts.select_prompt(has_context=True)
    messages = template.invoke({
        "context": "Docker 是一个容器化平台...",
        "question": "Docker 和虚拟机有什么区别？",
    })
    print(f"RAG 问答模板生成了 {len(messages.to_messages())} 条消息\n")
    
    # 场景3：代码分析
    template = DocMindPrompts.code_analysis()
    messages = template.invoke({
        "language": "python",
        "code": "def add(a, b): return a + b",
        "specific_focus": "请重点关注类型安全。",
    })
    for msg in messages.to_messages():
        print(f"[{msg.type}] {msg.content[:60]}...")
```

## 10.8 本章小结

1. **PromptTemplate** — 最基础的模板，用 `{variable}` 语法注入变量。
2. **ChatPromptTemplate** — 为对话场景设计，可以生成消息列表。
3. **FewShotPromptTemplate** — 动态选择最相关的示例，节省 token。
4. **MessagesPlaceholder** — 在模板中预留位置，动态插入消息列表。
5. **Prompt 版本管理** — 集中管理、版本标记、按需选择。
