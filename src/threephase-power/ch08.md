# 第8章 接触器与热继电器：电机控制的"开关"与"保镖"

"小王，搅拌机的接触器烧了，你去仓库领一个新的换上。"师傅老张递过来一个黑色方块状的东西。小王接过来翻来覆去看了看："这不就是个开关嘛？直接用空气开关不就行了，为什么非要这种'接触器'？"

老张摇摇头："空气开关是保护用的，不能用来频繁接通和断开电机。接触器才是控制用的——它能用很小的电流控制很大的电流，而且可以每小时操作几百次甚至上千次。你见过用普通墙壁开关控制7.5kW电机的吗？那开关几秒钟就烧了。"

小王若有所思："那热继电器呢？我看控制柜里接触器旁边总跟着一个方块。""那是电机的保镖，"老张说，"接触器负责开关，热继电器负责保护——电机过载时它会跳开，防止电机烧毁。这俩搭档是电机控制最基本的组合。"

## 8.1 交流接触器：用电磁铁控制大电流

交流接触器（简称接触器）本质上是一种用电信号控制通断的大功率开关。它的核心部件包括电磁系统、触点系统和灭弧装置。

**电磁系统**由线圈、静铁芯（E形硅钢片叠成）和动铁芯（衔铁）组成。当线圈通电时，产生电磁吸力将衔铁吸合；线圈断电时，弹簧将衔铁弹回。这个过程就像用电磁铁吸一个铁块——通电吸合，断电释放。控制线圈通断只需要很小的电流（通常几百毫安），但衔铁的动作可以带动触点通断几十安培甚至上百安培的主电路电流。这就是接触器的核心价值——以小控大。

**触点系统**分为主触点和辅助触点。主触点体积大、接触面积大，用于接通和断开电机的主电路（大电流），通常有三对（对应三相电的三根相线）。辅助触点体积小，用于控制电路中的信号传递和逻辑控制，分为常开触点（NO，线圈未通电时断开，通电吸合后闭合）和常闭触点（NC，线圈未通电时闭合，通电吸合后断开）。

为什么要有主触点和辅助触点之分？因为主电路电流大（比如15A以上），需要触点面积大、灭弧能力强；控制电路电流小（通常不超过5A），触点可以小巧灵敏。把两者分开设计，既保证了主电路的可靠通断，又能在控制电路中实现自锁、互锁等逻辑功能。

**灭弧装置**用来熄灭触点断开时产生的电弧。当触点分离的瞬间，电流不会立刻停止，而是通过空气形成电弧（就像闪电一样）。电弧温度高达几千度，如果不迅速熄灭，会烧蚀触点甚至引发火灾。接触器内部的灭弧罩（由多个金属栅片组成）能把电弧分割成许多短弧，利用近阴极效应快速熄灭。功率越大的接触器，灭弧装置越复杂。

## 8.2 接触器的选型

选接触器要看几个关键参数：

**额定工作电流**：接触器主触点的额定电流必须大于或等于电机的额定电流。比如电机额定电流15.6A，应选额定电流不小于16A的接触器（实际选用时通常取1.2到1.5倍的安全裕量，选25A的更稳妥）。

**线圈电压**：接触器线圈的工作电压必须与控制电路电压匹配。常见的线圈电压有AC 220V、AC 380V、DC 24V等。控制电路用220V就选220V线圈，用24V安全电压就选24V线圈。线圈电压选错了，要么吸不上（电压太低），要么烧毁线圈（电压太高）。

**使用类别**：接触器的使用类别标注了它适用的负载类型。AC-1类适用于阻性负载或微感性负载（如加热器），AC-3类适用于鼠笼式电机的启动和运转中断开（最常见），AC-4类适用于电机的频繁启动、反接制动和反转。控制电机一般选AC-3类，同一个接触器在AC-3类别下的额定电流比AC-1类别低——因为电机启动时的冲击电流远大于运行电流。

| 使用类别 | 适用场合 | 典型负载 |
| ---------- | ---------- | ---------- |
| AC-1 | 阻性或微感性负载 | 电加热器、照明 |
| AC-3 | 电机启动和运转中断开 | 泵、风机、压缩机 |
| AC-4 | 频繁启停、反接制动 | 起重设备、升降机 |

## 8.3 热继电器：电机的"温度保镖"

热继电器是专门用来保护电机免受过载损害的装置。它的核心部件是双金属片——由两种热膨胀系数不同的金属片压合在一起制成的。

工作原理很巧妙：电机的电流流过双金属片旁边的加热元件（或直接流过双金属片本身），电流越大，发热越厉害。双金属片受热后，由于两种金属膨胀程度不同，整体会向一侧弯曲。当电流超过设定值并持续一定时间后，双金属片弯曲到一定程度，推动脱扣机构，断开串接在控制电路中的常闭触点。控制电路断开后，接触器线圈失电，主触点断开，电机停转。

为什么叫"热"继电器？因为它的动作原理是基于热量积累的，不是电流超过阈值就立刻动作。这就模拟了电机的发热过程——电机短时间过载（比如启动时的大电流）不会导致热继电器动作，因为双金属片还没来得及弯曲到触发点；但长时间过载（即使只超过额定值10%-20%），热量逐渐积累，双金属片慢慢弯曲，最终触发保护。这种"反时限特性"（过载越严重，动作越快）恰好匹配电机的热特性——电机本身也有一定的热惯性，短时过载不会损坏，长时过载才会烧毁绝缘。

**整定电流**是热继电器的动作阈值，通常可以调节。设定原则：整定电流取电机额定电流的0.95到1.05倍。比如电机额定电流15.6A，热继电器整定电流设在15.6A左右。设得太低，电机正常运行时也会误跳；设得太高，电机过载时得不到保护。

## 8.4 接触器与断路器的区别

初学者容易把接触器和断路器搞混，因为两者都能接通和断开电路。但它们的角色完全不同：

接触器是"控制用"器件——负责按指令频繁地接通和断开电路。它可以每小时操作几百次，但它本身不具备过载和短路保护功能。接触器需要配合热继电器才能实现过载保护。

断路器（空气开关）是"保护用"器件——负责在电路发生短路或严重过载时自动跳闸切断电源。它不适合频繁操作，如果用来当开关频繁启停电机，内部机构会很快磨损。断路器自带过电流保护（电磁脱扣和热脱扣），能在短路和过载时自动断开。

在一个典型的电机控制电路中，断路器负责总电源的通断和短路保护，接触器负责电机的正常启停控制，热继电器负责过载保护。三者各司其职，缺一不可。

## 8.5 主电路与控制电路的分离

电机控制电路有一个重要的设计原则：主电路和控制电路分开。

主电路是从电源经过断路器、接触器主触点、热继电器加热元件到电机的电路，流过的是电机的工作电流（可能十几安甚至几十安）。控制电路是从电源经过按钮、热继电器常闭触点、接触器线圈和辅助触点的电路，流过的只是线圈电流（几百毫安）。

为什么要分开？第一，安全——操作人员接触的是控制电路的按钮和开关，即使控制电路电压较高（如220V），但电流很小，而且可以用24V安全电压的控制电路来操作，进一步保障人身安全。第二，方便——控制电路可以方便地加入各种逻辑元件（按钮、限位开关、时间继电器等），实现复杂的控制功能，而不需要改动主电路。第三，经济——控制电路的导线、开关等元件只需承受小电流，成本低、体积小。

## 8.6 常见错误与注意事项

**错误一：接触器线圈电压与控制电路电压不匹配。** 比如控制电路是24V安全电压，却买了220V线圈的接触器，结果怎么按按钮接触器都不吸合。购买前必须确认控制电路电压。

**错误二：热继电器整定电流设置不当。** 很多人装上热继电器后不调整整定电流，出厂默认值可能与电机额定电流不匹配。每次安装热继电器后，都必须根据电机铭牌上的额定电流重新调整。

**错误三：用断路器代替接触器频繁启停电机。** 断路器设计寿命通常只有几千次操作，频繁启停会加速磨损，导致保护功能失效。电机需要频繁启停时，必须用接触器。

**错误四：接触器选型只看额定电流不看使用类别。** 一个标注AC-1类40A的接触器，用在AC-3类（电机控制）下可能只能承受25A。必须按使用类别查看对应的额定电流。

## 本章小结

接触器是利用电磁铁原理实现"以小控大"的电气开关，由电磁系统、主触点、辅助触点和灭弧装置组成，用于电机的频繁启停控制。热继电器利用双金属片受热弯曲的原理，在电机过载时断开控制电路，起到过载保护作用。接触器负责控制，断路器负责保护，热继电器负责过载监测，三者配合构成完整的电机控制保护系统。选型时要注意额定电流、线圈电压、使用类别的匹配。

## 练习题

**8.1** 接触器的主触点和辅助触点各有什么用途？为什么需要分开设计？

**参考答案：** 主触点用于接通和断开电机主电路，承载电机的工作电流（大电流），需要大面积触点和灭弧装置。辅助触点用于控制电路中实现自锁、互锁等逻辑功能，只承载线圈电流（小电流）。分开设计是因为两者的电流等级、功能需求完全不同，分开后可以各自优化——主触点做得大而坚固以承受大电流和电弧，辅助触点做得小而灵敏以实现快速可靠的信号切换。

**8.2** 一台7.5kW三相异步电机，额定电压380V，额定电流15.6A。请选择合适的接触器型号参数（额定电流、线圈电压、使用类别）。

**参考答案：** 接触器额定电流应大于电机额定电流的1.2-1.5倍，即约19-23A，可选25A等级。使用类别选AC-3（鼠笼式电机启动和运转中断开）。线圈电压根据控制电路电压选择，如果控制电路为220V则选AC 220V线圈，如果为24V安全电压则选DC 24V线圈。

**8.3** 热继电器为什么不会在电机启动时动作？这利用了双金属片的什么特性？

**参考答案：** 电机启动时电流虽然是额定电流的5-7倍，但持续时间很短（通常几秒到十几秒）。热继电器利用双金属片的热惯性——双金属片从受热到弯曲至触发脱扣需要一定的热量积累时间。启动过程太短，双金属片来不及弯曲到触发点，所以不会动作。只有当过载持续较长时间、热量积累到一定程度时，热继电器才会动作。这种反时限特性恰好适应电机的启动和运行特点。

**8.4** 接触器和断路器在功能上有什么区别？能不能用断路器来代替接触器频繁启停电机？为什么？

**参考答案：** 接触器是控制器件，用于按指令频繁接通和断开电路，但不具备过载和短路保护功能。断路器是保护器件，用于在短路和过载时自动切断电路，但不适合频繁操作。不能用断路器代替接触器频繁启停电机，因为断路器的机械寿命和电气寿命远低于接触器，频繁操作会导致机构磨损、保护功能失效甚至触点熔焊。正确做法是用接触器做正常启停控制，断路器做线路保护。
