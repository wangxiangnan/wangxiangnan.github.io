# 第4章：点积——两个向量的"默契度"

> [!TIP] Part 2
> 向量之间的关系

## 故事引入

小王的奶茶店生意越来越好，骑手也从一个变成了三个。某天他盯着地图上骑手们的配送路线发呆，发现一个问题：

骑手小赵的路线是从店铺往东北方向走，骑手小钱的路线也是往东北方向走——这俩人的路线重合度极高，经常在同一条街上碰面。而骑手小孙的路线是往西北方向走，跟小赵几乎是反着来的。

小王心想：能不能用一个数字，来衡量两条路线在方向上到底有多"默契"？方向完全一致就是满分，完全相反就是负分，互相垂直就是零分？

这个"默契度分数"，就是今天要学的——**点积（dot product）**。

## 代数定义

点积的代数定义简单到令人发指：

> 两个向量 **a** = (a₁, a₂)，**b** = (b₁, b₂) 的点积 = 对应坐标相乘再相加。
>
> **a** · **b** = a₁b₁ + a₂b₂

就这么简单。没了。

举个例子：**a** = (3, 4)，**b** = (1, 2)

**a** · **b** = 3×1 + 4×2 = 3 + 8 = 11

等等，这就完了？别急，这只是"算数版本"。点积还有一个"几何版本"，两个版本其实是同一件事的不同面孔。

## 几何定义

点积的几何定义长这样：

> **a** · **b** = |**a**| |**b**| cos(θ)

其中 θ 是两个向量之间的夹角。

这个公式告诉我们：点积的大小取决于三个因素——**a** 的长度、**b** 的长度、以及它们之间夹角的余弦值。

当两个向量方向完全一致时（θ = 0°），cos(0°) = 1，点积取最大值 |**a**||**b**|。
当两个向量垂直时（θ = 90°），cos(90°) = 0，点积为 0。
当两个向量方向完全相反时（θ = 180°），cos(180°) = -1，点积取最小值 -|**a**||**b**|。

## 两个定义为什么等价？（余弦定理推导）

这是本章的重头戏。代数定义和几何定义看起来毫无关系——一个是坐标相乘相加，一个是模长乘余弦——但它们说的是同一件事。怎么证明？

靠**余弦定理**。

回忆一下三角形里的余弦定理：对于三角形三边 a、b、c，其中 c 是角 C 的对边：

$$c^2 = a^2 + b^2 - 2ab\cos(\theta)$$

现在，把向量 **a** 和 **b** 的起点放在一起，它们之间形成一个夹角 θ。连接两个向量的终点，就构成了一个三角形，第三条边就是向量 **a** - **b**。

令向量 **c** = **a** - **b**，那么 |**c**| 就是三角形第三条边的长度。

**第一步：** 用余弦定理写出：

$$|\mathbf{c}|^2 = |\mathbf{a}|^2 + |\mathbf{b}|^2 - 2|\mathbf{a}||\mathbf{b}|\cos(\theta)$$

**第二步：** 把 **c** = **a** - **b** 代入左边，展开 |**a** - **b**|²。

这里需要用到一个技巧：|**v**|² = **v** · **v**（向量和自己点积等于模长的平方）。这个后面会证明，先拿来用。

$$|\mathbf{a} - \mathbf{b}|^2 = (\mathbf{a} - \mathbf{b}) \cdot (\mathbf{a} - \mathbf{b})$$

展开这个点积（就像展开 (x-y)(x-y) 一样，点积满足分配律）：

$$= \mathbf{a} \cdot \mathbf{a} - \mathbf{a} \cdot \mathbf{b} - \mathbf{b} \cdot \mathbf{a} + \mathbf{b} \cdot \mathbf{b}$$

因为点积满足交换律（**a** · **b** = **b** · **a**），中间两项合并：

$$= |\mathbf{a}|^2 - 2(\mathbf{a} \cdot \mathbf{b}) + |\mathbf{b}|^2$$

**第三步：** 把第一步和第二步的结果放在一起：

$$|\mathbf{a}|^2 + |\mathbf{b}|^2 - 2|\mathbf{a}||\mathbf{b}|\cos(\theta) = |\mathbf{a}|^2 - 2(\mathbf{a} \cdot \mathbf{b}) + |\mathbf{b}|^2$$

两边都有 |**a**|² + |**b**|²，消掉：

$$-2|\mathbf{a}||\mathbf{b}|\cos(\theta) = -2(\mathbf{a} \cdot \mathbf{b})$$

两边除以 -2：

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos(\theta)$$

搞定！代数定义和几何定义，殊途同归。

## 点积的几何意义：投影 × 对方模长

把几何定义稍微变形一下：

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}| \cos(\theta) \times |\mathbf{b}|$$

|**a**|cos(θ) 是什么？就是向量 **a** 在 **b** 方向上的"影子长度"（投影长度）。

所以点积的几何意义是：**一个向量在另一个向量方向上的投影长度，乘以另一个向量的模长**。

打个比方：你和朋友一起搬砖，你使了 100 牛的力，朋友使了 80 牛的力，但你们用力的方向不完全一致。你实际"有效"贡献给朋友的力，就是你的力在朋友方向上的投影乘以朋友的力的大小——这就是点积在物理中的经典应用。

## 正交（垂直）：点积为 0

当两个向量垂直时，θ = 90°，cos(90°) = 0，所以：

**a** · **b** = 0

反过来也成立：如果两个非零向量的点积为 0，它们一定垂直。

这个性质非常实用——判断两个向量是否垂直，不用算角度，只要看点积是不是 0 就行。

在代数上验证一下：**a** = (3, 4)，**b** = (-8, 6)

**a** · **b** = 3×(-8) + 4×6 = -24 + 24 = 0

确实垂直！

## 点积的性质

- **交换律**：**a** · **b** = **b** · **a**（显然，乘法交换嘛）
- **分配律**：**a** · (**b** + **c**) = **a** · **b** + **a** · **c**
- **与模长的关系**：**a** · **a** = |**a**|²（这就是前面推导中用到的那个性质）
- **数乘结合**：(k**a**) · **b** = k(**a** · **b**) = **a** · (k**b**)

注意：**点积不满足结合律**！(**a** · **b**) · **c** 这个写法是错的——因为 **a** · **b** 的结果是一个标量，标量和向量的点积没有定义。

## 类比时间

点积就像"两个人聊天有多少共同话题"：

- 方向一致（θ = 0°）：聊得热火朝天，共同话题最多，点积最大。
- 方向垂直（θ = 90°）：一个聊奶茶，一个聊编程，完全不在一个频道，点积 = 0。
- 方向相反（θ = 180°）：你说东我说西，不仅没共同话题还在抬杠，点积为负。

## 代码示例

```javascript
// 计算两个二维向量的点积
function dot(a, b) {
  return a[0] * b[0] + a[1] * b[1];
}

// 计算向量的模长
function magnitude(v) {
  return Math.sqrt(v[0] * v[0] + v[1] * v[1]);
}

// 计算两个向量之间的夹角（弧度）
function angleBetween(a, b) {
  const cosTheta = dot(a, b) / (magnitude(a) * magnitude(b));
  // 防止浮点误差导致 cosTheta 超出 [-1, 1]
  const clampedCos = Math.max(-1, Math.min(1, cosTheta));
  return Math.acos(clampedCos);
}

// 来试试小王的骑手问题
const routeA = [3, 4]; // 骑手小赵的方向
const routeB = [1, 2]; // 骑手小钱的方向
const routeC = [-3, -4]; // 骑手小孙的方向（和A反着来）

console.log("小赵和小钱的默契度:", dot(routeA, routeB)); // 11
console.log("小赵和小孙的默契度:", dot(routeA, routeC)); // -25（完全相反！）

// 计算夹角
const angleAB = angleBetween(routeA, routeB);
console.log("小赵和小钱路线的夹角:", (angleAB * 180 / Math.PI).toFixed(2), "度");
// 约 8.13 度——非常默契！
```

## 小结

- 点积有两种定义：代数版（坐标相乘相加）和几何版（模长乘余弦），通过余弦定理可以证明它们等价。
- 点积衡量的是两个向量在方向上的"默契度"——方向越一致，值越大。
- 点积为 0 意味着两个向量垂直（前提是非零向量）。
- 点积的结果是一个标量，不是向量。

## 练习题

**第1题：** 计算 **a** = (2, 5) 和 **b** = (3, -1) 的点积。

**第2题：** 判断 **a** = (4, 3) 和 **b** = (6, -8) 是否垂直。

**第3题：** 已知 **a** = (1, √3)，**b** = (0, 2)，求两个向量的夹角。

**第4题：** 已知 **a** = (3, 4)，求 **a** · **a**，并验证它等于 |**a**|²。

## 练习题答案

**第1题：**
**a** · **b** = 2×3 + 5×(-1) = 6 - 5 = **1**

**第2题：**
**a** · **b** = 4×6 + 3×(-8) = 24 - 24 = 0
点积为 0，所以 **a** 和 **b** **垂直**。

**第3题：**
**a** · **b** = 1×0 + √3×2 = 2√3
|**a**| = √(1+3) = 2，|**b**| = 2
cos(θ) = 2√3 / (2×2) = √3/2
θ = arccos(√3/2) = **30°（π/6 弧度）**

**第4题：**
**a** · **a** = 3×3 + 4×4 = 9 + 16 = 25
|**a**| = √(9+16) = √25 = 5
|**a**|² = 25
两者相等，验证通过。
