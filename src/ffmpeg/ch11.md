# 第11章：水印与字幕——给视频加标签

水印是内容创作者的身份证，字幕是跨越语言障碍的桥梁。本章将教你用 FFmpeg 给视频添加图片水印、文字水印，以及嵌入各种格式的字幕。

## 11.1 图片水印：overlay 滤镜

**最基本的水印添加：**

```bash
ffmpeg -i input.mp4 -i logo.png -vf "overlay=10:10" output.mp4
```

`overlay=10:10` 表示把 logo.png 放在距离左上角 X=10, Y=10 的位置。

**设置水印透明度（需要先处理 logo）：**

```bash
ffmpeg -i input.mp4 -i logo.png -vf "overlay=10:10" -c:v libx264 -crf 23 output.mp4
```

如果 logo.png 本身带有透明通道（alpha channel），FFmpeg 会自动处理透明度。

> 💡 提示：确保你的 logo 是 PNG 格式并且带有透明背景。JPG 不支持透明。

## 11.2 水印位置控制（九宫格）

使用 FFmpeg 内置变量可以精确控制水印位置：

- `main_w` / `W`：视频宽度
- `main_h` / `H`：视频高度
- `overlay_w` / `w`：水印宽度
- `overlay_h` / `h`：水印高度

**九个常用位置：**

```bash
# 左上角
ffmpeg -i input.mp4 -i logo.png -vf "overlay=10:10" output.mp4

# 右上角
ffmpeg -i input.mp4 -i logo.png -vf "overlay=W-w-10:10" output.mp4

# 左下角
ffmpeg -i input.mp4 -i logo.png -vf "overlay=10:H-h-10" output.mp4

# 右下角
ffmpeg -i input.mp4 -i logo.png -vf "overlay=W-w-10:H-h-10" output.mp4

# 居中
ffmpeg -i input.mp4 -i logo.png -vf "overlay=(W-w)/2:(H-h)/2" output.mp4

# 上居中
ffmpeg -i input.mp4 -i logo.png -vf "overlay=(W-w)/2:10" output.mp4

# 下居中
ffmpeg -i input.mp4 -i logo.png -vf "overlay=(W-w)/2:H-h-10" output.mp4

# 左居中
ffmpeg -i input.mp4 -i logo.png -vf "overlay=10:(H-h)/2" output.mp4

# 右居中
ffmpeg -i input.mp4 -i logo.png -vf "overlay=W-w-10:(H-h)/2" output.mp4
```

**缩小水印尺寸：**

```bash
# 先将 logo 缩放到宽度 100，再叠加
ffmpeg -i input.mp4 -i logo.png -vf "[1:v]scale=100:-2[logo];[0:v][logo]overlay=W-w-10:10" output.mp4
```

这里用了滤镜链语法：先把第二个输入（logo）缩放到 100px 宽并标记为 `[logo]`，然后将 `[logo]` 叠加到视频上。

## 11.3 文字水印：drawtext 滤镜

不想准备 logo 图片？直接打文字也行。

**基本文字水印：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='Hello World':fontsize=36:fontcolor=white:x=10:y=10" output.mp4
```

**中文字符水印：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='测试文字':fontfile='C\:/Windows/Fonts/msyh.ttc':fontsize=36:fontcolor=white:x=10:y=10" output.mp4
```

> ⚠️ 注意：使用中文字符时，必须用 `fontfile` 指定支持中文的字体文件路径，否则会显示方块或乱码。Windows 路径中的冒号需要转义为 `\:`。

## 11.4 drawtext 参数详解

| 参数 | 说明 | 示例 |
| ------ | ------ | ------ |
| text | 文字内容 | `text='我的水印'` |
| fontfile | 字体文件路径 | `fontfile='arial.ttf'` |
| fontsize | 字体大小 | `fontsize=48` |
| fontcolor | 字体颜色 | `fontcolor=white@0.7` |
| x, y | 位置坐标 | `x=W-w-10:y=10` |
| borderw | 边框宽度 | `borderw=2` |
| bordercolor | 边框颜色 | `bordercolor=black` |
| shadowx, shadowy | 阴影偏移 | `shadowx=2:shadowy=2` |
| shadowcolor | 阴影颜色 | `shadowcolor=black@0.5` |
| box | 文字背景框 | `box=1` |
| boxcolor | 背景框颜色 | `boxcolor=black@0.4` |
| boxborderw | 背景框边距 | `boxborderw=5` |

**带描边和阴影的完整示例：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='Copyright 2024':fontsize=32:fontcolor=white:borderw=2:bordercolor=black:shadowx=3:shadowy=3:shadowcolor=black@0.5:x=W-w-20:y=H-h-20" output.mp4
```

**半透明白色 + 黑色描边（经典风格）：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='@MyChannel':fontfile='arial.ttf':fontsize=28:fontcolor=white@0.8:borderw=1:bordercolor=black@0.6:x=W-w-15:y=H-h-15" output.mp4
```

## 11.5 动态文字水印

**显示当前时间（实时时钟效果）：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='%{localtime\:%Y-%m-%d %H\\:%M\\:%S}':fontsize=24:fontcolor=white:x=10:y=10" output.mp4
```

**显示帧时间码：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='%{pts\:hms}':fontsize=24:fontcolor=white:x=10:y=10" output.mp4
```

**滚动文字（从右到左）：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='这是一条滚动字幕    ':fontsize=30:fontcolor=white:y=H-50:x=w-w*t/5" output.mp4
```

`x=w-w*t/5` 让文字位置随时间变化。

**淡入淡出效果：**

```bash
ffmpeg -i input.mp4 -vf "drawtext=text='Breaking News':fontsize=48:fontcolor=white:borderw=2:bordercolor=black:x=(W-w)/2:y=H-80:alpha='if(lt(t,1),t,if(gt(t,4),5-t,1))'" output.mp4
```

这条命令让文字在第 0-1 秒淡入，第 4-5 秒淡出，中间完全显示。

## 11.6 硬字幕 vs 软字幕

**硬字幕（Hardsub）：** 字幕被"烧"进视频画面，成为视频图像的一部分。所有播放器都能看到，但无法关闭。

**软字幕（Softsub）：** 字幕作为独立的流存储在容器中，播放器可以选择显示/隐藏、切换语言。

| 对比 | 硬字幕 | 软字幕 |
| ------ | -------- | -------- |
| 兼容性 | 所有播放器 | 需要播放器支持 |
| 可关闭 | 不可以 | 可以 |
| 画质影响 | 有（重新编码） | 无 |
| 样式保真 | 完全保真 | 取决于播放器 |
| 处理速度 | 慢（重编码） | 快（复制流） |

## 11.7 嵌入软字幕

**嵌入 SRT 字幕到 MKV：**

```bash
ffmpeg -i input.mp4 -i subtitle.srt -c:v copy -c:a copy -c:s srt output.mkv
```

**嵌入 ASS 字幕到 MKV（保留样式）：**

```bash
ffmpeg -i input.mp4 -i subtitle.ass -c:v copy -c:a copy -c:s ass output.mkv
```

**嵌入字幕到 MP4（使用 mov_text 编码）：**

```bash
ffmpeg -i input.mp4 -i subtitle.srt -c:v copy -c:a copy -c:s mov_text output.mp4
```

> ⚠️ 注意：MP4 容器只支持 `mov_text` 格式的字幕流。如果你需要 ASS 样式的完整支持，请使用 MKV 容器。

**设置字幕语言标签：**

```bash
ffmpeg -i input.mp4 -i sub_en.srt -i sub_cn.srt -c:v copy -c:a copy -c:s srt -metadata:s:s:0 language=eng -metadata:s:s:1 language=chi output.mkv
```

## 11.8 烧录硬字幕：subtitles 滤镜

```bash
# 烧录 SRT 字幕
ffmpeg -i input.mp4 -vf "subtitles=subtitle.srt" output.mp4

# 烧录 ASS 字幕（保留完整样式）
ffmpeg -i input.mp4 -vf "ass=subtitle.ass" output.mp4
```

> ⚠️ 注意：烧录字幕需要重新编码视频，处理时间取决于视频长度。

**自定义硬字幕样式：**

```bash
ffmpeg -i input.mp4 -vf "subtitles=subtitle.srt:force_style='FontSize=24,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2,MarginV=30'" output.mp4
```

**从 MKV 文件中提取内封字幕并烧录：**

```bash
ffmpeg -i input.mkv -vf "subtitles=input.mkv:si=0" output.mp4
```

`si=0` 表示选择第一个字幕流。

## 11.9 去除水印/马赛克：delogo 滤镜

```bash
# 去除指定区域的水印
ffmpeg -i input.mp4 -vf "delogo=x=10:y=10:w=200:h=50" output.mp4
```

`delogo` 会用周围的像素填充指定矩形区域，达到"擦除"效果。效果取决于水印位置和背景复杂度——简单背景效果好，复杂背景可能留下模糊痕迹。

> ⚠️ 注意：`delogo` 不是魔法。对于半透明水印或复杂背景上的水印，效果可能不理想。请尊重版权，仅用于去除自己视频中的水印。

## 11.10 多语言字幕轨道管理

**为 MKV 文件添加多条字幕轨道：**

```bash
ffmpeg -i video.mp4 -i sub_english.srt -i sub_chinese.srt -i sub_japanese.srt \
  -c:v copy -c:a copy -c:s srt \
  -metadata:s:s:0 language=eng -metadata:s:s:0 title="English" \
  -metadata:s:s:1 language=chi -metadata:s:s:1 title="中文" \
  -metadata:s:s:2 language=jpn -metadata:s:s:2 title="日本語" \
  output.mkv
```

**选择默认字幕轨道：**

```bash
ffmpeg -i input.mkv -c copy -disposition:s:0 default -disposition:s:1 0 output.mkv
```

`-disposition:s:0 default` 将第一条字幕设为默认显示。

**删除特定字幕轨道：**

```bash
# 保留视频、音频、第一条字幕，删除其他字幕
ffmpeg -i input.mkv -map 0:v -map 0:a -map 0:s:0 -c copy output.mkv
```

## 本章小结

- `overlay` 滤镜添加图片水印，用 `W`/`H`/`w`/`h` 变量精确定位九宫格位置
- `drawtext` 滤镜添加文字水印，支持中文字体、描边、阴影、动态效果
- 软字幕用 `-c:s copy` 快速嵌入，硬字幕用 `subtitles` 滤镜烧录
- MKV 是字幕支持最好的容器格式，MP4 只支持 mov_text
- `-map` 参数让你精确控制多字幕轨道的选择和排列
