# 第9章 读平面图：线管走向、回路编号与设备定位

小王对着平面图发愁。图上一间客厅里画了七八个符号——灯、开关、插座、空调——线管密密麻麻地连在一起，像一盘蜘蛛网。他试着从配电箱出发追踪线路走向，追了两根线就"迷路"了："这条线到底是去插座的还是去开关的？为什么好几条线挤在同一根管子里？"

老张走过来一看："你这样一根根追，追到天黑也追不完。平面图有平面图的读法——你得从配电箱出发，按回路编号一组一组地看，同一回路的线和设备用同一种颜色标记，思路就清楚了。"

## 9.1 平面图的阅读方法：从电源开始，按回路追踪

电气平面图是在建筑平面图的基础上叠加了电气信息的图纸。建筑平面图提供了墙体、门窗、房间的轮廓，电气信息则叠加在上面——配电箱装在哪面墙、灯具在天花板什么位置、插座离地多高、开关在门口还是床头。

读平面图的正确方法，就像你在水管平面图上追踪水流路径一样：从"水源"（配电箱）出发，沿"水管"（线管）走，看"水管"分了几路、每路供了哪些"水龙头"（灯具/插座/开关）。

具体步骤如下：

**第一步：找到配电箱的位置。** 配电箱是平面上所有线路的"起点"，通常画一个矩形方框，旁边标注编号（如AL-1）。

**第二步：识别每个回路的编号和走向。** 从配电箱引出的线管旁边会标注回路编号（如L1、N1等）。同一回路的所有设备和线管，都用相同的回路编号标记。

**第三步：沿回路追踪。** 选定一个回路，从配电箱开始，沿着线管走向一路追过去，看这根管子经过哪些设备（先到哪个开关、再到哪个灯具），最后到哪个设备终止。

**第四步：逐回路重复。** 一个回路追完，再追下一个，直到所有回路都理清。

为什么用"单线"表示多根导线？这是初学者最常感到困惑的地方。平面图上的线管通常只用一条线表示（单线表示法），但实际管子里可能穿了3根甚至5根导线。之所以用单线，是因为平面图表达的是"管子的走向"，而不是"每根导线的走向"——同一根管子里的所有导线走向当然是一样的，画3条线反而显得杂乱。导线的根数和规格，在系统图中已经标注清楚了。这就像水管平面图上只画一条线代表水管，不需要把管子里的水分子画出来一样。

## 9.2 线管走向的表示方法

平面图中，线管的走向用线段表示，线段的方向和路径就是线管的实际敷设路径。几个关键的表示方法：

**直线段**表示线管沿直线敷设。线段的方向（水平/垂直/斜线）对应线管在墙面或天花板上的实际走向。正规图纸中，线管应尽量沿墙面水平或垂直敷设，避免斜走——这和水管一样，横平竖直不仅美观，也方便后期检修。

**转折点**表示线管改变方向。在平面图上就是一个拐角。

**线段旁边标注**：通常在线段旁边标注回路编号、导线规格和管径。例如"L1 BV-3×1.5 PC16 CC"表示照明L1回路、3根1.5平方毫米导线、穿16mm PVC管、顶板暗敷。如果同一走向有多条回路共管，会并列标注多行。

**穿墙或穿楼板**：线管从一面墙穿到另一面墙、或从一层穿到另一层时，平面图上会用一个小圆圈或符号标记穿越点。

## 9.3 回路编号与设备定位

平面图中每个电气设备（灯具、开关、插座）旁边都会标注回路编号，告诉你它属于哪个回路。设备定位则通过安装高度标注来实现：

**灯具**：平面图中灯具的位置就是其在天花板上的投影位置。安装高度通常默认与天花板平齐（吸顶安装），如果是吊装灯具，会额外标注吊装高度。

**开关**：开关一般标注在门口或操作位置旁。安装高度通常为距地1.3-1.4米（底边距地）。平面图上开关旁边常标注几联几控，如"单联单控"表示一个开关控制一盏灯，"双联双控"表示两个开关可以从不同位置控制同一盏灯（如楼梯上下两端）。

**插座**：插座在平面图上用半圆加竖线的符号表示，旁边标注安装高度。普通插座一般距地0.3米，空调插座距地1.8-2.2米，厨房操作台插座距地1.1-1.3米，卫生间插座距地1.3-1.5米。这些高度都有规范依据（参考GB 50303和住宅设计规范），不是随意定的。

## 9.4 弱电平面图的阅读

现代住宅除了强电（照明、插座、空调等220V/380V的电力线路），还有一套弱电系统（也叫信息系统或智能化系统），包括：网络（以太网）、电视（有线电视）、电话、可视对讲、安防报警等。

弱电平面图和强电平面图的读法基本相同，但有几点区别：

第一，弱电设备用不同的符号表示，如网络插座（标注"TP"或"DATA"）、电视插座（标注"TV"）、电话插座（标注"TEL"）、信息面板（标注"ID"）。看图例表就能区分。

第二，弱电线管必须与强电线管保持一定距离（规范要求平行间距不小于300mm，交叉间距不小于150mm），以防止强电干扰弱电信号。平面图上如果看到强弱电线管靠得太近，就是设计问题。

第三，弱电系统通常有弱电箱（多媒体箱或信息箱），是所有弱电信号的汇聚点，相当于弱电信号的"总配电箱"。

## 9.5 从平面图统计工程量

平面图除了指导施工，还有一个重要用途——统计工程量。施工单位需要根据平面图计算：线管总长度（量图上各段线管长度再乘以比例）、导线总长度（线管长度乘以每管穿线根数）、各类设备的数量（灯具多少个、开关多少个、各种插座各多少个）。

统计方法是：准备一把尺子（或在CAD软件中用测量工具），沿着平面图上每段线管量取长度，乘以比例系数换算为实际长度，然后分回路汇总。导线的长度 = 线管长度 × 管内穿线根数 + 配电箱内预留长度（通常每端预留箱体半周长）。设备数量则直接数符号个数，按类型分类统计。

这些工程量数据是编制预算和采购材料的基础，也是竣工验收时核对实际用量的依据。

## 9.6 平面图与系统图的交叉验证

平面图和系统图必须完全一致，这是基本的设计质量要求。交叉验证的方法：

在系统图中列出的每个回路编号，在平面图中都应该能找到对应的线管和设备。如果系统图有N3回路但平面图上找不到，要么是设计遗漏，要么是图纸版本不对。

反过来，平面图上出现的每个回路编号，在系统图中都应该有对应的断路器和漏保配置。如果平面图上画了一个回路但系统图里没有，那这个回路就"没人保护"，是严重的漏项。

设备数量也应一致：系统图标注N1回路供8个插座，平面图上N1回路就应该刚好连了8个插座符号。数量对不上，需要找设计单位澄清。

## 9.7 常见错误与注意事项

**错误一：不按回路追踪，而是"满图乱看"。** 平面图线条密集，不按回路一组组看，很容易搞混。正确做法是每次只追踪一个回路，可以用荧光笔在图纸上标记已追踪的回路。

**错误二：忽视安装高度标注。** 平面图上的设备符号只表示水平位置，安装高度需要看旁边的标注。有的新手只看符号位置就以为知道了设备在哪，忘了看高度标注，结果把空调插座装在了0.3米的高度。

**错误三：强弱电管线距离不够。** 现场施工时为了省事，把网线和电线穿在同一根管子里，会导致网络信号严重干扰。平面图上如果强弱电管线靠得太近，施工时就应该主动提出调整。

**错误四：漏算工程量。** 统计线管长度时忘了乘以比例系数，或者忘了加配电箱内预留长度，导致材料采购不足。

## 本章小结

电气平面图以建筑平面为底图，叠加了电气设备位置和线管走向信息。读平面图应从配电箱出发，按回路编号逐回路追踪线管走向和设备位置。平面图采用单线表示法，一根线代表一根管子而非一根导线。弱电平面图读法类似，但需注意强弱电管线间距要求。平面图可用于统计工程量和与系统图交叉验证。

## 练习题

1. 为什么平面图用单线表示法（一条线代表一根管子），而不是把管子里每根导线都画出来？

2. 平面图上标注"WC"和"CC"分别代表什么敷设方式？这些标注对施工有什么影响？

3. 在平面图上发现一个插座旁边标注"N2 H+0.3"，请解释这个标注的含义。

4. 统计工程量时，导线长度应如何计算？为什么不能直接用线管长度代替导线长度？

5. 如果系统图中有N5回路，但平面图上找不到任何标注为N5的线管和设备，可能的原因有哪些？应如何处理？

**参考答案**

1. 因为同一根管子里的所有导线走向完全相同，画多根线只会让图纸杂乱且不提供额外信息。导线的根数和规格已在系统图中标注清楚，平面图只需表达管子的走向路径即可。

2. WC表示墙内暗敷（Wall Concealed），CC表示顶板暗敷（Ceiling Concealed）。WC意味着线管要预埋在墙体里或沿墙面开槽埋入，CC意味着线管要预埋在楼板中或沿天花板敷设。两种方式的施工工艺和所需材料完全不同。

3. N2表示这个插座属于N2（第二个插座回路）；H+0.3表示安装高度为距地0.3米（H通常代表地面标高）。

4. 导线长度 = 线管长度 × 管内穿线根数 + 配电箱预留长度 + 设备端预留长度。不能直接用线管长度代替，因为管子里穿了多根导线（如火线、零线、地线共3根），每根导线的长度都约等于管子长度，总导线用量是管子长度的数倍。

5. 可能原因：①平面图漏画了N5回路的线管和设备（设计遗漏）；②N5回路在其他楼层的平面图上（需要查看其他楼层图纸）；③图纸版本不一致，系统图和平面图不是同一版本。处理方式：联系设计单位确认，要求补充平面图或澄清回路归属。
