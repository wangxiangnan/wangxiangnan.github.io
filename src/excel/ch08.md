# 第8章：图表制作——数据可视化入门 📊

*月底了，小王要把这个月的销售数据汇报给他的合伙人小张。他直接把Excel表格发过去，小张回了一句："这么多数字我看不懂啊，能不能给我做个图？"小王一脸懵。小李又来了："Excel做图表超简单的，选数据、点一下、图表就出来了。"*

## 8.1 图表类型选择：柱形图、折线图、饼图、散点图各自适合什么

做图表之前，最重要的是**选对图表类型**。不同类型适合展示不同的信息：

**柱形图（Column Chart）**

- **适合**：比较不同类别的数据大小
- **奶茶店场景**：各商品的销售量对比、各天的营业额对比
- **口诀**：比大小，用柱形

**折线图（Line Chart）**

- **适合**：展示数据随时间的变化趋势
- **奶茶店场景**：一个月内营业额的走势、某种商品销量的变化
- **口诀**：看趋势，用折线

**饼图（Pie Chart）**

- **适合**：展示各部分占总体的比例
- **奶茶店场景**：各商品销售额占总营业额的比例
- **口诀**：看占比，用饼图
- **注意**：饼图只能展示一组数据，类别不宜太多（建议不超过6-7个）

**散点图（Scatter Chart）**

- **适合**：展示两组数据之间的关系/相关性
- **奶茶店场景**：天气温度与冷饮销量的关系
- **口诀**：看关系，用散点

> 💡 **提示**：选错图表类型是新手最常犯的错误。比如用饼图展示时间趋势（看不出趋势），或用折线图展示不同类别的对比（线连起来没有意义）。记住口诀：比大小用柱形，看趋势用折线，看占比用饼图，看关系用散点。

## 8.2 快速创建图表

Excel创建图表非常简单，三步搞定：

**方法一：鼠标操作**

1. 选中要做图表的数据区域（包括表头）
2. "插入"选项卡 → 选择图表类型 → 选择具体样式
3. 图表就出现在工作表中了！

**方法二：快捷键**

- `Alt + F1`：在当前工作表中快速创建图表（默认柱形图）
- `F11`：在新工作表中创建图表

**选数据的技巧**

选中数据时要包括**表头**（列标题），这样Excel会自动给图表加上图例和坐标轴标签。

比如，要做各商品销售对比：

选中 A1:B7（商品名称和金额），插入 → 柱形图 → 一个漂亮的柱形图就出来了。

要做每日营业额趋势：

选中 A1:A32（日期）和 E1:E32（总营业额），按住 `Ctrl` 可以选不连续的区域，插入 → 折线图。

## 8.3 图表元素：标题、图例、数据标签、坐标轴

图表创建后，可以根据需要添加或修改各种元素。

**图表元素按钮**

选中图表后，右上角会出现一个 `+` 号（图表元素按钮），点击可以勾选/取消各种元素：

**① 图表标题**

- 默认标题是"图表标题"，请改成有意义的标题
- 比如："小王奶茶店1月各商品销售对比"
- 双击标题文字可以直接编辑

**② 图例**

- 说明每种颜色/线条代表什么
- 可以放在图表的上方、下方、左侧、右侧
- 如果只有一组数据，图例可以省略

**③ 数据标签**

- 在图表上直接显示具体数值
- 对于柱形图，标签显示在柱子顶端
- 对于饼图，标签可以显示数值和百分比
- 勾选"数据标签"即可添加

**④ 坐标轴**

- **横轴（类别轴）**：通常是分类名称
- **纵轴（数值轴）**：通常是数值刻度
- 可以修改坐标轴的标题（如"金额（元）"）
- 可以调整刻度范围（如最小值从0改为100）

**⑤ 网格线**

- 水平网格线帮助读取纵轴数值
- 可以添加/删除/调整样式

> 💡 **提示**：图表元素不是越多越好。好的图表是"简洁清晰"的——必要的标签有，多余的去掉。Edward Tufte（数据可视化大师）说过："图表中每一滴墨水都应该传达信息。"

## 8.4 图表美化：配色、样式、布局调整

Excel提供了很多快速美化图表的方法：

**图表样式**

选中图表 → "图表设计"选项卡 → "图表样式"区域有很多预设样式，点击即可应用。从简约到华丽，选一个适合你的。

**配色方案**

"图表设计" → "更改颜色" → 选择一种配色方案。建议：

- 使用同色系的深浅变化（如深蓝→浅蓝）来展示同类数据
- 用对比色（如蓝vs橙）来区分不同类别
- 避免使用过于刺眼或相近的颜色

**布局调整**

- **移动图表**：直接拖拽图表到想要的位置
- **调整大小**：拖拽图表边框的圆点
- **独立工作表**：右键图表 → "移动图表" → 选择"新工作表"，可以把图表放在单独的Sheet里，更适合展示

**手动调整细节**

- 双击图表中的任何元素（柱子、线条、坐标轴）可以打开格式设置面板
- 可以修改颜色、边框、阴影、透明度等
- 右键点击数据系列 → "设置数据系列格式"可以调整间距、重叠等

> 💡 **提示**：图表美化要适度。3D效果、渐变、阴影这些虽然好看，但往往降低数据的可读性。"扁平化 + 简洁"是数据可视化的主流审美。

## 8.5 组合图表：双轴图表

有时候你需要在一张图表里展示两组**量级不同**的数据，比如"营业额（千元级）"和"订单数（百位级）"。如果放在同一个纵轴上，订单数的变化几乎看不出来。

**双轴图表**就是解决方案——左轴和右轴分别对应不同的数据。

**创建方法**

1. 选中包含两组数据的区域
2. 插入 → 图表 → "推荐的图表" → "所有图表" → "组合"
3. 为每组数据选择图表类型（比如营业额用柱形图，订单数用折线图）
4. 给其中一组勾选"次坐标轴"
5. 确定

**奶茶店实例**

| A | B | C |
| --- | --- | --- |
| 日期 | 营业额 | 订单数 |
| 1月1日 | 2164 | 142 |
| 1月2日 | 1890 | 128 |
| 1月3日 | 2450 | 163 |
| ... | ... | ... |

- 营业额（左轴，柱形图）：直观看出每天的金额
- 订单数（右轴，折线图）：叠加在上面，看出订单量的趋势

两个指标放在一张图里，一眼就能发现"营业额高但订单数少"（说明客单价高）或"订单数多但营业额低"（说明客单价低）的日子。

## 8.6 迷你图：单元格里的微型图表

**迷你图**是Excel 2010引入的功能——在单个单元格里嵌入一个微型图表，不占额外空间，特别适合在数据表格旁边添加快速可视化。

**三种迷你图类型**

- **折线迷你图**：展示趋势
- **柱形迷你图**：展示大小对比
- **盈亏迷你图**：展示正负值

**创建方法**

1. 选中要放置迷你图的单元格
2. "插入"选项卡 → "迷你图"区域 → 选择类型
3. 选择数据范围
4. 确定

**奶茶店实例**

假设小王有每种商品1月每周的销量数据：

| A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- |
| 商品 | 第1周 | 第2周 | 第3周 | 第4周 | 趋势 |
| 珍珠奶茶 | 220 | 235 | 210 | 250 | （迷你图） |
| 红豆奶茶 | 180 | 175 | 190 | 200 | （迷你图） |
| 芒果冰沙 | 100 | 95 | 110 | 130 | （迷你图） |

在F列创建折线迷你图，数据范围选B到E列对应行，就能在单元格里看到每种商品一个月的销量走势。

**迷你图设置**

- 选中迷你图 → "迷你图"选项卡
- 可以标记高点、低点、首点、末点
- 可以更改颜色和粗细
- 可以设置纵轴范围

> 💡 **提示**：迷你图特别适合放在月度/年度汇总表的最右侧，作为每行数据的快速可视化。不用单独做大图表，就能看出趋势。

## 8.7 实战：为奶茶店制作月度销售趋势图

让我们为小王的奶茶店制作一套完整的月度销售图表！

**数据基础**

"日销售记录"工作表包含1月31天的数据：

- A列：日期
- B~F列：五种商品各自的销量
- G列：每日总营业额

**图表一：每日营业额趋势图（折线图）**

1. 选中 A1:A32（日期）和 G1:G32（总营业额）
2. 插入 → 折线图 → 带数据标记的折线图
3. 图表标题改为"小王奶茶店1月每日营业额趋势"
4. 纵轴标题设为"营业额（元）"
5. 添加水平网格线
6. 选中营业额最高的那一天，添加数据标注

**图表二：各商品销售对比（柱形图）**

1. 在汇总区域计算每种商品的月度总销量
2. 选中商品名称和总销量
3. 插入 → 柱形图 → 簇状柱形图
4. 图表标题："1月各商品销售总量对比"
5. 添加数据标签
6. 给销量最高的柱子设为深蓝色，其他设为浅蓝色（突出冠军）

**图表三：销售占比（饼图）**

1. 选中商品名称和各自的月度销售金额
2. 插入 → 饼图 → 二维饼图
3. 图表标题："1月各商品销售额占比"
4. 添加数据标签 → 显示"百分比"
5. 把占比最大的那一片"拉出来"（选中后往外拖一点）

**图表四：迷你图趋势**

在汇总表的最后一列，给每种商品添加折线迷你图，展示该商品一个月内的销量走势。

**最终效果**

小王的合伙人小张看到这套图表后说："这下清楚多了！我一眼就能看出哪天的生意好、哪种奶茶最受欢迎、各种奶茶的占比是多少。"

> 💡 **提示**：好的数据报告不需要太多文字，图表就是最好的语言。记住一个原则——**一张图只传达一个核心信息**。不要试图在一张图里塞入太多东西，如果信息多，就做多张图。

2. 创建一个饼图展示五种奶茶的销售额占比，添加百分比数据标签。再创建一个柱形图对比五种奶茶的月度总销量，添加数据标签。
3. 在一份包含每周销量数据的汇总表中，给每种商品添加折线迷你图。然后创建一个双轴组合图表：左轴为月营业额（柱形图），右轴为月订单数（折线图）。
