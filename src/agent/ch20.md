## 20.1 Checkpointer：Agent的"数据库"

先看第19章的DocMind有多健忘：

```text
# 场景：用户和DocMind对话
# 第一轮
user: "帮我搜索Agent架构的文档"
agent: "找到了3篇相关文档..."

# 第二轮（刷新页面后）
user: "继续刚才的话题"
agent: "什么话题？我不记得了..."  # 失忆了！
```

这在开发调试阶段还能忍受，但在生产环境中完全不可接受。想象一下：

- 用户关闭浏览器后重新打开，所有对话历史丢失
- Agent执行到一半崩溃了，无法从中断处恢复
- 想回滚到对话的某个历史节点，做不到

> 用编程的话说：Agent现在就像一个没有数据库的Web应用——每次请求都是全新的，没有Session、没有持久化、没有回滚能力。我们需要给Agent加一个"数据库"。

**Checkpointer**就是Agent的"数据库"。它的核心思想只有一句话：**在图的每个节点执行完毕后，自动保存当前的完整State。**

```text
START -> agent (保存state_1) -> tools (保存state_2) -> agent (保存state_3) -> END (保存state_4)

每个保存点包含：
- 完整的消息历史
- 所有State字段的当前值
- 时间戳
- 父节点信息（用于回溯）
```

> 类比：Checkpointer就像Git——每次节点执行完就像做一次`git commit`。你可以查看历史（`git log`）、回退到某个版本（`git checkout`）、甚至分叉（`git branch`）。

## 20.2 内置Checkpointer

LangGraph提供了三种内置的Checkpointer。

### 20.2.1 MemorySaver（内存保存）

```python
"""
MemorySaver：最简单的Checkpointer
状态保存在内存中，程序结束就丢失
适合：开发调试、快速原型
"""
from langgraph.checkpoint.memory import MemorySaver

# 创建checkpointer
checkpointer = MemorySaver()

# 编译时传入
app = graph.compile(checkpointer=checkpointer)

# 调用时必须指定thread_id
config = {"configurable": {"thread_id": "conversation-1"}}
result = app.invoke(
    {"messages": [HumanMessage(content="你好")]},
    config=config
)
```

### 20.2.2 SqliteSaver（本地文件持久化）

```python
"""
SqliteSaver：状态保存在SQLite数据库文件中
程序重启后状态仍然存在
适合：单机部署、中小规模应用
"""
from langgraph.checkpoint.sqlite import SqliteSaver
import sqlite3

# 创建SQLite连接
conn = sqlite3.connect("docmind_checkpoints.db", check_same_thread=False)

# 创建checkpointer
checkpointer = SqliteSaver(conn)

# 第一次使用时创建表
checkpointer.setup()

# 编译时传入
app = graph.compile(checkpointer=checkpointer)

# 使用和MemorySaver完全一样
config = {"configurable": {"thread_id": "conversation-1"}}
result = app.invoke(
    {"messages": [HumanMessage(content="你好")]},
    config=config
)

# 程序重启后，状态仍然在！
# 重新连接数据库，之前的对话历史完好无损
```

### 20.2.3 PostgresSaver（生产级持久化）

```python
"""
PostgresSaver：状态保存在PostgreSQL数据库中
适合：生产环境、多实例部署
"""
from langgraph.checkpoint.postgres import PostgresSaver

DB_URI = "postgresql://admin:password@localhost:5432/docmind"

# 官方推荐写法：用from_conn_string上下文管理器创建（基于psycopg3，而不是裸的psycopg2连接）
with PostgresSaver.from_conn_string(DB_URI) as checkpointer:
    # 第一次使用时初始化数据库表结构
    checkpointer.setup()

    # 编译和使用方式完全相同
    app = graph.compile(checkpointer=checkpointer)
```

> [!NOTE] 安装提示
> PostgresSaver依赖单独的包`langgraph-checkpoint-postgres`（基于psycopg3），使用前需要先`pip install langgraph-checkpoint-postgres`。

### 20.2.4 三种Checkpointer对比

| 特性 | MemorySaver | SqliteSaver | PostgresSaver |
| ---- | ---- | ---- | ---- |
| 持久性 | 内存（重启丢失） | 文件（重启保留） | 数据库（重启保留） |
| 性能 | 最快 | 中等 | 取决于网络 |
| 并发 | 不支持 | 有限 | 完整支持 |
| 部署 | 单机开发 | 单机生产 | 分布式生产 |
| 依赖 | 无 | sqlite3(内置) | langgraph-checkpoint-postgres(psycopg3) |

### 20.3.1 什么是Thread？

Thread（线程）是Checkpointer的核心概念——**每个对话对应一个独立的thread_id，不同thread的状态完全隔离。**

> 类比：Thread就像HTTP Session。每个用户有一个Session ID，服务器通过Session ID区分不同用户的状态。thread_id就是Agent世界的Session ID。

```python
"""
Thread管理：多对话隔离
"""
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)

# 用户A的对话
config_a = {"configurable": {"thread_id": "user-A-session"}}
app.invoke(
    {"messages": [HumanMessage(content="我是用户A")]},
    config=config_a
)

# 用户B的对话（完全独立）
config_b = {"configurable": {"thread_id": "user-B-session"}}
app.invoke(
    {"messages": [HumanMessage(content="我是用户B")]},
    config=config_b
)

# 用户A继续对话——能看到之前的历史
app.invoke(
    {"messages": [HumanMessage(content="我之前说了什么？")]},
    config=config_a
)
# Agent会记得"我是用户A"

# 用户B继续对话——看不到用户A的历史
app.invoke(
    {"messages": [HumanMessage(content="用户A说了什么？")]},
    config=config_b
)
# Agent不知道用户A的存在
```

### 20.3.2 Thread的最佳实践

```python
"""
Thread ID的最佳实践
"""
import uuid

# 方案1：使用UUID（最通用）
thread_id = str(uuid.uuid4())

# 方案2：基于用户ID（方便查找）
thread_id = f"user_{user_id}_conversation_{conversation_id}"

# 方案3：基于场景（方便管理）
thread_id = f"docmind_{user_id}_{date}_{session_number}"

# 不要做的事：
# 1. 不要让所有用户共用一个thread_id（状态会互相污染）
# 2. 不要每次对话都生成新的thread_id（无法延续上下文）
# 3. 不要在thread_id中包含敏感信息（它会出现在数据库键中）
```

## 20.4 时间旅行(Time Travel)

这是Checkpointer最酷的功能——**回到Agent执行历史的任意时刻**。

### 20.4.1 查看历史状态

```python
"""
时间旅行：查看Agent的执行历史
"""
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)
config = {"configurable": {"thread_id": "time-travel-demo"}}

# 进行几轮对话
app.invoke({"messages": [HumanMessage(content="搜索Agent架构")]}, config=config)
app.invoke({"messages": [HumanMessage(content="搜索RAG")]}, config=config)
app.invoke({"messages": [HumanMessage(content="搜索LangGraph")]}, config=config)

# 查看完整历史
history = list(app.get_state_history(config))

print(f"共有 {len(history)} 个历史状态\n")

for i, state_snapshot in enumerate(history):
    print(f"--- 状态 #{i} ---")
    print(f"  配置: {state_snapshot.config}")
    print(f"  消息数: {len(state_snapshot.values.get('messages', []))}")
    print(f"  下一个节点: {state_snapshot.next}")
    print()
```

### 20.4.2 回溯到特定状态

```python
"""
时间旅行：回溯到历史状态
实际用途：撤销错误操作、重新尝试不同的回答路径
"""

# 获取历史
history = list(app.get_state_history(config))

# 假设我们想回到第2个状态（搜索RAG之后）
target_state = history[2]  # 选择目标状态

# 官方推荐写法：把目标检查点的checkpoint_id放进config，
# 输入传None，图会从该检查点"分叉"重放
target_config = {
    "configurable": {
        "thread_id": config["configurable"]["thread_id"],
        "checkpoint_id": target_state.config["configurable"]["checkpoint_id"],
    }
}
result = app.invoke(None, config=target_config)
print(f"从检查点重放后的最后一条消息: {result['messages'][-1].content[:200]}")

# 从回溯点继续对话（重放后线程的最新状态已在回溯点，直接接着聊即可）
result = app.invoke(
    {"messages": [HumanMessage(content="换一个方向，帮我搜索Function Calling")]},
    config=config
)
print(f"从回溯点继续的回答: {result['messages'][-1].content[:200]}")
```

特别提醒一种**看似可行、实则错误**的回退写法——把旧状态的values用`update_state`整体写回去：

```python
# ---- 错误写法 ----
app.update_state(config, target.values)   # 以为是"覆盖回旧状态"

# ---- 实际发生的事 ----
# messages字段挂了add_messages reducer，"更新"的语义是追加：
# 旧消息会被原样再追加一遍，历史不减反增，根本没有回退
```

回退的唯一正确姿势就是本节的checkpoint_id分叉重放。本节出现的API按"Git心智模型"汇总如下：

| API | 作用 | Git类比 |
| ---- | ---- | ---- |
| `app.get_state(config)` | 读取某线程当前最新状态快照（Snapshot） | `git status` |
| `app.get_state_history(config)` | 按新到旧列出全部历史检查点 | `git log` |
| `app.invoke(None, config含checkpoint_id)` | 从指定检查点分叉重放，"回到过去" | `git checkout` 旧版本继续开发 |
| `app.update_state(config, values)` | 手动写入状态（对messages是追加语义） | 提交一条新commit，并不等于回退 |

### 20.4.3 时间旅行的实际用途

```python
# 用途1：撤销错误操作
# Agent不小心删除了错误的文档，回退到删除之前的状态

# 用途2：A/B测试
# 从同一个历史节点分叉两条路径，比较哪种回答更好
# 分叉方式：复制thread_id，在新thread上继续

# 用途3：调试
# Agent在第5步出错了，回退到第4步，修改prompt后重新执行

# 用途4：分支对话
# "如果当时我问了另一个问题会怎样？"
# 从历史节点分叉，探索不同的对话路径
```

## 20.5 多会话管理：ConversationManager

Checkpointer与Thread都就位了，现在可以搭一个真正的多轮对话系统。图的构建与第19章逐行相同——这里不再重复那份清单，只列唯一的差异与新写的会话管理层：

```python
"""
多会话对话系统：ConversationManager
图的构建与第19章完全同构，这里只列差异与新写的管理层
"""
from typing import TypedDict, Annotated

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode
from langgraph.checkpoint.memory import MemorySaver
# 生产环境使用：
# from langgraph.checkpoint.sqlite import SqliteSaver

from langchain_core.messages import HumanMessage, AIMessage


class ChatState(TypedDict):
    messages: Annotated[list, add_messages]


def build_chat_graph():
    """与第19章的build_agent_graph()完全同构，节点函数与工具不再重复定义"""
    graph = StateGraph(ChatState)             # State同第19章的AgentState
    graph.add_node("agent", chat_agent)       # 节点函数同第19章的agent_node
    graph.add_node("tools", ToolNode(tools))  # 工具同第19章
    graph.add_edge(START, "agent")
    graph.add_edge("tools", "agent")
    graph.add_conditional_edges("agent", should_continue)

    # ---- 与第19章唯一的实质差异：编译时接入Checkpointer ----
    checkpointer = MemorySaver()
    # 生产环境替换为 SqliteSaver（见 20.2.2）
    return graph.compile(checkpointer=checkpointer)
```

会话管理层要做的只有三件事：创建会话（生成thread_id）、在指定会话里聊天、从Checkpointer读历史。再加一个回滚方法：

```python
class ConversationManager:
    """对话管理器：在Checkpointer之上管理多个对话会话"""

    def __init__(self, app):
        self.app = app
        self.sessions = {}  # thread_id -> 会话元数据

    def create_session(self, session_name: str) -> str:
        """创建新的对话会话"""
        import uuid
        thread_id = str(uuid.uuid4())[:8]
        self.sessions[thread_id] = {
            "name": session_name,
            "message_count": 0
        }
        print(f"创建会话: {session_name} (thread_id: {thread_id})")
        return thread_id

    def chat(self, thread_id: str, user_input: str) -> str:
        """在指定会话中发送消息"""
        config = {"configurable": {"thread_id": thread_id}}

        result = self.app.invoke(
            {"messages": [HumanMessage(content=user_input)]},
            config=config
        )

        # 更新消息计数
        self.sessions[thread_id]["message_count"] = len(result["messages"])

        # 返回最后一条AI消息
        return result["messages"][-1].content

    def get_history(self, thread_id: str) -> list:
        """从Checkpointer读取对话历史——不需要自己维护任何存储"""
        config = {"configurable": {"thread_id": thread_id}}
        state = self.app.get_state(config)

        history = []
        for msg in state.values.get("messages", []):
            msg_type = msg.__class__.__name__
            if msg_type == "HumanMessage":
                history.append({"role": "user", "content": msg.content})
            elif msg_type == "AIMessage" and msg.content:
                history.append({"role": "assistant", "content": msg.content})

        return history

    def rollback(self, thread_id: str, steps_back: int = 1):
        """回滚到N步之前：从目标检查点分叉重放（写法与 20.4.2 相同）。

        注意不能用 update_state(config, target.values) 实现——
        messages走add_messages reducer，写入旧值只会追加到末尾，
        并不会真的"退回去"。
        """
        config = {"configurable": {"thread_id": thread_id}}
        history = list(self.app.get_state_history(config))

        if len(history) > steps_back:
            target = history[steps_back]
            target_config = {
                "configurable": {
                    "thread_id": thread_id,
                    "checkpoint_id": target.config["configurable"]["checkpoint_id"],
                }
            }
            self.app.invoke(None, config=target_config)
            print(f"已回滚 {steps_back} 步（从检查点分叉重放）")
        else:
            print(f"历史记录不足（只有{len(history)}个状态）")
```

用一小段脚本验证会话隔离与回滚：

```python
if __name__ == "__main__":
    app = build_chat_graph()
    manager = ConversationManager(app)

    # 两个会话彼此隔离
    s1 = manager.create_session("技术学习")
    s2 = manager.create_session("项目讨论")
    print(manager.chat(s1, "什么是AI Agent？"))          # 会话1开始积累历史
    print(manager.chat(s1, "它的Memory部分怎么工作？"))   # 能接住上文
    print(manager.chat(s2, "DocMind项目用了哪些技术？"))  # 会话2从零开始

    # 回滚会话1到2步之前，再继续对话
    manager.rollback(s1, steps_back=2)
    print(manager.chat(s1, "换个话题，帮我算一下 256 * 1024"))
```

## 20.6 实操：为DocMind实现完整的对话持久化

这一节把前五节的一切装进一个可直接运行的类里：SQLite可选、多会话、历史查看、回滚、时间线一应俱全。

```python
"""
DocMind完整持久化实现
支持：关闭重开、回溯历史、多会话管理
"""
import sqlite3
from typing import TypedDict, Annotated

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode
from langgraph.checkpoint.memory import MemorySaver

from langchain_core.messages import HumanMessage, SystemMessage, AIMessage
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# ============================================================
# 持久化配置
# ============================================================

class PersistenceConfig:
    """持久化配置管理"""

    def __init__(self, use_sqlite: bool = False, db_path: str = "docmind.db"):
        self.use_sqlite = use_sqlite
        self.db_path = db_path

    def get_checkpointer(self):
        """根据配置创建对应的Checkpointer"""
        if self.use_sqlite:
            from langgraph.checkpoint.sqlite import SqliteSaver
            conn = sqlite3.connect(self.db_path, check_same_thread=False)
            checkpointer = SqliteSaver(conn)
            checkpointer.setup()
            print(f"使用SQLite持久化: {self.db_path}")
            return checkpointer
        else:
            print("使用内存Checkpointer（重启后数据丢失）")
            return MemorySaver()


# ============================================================
# DocMind持久化Agent
# ============================================================

class PersistentDocMind:
    """
    带持久化的DocMind Agent

    功能：
    - 对话历史自动保存
    - 支持关闭后重新打开
    - 支持回溯到历史状态
    - 支持多会话管理
    """

    def __init__(self, use_sqlite: bool = False):
        # 工具定义
        self.tools = self._create_tools()
        self.tool_map = {t.name: t for t in self.tools}

        # LLM
        self.llm = ChatOpenAI(model="deepseek-chat", temperature=0)
        self.llm_with_tools = self.llm.bind_tools(self.tools)

        # 构建图
        self.app = self._build_graph(use_sqlite)

        # 当前会话
        self.current_thread_id = None

    def _create_tools(self):
        """创建工具集"""

        @tool
        def search_documents(query: str, top_k: int = 3) -> str:
            """搜索文档知识库。

            Args:
                query: 搜索关键词
                top_k: 返回结果数量
            """
            return f"关于'{query}'的搜索结果：找到{top_k}条相关文档..."

        @tool
        def calculate(expression: str) -> str:
            """数学计算。

            Args:
                expression: 数学表达式
            """
            try:
                safe = {"abs": abs, "round": round, "min": min, "max": max}
                result = eval(expression, {"__builtins__": safe}, {})
                return f"{expression} = {result}"
            except Exception as e:
                return f"计算错误: {str(e)}"

        return [search_documents, calculate]

    def _agent_node(self, state):
        """Agent节点"""
        messages = state["messages"]
        if not messages or not isinstance(messages[0], SystemMessage):
            messages = [SystemMessage(content="""你是DocMind智能文档助手。
利用对话上下文提供连贯的回答。优先使用工具获取准确信息。用中文回答。""")] + messages

        response = self.llm_with_tools.invoke(messages)
        return {"messages": [response]}

    def _should_continue(self, state):
        last_msg = state["messages"][-1]
        if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
            return "tools"
        return "__end__"

    def _build_graph(self, use_sqlite: bool):
        """构建LangGraph"""

        class ChatState(TypedDict):
            messages: Annotated[list, add_messages]

        graph = StateGraph(ChatState)
        graph.add_node("agent", self._agent_node)
        graph.add_node("tools", ToolNode(self.tools))

        graph.add_edge(START, "agent")
        graph.add_edge("tools", "agent")
        graph.add_conditional_edges("agent", self._should_continue)

        # 持久化
        config = PersistenceConfig(use_sqlite=use_sqlite)
        checkpointer = config.get_checkpointer()

        return graph.compile(checkpointer=checkpointer)

    def new_session(self, name: str = "default") -> str:
        """创建新会话"""
        import uuid
        self.current_thread_id = f"{name}_{uuid.uuid4().hex[:8]}"
        print(f"新会话: {self.current_thread_id}")
        return self.current_thread_id

    def load_session(self, thread_id: str):
        """加载已有会话"""
        self.current_thread_id = thread_id
        print(f"加载会话: {thread_id}")

        # 显示历史消息数
        config = {"configurable": {"thread_id": thread_id}}
        state = self.app.get_state(config)
        msg_count = len(state.values.get("messages", []))
        print(f"历史消息: {msg_count} 条")

    def chat(self, user_input: str) -> str:
        """发送消息"""
        if not self.current_thread_id:
            self.new_session()

        config = {"configurable": {"thread_id": self.current_thread_id}}

        result = self.app.invoke(
            {"messages": [HumanMessage(content=user_input)]},
            config=config
        )

        return result["messages"][-1].content

    def get_history(self) -> list:
        """获取当前会话历史"""
        config = {"configurable": {"thread_id": self.current_thread_id}}
        state = self.app.get_state(config)

        history = []
        for msg in state.values.get("messages", []):
            msg_type = msg.__class__.__name__
            if msg_type == "HumanMessage":
                history.append(f"[用户] {msg.content}")
            elif msg_type == "AIMessage" and msg.content:
                history.append(f"[DocMind] {msg.content}")
        return history

    def rollback(self, steps: int = 1):
        """回滚到N步之前：与 20.4.2 一致的检查点分叉重放写法。

        注意不能用 update_state(config, target.values) 实现——
        messages走add_messages reducer，写入旧值只会追加，不会回退。
        """
        config = {"configurable": {"thread_id": self.current_thread_id}}
        history = list(self.app.get_state_history(config))

        if len(history) > steps:
            target = history[steps]
            target_config = {
                "configurable": {
                    "thread_id": self.current_thread_id,
                    "checkpoint_id": target.config["configurable"]["checkpoint_id"],
                }
            }
            self.app.invoke(None, config=target_config)
            print(f"已回滚 {steps} 步（从检查点分叉重放）")
        else:
            print(f"历史不足（共{len(history)}个状态）")

    def time_travel_info(self):
        """显示时间旅行信息"""
        config = {"configurable": {"thread_id": self.current_thread_id}}
        history = list(self.app.get_state_history(config))

        print(f"\n时间线（共 {len(history)} 个状态点）:")
        for i, snapshot in enumerate(history):
            msg_count = len(snapshot.values.get("messages", []))
            next_nodes = snapshot.next
            marker = " <-- 当前" if i == 0 else ""
            print(f"  [{i}] 消息数:{msg_count} 下一步:{next_nodes}{marker}")


# ============================================================
# 交互式演示
# ============================================================

def interactive_persistent_demo():
    """交互式持久化演示"""

    # 创建DocMind（使用内存模式；改为True可使用SQLite）
    docmind = PersistentDocMind(use_sqlite=False)
    docmind.new_session("demo")

    print("\nDocMind 持久化版本已启动")
    print("命令：")
    print("  直接输入 -> 发送消息")
    print("  /history -> 查看对话历史")
    print("  /rollback N -> 回滚N步")
    print("  /timeline -> 查看时间线")
    print("  /new -> 新建会话")
    print("  /quit -> 退出\n")

    while True:
        user_input = input("你: ").strip()

        if not user_input:
            continue

        if user_input == "/quit":
            print("再见！")
            break

        elif user_input == "/history":
            history = docmind.get_history()
            print("\n--- 对话历史 ---")
            for line in history:
                print(f"  {line}")
            print()

        elif user_input.startswith("/rollback"):
            try:
                steps = int(user_input.split()[1])
                docmind.rollback(steps)
            except (IndexError, ValueError):
                print("用法: /rollback N (N为回退步数)")

        elif user_input == "/timeline":
            docmind.time_travel_info()

        elif user_input == "/new":
            docmind.new_session("demo")

        else:
            reply = docmind.chat(user_input)
            print(f"DocMind: {reply}\n")


if __name__ == "__main__":
    interactive_persistent_demo()
```

## 20.7 思考题

1. **概念题**：Checkpointer和我们在第14章学的Memory有什么区别和联系？（提示：Memory是Agent的"认知记忆"，Checkpointer是Agent的"状态快照"）
2. **设计题**：如果要实现"对话导出"功能（将对话历史导出为JSON/PDF），应该怎么利用Checkpointer的历史数据？

4. **思考题**：时间旅行功能有什么潜在的安全风险？（提示：如果Agent之前执行了某个副作用操作，回退后副作用能回退吗？）
5. **架构题**：在高并发场景下（1000个用户同时对话），MemorySaver、SqliteSaver、PostgresSaver各有什么瓶颈？你会怎么选择？

## 本章小结

- **Checkpointer在编译时接入**：`graph.compile(checkpointer=...)`，此后每个节点执行完毕都会自动存一份完整State快照，相当于Agent自带的Git仓库。
- **三种内置实现按场景选**：开发调试用MemorySaver，单机持久化用SqliteSaver，分布式生产用PostgresSaver。
- **Thread是对话的隔离单位**：thread_id就是Agent世界的Session ID；命名用UUID或"用户+场景"组合，别共用、别每次换新、别夹带敏感信息。
- **时间旅行三件套**：`get_state_history`看历史、checkpoint_id分叉重放做回溯、复制thread_id做分支对话。
- **回退对话只能走checkpoint_id分叉重放**——`update_state(config, target.values)`在add_messages的追加语义下只会"再追加一遍旧消息"，不是回退。
- **会话管理收口成可复用代码**：ConversationManager与PersistentDocMind把创建会话、查看历史、回滚、时间线统一封装，上层应用不必直接操作快照API。
