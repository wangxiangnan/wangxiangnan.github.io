# 第4章：单元格引用——公式的"定位系统" 📍

*小王学会了公式，非常得意。他把计算"珍珠奶茶金额"的公式 `=B2*C2` 从D2复制到了E2（他想在E列算打折后的金额），结果发现E2显示的是C2*D2的结果——不是他要的！更气人的是，他想用一个固定的折扣率（写在G1单元格）去乘每个商品的价格，但公式一往下拖，G1就变成了G2、G3……全乱套了。小李说："你需要理解单元格引用。"*

## 4.1 相对引用：公式复制时地址会变

默认情况下，Excel中的单元格引用都是**相对引用**。什么意思呢？

当你在D2输入 `=B2*C2`，这个公式的含义其实是：**"取我左边两格的值，乘以我左边一格的值。"**

也就是说，Excel记住的不是"B2和C2"这两个绝对地址，而是**相对位置关系**——"左边两列"和"左边一列"。

所以当你把这个公式从D2**复制**到D3时，公式自动变成了 `=B3*C3`（整体往下移了一行）。复制到D4就变成 `=B4*C4`。这就是为什么用填充柄往下拖时公式会自动调整——非常方便！

但有时候，你不希望地址变化。这就需要用到绝对引用了。

## 4.2 绝对引用（$）：锁住某个单元格

**绝对引用**就是在列标和/或行号前面加一个美元符号 `$`，告诉Excel："这个地址给我锁死，不管公式怎么复制都不要变！"

- `$A$1`：绝对引用——列和行都锁住了，不管怎么复制都是A1
- `A1`：相对引用——列和行都不锁，复制时会跟着变

**奶茶店实战**

假设小王的折扣率写在 `G1` 单元格（值为 `0.9`，即打九折），他想在E列计算每种商品打折后的金额：

错误写法：在E2输入 `=D2*G1`，然后往下拖。结果E3变成了 `=D3*G2`——但G2是空的！折扣率只在G1。

正确写法：在E2输入 `=D2*$G$1`，然后往下拖。 `$G$1` 被锁住了，不管拖到哪里，引用的都是G1。

| 行 | D列公式 | E列公式（正确） | E列结果 |
| ---- | --------- | ----------------- | --------- |
| 2 | =B2*C2 | =D2*$G$1 | 432 |
| 3 | =B3*C3 | =D3*$G$1 | 302.4 |
| 4 | =B4*C4 | =D4*$G$1 | 243 |

> 💡 **提示**：输入引用地址后，按 `F4` 键可以快速切换引用类型：按一次变成 `$A$1`（全锁），再按一次变成 `A$1`（锁行），再按一次变成 `$A1`（锁列），再按一次回到 `A1`（全不锁）。这个快捷键超级实用！

## 4.3 混合引用：锁行不锁列/锁列不锁行

有时候你只想锁住行或列其中一个方向，这就是**混合引用**：

- `$A1`：**锁列不锁行**——列永远是A，但行号会随复制变化
- `A$1`：**锁行不锁列**——行永远是1，但列标会随复制变化

**什么时候用混合引用？**

经典场景：制作九九乘法表。

假设A列是1-9，第1行也是1-9，要在中间区域填乘法公式。

在B2输入：`=$A2*B$1`

- `$A2`：锁列A（被乘数始终来自A列），行不锁（往下拖时A2变成A3、A4……）
- `B$1`：锁行1（乘数始终来自第1行），列不锁（往右拖时B变成C、D……）

然后把B2的公式向右、向下填充到整个9×9区域，就得到完整的乘法表！

## 4.4 跨工作表引用：='Sheet2'!A1

公式不仅可以引用当前工作表的单元格，还能引用**其他工作表**的数据。

**语法**：`=工作表名!单元格地址`

比如，小王的"月度汇总"表需要引用"日销售记录"表中D9单元格（今日总营业额）的值：

```
='日销售记录'!D9
```

如果工作表名字包含空格或特殊字符，必须用单引号包裹。如果名字很简单（比如Sheet2），单引号可以省略：

```
=Sheet2!A1
```

**跨表引用实例**

小王有两个工作表：

- "日销售记录"：记录每天的详细销售数据
- "月度汇总"：汇总每月的关键指标

在"月度汇总"的B2中，他想显示1月1日的营业额：

```
='日销售记录'!D9
```

**操作方法**：不需要手动输入工作表名——在写公式时，直接用鼠标点击底部的工作表标签切换到另一个工作表，然后点击目标单元格，Excel会自动帮你填入正确的工作表引用。

> 💡 **提示**：跨工作表引用让数据的组织更加灵活。你可以把原始数据和汇总分析放在不同的工作表里，通过引用把它们连接起来，就像搭积木一样。

## 4.5 实战：制作销售提成计算表（用绝对引用锁定提成比例）

让我们做一个完整的实战案例，综合运用相对引用、绝对引用和跨工作表引用。

**场景**

小王要给员工发提成。规则如下：

- 基础提成比例：8%（写在"设置"工作表的B1单元格）
- 每个员工有不同的绩效系数（1.0~1.5）
- 提成金额 = 个人销售额 × 基础提成比例 × 绩效系数

**"设置"工作表**

| A | B |
|---|---|
| 基础提成比例 | 8% |

**"员工提成"工作表**

| A | B | C | D |
| --- | --- | --- | --- |
| 员工 | 销售额 | 绩效系数 | 提成金额 |
| 小张 | 15000 | 1.2 | |
| 小李 | 12000 | 1.0 | |
| 小陈 | 18000 | 1.5 | |
| 小周 | 9000 | 1.1 | |

**D2的公式**

```
=B2*设置!$B$1*C2
```

解释：

- `B2`：相对引用，往下拖时变成B3、B4……（每个员工的销售额不同）
- `设置!$B$1`：跨工作表的绝对引用，不管怎么复制都指向"设置"表的B1（提成比例固定）
- `C2`：相对引用，往下拖时变成C3、C4……（每个员工的绩效系数不同）

**计算结果**

| 员工 | 销售额 | 绩效系数 | 提成金额 |
| ------ | -------- | ---------- | ---------- |
| 小张 | 15000 | 1.2 | 1440 |
| 小李 | 12000 | 1.0 | 960 |
| 小陈 | 18000 | 1.5 | 2160 |
| 小周 | 9000 | 1.1 | 792 |

如果小王想调整提成比例，只需要改"设置"工作表的B1（比如改成10%），所有人的提成金额就会自动重新计算。这就是引用的魅力——**改一处，全表更新。**

> 💡 **提示**：像"提成比例"、"税率"、"汇率"这种全局统一的参数，建议放在单独的"设置"工作表中，用绝对引用去调用。这样方便管理，修改时也不用逐个去找。

**📋 本章小结**

| 引用类型 | 写法 | 复制时的行为 | 适用场景 |
| ---------- | ------ | ------------- | ---------- |
| 相对引用 | `A1` | 行列都变 | 普通公式，随位置自动调整 |
| 绝对引用 | `$A$1` | 行列都不变 | 固定参数（如税率、比例） |
| 混合引用（锁行） | `A$1` | 列变行不变 | 乘法表、引用固定行 |
| 混合引用（锁列） | `$A1` | 行变列不变 | 乘法表、引用固定列 |
| 跨表引用 | `='表名'!A1` | 引用其他工作表 | 数据汇总、参数调用 |

| 快捷键 | 功能 |
|--------|------|
| `F4` | 在四种引用类型之间切换 |
