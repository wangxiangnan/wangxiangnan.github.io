# 第16章：叠加与合成——画中画与分屏

从这一章开始，FFmpeg 的魔法进入了"合成"领域。所谓合成，就是把多个视觉元素组合到一个画面中——这恰恰是你在 YouTube、抖音、B站的视频中每天都能看到的技术。主播的小窗口叠加在游戏画面上（画中画）、两个视频并排播放（分屏）、Logo 水印漂浮在画面上、绿幕前的人物被替换到另一个场景……所有这些效果，FFmpeg 都能用命令行实现。

## 16.1 overlay 滤镜深入：位置表达式与时间控制

`overlay` 是 FFmpeg 中**使用频率最高的合成滤镜**，它的作用是将一个视频/图片叠加到另一个视频/图片上面。

### 基本语法

```bash
# 将 logo.png 叠加到视频左上角
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=0:0" output.mp4
```

`overlay=x:y` 中的 `x` 和 `y` 是叠加层（第二个输入）在底层（第一个输入）上的位置坐标。

### 位置表达式

`overlay` 的 x、y 参数支持丰富的变量和表达式：

| 变量 | 说明 |
| ------ | ------ |
| `W`, `H` | 底层视频（主画面）的宽度和高度 |
| `w`, `h` | 叠加层（小画面/Logo）的宽度和高度 |
| `t` | 当前时间（秒） |
| `n` | 当前帧数 |

**常用位置配方**：

```bash
# 左上角
overlay=10:10

# 右上角（留 10px 边距）
overlay=W-w-10:10

# 左下角
overlay=10:H-h-10

# 右下角
overlay=W-w-10:H-h-10

# 正中央
overlay=(W-w)/2:(H-h)/2

# 底部居中（常见字幕条位置）
overlay=(W-w)/2:H-h-20
```

### 时间控制

```bash
# Logo 只在第 3 秒到第 8 秒之间显示
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=10:10:enable='between(t,3,8)'" output.mp4

# Logo 在第 5 秒后淡入显示
# （结合 overlay 的 alpha 控制）
```

## 16.2 画中画（PiP）：大画面 + 小窗口

画中画是最经典的叠加效果，常见于游戏直播、教程视频、新闻播报。

### 基础画中画

```bash
# 将第二个视频缩小后叠加到主视频的右下角
ffmpeg -i main_video.mp4 -i pip_video.mp4 \
  -filter_complex "\
    [1:v]scale=320:-1[pip];\
    [0:v][pip]overlay=W-w-20:H-h-20" \
  output.mp4
```

**分步拆解**：

1. `[1:v]scale=320:-1[pip]` —— 将画中画视频宽度缩放到 320px，高度等比例自动计算，结果存为 `[pip]`
2. `[0:v][pip]overlay=W-w-20:H-h-20` —— 将 `[pip]` 叠加到主视频 `[0:v]` 的右下角（留 20px 边距）

### 带边框的画中画

```bash
ffmpeg -i main_video.mp4 -i pip_video.mp4 \
  -filter_complex "\
    [1:v]scale=320:-1,pad=324:ih+4:2:2:white[pip];\
    [0:v][pip]overlay=W-w-20:H-h-20" \
  output.mp4
```

使用 `pad` 滤镜在小画面周围添加白色边框。

### 圆角画中画

```bash
ffmpeg -i main_video.mp4 -i pip_video.mp4 \
  -filter_complex "\
    [1:v]scale=320:180,\
    geq='lum(X,Y)':cb='128':cr='128',\
    format=yuva420p,\
    geq='lum(X,Y)*if(between(X,0,20)*between(Y,0,20),1-if(hypot(X-20,Y-20)/20),1)*if(between(X,w-20,w)*between(Y,0,20),1-if(hypot(X-(w-20),Y-20)/20),1)*if(between(X,0,20)*between(Y,h-20,h),1-if(hypot(X-20,Y-(h-20))/20),1)*if(between(X,w-20,w)*between(Y,h-20,h),1-if(hypot(X-(w-20),Y-(h-20))/20),1)':alpha='255*if(between(X,0,20)*between(Y,0,20),if(hypot(X-20,Y-20)>20,0,1),1)*if(between(X,w-20,w)*between(Y,0,20),if(hypot(X-(w-20),Y-20)>20,0,1),1)*if(between(X,0,20)*between(Y,h-20,h),if(hypot(X-20,Y-(h-20))>20,0,1),1)*if(between(X,w-20,w)*between(Y,h-20,h),if(hypot(X-(w-20),Y-(h-20))>20,0,1),1)'[pip];\
    [0:v][pip]overlay=W-w-20:H-h-20" \
  output.mp4
```

> 上面的圆角实现比较复杂，实际使用中更常见的做法是在图像编辑软件中做好圆角遮罩再叠加。如果你追求命令行极致，`geq` 滤镜（第17章会详细讲解）可以实现几乎任何像素级操作。

### 移动的画中画

```bash
# 小窗口从左向右移动
ffmpeg -i main_video.mp4 -i pip_video.mp4 \
  -filter_complex "\
    [1:v]scale=320:-1[pip];\
    [0:v][pip]overlay='t*100':H-h-20" \
  output.mp4
```

`overlay='t*100':H-h-20` 让小窗口的 x 坐标随时间增长，实现从左到右移动的效果。

## 16.3 分屏效果：hstack 和 vstack

`hstack`（水平堆叠）和 `vstack`（垂直堆叠）是最简洁的分屏滤镜。

```bash
# 左右分屏
ffmpeg -i left.mp4 -i right.mp4 \
  -filter_complex "hstack=inputs=2" output.mp4

# 上下分屏
ffmpeg -i top.mp4 -i bottom.mp4 \
  -filter_complex "vstack=inputs=2" output.mp4
```

**重要前提**：`hstack` 要求所有输入**高度相同**，`vstack` 要求所有输入**宽度相同**。如果尺寸不一致，需要先缩放：

```bash
# 不同分辨率的左右分屏
ffmpeg -i left_1080p.mp4 -i right_720p.mp4 \
  -filter_complex "\
    [0:v]scale=-2:720[left];\
    [1:v]scale=-2:720[right];\
    [left][right]hstack=inputs=2" \
  output.mp4
```

`-2` 表示自动计算尺寸并对齐到偶数（很多编码器要求宽高为偶数）。

## 16.4 多视频拼接：2×2 网格

结合 `hstack` 和 `vstack` 可以实现多宫格分屏：

```bash
# 2×2 网格：4 个视频
ffmpeg -i v1.mp4 -i v2.mp4 -i v3.mp4 -i v4.mp4 \
  -filter_complex "\
    [0:v]scale=640:360[v1];\
    [1:v]scale=640:360[v2];\
    [2:v]scale=640:360[v3];\
    [3:v]scale=640:360[v4];\
    [v1][v2]hstack[top];\
    [v3][v4]hstack[bottom];\
    [top][bottom]vstack" \
  output.mp4
```

**拆解思路**：

1. 将 4 个视频都缩放到相同尺寸（640x360）
2. `[v1][v2]hstack[top]` —— 上面一行：视频 1 和 2 水平拼接
3. `[v3][v4]hstack[bottom]` —— 下面一行：视频 3 和 4 水平拼接
4. `[top][bottom]vstack` —— 两行垂直拼接，形成 2×2 网格

**3×3 网格**（9 个视频）只需把思路扩展：

```bash
# 3×3 网格
ffmpeg -i v1.mp4 -i v2.mp4 -i v3.mp4 -i v4.mp4 -i v5.mp4 -i v6.mp4 -i v7.mp4 -i v8.mp4 -i v9.mp4 \
  -filter_complex "\
    [0:v]scale=426:240[v1];[1:v]scale=426:240[v2];[2:v]scale=426:240[v3];\
    [3:v]scale=426:240[v4];[4:v]scale=426:240[v5];[5:v]scale=426:240[v6];\
    [6:v]scale=426:240[v7];[7:v]scale=426:240[v8];[8:v]scale=426:240[v9];\
    [v1][v2][v3]hstack=inputs=3[row1];\
    [v4][v5][v6]hstack=inputs=3[row2];\
    [v7][v8][v9]hstack=inputs=3[row3];\
    [row1][row2][row3]vstack=inputs=3" \
  output.mp4
```

## 16.5 透明度控制

默认情况下，叠加的图片/视频如果有 Alpha 通道（透明通道），`overlay` 会自动处理透明度。但有时你需要手动控制：

```bash
# 让叠加的 Logo 半透明（50% 不透明度）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "\
    [1:v]format=rgba,colorchannelmixer=aa=0.5[logo];\
    [0:v][logo]overlay=W-w-10:10" \
  output.mp4
```

- `format=rgba`：确保输入是 RGBA 格式（有 Alpha 通道）
- `colorchannelmixer=aa=0.5`：将 Alpha 通道乘以 0.5（半透明）

**适用场景**：水印不想太显眼、字幕条半透明、创建"幽灵般"的叠加效果。

## 16.6 图片/Logo 叠加动画

通过让 `overlay` 的位置参数随时间变化，可以实现 Logo 的运动动画：

```bash
# Logo 从屏幕左侧飞入，停在右上角
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "\
    [1:v]scale=150:-1[logo];\
    [0:v][logo]overlay='if(lt(t,2),-150+t*(W/2+75),W-w-10)':10" \
  output.mp4
```

```bash
# Logo 持续旋转（需要 geq 滤镜辅助）
# 更简单的做法是使用 zoompan 滤镜实现缩放动画
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "\
    [1:v]scale=200:-1,zoompan=z='1+0.002*in':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=200x150[logo];\
    [0:v][logo]overlay=W-w-20:20" \
  output.mp4
```

## 16.7 blend 滤镜：混合两个视频

`blend` 滤镜可以将两个视频画面按照各种模式进行混合，类似于 Photoshop 中的图层混合模式。

```bash
# 50% 混合两个视频（半透明叠加）
ffmpeg -i video1.mp4 -i video2.mp4 \
  -filter_complex "blend=all_mode=normal:all_opacity=0.5" output.mp4

# 使用 "screen" 混合模式（类似双重曝光）
ffmpeg -i video1.mp4 -i video2.mp4 \
  -filter_complex "blend=all_mode=screen" output.mp4

# 使用 "multiply" 混合模式
ffmpeg -i video1.mp4 -i video2.mp4 \
  -filter_complex "blend=all_mode=multiply" output.mp4
```

**常用混合模式**：

| 模式 | 效果 |
| ------ | ------ |
| `normal` | 正常叠加（配合 opacity 控制透明度） |
| `screen` | 滤色（去黑留白，适合光效叠加） |
| `multiply` | 正片叠底（去白留黑） |
| `addition` | 相加（亮度叠加） |
| `difference` | 差值（两画面差异可视化） |
| `overlay` | 叠加（保留底层暗部，增强对比） |
| `dodge` | 颜色减淡 |
| `burn` | 颜色加深 |

**适用场景**：双重曝光艺术效果、光效/粒子叠加、创意转场。

## 16.8 圆形画中画

使用 `geq` 滤镜配合 `overlay` 可以实现圆形的画中画窗口：

```bash
ffmpeg -i main_video.mp4 -i pip_video.mp4 \
  -filter_complex "\
    [1:v]scale=300:300,crop=300:300,\
    geq='lum(X,Y)':alpha='if(lte(hypot(X-150,Y-150),150),255,0)'[pip];\
    [0:v][pip]overlay=W-w-30:H-h-30" \
  output.mp4
```

**原理**：

1. 将画中画视频缩放并裁切为 300×300 正方形
2. `geq` 滤镜设置 Alpha 通道：距离中心 (150,150) 小于 150 像素的区域不透明，其余透明——形成一个圆形遮罩
3. 叠加到主视频上

## 16.9 绿幕/蓝幕抠图：chromakey 和 colorkey

**这是高频使用滤镜，需要重点掌握。**

### chromakey：基于色度的抠图

```bash
# 绿幕抠图：去除绿色背景
ffmpeg -i greenscreen.mp4 -i background.mp4 \
  -filter_complex "\
    [0:v]chromakey=0x00FF00:0.3:0.2[fg];\
    [1:v][fg]overlay" \
  output.mp4
```

**参数详解**：

| 参数 | 默认值 | 范围 | 说明 |
| ------ | -------- | ------ | ------ |
| 第 1 个 | — | 颜色值 | 目标抠除的颜色（如 `0x00FF00` 表示纯绿、`green` 也支持） |
| `similarity` | 0.01 | 0.01-1.0 | 颜色相似度阈值。越大抠除范围越广（相近颜色也会被抠除），但太大会抠到前景。推荐从 0.2-0.4 开始调试 |
| `blend` | 0.0 | 0.0-1.0 | 边缘混合程度。0 = 硬边缘，1 = 柔和边缘。推荐 0.1-0.3，可以消除绿边 |

```bash
# 更精细的绿幕抠图
ffmpeg -i greenscreen.mp4 -i background.mp4 \
  -filter_complex "\
    [0:v]chromakey=0x00B140:similarity=0.35:blend=0.2[fg];\
    [1:v]scale=1920:1080[bg];\
    [bg][fg]overlay" \
  output.mp4
```

> **重要提示**：`chromakey` 需要输入格式为 YUVA 或 RGBA（带 Alpha 通道）。如果输出格式不支持 Alpha，FFmpeg 会自动处理，但最好显式指定输出格式。

### colorkey：基于 RGB 的抠图

`colorkey` 与 `chromakey` 类似，但在 RGB 色彩空间工作，对某些颜色可能效果更好：

```bash
ffmpeg -i greenscreen.mp4 -i background.mp4 \
  -filter_complex "\
    [0:v]colorkey=0x00FF00:0.3:0.1[fg];\
    [1:v][fg]overlay" \
  output.mp4
```

**选择建议**：

- 绿幕素材 → 先试 `chromakey`（更常用，兼容性更好）
- 如果边缘有绿边残留 → 调整 `similarity` 和 `blend`
- 蓝幕素材 → 将颜色参数改为蓝色值，如 `0x0000FF`
- `chromakey` 效果不理想时 → 试试 `colorkey`

## 16.10 实战：替换视频背景

让我们把绿幕抠图做成一个完整的"替换背景"工作流：

```bash
# 完整工作流：绿幕抠图 + 替换背景 + 缩放 + 编码优化
ffmpeg -i person_greenscreen.mp4 -i new_background.jpg \
  -filter_complex "\
    [0:v]chromakey=0x00B140:0.35:0.15[fg];\
    [1:v]scale=1920:1080,setsar=1[bg];\
    [bg][fg]overlay=format=auto,\
    format=yuv420p" \
  -c:v libx264 -preset medium -crf 20 \
  output.mp4
```

**步骤拆解**：

1. `chromakey` 抠除绿幕，生成带 Alpha 通道的前景 `[fg]`
2. 背景图片缩放到 1920×1080，`setsar=1` 确保像素长宽比为 1:1
3. `overlay` 将前景叠加到背景上
4. `format=yuv420p` 确保输出格式兼容各种播放器
5. `-c:v libx264 -preset medium -crf 20` 使用 x264 编码器，中等速度和质量

### 处理边缘溢色（Spill Suppression）

绿幕抠图常见问题是人物边缘有绿色残留。可以使用 `colorbalance` 或 `curves` 来消除：

```bash
ffmpeg -i person_greenscreen.mp4 -i new_background.jpg \
  -filter_complex "\
    [0:v]chromakey=0x00B140:0.4:0.2,\
    colorbalance=gs=-0.15:gm=-0.1[fg];\
    [1:v]scale=1920:1080[bg];\
    [bg][fg]overlay=format=auto" \
  output.mp4
```

`colorbalance=gs=-0.15:gm=-0.1` 减少阴影和中间调中的绿色分量，有效消除绿边。

## 本章小结

本章我们掌握了 FFmpeg 的叠加与合成技术：

- **overlay**：最核心的合成滤镜，支持位置表达式和时间控制
- **画中画**：缩放 + overlay 的经典组合
- **hstack/vstack**：简洁的分屏方案，可组合实现多宫格
- **透明度**：format=rgba + colorchannelmixer 控制不透明度
- **blend**：类 Photoshop 的图层混合模式
- **chromakey/colorkey**：绿幕/蓝幕抠图，替换视频背景
- **圆形画中画**：geq 滤镜实现圆形遮罩
