## 7.2 Python 环境配置：虚拟环境是你的"安全网"

### 7.2.1 为什么必须用虚拟环境？

想象你在同时开发两个项目：项目 A 需要 LangChain 0.2.x，项目 B 需要 LangChain 0.3.x。如果两个项目共享同一个 Python 环境，你就会陷入"依赖地狱"。

虚拟环境就像给每个项目分配了一间独立的"工作间"，里面的工具互不干扰。

```python
# 错误做法：在全局 Python 环境中直接安装
# pip install langchain  # 这会污染你的全局环境

# 正确做法：先创建虚拟环境
# Windows:
# python -m venv docmind-env
# docmind-env\Scripts\activate

# macOS/Linux:
# python -m venv docmind-env
# source docmind-env/bin/activate
```

### 7.2.2 venv vs conda：如何选择？

| 特性 | venv | conda |
| ------ | ------ | ------- |
| 安装方式 | Python 内置 | 需要安装 Anaconda/Miniconda |
| 包管理 | pip only | pip + conda packages |
| 隔离级别 | Python 包 | Python 包 + 系统级依赖 |
| 启动速度 | 快 | 稍慢 |
| 适合场景 | 纯 Python 项目 | 需要 C 库（如 CUDA）的项目 |
| 磁盘占用 | 小（~30MB） | 大（~200MB+） |

**推荐策略**：如果你的项目只需要 Python 包（LangChain 的大部分情况），用 `venv` 就够了。如果你需要 GPU 加速（比如本地跑 Embedding 模型），用 `conda` 更方便。

### 7.2.3 创建 Python 3.11+ 环境

```python

import sys
print(f"Python 版本: {sys.version}")
# 确保是 3.11+
```

创建虚拟环境的完整流程：

```bash

# 3. 激活虚拟环境
```

## 7.3 LangChain 生态全景：理解包的关系

第一次接触 LangChain 的开发者通常会被它的包名搞晕。把 LangChain 想象成一个**乐高积木系统**：

```
langchain-core     → 基础底板（定义接口和抽象）
langchain          → 主积木套装（核心功能 + 链和Agent）
langchain-openai   → OpenAI 专用扩展包
langchain-anthropic → Anthropic 专用扩展包
langchain-community → 社区贡献的集成
langchain-chroma   → Chroma 向量数据库集成
langgraph          → 图结构编排框架（Part 3 重点）
```

### 7.3.1 核心包详解

**langchain-core**：LangChain 的地基。定义了所有核心接口——什么是"模型"、什么是"工具"、什么是"检索器"。不依赖任何第三方模型提供商。你可以把它理解为"接口定义层"，就像 TypeScript 的 `.d.ts` 文件。

**langchain**：你日常使用最多的包。在 `langchain-core` 的基础上，提供了链（Chains）、Agent 框架、Memory 等高层抽象。"应用框架层"。

**langchain-openai**：从 langchain 0.2 开始，OpenAI 的集成被拆分为独立包。这意味着如果你不用 OpenAI，就不需要安装它——减少了不必要的依赖。

**langchain-community**：社区贡献的各种集成。质量参差不齐，但覆盖面很广。

**langchain-chroma**：Chroma 向量数据库的集成包。

### 7.3.2 包关系图

```
                    ┌─────────────────┐
                    │  langchain-core │  ← 基础接口层
                    │ (Runnable, LLM  │
                    │  interfaces)    │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
    ┌─────────▼──────┐ ┌────▼─────┐ ┌──────▼────────┐
    │   langchain    │ │ langchain│ │  langchain    │
    │ (chains,agent) │ │ -openai  │ │  -community   │
    └─────────┬──────┘ └──────────┘ └───────────────┘
              │
    ┌─────────▼──────┐
    │  langgraph     │  ← 图编排（Part 3）
    └────────────────┘
```

## 7.4 安装和版本管理策略

### 7.4.1 LangChain 的版本策略

LangChain 有一个"特点"（委婉说法）：**更新极其频繁**。有时候一周能发好几个版本，而且 minor 版本之间可能有 breaking changes。

```python
# 错误做法：不锁定版本
# requirements.txt:
# langchain
# langchain-openai
# 下次安装可能就不是你开发时的版本了

# 正确做法：锁定具体版本
# requirements.txt:
# langchain==0.3.7
# langchain-core==0.3.15
# langchain-openai==0.2.8
# langchain-community==0.3.7
# langchain-chroma==0.1.4
```

### 7.4.2 使用 pip freeze 锁定版本

```bash
# 开发完成后，冻结所有依赖版本
pip freeze > requirements.txt

# 在新环境中精确复现
pip install -r requirements.txt
```

> ⚠️ **版本陷阱**：LangChain 的各个子包版本不一定同步更新。如果你手动指定了不兼容的版本组合，安装时不会报错，但运行时可能出现奇怪的错误。建议先用 `pip install langchain` 让它自动解析依赖，然后再用 `pip freeze` 锁定。

## 7.6 API Keys 管理：.env 文件与安全实践

### 7.6.1 为什么 API Key 管理如此重要？

这不是在危言耸听——**GitHub 上有数以万计的 API Key 因为被意外提交而泄露**。一旦你的 OpenAI API Key 泄露，机器人会在几分钟内扫描到它，然后疯狂调用，让你的账单爆炸。

把 API Key 写在代码里，就像把银行卡密码贴在额头上——在你自己家里可能没事，但只要走出门（push 到 GitHub），就会被看到。

### 7.6.2 使用 python-dotenv

```python
# 首先安装: pip install python-dotenv

# .env 文件（放在项目根目录，不要提交到 Git！）
# .env 的内容：
# OPENAI_API_KEY=sk-your-key-here
# ANTHROPIC_API_KEY=your-anthropic-key
# CHROMA_PERSIST_DIR=./data/vectorstore
```

```python
# config/settings.py
import os
from dotenv import load_dotenv

# 加载 .env 文件中的环境变量
load_dotenv()

class Config:
    """DocMind 全局配置"""
    
    # API Keys
    OPENAI_API_KEY: str = os.getenv("OPENAI_API_KEY", "")
    ANTHROPIC_API_KEY: str = os.getenv("ANTHROPIC_API_KEY", "")
    
    # 模型配置
    DEFAULT_MODEL: str = os.getenv("DEFAULT_MODEL", "gpt-4o-mini")
    DEFAULT_TEMPERATURE: float = float(os.getenv("DEFAULT_TEMPERATURE", "0.7"))
    MAX_TOKENS: int = int(os.getenv("MAX_TOKENS", "2048"))
    
    # 路径配置
    CHROMA_PERSIST_DIR: str = os.getenv("CHROMA_PERSIST_DIR", "./data/vectorstore")
    RAW_DATA_DIR: str = os.getenv("RAW_DATA_DIR", "./data/raw")
    
    # RAG 配置
    CHUNK_SIZE: int = int(os.getenv("CHUNK_SIZE", "1000"))
    CHUNK_OVERLAP: int = int(os.getenv("CHUNK_OVERLAP", "200"))
    
    @classmethod
    def validate(cls):
        """验证必要的配置是否存在"""
        if not cls.OPENAI_API_KEY:
            raise ValueError("缺少 OPENAI_API_KEY! 请在 .env 文件中设置。")
        print("配置验证通过")

if __name__ == "__main__":
    Config.validate()
    print(f"当前模型: {Config.DEFAULT_MODEL}")
    print(f"Chunk Size: {Config.CHUNK_SIZE}")
```

## 7.7 第一个 LangChain 程序

终于到了动手的时刻！让我们写一个最简单的 LangChain 程序。这就像你学编程时的第一个 "Hello, World!"，只不过这次是你在向 AI 打招呼。

### 7.7.1 Hello, DocMind

```python
# main.py — DocMind 的第一个程序
"""DocMind - 智能文档问答助手 - 第一个 LangChain 程序"""

import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

# 第一步：加载环境变量
load_dotenv()

def main():
    """DocMind 的第一声问候"""
    
    # 第二步：创建 ChatModel 实例
    llm = ChatOpenAI(
        model="gpt-4o-mini",     # 使用性价比高的模型
        temperature=0.7,         # 稍微有点创造性
        max_tokens=500,          # 限制回复长度
    )
    
    # 第三步：构建消息
    messages = [
        SystemMessage(
            content="你是 DocMind，一个智能文档问答助手。"
                    "你的使命是帮助开发者管理和理解技术文档。"
                    "请用友好、专业的方式回答问题。"
        ),
        HumanMessage(content="你好！请用一句话介绍你自己。"),
    ]
    
    # 第四步：调用模型
    response = llm.invoke(messages)
    
    # 第五步：查看结果
    print(f"DocMind 说: {response.content}")
    print(f"\n--- 调试信息 ---")
    print(f"Token 使用: {response.response_metadata.get('token_usage', 'N/A')}")
    print(f"模型: {response.response_metadata.get('model_name', 'N/A')}")

if __name__ == "__main__":
    main()
```

### 7.7.2 代码解析：发生了什么？

**第一步：加载环境变量** — `load_dotenv()` 把 `.env` 文件中的变量加载到操作系统的环境变量中。`ChatOpenAI` 会自动查找 `OPENAI_API_KEY`。

**第二步：创建 ChatModel** — `ChatOpenAI` 是 LangChain 对 OpenAI Chat API 的封装。它实现了 LangChain 的 `Runnable` 接口，可以和其他组件无缝组合。

**第三步：构建消息** — LangChain 使用消息对象而不是纯字符串。它需要区分不同角色的消息（系统、用户、AI），并且每条消息可以携带额外的元数据。

**第四步：调用模型** — `.invoke()` 是 LangChain 的标准调用方式。所有的 LangChain 组件都实现了这个方法。

### 7.7.3 添加流式输出

用户不喜欢等待。流式输出就像"打字机效果"——让 AI 的回复一个字一个字地出现：

```python
# streaming_demo.py
"""流式输出示例"""

from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

load_dotenv()

def stream_response():
    """演示流式输出"""
    llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7, streaming=True)
    
    messages = [
        SystemMessage(content="你是 DocMind，一个智能文档问答助手。"),
        HumanMessage(content="请简要介绍什么是 RAG（检索增强生成），用3-4句话。"),
    ]
    
    print("DocMind: ", end="", flush=True)
    
    # 使用 .stream() 替代 .invoke()
    for chunk in llm.stream(messages):
        # chunk.content 是本次新增的文本片段
        print(chunk.content, end="", flush=True)
    
    print()

if __name__ == "__main__":
    stream_response()
```

> ⚠️ **流式输出的限制**：流式输出时，你无法在接收完成前获取完整的 `response_metadata`（如 token 使用量）。

## 7.8 常见安装问题和解决方案

### 7.8.1 问题速查表

| 问题 | 原因 | 解决方案 |
| ------ | ------ | --------- |
| `ModuleNotFoundError: No module named 'langchain'` | 未安装或虚拟环境未激活 | 确认虚拟环境已激活，重新安装 |
| `ImportError: cannot import name 'ChatOpenAI'` | 缺少 langchain-openai 包 | `pip install langchain-openai` |
| `openai.APIConnectionError` | 网络问题或 API Key 无效 | 检查网络和 `.env` 文件 |
| `pydantic.ValidationError` | Pydantic 版本不兼容 | `pip install pydantic>=2.0` |
| `chromadb` 安装失败 | 缺少编译工具 | Windows: 安装 Build Tools |

### 7.8.2 诊断脚本

```python
# diagnose.py — 环境诊断脚本
"""运行这个脚本来检查你的环境是否正确配置"""

import sys
import importlib
import os

def check_python_version():
    version = sys.version_info
    print(f"Python 版本: {version.major}.{version.minor}.{version.micro}")
    if version.major == 3 and version.minor >= 11:
        print("  满足要求 (3.11+)")
    else:
        print("  建议升级到 Python 3.11+")

def check_package(name):
    try:
        module = importlib.import_module(name)
        version = getattr(module, "__version__", "未知")
        print(f"  OK: {name} == {version}")
        return True
    except ImportError:
        print(f"  MISSING: {name}")
        return False

def check_env_var(name):
    value = os.getenv(name)
    if value:
        masked = value[:8] + "..." if len(value) > 8 else "***"
        print(f"  OK: {name} = {masked}")
        return True
    else:
        print(f"  MISSING: {name}")
        return False

def main():
    from dotenv import load_dotenv
    load_dotenv()
```

## 7.9 实战演练：让 DocMind 跑起来

```python
# main.py — DocMind v0.1 基础交互版
"""DocMind v0.1 - 基础交互版"""

from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

load_dotenv()

DOCMIND_SYSTEM_PROMPT = """你是 DocMind，一个智能文档问答助手。

你的核心能力：
1. 帮助开发者理解技术文档
2. 解答编程和架构相关的问题
3. 用清晰、简洁的中文回答问题

你的风格：
- 专业但不死板
- 善于用类比解释复杂概念
- 如果不确定答案，会诚实说明

当前版本：v0.1（基础交互版）
"""

class DocMindApp:
    """DocMind 应用主类"""
    
    def __init__(self):
        self.llm = ChatOpenAI(
            model="gpt-4o-mini",
            temperature=0.7,
            streaming=True,
        )
        self.history = [SystemMessage(content=DOCMIND_SYSTEM_PROMPT)]
        print("DocMind v0.1 已启动！输入 'quit' 退出。\n")
    
    def chat(self, user_input: str) -> str:
        """处理一次对话"""
        self.history.append(HumanMessage(content=user_input))
        
        print("DocMind: ", end="", flush=True)
        full_response = ""
        
        for chunk in self.llm.stream(self.history):
            content = chunk.content
            print(content, end="", flush=True)
            full_response += content
        
        print()
        self.history.append(AIMessage(content=full_response))
        return full_response
    
    def run(self):
        """运行交互式循环"""
        while True:
            try:
                user_input = input("\n你: ").strip()
                if not user_input:
                    continue
                if user_input.lower() in ("quit", "exit", "q"):
                    print("\nDocMind 已退出。再见！")
                    break
                self.chat(user_input)
            except KeyboardInterrupt:
                print("\n\nDocMind 已退出。")
                break
            except Exception as e:
                print(f"\n出错了: {e}")

if __name__ == "__main__":
    app = DocMindApp()
    app.run()
```
