# 第10章：数据处理进阶——脏数据急救指南 🏥

小王从奶茶店的收银系统导出了一份客户数据，打开一看差点哭出来：名字前面有空格，手机号格式乱七八糟，有的写着"138-1234-5678"有的写着"13812345678"，地址和邮编混在一个单元格里，甚至还有的单元格内容里带着奇怪的乱码符号……

"这数据怎么分析啊！"小王哀嚎。

别担心，这一章我们就来学习如何对付这些"脏数据"。在数据处理的世界里，有一句话很流行：**80%的时间花在清洗数据上，只有20%的时间花在分析上。** 所以，清洗数据不是什么丢人的事，而是每个数据工作者的日常。

## 10.1 文本处理函数进阶：TRIM、CLEAN、SUBSTITUTE、TEXT

先来四个清洗数据的"基本功"：

**TRIM——去掉多余空格**

`=TRIM(A1)` 会删除文本中多余的空格，只保留单词之间必要的单个空格。

比如：`=TRIM("  珍珠  奶茶  ")` 结果是 `"珍珠 奶茶"`（前面的空格和后面的空格都删了，中间多个空格缩成一个）。

> 💡 **提示**：TRIM只能删普通的空格（ASCII 32）。如果数据里有"不换行空格"（从网页复制来的常见垃圾），需要用 `=TRIM(SUBSTITUTE(A1,CHAR(160)," "))` 来对付。

**CLEAN——清除不可见字符**

`=CLEAN(A1)` 删除文本中所有不可打印的控制字符（ASCII 0-31），比如换行符、制表符等。从某些老旧系统导出的数据里经常藏着这些东西。

**SUBSTITUTE——替换指定文本**

`=SUBSTITUTE(原文, 旧文本, 新文本)` 把文本中的某个内容替换成另一个。

比如：`=SUBSTITUTE("138-1234-5678", "-", "")` 结果是 `"13812345678"`，把手机号里的横杠去掉了。

再比如：`=SUBSTITUTE("大学城店-珍珠奶茶", "-", " | ")` 结果是 `"大学城店 | 珍珠奶茶"`。

> 💡 **提示**：SUBSTITUTE和REPLACE的区别——SUBSTITUTE按"内容"替换（找到什么替换什么），REPLACE按"位置"替换（从第几个字符开始替换）。大多数清洗场景用SUBSTITUTE更方便。

**TEXT——格式化数字为文本**

`=TEXT(数值, "格式代码")` 把数字转成指定格式的文本。

常用格式代码：

- `=TEXT(12345.6, "0.00")` → `"12345.60"`（保留两位小数）
- `=TEXT(45321, "yyyy-mm-dd")` → 把日期序列号转成日期文本
- `=TEXT(0.35, "0%")` → `"35%"`（转成百分比文本）
- `=TEXT(1234567, "#,##0")` → `"1,234,567"`（加千位分隔符）

## 10.2 查找提取：FIND、SEARCH、LEFT/RIGHT/MID组合技巧

脏数据经常把好几项信息挤在一个单元格里。比如客户地址写成了"广东省深圳市南山区科技园路88号 518000"，你需要把邮编单独提取出来。

**FIND和SEARCH——定位字符位置**

两个函数都是找某个文本在字符串中的位置，区别是：

- `FIND`：区分大小写
- `SEARCH`：不区分大小写，且支持通配符

比如：`=FIND("市", "广东省深圳市南山区")` 结果是 `6`，"市"在第6个字符的位置。

**LEFT、RIGHT、MID——按位置截取文本**

- `=LEFT(A1, 3)` ：从左边取3个字符
- `=RIGHT(A1, 6)` ：从右边取6个字符
- `=MID(A1, 4, 3)` ：从第4个字符开始取3个

**组合技巧——提取邮编**

假设A1内容是"广东省深圳市南山区科技园路88号 518000"，邮编在最后6位：

- `=RIGHT(A1, 6)` → `"518000"` ✅

**组合技巧——提取城市名**

假设A1内容是"广东省深圳市南山区科技园路88号"，要提取"深圳市"：

1. 先用FIND定位"市"的位置：`=FIND("市", A1)` → 6
2. 再用LEFT截取到"市"：`=LEFT(A1, FIND("市", A1))` → `"广东省深圳市"`

嗯，不太对，我们只想要"深圳市"。改进一下：

- `=MID(A1, FIND("省", A1)+1, FIND("市", A1)-FIND("省", A1))` → `"深圳市"` ✅

> 💡 **提示**：这类组合公式看起来复杂，但只要拆成步骤就好理解了：先定位（FIND），再截取（LEFT/RIGHT/MID）。建议先用FIND算出位置，确认无误后再嵌套到截取函数里。

## 10.3 分列功能：按分隔符拆分、按固定宽度拆分

当你需要把一个单元格的内容拆成多个单元格时，"分列"功能是最直接的工具。

**位置**：菜单栏 **数据** → **分列**

**方式一：按分隔符拆分**

适用于数据之间有明确分隔符的情况，比如用逗号、空格、横杠隔开的文本。

例如"珍珠奶茶-中杯-少糖-加珍珠"，用横杠拆分后变成4列：

| 珍珠奶茶 | 中杯 | 少糖 | 加珍珠 |
|----------|------|------|--------|

操作步骤：

1. 选中要拆分的列
2. 数据 → 分列 → 选择"分隔符号"
3. 勾选"其他"，填入 `-`
4. 预览确认 → 完成

**方式二：按固定宽度拆分**

适用于数据格式固定但没有分隔符的情况，比如"20240103"拆成"2024""01""03"。

操作步骤：

1. 选中列 → 数据 → 分列 → 选择"固定宽度"
2. 在预览窗口中点击需要断开的位置，会出现分隔线
3. 调整位置 → 完成

> 💡 **提示**：分列操作会覆盖右边的单元格！所以在操作前确保右边有足够的空列，否则原有数据会被覆盖。

## 10.4 快速填充（Flash Fill）：Excel的智能识别

这是Excel 2013版本开始引入的一个"魔法"功能——你只需要给它看一两个例子，它就能自动识别规律并填充剩下的数据。

**使用场景举例**：

假设A列是混乱的手机号格式，你想统一成"138 1234 5678"的格式：

1. 在B1手动输入格式化后的结果：`138 1234 5678`
2. 在B2再手动输入一个：`139 8765 4321`
3. 在B3开始输入时，Excel会自动识别规律，用浅灰色文字预览填充结果
4. 按 `Enter` 确认，整列就自动填好了！

或者直接操作：输入第一个例子后，按 `Ctrl + E` 触发快速填充。

**快速填充能做的事**：

- 从姓名+手机号中提取手机号：`张三 13812345678` → `13812345678`
- 从邮箱中提取用户名：`wang@milktrea.com` → `wang`
- 合并拆分的信息：把姓和名合并，把省市区拼成完整地址
- 提取括号里的内容：`珍珠奶茶（大杯）` → `大杯`

> 💡 **提示**：快速填充虽然智能，但有时会"猜错"。所以填充后一定要抽查几行结果是否正确。如果结果不对，多给一两个示例再触发一次，Excel会重新学习规律。

## 10.5 合并单元格的处理技巧

合并单元格是Excel中最"害人"的功能之一。它看起来让表格更好看，但会给后续的数据分析带来无数麻烦——排序会乱、筛选不准、公式报错……

**拆分合并单元格并填充数据**：

如果一个区域里有很多合并单元格，拆分后只有左上角的单元格保留数据，其余都是空白。怎么让每个单元格都填上正确的值？

操作步骤：

1. 选中包含合并单元格的区域
2. 取消合并（开始 → 合并后居中 → 取消合并单元格）
3. 保持选中状态，按 `Ctrl + G`（定位）→ 定位条件 → 选"空值"
4. 在编辑栏输入 `=` 然后按上箭头键（指向上面有数据的单元格）
5. 按 `Ctrl + Enter`（批量填充所有空单元格）

这样所有空白单元格都会被填上和它上方单元格相同的值。

> 💡 **提示**：在制作数据源表时，尽量避免使用合并单元格。合并单元格更适合用在"展示型"报表中，而不是"数据源"表中。

## 10.6 数据导入：从CSV和文本文件导入数据

很多时候数据不在Excel里，而是以CSV（逗号分隔值）或TXT文件的形式存在。直接双击打开CSV文件，经常会遇到中文乱码的问题。正确的打开方式是这样的：

**方法一：通过"数据"选项卡导入**

1. 菜单栏 **数据** → **从文本/CSV**
2. 选择文件
3. 在预览窗口中确认编码（中文数据通常选 `UTF-8` 或 `GB2312/GBK`）
4. 确认分隔符是否正确
5. 点击"加载"

**方法二：用Power Query导入（推荐）**
这种方式更灵活，后面会简单提到。

> 💡 **提示**：CSV文件本身不支持格式（没有字体颜色、没有合并单元格），它只是纯文本。所以导入后你可能需要重新设置格式。另外，如果CSV是从其他系统导出的，编码可能不是UTF-8，遇到乱码时试试切换编码选项。

## 10.7 Power Query初体验：自动化数据清洗

Power Query是Excel内置的一个"数据清洗神器"，从Excel 2016开始正式集成。它最大的优点是：**你做的每一步清洗操作都会被记录下来，下次数据更新时一键重放就行**。

打个比方：如果说手动清洗数据是"用手洗碗"，那Power Query就是"买了一台洗碗机"——第一次设置好程序，以后把脏碗放进去，按一下按钮就干净了。

**打开Power Query**：

- 菜单栏 **数据** → **获取数据** → 选择数据来源
- 或者 **数据** → **从表格/区域**（把当前选中的数据送入Power Query编辑器）

**Power Query能做的常见操作**：

- 删除多余的空行空列
- 拆分列、合并列
- 更改数据类型
- 替换值
- 去除重复项
- 合并多个表格（类似VLOOKUP的功能）

所有这些操作都在一个友好的图形界面中完成，不需要写公式。每一步操作都会记录在右侧的"应用步骤"面板中，你可以随时回退、修改、删除某一步。

> 💡 **提示**：Power Query是一个非常强大的工具，单独写一本书都不为过。本章只是让你知道它的存在和基本用途。当你经常需要重复清洗类似格式的数据时，深入学习Power Query会极大提升你的效率。

## 10.8 实战：清洗奶茶店导出的混乱客户数据

小王从收银系统导出了客户信息表，但数据一团糟。让我们来帮他清洗：

**原始数据问题清单**：

| 问题 | 示例 | 解决方案 |
| ------ | ------ | ---------- |
| 姓名前后有空格 | `"  张三  "` | `=TRIM(A2)` |
| 手机号有横杠 | `"138-1234-5678"` | `=SUBSTITUTE(B2,"-","")` |
| 地址和邮编混在一起 | `"深圳市南山区xx路 518000"` | 用RIGHT提取邮编，用LEFT+LEN组合提取地址 |
| 性别字段是数字 | `"1"` 代表男，`"2"` 代表女 | `=IF(D2="1","男","女")` |
| 会员卡号有不可见字符 | 卡号后面拖着乱码 | `=CLEAN(E2)` |
| 注册日期格式混乱 | `"20240103"` `"2024.1.3"` 混用 | 用分列或SUBSTITUTE统一格式，再用DATEVALUE转日期 |
| 有重复记录 | 同一客户出现多次 | 数据 → 删除重复项 |

**清洗步骤建议**（按顺序进行）：

1. **先备份原始数据**——把原始数据复制到一个新工作表，命名为"原始数据-勿动"
2. **清除不可见字符**——对每列用CLEAN处理
3. **去除多余空格**——对文本列用TRIM处理
4. **统一格式**——手机号去横杠、日期统一格式
5. **拆分混合字段**——地址和邮编拆分
6. **转换编码**——数字性别转文字
7. **删除重复项**——最后一步去重

> 💡 **提示**：数据清洗最重要的原则是——永远保留原始数据，所有操作在副本上进行。你永远不知道什么时候需要回去对照原始数据。

## 练习题

1. **基础题**：有一列数据格式为"姓名-手机号-城市"（如"张三-13812345678-深圳"），用分列功能拆成三列，然后再用SUBSTITUTE和`&`合并成"张三 | 138 1234 5678 | 深圳市"的格式。
2. **进阶题**：给定一列混乱的地址数据（如"广东省深圳市南山区科技园路88号 518000"），用公式分别提取省份、城市、详细地址和邮编。
3. **挑战题**：找一份你自己的真实数据（比如导出的通讯录、网购记录），尝试用本章学到的至少5种清洗方法处理它。
