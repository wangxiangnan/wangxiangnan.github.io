# 第2章：安装与环境配置

> 理论讲完了，让我们卷起袖子动手装起来。这一章的目标是：在 5 分钟内让 FFmpeg 在你的电脑上跑起来，并验证它能正常工作。

## 2.1 Windows 安装

Windows 用户有三种主流安装方式，按推荐顺序排列：

**方式一：官网下载静态编译版（推荐新手）**

这是最直接的方式。访问 FFmpeg 官方构建站点：

```
https://www.gyan.dev/ffmpeg/builds/
```

> **注意**：FFmpeg 官网（ffmpeg.org）本身不提供 Windows 构建包，它链接到上述由 Gyan Doshi 维护的构建站点。另一个常用的构建来源是 <https://github.com/BtbN/FFmpeg-Builds。>

下载页面上有两个版本可选：

- **ffmpeg-release-essentials.zip**：包含常用编码器，约 80MB，适合大多数人
- **ffmpeg-release-full.zip**：包含所有编码器（包括 libx265、libaom 等），约 130MB，推荐下载

下载后解压到任意目录（建议 `C:\ffmpeg`），然后将 `bin` 目录添加到系统环境变量 PATH 中：

```
1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
2. 在"系统变量"中找到 Path，点击"编辑"
3. 新增一行：C:\ffmpeg\bin
4. 确定保存
```

**方式二：使用 Chocolatey（包管理器）**

如果你已经安装了 Chocolatey，一条命令搞定：

```bash
choco install ffmpeg-full
```

这个命令会自动下载、解压并配置好 PATH，非常方便。

**方式三：使用 Scoop（另一款包管理器）**

```bash
scoop install ffmpeg
```

Scoop 的优势是安装过程不需要管理员权限，适合公司电脑。

## 2.2 macOS 安装

macOS 用户的首选方式是 **Homebrew**：

```bash
brew install ffmpeg
```

这条命令会安装 FFmpeg 及其依赖，并自动配置好环境变量。

如果你需要更多编码器支持（比如 libx265、libaom-av1），可以通过自定义选项安装：

```bash
brew install ffmpeg --with-libx265 --with-libaom
```

> **注意**：较新版本的 Homebrew FFmpeg 已经默认包含了大多数常用编码器，上述选项可能不再需要。可以用 `ffmpeg -encoders` 来确认当前支持的编码器列表。

## 2.3 Linux 安装

**Ubuntu / Debian 系列（apt）：**

```bash
# 更新软件包列表
sudo apt update

# 安装 FFmpeg
sudo apt install ffmpeg
```

> **版本提示**：Ubuntu 仓库里的 FFmpeg 版本可能较旧。如果需要最新版本，可以使用 PPA：
>
> ```bash
> sudo add-apt-repository ppa:savoury1/ffmpeg6
> sudo apt update && sudo apt install ffmpeg
> ```

**CentOS / RHEL / Fedora 系列（yum/dnf）：**

```bash
# 启用 RPM Fusion 仓库（FFmpeg 因专利原因不在默认仓库）
sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm

# 安装 FFmpeg
sudo dnf install ffmpeg ffmpeg-devel
```

**源码编译安装（高级用户，获取最新功能和完整控制）：**

```bash
# 安装编译依赖
sudo apt install build-essential yasm nasm pkg-config

# 下载源码
wget https://ffmpeg.org/releases/ffmpeg-7.0.tar.xz
tar xf ffmpeg-7.0.tar.xz
cd ffmpeg-7.0

# 配置（启用常用编码器）
./configure \
  --enable-gpl \
  --enable-libx264 \
  --enable-libx265 \
  --enable-libvpx \
  --enable-libopus \
  --enable-libaom

# 编译（-j4 表示使用 4 个 CPU 核心并行编译）
make -j4

# 安装
sudo make install
```

## 2.4 验证安装

安装完成后，打开终端（Windows 用 CMD 或 PowerShell，macOS/Linux 用 Terminal），运行以下命令：

```bash
ffmpeg -version
```

如果看到类似这样的输出，说明安装成功：

```
ffmpeg version 7.0 Copyright (c) 2000-2024 the FFmpeg developers
built with gcc 13.2.0 ...
configuration: --enable-gpl --enable-libx264 ...
```

## 2.5 认识三兄弟：ffmpeg / ffprobe / ffplay

FFmpeg 项目实际上包含三个独立的可执行文件，它们各司其职：

**ffmpeg —— 主程序（加工者）**
这是核心工具，负责所有的格式转换、编辑、滤镜处理工作。你 90% 的时间都在用它。

```bash
# 示例：将 input.mp4 转换为 output.webm
ffmpeg -i input.mp4 output.webm
```

**ffprobe —— 文件分析器（检查员）**
它不修改任何文件，只读取文件并输出详细的技术信息。想知道一个视频是什么编码、什么分辨率、多少帧率？问它。

```bash
# 查看视频文件的详细信息
ffprobe -v quiet -print_format json -show_streams input.mp4
```

**ffplay —— 简易播放器（预览员）**
一个基于 SDL 的极简视频播放器，用于快速预览视频效果，不需要打开 VLC 或其他播放器。

```bash
# 播放视频（按 q 退出）
ffplay input.mp4
```

三者的关系可以这样理解：**ffprobe 是体检医生（只检查不治疗），ffmpeg 是外科医生（负责手术），ffplay 是病人自己照镜子（快速预览）**。

## 2.6 静态编译 vs 动态编译

如果你下载的是 Windows 预编译包，会看到"static"和"shared"两个版本。它们的区别是：

**静态编译（Static Build）**
所有依赖库（libx264、libx265、libvpx 等）都被"烘焙"进了 ffmpeg.exe 这一个文件里。优点是拷贝到哪台电脑都能直接运行，不需要安装任何其他东西。缺点是文件体积较大（约 100MB+）。

**动态编译（Shared Build）**
依赖库以 .dll（Windows）或 .so（Linux）文件的形式独立存在。优点是文件分开，共享库可以被多个程序共用。缺点是你必须确保所有 .dll 文件都在正确的位置，否则运行时会报"找不到 DLL"错误。

**本教程推荐使用静态编译版**，因为：

- 无需担心 DLL 依赖问题
- 方便拷贝到 U 盘随身携带
- 在服务器部署时也更简单

## 2.7 常见安装问题排查

**问题 1：运行 ffmpeg 提示"不是内部或外部命令"（Windows）**

原因：ffmpeg 的 bin 目录没有加入 PATH 环境变量。

```bash
# 临时解决（当前 CMD 窗口有效）
set PATH=%PATH%;C:\ffmpeg\bin

# 验证
ffmpeg -version
```

永久解决请参考 2.1 节中的环境变量配置步骤。

**问题 2：提示"Unknown encoder 'libx264'"**

原因：你安装的 FFmpeg 版本没有编译进 libx264 编码器。

```bash
# 检查当前支持哪些编码器
ffmpeg -encoders | findstr x264

# 如果没有结果，需要重新安装 full 版本
# Windows：下载 ffmpeg-release-full.zip
# macOS：brew reinstall ffmpeg
# Linux：使用 PPA 或源码编译
```

**问题 3：macOS 提示 "dyld: Library not loaded"**

原因：动态链接的库找不到。通常是因为 Homebrew 更新后某些库被移除。

```bash
# 重新安装 FFmpeg 及其依赖
brew reinstall ffmpeg
```

**问题 4：Linux 上版本太旧，不支持某些新编码器**

```bash
# 查看当前版本
ffmpeg -version | head -1

# 如果版本低于 4.4，建议升级到最新版本
# Ubuntu 可用 PPA，或直接源码编译
```

## 本章小结

- Windows 推荐下载静态编译版（gyan.dev 或 BtbN 的 GitHub），也可用 Chocolatey/Scoop
- macOS 用 Homebrew 一条命令搞定
- Linux 用 apt/dnf 安装，或用源码编译获取最新版本
- FFmpeg 包含三个工具：ffmpeg（处理）、ffprobe（分析）、ffplay（预览）
- 静态编译版将所有库打包进单个文件，推荐使用
- 遇到问题优先检查 PATH 环境变量和编码器支持情况
