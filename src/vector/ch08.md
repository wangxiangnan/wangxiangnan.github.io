# 第8章：矩阵——空间的"变形术"

## 故事引入

小王的奶茶店开了三家分店，配送区域需要重新划分。

第一家分店要做一个调整：把所有配送方向顺时针旋转 30°——因为新区域的主干道就是这个角度。第二家分店要沿东西方向拉伸配送范围——因为东边新开了一个大学城，距离远了但订单多。

小王在纸上画了半天，突然意识到：这些操作——旋转、拉伸——都是对"整个空间"的变换。而描述这种变换的工具，就是**矩阵**。

"矩阵不是表格，"小王对着店员们说，"矩阵是一种魔法，它能把整个空间扭成另一个样子。"

店员们一脸茫然。没关系，你比他们先懂就行。

## 矩阵的本质：线性变换

很多人第一次学矩阵，以为它就是"一堆数排成的表格"。这个理解太表面了。

矩阵的本质是**线性变换**——一种对空间的变换方式。它有两个关键特征：

1. 变换后，原来的直线还是直线（不会变弯）
2. 原点保持不动

旋转、缩放、剪切、投影……这些都是线性变换。而"平移"不是（因为原点会移动）。

## 矩阵乘向量：基向量决定一切

一个 2×2 矩阵长这样：

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

它到底做了什么变换？答案藏在**列向量**里。

矩阵的第一列 (a, c) 就是标准基 î = (1, 0) 变换后去了哪里。
矩阵的第二列 (b, d) 就是标准基 ĵ = (0, 1) 变换后去了哪里。

知道了基向量的去向，任何向量的变换结果就确定了。因为任何向量都是基向量的线性组合，而线性变换保持"组合关系"不变。

具体来说：

$$A \begin{pmatrix} x \\ y \end{pmatrix} = x \begin{pmatrix} a \\ c \end{pmatrix} + y \begin{pmatrix} b \\ d \end{pmatrix} = \begin{pmatrix} ax + by \\ cx + dy \end{pmatrix}$$

举个例子：矩阵 A = $\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$

- î = (1, 0) 变成了 (2, 0)——x 方向拉伸了 2 倍
- ĵ = (0, 1) 变成了 (0, 3)——y 方向拉伸了 3 倍
- 向量 (1, 1) 变成了 (2, 3)

整个空间被"拉宽压高"了。

## 矩阵乘法 = 变换的复合

如果先做一个变换 A，再做一个变换 B，效果等价于一个矩阵 C = BA（注意顺序：后做的写在前面）。

比如小王想先旋转 90°，再沿 x 轴拉伸 2 倍：

旋转 90° 的矩阵：R = $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$

拉伸矩阵：S = $\begin{pmatrix} 2 & 0 \\ 0 & 1 \end{pmatrix}$

复合变换：SR = $\begin{pmatrix} 2 & 0 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & -2 \\ 1 & 0 \end{pmatrix}$

验证：(1, 0) 先旋转变成 (0, 1)，再拉伸变成 (0, 1)。用复合矩阵算：$\begin{pmatrix} 0 & -2 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$。一致。

**矩阵乘法不是"数的相乘"，而是"变换的叠加"。** 这一点非常重要。

## 常见变换矩阵

**旋转 θ 角（逆时针）：**

$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

**缩放（x 方向 a 倍，y 方向 b 倍）：**

$$S = \begin{pmatrix} a & 0 \\ 0 & b \end{pmatrix}$$

**剪切（沿 x 方向，依赖 y）：**

$$H = \begin{pmatrix} 1 & k \\ 0 & 1 \end{pmatrix}$$

效果是把每个点的 x 坐标加上 k 倍的 y 坐标——想象一摞扑克牌，底部固定，顶部被推了一把。

**投影到 x 轴：**

$$P = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$$

直接把 y 坐标抹掉，所有向量"拍扁"到 x 轴上。

## 单位矩阵

$$I = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$$

单位矩阵就是"什么都不做"的变换。î 还是 î，ĵ 还是 ĵ，一切原封不动。

任何向量乘以单位矩阵，还是它自己：AI = IA = A。就像数字里的 1 一样——乘以 1 不变。

## 类比：滤镜

把矩阵想象成手机相机的"滤镜"。

空间本身（原图）没有变，但透过不同的滤镜（矩阵），你看到的效果完全不同：旋转滤镜把画面转了个角度，缩放滤镜把画面拉宽了，投影滤镜把画面压成了一条线……

同一个向量，经过不同的矩阵变换，就得到不同的结果。关键不在于向量本身，而在于你选了哪个"滤镜"。

## 代码示例

```javascript
// 2×2 矩阵乘向量
function matrixVectorMultiply(matrix, vector) {
  // matrix = [[a, b], [c, d]]
  // vector = [x, y]
  const [a, b] = matrix[0];
  const [c, d] = matrix[1];
  const [x, y] = vector;

  return [
    a * x + b * y,
    c * x + d * y
  ];
}

// 生成旋转矩阵（角度单位为弧度）
function rotationMatrix(angle) {
  const cos = Math.cos(angle);
  const sin = Math.sin(angle);
  return [
    [cos, -sin],
    [sin,  cos]
  ];
}

// 小王要把配送区域旋转 30°
const angle30 = (30 * Math.PI) / 180; // 转成弧度
const R = rotationMatrix(angle30);

// 原来东边 5 公里的配送点 (5, 0)
const original = [5, 0];
const rotated = matrixVectorMultiply(R, original);

console.log("旋转后的坐标:", rotated);
// 约 [4.33, 2.5]——往北偏了一些
```

## 小结

- 矩阵的本质是**线性变换**，不是"数的表格"
- 矩阵的**列**告诉你基向量变换后去了哪里
- 矩阵乘法 = **变换的复合**（注意顺序）
- 常见变换：旋转、缩放、剪切、投影
- 单位矩阵 = "什么都不做"
- 矩阵就像"滤镜"——对空间施加不同的效果

## 练习题

**题1：** 矩阵 A = $\begin{pmatrix} 3 & 0 \\ 0 & 3 \end{pmatrix}$ 代表什么变换？向量 (2, 1) 经过变换后变成什么？

**题2：** 写出"先沿 y 方向缩放 2 倍，再投影到 x 轴"的复合变换矩阵。

**题3：** 剪切矩阵 H = $\begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}$ 作用在向量 (3, 1) 上，结果是什么？这个变换的几何效果是什么？

## 练习题答案

**题1：** A 是**均匀缩放**变换，x 和 y 方向都放大 3 倍。(2, 1) 变成 (6, 3)。

**题2：**
沿 y 方向缩放 2 倍：S = $\begin{pmatrix} 1 & 0 \\ 0 & 2 \end{pmatrix}$

投影到 x 轴：P = $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$

先 S 后 P，复合矩阵 = PS = $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} 1 & 0 \\ 0 & 2 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$

有意思——投影到 x 轴这个操作，直接把 y 方向的信息全丢了，所以之前 y 方向缩放多少都白搭。最终效果就等于直接投影到 x 轴。

**题3：**
H(3, 1) = $\begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 1×3 + 2×1 \\ 0×3 + 1×1 \end{pmatrix} = \begin{pmatrix} 5 \\ 1 \end{pmatrix}$

几何效果：x 坐标增加了 2 倍的 y 坐标（增加了 2），y 坐标不变。就像把空间沿 x 方向"推歪"了——y 越大的点被推得越远，y = 0 的点纹丝不动。
