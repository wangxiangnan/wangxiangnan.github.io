# 第七章：泛型——类型的函数

泛型是 TypeScript 中最重要、也最容易让人困惑的特性。如果前面的内容你都理解了，泛型其实只是水到渠成的延伸。

## 为什么需要泛型

假设你要写一个函数，返回数组的第一个元素：

```ts
function first(arr: any[]): any {
  return arr[0];
}
```

这个函数能用，但返回值是 `any`，调用之后你失去了类型信息：

```ts
const n = first([1, 2, 3]); // n 是 any，不是 number
```

如果你为每种类型都写一个重载，代码会爆炸：

```ts
function firstNumber(arr: number[]): number { ... }
function firstString(arr: string[]): string { ... }
```

泛型就是来解决这个问题的：

```ts
function first<T>(arr: T[]): T {
  return arr[0];
}

const n = first([1, 2, 3]);       // n 是 number
const s = first(["a", "b", "c"]); // s 是 string
```

`<T>` 叫做**类型参数**，你可以把它理解为"类型的函数参数"。调用函数时，TypeScript 会根据传入的实参自动推断 `T` 是什么。

## 泛型函数

```ts
function identity<T>(value: T): T {
  return value;
}

const num = identity(42);        // T 推断为 number
const str = identity<string>("hello"); // 显式指定 T 为 string
```

大多数情况下不需要显式指定，TypeScript 的推断很智能。

## 泛型接口

```ts
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

const userResponse: ApiResponse<User> = {
  data: { name: "Alice", age: 25 },
  status: 200,
  message: "ok",
};
```

泛型接口在定义通用数据结构时非常有用，比如 API 响应、分页列表、状态容器等。

## 泛型约束

有时你需要限制泛型参数必须满足某些条件，这时用 `extends`：

```ts
function logLength<T extends { length: number }>(value: T): T {
  console.log(value.length);
  return value;
}

logLength("hello"); // OK，string 有 length
logLength([1, 2]);  // OK，数组有 length
logLength(42);      // 错误，number 没有 length
```

`extends` 在这里不是继承的意思，而是"约束"。它要求 `T` 必须具有 `length` 属性。

## 多个泛型参数

```ts
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

const result = pair(1, "one"); // [number, string]
```

## 泛型类

```ts
class Stack<T> {
  private items: T[] = [];

  push(item: T): void {
    this.items.push(item);
  }

  pop(): T | undefined {
    return this.items.pop();
  }
}

const numberStack = new Stack<number>();
numberStack.push(10);
```

## 泛型的默认类型

```ts
interface Container<T = string> {
  value: T;
}

const c1: Container = { value: "hello" }; // T 默认为 string
const c2: Container<number> = { value: 42 };
```

## 理解泛型的关键

很多人学泛型时容易陷入一个误区：把 `T` 当成某种具体的类型。其实 `T` 更像是一个**占位符**。在函数被调用之前，`T` 是什么并不知道；调用时，TypeScript 根据上下文把它"填充"成具体类型。

你可以把泛型函数想象成一个模板：

```ts
function first<T>(arr: T[]): T
```

这个模板告诉 TypeScript："无论你传什么类型的数组给我，我返回的元素都和数组元素类型一致。"

这种"延迟确定类型"的能力，让泛型成为复用代码和保持类型安全之间的完美桥梁。
