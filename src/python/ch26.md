# 第 26 章 Web 开发入门

你有没有想过，当你在浏览器里打开一个网页，背后到底发生了什么？简单来说，有一个程序（Web 服务器）一直在那里等着，收到你的请求后，找到对应的"内容"返回给你。这就像一个餐厅——你（顾客/浏览器）看菜单（URL）点菜，服务员（Web 框架）把你的需求告诉厨房（后端逻辑），厨房做好菜（生成响应），服务员端给你。

Web 开发的核心就是搭建这个"厨房"。Python 生态中有两大主流 Web 框架：Flask 和 FastAPI。Flask 是老牌选手，轻量灵活，适合入门；FastAPI 是后起之秀，性能出色，自动生成 API 文档，代表了现代 Web 开发的方向。本章两个都会讲，让你能根据项目需求做出选择。

## 26.1 Flask 极简入门

Flask 是一个"微框架"——它只提供最核心的功能（路由和请求处理），其他功能（数据库、表单验证、用户认证）都通过扩展来实现。这种设计哲学就像给你一个空白的乐高底板，你需要什么零件自己往上搭。

```bash
pip install flask
```

### 第一个 Flask 应用

```python
# app.py
from flask import Flask

# 创建 Flask 应用实例
app = Flask(__name__)

# 路由：把 URL 映射到函数
@app.route("/")
def hello():
    return "<h1>Hello, Flask!</h1><p>欢迎来到我的第一个 Web 应用。</p>"

@app.route("/about")
def about():
    return "<h1>关于我</h1><p>我是一个正在学习 Flask 的 Python 开发者。</p>"

if __name__ == "__main__":
    # debug=True 会在代码修改后自动重启服务器
    app.run(debug=True, port=5000)
```

运行后访问 `http://localhost:5000` 就能看到页面了。就这么简单——不到 10 行代码，你就有了一个 Web 服务器。

### 动态路由与参数

现实中，URL 经常包含动态部分，比如 `/user/zhangsan` 和 `/user/lisi` 应该对应不同的用户信息。

```python
from flask import Flask, abort

app = Flask(__name__)

# 模拟一个用户数据库
USERS = {
    "zhangsan": {"name": "张三", "age": 28, "city": "北京"},
    "lisi": {"name": "李四", "age": 32, "city": "上海"},
    "wangwu": {"name": "王五", "age": 25, "city": "广州"},
}

@app.route("/user/<username>")
def show_user(username):
    """根据用户名显示用户信息"""
    user = USERS.get(username)
    if user is None:
        abort(404)  # 返回 404 错误
    return f"<h1>{user['name']}</h1><p>年龄: {user['age']}<br>城市: {user['city']}</p>"

# 还可以指定参数类型
@app.route("/post/<int:post_id>")
def show_post(post_id):
    """显示指定 ID 的文章"""
    return f"文章 ID: {post_id}"
```

### HTTP 方法处理

```python
from flask import Flask, request

app = Flask(__name__)

@app.route("/search", methods=["GET", "POST"])
def search():
    if request.method == "POST":
        # 从表单获取数据
        keyword = request.form.get("keyword", "")
        return f"<p>搜索结果: 你搜索了 '{keyword}'</p>"
    else:
        # GET 请求返回搜索表单
        return """
        <form method="POST">
            <input type="text" name="keyword" placeholder="输入关键词">
            <button type="submit">搜索</button>
        </form>
        """
```

### Jinja2 模板引擎

把 HTML 直接写在 Python 代码里，一旦页面复杂起来就变成了噩梦。模板引擎让你把 HTML 抽离到单独的文件中，用变量和逻辑控制内容渲染。

```python
# app.py
from flask import Flask, render_template

app = Flask(__name__)

BOOKS = [
    {"title": "Python 编程", "author": "张三", "rating": 4.5},
    {"title": "Flask Web 开发", "author": "李四", "rating": 4.2},
    {"title": "数据结构与算法", "author": "王五", "rating": 4.8},
]

@app.route("/books")
def book_list():
    return render_template("books.html", books=BOOKS, title="书单推荐")
```

```html
<!-- templates/books.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ title }}</title>
</head>
<body>
    <h1>{{ title }}</h1>
    <table border="1">
        <tr>
            <th>书名</th>
            <th>作者</th>
            <th>评分</th>
        </tr>
        {% for book in books %}
        <tr>
            <td>{{ book.title }}</td>
            <td>{{ book.author }}</td>
            <td>{{ "★" * book.rating | int }}{{ "☆" * (5 - book.rating | int) }}</td>
        </tr>
        {% endfor %}
    </table>
    {% if not books %}
    <p>暂无书籍数据。</p>
    {% endif %}
</body>
</html>
```

Jinja2 模板的核心语法：

- `{{ variable }}`：输出变量值
- `{% if condition %}`：条件判断
- `{% for item in list %}`：循环
- `{% extends "base.html" %}`：模板继承
- `{% block content %}{% endblock %}`：定义可覆盖的区块

### 蓝图（Blueprint）：组织大型项目

当应用变大后，所有路由写在一个文件里会变得难以维护。蓝图让你把功能模块化：

```python
# blueprints/auth.py
from flask import Blueprint

auth_bp = Blueprint("auth", __name__, url_prefix="/auth")

@auth_bp.route("/login")
def login():
    return "登录页面"

@auth_bp.route("/register")
def register():
    return "注册页面"


# blueprints/api.py
from flask import Blueprint, jsonify

api_bp = Blueprint("api", __name__, url_prefix="/api")

@api_bp.route("/books")
def get_books():
    books = [{"title": "Python 入门", "price": 89}]
    return jsonify(books)  # jsonify 自动转换为 JSON 响应


# app.py（主文件）
from flask import Flask
from blueprints.auth import auth_bp
from blueprints.api import api_bp

app = Flask(__name__)
app.register_blueprint(auth_bp)
app.register_blueprint(api_bp)

if __name__ == "__main__":
    app.run(debug=True)
```

## 26.2 FastAPI：现代 Web 框架

FastAPI 是近几年最火的 Python Web 框架，它的核心卖点有三个：快（性能接近 Go/Node.js）、自动 API 文档、原生类型提示支持。如果说 Flask 是一把万能瑞士军刀，FastAPI 就是一把自带激光瞄准器的高精度工具。

```bash
pip install fastapi uvicorn
```

### 第一个 FastAPI 应用

```python
# main.py
from fastapi import FastAPI

app = FastAPI(title="我的第一个 API")

@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    """
    item_id 是路径参数，自动验证为整数
    q 是可选的查询参数
    """
    return {"item_id": item_id, "q": q}
```

运行：

```bash
uvicorn main:app --reload
```

然后打开 `http://localhost:8000/docs`，你会看到一个自动生成的交互式 API 文档——这就是 FastAPI 的魅力所在，你只需要写代码，文档自动生成。

### Pydantic 数据模型

FastAPI 使用 Pydantic 进行数据验证，这是它最强大的特性之一：

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class BookCreate(BaseModel):
    """创建书籍的请求模型"""
    title: str = Field(..., min_length=1, max_length=100, description="书名")
    author: str = Field(..., min_length=1, max_length=50, description="作者")
    price: float = Field(..., gt=0, description="价格，必须大于 0")
    isbn: str | None = Field(None, pattern=r"^\d{13}$", description="ISBN 13位")

class BookResponse(BaseModel):
    """书籍响应模型"""
    id: int
    title: str
    author: str
    price: float

# 模拟数据库
db: list[dict] = []
next_id = 1

@app.post("/books", response_model=BookResponse, status_code=201)
def create_book(book: BookCreate):
    """创建一本新书"""
    global next_id
    new_book = {"id": next_id, **book.model_dump()}
    db.append(new_book)
    next_id += 1
    return new_book

@app.get("/books", response_model=list[BookResponse])
def list_books():
    """获取所有书籍"""
    return db

@app.get("/books/{book_id}", response_model=BookResponse)
def get_book(book_id: int):
    """获取指定书籍"""
    for book in db:
        if book["id"] == book_id:
            return book
    raise HTTPException(status_code=404, detail="书籍不存在")
```

### 依赖注入

FastAPI 的依赖注入系统非常优雅，可以处理数据库连接、认证、分页等横切关注点：

```python
from fastapi import FastAPI, Depends, Query

app = FastAPI()

def pagination_params(
    page: int = Query(1, ge=1, description="页码"),
    size: int = Query(10, ge=1, le=100, description="每页数量"),
):
    """分页参数依赖"""
    return {"skip": (page - 1) * size, "limit": size}

@app.get("/items")
def list_items(params: dict = Depends(pagination_params)):
    """列表接口自动注入分页参数"""
    return {
        "params": params,
        "message": f"跳过 {params['skip']} 条，取 {params['limit']} 条"
    }
```

### Flask vs FastAPI 怎么选？

| 特性 | Flask | FastAPI |
| ------ | ------- | --------- |
| 学习曲线 | 低，极简 | 中，需要了解类型提示 |
| 性能 | 同步，一般 | 异步，很高 |
| API 文档 | 需要手动或扩展 | 自动生成 Swagger UI |
| 数据验证 | 需要 WTForms 等 | 内置 Pydantic |
| 模板渲染 | Jinja2（内置） | 支持但不推荐（API 优先） |
| 生态成熟度 | 非常成熟 | 快速成长中 |
| 适用场景 | 传统 Web、小项目 | API 服务、微服务 |

建议：新项目优先考虑 FastAPI，尤其是构建 API；如果需要服务端渲染 HTML 页面，Flask 仍然方便。

## 26.3 SQLAlchemy ORM 快速上手

几乎所有 Web 应用都需要数据库。直接写 SQL 语句既繁琐又容易出错，ORM（Object-Relational Mapping，对象关系映射）让你用 Python 类和对象来操作数据库，就像用 Python 的方式思考数据。

```bash
pip install sqlalchemy
```

### 定义模型

```python
from sqlalchemy import create_engine, Column, Integer, String, Float, DateTime
from sqlalchemy.orm import DeclarativeBase, Session
from datetime import datetime

# 使用 SQLite 作为数据库（零配置，文件存储）
engine = create_engine("sqlite:///books.db", echo=True)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"

    id = Column(Integer, primary_key=True, autoincrement=True)
    title = Column(String(100), nullable=False)
    author = Column(String(50), nullable=False)
    price = Column(Float, nullable=False)
    created_at = Column(DateTime, default=datetime.now)

    def __repr__(self):
        return f"<Book(id={self.id}, title='{self.title}')>"

# 创建所有表
Base.metadata.create_all(engine)
```

### CRUD 操作

```python
# ========== Create（创建） ==========
with Session(engine) as session:
    book1 = Book(title="Python 入门", author="张三", price=89.0)
    book2 = Book(title="Flask 实战", author="李四", price=79.0)
    book3 = Book(title="FastAPI 指南", author="王五", price=99.0)
    session.add_all([book1, book2, book3])
    session.commit()

# ========== Read（查询） ==========
with Session(engine) as session:
    # 查询所有书籍
    all_books = session.query(Book).all()
    for book in all_books:
        print(book)

    # 条件查询
    expensive = session.query(Book).filter(Book.price > 80).all()
    print(f"\n价格 > 80 的书: {len(expensive)} 本")

    # 排序
    sorted_books = session.query(Book).order_by(Book.price.desc()).all()
    print(f"\n按价格降序: {[b.title for b in sorted_books]}")

    # 查询单条
    book = session.query(Book).filter_by(title="Python 入门").first()
    print(f"\n找到: {book}")

# ========== Update（更新） ==========
with Session(engine) as session:
    book = session.query(Book).filter_by(title="Python 入门").first()
    book.price = 95.0  # 修改价格
    session.commit()

# ========== Delete（删除） ==========
with Session(engine) as session:
    book = session.query(Book).filter_by(title="Flask 实战").first()
    session.delete(book)
    session.commit()
```

### 在 FastAPI 中使用 SQLAlchemy

```python
from fastapi import FastAPI, Depends, HTTPException
from sqlalchemy import create_engine, Column, Integer, String, Float
from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker

DATABASE_URL = "sqlite:///./app.db"
engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(bind=engine)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"
    id = Column(Integer, primary_key=True)
    title = Column(String(100), nullable=False)
    author = Column(String(50), nullable=False)
    price = Column(Float, nullable=False)

Base.metadata.create_all(engine)

app = FastAPI()

def get_db():
    """数据库会话依赖"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

@app.get("/books")
def list_books(db: Session = Depends(get_db)):
    books = db.query(Book).all()
    return [{"id": b.id, "title": b.title, "author": b.author, "price": b.price}
            for b in books]

@app.post("/books")
def create_book(title: str, author: str, price: float, db: Session = Depends(get_db)):
    book = Book(title=title, author=author, price=price)
    db.add(book)
    db.commit()
    db.refresh(book)
    return {"id": book.id, "title": book.title}
```

## 26.4 RESTful API 设计原则

API 是应用程序之间沟通的"菜单"。RESTful 是一种设计风格，让你的 API 像菜单一样清晰易懂。

### RESTful 的核心原则

1. **资源为王**：URL 代表资源（名词），操作用 HTTP 方法（动词）
2. **统一接口**：相同的操作使用相同的 HTTP 方法
3. **无状态**：每个请求包含所有信息，服务器不保存会话状态

### API 设计示例

```
GET    /api/books          # 获取书籍列表
GET    /api/books/42       # 获取 ID 为 42 的书
POST   /api/books          # 创建新书
PUT    /api/books/42       # 更新 ID 为 42 的书（全量）
PATCH  /api/books/42       # 部分更新
DELETE /api/books/42       # 删除
```

### 状态码使用规范

```python
from fastapi import FastAPI, HTTPException
from fastapi.responses import JSONResponse

app = FastAPI()

@app.post("/books", status_code=201)  # 201 Created
def create_book():
    return {"id": 1, "title": "新书"}

@app.get("/books/{book_id}")
def get_book(book_id: int):
    # 找不到返回 404
    raise HTTPException(status_code=404, detail="书籍不存在")

@app.delete("/books/{book_id}", status_code=204)  # 204 No Content
def delete_book(book_id: int):
    return None
```

### 分页、排序与过滤

```python
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/api/books")
def list_books(
    page: int = Query(1, ge=1),
    size: int = Query(10, ge=1, le=100),
    sort_by: str = Query("title", pattern="^(title|price|created_at)$"),
    order: str = Query("asc", pattern="^(asc|desc)$"),
    min_price: float | None = None,
    max_price: float | None = None,
):
    """
    支持分页、排序、价格区间过滤的书籍列表 API
    """
    return {
        "page": page,
        "size": size,
        "sort_by": sort_by,
        "order": order,
        "filters": {"min_price": min_price, "max_price": max_price},
        "data": [],  # 实际项目中这里返回查询结果
        "total": 0,
    }
```

## 26.5 部署到生产环境

在本地 `python app.py` 跑起来的服务器只适合开发。生产环境需要考虑性能、稳定性、安全性。常见的部署方案是使用多层代理架构：

```
客户端 → Nginx（反向代理） → Gunicorn（WSGI 服务器） → Flask/FastAPI（应用）
```

这就像一个餐厅的前厅和后厨：Nginx 是门口接待，负责分流客人；Gunicorn 是传菜员，管理并发；Flask/FastAPI 是厨师，专注做菜。

### Uvicorn + Gunicorn（FastAPI 部署）

```bash
pip install gunicorn uvicorn[standard]
```

```bash
# 启动命令
gunicorn main:app \
    --workers 4 \
    --worker-class uvicorn.workers.UvicornWorker \
    --bind 0.0.0.0:8000
```

参数说明：

- `main:app`：`main.py` 文件中的 `app` 变量
- `--workers 4`：4 个工作进程（一般设置为 CPU 核心数 × 2 + 1）
- `--worker-class`：使用 Uvicorn 的工作类（支持异步）
- `--bind`：绑定地址和端口

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态文件直接由 Nginx 处理，性能更好
    location /static {
        alias /path/to/your/static;
    }
}
```

### 使用 systemd 管理服务

```ini
# /etc/systemd/system/myapp.service
[Unit]
Description=My FastAPI Application
After=network.target

[Service]
User=www-data
WorkingDirectory=/home/user/myapp
ExecStart=/home/user/myapp/venv/bin/gunicorn main:app \
    --workers 4 \
    --worker-class uvicorn.workers.UvicornWorker \
    --bind 127.0.0.1:8000
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl start myapp
sudo systemctl enable myapp  # 开机自启
```

## 26.6 小结

本章我们学习了 Web 开发的核心知识：

- **Flask** 是轻量级框架，适合快速原型和传统 Web 应用
- **FastAPI** 是现代框架，性能优秀，自动生成文档，适合 API 开发

Web 开发是一个庞大的领域，本章只是入门。要真正掌握，需要大量实践——从一个小项目开始，逐步增加功能。

## 26.8 参考答案

**第 1 题：**

```python
from flask import Flask, request, redirect, url_for

app = Flask(__name__)
todos = []

@app.route("/")
def index():
    items_html = ""
    for i, todo in enumerate(todos):
        items_html += f"""
        <li>
            {todo}
            <form action="/delete/{i}" method="POST" style="display:inline">
                <button type="submit">删除</button>
            </form>
        </li>
        """
    return f"""
    <h1>待办清单</h1>
    <form action="/add" method="POST">
        <input type="text" name="todo" placeholder="输入待办事项">
        <button type="submit">添加</button>
    </form>
    <ul>{items_html}</ul>
    """

@app.route("/add", methods=["POST"])
def add():
    todo = request.form.get("todo", "").strip()
    if todo:
        todos.append(todo)
    return redirect(url_for("index"))

@app.route("/delete/<int:index>", methods=["POST"])
def delete(index):
    if 0 <= index < len(todos):
        todos.pop(index)
    return redirect(url_for("index"))

if __name__ == "__main__":
    app.run(debug=True)
```

**第 2 题：**

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI(title="待办清单 API")

class TodoCreate(BaseModel):
    title: str
    done: bool = False

class TodoResponse(BaseModel):
    id: int
    title: str
    done: bool

todos: list[dict] = []
next_id = 1

@app.post("/todos", response_model=TodoResponse, status_code=201)
def create_todo(todo: TodoCreate):
    global next_id
    item = {"id": next_id, **todo.model_dump()}
    todos.append(item)
    next_id += 1
    return item

@app.get("/todos", response_model=list[TodoResponse])
def list_todos():
    return todos

@app.delete("/todos/{todo_id}", status_code=204)
def delete_todo(todo_id: int):
    for i, todo in enumerate(todos):
        if todo["id"] == todo_id:
            todos.pop(i)
            return None
    raise HTTPException(status_code=404, detail="待办项不存在")

@app.patch("/todos/{todo_id}")
def toggle_todo(todo_id: int):
    for todo in todos:
        if todo["id"] == todo_id:
            todo["done"] = not todo["done"]
            return todo
    raise HTTPException(status_code=404, detail="待办项不存在")
```

**第 6 题：**

`app.run()` 内置的开发服务器是单线程、单进程的，它设计目的是方便开发调试，不适合生产环境的原因包括：

- **性能差**：无法处理高并发请求
- **不稳定**：一个错误可能导致整个服务崩溃
- **无进程管理**：不支持多 worker、自动重启
- **不安全**：debug 模式下可能泄露敏感信息

Gunicorn/Uvicorn 是专业的应用服务器，支持多进程/多线程、优雅重启、负载均衡，能处理高并发场景。

## 26.9 常见错误与避坑

**1. debug 模式在生产环境中未关闭**

```python
# 危险！生产环境绝对不能开 debug
app.run(debug=True)

# 正确做法：通过环境变量控制
import os
debug_mode = os.getenv("FLASK_DEBUG", "false").lower() == "true"
app.run(debug=debug_mode)
```

**2. 数据库连接未正确关闭**

```python
# 错误示范：连接泄漏
db = SessionLocal()
books = db.query(Book).all()
# 忘记关闭 db...

# 正确做法：使用上下文管理器或依赖注入
with SessionLocal() as db:
    books = db.query(Book).all()
# 自动关闭
```

**3. 在 URL 中暴露敏感信息**

```python
# 错误：密码出现在 URL 中
@app.route("/login/<username>/<password>")
def login(username, password): ...

# 正确：使用 POST 请求体
@app.route("/login", methods=["POST"])
def login():
    username = request.json["username"]
    password = request.json["password"]
    ...
```

**4. 不验证用户输入**

永远不要信任用户输入。FastAPI 的 Pydantic 模型自动帮你做了验证，如果你用 Flask，记得手动验证或使用 WTForms/marshmallow 等库。

**5. 硬编码配置信息**

```python
# 错误示范
DATABASE_URL = "postgresql://user:password123@localhost/mydb"

# 正确做法
import os
DATABASE_URL = os.getenv("DATABASE_URL")
if not DATABASE_URL:
    raise ValueError("DATABASE_URL 环境变量未设置")
```

**6. 忽视 CORS 问题**

当前端和后端不在同一个域名下时，浏览器会因为 CORS 策略阻止请求。记得在 API 端添加 CORS 中间件。
