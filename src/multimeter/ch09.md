# 第9章 测二极管与三极管：半导体的照妖镜

> [!TIP]
> Part III 进阶与实战

小王最近染上了一个"职业病"：拆下来的旧件舍不得扔。封口机换下来的旧主板，被他当宝贝一样摆在吧台后面的纸箱里，得空就拿出来"考古"。主板上那些花花绿绿的小元件里，最让他好奇的是一种黑色小圆柱：一头画着一圈银色圆环，旁边还印着个箭头符号。他翻出手机查了半天，得出结论——这叫二极管。

"二极管，二极——是不是和水管一样，水只能往一个方向流？"小王一拍大腿。前八章的水管类比已经长在他脑子里了。果然，资料上说二极管就是"电路里的单向阀"：正向通、反向不通。他又发现主板上还有四个二极管手拉手封装在一起的"整流桥"，以及三只脚、长得像小帽子的三极管。这些小家伙到底是干什么的？坏了怎么查？他决定用万用表当"照妖镜"，把这些半导体一个个照个明白。

本章就跟着小王，从半导体的老底讲起，学会测二极管、发光二极管、整流桥，最后给三极管做一次"粗体检"。

## 9.1 半导体与PN结：单向阀的秘密

要理解二极管，先得认识半导体。世界上的材料按导电能力分三类：导体（铜、铝，电子随便跑）、绝缘体（塑料、陶瓷，电子被锁死）、半导体（硅、锗，夹在中间）。硅原子最外层有4个电子，正好和邻居手拉手形成稳定的"四人帮"结构，谁也不多谁也不少，所以纯净的硅导电能力很差。

但硅有个脾气：掺点杂质就变性子。往硅里掺一点磷（最外层5个电子），就多出一个没人管的自由电子，这种料叫N型半导体（N是Negative，负）；往硅里掺一点硼（最外层3个电子），反而多出一个"缺电子的坑"，叫空穴，这种料叫P型半导体（P是Positive，正）。空穴可以想象成停车场的空车位：旁边的电子挪进这个空位，空位就跑到邻居那里去了，等效于"正电荷"在移动。

把一块P型和一块N型紧紧贴在一起，好戏开场：交界面附近，N区的自由电子往P区扩散，留下带正电的原子核；P区的空穴往N区扩散，留下带负电的离子。扩散的结果，是交界面两侧堆起一堵"电荷墙"，墙内形成一个内建电场，像一道堤坝挡住更多电子继续扩散。这道堤坝的高度，硅材料大约是0.6-0.7伏。这个"P-N"交界面，就是大名鼎鼎的PN结——二极管的心脏。

现在看二极管为什么单向导电。用单向阀来类比：阀门里有个弹簧顶着阀芯，水压必须超过弹簧的弹力，阀才被顶开；水从反方向来，只会把阀芯越压越紧。PN结同理：外部电压正接（P区接正、N区接负），等于帮忙把电子往堤坝上推，推过0.6-0.7伏这道坝，电流哗啦涌过去，这就是正向导通；导通后阀门维持打开状态，两端始终保留0.6-0.7伏左右的"压降"（水过阀门总有点阻力，水位差不会消失）。外部电压反接，等于把堤坝越垒越高，电子更过不去，电流几乎为零，这就是反向截止。

顺带说一句，不同材料的"堤坝高度"不同：锗二极管0.2-0.3伏，肖特基二极管0.2-0.4伏，硅二极管0.5-0.7伏，发光二极管1.8-3.2伏（材料特殊，发光要付出更高代价）。这个"高度"数字，马上就是我们的判案依据。

## 9.2 二极管档测二极管：正向压降就是体检报告

万用表二极管档的档位符号，通常是二极管电路符号加一个发声标记。它内部的工作原理是"恒流源+电压表"：表内输出一个恒定的小电流（约1毫安），同时测量被测元件两端的电压，把这个电压值直接显示在屏幕上。

为什么测健康二极管时，正向显示0.5-0.7伏？因为那1毫安电流刚好能从正向导通的PN结流过去，元件两端呈现的电压，恰好就是它自己的正向压降——0.5-0.7伏。仪表等于在问二极管："我放1毫安过去，你收多少过路费？"二极管老实回答："硅管的行价，0.6伏。"注意，这里显示的是伏特（V），不是欧姆——二极管不是电阻，它的"电阻"随电压变化，报压降才是有意义的信息。

为什么反向显示OL？反接时PN结截止，1毫安电流根本流不过去，表内电压会一路往上升，直到超过量程上限，于是显示OL（Over Load，超出量程）。就像单向阀反装，水压再大也过不去，压力表只会一路飙到爆表。

操作步骤：断电、拆下元件（或至少焊开一只脚）→ 打到二极管档 → 红表笔接阳极（没有银环的那端），黑表笔接阴极（带银环那端）→ 正常应显示0.5-0.7伏 → 对调表笔再测 → 正常应显示OL。

判读口诀：一个方向0.5-0.7伏、另一方向OL＝健康；两个方向都通（显示接近0伏）＝击穿短路（单向阀的弹簧断了，正反都漏水）；两个方向都OL＝内部开路（阀门锈死了，正反都不通）。补充两个特例：读数只有0.2-0.4伏，可能是肖特基管或锗管，未必是坏；读数1.8-3伏而且元件在发光，那是LED，也不是坏。

还要提醒：在电路板上"在路"测量时，二极管旁边并联的线圈、电容、别的二极管会"帮倒忙"，把读数搅乱。可疑的元件，焊开一只脚再复测，才是铁证。

## 9.3 测发光二极管LED：会发光的单向阀

发光二极管（LED，Light Emitting Diode）本质上也是PN结，只不过材料换成了砷化镓、氮化镓这些特殊半导体。电子和空穴在结里"复合"时，普通二极管把能量变成热，LED把能量变成光。发光需要更高的能量门槛，所以LED的正向压降更高：红/黄色1.8-2.2伏，绿色2-3.2伏，蓝/白色3-3.4伏。

测量方法和普通二极管完全一样：二极管档，红表笔接长脚（正极，阳极），黑表笔接短脚（负极，阴极，管壳上通常还有一个平边标记），显示1.8-3伏左右，同时LED会被表内那1毫安电流微微点亮——这是它"活着"的直接证据；反接显示OL。有一点要留意：一些老款万用表二极管档的开路电压不足3伏，测蓝白LED时可能正反都显示OL，别急着判死刑，换一块表或串个电池再测一次。

另外提醒：LED反向耐压一般只有5伏左右，别拿电阻档大电流轰它，更别反接高电压，否则一记闷棍就把这只"小灯泡"打瞎了。

## 9.4 整流桥：四个二极管手拉手

封口机、充电器要把220伏交流电变成直流电，主角就是整流桥。它把四个二极管按特定方式封装在一个小方块里，外壳印着四个引脚标记：两个"~"脚是交流输入，一个"+"脚是直流正输出，一个"-"脚是直流负输出。

为什么四个二极管能把交流"掰直"？交流电正半周时，其中两只二极管导通；负半周时，另两只导通。不管进来的水往哪个方向冲，出水口的方向永远不变——就像四个单向阀搭成的"换向桥"，水流来回变，出口始终朝一个方向。这就是"整流"。

测量方法：整流桥内部就是四个独立的二极管，用二极管档挨个照：①红表笔接任意一个~脚，黑表笔接+脚 → 应显示0.5-0.7伏；②红表笔接-脚，黑表笔接同一个~脚 → 应显示0.5-0.7伏；换另一个~脚再重复①和②；两个~脚之间互测 → 应为OL；所有方向反过来 → 都应为OL。一共四组读数，组组正常，桥就健康。

判读：任意一组出现"两个方向都通"（读数接近0）＝桥击穿。整流桥击穿是电源类设备最常见的死法之一，典型症状是保险丝烧断、通电就跳闸。

## 9.5 三极管粗测：小水流控制大水流的水龙头

三极管是两片同型半导体夹一片反型半导体做成的"三明治"：NPN型（N-P-N）或PNP型（P-N-P），内部天然形成两个背靠背的PN结，引出三只脚：基极（b）、集电极（c）、发射极（e）。

它凭什么重要？类比水龙头：基极流入的小水流，控制着集电极到发射极的大水流，放大倍数可达几十到几百倍。水龙头拧一小圈，出水量变化一大截——三极管就是电路里的"电子水龙头"。很多数字万用表面板上有个hFE插孔，就是专门插三极管测放大倍数的。

粗测思路：三极管＝两个二极管共用一只脚。b与e之间是一个PN结，b与c之间是另一个PN结，用二极管档把这两个结分别照一遍即可。

第一步，找基极：任意两只脚组合互测，找到这样一只脚——它与另外两只脚之间都能测出0.5-0.7伏。它就是基极。具体到表笔：红表笔固定在这只脚上、黑表笔分别接另外两脚，都导通（0.5-0.7伏）→ 这是NPN管（基极是P区，红表笔的正电压正好正向偏置两个结）；反过来，黑表笔固定在这只脚上、红表笔分别接另外两脚都导通 → 这是PNP管。

第二步，区分集电极和发射极：光靠二极管档分不出来（两个结"看起来"一样）。三个办法：①查资料——型号就印在管壳上，上网一搜引脚图立现；②用hFE插孔——按常见脚位顺序试着插（不少管是E-B-C或B-C-E排列），放大倍数读数正常且稳定的那组插法就是对的；③经验——多数中功率塑封管的中间脚是集电极。

粗测判读：两个结都正常（各方向0.5-0.7伏/OL）＝大概率是好的；任意一个结两个方向都通或都OL＝该三极管已阵亡。

## 9.6 常见错误与注意事项

1. 带电测量：在路测二极管、整流桥必须断电并放掉大电容余电，否则读数全错，还可能烧表。
2. 二极管档与电阻档混淆：二极管档显示的是伏特，电阻档显示的是欧姆，别把0.5V当成0.5Ω。
3. 只测一个方向就下结论：正反两次都要测，测一半就判死刑容易冤枉好元件。
4. 把LED当普通二极管：显示1.8伏以上不是坏了，那是发光二极管在报自己的"身高"。
5. 在路测量不拆件：并联元件会搅局，可疑就拆一只脚再测。
6. 手指同时捏住两表笔金属头：人体电阻（几十千欧）会并联进电路，干扰判断。

## 9.7 本章小结

PN结是P型与N型半导体交界处的一堵"电荷堤坝"，高度约0.6-0.7伏，它让二极管成为只能单向过水的阀门。二极管档用1毫安恒流"问路"，正向显示的就是压降本身，反向则因电流过不去而显示OL。一个方向0.5-0.7伏、另一方向OL是健康；两个方向都通是击穿，都OL是开路。LED是压降更高的发光二极管，整流桥是四个二极管的手拉手组合，三极管则是两个PN结共用一个基极的水龙头——用二极管档照遍这些PN结，好坏立现。

## 9.8 练习题

1. 用二极管档测一只未知二极管：红表笔接A端、黑表笔接B端显示0.62V；对调表笔显示OL。这只二极管好坏如何？哪端是阳极？
2. 为什么二极管反接时万用表显示OL，而不是0？
3. 测一只三极管：红表笔接1脚，黑表笔分别接2脚、3脚，都显示0.65V。1脚是什么极？这是NPN还是PNP管？
4. 某整流桥的+脚与其中一个~脚之间，两个方向测都显示接近0V。这个整流桥还能用吗？为什么？
5. 一只蓝色LED，二极管档正反都显示OL。它一定坏了吗？为什么？

**参考答案：**

1. 健康。0.62V是正向压降（硅管），A端是阳极，B端是阴极。
2. 反接时PN结截止，表内的1毫安测试电流流不过去，表内电压升到超出量程，所以显示OL（超出量程）。
3. 1脚是基极，且是NPN管（红表笔固定能同时正向导通两个结，说明基极是P区）。
4. 不能用。+脚与~脚之间的二极管已击穿短路（正反都通），整流桥失去整流能力，通电会烧保险。
5. 不一定。蓝白LED正向压降3伏左右，老款万用表二极管档开路电压不足3伏，无法正向导通，正反都显示OL。换一块开路电压更高的表或串电池再测。
