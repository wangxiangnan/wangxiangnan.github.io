# 第25章：网络编程实战与协议设计

## Socket 编程基础回顾

所有网络通信的起点都是 **Socket**——操作系统提供的网络通信抽象。

```python
"""
TCP Echo 服务器与客户端
最基础的网络编程模式
"""
import socket
import threading

# ========== TCP 服务器 ==========
def tcp_server():
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind(('0.0.0.0', 9999))
    server.listen(5)
    print("[TCP Server] 监听端口 9999...")

    while True:
        conn, addr = server.accept()
        print(f"[TCP Server] 新连接: {addr}")
        threading.Thread(target=handle_client, args=(conn,)).start()

def handle_client(conn):
    try:
        while True:
            data = conn.recv(1024)
            if not data:
                break
            print(f"[TCP Server] 收到: {data.decode()}")
            conn.sendall(b"Echo: " + data)
    finally:
        conn.close()

# ========== TCP 客户端 ==========
def tcp_client():
    client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    client.connect(('127.0.0.1', 9999))

    client.sendall(b"Hello, Socket!")
    response = client.recv(1024)
    print(f"[TCP Client] 收到: {response.decode()}")

    client.close()

# 在两个终端分别运行 server 和 client
```

## I/O 模型：从阻塞到事件驱动

**阻塞 I/O（Blocking I/O）：** `recv()` 调用会一直等到数据到达。简单但低效——一个连接占一个线程，1000 个连接需要 1000 个线程。

**非阻塞 I/O（Non-blocking I/O）：** `recv()` 没数据时立即返回而非阻塞。但你需要不断轮询检查，浪费 CPU。

**I/O 多路复用（I/O Multiplexing）：** 用一个线程同时监控多个 Socket。这是现代高性能服务器的基础。

```
select() → poll() → epoll()（Linux）/ kqueue()（BSD/macOS）

select: "这几个 socket 里有数据吗？" → 遍历检查 → O(n)
epoll:  "有数据的 socket 告诉我" → 事件回调 → O(1)
```

**epoll** 是 Linux 上的终极方案。它维护一个"兴趣列表"，当注册的 Socket 有事件发生时，epoll 直接返回有事件的 Socket，无需遍历所有 Socket。

## 事件驱动编程：asyncio 与网络编程

Python 的 `asyncio` 库把 I/O 多路复用封装成了更友好的 async/await 语法：

```python
"""
asyncio 实现的并发 TCP Echo 服务器
一个线程处理数千个连接
"""
import asyncio

async def handle_echo(reader: asyncio.StreamReader,
                      writer: asyncio.StreamWriter):
    addr = writer.get_extra_info('peername')
    print(f"[Server] 新连接: {addr}")

    while True:
        data = await reader.read(1024)  # 非阻塞读取
        if not data:
            break
        message = data.decode()
        print(f"[Server] {addr}: {message}")
        writer.write(f"Echo: {message}".encode())
        await writer.drain()  # 确保数据发送完成

    writer.close()
    await writer.wait_closed()
    print(f"[Server] 断开: {addr}")

async def main():
    server = await asyncio.start_server(handle_echo, '0.0.0.0', 9999)
    print("[Server] asyncio Echo Server 启动在端口 9999")
    async with server:
        await server.serve_forever()

asyncio.run(main())
```

asyncio 的核心是**事件循环（Event Loop）**。当某个 `await` 的 I/O 操作未完成时，事件循环切换到其他协程执行。这使得单线程就能处理大量并发连接。

## 设计你自己的协议

这是本章最有趣的部分——从零设计一个网络协议。协议设计是网络编程中最具创造性也最容易出错的环节。

### 需求分析：你需要解决什么问题？

协议设计的第一步不是写代码，而是回答：

- 你的协议要传输什么数据？
- 对延迟、吞吐量、可靠性的要求是什么？
- 通信模式是什么？（请求/响应？推送？双向？）
- 连接是长期的还是短期的？
- 需要处理多少并发连接？

### 消息格式设计

**方案一：定长消息**

```
[消息类型 1B][消息长度 4B][载荷 固定N字节]
```

简单，解析快，但浪费带宽（短消息也要填充到固定长度）。

**方案二：变长消息（长度前缀）**

```
[消息长度 4B][消息体 N字节]
```

最常用。发送方先写长度，再写内容；接收方先读长度，再按长度读内容。

**方案三：TLV（Type-Length-Value）**

```
[类型 1B][长度 2B][值 N字节][类型 1B][长度 2B][值 N字节]...
```

灵活，可扩展，Protobuf 就使用类似思想。

### 状态机设计

每个连接都有状态，用**有限状态机（FSM）** 来管理：

```
CLOSED → CONNECTING → AUTHENTICATING → ACTIVE → CLOSING → CLOSED

状态转换：
CLOSED + connect() → CONNECTING
CONNECTING + auth_success → AUTHENTICATING
AUTHENTICATING + auth_ok → ACTIVE
ACTIVE + close() → CLOSING
任意状态 + error/timeout → CLOSING
```

### 错误处理

网络编程中最常被忽视但最重要的部分：

- **超时**：每个 I/O 操作都要有超时。永远不要无限等待。
- **重连**：连接断开后，使用指数退避策略重连（1s, 2s, 4s, 8s...，加随机抖动避免惊群效应）。
- **降级**：后端不可用时返回缓存数据，而非直接报错。

### 版本协商

协议会演进，必须考虑向前兼容：

```
握手阶段：
Client → Server: VERSION_REQUEST supported_versions=[1, 2, 3]
Server → Client: VERSION_RESPONSE selected_version=2
```

## 综合实战项目：简易即时通讯协议

让我们设计并实现一个名为 **SICP（Simple Instant Chat Protocol）** 的即时通讯协议。

### 协议规范

```
SICP v1 协议规范
=================

消息格式：[长度(4B, big-endian)][类型(1B)][载荷(N字节)]

消息类型：
  0x01: CONNECT      - 客户端连接（载荷：用户名）
  0x02: CONNECT_ACK  - 连接确认（载荷：欢迎消息）
  0x03: MESSAGE      - 聊天消息（载荷：JSON {"from":"...", "text":"...", "time":...}）
  0x04: BROADCAST    - 广播消息（载荷：同 MESSAGE）
  0x05: USER_LIST    - 在线用户列表（载荷：JSON 数组）
  0x06: DISCONNECT   - 断开连接（载荷：空）
  0xFF: ERROR        - 错误（载荷：错误消息）

状态机：
  DISCONNECTED → CONNECTING → AUTHENTICATED → CHATTING → DISCONNECTING → DISCONNECTED
```

### Python 服务端实现

```python
"""
SICP Server - 简易即时通讯服务器
运行: python sicp_server.py
"""
import asyncio
import json
import struct
import time
from typing import Dict

# 消息类型常量
CONNECT = 0x01
CONNECT_ACK = 0x02
MESSAGE = 0x03
BROADCAST = 0x04
USER_LIST = 0x05
DISCONNECT = 0x06
ERROR = 0xFF

class SICPServer:
    def __init__(self):
        self.clients: Dict[str, asyncio.StreamWriter] = {}

    def encode_message(self, msg_type: int, payload: bytes) -> bytes:
        """编码 SICP 消息：[长度4B][类型1B][载荷]"""
        body = struct.pack('!B', msg_type) + payload
        length = len(body)
        return struct.pack('!I', length) + body

    async def decode_message(self, reader: asyncio.StreamReader):
        """解码 SICP 消息"""
        # 读取 4 字节长度前缀
        length_bytes = await reader.readexactly(4)
        length = struct.unpack('!I', length_bytes)[0]
        # 读取消息体
        body = await reader.readexactly(length)
        msg_type = body[0]
        payload = body[1:]
        return msg_type, payload

    async def broadcast(self, sender: str, message: dict):
        """广播消息给所有在线用户"""
        payload = json.dumps({
            "from": sender,
            "text": message["text"],
            "time": time.time()
        }).encode()
        msg = self.encode_message(BROADCAST, payload)

        disconnected = []
        for name, writer in self.clients.items():
            if name != sender:
                try:
                    writer.write(msg)
                    await writer.drain()
                except Exception:
                    disconnected.append(name)

        for name in disconnected:
            self.remove_client(name)

    def remove_client(self, name: str):
        if name in self.clients:
            del self.clients[name]
            print(f"[Server] {name} 断开连接，当前在线: {list(self.clients.keys())}")

    async def handle_client(self, reader: asyncio.StreamReader,
                            writer: asyncio.StreamWriter):
        username = None
        try:
            # 等待 CONNECT 消息
            msg_type, payload = await asyncio.wait_for(
                self.decode_message(reader), timeout=10.0)

            if msg_type != CONNECT:
                err = self.encode_message(ERROR, b"Expected CONNECT message")
                writer.write(err)
                await writer.drain()
                writer.close()
                return

            username = payload.decode()
            if username in self.clients:
                err = self.encode_message(ERROR, f"Username '{username}' taken".encode())
                writer.write(err)
                await writer.drain()
                writer.close()
                return

            # 注册客户端
            self.clients[username] = writer
            print(f"[Server] {username} 上线，当前在线: {list(self.clients.keys())}")

            # 发送连接确认
            ack_payload = f"Welcome, {username}! Online users: {len(self.clients)}".encode()
            writer.write(self.encode_message(CONNECT_ACK, ack_payload))

            # 发送用户列表
            user_list = json.dumps(list(self.clients.keys())).encode()
            writer.write(self.encode_message(USER_LIST, user_list))
            await writer.drain()

            # 通知其他用户
            await self.broadcast("SYSTEM", {"text": f"{username} joined the chat"})

            # 消息处理循环
            while True:
                msg_type, payload = await self.decode_message(reader)

                if msg_type == MESSAGE:
                    message = json.loads(payload.decode())
                    await self.broadcast(username, message)
                    print(f"[Chat] {username}: {message['text']}")

                elif msg_type == DISCONNECT:
                    break

        except (asyncio.IncompleteReadError, ConnectionResetError,
                asyncio.TimeoutError):
            pass
        finally:
            if username:
                self.remove_client(username)
                await self.broadcast("SYSTEM",
                                     {"text": f"{username} left the chat"})
            writer.close()

    async def start(self):
        server = await asyncio.start_server(
            self.handle_client, '0.0.0.0', 8888)
        print("[SICP Server] 启动在端口 8888")
        async with server:
            await server.serve_forever()

if __name__ == '__main__':
    server = SICPServer()
    asyncio.run(server.start())
```

### Python 客户端实现

```python
"""
SICP Client - 简易即时通讯客户端
运行: python sicp_client.py
"""
import asyncio
import json
import struct
import sys
import threading

CONNECT = 0x01
CONNECT_ACK = 0x02
MESSAGE = 0x03
BROADCAST = 0x04
USER_LIST = 0x05
DISCONNECT = 0x06
ERROR = 0xFF

class SICPClient:
    def __init__(self, username: str):
        self.username = username
        self.reader = None
        self.writer = None

    def encode_message(self, msg_type: int, payload: bytes) -> bytes:
        body = struct.pack('!B', msg_type) + payload
        return struct.pack('!I', len(body)) + body

    async def decode_message(self):
        length_bytes = await self.reader.readexactly(4)
        length = struct.unpack('!I', length_bytes)[0]
        body = await self.reader.readexactly(length)
        return body[0], body[1:]

    async def connect(self, host='127.0.0.1', port=8888):
        self.reader, self.writer = await asyncio.open_connection(host, port)
        # 发送 CONNECT
        self.writer.write(self.encode_message(CONNECT, self.username.encode()))
        await self.writer.drain()

        # 等待 CONNECT_ACK
        msg_type, payload = await self.decode_message()
        if msg_type == CONNECT_ACK:
            print(f"[Connected] {payload.decode()}")
        elif msg_type == ERROR:
            print(f"[Error] {payload.decode()}")
            sys.exit(1)

    async def receive_loop(self):
        """接收消息循环"""
        try:
            while True:
                msg_type, payload = await self.decode_message()

                if msg_type == BROADCAST:
                    data = json.loads(payload.decode())
                    print(f"\n[{data['from']}]: {data['text']}")
                elif msg_type == USER_LIST:
                    users = json.loads(payload.decode())
                    print(f"[在线用户] {', '.join(users)}")
                elif msg_type == ERROR:
                    print(f"\n[服务器错误] {payload.decode()}")
        except (asyncio.IncompleteReadError, ConnectionResetError):
            print("\n[连接已断开]")

    async def send_message(self, text: str):
        """发送聊天消息"""
        payload = json.dumps({
            "from": self.username,
            "text": text,
            "time": asyncio.get_event_loop().time()
        }).encode()
        self.writer.write(self.encode_message(MESSAGE, payload))
        await self.writer.drain()

    async def run(self):
        await self.connect()
        # 启动接收循环
        receive_task = asyncio.create_task(self.receive_loop())

        # 主循环：读取用户输入并发送
        try:
            loop = asyncio.get_event_loop()
            while True:
                # 在线程中读取输入以避免阻塞事件循环
                text = await loop.run_in_executor(None, input, f"[{self.username}] > ")
                if text.strip() == '/quit':
                    self.writer.write(self.encode_message(DISCONNECT, b''))
                    await self.writer.drain()
                    break
                elif text.strip() == '/users':
                    # 请求用户列表（简化实现）
                    pass
                elif text.strip():
                    await self.send_message(text)
        except (EOFError, KeyboardInterrupt):
            pass
        finally:
            receive_task.cancel()
            self.writer.close()

if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("Usage: python sicp_client.py <username>")
        sys.exit(1)

    client = SICPClient(sys.argv[1])
    asyncio.run(client.run())
```

4. TCP 粘包/拆包是否被正确处理（连续发送多条消息时）

## 总结：协议设计的核心原则

经过这一章的实战，我们可以总结出协议设计的三条核心原则：

**1. 简单（Simplicity）**
协议越简单，实现越容易，bug 越少。SMTP（邮件协议）之所以运行了 40 多年，核心原因就是它足够简单。不要试图在一个协议里解决所有问题。

**2. 明确（Explicitness）**
消息格式、状态转换、错误码都要有明确的规范。"未定义行为"是协议安全的最大敌人。好的协议文档应该让两个独立团队实现出完全兼容的客户端和服务器。

**3. 可扩展（Extensibility）**
协议会演进。预留版本号字段、使用 TLV 格式、定义保留位——这些小细节能让你的协议在未来不需要推倒重来。HTTP 从 1.0 到 1.1 到 2 到 3 的演进，正是可扩展性设计的典范。

最后，记住网络编程的一条铁律：**永远不要假设网络是可靠的**。每一个 `send()` 都可能失败，每一个 `recv()` 都可能超时，每一个连接都可能突然断开。防御性编程不是可选项——它是网络编程的基本功。
