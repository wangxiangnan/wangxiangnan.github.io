# 第15章：实战——制作完整的创业路演PPT 🏆

*路演当天早晨6点，小林被闹钟叫醒。他坐在床边，深呼吸三次，然后打开电脑，最后看了一遍自己的路演PPT。这份PPT，从一个空白文件到现在，陪他度过了两个星期。他从完全不懂PPT的小白，变成了一个能熟练运用母版、动画、图表的人。他学会了配色、排版、演讲技巧，还学会了怎么把PPT安全地分享给别人。现在，只差最后一步——走上那个舞台，把"账本精灵"的故事讲给投资人听。但在那之前，让我们把这份路演PPT的完整制作过程回顾一遍，让它也成为你的作品。*

## 15.1 路演PPT的内容策划：10页黄金结构

一份优秀的创业路演PPT，通常遵循一个被验证过的结构。以下是适合15分钟路演的"10页黄金结构"：

| 页码 | 页面名称 | 核心问题 | 建议时长 |
| ------ | --------- | --------- | --------- |
| 1 | 封面 | 你是谁？做什么？ | 30秒 |
| 2 | 痛点/问题 | 市场存在什么问题？ | 1.5分钟 |
| 3 | 解决方案/产品 | 你怎么解决的？ | 2分钟 |
| 4 | 产品演示/截图 | 产品长什么样？ | 2分钟 |
| 5 | 市场规模 | 这个市场有多大？ | 1.5分钟 |
| 6 | 商业模式 | 你怎么赚钱？ | 1.5分钟 |
| 7 | 竞争优势 | 为什么是你？ | 1分钟 |
| 8 | 运营数据/里程碑 | 你已经做到了什么？ | 1.5分钟 |
| 9 | 团队 | 谁在做这件事？ | 1分钟 |
| 10 | 融资需求 | 要多少钱？怎么花？ | 1.5分钟 |

> 💡 **提示**：这只是一个参考框架，不是死规矩。根据你的项目特点，可以合并某些页面或增加页面。比如技术驱动型项目可以加一页"技术壁垒"，社交类产品可以加一页"用户增长曲线"。但总页数建议控制在10-15页以内，多了投资人会走神。

**策划阶段的三个关键问题**：

在动手制作之前，先拿纸和笔回答这三个问题：

1. **我的听众是谁？**——投资人关心的是回报，所以每一页都应该围绕"为什么投你能赚钱"来展开
2. **我最想传递的一个信息是什么？**——如果投资人只记住一句话，你希望是哪句？（对小林来说是："年轻人不是不记账，是没有好用的记账工具。"）
3. **我希望听众做什么？**——听完路演后，你希望他们做什么？（投资、试用产品、介绍资源？）

## 15.2 从空白开始：按结构创建所有页面

**第一步：新建文件，设置幻灯片大小**

1. 打开PowerPoint，创建空白演示文稿
2. 确认幻灯片大小为16:9（`设计 > 幻灯片大小 > 宽屏16:9`）
3. `Ctrl + S` 保存文件，命名为"账本精灵_融资路演_2026"

**第二步：创建母版**

1. `视图 > 幻灯片母版`
2. 在幻灯片母版上设置：
   - Logo：左上角，"账本精灵"图标，高度1.2cm
   - 页脚：底部居中，"Confidential | 账本精灵科技"，9pt，灰色
   - 页码：右下角
3. 设置主题字体：思源黑体（中文） + Montserrat（英文）
4. 设置主题颜色：品牌蓝 #00B4D8、活力黄 #FFB703、深灰 #2B2D42
5. 创建3个自定义版式："大图+文字"、"数据图表"、"人物卡片"
6. 退出母版视图

**第三步：按结构创建10页空白页**

1. 添加10张幻灯片，分别应用合适的版式
2. 在每页顶部输入页面标题（先不写正文内容）：
   - 第1页：账本精灵（封面）
   - 第2页：年轻人为什么不记账了？
   - 第3页：一款让记账变简单的App
   - 第4页：产品功能一览
   - 第5页：4000亿市场，我们只做了一角
   - 第6页：商业模式
   - 第7页：我们的差异化优势
   - 第8页：增长中的关键数据
   - 第9页：核心团队
   - 第10页：融资计划

> 💡 **提示**：先把骨架搭好，再填充内容。很多人的错误做法是一页一页从头做到尾，做完第3页才发现第1页的方向不对。先搭骨架、确定结构，再逐页填充，效率更高。记住：**好的PPT是改出来的，不是一次做出来的。**

## 15.3 内容撰写：每页写什么、怎么写

这一节是整份PPT的灵魂。设计再好看，内容空洞也是白搭。

**第1页：封面**

```
标题：账本精灵
副标题：AI驱动的智能记账助手
底部：融资路演 | 2026年X月 | 创始人：林XX
```

设计要点：全屏品牌色渐变背景，Logo居中放大，文字白色。简洁有力，3秒内让投资人知道你是谁、做什么。

**第2页：痛点**

```
标题：年轻人为什么不记账了？

三个痛点（配图标）：
📊 手动记账太麻烦 —— 每笔消费手动输入，坚持率不到20%
🧾 账单散落各处 —— 微信、支付宝、银行卡，消费记录分散
💸 不知道钱花哪了 —— 78%的年轻人表示"想记账但不知道从何开始"

底部数据条：
"中国18-35岁人群中，仅22%保持记账习惯"——2025年艾瑞咨询
```

设计要点：三栏布局，每栏一个图标 + 一句话痛点。底部用深色背景条突出数据。

**第3页：解决方案**

```
标题：账本精灵——让记账变得像聊天一样简单

核心理念（大字）：拍一下，记一笔

三个核心功能：
1. 📸 AI识别记账 —— 拍小票/截图账单，AI自动识别金额、分类
2. 🔄 多平台同步 —— 自动关联微信、支付宝、银行账单
3. 💡 消费洞察 —— 每周生成消费报告，告诉你"钱去哪了"
```

设计要点：左侧大文字，右侧手机App截图（mockup）。三个功能用编号+图标+一行描述。

**第4页：产品演示**

```
标题：产品功能一览

展示3个核心界面截图（手机mockup）：
- 界面1：首页记账流程（拍照→识别→保存，3秒完成）
- 界面2：月度消费报告（饼图+柱状图+文字建议）
- 界面3：消费洞察推送（"本周外卖消费占比42%，建议…"）

底部：内测期间用户平均每日记账3.2笔，远超传统记账App的0.8笔
```

设计要点：三个手机mockup并排展示，下方简短说明。让产品自己说话。

**第5页：市场规模**

```
标题：4000亿个人财务管理市场

TAM（全部可触达市场）：4000亿元
——中国个人财务管理及记账工具市场总规模

SAM（可服务市场）：360亿元
——18-35岁城市青年，线上记账工具市场

SOM（可获得市场）：18亿元
——一二线城市，有付费意愿的目标用户
```

设计要点：三个同心圆或漏斗图展示TAM/SAM/SOM，从大到小。用品牌蓝的不同深浅表示层级。

**第6页：商业模式**

```
标题：免费增值 + 订阅收入

收入模型：
┌─────────────────────┐
│ 免费版：基础记账功能    │ ← 获客工具，零门槛
│ 会员版：¥12/月 或 ¥98/年 │ ← 核心收入
│  包含：高级报告、数据导出、AI洞察  │
└─────────────────────┘

预期付费转化率：8%（行业平均5%）
单用户LTV（生命周期价值）：¥156
获客成本（CAC）：¥35
LTV/CAC = 4.5（健康指标）
```

设计要点：用表格或卡片展示免费/付费对比。底部用大数字突出LTV/CAC比例。

**第7页：竞争优势**

```
标题：为什么是我们？

竞争矩阵（2×2表格）：
        | 传统记账App | 账本精灵
记账方式  | 手动输入     | AI自动识别
用户体验  | 繁琐枯燥     | 轻松有趣
数据分析  | 基础报表     | AI消费洞察
付费意愿  | 低（工具感）  | 高（服务感）

我们的护城河：
✅ AI识别准确率98.7%（6个月数据训练）
✅ 用户习惯已养成（平均使用68天）
✅ 先发优势（AI记账赛道目前无头部玩家）
```

设计要点：左侧竞争矩阵表格，右侧三个护城河要点。可以用打钩/打叉图标增强对比感。

**第8页：运营数据**

```
标题：增长中的关键数据

核心指标（大数字展示）：
📱 内测用户：5,200+
📈 月活跃率：68%
🔁 次月留存：72%
⭐ 应用商店评分：4.8/5.0

增长曲线：折线图展示近6个月用户增长趋势
里程碑时间线：
- 2025.09 产品上线内测
- 2025.12 用户突破5000
- 2026.03 获得XX创业大赛亚军
- 2026.06 计划正式上线（融资后）
```

设计要点：上半部分4个大数字指标，下半部分折线图或时间线。数据是最有说服力的内容。

**第9页：团队**

```
标题：核心团队

三个人物卡片并排：
1. 林XX（创始人/CEO）
   头像 + "前XX公司产品经理，5年移动互联网经验，主导过千万级用户产品"

   头像 + "前XX公司高级工程师，AI方向硕士，负责核心识别算法"
```

**第10页：融资需求**

设计要点：左侧大字展示融资金额，右侧饼图展示资金分配。底部联系方式清晰可见。

## 15.4 视觉设计：应用配色、排版、图片

骨架和内容都有了，现在给PPT穿上好看的衣服。

**配色应用**：

- 封面和结尾页使用品牌蓝（#00B4D8）渐变背景 + 白色文字
- 内容页使用白色背景 + 深灰文字（#2B2D42）
- 关键数据和重点数字使用活力黄（#FFB703）突出
- 正向数据（增长、留存）使用成长绿（#8ACB88）
- 图表使用品牌蓝的不同深浅梯度

**排版原则**：

1. **留白**：每页内容不超过页面面积的60%，四周至少留2cm边距
2. **层次**：标题 > 副标题 > 正文 > 注释，用字号和粗细区分层次
   - 页面标题：36-44pt Bold
   - 副标题/关键数据：24-28pt
   - 正文：18-22pt
   - 注释/数据来源：12-14pt 灰色
3. **对齐**：所有元素严格对齐，使用参考线（`视图 > 参考线`）辅助
4. **一致**：所有页面使用相同的标题位置、正文起始位置、Logo位置

**图片处理**：

- 产品截图使用手机mockup框架（可在素材网站下载PSD/PNG mockup）
- 人物照片统一裁剪为圆形或圆角矩形
- 背景图片使用半透明叠加层（插入矩形 > 填充黑色 > 透明度50%）后再叠加文字
- 所有图片确保分辨率足够，避免模糊

> 💡 **提示**：设计阶段是修改最频繁的阶段。不要追求一次做到完美，先做出"够用的版本"，然后反复打磨。好的PPT是改出来的——每一页至少改3遍。

## 15.5 数据呈现：市场数据、财务预测的图表制作

PPT中的数据图表不是简单的"插入图表"，而是要**讲好数据故事**。

**制作市场规模图（第5页）**：

1. `插入 > 图表 > 圆环图`
2. 输入TAM/SAM/SOM三个数据
3. 调整颜色：TAM浅蓝、SAM中蓝、SOM深蓝（品牌蓝）
4. 添加数据标签，显示金额和名称
5. 调整圆环宽度，使三个层级清晰可辨

**制作增长曲线图（第8页）**：

1. `插入 > 图表 > 折线图`
2. 输入6个月的用户数据
3. 设置折线颜色为品牌蓝，线宽3pt
4. 添加数据标记点（圆点）
5. 在关键节点添加注释（比如"产品上线""突破5000用户"）
6. 删除图表默认的网格线和多余的图例，保持简洁

**制作资金用途饼图（第10页）**：

1. `插入 > 图表 > 饼图`
2. 输入三个资金用途及比例
3. 使用品牌蓝、活力黄、灰色三种颜色区分
4. 添加百分比数据标签
5. 在饼图旁边用文字标注具体金额

**图表设计原则**：

| 原则 | 说明 |
| ------ | ------ |
| 一页一图 | 每页最多一个图表，不要堆砌 |
| 删除噪音 | 去掉不必要的网格线、图例、边框 |
| 突出重点 | 用颜色或标注突出你想让投资人注意的数据点 |
| 标题说结论 | 图表标题不要写"用户增长趋势"，要写"用户6个月增长10倍" |
| 标注来源 | 数据底部标注来源（"数据来源：XX报告"），增加可信度 |

> 💡 **提示**：图表的标题应该直接传递结论，而不是描述数据。"用户增长了300%"比"用户数据"更有冲击力。投资人看图表的时间只有3-5秒，标题要帮他们直接get到重点。

## 15.6 动效与切换：为关键页面添加动画

动画不是越多越好，而是要在**正确的地方**使用**正确的动画**。

**为路演PPT设计的动画方案**：

| 页面 | 动画类型 | 具体效果 | 目的 |
| ------ | --------- | --------- | ------ |
| 封面 | 淡入 | 标题和副标题依次淡入 | 营造仪式感 |
| 痛点页 | 逐个出现 | 三个痛点依次出现（点击触发） | 配合演讲节奏 |
| 产品页 | 浮入 | 手机mockup从底部浮入 | 吸引注意力 |
| 数据页 | 擦除 | 折线图从左到右擦除出现 | 模拟增长过程 |
| 融资页 | 缩放 | 融资金额数字缩放出现 | 强调关键信息 |

**页面切换效果**：

- 全局统一使用"淡出"切换，时长0.5秒
- 封面到第2页使用"平滑"切换（制造视觉连续感）
- 不要使用过于花哨的切换效果（如旋转、弹跳、碎片）

**设置步骤**：

1. 选中所有幻灯片（`Ctrl + A` 在左侧缩略图区域）
2. `切换 > 淡出`，持续时间0.5秒
3. 对需要特殊切换的页面单独设置：选中封面页，`切换 > 平滑`
4. 对需要元素动画的页面，逐个添加：
   - 选中元素 > `动画 > 选择效果`
   - 设置触发方式："单击时"（配合演讲翻页）
   - 设置持续时间：0.3-0.5秒

> 💡 **提示**：路演的PPT动画原则——**少即是多**。投资人不会因为你用了炫酷的3D翻转就投你钱，但他们会因为你一页有15个动画而觉得你不专业。动画服务于内容，不是炫技。

## 15.7 最终检查清单：字体、对齐、动画、链接、文件大小

在发送PPT之前，逐项检查以下清单：

**内容检查**：

- [ ] 每页标题无错别字
- [ ] 所有数据准确无误（尤其融资金额、市场数据）
- [ ] 联系方式正确
- [ ] 无多余的空文本框或占位符
- [ ] 每页内容不超过7个要点

**视觉检查**：

- [ ] 所有页面对齐一致（标题位置、正文起始位置）
- [ ] 字体统一（未出现意外的字体变化）
- [ ] 配色统一（未出现非品牌色的意外颜色）
- [ ] 图片清晰，无模糊或拉伸变形
- [ ] 每页有足够的留白

**功能检查**：

- [ ] 所有动画正常播放（逐页测试）
- [ ] 所有超链接可用（点击测试）
- [ ] 嵌入的视频可以播放
- [ ] 图表数据正确显示
- [ ] 页面切换效果一致

**技术检查**：

- [ ] 字体已嵌入（`文件 > 选项 > 保存 > 嵌入字体`）
- [ ] 文件大小合理（目标<30MB，不含视频的话<15MB）
- [ ] PDF版本已导出（作为备份）
- [ ] 在另一台电脑上打开测试（确认无兼容问题）
- [ ] U盘备份已准备

**演讲准备**：

- [ ] 每页演讲者备注已写好
- [ ] 排练计时完成（总时长在目标时间内）
- [ ] 翻页笔电池有电
- [ ] 备份方案已准备（OneDrive链接 + U盘）

> 💡 **提示**：这份检查清单建议你打印出来，每次修改完PPT后对照检查一遍。尤其是"在另一台电脑上测试"这一条——很多问题是换电脑后才发现的。

## 15.8 小林的路演PPT完整效果展示

经过两周的打磨，小林的路演PPT终于完成了。让我们逐页欣赏最终成品：

**第1页 · 封面**

**给读者的进阶建议**：

1. **多看优秀的PPT**：关注演示设计类公众号、浏览SlideShare和Behance上的优秀作品。审美是练出来的，但首先要"养眼"。
2. **做中学**：不要只是看教程，一定要动手做。每学一个技巧，立刻打开PPT试一试。
3. **给自己找真实项目**：帮朋友做PPT、帮公司做汇报PPT、给自己的爱好做展示PPT——真实需求是最好的学习动力。
4. **接受不完美**：你的前10份PPT一定不够好，这很正常。每一份都比上一份好一点，就是进步。
5. **保持更新**：PPT软件会持续更新新功能（尤其是AI相关功能），保持学习和探索的心态。
