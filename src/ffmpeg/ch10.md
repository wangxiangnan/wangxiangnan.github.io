# 第10章：视频缩放与裁剪——画面变形记

手机拍的竖屏视频想在横屏电视上看？4K 视频想压缩到 1080p 节省空间？想把电影画面裁剪成 16:9 去掉上下黑边？本章将教会你所有关于画面尺寸的操作。

## 10.1 缩放分辨率：scale 滤镜

**基本缩放：**

```bash
# 缩放到 1280x720
ffmpeg -i input.mp4 -vf "scale=1280:720" output.mp4

# 使用 -s 参数（效果相同）
ffmpeg -i input.mp4 -s 1280x720 output.mp4
```

> 💡 提示：`-vf "scale=w:h"` 是更推荐的写法，因为后面可以和别的滤镜组合使用。

**缩放并指定编码器参数：**

```bash
ffmpeg -i input_4k.mp4 -vf "scale=1920:1080" -c:v libx264 -crf 23 -c:a copy output_1080p.mp4
```

## 10.2 智能缩放：保持宽高比

手动计算宽高比很烦。FFmpeg 提供了智能方式：

**宽度自适应，高度固定 720：**

```bash
ffmpeg -i input.mp4 -vf "scale=-2:720" output.mp4
```

`-2` 表示"自动计算宽度，并确保是 2 的倍数"（很多编码器要求宽高为偶数）。

**高度自适应，宽度固定 1280：**

```bash
ffmpeg -i input.mp4 -vf "scale=1280:-2" output.mp4
```

**限制最大尺寸（不放大）：**

```bash
# 如果原视频大于 1080p，缩到 1080p；如果小于 1080p，保持不变
ffmpeg -i input.mp4 -vf "scale='min(1920,iw)':'min(1080,ih)':force_original_aspect_ratio=decrease" output.mp4
```

> 💡 提示：永远不要用 `scale=-1:720`（用 -1），有些编码器对奇数宽高会报错。用 `-2` 更安全。

## 10.3 常用缩放预设

```bash
# 720p (HD)
ffmpeg -i input.mp4 -vf "scale=-2:720" output_720p.mp4

# 1080p (Full HD)
ffmpeg -i input.mp4 -vf "scale=-2:1080" output_1080p.mp4

# 1440p (2K)
ffmpeg -i input.mp4 -vf "scale=-2:1440" output_2k.mp4

# 2160p (4K)
ffmpeg -i input.mp4 -vf "scale=-2:2160" output_4k.mp4

# 480p (标清)
ffmpeg -i input.mp4 -vf "scale=-2:480" output_480p.mp4
```

**缩放到指定宽度，按比例计算高度：**

```bash
# 缩放到宽度 640，高度自动
ffmpeg -i input.mp4 -vf "scale=640:-2" output.mp4
```

**缩放算法选择：**

```bash
# 使用 lanczos 算法（高质量，默认）
ffmpeg -i input.mp4 -vf "scale=1280:720:flags=lanczos" output.mp4

# 使用 bicubic 算法（较快）
ffmpeg -i input.mp4 -vf "scale=1280:720:flags=bicubic" output.mp4

# 使用 fast_bilinear（最快，质量较低）
ffmpeg -i input.mp4 -vf "scale=1280:720:flags=fast_bilinear" output.mp4
```

可用缩放算法（质量从高到低）：`lanczos` > `spline` > `bicubic` > `bilinear` > `fast_bilinear`

## 10.4 画面裁剪：crop 滤镜

**基本语法：`crop=宽:高:X起点:Y起点`**

```bash
# 从画面中心裁剪出 640x480 的区域
ffmpeg -i input.mp4 -vf "crop=640:480" output.mp4
```

不指定 X、Y 时，默认从画面中心裁剪。

**指定裁剪位置：**

```bash
# 从左上角 (100, 50) 开始，裁剪 640x480
ffmpeg -i input.mp4 -vf "crop=640:480:100:50" output.mp4
```

## 10.5 裁剪实战

**去除上下黑边：**

假设视频是 1920x1080，上下各有 140 像素黑边：

```bash
ffmpeg -i input.mp4 -vf "crop=1920:800:0:140" output.mp4
```

解释：宽度保持 1920，高度 1080-140-140=800，X 从 0 开始，Y 从 140 开始（跳过上方黑边）。

**自动检测并去除黑边：**

```bash
ffmpeg -i input.mp4 -vf "cropdetect" -f null -t 10 NUL
```

FFmpeg 会分析前 10 秒画面，输出检测到的裁剪参数，然后你可以用这个参数执行真正的裁剪。

**提取画面局部（比如只保留右边一半）：**

```bash
ffmpeg -i input.mp4 -vf "crop=iw/2:ih:iw/2:0" output.mp4
```

`iw` = 输入宽度，`ih` = 输入高度。`iw/2` 就是一半宽度。

## 10.6 旋转与翻转

**旋转 90 度（顺时针）：**

```bash
ffmpeg -i input.mp4 -vf "transpose=1" output.mp4
```

**旋转 90 度（逆时针）：**

```bash
ffmpeg -i input.mp4 -vf "transpose=2" output.mp4
```

**旋转 180 度：**

```bash
ffmpeg -i input.mp4 -vf "transpose=2,transpose=2" output.mp4
```

transpose 参数说明：

- `0`：逆时针 90 度 + 垂直翻转
- `1`：顺时针 90 度
- `2`：逆时针 90 度
- `3`：顺时针 90 度 + 垂直翻转

**水平翻转（镜像）：**

```bash
ffmpeg -i input.mp4 -vf "hflip" output.mp4
```

**垂直翻转（上下颠倒）：**

```bash
ffmpeg -i input.mp4 -vf "vflip" output.mp4
```

**组合使用——顺时针旋转 90 度 + 水平翻转：**

```bash
ffmpeg -i input.mp4 -vf "transpose=1,hflip" output.mp4
```

> 💡 提示：手机竖拍的视频在电脑上可能是横着的。用 `transpose=1` 或 `transpose=2` 旋转回来。有些播放器会自动旋转，但文件本身没变，上传到某些平台可能方向就不对了。

## 10.7 宽高比的概念与转换

视频领域有三种宽高比概念：

- **DAR（Display Aspect Ratio）**：显示宽高比，观众看到的实际比例，如 16:9
- **SAR（Storage Aspect Ratio）**：存储宽高比，像素数量的比例，如 1920:1080 = 16:9
- **PAR（Pixel Aspect Ratio）**：像素宽高比，单个像素的宽高比

关系：`DAR = SAR × PAR`

大多数现代视频 PAR = 1:1（方形像素），所以 DAR = SAR。但老旧的 DVD 视频可能有非方形像素。

**设置显示宽高比（不改变像素，只改元数据）：**

```bash
ffmpeg -i input.mp4 -aspect 16:9 -c copy output.mp4
```

**强制方形像素（修复变形视频）：**

```bash
ffmpeg -i input.mp4 -vf "scale=iw*sar:ih,setsar=1:1" output.mp4
```

## 10.8 pad 滤镜：加边适配

当你需要把 4:3 的视频放到 16:9 的屏幕上，又不想拉伸变形，可以加黑边（或白边）。

**上下加黑边（letterbox）：**

```bash
# 将视频放入 1920x1080 画布中央，四周补黑边
ffmpeg -i input.mp4 -vf "pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black" output.mp4
```

`ow` = 输出宽度，`oh` = 输出高度，`iw` = 输入宽度，`ih` = 输入高度。

**加白边：**

```bash
ffmpeg -i input.mp4 -vf "pad=1920:1080:(ow-iw)/2:(oh-ih)/2:white" output.mp4
```

**智能适配——自动计算并填充：**

```bash
# 将任意视频适配到 1920x1080，保持比例，补黑边
ffmpeg -i input.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2" output.mp4
```

这条命令先缩放到不超过 1920x1080 的最大尺寸（保持比例），然后用黑边填充到正好 1920x1080。

> 💡 提示：这个"缩放 + pad"组合是处理不同分辨率视频统一输出的标准方案。批量处理用户上传的视频时特别有用。

## 10.9 超分辨率：AI 放大视频（简介）

FFmpeg 本身不内置 AI 超分模型，但可以通过外部工具实现：

**使用 Real-ESRGAN（需要单独安装）：**

```bash
# 先用 FFmpeg 提取所有帧
ffmpeg -i input.mp4 -qscale:v 1 frames/frame_%04d.png

# 用 Real-ESRGAN 放大每一帧（需单独安装工具）
realesrgan-ncnn-vulkan -i frames -o frames_upscaled -n realesrgan-x4plus

# 将放大后的帧合成视频
ffmpeg -i frames_upscaled/frame_%04d.png -i input.mp4 -map 0:v -map 1:a -c:v libx264 -crf 18 output_upscaled.mp4
```

> ⚠️ 注意：AI 超分辨率非常耗时（每帧可能需要数秒），且需要 GPU 支持。对于日常使用，普通的 lanczos 缩放已经足够好。

## 本章小结

- `scale=-2:720` 是智能缩放的黄金写法，自动保持宽高比
- `crop` 从中心裁剪是默认行为，指定 x:y 可以精确控制裁剪区域
- `transpose` 旋转、`hflip/vflip` 翻转，可以链式组合
- `pad` 滤镜配合 `scale` 可以将任意视频适配到目标尺寸
