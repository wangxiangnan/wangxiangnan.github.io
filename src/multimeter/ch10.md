# 第10章 测电容：充放电背后的好坏判别

制冰机最近闹脾气。每天早上开机，压缩机"嗡嗡"两声，然后就不动了，多按几次启动键才勉强转起来，冰块产量直线下降，顾客的冰沙都差点供应不上。小王网上查了一圈，看到最多的诊断是"启动电容老化"。他拆开制冰机后盖，果然在压缩机旁边找到一只圆滚滚的圆柱形元件——上面印着"25µF 450VAC"。这就是电容？

更让他心里发毛的是，维修视频里的老师傅给开关电源换电容之前，都要拿螺丝刀往大电容两个引脚上一搭——"啪！"一串火花，弹幕一片"物理超度"。那玩意儿断电之后居然还带电！小王决定把电容的脾气彻底摸透：它到底怎么存电？怎么放电？怎么判断好坏？

本章就来讲电容——电路里的蓄水池，以及万用表测电容的全套姿势。

## 10.1 电容是什么：电路里的蓄水池

电容的结构简单得惊人：两块金属板，中间隔一层绝缘介质。通电后，正电荷堆在一块板上，负电荷堆在另一块板上，两块板隔着介质互相吸引、互相"拉住"，电就存住了。它就像电路里的蓄水池：池子存水，电容存电荷；电容的"容量"（单位法拉，符号F）就是池子的容积——同样的水压下容积越大存水越多，同样的电压下容量越大存的电荷越多（电荷量Q＝容量C×电压U）。

法拉这个单位太大，日常见到的电容都是它的零头：微法（µF，百万分之一法）、纳法（nF，十亿分之一法）、皮法（pF，万亿分之一法）。1微法＝1000纳法＝1000000皮法。

电容有个著名脾气："隔直通交"。为什么直流电过不去？电容充满后，电压与电源持平，电流就停了——蓄水池满了，水自然不再往里流。为什么交流电却能"通过"？交流电方向来回变，相当于一会儿往里灌水、一会儿往外抽水，充放电的电流持续流动。更有画面感的类比：在蓄水池中间隔一张橡皮膜，从一边持续推水，膜鼓过去，水流就停了（隔直）；来回推拉，膜来回鼓，两边的水跟着来回涌动（通交）。记住这张"橡皮膜蓄水池"，后面所有现象都好懂。

## 10.2 充放电过程：蓄水池的进水和放水

给电容充电时（串联一个电阻），一开始电容是空的，两端电压为零，与电源的电压差最大，充电电流最大；随着电容电压升高，电压差越来越小，电流越来越小——这是一个"自己拖自己后腿"的过程，所以充电电压沿一条指数曲线上升：经过1个时间常数时充到63%，3个时间常数到95%，5个时间常数到99%（工程上算充满）。放电同理，电压沿指数曲线下降。

时间常数τ＝R×C：电阻越大、容量越大，充放电越慢。为什么是这个公式？因为电流大小取决于"还剩多少要充"，剩得越少充得越慢，这种自我减速的规律在数学上就是指数，而减速的快慢由"管子粗细（电阻）"和"池子大小（容量）"共同决定。用蓄水池想：往空池子放水，水位差大、水流猛；快满时水流细若游丝。池子越大、管子越细，放满越慢——τ就是"池子×管子"的乘积。

这个"先猛后缓"的规律，就是万用表测电容的原理基础：我们不看它最终状态，只看它"爬坡"的过程。

## 10.3 用电阻档粗测电容：看数字爬坡

数字万用表的电阻档内部相当于"小水泵+压力表"：它向被测对象输出一个小电流，同时测两端的电压，然后按"电压÷电流"报出电阻。把电容接上去，等于水泵往空蓄水池里灌水：刚接上时电容两端电压接近0，算出的"电阻"很小，读数从接近0开始；随着电容被充电、两端电压不断升高，"电压÷电流"算出的"电阻"越来越大，读数一路往上爬，最后超出量程显示OL。

为什么数字从小到大？因为仪表把"电容被充电、电压升高"的过程，算成了"电阻在变大"。这正是我们想看的：电容健康的标志就是"会爬坡"。容量越大，爬坡越慢、越明显（池子大，灌满需要时间）；容量越小，爬坡越快，小到一定程度就"唰"地一下到OL，肉眼根本看不清。

指针表上的对应现象是：表针向右猛摆一下（冲到接近0Ω），再慢慢退回无穷大。指针表欧姆档相当于电池串内阻，充电电流先大后小，表针就跟着"先冲后回"——同样是"先猛后缓"的充电过程。

判读口诀：①读数从低爬到OL＝好；②读数停在0附近不动＝内部短路（池底漏了，永远灌不满）；③接上就OL、纹丝不动＝开路（注意：小容量电容正常也这样，所以这招对大电解电容才有效）；④爬坡速度明显比同规格新电容快很多＝容量衰减，该换了。测量时用小电阻档（如20kΩ档）测大电解，换档或重新测量前，记得先把电容放电。

## 10.4 电容档直接测容量：一读便知

粗测只能定性，要定量还得用电容档。现在大多数数字表都有电容档（档位符号是F，有的带专用插孔）：放电后把电容接到表笔或插孔上，屏幕直接读出容量。读数与外壳标称值比较：电解电容允许±20%的误差，新电容读数略高于标称是正常的；明显低于标称（低于80%）就是老化衰减。

为什么测电容前必须先放电？三条理由，条条要命：①安全——大电容存的是真电荷，断电后电压可能还有几百伏，摸一下比摸电门还狠；②保护仪表——电容带着高电压插进电容档，瞬间大电流可能把表内电路烧穿；③读数准确——电容档靠"灌电流、看电压"来算容量，电容里已有残压，算出来的全是糊涂账。"先放电"是测电容的铁律，没有例外。

怎么放电？小电容：拿表笔或导线短接一下即可。大电容（尤其电源板上的几百伏大电解）：必须通过电阻慢慢放，比如用100欧到1千欧的大功率电阻或白炽灯泡搭在电容两端，等电压归零再动手。为什么不能直接短路？放电电流＝电压÷导线电阻，几百伏除以零点几欧，瞬间电流上千安——火花四溅、烫坏触点、损伤电容内部，甚至炸壳。就像泄洪不能拿铁棍堵闸口，得打开泄洪道慢慢放。

## 10.5 极性电容与无极性电容

电解电容（最常见的大圆柱）：用化学方法在铝箔表面"长"出一层极薄的氧化膜当绝缘层，所以体积小、容量大，是电容界的"大胃王"。但氧化膜是有方向的：接反了会被电解破坏，漏电、发热、鼓包，严重时直接爆炸。外壳上标着负极（一条带"-"号的竖道或箭头），长脚是正极。无极性电容（陶瓷电容、薄膜电容）：介质是普通绝缘材料，不分正负，随便接。规律：电源滤波、储能这些直流场合用大电解（有极性）；电机启动、音箱分频这些交流场合用无极性电容。制冰机那只"25µF 450VAC"就是无极性启动电容（标注VAC正说明它工作在交流下）。

## 10.6 好坏判断：三看一测

一看外观：顶部鼓包、裂口（俗称"怀孕"）、漏液、外壳变色——直接判死刑。这是电解电容最常见的死法，鼓包说明内部产气、氧化膜已崩。

二看容量：电容档读数远低于标称，或显示OL（开路）——容量衰减是"慢性病"，容量掉太多，电机起不来、电源滤波变差、设备间歇性抽风。

三看短路：电阻档测两脚之间接近0Ω——击穿短路，通常伴随烧保险、跳闸。

最后看"顶不顶用"：容量读数正常但设备还是不正常，可能是ESR（等效串联电阻）变大——可以理解为电容内部偷偷串了个电阻，存电不少但放电没劲，关键时刻供不出大电流。普通万用表测不了ESR，诀窍是拿一只同规格新电容对比，或直接替换试验。制冰机启动电容容量衰减，压缩机就"嗡嗡"起不来；换一只容量、耐压都一致的新电容，制冰机满血复活——小王亲测有效。

## 10.7 常见错误与注意事项

1. 不放电就测、就摸——本章头号危险动作。带电的大电容就是一颗小蓄电池。
2. 用螺丝刀直接短路大电容放电——火花伤元件伤自己，务必用电阻或灯泡慢慢放。
3. 电解电容极性接反——反接本身就是伤害，测之前先看清负极标记。
4. 手捏着电容引脚测容量——人体电容会并进去，皮法级小电容直接测不准。
5. 在路测量——旁边元件并联影响结果，拆下一只脚再测。
6. 换电容只看容量不看耐压——容量、耐压都必须大于等于原规格，耐压不够等于埋雷。

## 10.8 本章小结

电容是"蓄水池"：两块极板隔着绝缘介质存电荷，容量是池子容积，充放电遵循"先猛后缓"的指数规律。电阻档测电容就是看充电过程——读数从低爬到OL是好电容，停在0是短路，纹丝不动是开路。电容档能直接读出容量，但测前必须放电：为了安全、护表、读数准。电解电容有极性、接反会鼓包爆炸；判断好坏靠"三看一测"：看外观、看容量、看短路，再怀疑ESR时用替换法验证。

## 10.9 练习题

1. 为什么用数字万用表电阻档测好电容时，读数会从接近0一路爬到OL？
2. 测电容前为什么要先放电？直接短路大电容放电有什么危险？
3. 电阻档测一只电解电容，读数停在0Ω附近不动。这只电容出了什么问题？
4. 一只标称1000µF的电解电容，电容档测出830µF。算正常还是老化？（电解电容允许±20%误差）
5. 一只电解电容顶部鼓包，但容量读数正常。还能继续用吗？为什么？

**参考答案：**

1. 电阻档输出的小电流给电容充电，开始电容两端电压低、算出的"电阻"小；电容越充越满、电压越高，"电压÷电流"算出的"电阻"越大，最后超出量程显示OL。
2. 大电容存有残压：不放电会触电、会烧表、会读数不准。直接短路放电时电流＝电压÷导线电阻，可达上千安，产生火花、损伤元件甚至爆炸，应通过电阻或灯泡放电。
3. 内部击穿短路（读数接近0且不变，说明电流一直很大，电容永远充不满）。
4. 830µF是标称值的83%，在±20%误差范围内，属于正常。
5. 不能。鼓包说明内部氧化膜已损坏、产生气体，随时可能漏液甚至炸裂，即使当前容量读数正常也必须更换。
