# 第13章：滤镜系统入门

> [!TIP] Part 3: 进阶魔法（滤镜与特效篇）
> 欢迎来到 FFmpeg 最迷人的领域——滤镜与特效。如果说 Part 1 让你认识了 FFmpeg 这位"瑞士军刀"，Part 2 教会了你日常切菜削皮，那么 Part 3 将带你进入"分子料理"的世界。在这里，你可以把平淡的视频调出电影感色调，给音频做"微整形"，实现画中画、绿幕抠图、故障艺术……甚至用命令行做出让甲方满意的片头动画。

滤镜是 FFmpeg 的灵魂。掌握了滤镜，你就从一个"格式转换工具人"进化为"视频炼金术士"。准备好了吗？让我们开始这场视觉与听觉的魔法之旅。

如果你以为 FFmpeg 只是个"格式转换器"，那就像以为 Photoshop 只能裁剪图片一样。FFmpeg 内置了一套强大到令人窒息的滤镜系统——**avfilter 库**，它拥有超过 **400 个滤镜**，覆盖了视频处理、音频处理、色彩校正、特效合成等几乎所有你能想到的多媒体操作。本章将为你打开这扇大门，让你理解滤镜系统的整体架构，为后续章节的"花式操作"打下坚实基础。

## 13.1 avfilter 库：滤镜的宇宙

avfilter 是 FFmpeg 的四大核心库之一（另外三个是 avcodec、avformat、avdevice）。它的设计哲学是**模块化**和**可组合**——每个滤镜就像一个乐高积木，单独使用可以完成一个简单任务，组合起来却能搭建出惊人的复杂效果。

avfilter 中的滤镜按功能可以分为四大类：

| 类别 | 说明 | 典型代表 |
| ------ | ------ | --------- |
| **source** | 信号源滤镜，生成视频/音频流 | `color`（纯色画面）、`testsrc`（测试图案）、`sine`（正弦波音频） |
| **video** | 视频处理滤镜 | `scale`、`overlay`、`eq`、`drawtext` |
| **audio** | 音频处理滤镜 | `volume`、`afade`、`loudnorm`、`aecho` |
| **sink** | 输出端滤镜（通常隐式使用） | `buffersink`（通常不需要手动指定） |

你可以用以下命令查看你当前 FFmpeg 版本支持的所有滤镜：

```bash
ffmpeg -filters
```

这会输出一长串列表。如果你只想看视频滤镜：

```bash
ffmpeg -filters | grep " V"
```

只看音频滤镜：

```bash
ffmpeg -filters | grep " A"
```

> **小贴士**：`ffmpeg -filters` 输出中，`V` 代表视频滤镜，`A` 代表音频滤镜，`T` 代表支持时间线（timeline）控制——即可以通过 `enable` 参数按时间启用/禁用。

## 13.2 简单滤镜链：一条线性的魔法流水线

最简单的滤镜使用方式是通过 `-vf`（视频滤镜）或 `-af`（音频滤镜）参数，将多个滤镜用逗号串联起来：

```bash
# 简单滤镜链：缩放 → 调整亮度 → 添加文字
ffmpeg -i input.mp4 -vf "scale=1280:720,eq=brightness=0.1,drawtext=text='Hello':fontsize=48:fontcolor=white:x=100:y=100" output.mp4
```

**数据流动方向**是从左到右：原始帧先进入 `scale` 滤镜进行缩放，缩放后的帧进入 `eq` 调整亮度，最后经过 `drawtext` 添加文字。

### 滤镜参数传递方式

FFmpeg 支持两种参数传递方式：

**命名参数**（推荐，可读性更好）：

```bash
ffmpeg -i input.mp4 -vf "eq=brightness=0.06:contrast=1.2:saturation=1.3" output.mp4
```

**位置参数**（简短但容易搞混）：

```bash
# eq 滤镜的前三个位置参数依次是：brightness, contrast, gamma
ffmpeg -i input.mp4 -vf "eq=0.06:1.2:1.0" output.mp4
```

> **强烈建议**：始终使用命名参数。滤镜参数多的可能有十几个，位置参数只有写命令的人（也许就是三天后的你自己）才能看懂。命名参数就像代码里的关键字参数，是自文档化的好习惯。

### 特殊字符转义

当滤镜参数中包含冒号、逗号等特殊字符时，需要转义。比如 `drawtext` 中的文字包含冒号：

```bash
# 使用反斜杠转义
ffmpeg -i input.mp4 -vf "drawtext=text='Time\: 12\:00':fontsize=36" output.mp4

# 或者用单引号包裹整个参数值（某些 shell 下需要注意嵌套）
```

## 13.3 Filtergraph：从链条到网络

简单滤镜链（`-vf`/`-af`）本质上是一条**线性流水线**——一个输入、一条处理链、一个输出。但很多时候你需要更复杂的拓扑结构，比如：

- 同时处理多个输入源（画中画需要两个视频输入）
- 一个流需要被多条路径使用（比如原始视频既要直接输出，又要加一层模糊做背景）
- 音频和视频需要交叉处理

这时候就需要**复杂滤镜图（Filtergraph）**，使用 `-filter_complex` 参数。

### 简单滤镜链 vs 复杂滤镜图

| 特性 | 简单滤镜链 (`-vf`/`-af`) | 复杂滤镜图 (`-filter_complex`) |
| ------ | -------------------------- | ------------------------------- |
| 输入数量 | 仅 1 个 | 可多个 |
| 拓扑结构 | 线性链 | 任意有向图 |
| 流标签 | 不支持 | 支持 `[label]` 语法 |
| 音视频交叉 | 不支持 | 支持 |
| 使用难度 | 低 | 中高 |

## 13.4 复杂滤镜图：-filter_complex 语法

复杂滤镜图用分号 `;` 分隔不同的滤镜节点，用方括号 `[...]` 定义的**流标签**连接它们：

```bash
ffmpeg -i input1.mp4 -i input2.mp4 \
  -filter_complex "[0:v][1:v]overlay=10:10[out]" \
  -map "[out]" output.mp4
```

让我们拆解这个命令：

- `[0:v]` —— 第 1 个输入文件的视频流
- `[1:v]` —— 第 2 个输入文件的视频流
- `overlay=10:10` —— 将两个视频流叠加，小窗口位于 (10, 10) 位置
- `[out]` —— 叠加后的输出流，取名为 "out"
- `-map "[out]"` —— 将 "out" 流映射到输出文件

### 流标签（Stream Labels）详解

流标签是复杂滤镜图的"血管"，负责在各个节点之间传输数据：

```
[输入编号:流类型]
```

- `[0:v]` —— 第 1 个输入的视频流（`0` 是输入索引，`v` 表示视频）
- `[0:a]` —— 第 1 个输入的音频流
- `[1:v]` —— 第 2 个输入的视频流
- `[0:v:0]` —— 第 1 个输入的第 1 条视频流（多视频流时有用）

自定义中间标签可以用任意名称：

```bash
-filter_complex "[0:v]scale=640:360[scaled];[scaled][1:v]overlay[out]"
```

这里 `[scaled]` 是我们给缩放后的中间流取的名字，它作为 `overlay` 的输入。

### 多节点复杂滤镜图示例

```bash
ffmpeg -i main.mp4 -i logo.png -i bgm.mp3 \
  -filter_complex "\
    [0:v]scale=1280:720[main];\
    [1:v]scale=200:-1[logo];\
    [main][logo]overlay=W-w-10:10[video];\
    [2:a]volume=0.3[bgm_quiet];\
    [0:a][bgm_quiet]amix=inputs=2[audio]" \
  -map "[video]" -map "[audio]" output.mp4
```

这个命令同时做了四件事：缩放主视频、缩放 Logo、叠加 Logo 到右上角、混合原始音频和背景音乐。这就是复杂滤镜图的威力——一次处理，一步到位。

## 13.5 滤镜性能：认识你的 CPU 杀手

不是所有滤镜都"平等"。有些滤镜轻量得几乎不占资源，有些则能让你的 CPU 风扇狂转、笔记本变成暖手宝。

| 性能等级 | 滤镜 | 说明 |
| --------- | ------ | ------ |
| 🟢 轻量 | `scale`, `crop`, `pad`, `format`, `setpts`, `fade` | 简单的像素搬运，速度很快 |
| 🟡 中等 | `eq`, `colorbalance`, `overlay`, `drawtext`, `volume` | 需要逐像素计算，但算法简单 |
| 🔴 重量 | `nlmeans`, `minterpolate`, `vidstabdetect`, `unsharp`, `hqdn3d` | 涉及多帧分析或复杂算法 |
| 💀 黑洞 | `minterpolate`（高质量模式）、`nlmeans`（大 patch 尺寸） | 可能需要数倍甚至数十倍时间 |

**性能优化建议**：

1. **先轻后重**：先用 `scale` 缩小分辨率，再做降噪等重计算。处理 640x360 比 1920x1080 快得多。
2. **善用 `-preset` 和 `-crf`**：滤镜处理后的编码质量同样重要，选择合适的编码参数避免瓶颈在编码端。
3. **考虑 GPU 加速**：部分滤镜有 CUDA/OpenCL 版本，如 `scale_cuda`、`unsharp_opencl`。

## 13.6 时间线控制：enable 参数

很多滤镜支持 `enable` 参数，允许你按时间条件启用或禁用滤镜。这是创建"部分效果"的利器。

```bash
# 只在第 5 秒到第 10 秒之间调整亮度
ffmpeg -i input.mp4 -vf "eq=brightness=0.2:enable='between(t,5,10)'" output.mp4
```

`enable` 参数接受一个表达式，常用函数包括：

| 函数 | 说明 | 示例 |
| ------ | ------ | ------ |
| `between(t, start, end)` | t 在 start 和 end 之间 | `enable='between(t,5,10)'` |
| `gte(t, value)` | t 大于等于 value | `enable='gte(t,3)'`（3秒后启用） |
| `lte(t, value)` | t 小于等于 value | `enable='lte(t,5)'`（前5秒启用） |
| `mod(t, period)` | t 对 period 取模 | `enable='lt(mod(t,4),2)'`（每4秒中的前2秒启用） |
| `if(cond, true, false)` | 条件判断 | 用于更复杂的逻辑 |

```bash
# 每隔 2 秒闪烁一次水印
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=enable='lt(mod(t,4),2)'" \
  output.mp4
```

## 13.7 调试滤镜：看见你的魔法在起效

滤镜调试的关键原则是：**小步快跑，逐步验证**。

### 1. 先用短视频测试

不要上来就对一个 2 小时的电影做实验。先截取一小段：

```bash
# 先截取 10 秒测试片段
ffmpeg -i input.mp4 -ss 30 -t 10 -c copy test_clip.mp4

# 在测试片段上调试滤镜
ffmpeg -i test_clip.mp4 -vf "eq=brightness=0.1:contrast=1.2" test_output.mp4
```

### 2. 使用 ffplay 实时预览

`ffplay` 是 FFmpeg 自带的播放器，支持实时应用滤镜：

```bash
# 实时预览滤镜效果（不需要等待编码）
ffplay -i input.mp4 -vf "eq=brightness=0.1:contrast=1.2"

# 预览复杂滤镜图
ffplay -i input.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:10"
```

### 3. 逐步构建滤镜链

不要一次写 10 个滤镜然后祈祷它能工作。每加一个滤镜就测试一次：

```bash
# Step 1: 只测试缩放
ffmpeg -i input.mp4 -vf "scale=1280:720" step1.mp4

# Step 2: 加调色
ffmpeg -i input.mp4 -vf "scale=1280:720,eq=brightness=0.1" step2.mp4

# Step 3: 加文字
ffmpeg -i input.mp4 -vf "scale=1280:720,eq=brightness=0.1,drawtext=text='Test'" step3.mp4
```

### 4. 查看滤镜可用参数

```bash
# 查看 eq 滤镜的所有参数和默认值
ffmpeg -h filter=eq

# 查看 overlay 滤镜的所有参数
ffmpeg -h filter=overlay
```

这个命令会列出滤镜的每个参数、类型、默认值和取值范围，是你最可靠的参考手册。

## 本章小结

本章我们揭开了 FFmpeg 滤镜系统的面纱：

- **avfilter 库**包含 400+ 滤镜，分为 source、video、audio、sink 四类
- **简单滤镜链**（`-vf`/`-af`）是线性的处理流水线，适合单输入单输出
- **复杂滤镜图**（`-filter_complex`）支持多输入、多分支、任意拓扑结构
- **流标签**（如 `[0:v]`、`[out]`）是复杂滤镜图的连接"血管"
- **性能差异巨大**，轻量滤镜几乎无感，重量滤镜可能慢到怀疑人生
- **enable 参数**让滤镜可以按时间条件启用/禁用
- **调试秘诀**：先截短片、用 ffplay 预览、逐步构建、善用 `ffmpeg -h filter=xxx`
