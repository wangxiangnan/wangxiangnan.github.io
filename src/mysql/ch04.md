# 第4章 SELECT 查询进阶

> 如果说基础SELECT是查字典，那进阶查询就是写论文——你需要精确地筛选、排列、切割数据，才能得到想要的结果。

## 4.1 WHERE 条件过滤

WHERE是查询的"筛选器"，帮你从海量数据中精准定位目标。

### 比较运算符

```sql
-- 等于
SELECT * FROM products WHERE category_id = 1;

-- 不等于
SELECT * FROM products WHERE category_id != 1;
SELECT * FROM products WHERE category_id <> 1;  -- 等价写法

-- 大于/小于
SELECT * FROM products WHERE price > 5000;
SELECT * FROM products WHERE stock <= 10;

-- 安全等于（NULL安全比较）
SELECT * FROM users WHERE phone <=> NULL;  -- phone IS NULL时返回true
```

### 逻辑运算符

```sql
-- AND：同时满足
SELECT * FROM products
WHERE category_id = 1 AND price < 8000 AND stock > 0;

-- OR：满足其一
SELECT * FROM users
WHERE status = 'active' OR status = 'inactive';

-- NOT：取反
SELECT * FROM products
WHERE NOT category_id IN (1, 2, 3);

-- 组合使用（注意优先级：NOT > AND > OR）
SELECT * FROM products
WHERE (category_id = 1 OR category_id = 2)
  AND price BETWEEN 1000 AND 5000
  AND is_active = 1;
```

> [!TIP] 提示
> 当有多个OR条件作用于同一列时，用`IN`替代会更清晰，性能也更好。

### BETWEEN

```sql
-- 数值范围（包含边界值）
SELECT * FROM products WHERE price BETWEEN 1000 AND 5000;
-- 等价于：WHERE price >= 1000 AND price <= 5000

-- 日期范围
SELECT * FROM orders
WHERE created_at BETWEEN '2024-01-01' AND '2024-01-31 23:59:59';
```

> [!WARNING] 注意
> `BETWEEN`是**包含边界值**的（相当于`>=`和`<=`）。日期查询时，`BETWEEN '2024-01-01' AND '2024-01-31'`只包含到1月31日的00:00:00，不包含当天的其他时间。建议用`>= '2024-01-01' AND < '2024-02-01'`代替。

### IN

```sql
-- 在列表范围内
SELECT * FROM products WHERE category_id IN (1, 2, 3, 5);

-- NOT IN
SELECT * FROM products WHERE category_id NOT IN (4, 6);

-- 子查询中的IN
SELECT * FROM users
WHERE id IN (
  SELECT DISTINCT user_id
  FROM orders
  WHERE total_amount > 10000
);
```

> [!WARNING] 注意
> `NOT IN`遇到NULL值会有意外行为。如果子查询结果中包含NULL，`NOT IN`会返回空结果集。建议用`NOT EXISTS`替代，或者加上`WHERE ... IS NOT NULL`过滤。

### LIKE 与通配符

```sql
-- % 匹配任意数量的字符
SELECT * FROM products WHERE name LIKE '%iPhone%';   -- 包含iPhone
SELECT * FROM users WHERE email LIKE '%@gmail.com';  -- Gmail用户

-- _ 匹配单个字符
SELECT * FROM users WHERE username LIKE 'a___';  -- 4个字符且以a开头

-- 转义特殊字符
SELECT * FROM products WHERE name LIKE '%10\%%';  -- 包含"10%"

-- NOT LIKE
SELECT * FROM products WHERE name NOT LIKE '%二手%';
```

> [!WARNING] 注意
> `LIKE '%xxx%'`（前面有%）无法使用索引，会导致全表扫描。在大数据量场景下，考虑使用全文索引（FULLTEXT）或Elasticsearch。

### IS NULL

```sql
-- 查找NULL值
SELECT * FROM users WHERE phone IS NULL;

-- 查找非NULL值
SELECT * FROM users WHERE phone IS NOT NULL;

-- COALESCE：NULL值的默认替代
SELECT
  username,
  COALESCE(phone, '未填写') AS phone_display
FROM users;

-- IFNULL：MySQL特有函数（只能接收两个参数）
SELECT IFNULL(phone, '未填写') AS phone_display FROM users;
```

## 4.2 ORDER BY：排序

```sql
-- 单列排序（默认升序ASC）
SELECT * FROM products ORDER BY price ASC;

-- 降序
SELECT * FROM products ORDER BY price DESC;

-- 多列排序：先按分类升序，再按价格降序
SELECT * FROM products
ORDER BY category_id ASC, price DESC;

-- 按表达式排序
SELECT * FROM products
ORDER BY price * stock DESC;  -- 按库存总价值排序

-- 按FIELD自定义顺序
SELECT * FROM products
ORDER BY FIELD(category_id, 3, 1, 2, 5, 4);

-- NULL值排序（MySQL中NULL在ASC时排在最前，DESC时排在最后）
-- 想让NULL排在最后：
SELECT * FROM products
ORDER BY ISNULL(sort_order), sort_order ASC;
```

## 4.3 LIMIT 与 OFFSET 分页

分页是Web开发中最常见的功能之一：

```sql
-- 取前10条
SELECT * FROM products ORDER BY id LIMIT 10;

-- 第2页（跳过前10条，取10条）
SELECT * FROM products ORDER BY id LIMIT 10 OFFSET 10;
-- 简写形式
SELECT * FROM products ORDER BY id LIMIT 10, 10;

-- 通用分页公式
-- LIMIT (page - 1) * page_size, page_size
-- 第5页，每页20条
SELECT * FROM products ORDER BY id LIMIT 80, 20;
```

> [!WARNING] 注意
> `OFFSET`在大数据量时性能很差！`LIMIT 1000000, 10`意味着MySQL要先扫描1000010条记录，然后丢弃前1000000条。对于深分页，推荐使用"游标分页"（基于上一页最后一条的ID）：

```sql
-- 低效：深分页
SELECT * FROM products ORDER BY id LIMIT 1000000, 10;

-- 高效：游标分页（记住上一页最后的id）
SELECT * FROM products
WHERE id > 1000000  -- 上一页最后一条的id
ORDER BY id
LIMIT 10;
```

## 4.4 实用查询函数

```sql
-- 字符串函数
SELECT
  CONCAT(first_name, ' ', last_name) AS full_name,
  UPPER(username) AS upper_name,
  LENGTH(email) AS email_len,
  SUBSTRING(email, 1, 3) AS email_prefix,
  REPLACE(email, '@', '[at]') AS masked_email
FROM users;

-- 日期函数
SELECT
  NOW() AS now,
  CURDATE() AS today,
  DATE_FORMAT(created_at, '%Y年%m月%d日') AS formatted_date,
  DATEDIFF(NOW(), created_at) AS days_since_created,
  DATE_ADD(created_at, INTERVAL 30 DAY) AS expire_date
FROM users;

-- 条件表达式
SELECT
  name,
  price,
  CASE
    WHEN price > 5000 THEN '高端'
    WHEN price > 1000 THEN '中端'
    ELSE '入门'
  END AS price_level,
  IF(stock > 0, '有货', '缺货') AS availability
FROM products;
```

## 小结

本章我们深入学习了WHERE的各种条件过滤、ORDER BY排序技巧、LIMIT分页的最佳实践，以及一些实用的查询函数。重点记住：LIKE前缀%不走索引、OFFSET深分页性能差、NOT IN小心NULL值。
