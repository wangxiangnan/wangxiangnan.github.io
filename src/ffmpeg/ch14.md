# 第14章：视频滤镜——画面调色盘

如果说滤镜系统是 FFmpeg 的魔法学校，那视频滤镜就是学校里最热门的"变形术"专业。一个平淡无奇的视频素材，经过调色、降噪、稳像、变速等一系列操作后，可以焕发完全不同的视觉生命力。本章将带你掌握 FFmpeg 中最实用的视频滤镜，让你成为手持调色盘的"命令行达芬奇"。

## 14.1 色彩调整：eq 滤镜——你的基础调光台

`eq` 是英文 equalizer（均衡器）的缩写，它是最常用的色彩调整滤镜，可以一站式调整亮度、对比度、饱和度和伽马值。

```bash
ffmpeg -i input.mp4 -vf "eq=brightness=0.06:contrast=1.2:saturation=1.3:gamma=1.0" output.mp4
```

**参数详解**：

| 参数 | 默认值 | 范围 | 效果说明 |
| ------ | -------- | ------ | --------- |
| `brightness` | 0 | -1.0 ~ 1.0 | 正值变亮，负值变暗。0.06 大约是"稍微提亮一点" |
| `contrast` | 1.0 | -1000 ~ 1000 | 大于 1 增强对比度，小于 1 降低。1.2 是"略有质感" |
| `saturation` | 1.0 | 0 ~ 3.0 | 0 变灰度，大于 1 更鲜艳，1.3 是"微暖色调" |
| `gamma` | 1.0 | 0.1 ~ 10.0 | 调整中间调亮度，不影响纯黑和纯白 |

**适用场景**：手机拍的视频太暗？对比度不够？颜色发灰？`eq` 是你的第一选择。它就像相机里的"自动增强"按钮，但给你完全手动控制权。

**实用配方**：

```bash
# "电影感"调色：微降饱和度、提高对比度、略压暗
ffmpeg -i input.mp4 -vf "eq=brightness=-0.03:contrast=1.15:saturation=0.85" output.mp4

# "清新明亮"Vlog 风：提亮、增加饱和度
ffmpeg -i input.mp4 -vf "eq=brightness=0.08:contrast=1.05:saturation=1.2" output.mp4

# 黑白效果：饱和度归零
ffmpeg -i input.mp4 -vf "eq=saturation=0" output.mp4
```

## 14.2 curves 滤镜：Photoshop 级别的曲线调色

如果你用过 Photoshop 或 Lightroom 的曲线工具，`curves` 滤镜会让你倍感亲切。它通过控制 RGB 曲线的控制点来实现精细的色调调整。

```bash
# 经典 S 曲线：压暗阴影 + 提亮高光 = 增强对比度
ffmpeg -i input.mp4 -vf "curves=m='0/0 0.25/0.15 0.75/0.85 1/1'" output.mp4
```

**参数说明**：

- `m`：主曲线（Master，整体亮度）
- `r`：红色通道
- `g`：绿色通道
- `b`：蓝色通道
- `all`：同时应用到所有通道

曲线的格式是 `x1/y1 x2/y2 x3/y3 ...`，每个点用 `/` 分隔 x（输入）和 y（输出），取值范围 0-1。

```bash
# 暖色调：提升红色通道中间调，降低蓝色通道
ffmpeg -i input.mp4 -vf "curves=r='0/0 0.5/0.6 1/1':b='0/0 0.5/0.4 1/1'" output.mp4

# 经典电影橙青色调：阴影偏青，高光偏橙
ffmpeg -i input.mp4 -vf "curves=r='0/0 0.5/0.55 1/1':g='0/0 0.5/0.5 1/1':b='0/0.05 0.5/0.45 1/0.9'" output.mp4
```

**适用场景**：当你需要比 `eq` 更精细的色彩控制时使用。比如"只想调整中间调不影响高光和阴影"，或者"想要某种特定的色调风格"。曲线调色是专业调色师的基本功，在 FFmpeg 中也能实现。

## 14.3 colorbalance：色温调整

`colorbalance` 专门用于调整画面的色温，可以分别对阴影（shadows）、中间调（midtones）、高光（highlights）进行红-青、绿-品红、蓝-黄的偏移。

```bash
# 整体偏暖（增加红色和黄色）
ffmpeg -i input.mp4 -vf "colorbalance=rs=0.15:gs=-0.05:bs=-0.15" output.mp4
```

**参数命名规则**：`{颜色}{区域}`

- 颜色前缀：`r`（红-青）、`g`（绿-品红）、`b`（蓝-黄）
- 区域后缀：`s`（阴影）、`m`（中间调）、`h`（高光）

```bash
# 让阴影偏蓝，高光偏黄（经典电影色调）
ffmpeg -i input.mp4 -vf "colorbalance=bs=0.2:bh=-0.2" output.mp4
```

**适用场景**：修正白平衡不准的视频、营造冷暖色调氛围。比如室内灯光偏黄的视频，可以用 `colorbalance` 回调至自然色温。

## 14.4 lut3d：应用 3D LUT——电影色调预设

3D LUT（Look-Up Table）是专业影视后期中的"调色预设文件"，通常以 `.cube` 或 `.3dl` 为扩展名。你可以把 LUT 理解为"一个复杂的色彩映射表"——输入一个颜色，LUT 告诉你应该输出什么颜色。

```bash
# 应用 .cube 格式的 3D LUT
ffmpeg -i input.mp4 -vf "lut3d=file=cinematic_warm.cube" output.mp4
```

**常用 LUT 格式**：`.cube`（最通用）、`.3dl`、`.dat`

**适用场景**：你从网上下载了电影调色预设（LUT 文件），想一键应用。很多摄影师和 Vlogger 会在 DaVinci Resolve 或 Premiere 里使用 LUT，FFmpeg 同样支持。

> **小贴士**：如果你没有 LUT 文件但又想获得电影色调，可以组合使用 `curves` + `colorbalance` + `eq` 手动调出一个效果，然后把这个命令当作你的"命令行 LUT"。

## 14.5 降噪滤镜：让画面更干净

视频降噪是后期处理中的常见需求，尤其是低光环境下拍摄的视频往往布满噪点。

### hqdn3d：高质量 3D 降噪

```bash
ffmpeg -i input.mp4 -vf "hqdn3d=luma_spatial=4:chroma_spatial=3:luma_tmp=6:chroma_tmp=4.5" output.mp4
```

| 参数 | 默认值 | 说明 |
| ------ | -------- | ------ |
| `luma_spatial` | 4 | 亮度空间降噪强度 |
| `chroma_spatial` | 3 | 色度空间降噪强度 |
| `luma_tmp` | 6 | 亮度时间降噪强度（跨帧） |
| `chroma_tmp` | 4.5 | 色度时间降噪强度 |

### nlmeans：非局部均值降噪（质量更高但更慢）

```bash
# nlmeans 降噪效果更好，但速度可能慢 10-50 倍
ffmpeg -i input.mp4 -vf "nlmeans=s=3:p=7:pc=5:r=9:rc=5" output.mp4
```

**选择建议**：

- **快速处理**或降噪要求不高 → `hqdn3d`
- **追求质量**且不怕等待 → `nlmeans`
- **实时预览** → `hqdn3d`（`nlmeans` 基本无法实时播放）

## 14.6 锐化滤镜：unsharp

降噪会让画面变"软"（丢失细节），这时候需要锐化来补救。`unsharp` 是最常用的锐化滤镜。

```bash
# 默认参数：5x5 矩阵，亮度锐化强度 1.0
ffmpeg -i input.mp4 -vf "unsharp=5:5:1.0:5:5:0.0" output.mp4
```

**参数格式**：`lx:ly:la:cx:cy:ca`

- `lx:ly` —— 亮度矩阵尺寸（奇数，如 3、5、7）
- `la` —— 亮度锐化强度（0-1.5，负值为模糊）
- `cx:cy` —— 色度矩阵尺寸
- `ca` —— 色度锐化强度

```bash
# 轻度锐化（适合人像，避免过度锐化导致皮肤粗糙）
ffmpeg -i input.mp4 -vf "unsharp=3:3:0.8:3:3:0.0" output.mp4

# 模糊效果（负值 = 模糊）
ffmpeg -i input.mp4 -vf "unsharp=7:7:-1.5" output.mp4
```

**适用场景**：视频看起来"肉肉的"不够清晰、降噪后细节丢失、想增强画面质感。

## 14.7 去隔行：yadif 和 bwdif

如果你的视频素材来自老式摄像机或电视信号，画面可能出现"拉丝"现象（隔行扫描的特征）。去隔行滤镜可以将隔行视频转换为逐行视频。

```bash
# yadif（Yet Another DeInterlacing Filter）— 最经典的去隔行滤镜
ffmpeg -i input.mp4 -vf "yadif=mode=0" output.mp4

# bwdif（Bob Weaver Deinterlacing Filter）— 更高质量
ffmpeg -i input.mp4 -vf "bwdif=mode=0" output.mp4
```

| mode | 说明 |
| ------ | ------ |
| 0 | 每帧输出一帧（帧率不变） |
| 1 | 每帧输出两场（帧率翻倍，运动更流畅） |
| 2 | 每帧输出一帧（仅输出奇数场） |
| 3 | 每帧输出一帧（仅输出偶数场） |

**适用场景**：处理 DVD 翻录、老电视录制、旧摄像机素材时，画面有横向拉丝条纹。

## 14.8 视频稳像：vidstabdetect + vidstabtransform

手持拍摄的视频往往有抖动，FFmpeg 提供了两步法稳像方案：

**第一步：分析运动轨迹**

```bash
ffmpeg -i input.mp4 -vf "vidstabdetect=stepsize=6:shakiness=8:accuracy=9:result=motion.trf" -f null -
```

- `stepsize`：运动检测步长（越小越精确，默认 6）
- `shakiness`：抖动程度估计（1-10，越大认为越抖，默认 4）
- `accuracy`：检测精度（1-15，默认 15）
- `result`：输出分析文件路径

注意 `-f null -` 表示不输出视频，只做分析。

**第二步：应用稳定变换**

```bash
ffmpeg -i input.mp4 -vf "vidstabtransform=input=motion.trf:smoothing=10:optalgo=vs:maxshift=100:maxangle=10:zoom=2" output.mp4
```

- `smoothing`：平滑帧数（默认 10，越大越平滑但画面裁切越多）
- `maxshift`：最大位移像素（默认 -1 即不限制）
- `maxangle`：最大旋转角度（弧度，默认 -1）
- `zoom`：放大百分比以补偿边缘黑边（默认 0）

**适用场景**：手持行走拍摄、运动相机、无人机在风中拍摄等有抖动的视频。

> **注意**：稳像会裁切画面边缘（因为需要移动画面来补偿抖动），`zoom` 参数可以放大画面以消除黑边，但会损失一些分辨率。

## 14.9 变速滤镜：setpts

`setpts`（Set Presentation Time Stamp）通过修改帧的时间戳来实现视频变速效果。

```bash
# 2 倍速播放（时间戳减半）
ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" output.mp4

# 0.5 倍速慢动作（时间戳翻倍）
ffmpeg -i input.mp4 -vf "setpts=2.0*PTS" output.mp4
```

**原理**：`PTS` 是每一帧的显示时间戳。将 PTS 乘以 0.5，帧与帧之间的时间间隔减半，播放速度就变成了 2 倍。

**注意**：`setpts` 只改变视频帧的时间戳，不会改变帧数。2 倍速会"跳过"一半帧（通过调整时间戳），0.5 倍速会让每帧显示时间翻倍，但不会有新的中间帧生成，所以慢动作可能看起来"卡顿"。

如果需要丝滑的慢动作，需要配合帧插值滤镜 `minterpolate`（见 14.11 节）。

### 动态变速

```bash
# 前 5 秒正常速度，之后 2 倍速
ffmpeg -i input.mp4 -vf "setpts='if(lt(t,5),PTS,0.5*PTS+2.5)'" output.mp4
```

## 14.10 帧率转换：fps 和 minterpolate

### fps：简单的帧率转换

```bash
# 将 60fps 视频转换为 30fps（每隔一帧丢弃一帧）
ffmpeg -i input.mp4 -vf "fps=30" output.mp4

# 将 24fps 转为 60fps（简单复制帧，可能不流畅）
ffmpeg -i input.mp4 -vf "fps=60" output.mp4
```

### minterpolate：运动补偿帧插值

`minterpolate` 是帧插值的"核武器"，它通过分析前后帧的运动矢量来生成中间帧，效果远优于简单的帧复制。

```bash
# 将 24fps 插值到 60fps（丝滑慢动作的秘密）
ffmpeg -i input.mp4 -vf "minterpolate=fps=60:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1" output.mp4
```

| 参数 | 说明 |
| ------ | ------ |
| `fps` | 目标帧率 |
| `mi_mode` | 插值模式：`mci`（运动补偿插值，质量最好） |
| `mc_mode` | 运动补偿模式：`aobmc`（自适应，质量最好但最慢） |
| `me_mode` | 运动估计：`bidir`（双向，更准确） |
| `vsbmc` | 可变块大小运动补偿（1=启用） |

> **警告**：`minterpolate` 是 FFmpeg 中**最慢的滤镜之一**。一段 10 秒的 1080p 视频从 24fps 插值到 60fps，在普通 CPU 上可能需要 10-30 分钟。建议先用低分辨率测试。

**适用场景**：制作丝滑慢动作视频、将电影 24fps 转为流畅的 60fps。

## 14.11 色彩空间转换：colorspace 和 format

`format` 滤镜用于转换像素格式：

```bash
# 转换为 yuv420p（兼容性最好的格式）
ffmpeg -i input.mp4 -vf "format=yuv420p" output.mp4

# 转换为 RGB（某些滤镜需要 RGB 输入）
ffmpeg -i input.mp4 -vf "format=rgb24" output.mp4
```

`colorspace` 滤镜用于转换色彩空间：

```bash
# 从 BT.709 转换到 BT.2020（HDR 工作流）
ffmpeg -i input.mp4 -vf "colorspace=all=bt2020" output.mp4
```

**常见场景**：某些播放器播放视频颜色异常，往往是色彩空间标记不正确导致的。

## 14.12 淡入淡出：fade 滤镜

`fade` 可以实现画面的淡入（从黑/白渐变到正常画面）和淡出（从正常画面渐变到黑/白）。

```bash
# 视频开头 2 秒淡入
ffmpeg -i input.mp4 -vf "fade=t=in:st=0:d=2" output.mp4

# 视频最后 3 秒淡出（假设视频总长 60 秒）
ffmpeg -i input.mp4 -vf "fade=t=out:st=57:d=3" output.mp4

# 同时淡入淡出
ffmpeg -i input.mp4 -vf "fade=t=in:st=0:d=2,fade=t=out:st=57:d=3" output.mp4
```

| 参数 | 说明 |
| ------ | ------ |
| `t` / `type` | `in`（淡入）或 `out`（淡出） |
| `st` / `start_time` | 开始时间（秒） |
| `d` / `duration` | 持续时间（秒） |
| `color` | 淡入淡出的目标颜色（默认 black，可设为 white 或其他颜色） |

**适用场景**：Vlog 开头/结尾的渐变效果、多个片段之间的过渡、MV 中的场景转换。

> **小技巧**：如果想做白色淡入（常见于梦境/回忆场景），设置 `color=white`：
>
> ```bash
> ffmpeg -i input.mp4 -vf "fade=t=in:st=0:d=2:color=white" output.mp4
> ```

## 本章小结

本章我们学习了 FFmpeg 视频滤镜中最核心的调色与画面处理工具：

- **eq**：亮度/对比度/饱和度/伽马一站调整，最基础的调色工具
- **curves**：曲线调色，实现精细的色调控制
- **colorbalance**：色温调整，分别控制阴影/中间调/高光
- **lut3d**：应用 3D LUT 预设文件，一键电影色调
- **hqdn3d / nlmeans**：视频降噪，让画面更干净
- **unsharp**：锐化/模糊，控制画面细节
- **yadif / bwdif**：去隔行，处理老式视频素材
- **vidstab**：两步法视频稳像，拯救抖动画面
- **setpts**：视频变速
- **minterpolate**：运动补偿帧插值，丝滑慢动作
- **fade**：淡入淡出效果

下一章，我们将转向声音的世界——音频滤镜。毕竟，一个好的视频不仅要有好看的画面，还要有好听的声音。
