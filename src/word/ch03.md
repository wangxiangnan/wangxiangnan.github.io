# 第3章：文字与段落格式——让文档清晰易读 📖

*小王把开业公告打印出来贴在店门口，结果路过的人看了一眼就走了——为什么？因为所有文字都一样大，密密麻麻挤在一起，根本分不清哪里是标题、哪里是正文、哪里是优惠信息。小王的老妈路过时说了一句："儿子，你这公告跟讣告似的，黑压压一片。"小王受到了一万点暴击，决定好好学习排版。这一章，我们就来教你怎么让文档"看起来舒服"。*

## 3.1 字体设置：字体、字号、加粗、斜体、颜色

打开 `开始` 选项卡，左侧就是"字体"功能组，这是你调整文字外观的主战场。

**核心字体设置**：

| 设置项 | 说明 | 快捷键 |
| -------- | ------ | -------- |
| 字体 | 选择字体（宋体、黑体、微软雅黑等） | 无 |
| 字号 | 文字大小（中文常用"号"，也可用"磅"） | 无 |
| 加粗 | 让文字更醒目 | `Ctrl + B` |
| 斜体 | 强调（中文较少使用） | `Ctrl + I` |
| 下划线 | 强调（注意和超链接区分） | `Ctrl + U` |
| 字体颜色 | 改变文字颜色 | 无 |
| 突出显示 | 类似荧光笔效果 | 无 |

**字号对照**：
中文文档中常用"号"来表示字号，这里给一个实用对照：

| 名称 | 磅值 | 常见用途 |
| ------ | ------ | --------- |
| 初号 | 42磅 | 极少用 |
| 小初 | 36磅 | 封面大标题 |
| 一号 | 26磅 | 大标题 |
| 二号 | 22磅 | 章标题 |
| 三号 | 16磅 | 节标题 |
| 四号 | 14磅 | 小标题 |
| 小四 | 12磅 | 正文（偏大） |
| 五号 | 10.5磅 | 正文（常用） |
| 小五 | 9磅 | 注释、脚注 |

> 💡 **提示**：正文一般用五号（10.5磅）或小四（12磅），标题用三号或四号。字号差距至少2级才能让层次分明——比如正文五号，标题就用三号，别正文五号标题也用五号只加个粗，区分度太低。

## 3.2 中文文档推荐字体搭配

选字体就像穿衣服——不是越花哨越好，而是要协调、得体、易读。

**推荐搭配方案**：

| 文档类型 | 标题字体 | 正文字体 | 适用场景 |
| --------- | --------- | --------- | --------- |
| 正式文档 | 黑体 / 方正小标宋 | 宋体 / 仿宋 | 合同、公文、制度文件 |
| 商务文档 | 微软雅黑（加粗） | 微软雅黑 / 等线 | 方案、报告、手册 |
| 轻松活泼 | 微软雅黑 | 微软雅黑 | 内部通知、活动公告 |

**几个重要原则**：

- **一份文档不要超过3种字体**——标题一种、正文一种，顶多加一种特殊用途
- **正文避免用艺术字体**——看着酷但读着累
- **中文字体不要用"Arial""Times New Roman"**——这些是英文字体，对中文字符无效（或者会回退到默认字体，效果不可控）

> 💡 **提示**：如果你不知道用什么字体，就用"微软雅黑全家桶"——标题微软雅黑加粗，正文微软雅黑常规。简洁大方，不会出错。小王的奶茶店文档统一用微软雅黑，清爽又现代。

## 3.3 段落对齐：左对齐、居中、右对齐、两端对齐

对齐方式决定了文字在页面上的"站位"，在 `开始 > 段落` 分组中设置。

| 对齐方式 | 快捷键 | 适用场景 |
| --------- | -------- | --------- |
| 左对齐 | `Ctrl + L` | 默认对齐，正文最常用 |
| 居中 | `Ctrl + E` | 标题、封面、公告 |
| 右对齐 | `Ctrl + R` | 日期、签名、联系方式 |
| 两端对齐 | `Ctrl + J` | 正式文档正文（推荐） |

**两端对齐 vs 左对齐**：
两端对齐会让每一行的左右边缘都对齐（最后一行除外），文档看起来更整齐。中文文档推荐使用两端对齐，因为中文方块字天生适合两端对齐，效果比英文好得多。

> 💡 **提示**：千万不要用空格键来"手动对齐"文字！比如想让标题居中，不要在前面敲一堆空格——用"居中对齐"按钮就行。空格对齐在不同电脑上显示效果不同，打印出来也会歪歪扭扭。这个坏习惯必须从一开始就杜绝。

## 3.4 行距与段间距：为什么你的文档看起来"挤"

这是很多人忽略但影响巨大的设置。行距太密，读者看得喘不过气；行距太松，文档像水文。

**行距（行与行之间的距离）**：
在 `开始 > 段落` 分组中点击"行和段落间距"按钮（图标是几行横线加上下箭头）。

| 行距设置 | 效果 | 推荐用途 |
| --------- | ------ | --------- |
| 单倍行距 | 很紧凑 | 不推荐用于正式文档 |
| 1.15倍 | 略宽松 | 内部文档 |
| 1.5倍 | ✅ 舒适 | 推荐用于大多数文档正文 |
| 2倍 | 很宽松 | 论文、需要大量批注的文档 |

**段间距（段落与段落之间的距离）**：
在 `布局 > 段落` 或右键段落选择"段落"设置。

- **段前**：段落上方的空白距离
- **段后**：段落下方的空白距离

推荐设置：段后 0.5行 到 1行，让段落之间有"呼吸空间"。

> 💡 **提示**：又一个绝对不要用空格键的场景——不要用"多敲几个回车"来增加段落间距！这样做会产生多个空段落，格式不可控，而且在不同电脑上显示不一样。正确的做法是设置段间距数值。记住这条铁律：**空格键不管排版，回车键不管间距。**

## 3.5 首行缩进与悬挂缩进

中文文档有一个传统：每段第一行缩进两个字符。这个效果怎么实现？

**❌ 错误做法**：在每段开头敲两个空格。
**✅ 正确做法**：设置首行缩进。

操作方法：

1. 选中需要缩进的段落
2. 右键选择"段落"
3. 在"特殊格式"下拉框中选择"首行缩进"
4. 磅值设为"2字符"

也可以在标尺上拖动滑块来设置（但对初学者不太推荐，容易不精确）。

**什么是悬挂缩进？**
悬挂缩进和首行缩进正好相反——第一行不缩进，后面的行缩进。常用于参考文献列表、联系方式列表等。

```
首行缩进效果：
  这是第一行缩进了两个字符的文字。
这是第二行，不缩进，顶格写。

悬挂缩进效果：
这是第一行，顶格不缩进。
  这是后面的行，全部缩进两个字符。
  也是缩进的，整整齐齐。
```

> 💡 **提示**：首行缩进设置一次就够了——选中所有正文段落，一次性设置"首行缩进2字符"。然后配合格式刷（后面会讲）快速应用到其他段落。再次强调：**不要在段首敲空格来模拟缩进**！

## 3.6 项目符号与编号列表

当你要列举一系列内容时（比如奶茶店的菜单分类、员工守则条目），列表比纯文字清晰得多。

**项目符号列表（无序列表）**：
适用于不需要排序的列举。

- 操作方法：选中文字，点击 `开始 > 段落 > 项目符号` 按钮
- 可以自定义符号：圆点、方块、菱形、自定义图片等

**编号列表（有序列表）**：
适用于有顺序的列举。

- 操作方法：选中文字，点击 `开始 > 段落 > 编号` 按钮
- 可以自定义编号格式：1. 2. 3. / 一、二、三 / a) b) c) 等

**多级列表**：
适用于分层次的列举（比如员工手册的章节结构）。

- 操作方法：`开始 > 段落 > 多级列表`
- 按 `Tab` 键可以降低层级，按 `Shift + Tab` 可以提升层级

**实战示例**——小王的奶茶店员工守则：

```
1. 工作纪律
   1.1 按时到岗，不迟到不早退
   1.2 工作期间不玩手机
   1.3 保持工作区域整洁
2. 服务规范
   2.1 微笑服务，热情待客
   2.2 出杯前确认饮品名称
   2.3 主动询问客户甜度冰量
3. 卫生标准
   3.1 每日营业前清洁设备
   3.2 原料开封后标注日期
   3.3 每周进行一次深度清洁
```

> 💡 **提示**：列表的缩进量可以通过标尺上的滑块调整，也可以在右键"调整列表缩进"中精确设置。默认缩进有时候太大，可以适当调小。

## 3.7 格式刷：快速复制格式

格式刷是Word里最"偷懒"的功能——它能把一个地方的格式"刷"到另一个地方，省去重复设置的麻烦。

**使用方法**：

1. 选中已经设好格式的文字（比如标题）
2. 点击 `开始 > 剪贴板 > 格式刷`（图标是一把刷子）
3. 用刷子去"刷"（选中）需要同样格式的文字
4. 刷完后格式就复制过去了

**单击 vs 双击格式刷**：

- **单击**：刷一次后格式刷自动关闭
- **双击**：格式刷会一直保持激活状态，可以连续刷多个地方，直到按 `Esc` 或再次点击格式刷按钮取消

> 💡 **提示**：当你要给文档中10个不同位置的小标题设置同样的格式时，双击格式刷然后逐一刷过去，比一个一个手动设置快10倍。小王的员工手册里有20多条守则，全靠格式刷统一格式。

## 3.8 清除格式：当格式乱了怎么办

有时候从网上复制的内容格式乱得不行，或者自己改来改去改乱了。这时候"清除格式"就是你的救命稻草。

**操作方法**：

1. 选中需要清除格式的文字
2. 点击 `开始 > 字体 > 清除所有格式`（图标是一个带橡皮擦的A）
3. 所有字体、颜色、大小等格式全部恢复为默认

**注意**：清除格式会把所有字符级别的格式都去掉，只保留段落级别的格式（对齐、缩进等）。清除后你需要重新设置想要的格式。

**替代方案**：

- 如果只需要清除部分格式，可以选中后直接重新设置字体和字号——新设置会覆盖旧设置
- `Ctrl + 空格` 可以清除选中文字的字符格式（恢复为默认字体）
- `Ctrl + Q` 可以清除选中文字的段落格式（恢复为默认段落设置）

> 💡 **提示**：遇到格式怎么调都不对的情况，不要死磕——先清除格式，再从头设置，往往比在乱格式上修修补补快得多。这就像代码写乱了不如重构一样。

## 3.9 实战：排版奶茶店的员工入职须知

来，我们用这一章学到的所有技能，帮小王把员工入职须知排版得漂漂亮亮。

**原文（未排版，纯文字）**：

```
茶里茶气 员工入职须知

欢迎加入茶里茶气大家庭！为了让你尽快融入团队，请仔细阅读以下须知。

一、工作时间
早班：9:30-17:30
晚班：14:00-22:00
请提前10分钟到岗做准备。

二、着装要求
统一穿着店内提供的工服。保持整洁，不佩戴夸张饰品。长发需扎起。

三、薪资发放
每月15日发放上月工资，遇节假日提前发放。试用期3个月，工资为正式的80%。

四、请假制度
事假需提前1天申请。病假需提供医院证明。每月可请假2天，超出按旷工处理。

茶里茶气
2025年3月
```

**排版步骤**：

**第一步：设置页面基础**（下一章会详细讲，这里先简单设置）

- `布局 > 页边距 > 普通`（默认即可）

**第二步：设置标题**

- 选中"茶里茶气 员工入职须知"
- 字体：微软雅黑，二号，加粗
- 对齐：居中
- 段后间距：1行

**第三步：设置欢迎语**

- 选中欢迎语段落
- 字体：微软雅黑，五号
- 首行缩进：2字符
- 行距：1.5倍
- 字体颜色：灰色（不要太黑，和正文有区分）

**第四步：设置章节标题（一、二、三、四）**

- 逐一选中每个章节标题
- 字体：微软雅黑，四号，加粗
- 段前间距：0.5行，段后间距：0.5行
- （或使用格式刷：设好第一个，双击格式刷，刷其余三个）

**第五步：设置正文内容**

- 选中所有正文段落
- 字体：微软雅黑，五号
- 首行缩进：2字符
- 行距：1.5倍
- 段后间距：0.5行

**第六步：设置落款**

- 选中"茶里茶气"和日期
- 对齐：右对齐
- 段前间距：2行（和正文拉开距离）

排版完成后，这份入职须知就从"一坨文字"变成了"一份正式文件"。同样的内容，排版不同，专业感天差地别。

## 本章小结

| 知识点 | 要点 |
| -------- | ------ |
| 字体设置 | 字号用"号"或"磅"，正文五号/小四，标题大三号以上 |
| 字体搭配 | 一份文档不超3种字体，推荐微软雅黑全家桶 |
| 段落对齐 | 正文用两端对齐，标题可居中，日期右对齐 |
| 行距段间距 | 正文推荐1.5倍行距，段后0.5-1行 |
| 首行缩进 | 用段落设置，绝不用空格键模拟 |
| 项目符号/编号 | 无序用项目符号，有序用编号，分层用多级列表 |
| 格式刷 | 单击刷一次，双击连续刷，快速统一格式 |
| 清除格式 | 格式乱了先清除再重设，比修补更快 |

## 练习题

1. **【基础】** 打开上一章写的开业公告，运用本章所学知识给它排版：标题居中加粗、正文两端对齐、行距1.5倍、首行缩进。完成后和排版前对比效果。

2. **【进阶】** 撰写一份奶茶店的"每日开店流程"（至少8个步骤），使用编号列表排版，然后给列表设置自定义编号格式（如"步骤一、步骤二……"）。

3. **【挑战】** 从网上找一篇排版混乱的文章复制到Word中，先"清除格式"，然后自己从零开始排版：设置标题、正文、行距、缩进。全程不能使用空格键来对齐或缩进。
