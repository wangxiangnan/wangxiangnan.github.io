# 第6章：投影——向量的"影子"

## 故事引入

小王的奶茶店门口有一条笔直的主干道（小王把它定义为 x 轴）。骑手们从店铺出发，沿着各种方向配送。

小王突然好奇：每条配送路线在主干道上到底"占了多少距离"？比如骑手小赵的路线是往东北方向走的，但他在主干道上实际跑了多远？

这个问题本质上是在问：一个向量在另一个向量方向上的**投影**有多长？

## 几何直觉

想象太阳挂在天空中，光线沿着向量 **b** 的方向照下来。向量 **a** 是一根竖在地上的棍子。

棍子 **a** 在地面上投下的影子，就是 **a** 在 **b** 方向上的投影。

- 如果 **a** 和 **b** 方向一致，影子最长，等于 **a** 本身的长度。
- 如果 **a** 和 **b** 垂直，影子缩成一个点，长度为 0。
- 如果 **a** 和 **b** 方向相反，影子是"负的"——意思是影子投在了 **b** 的反方向。

## 标量投影

**a** 在 **b** 方向上的**标量投影**（就是影子的长度，带正负号）：

$$\text{comp}_{\mathbf{b}}\mathbf{a} = \frac{\mathbf{a} \cdot \mathbf{b}}{|\mathbf{b}|}$$

为什么是这个公式？回顾点积的几何定义：

**a** · **b** = |**a**|cos(θ) × |**b**|

所以 |**a**|cos(θ) = (**a** · **b**) / |**b**|

而 |**a**|cos(θ) 恰好就是 **a** 在 **b** 方向上的影子长度。

标量投影可以是负数——当 θ > 90° 时，cos(θ) < 0，影子投在了 **b** 的反方向。

## 向量投影

标量投影只是一个数字。但有时候我们需要影子本身也是一个向量——既有长度又有方向。

**a** 在 **b** 方向上的**向量投影**：

$$\text{proj}_{\mathbf{b}}\mathbf{a} = \frac{\mathbf{a} \cdot \mathbf{b}}{|\mathbf{b}|^2} \mathbf{b}$$

怎么理解这个公式？

- **a** · **b** / |**b**|² 是一个标量系数。
- 把这个系数乘以向量 **b**，就得到了一个沿着 **b** 方向的向量。
- 这个向量的长度恰好等于标量投影，方向沿着 **b**（或 **b** 的反方向，如果系数为负的话）。

换个写法更容易理解：

$$\text{proj}_{\mathbf{b}}\mathbf{a} = \underbrace{\frac{\mathbf{a} \cdot \mathbf{b}}{|\mathbf{b}|}}_{\text{标量投影}} \times \underbrace{\frac{\mathbf{b}}{|\mathbf{b}|}}_{\text{b 方向的单位向量}}$$

向量投影 = 影子长度 × 影子方向。

## 向量投影 vs 标量投影

总结一下区别：

| | 标量投影 | 向量投影 |
| --- | --- | --- |
| 是什么 | 一个数（带正负） | 一个向量 |
| 公式 | **a** · **b** / \|**b**\| | (**a** · **b** / \|**b**\|²) **b** |
| 含义 | 影子有多长 | 影子这个"有方向的量"本身 |

## 投影的应用

**应用一：力的分解**

物理课上经典场景：一个物体在斜面上，重力竖直向下。需要把重力分解成"沿斜面方向"和"垂直于斜面方向"两个分量。沿斜面方向的分量，就是重力向量在斜面方向上的投影。

**应用二：求点到直线的最近距离**

给定点 P 和一条过原点、方向为 **d** 的直线。P 到直线的最近距离 = |OP| 减去 OP 在 **d** 上的投影长度（用勾股定理算）。这在游戏开发、机器人路径规划里用得非常多。

## Gram-Schmidt 正交化简介

投影还有一个很酷的应用：**Gram-Schmidt 正交化**。

假设你有一组向量，它们之间互相不垂直。你想把它们变成一组互相垂直的向量，同时保持它们"撑开"的空间不变。怎么做？

思路很朴素：

1. 第一个向量 **v₁** 保持不变。
2. 第二个向量 **v₂**，减去它在 **v₁** 方向上的投影——剩下的部分就垂直于 **v₁** 了。
3. 第三个向量 **v₃**，减去它在 **v₁** 和新的 **v₂** 方向上的投影——剩下的部分就同时垂直于 **v₁** 和 **v₂** 了。
4. 以此类推。

每一步都在做同一件事：**把"已经存在的方向"从新向量中减掉，剩下的就是全新的、正交的方向**。

就像小王整理骑手路线：第一条路线随便定，第二条路线去掉和第一条重合的部分，第三条路线去掉和前两条重合的部分……最后每条路线都互不重叠。

## 类比时间

投影就像"太阳底下物体的影子"：

- 太阳的位置决定了投影的方向（相当于向量 **b** 的方向）。
- 物体本身是向量 **a**。
- 影子的长度就是标量投影，影子本身（从物体底部到影子顶端的有向线段）就是向量投影。
- 如果太阳从侧面照（垂直），影子缩成一个点——投影为 0。

## 代码示例

```javascript
// 点积
function dot(a, b) {
  return a.reduce((sum, ai, i) => sum + ai * b[i], 0);
}

// 模长
function magnitude(v) {
  return Math.sqrt(v.reduce((sum, vi) => sum + vi * vi, 0));
}

// 向量数乘
function scale(v, k) {
  return v.map(vi => vi * k);
}

// 向量减法
function subtract(a, b) {
  return a.map((ai, i) => ai - b[i]);
}

// 标量投影：a 在 b 方向上的影子长度
function scalarProjection(a, b) {
  return dot(a, b) / magnitude(b);
}

// 向量投影：a 在 b 方向上的投影向量
function vectorProjection(a, b) {
  const bSquared = dot(b, b); // |b|²
  const scalar = dot(a, b) / bSquared;
  return scale(b, scalar);
}

// Gram-Schmidt 正交化
function gramSchmidt(vectors) {
  const ortho = [];
  for (const v of vectors) {
    let u = [...v]; // 拷贝一份
    for (const e of ortho) {
      // 减去 v 在 e 方向上的投影
      const proj = vectorProjection(v, e);
      u = subtract(u, proj);
    }
    ortho.push(u);
  }
  return ortho;
}

// 小王的配送路线投影
const route = [3, 4];       // 骑手小赵的路线
const mainRoad = [1, 0];    // 主干道（x 轴）

console.log("小赵在主干道上的有效距离:", scalarProjection(route, mainRoad));
// 3 —— 在 x 轴方向上实际跑了 3 公里

const proj = vectorProjection(route, mainRoad);
console.log("投影向量:", proj); // [3, 0]

// Gram-Schmidt 示例
const v1 = [1, 1];
const v2 = [1, 0];
const result = gramSchmidt([v1, v2]);
console.log("正交化结果:", result);
// 第一组：[1, 1]（不变）
// 第二组：[1, 0] - 在 [1,1] 上的投影 = [0.5, -0.5]（垂直于 [1,1]）
```

## 小结

- 投影就是一个向量在另一个向量方向上的"影子"。
- 标量投影 = **a** · **b** / |**b**|，是一个带正负号的数。
- 向量投影 = (**a** · **b** / |**b**|²) **b**，是一个向量。
- 投影在力的分解、最近点计算等场景中非常实用。
- Gram-Schmidt 正交化利用投影，可以把一组向量变成互相正交的向量组。

## 练习题

**第1题：** 求 **a** = (4, 3) 在 **b** = (1, 0) 方向上的标量投影和向量投影。

**第2题：** 求 **a** = (3, 4) 在 **b** = (1, 1) 方向上的标量投影和向量投影。

**第3题：** 用 Gram-Schmidt 正交化，把 **v₁** = (1, 1)，**v₂** = (1, -1) 变成一组正交向量。

## 练习题答案

**第1题：**
标量投影 = **a** · **b** / |**b**| = (4×1 + 3×0) / 1 = **4**
向量投影 = (4 / 1²) × (1, 0) = **(4, 0)**

直觉上很直观：**b** 就是 x 轴方向，**a** 在 x 轴上的影子长度就是 x 分量 4。

**第2题：**
**a** · **b** = 3×1 + 4×1 = 7
|**b**| = √2
标量投影 = 7 / √2 = **7√2 / 2 ≈ 4.95**

|**b**|² = 2
向量投影 = (7 / 2) × (1, 1) = **(3.5, 3.5)**

**第3题：**
第一步：**u₁** = **v₁** = (1, 1)

第二步：计算 **v₂** 在 **u₁** 上的投影：
**v₂** · **u₁** = 1×1 + (-1)×1 = 0
投影 = (0 / 2) × (1, 1) = (0, 0)

**u₂** = **v₂** - (0, 0) = **(1, -1)**

验证：**u₁** · **u₂** = 1×1 + 1×(-1) = 0。确实正交！

其实这组向量本来就是正交的——小王运气不错，一开始选的路线就是互相垂直的。
