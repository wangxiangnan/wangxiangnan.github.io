# 第5章：引用与借用

## 借书模型

上一章我们发现，每次传 String 给函数都会失去它——这太不方便了。

想象一下图书馆：你把书**借**出去看，看完**还**回来，书的**所有权**还是图书馆的。

Rust 的引用（Reference）就是这个机制：你可以"借用"数据而不获取所有权。

## 不可变引用（&）

```rust
fn calculate_length(s: &String) -> usize {
    s.len()
}   // s 离开作用域，但它不拥有数据，所以不会 drop 任何东西

fn main() {
    let s = String::from("hello");
    let len = calculate_length(&s);  // &s 创建一个引用
    println!("'{s}' 的长度是 {len}"); // s 仍然可用！
}
```

`&s` 创建了一个指向 `s` 的**引用**（reference），类型是 `&String`（读作"对 String 的引用"）。这个过程叫**借用**（borrowing）。

## 可变引用（&mut）

```rust
fn add_world(s: &mut String) {
    s.push_str(", world!");
}

fn main() {
    let mut s = String::from("hello");
    add_world(&mut s);
    println!("{s}"); // "hello, world!"
}
```

## 借用规则——Rust 的铁律

> **在同一时刻，你可以拥有：**
>
> - 任意数量的不可变引用（`&T`），**或者**
> - 恰好一个可变引用（`&mut T`）
>
> **两者不可共存。**

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;       // 不可变引用 ✓
    let r2 = &s;       // 再来一个不可变引用 ✓
    // let r3 = &mut s;  // 编译错误！已有不可变引用时不能创建可变引用

    println!("{r1} {r2}"); // r1 和 r2 在这里最后使用

    let r3 = &mut s;   // 现在可以了，因为 r1、r2 已经不再使用
    r3.push_str("!");
    println!("{r3}");
}
```

> **为什么要有这个规则？**
>
> - 防止**数据竞争**：多个地方同时读写同一数据
> - 防止**意外修改**：你在读取数据时，不希望别人偷偷改掉它
> - 这在并发编程中尤为重要——Rust 在编译时就消灭了数据竞争

## 引用的作用域

引用的作用域从声明处开始，到**最后一次使用**结束（Non-Lexical Lifetimes，NLL）：

```rust
fn main() {
    let mut s = String::from("hello");

    let r1 = &s;
    let r2 = &s;
    println!("{r1} and {r2}");
    // r1 和 r2 的作用域在此结束

    let r3 = &mut s;   // OK！r1、r2 已不再活跃
    println!("{r3}");
}
```

## 悬垂引用（Dangling Reference）

Rust 编译器会阻止你创建指向已释放内存的引用：

```rust
fn main() {
    let r;
    {
        let x = 5;
        r = &x;    // 编译错误！x 在此作用域结束后会被销毁
    }
    // println!("{r}"); // 如果允许，r 就会指向无效内存
}
```

编译器会告诉你："borrowed value does not live long enough"（借用的值活得不够长）。

```rust
// 错误示例
fn dangle() -> &String {
    let s = String::from("hello");
    &s  // 编译错误！s 在函数结束时被 drop，引用指向无效内存
}

// 正确做法：返回所有权而不是引用
fn no_dangle() -> String {
    let s = String::from("hello");
    s  // 所有权移出函数
}
```

## 切片（Slice）

切片是对连续数据的一段**引用**，不拥有数据：

### 字符串切片

```rust
fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];   // "hello"（类型是 &str）
    let world = &s[6..11];  // "world"

    println!("{hello} {world}");

    // 省略写法
    let from_start = &s[..5];    // 等同于 &s[0..5]
    let to_end = &s[6..];        // 等同于 &s[6..11]
    let whole = &s[..];          // 整个字符串

    println!("{from_start} | {to_end} | {whole}");
}
```

> **重要**：字符串切片的索引是**字节索引**，不是字符索引！中文等多字节 UTF-8 字符不能随便切片，否则会 panic。

```rust
fn main() {
    let s = String::from("你好世界");
    // let bad = &s[0..1];  // panic！"你" 占3个字节，切在中间会崩溃
    let ok = &s[0..3];     // "你"（UTF-8 中一个中文字符占3字节）
    println!("{ok}");
}
```

### 实战：获取第一个单词

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &byte) in bytes.iter().enumerate() {
        if byte == b' ' {
            return &s[..i];
        }
    }
    s  // 没有空格，返回整个字符串
}

fn main() {
    let sentence = String::from("hello beautiful world");
    let word = first_word(&sentence);
    println!("第一个单词: {word}"); // "hello"
}
```

### 数组切片

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let slice = &a[1..4];  // &[2, 3, 4]，类型是 &[i32]

    for val in slice {
        print!("{val} ");
    }
    println!();
}
```

## 用引用重写之前的例子

第4章的 `takes_ownership` 太粗暴了，用引用重写：

```rust
// 借用版本：不获取所有权
fn print_string(s: &str) {
    println!("内容是: {s}");
}

fn get_length(s: &str) -> usize {
    s.len()
}

fn main() {
    let s = String::from("Rust 真棒");

    print_string(&s);             // 借用
    let len = get_length(&s);     // 再次借用
    println!("长度: {len}");
    println!("还能用: {s}");      // s 依然有效
}
```

## 常见陷阱

1. **不可变引用和可变引用同时存在**：即使你只是"读"，也不允许在有 `&mut` 的同时持有 `&`
2. **字符串切片的字节索引**：中文字符占多个字节，切错位置会 panic
3. **返回局部变量的引用**：函数里的局部变量在函数结束时被 drop，不能返回其引用
4. **忘记 `&mut` 需要 `mut` 变量**：`let s = String::from("hi"); &mut s` 会编译错误

## 小结

- `&T` 是不可变引用，`&mut T` 是可变引用
- 同一时刻：多个不可变引用 **或** 一个可变引用
- 引用的生命周期不能超过数据本身
- 切片是对连续数据的只读引用
- `&str` 是字符串切片类型，比 `&String` 更通用
