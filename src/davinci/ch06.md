## 6.1 为什么要调色？调色 vs 滤镜的本质区别

很多新手会问："我手机拍的时候不是已经挺好看了吗，为什么还要调色？"

好问题。打个比方：你手机相机拍出来的画面，就像刚从菜市场买回来的食材——新鲜是新鲜，但还没经过厨师的烹饪。调色，就是那个"烹饪"的过程。

**滤镜和调色的区别**，就像是方便面调料包 vs 大厨现炒：

- **滤镜**（Filter）是预制好的一套参数，往上一套，所有画面都变成同一个味道。就像方便面调料包，方便但千篇一律。
- **调色**（Color Grading）是你根据每个画面的具体情况，手动调整每一个参数。就像大厨根据食材状态调整火候和调味，每一道菜都是量身定制。

DaVinci Resolve之所以在专业影视圈地位崇高，就是因为它的调色功能是所有剪辑软件中最强大的。没有之一。好莱坞大片的调色师，用的就是你现在打开的这个软件。

> 💡 **提示**：调色分为两个阶段——**一级校色（Primary Grading）** 是把画面"修正"到正常好看的状态（比如曝光准确、白平衡正确）；**二级调色（Secondary Grading）** 是在此基础上进行风格化处理（比如打造电影感、复古感）。先校色，再调色，顺序不能乱。

## 6.2 调色页界面详解：节点图、示波器、调色轮

点击软件底部的**调色页（Color Page）** 图标，你会看到一个信息密度很高的界面。别怕，我们一块一块来认识：

**左上区域——检视器（Viewer）**：预览你正在调色的画面。

**右上区域——示波器（Scopes）**：这是你的"体检仪器"，用图形化的方式显示画面的亮度、色彩分布。后面我们会详细讲。

**中央下方——调色轮/色轮（Color Wheels）**：四个大圆盘，分别是：

- **Lift（暗部）**：控制画面中最暗的部分
- **Gamma（中间调）**：控制画面中间亮度的部分
- **Gain（亮部）**：控制画面中最亮的部分
- **Offset（整体偏移）**：同时影响所有亮度范围

把它们想象成三个调光开关——一个管灯泡最暗的那一档，一个管中间档，一个管最亮那档。你可以分别调节，互不干扰。

**底部——节点图（Node Graph）**：这是DaVinci调色的核心，也是它区别于其他软件的地方。我们6.5节会详细讲。

**右侧——各种调色面板**：包括曲线（Curves）、限定器（Qualifier）、跟踪器（Tracker）等高级工具。

> 💡 **提示**：第一次进入调色页如果觉得界面太复杂，可以按 `Ctrl + F`（Windows）/ `Cmd + F`（Mac）切换全屏预览，先看看素材的原始画面，深呼吸，我们慢慢来。

## 6.3 一级校色：曝光、白平衡、对比度的基础调整

一级校色是调色的第一步，目标是让画面"正确"——曝光合适、颜色自然、对比度适中。

**第一步：调整曝光**

曝光是调色的地基。打开调色页后，看示波器中的**波形图（Waveform）**（像一座山脉的图形），它显示画面从左到右每个位置的亮度。

- 波形图底部（0线）= 纯黑
- 波形图顶部（1023线）= 纯白
- 大部分内容应该分布在中间区域

如果波形整体贴着底部，说明画面**欠曝**（太暗了）；如果贴着顶部，说明**过曝**（太亮了）。

调整方法：

1. 用 **Gain（亮部）** 色轮往上推，让高光区域变亮
2. 用 **Lift（暗部）** 色轮往下拉，让暗部沉下去
3. 用 **Gamma（中间调）** 微调整体明暗感觉

**第二步：校正白平衡**

白平衡不正确，画面会整体偏蓝（色温太低）或偏黄（色温太高）。就像你在日光灯下和白炽灯下看同一件白衬衫，颜色感觉完全不同。

调整方法：

- 在**Camera Raw**面板（如果你的素材支持）中调整**色温（Temp）** 和**色调（Tint）**
- 或者使用**白平衡选择器（White Balance Picker）**——点击工具栏中的吸管图标，然后在画面中找到一个应该是白色或灰色的区域点一下，软件会自动帮你校正

> 💡 **提示**：如果画面中有白色的墙壁、白色的纸张、灰色的路面，这些都是很好的白平衡参考点。

**第三步：调整对比度**

对比度就是画面最亮和最暗之间的差距。对比度太低，画面灰蒙蒙的像蒙了一层雾；对比度太高，暗部死黑、亮部死白，细节全丢了。

最简单的对比度调整：

- **Lift 往下拉一点**（让暗部更深）
- **Gain 往上推一点**（让亮部更亮）
- 两者配合，画面的"层次感"就出来了

你也可以使用**曲线（Curves）**工具——它是一条对角线，往上拉变亮，往下拉变暗。经典的"S曲线"就是在暗部往下拉一点、亮部往上推一点，形成一个S形，能快速增加对比度。

## 6.4 看懂示波器：波形图、矢量图、直方图

示波器是很多新手最头疼的部分，但它其实是你最好的朋友。想象你是一个医生，示波器就是心电图——它用图形告诉你画面的"健康状况"。

**波形图（Waveform）**——画面的"亮度地图"

把波形图想象成从正上方俯瞰你的画面，然后把每一列像素的亮度叠起来显示。横轴对应画面的左右位置，纵轴是亮度（下暗上亮）。

怎么看：

- 波形集中在底部 → 画面太暗
- 波形集中在顶部 → 画面太亮或过曝
- 波形铺满从底到顶 → 对比度不错
- 波形最顶端被"削平"了 → 高光溢出（细节丢失）

**矢量图（Vectorscope）**——色彩的"指南针"

矢量图显示画面中所有颜色的分布。圆心是灰色（无色彩），越往外颜色越饱和。图上标有六个颜色目标：红（R）、黄（YL）、绿（G）、青（CY）、蓝（B）、品红（MG）。

怎么看：

- 图形集中在圆心 → 画面色彩很淡（接近黑白）
- 图形延伸到边缘 → 色彩非常饱和
- **肤色线（Skin Tone Line）**：矢量图上有一条从圆心指向肤色区域的线，不管你是什么肤色的人，人皮肤的色调都应该落在这条线附近。如果偏离了，说明肤色不对。

**直方图（Histogram）**——像素的"人口普查"

直方图把画面中的像素按亮度从左（暗）到右（亮）统计，告诉你有多少像素在哪个亮度区间。

怎么看：

- 左边堆了一坨 → 很多像素很暗（可能暗部细节丢失）
- 右边堆了一坨 → 很多像素很亮（可能过曝）
- 中间隆起、两边低 → 画面偏灰，对比度不够
- 均匀分布 → 通常说明曝光比较合理

> 💡 **提示**：示波器比你的眼睛可靠得多！你的显示器可能有色差，你的眼睛会受环境光影响，但示波器永远说实话。养成看示波器的习惯，是调色调好的关键。

## 6.5 节点系统：为什么DaVinci用节点而不是图层

在Photoshop里你习惯了图层，在Premiere里你习惯了效果叠加。但DaVinci Resolve用了一套完全不同的思路——**节点（Node）** 系统。

**节点是什么？**

把每个节点想象成一道"加工工序"。画面像流水线上的产品，从第一个节点流入，经过每个节点的处理，最终变成成品输出。

```
[原始画面] → [节点1: 白平衡] → [节点2: 曝光] → [节点3: 风格调色] → [最终画面]
```

每个节点可以只做一件事，这样的好处是：

1. **可以随时修改**：觉得白平衡不对？回到节点1改就行，不影响后面的调整
2. **可以单独开关**：每个节点左上角有个蓝色小圆点，点一下就能关闭这个节点的效果，方便对比
3. **可以调整顺序**：拖拽节点改变处理顺序，效果会不同
4. **便于理解思路**：看节点图就知道你的调色逻辑

**节点的基本操作：**

- **添加节点**：在节点图区域右键 > 添加节点 > 串行节点（Serial Node），或按 `Alt + S`（Windows）/ `Option + S`（Mac）
- **重命名节点**：双击节点名称，改成有意义的名字（比如"白平衡""曝光""风格化"）——这是好习惯！
- **连接节点**：节点左侧黄色三角是输入，右侧黄色三角是输出，从一个节点的输出拖线到另一个节点的输入就建立了连接
- **禁用节点**：按 `Ctrl + D`（Windows）/ `Cmd + D`（Mac），或者点击节点上的蓝色圆点

> 💡 **提示**：新手常见的错误是把所有调整都塞进一个节点，导致调到最后根本不知道哪步做了什么。建议每个节点只做一类调整，并给它取好名字。就像整理衣柜——上衣一个抽屉、裤子一个抽屉、袜子一个抽屉，找起来才方便。

**推荐的节点结构（新手起步）：**

| 节点顺序 | 用途 | 说明 |
| --------- | ------ | ------ |
| 节点1 | 降噪 | 如果需要，最先处理 |
| 节点2 | 白平衡 | 校正色温 |
| 节点3 | 曝光/对比度 | 一级校色 |
| 节点4 | 二级调色 | 局部调整、肤色修正 |
| 节点5 | 风格化 | 整体氛围和色调 |

## 6.6 二级调色：用限定器选择特定颜色进行调整

一级校色是对整个画面进行全局调整。但有时候你只想改画面中的某一部分——比如只让天空更蓝，只让肤色更好看，只让绿色的草地更鲜艳。这就需要**二级调色（Secondary Grading）**。

**限定器（Qualifier）** 就是用来"选中"你想调整的那部分画面的工具。

打个比方：一级校色是给整个房间刷漆，二级调色是只给某一面墙换个颜色。限定器就是帮你精确地"贴胶带"，把不想改的地方保护起来。

**使用方法：**

1. 新建一个串行节点（专门用于二级调色）
2. 点击右侧面板的**限定器（Qualifier）** 工具——那个像滴管一样的图标
3. 用**吸管工具**在画面中点击你想调整的颜色（比如天空的蓝色）
4. 调整限定器的参数（色相范围、饱和度范围、亮度范围）来精确控制选区
5. 点击检视器左上角的**高亮显示（Highlight）** 按钮，可以看到被选中的区域（白色部分=被选中的区域）
6. 现在用调色轮或曲线调整，就只会影响被选中的区域

> 💡 **提示**：限定器选区的边缘要尽量"柔和"——在限定器面板中调高**柔化（Soften）** 参数，避免出现明显的颜色分界线。如果选区边缘太硬，画面看起来会很假。

**实战：让天空更蓝**

1. 新建节点，命名"天空"
2. 用限定器吸取天空的蓝色
3. 调整柔化到30-50
4. 在高亮模式下确认只选中了天空
5. 在Gain色轮上往蓝色方向轻推
6. 适当提高选中区域的饱和度
7. 关闭高亮，查看最终效果——天空变蓝了，其他区域不受影响

## 6.7 LUT的应用：什么是LUT、怎么加载、怎么微调

**LUT（Look-Up Table，查找表）** 是一种预设的颜色转换方案。你可以把它理解为一个"色彩翻译器"——它把输入的颜色按照预设规则转换成输出的颜色。

比喻一下：LUT就像给照片加的"滤镜配方"，但它比手机App滤镜精确得多。专业电影剧组在拍摄时就会用LUT预览最终效果，调色时再用LUT作为起点进行微调。

**DaVinci Resolve内置了一些LUT**，你也可以从网上下载第三方LUT（很多是免费的）。

**加载LUT的方法：**

1. 在项目设置（Project Settings）> 色彩管理（Color Management）中可以设置全局LUT
2. 或者更灵活的方式：在节点图上右键 > LUTs > 选择内置LUT或浏览自定义LUT

**使用LUT的正确姿势：**

⚠️ **重要原则：LUT是起点，不是终点。**

很多人的错误做法是套上LUT就觉得完事了。正确的流程是：

1. 先完成一级校色（确保曝光、白平衡正确）
2. 在最后一个节点上应用LUT
3. 用LUT的**关键输出（Key Output）** 参数控制LUT的强度（默认100%，可以调低）
4. 根据LUT效果回头微调前面的节点

**调整LUT强度：**
选中应用了LUT的节点，在右侧面板找到**关键输出（Key Output）** 或**LUT强度**，把数值从1.000降低（比如0.700 = 70%效果），让LUT效果更自然。

> 💡 **提示**：网上有很多免费的电影感LUT包，搜索"DaVinci Resolve free LUT pack"就能找到。下载后把 `.cube` 文件放入 DaVinci Resolve 的 LUT 文件夹，就能在软件中直接使用了。路径一般是：`C:\Users\你的用户名\AppData\Roaming\Blackmagic Design\DaVinci Resolve\Support\LUT`（Windows）。

## 6.8 手机素材调色实战：把手机直出调到"电影感"

小陈的Vlog素材都是手机拍的。手机直出的素材有几个特点：**过度锐化、对比度偏低、颜色过于鲜艳但不自然、暗部发灰**。我们一步步来拯救它。

**手机素材调色五步法：**

**步骤1：基础修正节点**

- 新建节点"基础"
- 稍微降低锐化（手机锐化过度了）
- 在曲线工具中做一个小S曲线，增加自然对比度
- 用Lift把暗部压低一点（解决发灰问题）

**步骤2：白平衡校正**

- 新建节点"白平衡"
- 手机自动白平衡经常不准
- 用白平衡吸管点击画面中的中性色区域
- 或者手动调整色温——室内通常偏黄需要往蓝推，室外阴影下偏蓝需要往黄推

**步骤3：色彩修正**

- 新建节点"色彩"
- 手机通常会把绿色和红色推得过于鲜艳
- 在**色相 vs 饱和度（Hue vs Saturation）** 曲线中，找到过于鲜艳的颜色区域，轻轻下拉降低饱和度
- 特别注意肤色——用矢量图确认肤色是否落在肤色线上

**步骤4：电影感调色**

- 新建节点"风格"
- 暗部稍微往蓝/青推（Lift色轮往冷色调偏移）
- 亮部稍微往暖色推（Gain色轮往橙/黄偏移）
- 这种"暗冷亮暖"的处理是电影调色的经典手法
- 适当降低整体饱和度5%-10%，电影感更强

**步骤5：最终微调**

- 播放整个片段，确认所有镜头的色调一致
- 如果某个镜头色调明显不同，需要单独调整匹配
- 可以使用**色彩匹配（Color Match）**功能辅助统一色调

> 💡 **提示**：手机素材调色的核心秘诀是"克制"。很多新手一上来就猛拉饱和度、猛推对比度，结果画面比手机直出还难看。记住——调色的最高境界是"看不出调过"。每次调整后，关掉节点对比一下，如果差距太大说明你调过头了。

## 6.9 调色风格化：暖色调、冷色调、胶片感

掌握了基础校色之后，你可以根据视频主题和氛围进行风格化处理。这里介绍三种最受欢迎的调色风格：

**暖色调（Warm Tone）**——温馨、治愈、美食

适用场景：美食Vlog、日常记录、温馨家庭内容

操作方法：

- Gain色轮往橙/黄方向推
- 整体色温往暖调偏移
- 适当提高中间调亮度
- 保持肤色自然（不要因为追求暖调让脸变成橘色）

**冷色调（Cool Tone）**——科技感、都市、悬疑

适用场景：科技评测、城市夜景、旅行记录中的"孤独感"

操作方法：

- Gain色轮往蓝/青方向推
- Lift色轮可以往深蓝偏移
- 适当降低饱和度
- 增加对比度让画面更"利落"

**胶片感（Film Look）**——复古、文艺、怀旧

适用场景：旅行Vlog、文艺短片、个人记录

操作方法：

- 使用曲线把最暗的点稍微上提（让纯黑变成深灰，这是胶片的标志性特征——"提升暗部/Faded Film"）
- 在亮部曲线末端稍微下拉（让最亮的地方不那么刺眼）
- 降低整体饱和度10%-15%
- 暗部加一点绿色或青色偏移
- 可以叠加一层胶片颗粒效果（在效果库中找到**Film Grain**效果，拖到节点上）（需Studio版，免费版可用节点手动模拟）

> 💡 **提示**：风格化调色没有"正确答案"。同一个素材，不同的调色风格会带来完全不同的情绪。多尝试，多对比，找到属于你自己的风格。你可以把喜欢的调色方案保存为**静帧（Still）**——在调色页右键 > 抓取静帧（Grab Still），下次就能直接复用。

## 6.10 调色常见错误：过曝、偏色、肤色失真

新手调色最容易犯的错误，这里帮你列出来——对照检查，及时避坑：

**错误1：过曝/死白**

- 表现：画面中的高光区域变成纯白，没有任何细节
- 波形图上表现为波形顶部被"削平"
- 解决：降低Gain色轮，或者在曲线上拉暗高光区域

**错误2：暗部死黑**

- 表现：阴影区域变成纯黑，什么都看不见
- 波形图上波形底部被"削平"
- 解决：适当提升Lift色轮，或者提亮曲线暗部

**错误3：整体偏色**

- 表现：画面有明显的色偏——整体偏蓝、偏绿、偏洋红
- 矢量图上色彩分布明显偏向某一侧
- 解决：回到白平衡节点重新校正，确保中性色（白色、灰色）确实是无色的

**错误4：肤色失真**

- 表现：人物脸色发绿、发紫、过于红润或过于苍白
- 矢量图上肤色偏离肤色线
- 解决：使用限定器选中肤色区域，单独校正。肤色是调色的"底线"——不管什么风格，肤色必须自然

**错误5：饱和度过高**

- 表现：颜色鲜艳到刺眼，像被打翻的颜料盘
- 矢量图上色彩分布延伸到最外圈
- 解决：全局降低饱和度，或针对特定颜色降低饱和度

**错误6：不同镜头色调不一致**

- 表现：同一个场景的不同镜头，颜色感觉完全不同
- 解决：使用**色彩匹配（Color Match）**功能，或者手动以其中一个镜头为参考，把其他镜头调到一致

> 💡 **提示**：调色每进行15-20分钟就休息一会儿，看看窗外或白墙。你的眼睛会"适应"当前的色彩，久了就判断不准了。这是所有调色师都需要注意的"视觉疲劳"问题。

## 6.11 实战：为小陈的Vlog素材进行完整调色

让我们跟着小陈走一遍完整的调色流程。他拍了一段周末探店的Vlog，用手机拍摄，素材包括：室外街景、室内咖啡店、食物特写、自拍讲话。

**小陈的调色流程：**

**准备阶段：**

- 切换到调色页
- 打开示波器面板（波形图 + 矢量图）
- 浏览所有片段，标记需要调色的素材

**第1步：全局一级校色**

- 为所有片段统一创建基础节点结构
- 逐片段校正白平衡（咖啡店室内偏黄，需要往蓝推）
- 调整曝光（室外稍过曝，降低Gain；室内稍欠曝，提升Gamma）
- 做基础S曲线增加对比度

**第2步：肤色处理**

- 对有人的片段新建节点"肤色"
- 用限定器选中肤色区域
- 微调让肤色落在矢量图的肤色线上
- 轻微提亮肤色区域（让人物更突出）

**第3步：风格化**

- 整体走"暖调文艺风"——Gain往暖色推，暗部保留一点冷色
- 食物特写：适当增加暖色饱和度，让食物看起来更有食欲
- 街景：保持自然色调，略微降低饱和度
- 咖啡店内：整体偏暖，营造温馨氛围

**第4步：一致性检查**

- 播放整个时间线，检查镜头之间是否连贯
- 发现有一个镜头明显偏绿，单独校正
- 确认所有镜头肤色一致

**第5步：最终微调**

- 整体降低LUT强度到70%
- 添加轻微暗角效果（让视线聚焦画面中心）
- 导出预览，在手机上看一遍效果（因为观众大多用手机看）

**本章小结：**

| 知识点 | 要点 |
| ------- | ------ |
| 调色 vs 滤镜 | 调色是精确的手动调整，滤镜是一键套用 |
| 一级校色 | 先校正曝光、白平衡、对比度 |
| 示波器 | 波形图看亮度、矢量图看色彩、直方图看分布 |
| 节点系统 | 每个节点做一件事，保持清晰的调色逻辑 |
| 二级调色 | 用限定器选中特定颜色区域进行精确调整 |
| LUT | 是起点不是终点，套上后要微调 |
| 手机素材 | 降噪→校色→修正色彩→风格化，每步要克制 |
| 常见错误 | 过曝、死黑、偏色、肤色失真、饱和度过高 |

**练习题：**

1. **【基础】** 打开DaVinci Resolve调色页，导入一段手机拍摄的素材。按照"五步法"完成一级校色：校正白平衡、调整曝光、增加对比度。用示波器确认曝光是否正确。

2. **【进阶】** 使用限定器选中素材中的天空区域（或其他特定颜色区域），单独调整其饱和度和色相，让天空变得更蓝（或让某个颜色更突出）。在高亮模式下确认选区边缘是否柔和。

3. **【挑战】** 为同一段素材分别调出"暖色调""冷色调""胶片感"三种风格，导出三张静帧对比图，选出你最喜欢的一种并说明理由。
