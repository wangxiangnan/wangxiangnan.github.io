# 第2章：数据输入与格式化——让数据好看又好读 🎨

*小王终于开始用Excel了！他兴奋地打开表格，噼里啪啦输了一堆数据。但回头一看——日期格式乱七八糟，金额没有小数点，整张表灰扑扑的，跟记事本似的。他朋友小李看了一眼说："兄弟，数据得好好输入，还得好好打扮。"*

## 2.1 输入文本、数字、日期

在Excel里输入数据很简单——选中单元格，直接打字，按 `Enter` 确认。但有一些细节值得注意：

**文本输入**

- 直接输入文字即可，比如"珍珠奶茶"、"小王"。
- 文本默认左对齐。
- 如果输入的内容以 `=` 开头，Excel会把它当成公式。如果你想输入以等号开头的文本，在前面加一个单引号 `'`，比如输入 `'=SUM`。

**数字输入**

- 直接输入数字，比如 `15.5`、`200`。
- 数字默认右对齐。
- Excel默认保留15位有效数字，对于更长的数字（比如身份证号），需要先把单元格格式设置为"文本"，否则末尾的数字会被变成0。

**日期输入**

- Excel能识别多种日期格式：`2024/1/15`、`2024-1-15`、`2024年1月15日` 都可以。
- 输入当前日期的快捷键：`Ctrl + ;`
- 输入当前时间的快捷键：`Ctrl + Shift + ;`

> 💡 **提示**：日期在Excel里其实是一个数字！比如"2024年1月1日"在Excel内部存储的是 `45292`（从1900年1月1日开始算的天数）。了解这一点很重要，后面学日期函数时你就明白了。

**输入技巧**

- 按 `Enter`：确认输入并跳到下一行
- 按 `Tab`：确认输入并跳到右边一个单元格
- 按 `Esc`：取消当前输入
- 按 `F2` 或双击单元格：进入编辑模式
- 批量输入相同内容：选中多个单元格 → 输入内容 → 按 `Ctrl + Enter`

## 2.2 自动填充：拖拽生成序列

上一章提到了填充柄，这里我们详细讲讲**自动填充**这个超实用的功能。

**数字序列**

- 在A1输入 `1`，A2输入 `2`，然后选中这两个单元格，拖动填充柄往下，Excel会自动识别等差规律，填充 `3、4、5、6……`
- 如果只输入一个数字然后拖填充柄，默认是复制。按住 `Ctrl` 再拖，才会变成递增序列。

**日期序列**

- 输入 `2024/1/1`，拖填充柄往下，会自动变成 `2024/1/2`、`2024/1/3`……
- 右键拖填充柄松开后，可以选择"以工作日填充"、"以月填充"、"以年填充"等。

**文本序列**

- Excel内置了一些常见序列：星期一~星期日、一月~十二月、第一季度~第四季度等。输入其中一个，拖填充柄就能自动补全。

**自定义序列**

- "文件" → "选项" → "高级" → 拉到底部 → "编辑自定义列表"，可以创建自己的序列，比如"珍珠奶茶、红豆奶茶、芒果冰沙、抹茶拿铁"。

**右键菜单的填充选项**

选中一个单元格后，右键拖拽填充柄到下端松开，会弹出一个菜单，可以选择：

- 复制单元格
- 以序列方式填充
- 仅填充格式
- 不带格式填充

> 💡 **提示**：小王给奶茶店做了一张价目表，他用自动填充功能，在A列快速生成了"序号1~50"，比自己一个个打快了几十倍。以后你需要编号时，千万别傻傻手动输！

## 2.3 单元格格式：字体、对齐、边框、填充色

现在我们来"装修"表格，让数据好看又好读。这些格式化工具都在"开始"选项卡里。

**字体相关**

- **字体**：推荐使用"微软雅黑"，清晰易读。
- **字号**：表头一般用12-14号加粗，正文用10-11号。
- **加粗** `Ctrl + B`、*斜体* `Ctrl + I`、<u>下划线</u> `Ctrl + U`
- **字体颜色**：点击字体颜色按钮旁的三角可以选择颜色。

**对齐方式**

- 水平对齐：左对齐、居中、右对齐
- 垂直对齐：顶端对齐、居中、底端对齐
- **自动换行**：内容太长时，勾选"自动换行"可以让文字在单元格内折行显示
- **缩小字体填充**：让文字自动缩小以适应单元格宽度

**边框**

- 默认情况下，Excel的网格线只是辅助线，打印时不会显示。如果要打印边框，需要手动添加。
- 选中区域 → 点击"边框"按钮 → 选择"所有框线"或"外侧框线"等。
- 可以自定义边框的线条样式和颜色。

**填充色（背景色）**

- 选中单元格 → 点击"填充颜色"（油漆桶图标）→ 选择颜色。
- 建议用法：表头用深色背景 + 白色文字，数据行用浅色背景交替（斑马纹效果），这样既美观又方便阅读。

> 💡 **提示**：格式化不是越花哨越好。好的表格设计是"简洁 + 一致"——全表不超过2-3种颜色，表头和数据有明显区分，这就够了。小王的表格曾经被他搞得像个调色盘，被小李吐槽"你这是Excel还是涂鸦墙"。

## 2.4 数字格式：货币、百分比、自定义格式

Excel的数字格式功能非常强大，同样的数字可以用不同的方式"穿不同的衣服"。

**常用数字格式**

- **常规**：默认格式，不添加任何特殊效果。
- **数值**：可以设置小数位数和千位分隔符。比如 `12345.6` 显示为 `12,345.60`。
- **货币**：在数值基础上加上货币符号。比如 `¥12,345.60`。
- **百分比**：将数字乘以100并加上 `%`。比如 `0.856` 显示为 `85.6%`。
- **日期/时间**：同一个日期数字可以显示为不同格式，如 `2024/1/15` 或 `2024年1月15日` 或 `15-Jan-2024`。

**如何设置**

- 方法一："开始"选项卡 → "数字"区域的下拉菜单
- 方法二：右键 → "设置单元格格式" → "数字"选项卡（更详细）
- 方法三：快捷键 `Ctrl + 1`（直接打开格式设置对话框）

**自定义格式（进阶）**

在"数字"选项卡中选择"自定义"，可以输入格式代码：

- `0.00`：强制显示两位小数（如 `5` 显示为 `5.00`）
- `#,##0`：千位分隔符，无小数
- `¥#,##0.00`：带人民币符号和千位分隔符
- `0.0%`：百分比格式
- `0.00;(0.00);"零"`：正数正常显示，负数加括号，零显示为"零"

> 💡 **提示**：自定义格式只改变**显示方式**，不改变**实际存储值**。比如单元格实际值是 `0.856`，设置百分比格式后显示为 `85.6%`，但参与公式计算时仍然是 `0.856`。

**举个奶茶店的例子**

小王的日销售表里有这些数据：

| 商品 | 单价 | 数量 | 金额 | 折扣 |
| ------ | ------ | ------ | ------ | ------ |
| 珍珠奶茶 | ¥15.00 | 32 | ¥480.00 | 95% |
| 红豆奶茶 | ¥12.00 | 28 | ¥336.00 | 90% |
| 芒果冰沙 | ¥18.00 | 15 | ¥270.00 | 100% |

单价和金额设置了货币格式（`¥#,##0.00`），折扣设置了百分比格式（`0%`）。这样一眼就能看清数据含义。

## 2.5 合并居中与跨列居中

当你需要在表格顶部放一个大标题时（比如"小王奶茶店2024年1月销售日报"），就会用到合并居中。

**合并居中**

- 选中要合并的多个单元格（比如A1到E1）
- 点击"开始" → "合并居中"按钮
- 这五个格子会合成一个大格子，文字居中显示

> ⚠️ **注意**：合并单元格虽然好看，但会带来一些麻烦——排序、筛选、复制公式时可能会出错。建议只在表头标题等不涉及数据计算的场合使用。

**跨列居中（更好的替代方案）**

- 选中A1到E1
- 右键 → "设置单元格格式" → "对齐"选项卡 → 水平对齐选择"跨列居中"
- 效果看起来和合并居中一样，但实际上单元格并没有被合并，避免了后续的麻烦

> 💡 **提示**：小李告诉小王一个经验——"合并居中就像把几个房间打通成一个大房间，看着宽敞，但以后想再隔回来就麻烦了。跨列居中就像在几个房间上面挂一个大横幅，房间还是独立的。"所以推荐优先使用跨列居中。

## 2.6 冻结窗格：大表格不迷路

小王的日销售记录表有300多行数据，往下滚动的时候，表头就看不到了——每次都要滚回最上面看看这一列到底是"单价"还是"金额"，特别烦。

**冻结窗格**就是解决这个问题的！它可以让你在滚动时，某些行或列始终保持在屏幕上。

**操作方法**

- **冻结首行**："视图"选项卡 → "冻结窗格" → "冻结首行"
- **冻结首列**：同上 → "冻结首列"
- **冻结指定行和列**：先选中一个单元格（比如B2），然后 → "冻结窗格" → "冻结拆分窗格"。这样B2上方和左侧的所有行和列都会被冻结。

举个例子：如果表头在第1行，A列是日期，你想让第1行和A列都固定住，就选中 `B2` 单元格，然后点击"冻结拆分窗格"。之后不管怎么滚动，表头和日期列都看得见。

**取消冻结**

- "视图" → "冻结窗格" → "取消冻结窗格"

> 💡 **提示**：冻结窗格是每个经常处理大表格的人的必备技能。设置一次，受益无穷。小王设置完冻结窗格后感叹："终于不用每次看数据都玩'猜猜这是哪一列'的游戏了！"
