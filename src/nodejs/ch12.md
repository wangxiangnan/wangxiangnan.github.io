# 第12章：子进程与集群——榨干每一核 CPU

## 引言：单线程的烦恼

Node.js 是单线程的——这是它的超能力（事件循环、非阻塞 I/O），也是它的阿喀琉斯之踵。

想象你开了一家餐厅：

- Node.js 就是那个超级高效的独臂服务员——它能同时接单、传菜、收银（异步 I/O）
- 但如果有人点了一个需要现做1小时的菜（CPU 密集计算），整个餐厅就卡死了

怎么办？——**请帮手！**

- `child_process`：雇临时工（子进程）帮你干活
- `cluster`：开连锁店（多进程），每个店配一个服务员
- `worker_threads`：给服务员多配几只手（多线程，第21章详讲）

## 12.1 child_process 四大方法

### exec：执行 shell 命令

```javascript
import { exec } from 'node:child_process';
import { promisify } from 'node:util';

const execAsync = promisify(exec);

// 基本用法
const { stdout, stderr } = await execAsync('ls -la');
console.log(stdout);

// 带选项
const { stdout: gitLog } = await execAsync('git log --oneline -5', {
  cwd: '/path/to/repo', // 工作目录
  encoding: 'utf8',
  timeout: 5000,        // 超时（毫秒）
  maxBuffer: 1024 * 1024, // 最大输出大小（默认 1MB）
});
```

**特点**：

- 在 shell 中执行（可以用管道、通配符等 shell 特性）
- 输出缓存在内存中，一次性返回
- 有 `maxBuffer` 限制（默认 1MB）
- ⚠️ 有**命令注入**风险！

```javascript
// ❌ 危险！命令注入！
const userInput = '; rm -rf /';
exec(`echo ${userInput}`); // 这会执行 rm -rf / ！

// ✅ 使用 execFile 代替（不经过 shell）
```

### execFile：执行可执行文件

```javascript
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);

// 直接执行文件，不经过 shell（更安全）
const { stdout } = await execFileAsync('git', ['log', '--oneline', '-5'], {
  cwd: '/path/to/repo',
});

// 不会发生命令注入
const filename = '; rm -rf /'; // 这只会作为参数传给 ls
await execFileAsync('ls', [filename]); // 安全！只是找不到这个文件
```

### spawn：生成子进程（流式）

```javascript
import { spawn } from 'node:child_process';

// spawn 返回的是 ChildProcess 对象，stdout/stderr 是 Stream
const child = spawn('find', ['.', '-name', '*.js'], {
  cwd: '/path/to/project',
});

// 流式读取输出（适合大量输出）
child.stdout.on('data', (data) => {
  console.log(`输出: ${data}`);
});

child.stderr.on('data', (data) => {
  console.error(`错误: ${data}`);
});

child.on('close', (code) => {
  console.log(`子进程退出，退出码: ${code}`);
});

// 可以写入 stdin
const grep = spawn('grep', ['hello']);
grep.stdin.write('hello world\n');
grep.stdin.write('foo bar\n');
grep.stdin.write('hello node\n');
grep.stdin.end();

grep.stdout.on('data', (data) => {
  console.log('匹配到:', data.toString());
  // "hello world\nhello node\n"
});
```

### spawn 的高级选项

```javascript
import { spawn } from 'node:child_process';

const child = spawn('node', ['worker.js'], {
  // 工作目录
  cwd: '/path/to/dir',

  // 环境变量（默认继承 process.env）
  env: { ...process.env, NODE_ENV: 'production' },

  // stdio 配置
  stdio: 'pipe',           // 默认：创建管道
  // stdio: 'inherit',     // 共享父进程的 stdin/stdout/stderr
  // stdio: 'ignore',      // 忽略所有 IO
  // stdio: ['pipe', 'pipe', 'pipe', 'ipc'], // 自定义 + IPC

  // 脱离父进程（后台运行）
  detached: false,

  // 在 shell 中执行（可以用 shell 特性）
  shell: false,

  // 信号：取消子进程
  signal: controller.signal,

  // 超时
  timeout: 10000,
  killSignal: 'SIGTERM',
});
```

### fork：创建 Node.js 子进程

`fork` 是 `spawn` 的特化版本，专门用于创建 Node.js 子进程，自带 IPC 通道：

```javascript
// parent.js
import { fork } from 'node:child_process';

const child = fork('./worker.js', ['arg1', 'arg2'], {
  // fork 自动添加 IPC 通道
  // stdio 默认是 ['pipe', 'pipe', 'pipe', 'ipc']
});

// 父→子 发送消息
child.send({ type: 'task', data: { numbers: [1, 2, 3, 4, 5] } });

// 接收子进程消息
child.on('message', (msg) => {
  console.log('子进程返回:', msg);
});

child.on('exit', (code) => {
  console.log(`子进程退出: ${code}`);
});
```

```javascript
// worker.js
process.on('message', (msg) => {
  console.log('收到父进程消息:', msg);

  if (msg.type === 'task') {
    // 执行计算
    const result = msg.data.numbers.reduce((sum, n) => sum + n, 0);

    // 子→父 发送结果
    process.send({ type: 'result', data: result });
  }
});
```

## 12.2 spawn vs exec：什么时候用哪个？

| 特性 | exec/execFile | spawn |
| ------ | -------------- | ------- |
| 输出方式 | 缓存后一次性返回 | 流式 |
| 大量输出 | ❌ 有 maxBuffer 限制 | ✅ 无限 |
| shell 特性 | exec 支持 | 需要 shell:true |
| 适合场景 | 短命令、小输出 | 长时间运行、大输出 |
| API 风格 | callback/Promise | EventEmitter + Stream |

```javascript
// ✅ exec 适合的场景：
// - 获取 git 版本
const { stdout } = await execAsync('git --version');

// - 获取系统信息
const { stdout: whoami } = await execAsync('whoami');

// ✅ spawn 适合的场景：
// - 实时日志跟踪
const tail = spawn('tail', ['-f', '/var/log/app.log']);
tail.stdout.on('data', (line) => processLogLine(line));

// - 视频转码（长时间运行）
const ffmpeg = spawn('ffmpeg', ['-i', 'input.mp4', '-c:v', 'h264', 'output.mp4']);
```

## 12.3 进程间通信（IPC）

### fork + message

```typescript
// cpu-task.ts（子进程）
interface TaskMessage {
  type: 'compute';
  id: string;
  data: number[];
}

interface ResultMessage {
  type: 'result';
  id: string;
  result: number;
  duration: number;
}

process.on('message', (msg: TaskMessage) => {
  if (msg.type === 'compute') {
    const start = performance.now();

    // 模拟 CPU 密集计算
    const result = msg.data.reduce((sum, n) => {
      // 做一些"昂贵"的计算
      let temp = n;
      for (let i = 0; i < 1000000; i++) {
        temp = Math.sqrt(temp * temp + 1);
      }
      return sum + temp;
    }, 0);

    const duration = performance.now() - start;

    process.send!({
      type: 'result',
      id: msg.id,
      result,
      duration,
    } satisfies ResultMessage);
  }
});
```

```typescript
// main.ts（父进程）
import { fork } from 'node:child_process';
import { randomUUID } from 'node:crypto';

class WorkerPool {
  private workers: ReturnType<typeof fork>[] = [];
  private taskQueue: Map<string, {
    resolve: (value: any) => void;
    reject: (error: Error) => void;
  }> = new Map();
  private currentWorker = 0;

  constructor(workerScript: string, poolSize: number) {
    for (let i = 0; i < poolSize; i++) {
      const worker = fork(workerScript);

      worker.on('message', (msg: any) => {
        if (msg.type === 'result') {
          const task = this.taskQueue.get(msg.id);
          if (task) {
            task.resolve(msg);
            this.taskQueue.delete(msg.id);
          }
        }
      });

      worker.on('error', (err) => {
        console.error(`Worker ${i} 错误:`, err);
      });

      this.workers.push(worker);
    }
    console.log(`工作池已创建，${poolSize} 个 worker`);
  }

  async execute(data: number[]): Promise<any> {
    const id = randomUUID();

    return new Promise((resolve, reject) => {
      this.taskQueue.set(id, { resolve, reject });

      // 轮询选择 worker
      const worker = this.workers[this.currentWorker % this.workers.length];
      this.currentWorker++;

      worker.send({ type: 'compute', id, data });

      // 超时处理
      setTimeout(() => {
        if (this.taskQueue.has(id)) {
          this.taskQueue.delete(id);
          reject(new Error('任务超时'));
        }
      }, 30000);
    });
  }

  destroy(): void {
    for (const worker of this.workers) {
      worker.kill();
    }
  }
}

// 使用
const pool = new WorkerPool('./cpu-task.js', 4);

const results = await Promise.all([
  pool.execute([1, 2, 3]),
  pool.execute([4, 5, 6]),
  pool.execute([7, 8, 9]),
]);

console.log('计算结果:', results);
pool.destroy();
```

## 12.4 cluster 模块：多进程负载均衡

```javascript
import cluster from 'node:cluster';
import { createServer } from 'node:http';
import { availableParallelism } from 'node:os';

const numCPUs = availableParallelism(); // Node.js 20+ 推荐用这个

if (cluster.isPrimary) {
  console.log(`主进程 ${process.pid} 启动`);
  console.log(`CPU 核心数: ${numCPUs}`);

  // 创建工作进程
  for (let i = 0; i < numCPUs; i++) {
    cluster.fork();
  }

  // 工作进程退出时重启
  cluster.on('exit', (worker, code, signal) => {
    console.log(`工作进程 ${worker.process.pid} 退出 (${signal || code})`);
    console.log('重启新的工作进程...');
    cluster.fork();
  });

  // 收到工作进程消息
  cluster.on('message', (worker, message) => {
    console.log(`[Worker ${worker.id}] ${JSON.stringify(message)}`);
  });
} else {
  // 工作进程：创建 HTTP 服务器
  const server = createServer((req, res) => {
    // 模拟一些处理时间
    const result = heavyComputation();
    res.writeHead(200);
    res.end(`Worker ${process.pid}: ${result}\n`);
  });

  server.listen(8000, () => {
    console.log(`工作进程 ${process.pid} 启动，监听端口 8000`);
  });

  // 向主进程报告状态
  process.send?.({ type: 'ready', pid: process.pid });
}

function heavyComputation() {
  let sum = 0;
  for (let i = 0; i < 1e7; i++) {
    sum += Math.sqrt(i);
  }
  return sum;
}
```

### cluster 的调度策略

```javascript
import cluster from 'node:cluster';

// 设置调度策略
// cluster.SCHED_RR：轮询（Round-Robin），默认在非 Windows 系统
// cluster.SCHED_NONE：操作系统调度
cluster.schedulingPolicy = cluster.SCHED_RR;
```

| 策略 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| SCHED_RR | 主进程轮询分配 | 负载均匀 | 主进程成为瓶颈 |
| SCHED_NONE | OS 调度 | 主进程无压力 | 可能负载不均 |

## 12.6 实战案例

### 实战1：利用 cluster 实现多核 HTTP 服务器

```typescript
import cluster from 'node:cluster';
import { createServer, IncomingMessage, ServerResponse } from 'node:http';
import { availableParallelism } from 'node:os';

if (cluster.isPrimary) {
  const numWorkers = availableParallelism();
  console.log(`🚀 主进程 PID: ${process.pid}`);
  console.log(`📦 启动 ${numWorkers} 个工作进程...`);

  const workers: Map<number, ReturnType<typeof cluster.fork>> = new Map();

  for (let i = 0; i < numWorkers; i++) {
    const worker = cluster.fork();
    workers.set(worker.id, worker);
  }

  // 监控工作进程
  cluster.on('exit', (worker, code, signal) => {
    workers.delete(worker.id);
    console.log(`⚠️  Worker ${worker.id} (PID: ${worker.process.pid}) 退出 [${signal || code}]`);

    // 非正常退出时重启
    if (code !== 0 && !worker.exitedAfterDisconnect) {
      console.log('🔄 重启新的工作进程...');
      const newWorker = cluster.fork();
      workers.set(newWorker.id, newWorker);
    }
  });

  // 统计请求数
  let totalRequests = 0;
  cluster.on('message', (worker, msg) => {
    if (msg.type === 'request') {
      totalRequests++;
    }
  });

  // 每 10 秒打印统计信息
  setInterval(() => {
    console.log(`📊 总请求数: ${totalRequests}, 活跃 Worker: ${workers.size}`);
  }, 10000);

  // 优雅关闭
  process.on('SIGTERM', () => {
    console.log('收到 SIGTERM，优雅关闭...');
    for (const [id, worker] of workers) {
      worker.send({ type: 'shutdown' });
    }
    setTimeout(() => process.exit(0), 5000);
  });

} else {
  const server = createServer((req: IncomingMessage, res: ServerResponse) => {
    // 通知主进程
    process.send?.({ type: 'request' });

    // 简单路由
    if (req.url === '/health') {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({
        status: 'ok',
        pid: process.pid,
        uptime: process.uptime(),
        memory: process.memoryUsage(),
      }));
    } else {
      res.writeHead(200, { 'Content-Type': 'text/plain' });
      res.end(`Hello from Worker ${process.pid}\n`);
    }
  });

  server.listen(3000);
  console.log(`  Worker ${cluster.worker?.id} (PID: ${process.pid}) 就绪`);

  // 监听关闭信号
  process.on('message', (msg: any) => {
    if (msg.type === 'shutdown') {
      console.log(`Worker ${process.pid} 开始优雅关闭...`);
      server.close(() => {
        process.exit(0);
      });
    }
  });
}
```

### 实战2：子进程执行 CPU 密集任务

```javascript
import { fork } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const __dirname = dirname(fileURLToPath(import.meta.url));

/**
 * 将 CPU 密集任务交给子进程
 */
function computeInProcess(data) {
  return new Promise((resolve, reject) => {
    const child = fork(join(__dirname, 'compute-worker.js'));

    child.send(data);

    child.on('message', (result) => {
      resolve(result);
      child.kill();
    });

    child.on('error', reject);

    child.on('exit', (code) => {
      if (code !== 0) {
        reject(new Error(`Worker 异常退出: ${code}`));
      }
    });
  });
}

// 在 HTTP 服务器中使用
import { createServer } from 'node:http';

const server = createServer(async (req, res) => {
  if (req.url === '/fibonacci') {
    // 不阻塞主线程！
    const result = await computeInProcess({ type: 'fibonacci', n: 45 });
    res.end(JSON.stringify(result));
  } else {
    // 其他请求不受影响
    res.end('Hello World');
  }
});

server.listen(3000);
```

```javascript
// compute-worker.js
process.on('message', (msg) => {
  let result;

  switch (msg.type) {
    case 'fibonacci':
      result = fibonacci(msg.n);
      break;
    case 'prime':
      result = isPrime(msg.n);
      break;
    default:
      result = null;
  }

  process.send({ type: msg.type, input: msg.n, result });
});

function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

function isPrime(n) {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}
```

### 实战3：优雅重启（Graceful Reload）

```typescript
import cluster from 'node:cluster';
import { availableParallelism } from 'node:os';

if (cluster.isPrimary) {
  const numWorkers = availableParallelism();

  for (let i = 0; i < numWorkers; i++) {
    cluster.fork();
  }

  /**
   * 优雅重启所有工作进程
   * 策略：逐个重启，确保始终有活跃的 worker 处理请求
   */
  async function gracefulReload() {
    const workers = Object.values(cluster.workers || {});
    console.log(`开始优雅重启 ${workers.length} 个工作进程...`);

    for (const worker of workers) {
      if (!worker) continue;

      // 1. 启动新 worker
      const newWorker = cluster.fork();

      // 2. 等待新 worker 就绪
      await new Promise<void>((resolve) => {
        newWorker.on('listening', () => {
          console.log(`新 Worker ${newWorker.id} 就绪`);
          resolve();
        });
      });

      // 3. 通知旧 worker 停止接收新请求
      worker.send({ type: 'shutdown' });

      // 4. 等待旧 worker 处理完现有请求后退出
      await new Promise<void>((resolve) => {
        worker.on('exit', () => {
          console.log(`旧 Worker ${worker.id} 已退出`);
          resolve();
        });

        // 超时强制 kill
        setTimeout(() => {
          worker.kill('SIGKILL');
          resolve();
        }, 10000);
      });
    }

    console.log('所有工作进程已重启完成！');
  }

  // 收到 SIGUSR2 信号时优雅重启
  process.on('SIGUSR2', () => {
    console.log('收到 SIGUSR2，开始优雅重启...');
    gracefulReload();
  });

  console.log(`主进程 ${process.pid} 启动`);
  console.log(`发送 kill -USR2 ${process.pid} 触发优雅重启`);
}
```

## 12.7 worker_threads 预览

`worker_threads` 是 Node.js 的多线程方案，将在第21章深入讲解。这里做个简单对比：

| 特性 | child_process | cluster | worker_threads |
| ------ | -------------- | --------- | ---------------- |
| 创建开销 | 大（新进程） | 大（新进程） | 小（新线程） |
| 内存隔离 | 完全隔离 | 完全隔离 | 共享（SharedArrayBuffer） |
| 通信方式 | IPC（序列化） | IPC | MessagePort / SharedMemory |
| 适用场景 | 执行外部命令 | HTTP 负载均衡 | CPU 密集计算 |
| 崩溃影响 | 不影响主进程 | 不影响主进程 | 不影响主线程 |

```javascript
// worker_threads 快速示例
import { Worker, isMainThread, parentPort } from 'node:worker_threads';

if (isMainThread) {
  const worker = new Worker(new URL(import.meta.url));
  worker.on('message', (msg) => console.log('收到:', msg));
  worker.postMessage({ n: 42 });
} else {
  parentPort!.on('message', (msg) => {
    const result = heavyComputation(msg.n);
    parentPort!.postMessage(result);
  });
}
```

## 12.8 常见坑点

### 坑1：exec 的 maxBuffer

```javascript
// ❌ 输出超过 maxBuffer 时会报错
const { stdout } = await execAsync('find / -name "*.log"');
// Error: maxBuffer length exceeded

// ✅ 大输出用 spawn
const child = spawn('find', ['/', '-name', '*.log']);
const chunks = [];
child.stdout.on('data', (chunk) => chunks.push(chunk));
child.on('close', () => {
  const output = Buffer.concat(chunks).toString();
});
```

### 坑2：僵尸进程

```javascript
// ❌ 子进程可能变成僵尸进程（已退出但未被回收）
const child = spawn('some-command');
// 如果父进程不监听 'exit' 事件...

// ✅ 始终处理子进程的退出
child.on('exit', (code) => {
  console.log(`子进程退出: ${code}`);
});

// 或者使用 unref()，让子进程不阻止父进程退出
child.unref();
```

### 坑3：IPC 传输大数据

```javascript
// ❌ 通过 IPC 传输大对象很慢（需要序列化/反序列化）
process.send({ type: 'data', payload: hugeArray }); // 慢！

// ✅ 大数据通过共享内存或文件传输
// 使用 SharedArrayBuffer（worker_threads）
// 或者写入临时文件，只传递文件路径
```

### 坑4：Windows 上 shell 命令

```javascript
// ❌ Unix 命令在 Windows 上不存在
spawn('ls', ['-la']); // Windows: ENOENT

// ✅ 跨平台方案
import { platform } from 'node:os';

if (platform() === 'win32') {
  spawn('dir', [], { shell: true });
} else {
  spawn('ls', ['-la']);
}

// 或者使用 cross-spawn 库
// import spawn from 'cross-spawn';
```

## 12.9 本章小结

| 方法 | 用途 | 通信方式 |
| ------ | ------ | --------- |
| exec | 执行 shell 命令，获取输出 | 缓冲 stdout/stderr |
| execFile | 执行文件（更安全） | 缓冲 stdout/stderr |
| spawn | 长时间运行的命令 | Stream |
| fork | Node.js 子进程 | IPC (send/message) |
| cluster | 多进程负载均衡 | IPC |

**核心原则**：

1. CPU 密集任务交给子进程/线程
2. HTTP 服务用 cluster 利用多核
3. 短命令用 exec，长命令用 spawn
4. 生产环境用 PM2 管理进程
5. 注意命令注入安全问题
6. 实现优雅重启，避免请求中断
