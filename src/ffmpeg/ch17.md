# 第17章：高级视频效果

如果说前面的章节是在学习"标准菜谱"，这一章就是进入"创意料理"的领域。我们将学习如何用 FFmpeg 实现电影级调色、音频可视化、故障艺术、老电影效果、转场动画等一系列高级视觉效果。这些效果单独使用就已经很酷，组合起来更能创造出无限可能。

## 17.1 3D LUT 应用详解：电影色调一键预设

第 14 章中我们简单提到了 `lut3d`，这里来深入讲解。

### 什么是 3D LUT？

3D LUT（三维查找表）本质上是一个"颜色映射立方体"。想象一个 RGB 三维空间，每个维度从 0 到 255。LUT 定义了这个空间中每个输入颜色应该映射到什么输出颜色。它之所以叫"3D"，是因为红、绿、蓝三个通道同时被映射，不像 1D LUT 那样各通道独立。

### 获取 LUT 文件

网上有大量免费和付费的 LUT 文件：

- **免费资源**：FreshLuts、RocketStock、PremiumBeat 博客
- **付费资源**：MotionVFX、Color Grading Central
- **自制**：在 DaVinci Resolve 中调色后导出 .cube 文件

### 使用 LUT

```bash
# 应用电影色调 LUT
ffmpeg -i input.mp4 -vf "lut3d=file=orange_teal.cube" output.mp4

# LUT + 额外微调（LUT 后再接一个 eq 做微调）
ffmpeg -i input.mp4 -vf "lut3d=file=warm_cinematic.cube,eq=contrast=1.05:saturation=0.95" output.mp4
```

### LUT 强度控制

有时 LUT 效果太强，你想用"50% 强度"的 LUT 效果。FFmpeg 没有直接的参数，但可以用混合的方式实现：

```bash
# 50% 强度的 LUT：将 LUT 处理后的画面与原画面混合
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]lut3d=file=cinematic.cube[lutted];\
    [0:v][lutted]blend=all_mode=normal:all_opacity=0.5" \
  output.mp4
```

**原理**：用 `split`（隐式地通过两次引用 `[0:v]`）获得两份输入，一份应用 LUT，另一份保持原样，然后 50% 混合。

## 17.2 色彩分级工作流：从 raw 素材到成片

专业的调色通常分为两步：**一级调色（Primary Grading）**和**二级调色（Secondary Grading）**。

```bash
# 完整调色工作流
ffmpeg -i raw_footage.mp4 \
  -vf "\
    eq=brightness=0.02:contrast=1.1:saturation=1.05,\
    colorbalance=ms=0.05:mh=0.03,\
    curves=m='0/0 0.25/0.2 0.5/0.52 0.75/0.8 1/1',\
    lut3d=file=final_look.cube,\
    eq=saturation=0.95" \
  output.mp4
```

**工作流解读**：

1. **一级调色**：`eq` 做基础亮度/对比度校正
2. **色温微调**：`colorbalance` 调整中间调偏暖
3. **曲线精调**：`curves` 做 S 曲线增强对比度
4. **风格化**：`lut3d` 应用最终色调风格
5. **最终微调**：`eq` 轻微降低饱和度避免过艳

## 17.3 运动模糊：tmix 滤镜

FFmpeg 没有原生的 `mblur` 滤镜，但可以用 `tmix`（时间混合）模拟运动模糊效果：

```bash
# 用 tmix 模拟运动模糊（混合前后 5 帧）
ffmpeg -i input.mp4 -vf "tmix=frames=5:weights='1 1 1 1 1'" output.mp4
```

`tmix` 将相邻帧按权重混合，产生运动模糊效果。权重数组中的数字决定每帧的贡献度。

```bash
# 更自然的运动模糊（中间帧权重最大）
ffmpeg -i input.mp4 -vf "tmix=frames=5:weights='1 2 4 2 1'" output.mp4
```

**适用场景**：低帧率视频看起来卡顿、想让快速运动的画面更"丝滑"、创意效果。

## 17.4 时间戳烧录：drawtext + 变量

`drawtext` 滤镜支持动态变量，可以在画面上烧录实时变化的时间信息。

```bash
# 烧录当前帧的时间码（HH:MM:SS 格式）
ffmpeg -i input.mp4 \
  -vf "drawtext=text='%{pts\:hms}':fontsize=24:fontcolor=white:x=10:y=10:box=1:boxcolor=black@0.5:boxborderw=5" \
  output.mp4
```

```bash
# 烧录帧号
ffmpeg -i input.mp4 \
  -vf "drawtext=text='Frame %{n}':fontsize=24:fontcolor=yellow:x=10:y=H-40" \
  output.mp4
```

```bash
# 自定义时间码格式 + 日期
ffmpeg -i input.mp4 \
  -vf "drawtext=text='%{localtime\\:%Y-%m-%d %H\\\\\\:%M\\\\\\:%S}':fontsize=20:fontcolor=white:x=W-tw-10:y=10" \
  output.mp4
```

**常用变量**：

| 变量 | 说明 |
| ------ | ------ |
| `%{pts:hms}` | 当前帧时间（HH:MM:SS.mmm） |
| `%{pts}` | 当前帧时间戳（秒，浮点数） |
| `%{n}` | 当前帧号 |
| `%{localtime}` | 本地系统时间 |
| `%{metadata:key}` | 视频元数据中的某个字段 |

**适用场景**：监控视频标注时间、Vlog 显示拍摄时间、技术审核用时间码、教育视频中标注进度。

## 17.5 视频信息叠加：波形图、直方图、矢量图

FFmpeg 内置了一系列专业级的信号分析可视化工具，让你可以在画面上叠加各种"示波器"。

### showwaves：音频波形图

```bash
# 将音频波形渲染为视频
ffmpeg -i input.mp4 \
  -filter_complex "[0:a]showwaves=s=640x200:mode=line:colors=white[waves];\
    [0:v][waves]overlay=0:H-h" \
  -c:a copy output.mp4
```

### showfreqs：频谱图

```bash
# 将音频频谱渲染为视频并叠加到画面上
ffmpeg -i input.mp4 \
  -filter_complex "[0:a]showfreqs=s=640x200:mode=line:colors=cyan[freqs];\
    [0:v][freqs]overlay=0:H-h" \
  -c:a copy output.mp4
```

### vectorscope：矢量示波器

```bash
# 在画面右下角叠加矢量示波器
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]split[main][scope];\
    [scope]vectorscope=m=color4:graticule=green,\
    scale=256:256[vs];\
    [main][vs]overlay=W-w-10:H-h-10" \
  output.mp4
```

**适用场景**：视频调色时监控色彩分布、音频可视化 MV、技术分析视频信号质量。

## 17.6 音频可视化：将音频渲染为视频叠加层

这是将 17.5 节的工具组合成一个完整的"音频可视化"效果：

```bash
# 底部显示波形 + 频谱的音频可视化
ffmpeg -i input.mp3 \
  -filter_complex "\
    color=c=black:s=1280x720:r=30[bg];\
    [0:a]showwaves=s=1280x360:mode=cline:colors=0x00FF00|0xFF0000[waves];\
    [0:a]showfreqs=s=1280x360:mode=line:colors=yellow|cyan[freqs];\
    [bg][waves]overlay=0:0[v1];\
    [v1][freqs]overlay=0:360" \
  -c:a copy output.mp4
```

## 17.7 变形效果：geq 通用表达式滤镜

`geq`（Generic Equation）是 FFmpeg 中最灵活也最复杂的滤镜——它允许你用数学表达式逐像素地操作画面。

```bash
# 水平波纹效果
ffmpeg -i input.mp4 \
  -vf "geq=lum='lum(X+20*sin(2*PI*Y/200+T*5),Y)':cb='cb(X,Y)':cr='cr(X,Y)'" \
  output.mp4
```

**geq 的表达式变量**：

| 变量 | 说明 |
| ------ | ------ |
| `X`, `Y` | 当前像素坐标 |
| `W`, `H` | 画面宽高 |
| `N` | 当前帧号 |
| `T` | 当前时间（秒） |

```bash
# 漩涡效果
ffmpeg -i input.mp4 \
  -vf "geq=lum='lum(W/2+(X-W/2)*cos(0.02*T)+(Y-H/2)*sin(0.02*T), H/2-(X-W/2)*sin(0.02*T)+(Y-H/2)*cos(0.02*T))'" \
  output.mp4

# 像素化效果（马赛克风格）
ffmpeg -i input.mp4 \
  -vf "geq=lum='lum(int(X/16)*16,int(Y/16)*16)':cb='cb(int(X/16)*16,int(Y/16)*16)':cr='cr(int(X/16)*16,int(Y/16)*16)'" \
  output.mp4
```

## 17.8 故障效果（Glitch Art）

故障艺术是一种故意制造"数据损坏"视觉效果的创意风格。

```bash
# 基础故障效果：噪声 + 色彩通道偏移
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]split[main][glitch];\
    [glitch]noise=alls=30:allf=t+u,\
    shuffleplanes=0:2:1:0,\
    crop=iw-10:ih:5:0,\
    pad=iw+10:ih:0:0[gl];\
    [main][gl]blend=all_mode=screen:all_opacity=0.4" \
  output.mp4
```

```bash
# 简单的 RGB 分离故障
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]split=3[r][g][b];\
    [r]crop=iw:ih:5:0,lutrgb=g=0:b=0,pad=iw+5:ih:0:0[r2];\
    [b]crop=iw:ih:-5:0,lutrgb=r=0:g=0,pad=iw+5:ih:5:0[b2];\
    [g]lutrgb=r=0:b=0[g2];\
    [r2][g2]blend=all_mode=addition[rg];\
    [rg][b2]blend=all_mode=addition" \
  output.mp4
```

**适用场景**：MV/音乐视频、恐怖片预告、赛博朋克风格、科技类视频转场。

## 17.9 老电影效果

通过组合多个滤镜，可以模拟老式胶片的视觉效果：

```bash
ffmpeg -i input.mp4 \
  -vf "\
    eq=saturation=0.3:brightness=-0.05:contrast=1.1,\
    noise=alls=15:allf=t,\
    unsharp=3:3:-0.5,\
    vignette=PI/4,\
    eq=brightness=-0.02,\
    curves=m='0/0.02 0.1/0.08 0.9/0.92 1/0.98'" \
  output.mp4
```

**效果拆解**：

1. `eq=saturation=0.3`：大幅降低饱和度，模拟褪色的胶片
2. `noise=alls=15`：添加胶片颗粒感
3. `unsharp=3:3:-0.5`：轻微模糊，模拟老旧镜头的"柔焦"
4. `vignette=PI/4`：添加暗角（老式镜头边缘暗）
5. `curves`：压缩黑位和白位，模拟胶片有限的动态范围

**进阶版——加入闪烁和刮痕**：

```bash
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]eq=saturation=0.3:contrast=1.1,\
    noise=alls=20:allf=t+u,\
    vignette=PI/5,\
    curves=m='0/0.03 1/0.97',\
    fps=18" \
  output.mp4
```

`fps=18` 将帧率降到 18fps，模拟老式放映机的不流畅感。

## 17.10 马赛克效果：区域模糊

使用 `boxblur` 或 `avgblur` 配合 `overlay` 可以实现局部马赛克：

```bash
# 对画面中的特定区域（人脸位置）打马赛克
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]crop=200:200:300:150,\
    boxblur=20:5[blur];\
    [0:v][blur]overlay=300:150" \
  output.mp4
```

**步骤**：

1. `crop=200:200:300:150`：裁切出需要打码的区域（宽200 高200 起始位置300,150）
2. `boxblur=20:5`：对裁切区域进行模糊
3. `overlay=300:150`：将模糊后的区域叠回原位置

**动态跟踪马赛克**（如果目标在移动，需要结合 `vidstabdetect` 或外部工具获取位置数据）。

## 17.11 转场效果：xfade 滤镜

**这是高频使用滤镜，需要重点掌握。**

`xfade` 是 FFmpeg 4.3+ 引入的转场滤镜，支持多种内置转场效果。

### 基本语法

```bash
# 两个视频之间添加淡入淡出转场
ffmpeg -i clip1.mp4 -i clip2.mp4 \
  -filter_complex "\
    [0:v][1:v]xfade=transition=fade:duration=1:offset=4" \
  output.mp4
```

| 参数 | 说明 |
| ------ | ------ |
| `transition` | 转场类型（见下方列表） |
| `duration` | 转场持续时间（秒） |
| `offset` | 转场开始时间（相对于第一个视频的时间，秒） |

### 内置转场类型

| transition 值 | 效果描述 |
| --------------- | --------- |
| `fade` | 淡入淡出（最经典） |
| `wipeleft` | 从右向左擦除 |
| `wiperight` | 从左向右擦除 |
| `wipeup` | 从下向上擦除 |
| `wipedown` | 从上向下擦除 |
| `slideleft` | 从右向左滑动 |
| `slideright` | 从左向右滑动 |
| `slideup` | 从下向上滑动 |
| `slidedown` | 从上向下滑动 |
| `circlecrop` | 圆形裁切 |
| `rectcrop` | 矩形裁切 |
| `dissolve` | 溶解（比 fade 更有颗粒感） |
| `pixelize` | 像素化过渡 |
| `horzopen` | 从中间向两侧打开 |
| `horzclose` | 从两侧向中间关闭 |
| `vertopen` | 从中间向上下打开 |
| `vertclose` | 从上下向中间关闭 |
| `diagbl` | 对角线（左下到右上） |
| `diagtl` | 对角线（左上到右下） |
| `radial` | 径向扫描 |
| `smoothleft` | 平滑左擦除 |
| `smoothright` | 平滑右擦除 |
| `smoothup` | 平滑上擦除 |
| `smoothdown` | 平滑下擦除 |
| `circleopen` | 圆形打开 |
| `circleclose` | 圆形关闭 |
| `squeezev` | 垂直挤压 |
| `squeezeh` | 水平挤压 |
| `zoomin` | 放大进入 |
| `hlwind` | 水平风 |
| `hrwind` | 水平风（反向） |
| `coverleft` | 覆盖（向左） |
| `coverright` | 覆盖（向右） |
| `coverup` | 覆盖（向上） |
| `coverdown` | 覆盖（向下） |
| `revealleft` | 揭示（向左） |
| `revealright` | 揭示（向右） |
| `revealup` | 揭示（向上） |
| `revealdown` | 揭示（向下） |

### 多段视频连续转场

当有 3 个或更多视频需要连续转场时，需要链式使用 `xfade`：

```bash
# 3 段视频，每段 5 秒，转场 1 秒
ffmpeg -i clip1.mp4 -i clip2.mp4 -i clip3.mp4 \
  -filter_complex "\
    [0:v][1:v]xfade=transition=fade:duration=1:offset=4[v01];\
    [v01][2:v]xfade=transition=wipeleft:duration=1:offset=8" \
  output.mp4
```

**offset 计算方法**：

- 第一个转场的 offset = clip1 的时长 - 转场时长
- 第二个转场的 offset = clip1 时长 + clip2 时长 - 2×转场时长
- 以此类推……

```bash
# 通用公式（假设每段视频 5 秒，转场 1 秒）
# offset_n = sum(durations[0..n]) - n * transition_duration
# offset_0 = 5 - 1 = 4
# offset_1 = 5 + 5 - 2*1 = 8
# offset_2 = 5 + 5 + 5 - 3*1 = 12
```

### 带音频的转场

视频转场通常也需要配合音频转场（交叉淡化）：

```bash
ffmpeg -i clip1.mp4 -i clip2.mp4 \
  -filter_complex "\
    [0:v][1:v]xfade=transition=fade:duration=1:offset=4[vout];\
    [0:a][1:a]acrossfade=d=1:c1=tri:c2=tri[aout]" \
  -map "[vout]" -map "[aout]" output.mp4
```

`acrossfade` 是音频的交叉淡化滤镜，参数 `d` 是淡化时长，`c1`/`c2` 是淡入淡出曲线。
