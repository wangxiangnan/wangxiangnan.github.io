## 2.1 引言：一切从一个空文件夹开始

还记得我第一次创建 React 项目的时候，对着黑漆漆的终端窗口敲下第一行命令，然后看着满屏滚动的安装日志——那种感觉，就像打开一个神秘的宝箱，满心期待着里面会蹦出什么好东西。

今天，我要带你一起体验这个过程。别担心，我会一步一步来，每一步都告诉你"为什么这么做"。当你看到浏览器中出现那个旋转的 React Logo 时，相信我，你会上瘾的。

## 2.2 第一步：安装 Node.js

React 的开发离不开 Node.js。为什么？因为我们需要用它来运行开发服务器、打包代码、安装各种工具包。你可以把 Node.js 理解为"让 JavaScript 能在你的电脑上运行的引擎"——就像浏览器能运行 JS 一样，Node.js 让你的终端也能运行 JS。

**安装方法：**

1. 打开 [Node.js 官网](https://nodejs.org)
2. 下载 **LTS（长期支持）版本**——这个版本最稳定
3. 双击安装包，一路 Next 就行

安装完成后，打开终端验证一下：

```bash
# 检查 Node.js 版本
node --version
# 输出类似：v20.11.0（数字可能不同，没关系）

# 检查 npm 版本（npm 是 Node.js 的包管理器，安装 Node.js 时会自动带上）
npm --version
# 输出类似：10.2.4
```

> [!TIP] 提示
> 如果你看到版本号输出，说明安装成功了！如果提示"命令未找到"，可能需要重启终端，或者检查一下 Node.js 是否加入了系统 PATH 环境变量。

> [!WARNING] 注意
> 不要用太旧的 Node.js 版本。React 和 Vite 要求 Node.js 版本 >= 18.0。如果你的版本低于 18，请升级到最新的 LTS 版本。

## 2.3 为什么选择 Vite？

在创建项目之前，先聊聊我们的"脚手架"工具。

过去几年，React 社区创建项目的标准方式是 **Create React App（CRA）**——它是 Facebook 官方出品的脚手架工具。但问题是，随着项目变大，CRA 越来越慢了。启动一个开发服务器要等几十秒，热更新也要好几秒——这对于追求效率的开发者来说简直是折磨。

于是，**Vite** 横空出世。

> **比喻时间：** 如果说 Create React App 是一辆自行车——可靠但有点慢，那 Vite 就是一枚火箭助推器。你的开发体验直接从"蹬自行车"升级到"坐火箭"。

Vite 有多快？

| 操作 | Create React App | Vite |
|------|-----------------|------|
| 首次启动开发服务器 | 约 10-30 秒 | 约 0.3-1 秒 |
| 热更新（保存代码后页面更新） | 约 1-5 秒 | 约 50-100 毫秒 |
| 构建生产版本 | 约 30-60 秒 | 约 5-15 秒 |

是的，你没看错——**Vite 比 CRA 快了大约 100 倍**。这就是我们选择 Vite 的原因。

Vite 之所以这么快，是因为它利用了浏览器原生的 **ES Modules** 支持。传统的工具（如 Webpack）需要把所有代码打包成一个文件才能运行，而 Vite 让浏览器直接按需加载各个模块——就像从"把所有食材做成一锅炖"变成了"现点现做"。

## 2.4 用 Vite 创建你的第一个 React 项目

好，激动人心的时刻到了！打开终端，输入以下命令：

```bash
# 创建一个名为 my-first-react 的 React 项目
npm create vite@latest my-first-react -- --template react
```

> [!TIP] 提示
> `--template react` 表示我们使用 React 模板。Vite 还支持 Vue、Svelte 等其他模板，但我们是 React 教程，所以用 `react` 就对了。

终端会输出一些信息，然后你会看到类似这样的提示：

```
Scaffolding project in ./my-first-react...

Done. Now run:

  cd my-first-react
  npm install
  npm run dev
```

按照提示，依次执行：

```bash
# 进入项目目录
cd my-first-react

# 安装依赖包（这一步会下载 React 和其他需要的包）
npm install

# 启动开发服务器
npm run dev
```

执行 `npm run dev` 后，你会看到类似这样的输出：

```
  VITE v5.1.0  ready in 320 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

**打开浏览器，访问 `http://localhost:5173/`**

🎉 **恭喜你！你看到了你的第一个 React 应用！** 页面上应该有一个旋转的 React Logo 和一段欢迎文字。

> [!TIP] 提示
> 开发服务器会一直运行在后台。只要你不按 `Ctrl + C` 停止它，每次你保存代码，浏览器都会自动更新。这就是"热更新"（HMR - Hot Module Replacement）。

## 2.5 项目结构解读：每个文件都是干嘛的？

现在让我们来看看 Vite 帮我们生成了哪些文件：

```
my-first-react/
├── node_modules/     ← 依赖包的存放目录（自动生成的，不用管它）
├── public/           ← 静态资源目录
│   └── vite.svg      ← Vite 的 Logo
├── src/              ← ★ 源代码目录（我们的代码都写在这里！）
│   ├── assets/       ← 资源文件（图片、字体等）
│   │   └── react.svg ← React 的 Logo
│   ├── App.css       ← App 组件的样式
│   ├── App.jsx       ← ★ App 组件（主组件）
│   ├── index.css     ← 全局样式
│   └── main.jsx      ← ★ 入口文件（应用从这里启动）
├── .gitignore        ← Git 忽略配置
├── index.html        ← HTML 模板
├── package.json      ← 项目配置和依赖清单
├── package-lock.json ← 依赖版本锁定文件（自动生成）
└── vite.config.js    ← Vite 配置文件
```

让我们重点看几个关键文件：

### 2.5.1 `index.html` —— 入口 HTML

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite + React</title>
  </head>
  <body>
    <!-- React 应用会挂载到这个 div 上 -->
    <div id="root"></div>
    <!-- 引入入口 JS 文件 -->
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
```

注意看那个 `<div id="root"></div>`——这就是 React 应用的"舞台"。所有的 React 组件最终都会被渲染到这个 div 里面。

### 2.5.2 `main.jsx` —— 应用的入口

```jsx
// 导入 React 的严格模式组件
import { StrictMode } from 'react'
// 导入创建 DOM 渲染的工具
import { createRoot } from 'react-dom/client'
// 导入全局样式
import './index.css'
// 导入 App 组件
import App from './App.jsx'

// 找到 id 为 root 的 DOM 元素
// 创建一个 React 根节点
// 把 App 组件渲染上去
createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

这段代码做了三件关键的事情：

1. 找到页面上的 `#root` 元素
2. 创建一个 React 根节点
3. 把 `App` 组件渲染到这个根节点里

### 2.5.3 `App.jsx` —— 你的主组件

```jsx
import { useState } from 'react'      // 导入 useState Hook
import reactLogo from './assets/react.svg'  // 导入图片
import viteLogo from '/vite.svg'       // 导入 Vite Logo
import './App.css'                     // 导入组件样式

// 定义 App 组件
function App() {
  // 创建一个状态变量 count，初始值为 0
  // setCount 是用来更新 count 的函数
  const [count, setCount] = useState(0)

  // 返回 JSX（看起来像 HTML，但其实是 JavaScript）
  return (
    <>
      <div>
        <a href="https://vite.dev" target="_blank">
          <img src={viteLogo} className="logo" alt="Vite logo" />
        </a>
        <a href="https://react.dev" target="_blank">
          <img src={reactLogo} className="logo react" alt="React logo" />
        </a>
      </div>
      <h1>Vite + React</h1>
      <div className="card">
        {/* 点击按钮时，count 加 1 */}
        <button onClick={() => setCount((count) => count + 1)}>
          count is {count}
        </button>
        <p>
          Edit <code>src/App.jsx</code> and save to test HMR
        </p>
      </div>
      <p className="read-the-docs">
        Click on the Vite and React logos to learn more
      </p>
    </>
  )
}

// 导出组件，让其他文件可以使用
export default App
```

> [!WARNING] 注意
> 注意看 `<></>` 这对标签——它叫 **Fragment（片段）**，是 React 提供的一种"隐形包装"。因为 React 要求组件返回的内容必须包裹在一个根元素里，如果你不想多加一层 `<div>`，就可以用 `<>...</>` 来代替。

### 2.5.4 `package.json` —— 项目的身份证

```json
{
  "name": "my-first-react",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^19.0.0",
    "react-dom": "^19.0.0"
  },
  "devDependencies": {
    "@eslint/js": "^9.17.0",
    "@types/react": "^19.0.0",
    "@vitejs/plugin-react": "^4.3.4",
    "eslint": "^9.17.0",
    "eslint-plugin-react": "^7.37.2",
    "eslint-plugin-react-hooks": "^5.0.0",
    "globals": "^15.14.0",
    "vite": "^6.0.0"
  }
}
```

这个文件里有几个重要的地方：

- **`scripts`**：定义了各种命令。`npm run dev` 就是运行 `vite` 命令。
- **`dependencies`**：项目运行时需要的包。这里只有 `react` 和 `react-dom`——React 就是这么轻量。
- **`devDependencies`**：只在开发时需要的包（如 Vite、ESLint）。

## 2.6 你的第一次代码修改

好了，理论看够了，让我们动手改代码！

打开 `src/App.jsx`，把整个内容替换成以下代码：

```jsx
import { useState } from 'react'

// 我的第一个自定义 React 应用
function App() {
  // 定义一个"名字"状态
  const [name, setName] = useState('')
  // 定义一个"点赞数"状态
  const [likes, setLikes] = useState(0)

  return (
    <div style={{ padding: '20px', fontFamily: 'sans-serif' }}>
      {/* 标题 */}
      <h1>🎉 你好，React！</h1>
      <p>这是我的第一个 React 应用，我正在学习 React！</p>

      {/* 输入区域 */}
      <div style={{ marginBottom: '20px' }}>
        <label>你叫什么名字？</label>
        <br />
        <input
          type="text"
          value={name}
          onChange={(e) => setName(e.target.value)}
          placeholder="在这里输入你的名字..."
          style={{ padding: '8px', fontSize: '16px', marginTop: '8px' }}
        />
        {/* 如果输入了名字，就显示问候语 */}
        {name && <p style={{ color: 'blue', fontSize: '18px' }}>你好，{name}！欢迎来到 React 的世界！</p>}
      </div>

      {/* 点赞按钮 */}
      <div>
        <button
          onClick={() => setLikes(likes + 1)}
          style={{
            padding: '10px 20px',
            fontSize: '16px',
            cursor: 'pointer',
            backgroundColor: '#ff4757',
            color: 'white',
            border: 'none',
            borderRadius: '8px',
          }}
        >
          ❤️ 点赞 ({likes})
        </button>
        {likes >= 10 && <p>🎊 你已经点了 {likes} 次赞了，太热情了！</p>}
      </div>

      {/* 当前时间（每秒更新一次的小挑战，选做） */}
      <p style={{ marginTop: '30px', color: 'gray' }}>
        当前学习进度：入门第一步 ✅
      </p>
    </div>
  )
}

export default App
```

保存文件，切到浏览器——**页面应该已经自动更新了！** 不需要你手动刷新。

这就是 Vite 的 **热更新（HMR）** 魔法。你改了什么代码，它就只更新那个部分，而且速度极快（毫秒级）。

试试在页面上：

1. 在输入框里输入你的名字——看到问候语了吗？
2. 点击点赞按钮——数字在增长！
3. 点到 10 次——会弹出一条隐藏消息！

> [!TIP] 提示
> 如果页面没有自动更新，可能是热更新出了问题。试试手动刷新浏览器（F5 或 Ctrl+R）。如果还是不行，检查终端有没有报错信息。


## 2.8 开发工具推荐

好的工具能让你的开发效率翻倍。这里推荐几个：

### VS Code 插件

- **ES7+ React/Redux/React-Native snippets**：React 代码片段，输入 `rafce` 就能生成一个完整的函数组件模板

## 2.9 常见的新手困惑解答

**Q: `npm install` 太慢了怎么办？**

A: 可以设置 npm 镜像源来加速（国内用户推荐）：

```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com
```

或者每次安装时指定：

```bash
npm install --registry=https://registry.npmmirror.com
```

**Q: `node_modules` 文件夹好大，能删吗？**

A: 可以删，但删完之后要重新 `npm install`。`node_modules` 是依赖包的安装目录，`.gitignore` 文件已经帮你排除了它，所以不会被提交到 Git 仓库。

**Q: 端口 5173 被占用了怎么办？**

A: Vite 会自动切换到下一个可用端口（如 5174）。你也可以在 `vite.config.js` 中指定端口：

```javascript
export default {
  server: {
    port: 3000
  }
}
```

**Q: `.jsx` 和 `.js` 文件有什么区别？**

A: `.jsx` 表示这个 JavaScript 文件包含 JSX 语法（看起来像 HTML 的东西）。虽然 Vite 也能处理 `.js` 文件中的 JSX，但用 `.jsx` 扩展名更加语义化，推荐统一使用 `.jsx`。
