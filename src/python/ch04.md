# 第 4 章 运算符与表达式

你去菜市场买菜，摊主称完重量、算完单价、加上折扣、抹掉零头，最后给你一个总价——这一连串计算过程，在编程里就叫做**表达式**，而加减乘除、比较大小、判断是否满足条件等符号，就叫做**运算符**。Python 的运算符种类丰富，学透了它们，你就能把各种复杂的逻辑用简洁的代码表达出来。

在 Python 中，运算符可以分为几大类：**算术运算符**（做数学计算）、**比较运算符**（比较大小或是否相等）、**逻辑运算符**（组合多个条件）、**赋值运算符**（更新变量的值）、以及几个 Python 独有的特殊运算符。掌握这些运算符，就像学会了数学课上的加减乘除——它们是你编写任何程序的"基本功"。

值得一提的是，Python 的设计者在运算符上做了很多人性化的设计。比如链式比较 `a < b < c`（其他语言要写成 `a < b and b < c`）、比如 `in` 运算符检查成员关系（比写循环查找简洁得多）。这些设计让 Python 代码读起来更像自然语言，也更不容易出错。

## 4.1 算术运算符

算术运算符用来做数学计算，大部分和数学课上学的一样：

```python
a = 17
b = 5

print(a + b)    # 加法：22
print(a - b)    # 减法：12
print(a * b)    # 乘法：85
print(a / b)    # 除法：3.4（结果始终是浮点数）
print(a // b)   # 整除（地板除）：3（向下取整）
print(a % b)    # 取余（模运算）：2（17 除以 5 余 2）
print(a ** b)   # 幂运算：1419857（17 的 5 次方）
```

注意几个容易搞混的点：

- `/` 是"真除法"，结果永远是浮点数：`10 / 2` 得到 `5.0`，不是 `5`。
- `//` 是"地板除"，结果向下取整：`-7 // 2` 得到 `-4`（不是 `-3`），因为它向负无穷方向取整。
- `%` 取余运算经常用来判断奇偶（`n % 2 == 0` 为偶数）、判断整除、做循环计数器等。

```python
# 实际应用：判断一个年份是否是闰年
year = 2024
is_leap = (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
print(f"{year} 是闰年吗？{is_leap}")  # True
```

## 4.2 比较运算符

比较运算符用来比较两个值的大小或是否相等，结果总是 `True` 或 `False`：

```python
x = 10
y = 20

print(x == y)   # 等于：False
print(x != y)   # 不等于：True
print(x > y)    # 大于：False
print(x < y)    # 小于：True
print(x >= 10)  # 大于等于：True
print(x <= 5)   # 小于等于：False
```

Python 支持**链式比较**，这是很多其他语言没有的便利特性：

```python
age = 25

# Python 可以链式比较，非常直观
print(18 <= age < 60)   # True（等同于 18 <= age and age < 60）
print(0 < age < 18)     # False

# 其他语言需要写成两个条件
# age >= 18 && age < 60  （Java/C++ 写法）
```

### `==` 与 `is` 的区别

`==` 比较的是**值**是否相等，`is` 比较的是**是否是同一个对象**（内存地址是否相同）：

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True（值相等）
print(a is b)  # False（不是同一个对象，内存地址不同）

c = a
print(a is c)  # True（c 和 a 指向同一个对象）
```

对于数字、字符串等简单类型，`==` 和 `is` 通常结果一样（Python 对小整数有缓存优化）。但判断是否为 `None` 时，始终推荐用 `is`：

```python
result = None
if result is None:
    print("没有结果")
```

## 4.3 逻辑运算符

逻辑运算符用来组合多个条件，构建更复杂的判断：

```python
a = True
b = False

print(a and b)  # False（两个都为 True 才是 True）
print(a or b)   # True（至少一个为 True 就是 True）
print(not a)    # False（取反）
```

### 实际应用：组合条件

```python
age = 25
income = 8000
has_credit = True

# 贷款审批条件：年龄 18-60 且（月收入超过 5000 或有信用记录）
can_loan = (18 <= age <= 60) and (income > 5000 or has_credit)
print(f"能否贷款：{can_loan}")  # True

# 短路求值：and 中第一个条件为 False 时，不会执行第二个
# or 中第一个条件为 True 时，不会执行第二个
# 这个特性常用于安全检查：
user = None
# 下面不会报错，因为 user is not None 为 False 时，
# Python 不会去执行 user.name
name = user and user.name  # name 被赋值为 None
```

### 逻辑运算符的"短路"与返回值

逻辑运算符不一定返回 `True` 或 `False`——它返回的是参与运算的某个值本身：

```python
# and 返回第一个 falsy 值，或最后一个值
print(0 and "hello")      # 0（0 是 falsy，直接返回）
print("hello" and "world") # "world"（两个都 truthy，返回最后一个）
print(1 and 2 and 0 and 3) # 0

# or 返回第一个 truthy 值，或最后一个值
print(0 or "hello")       # "hello"（0 是 falsy，继续；"hello" 是 truthy，返回）
print("" or None or 42)   # 42
print(0 or "" or None)    # None（全是 falsy，返回最后一个）

# 实际用途：设置默认值
username = input("请输入用户名：") or "匿名用户"
# 如果用户直接回车（输入空字符串），username 会被设为 "匿名用户"
```

## 4.4 赋值运算符

赋值运算符用来更新变量的值：

```python
x = 10
x += 5    # 等同于 x = x + 5，x 现在是 15
x -= 3    # 等同于 x = x - 3，x 现在是 12
x *= 2    # 等同于 x = x * 2，x 现在是 24
x //= 5   # 等同于 x = x // 5，x 现在是 4
x **= 3   # 等同于 x = x ** 3，x 现在是 64
x %= 10   # 等同于 x = x % 10，x 现在是 4
```

这些"复合赋值运算符"不仅写起来更短，而且执行效率也略高于等价展开形式。

## 4.5 成员运算符和身份运算符

Python 还有两个"独门"运算符，在其他语言中不太常见：

```python
# in：检查某个值是否在容器中
fruits = ["苹果", "香蕉", "橘子"]
print("苹果" in fruits)      # True
print("西瓜" in fruits)      # False
print("西瓜" not in fruits)  # True

# 也适用于字符串
text = "Hello, World!"
print("World" in text)   # True
print("world" in text)   # False（区分大小写）

# is / is not：检查是否是同一个对象
a = None
print(a is None)      # True
print(a is not None)  # False
```

## 4.6 位运算符（了解即可）

位运算符直接操作数字的二进制表示。日常开发中用得不多，但在处理底层协议、加密算法、性能优化等场景时会用到：

```python
a = 0b1010  # 二进制 1010，十进制 10
b = 0b1100  # 二进制 1100，十进制 12

print(bin(a & b))   # 按位与：0b1000（8）
print(bin(a | b))   # 按位或：0b1110（14）
print(bin(a ^ b))   # 按位异或：0b0110（6）
print(bin(~a))      # 按位取反：-0b1011（-11）
print(bin(a << 1))  # 左移一位：0b10100（20）
print(bin(a >> 1))  # 右移一位：0b0101（5）
```

一个常用技巧：用 `& 1` 判断奇偶比 `% 2` 更快，用 `<< 1` 代替 `* 2`、`>> 1` 代替 `// 2`。

## 4.7 运算符优先级

和数学一样，Python 的运算符也有优先级。从高到低排列（仅列出最常用的）：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 最高   | `**`   | 幂运算 |
|        | `~`    | 按位取反 |
|        | `*`, `/`, `//`, `%` | 乘、除、整除、取余 |
|        | `+`, `-` | 加、减 |
|        | `<<`, `>>` | 位移 |
|        | `&`    | 按位与 |
|        | `^`, `\|` | 按位异或、按位或 |
|        | `==`, `!=`, `<`, `>`, `<=`, `>=` | 比较 |
|        | `not`  | 逻辑非 |
|        | `and`  | 逻辑与 |
|        | `or`   | 逻辑或 |
| 最低   | `=`    | 赋值 |

```python
# 示例：优先级
print(2 + 3 * 4)      # 14（先乘后加）
print(2 ** 3 ** 2)    # 512（幂运算从右向左结合：2 ** (3 ** 2) = 2 ** 9）
print(not True or False and True)  # False（not > and > or）
# 拆解：(not True) or (False and True) = False or False = False

# 不确定优先级时，加括号永远是最安全的选择
print((2 + 3) * 4)    # 20
print((not True) or (False and True))  # False
```

## 4.8 海象运算符 :=（Python 3.8+）

海象运算符（Walrus Operator）允许你在表达式中同时赋值和返回值。它长得像海象的眼睛和獠牙 `:=`：

```python
# 传统写法
data = input("请输入内容：")
if data:
    print(f"你输入了：{data}")

# 使用海象运算符（赋值和判断在一步完成）
if (data := input("请输入内容：")):
    print(f"你输入了：{data}")

# 更实用的场景：在 while 循环中
# 传统写法
# line = input("> ")
# while line != "quit":
#     print(f"你说：{line}")
#     line = input("> ")

# 使用海象运算符
while (line := input("> ")) != "quit":
    print(f"你说：{line}")
```

海象运算符能让代码更简洁，但别滥用——如果让代码变得更难读，就得不偿失了。

## 4.9 常用表达式模式

在日常编程中，有些表达式模式你会反复使用。这里总结一些最常见的：

```python
# 模式 1：取余判断——整除、奇偶、循环计数
n = 15
print(n % 2 == 0)   # False（判断偶数）
print(n % 3 == 0)   # True（判断能否被 3 整除）
print(n % 10)        # 5（取个位数）
print(n // 10)       # 1（去掉个位数）
```

```python
# 模式 2：范围检查——判断数值是否合法
score = 85
is_valid = 0 <= score <= 100
print(f"成绩 {score} 是否合法：{is_valid}")  # True

# 模式 3：条件赋值（给变量设默认值）
user_input = ""
name = user_input or "匿名用户"  # 如果 user_input 为空，使用默认值
print(name)  # 匿名用户

# 模式 4：字符串中查找子串
text = "Hello, Python World!"
has_python = "Python" in text
print(has_python)  # True
```

```python
# 模式 5：多条件组合
age = 25
has_id = True
is_vip = False

# 进入条件：年龄 18-65 且有身份证，且不是 VIP（VIP 走专用通道）
can_enter = (18 <= age <= 65) and has_id and not is_vip
print(f"是否可以进入普通通道：{can_enter}")  # True

# 模式 6：三元表达式嵌套（慎用，影响可读性）
x = 0
result = "正数" if x > 0 else ("负数" if x < 0 else "零")
print(result)  # 零
# 虽然能写，但不如 if-elif-else 清晰，复杂情况请避免嵌套三元
```

```python
# 模式 7：利用布尔运算做简单的数据过滤
values = [0, "", None, "hello", 42, [], False, 3.14]
# 筛选出所有 truthy 值
truthy_values = [v for v in values if v]
print(truthy_values)  # ['hello', 42, 3.14]
```

## 4.10 表达式 vs 语句

最后说一个小概念区分。**表达式**（expression）是有值的代码，比如 `3 + 4`、`"hello".upper()`、`x > 5`。**语句**（statement）是执行某个动作的代码，比如 `x = 10`（赋值语句）、`if` 语句、`for` 循环。

简单来说：表达式能"求值"，语句是"做事"。在 Python 的交互式环境中，输入表达式会直接显示结果，输入语句则不会显示值（除非语句里包含表达式）。

## 4.11 小结

- 算术运算符包括 `+`、`-`、`*`、`/`、`//`、`%`、`**`，注意 `/` 返回浮点数，`//` 向下取整。
- 比较运算符返回布尔值，Python 支持链式比较如 `a < b < c`。
- 逻辑运算符 `and`、`or`、`not` 具有短路特性，且返回的是操作数本身而非布尔值。
- `==` 比较值，`is` 比较对象身份（内存地址）。
- `in` 检查成员关系，`not in` 是其否定形式。
- 运算符优先级可以用括号来明确，不要靠记忆赌运气。

**填空题：**

2. `0 or "hello" or None` 的结果是 ______。
3. 检查变量 `x` 是否在 10 到 20 之间（包含 10，不包含 20）的 Python 表达式是 ______。

**选择题：**

1. `2 ** 3 ** 2` 的结果是：
   - A. 64
   - B. 512
   - C. 36
   - D. 8

**编程题：**

1. 编写程序，输入一个整数，判断它是否能同时被 3 和 5 整除。
2. 编写程序，输入三个数字，输出其中的最大值（不使用 `max()` 函数，只用比较运算符和条件表达式）。
3. 用位运算实现：给定一个整数 n，不使用乘除法，计算 n × 8 和 n ÷ 4（整除）的结果。
4. 编写一个"BMI 计算器"：输入身高（米）和体重（公斤），输出 BMI 值和等级（BMI < 18.5 偏瘦，18.5-24 正常，24-28 偏胖，≥28 肥胖）。

1. `3`，`2`
2. `"hello"`（`0` 是 falsy，跳过；`"hello"` 是 truthy，返回）
3. `10 <= x < 20`
4. B（幂运算从右向左结合：`2 ** (3 ** 2) = 2 ** 9 = 512`）
5. 参考代码：

```python
n = int(input("请输入一个整数："))
if n % 3 == 0 and n % 5 == 0:
    print(f"{n} 能同时被 3 和 5 整除")
else:
    print(f"{n} 不能同时被 3 和 5 整除")
```

1. 参考代码：

```python
a = float(input("请输入第一个数字："))
b = float(input("请输入第二个数字："))

if a >= b and a >= c:
    biggest = a
elif b >= a and b >= c:
    biggest = b

```

1. 参考代码：

```python
n = int(input("请输入一个整数："))
```


## 4.14 常见错误与避坑

- **`/` 和 `//` 的区别**：`/` 总是返回浮点数，`//` 返回整数（如果操作数都是整数）。`7 / 2` 是 `3.5`，`7 // 2` 是 `3`。
- **负数的 `//` 运算**：`-7 // 2` 的结果是 `-4`，不是 `-3`。地板除是向负无穷方向取整，不是"去掉小数部分"。
- **`==` 和 `=` 搞混**：`=` 是赋值，`==` 是比较。`if x = 5:` 会报 `SyntaxError`，应该是 `if x == 5:`。
- **浮点数比较**：`0.1 + 0.2 == 0.3` 是 `False`。应该用 `math.isclose(0.1 + 0.2, 0.3)` 或者 `abs(a - b) < 1e-9`。
- **`and` / `or` 的返回值**：它们不一定返回布尔值。`3 and 5` 返回 `5`，`0 or ""` 返回 `""`。如果确实需要布尔值，用 `bool()` 包一层。
