# 第十章：数据分析——用数据驱动决策

## 核心观点

**不要凭感觉，要看数据；看数据之前，先统一口径。**

## 10.1 五个核心指标

| 指标 | 口径 | 参考区间 | 说明 |
| --- | --- | --- | --- |
| 送达阅读率 | 阅读人数 / 送达人数 | 3-5% | 后台「图文分析」 |
| 阅读完成率 | 读完人数 / 阅读人数 | 30-50% | 反映结构和长度 |
| 分享率 | 分享次数 / 阅读人数 | 1-3% | 内容是否值得转 |
| 关注转化率 | 新增关注 / 阅读人数 | 0.5-2% | 文章是否带来粉丝 |
| 取关率 | 取关人数 / 粉丝总数 | 每篇 <0.5% | 选题是否跑偏 |

**口径提醒：**

- 阅读量不等于打开率。阅读量包含搜一搜、看一看、转发等非粉丝来源，只有"送达阅读率"才反映粉丝的打开意愿。
- 参考区间随账号规模、领域波动很大。**看自己的趋势，不和别人比绝对值。** 新号粉丝少而活跃，送达阅读率通常高于大号。
- 第三方工具（新榜等）的阅读数是估算值，以自己后台为准。

## 10.2 关注转化漏斗

```
曝光（会话 / 搜一搜 / 看一看 / 朋友圈）
  → 打开
  → 读完
  → 分享
  → 关注
```

每个环节掉得厉害，改法完全不同：

| 环节 | 看什么 | 掉得多就改 |
| --- | --- | --- |
| 曝光 | 阅读来源构成 | 标题关键词、发布时间、平台分发 |
| 打开 | 送达阅读率 | 标题、封面、摘要 |
| 读完 | 阅读完成率 | 开头、结构、段落长度 |
| 分享 | 分享率 | 观点、金句、实用工具 |
| 关注 | 关注转化率 | 文末引导、账号定位一致性 |

**建议：** 每月找出漏斗中转化最差的一环，下个月只优化这一环，别同时改五个变量。

## 10.3 单篇复盘（发布 48 小时后）

| 维度 | 看什么 | 行动 |
| --- | --- | --- |
| 标题 | 送达阅读率高低 | 优化标题公式 |
| 内容 | 阅读完成率、分享率 | 调整结构 / 长度 |
| 封面 | 同题材文章的打开对比 | 测试不同风格 |
| 发布时间 | 不同时段打开对比 | 固定最佳时段 |
