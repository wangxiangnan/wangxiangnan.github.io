# 第三章：账号搭建——把基础设施做好

## 核心观点

**用户关注你后，前 30 秒决定去留。把这段时间的体验做到极致。**

## 3.1 先选账号类型

| 类型 | 群发频率 | 能力 | 适合 |
| --- | --- | --- | --- |
| 订阅号 | 每天 1 次 | 图文、自动回复、自定义菜单 | 个人做内容，绝大多数教程号 |
| 服务号 | 每月 4 次 | 支付、模板消息、更多接口 | 有产品、需要交易和通知的企业 |

**结论：** 个人做内容，选订阅号。个人主体无法注册服务号，也无法完成微信认证。

## 3.2 注册前的准备

| 项目 | 说明 |
| --- | --- |
| 邮箱 | 未绑定过公众号、未注册过微信开放平台的邮箱 |
| 主体资料 | 个人：身份证 + 本人微信；企业：营业执照 + 对公账户 |
| 账号名称 | 全平台唯一，注册后改名次数有限，先想好 |
| 功能介绍 | 一句话定位，与第 1 章的结论保持一致 |
| 认证 | 企业可申请微信认证（约 300 元/年），个人号不能认证 |

**流程：** 微信公众平台（mp.weixin.qq.com）→ 立即注册 → 选择订阅号 → 填写主体信息 → 等待审核。

注册当天不要急着发文章，先把下面的设置做完。

## 3.3 账号五件套

| 元素 | 要求 | 常见错误 |
| --- | --- | --- |
| 名称 | 好记、好搜、与定位相关 | 用生僻字、英文名、过长 |
| 头像 | 简洁、可识别、小尺寸清晰 | 复杂图案、文字过多 |
| 简介 | 一句话说清价值 | 写"欢迎关注"（废话） |
| 菜单栏 | 3 个主菜单，指向核心内容 | 菜单太多、链接失效 |
| 被关注回复 | 欢迎 + 引导下一步 | 只写"谢谢关注" |

## 3.4 被关注回复公式

```
欢迎语（1 句）+ 价值说明（1 句）+ 引导行动（1 句）

示例：
"你好，这里是英语404。
每周五拆解一条前端报错，帮你读懂英文报错。
回复「目录」查看全部报错，回复「01」开始第一期。"
```

## 3.5 菜单栏

三个主菜单足够，别把菜单做成"关于我们"陈列馆：

| 菜单 | 指向 | 示例（英语404） |
| --- | --- | --- |
| 看文章 | 历史文章合集页 | 按报错类型分类的页面模板 |
| 找资源 | 资料包 / 工具 | 报错词汇表领取入口 |
| 联系我 | 投稿、合作 | 投稿说明 + 商务邮箱 |

**注意：** 未认证账号的「跳转网页」菜单只能填公众号图文或页面模板；认证后才可填外部链接（以后台实际权限为准）。历史文章用「页面模板」做成合集，比让读者翻历史消息友好得多。

关键词自动回复的完整设计放在第 8 章，这里先保证「目录」一个入口可用。

## 检查清单

- [ ] 确认账号类型（个人做内容 → 订阅号）
- [ ] 完成注册并通过主体审核
- [ ] 账号五件套完成
- [ ] 被关注回复配置（含引导行动）
- [ ] 菜单栏 3 个入口可用
