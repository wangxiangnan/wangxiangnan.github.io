# 第11章：协作与保护——数据安全指南 🔒

小王的奶茶店越做越好了，现在有三个员工也需要用Excel。小王做了一张考勤表让大家每天填写出勤时间，结果第二天一看——有人不小心把公式列删了，有人把表头的格式改得面目全非，还有人在备注栏写了"今天奶茶好好喝哦~"……

"我的表格啊啊啊！"小王崩溃了。

这一章我们来学习如何保护你的Excel文件，让该看的人能看，该填的人能填，不该改的地方改不了。

## 11.1 工作表保护：锁定特定单元格、设置密码

工作表保护是最常用的保护方式，它能防止别人修改你指定的区域。

**开启工作表保护**：

1. 菜单栏 **审阅** → **保护工作表**
2. 设置密码（可选，但建议设置）
3. 勾选允许用户执行的操作（比如"选定单元格""排序"等）
4. 点击确定

但等等——保护工作表之后，默认所有单元格都被锁定了，别人什么都填不了啊？这就是我们接下来要学的：**先解锁需要编辑的区域，再开启保护**。

## 11.2 工作簿保护：防止结构修改

工作表保护管的是"单元格内容不能被改"，而工作簿保护管的是"工作表结构不能被改"——比如不能新增、删除、重命名、移动工作表。

**开启工作簿保护**：

1. 菜单栏 **审阅** → **保护工作簿**
2. 设置密码
3. 确定

这对防止别人打乱你的表格结构很有用。想象一下：你花了半天做好了12个月的汇总表，结果有人不小心把"3月"那个标签页拖走了——那感觉简直像搭好的积木被人碰倒。

## 11.3 单元格锁定与解锁的完整流程

这是工作表保护的核心操作流程，也是很多人容易搞混的地方。记住一个关键概念：**Excel中每个单元格默认都是"锁定"状态，但这个锁定只有在开启工作表保护后才生效**。

**完整操作步骤**：

1. **全选工作表**（点击左上角行号列标交叉处的三角，或 `Ctrl + A`）
2. **右键 → 设置单元格格式 → 保护选项卡**
3. **取消勾选"锁定"**——现在所有单元格都是未锁定状态
4. **选中你不想让别人改的区域**（比如公式列、表头行）
5. **右键 → 设置单元格格式 → 保护 → 勾选"锁定"**
6. **审阅 → 保护工作表 → 设置密码 → 确定**

这样操作之后：被锁定的单元格不能编辑，其他单元格可以正常填写。

> 💡 **提示**：如果你只想锁定公式单元格，可以用一个小技巧：按 `Ctrl + G` → 定位条件 → 选"公式"，就能一次选中所有包含公式的单元格，然后对它们设置锁定。

## 11.4 隐藏公式：保护计算逻辑

有时候你不希望别人看到你的公式（比如里面涉及提成比例、定价策略等敏感信息）。Excel允许你隐藏公式——隐藏后，单元格显示计算结果，但编辑栏中不显示公式内容。

**操作步骤**：

1. 选中包含公式的单元格
2. 右键 → 设置单元格格式 → 保护
3. 勾选"隐藏"（注意：隐藏和锁定可以同时勾选）
4. 审阅 → 保护工作表 → 确定

**重要**：隐藏公式同样需要开启工作表保护才能生效。只勾选"隐藏"但不保护工作表的话，公式依然可见。

> 💡 **提示**：隐藏公式后，选中该单元格时编辑栏会是空白的。这对防止他人窥探你的计算逻辑很有用，但也别忘了自己留一份公式备份，万一以后需要修改呢。

## 11.5 共享工作簿与审阅功能

**批注（注释）**：
在单元格上右键 → **新建批注**（新版Excel叫"新建注释"），可以给某个单元格添加备注。比如在小王的考勤表里，某天的出勤数据有异常，可以加个批注："当天停电，手工记录，数据可能有偏差"。

快捷键：`Shift + F2` 插入/编辑批注。

**修订追踪**：
在较旧版本的Excel中有"修订"功能（审阅 → 修订 → 突出显示修订），可以记录谁在什么时候改了什么。在较新版本的Excel（Microsoft 365）中，这个功能被"共同编辑+版本历史"取代了。

**共享工作簿注意事项**：

- 在Microsoft 365中，把文件保存在OneDrive或SharePoint上就能多人同时编辑
- 传统"共享工作簿"功能在新版本中已被隐藏，但仍可通过自定义功能区找到
- 共享状态下，部分功能会受限（比如不能合并单元格、不能修改数据透视表等）

> 💡 **提示**：如果需要多人协作，更推荐用Microsoft 365的在线协作功能，而不是传统的"共享工作簿"。在线协作更稳定，冲突处理也更好。

## 11.6 文件级加密：打开密码与修改密码

前面讲的工作表保护和工作簿保护，都是"打开文件后"的限制。如果你连文件都不想让无关的人打开，就需要文件级加密。

**设置打开密码**：

1. **文件** → **信息** → **保护工作簿** → **用密码进行加密**
2. 输入密码 → 确认密码 → 保存

设置了打开密码后，任何人打开这个文件都必须先输入密码。

**设置修改密码（建议以只读方式打开）**：

1. **文件** → **另存为** → 点击"工具"下拉按钮 → **常规选项**
2. 可以分别设置"打开权限密码"和"修改权限密码"
3. 还可以勾选"建议以只读方式打开"

这样别人可以打开文件查看，但如果不知道修改密码，就只能以只读模式查看，不能保存修改。

> 💡 **提示**：Excel的密码强度有限，专业的破解工具可以在短时间内破解。所以Excel密码防君子不防小人——它能防止同事的误操作，但别指望它能抵挡蓄意的攻击。特别敏感的数据建议用更专业的加密方案。

**忘记密码怎么办？**
说实话……很麻烦。Excel没有"找回密码"功能。所以请务必：

- 把密码记在安全的地方（比如密码管理器）
- 密码不要太复杂以至于自己都记不住
- 重要文件做好备份

## 11.7 实战：为奶茶店制作员工可填写但不能改格式的考勤表

让我们来帮小王做一张"防员工手滑"的考勤表。

**设计目标**：

- 表头（日期、姓名、出勤状态等标题）不能修改
- 出勤状态列可以填写（只允许填"出勤""休假""迟到""请假"）
- 工时列可以填写数字
- 月度统计列（SUM公式自动算总工时）不能修改
- 整体格式和样式不能改

**制作步骤**：

**步骤1：设计表格结构**

| 日期 | 姓名 | 出勤状态 | 上班时间 | 下班时间 | 工时 | 备注 |
|------|------|----------|----------|----------|------|------|
| 1月1日 | 小张 | （可填） | （可填） | （可填） | =下班-上班 | （可填） |
| 1月1日 | 小李 | （可填） | （可填） | （可填） | =下班-上班 | （可填） |

**步骤2：设置数据验证**
对"出勤状态"列：数据 → 数据验证 → 允许"序列" → 来源填"出勤,休假,迟到,请假"。这样员工只能从下拉列表中选择，不能随便输入。

**步骤3：解锁可编辑区域**

1. 全选 → 取消锁定
2. 选中出勤状态、上班时间、下班时间、备注列的数据区域 → 右键 → 设置单元格格式 → 保护 → 勾选锁定（注意：这里我们先全部取消锁定，再对可编辑区域不锁定——等等，逻辑反了！正确流程是：全部取消锁定，然后只锁定不能改的区域）

正确流程：

1. 全选 → 取消锁定（所有单元格变为可编辑）
2. 选中表头行、日期列、工时公式列、月度汇总区域 → 设置锁定
3. 审阅 → 保护工作表 → 设密码 → 完成

**步骤4：隐藏公式**
工时列用的是公式，勾选"隐藏"保护计算逻辑。

**步骤5：保护工作簿结构**
审阅 → 保护工作簿 → 设密码，防止员工误删或重排工作表。

**最终效果**：

- 员工打开文件，只能在白色区域填写数据
- 表头、日期、公式列都是灰色底的锁定区域，点击时会提示"此单元格受保护"
- 出勤状态只能从下拉列表选择
- 工时自动计算，员工看不到公式
- 不能新增或删除工作表

> 💡 **提示**：做完保护后，自己先测试一遍——试试能不能在锁定区域输入内容、能不能改格式、能不能删除工作表。确认一切符合预期后再发给员工使用。

## 本章小结

| 知识点 | 要点 |
| -------- | ------ |
| 工作表保护 | 审阅 → 保护工作表，锁定指定单元格防止修改 |
| 工作簿保护 | 防止新增/删除/移动工作表 |
| 锁定流程 | 先取消全表锁定 → 锁定特定区域 → 开启保护 |
| 隐藏公式 | 单元格格式 → 保护 → 隐藏，需配合工作表保护生效 |
| 批注 | `Shift + F2` 添加，用于标注数据说明 |
| 打开密码 | 文件 → 信息 → 保护工作簿 → 用密码加密 |
| 修改密码 | 另存为 → 工具 → 常规选项，可分开设置打开和修改密码 |
| 数据验证 | 限制单元格输入内容，如只允许选择下拉列表 |

## 练习题

1. **基础题**：创建一个简单的工作表，把A1:C1作为表头锁定保护，D1:D10作为输入区域允许编辑。设置保护后测试，确认表头不能改但输入区域可以填写。
2. **进阶题**：为奶茶店设计一张"每日销售记录表"，要求：日期和商品名称列锁定不可改，销售数量和金额可以填写，合计行用SUM公式并隐藏公式。
3. **挑战题**：给一个文件同时设置"打开密码"和"修改权限密码"，体验两种密码的区别。再用"建议以只读方式打开"选项保存一份副本，看看打开时是什么效果。
