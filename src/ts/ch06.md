# 第六章：联合类型、交叉类型与索引类型

## 联合类型

联合类型表示一个值可以是几种类型之一：

```ts
type Status = "pending" | "success" | "error";
type ID = string | number;

let userId: ID = 123;
userId = "abc";
```

联合类型是 TypeScript 中最强大的工具之一。它让类型变得精确，而不是笼统地用 `any`。

## 收窄类型

当你对一个联合类型的值进行操作时，TypeScript 需要你先"收窄"它的类型：

```ts
function printId(id: string | number) {
  if (typeof id === "string") {
    console.log(id.toUpperCase()); // 这里 id 被收窄为 string
  } else {
    console.log(id.toFixed(2));    // 这里 id 被收窄为 number
  }
}
```

类型收窄的方式有很多：`typeof`、`instanceof`、自定义类型守卫、`in` 操作符等。

## 交叉类型

交叉类型表示一个值同时具有多种类型的特征：

```ts
type Person = { name: string };
type Employee = { companyId: number };

type EmployeePerson = Person & Employee;

const alice: EmployeePerson = {
  name: "Alice",
  companyId: 1001,
};
```

交叉类型常用于 mixin、组合多个接口等场景。

## 索引签名

当你不确定对象具体有哪些属性，但知道属性类型时，用索引签名：

```ts
interface Dictionary {
  [key: string]: number;
}

const scores: Dictionary = {
  Alice: 90,
  Bob: 85,
};
```

索引签名适合描述动态键值对，比如字典、缓存、配置表等。

## keyof 和索引访问类型

`keyof` 可以获取一个对象类型的所有键：

```ts
interface User {
  name: string;
  age: number;
}

type UserKeys = keyof User; // "name" | "age"
```

结合索引访问，可以动态获取属性类型：

```ts
type NameType = User["name"]; // string
```

这些工具是 TypeScript 类型体操的基础，后面讲映射类型时会大量用到。
