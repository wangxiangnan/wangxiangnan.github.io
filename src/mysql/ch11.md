# 第11章 常用内置函数

## 11.1 字符串函数

字符串函数是SQL中处理文本数据的瑞士军刀。想象你在处理用户提交的各种数据——名字有多余空格需要清理、手机号需要脱敏显示、地址需要拼接成完整格式、用户名长度需要验证——这些日常任务都离不开字符串函数。MySQL提供了非常丰富的字符串处理函数，掌握它们能大幅提升你的数据清洗和格式化能力。

```sql
-- CONCAT/CONCAT_WS：字符串拼接
SELECT CONCAT(emp_name, ' - ', department) AS info FROM employees;
-- CONCAT_WS用指定分隔符拼接，并且会自动跳过NULL值（不会导致整个结果为NULL）
SELECT CONCAT_WS(' | ', emp_name, department, salary) AS info FROM employees;

-- SUBSTRING/SUBSTR：截取子串（索引从1开始，不是从0！）
SELECT SUBSTRING('Hello MySQL', 7, 5);   -- 'MySQL'（从第7个字符开始取5个）
SELECT SUBSTRING('Hello MySQL', -5);     -- 'MySQL'（从倒数第5个字符到末尾）
SELECT LEFT('Hello MySQL', 5);           -- 'Hello'（从左取5个）
SELECT RIGHT('Hello MySQL', 5);          -- 'MySQL'（从右取5个）
```

```sql
-- LENGTH vs CHAR_LENGTH（处理中文时的经典坑）
SELECT LENGTH('你好');       -- 6（字节数，UTF-8中文字符每个占3字节）
SELECT CHAR_LENGTH('你好');  -- 2（字符数，这才是"两个汉字"）
-- 记住口诀：LENGTH算字节（bytes），CHAR_LENGTH算字符（chars）
-- 处理中文或任何多字节字符时，用CHAR_LENGTH才是你要的"长度"

-- REPLACE：替换子串
SELECT REPLACE('I love Java', 'Java', 'MySQL');  -- 'I love MySQL'

-- UPPER/LOWER：大小写转换
SELECT UPPER('hello');  -- 'HELLO'
SELECT LOWER('HELLO');  -- 'hello'

-- TRIM系列：去除空格
SELECT TRIM('  hello  ');    -- 'hello'（两边都去）
SELECT LTRIM('  hello  ');   -- 'hello  '（去左边）
SELECT RTRIM('  hello  ');   -- '  hello'（去右边）
```

> [!WARNING] 注意
> LENGTH()返回的是字节数而不是字符数！在UTF-8编码下，一个中文字符占3个字节，一个ASCII字符占1个字节。如果你用 `WHERE LENGTH(name) > 10` 来限制中文名字长度，"张三"（6字节）会被认为比"John Smith"（10字节）短，但实际上"张三"只有2个字符而"John Smith"有10个字符。对中文或多字节文本，始终用CHAR_LENGTH()。

```sql
-- LPAD/RPAD：左/右填充到指定长度（常用于格式化编号）
SELECT LPAD('42', 6, '0');        -- '000042'（工号补零到6位）
SELECT RPAD('hello', 10, '.');    -- 'hello.....'（右填充点号）

-- INSTR/LOCATE/POSITION：查找子串位置（都返回1-based索引，找不到返回0）
SELECT INSTR('Hello MySQL', 'MySQL');       -- 7
SELECT LOCATE('MySQL', 'Hello MySQL');      -- 7（注意：参数顺序和INSTR相反）
SELECT POSITION('MySQL' IN 'Hello MySQL');  -- 7

-- 实战：手机号脱敏（中间4位用****替换）
SELECT CONCAT(LEFT('13812345678', 3), '****', RIGHT('13812345678', 4)) AS masked_phone;
-- 结果：138****5678
```

## 11.2 日期时间函数

日期处理在实际开发中无处不在——计算员工入职天数、统计月度销售数据、判断会员是否过期、计算两个事件之间的间隔等等。MySQL的日期函数功能非常全面，从简单的日期获取到复杂的日期计算都能胜任。

```sql
-- 获取当前时间（三个函数的精度不同）
SELECT NOW();            -- '2025-06-15 14:30:00'（日期+时间，最完整）
SELECT CURDATE();        -- '2025-06-15'（只有日期部分）
SELECT CURTIME();        -- '14:30:00'（只有时间部分）
SELECT UNIX_TIMESTAMP(); -- 当前Unix时间戳（秒数，适合做时间比较）
```

```sql
-- DATE_ADD/DATE_SUB：日期加减运算
-- INTERVAL语法非常灵活，支持YEAR/MONTH/DAY/HOUR/MINUTE/SECOND等
SELECT DATE_ADD('2025-01-31', INTERVAL 1 MONTH);  -- '2025-02-28'（智能处理月末溢出！）
SELECT DATE_SUB('2025-03-01', INTERVAL 1 MONTH);  -- '2025-02-01'
SELECT DATE_ADD(NOW(), INTERVAL 7 DAY);            -- 7天后的日期时间

-- DATEDIFF：两个日期之间相差的天数（只算天数）
SELECT DATEDIFF('2025-12-31', '2025-01-01');  -- 364天

-- TIMESTAMPDIFF：更精确的时间差，可以指定单位
SELECT TIMESTAMPDIFF(HOUR, '2025-01-01 08:00', '2025-01-01 20:00');  -- 12小时
SELECT TIMESTAMPDIFF(MONTH, '2025-01-15', '2025-06-15');             -- 5个月
SELECT TIMESTAMPDIFF(YEAR, '2000-06-15', CURDATE());                 -- 年龄
```

> [!TIP] 提示
> DATEDIFF和TIMESTAMPDIFF很容易搞混。DATEDIFF只计算天数差，参数顺序是 `DATEDIFF(后来的日期, 先前的日期)` 返回正数。TIMESTAMPDIFF更灵活，可以指定SECOND、MINUTE、HOUR、DAY、MONTH、YEAR等单位，参数顺序是 `TIMESTAMPDIFF(单位, 先前的日期, 后来的日期)`。建议统一使用TIMESTAMPDIFF，因为它的功能更全面。

```sql
-- DATE_FORMAT/STR_TO_DATE：日期和字符串之间的转换
-- DATE_FORMAT把日期格式化为字符串（常用于展示和按月分组）
SELECT DATE_FORMAT(NOW(), '%Y年%m月%d日 %H:%i:%s');  -- '2025年06月15日 14:30:00'
SELECT DATE_FORMAT(NOW(), '%Y-%m');                   -- '2025-06'（按月分组必备）

-- STR_TO_DATE把字符串解析为日期（处理用户输入或非标准格式）
SELECT STR_TO_DATE('15/06/2025', '%d/%m/%Y');  -- '2025-06-15'

-- 提取日期的各个部分
SELECT YEAR('2025-06-15') AS yr, MONTH('2025-06-15') AS mon,
    DAY('2025-06-15') AS dy, DAYNAME('2025-06-15') AS weekday,
    LAST_DAY('2025-02-15') AS last_feb_day;
-- yr=2025, mon=6, dy=15, weekday='Sunday', last_feb_day='2025-02-28'
```

## 11.3 数值函数

数值函数覆盖了日常开发中常见的数学运算需求，从简单的绝对值、取整到幂运算、随机数生成：

```sql
-- ABS绝对值、CEIL向上取整、FLOOR向下取整
SELECT ABS(-42);    -- 42
SELECT CEIL(3.2);   -- 4（天花板，向上）
SELECT FLOOR(3.8);  -- 3（地板，向下）

-- ROUND四舍五入（第二个参数控制小数位数，负数表示整数位）
SELECT ROUND(3.456, 2);   -- 3.46（保留2位小数）
SELECT ROUND(3.456, -1);  -- 0（四舍五入到十位）

-- TRUNCATE截断（不四舍五入，直接砍掉多余位数）
SELECT TRUNCATE(3.456, 2);  -- 3.45

-- MOD取模、POWER幂运算、SQRT平方根
SELECT MOD(10, 3);     -- 1
SELECT POWER(2, 10);   -- 1024
SELECT SQRT(144);      -- 12

-- RAND()随机数：生成0到1之间的随机浮点数
SELECT FLOOR(1 + RAND() * 100);  -- 1到100的随机整数

-- 随机抽取3名幸运员工（小表可以用，大表慎用！）
SELECT emp_name, salary FROM employees ORDER BY RAND() LIMIT 3;
```

> [!WARNING] 注意
> `ORDER BY RAND()` 在大表上性能极差。MySQL需要为表中的每一行生成一个随机数，然后对所有行按这个随机数排序。如果表有100万行，就需要生成100万个随机数然后排序100万行。替代方案是先获取总行数 `COUNT(*)`，用应用程序生成随机偏移量，再用 `LIMIT offset, 1` 来取数据。

## 11.4 类型转换：CAST / CONVERT

MySQL虽然会在很多场景下自动做隐式类型转换（比如你用字符串'123'和数字比较时），但有时候你需要显式转换来确保结果正确、避免歧义或提升可读性。特别是在涉及日期比较、字符串拼接等场景时，显式转换是最佳实践：

```sql
-- CAST语法：CAST(表达式 AS 目标类型)
SELECT CAST('2025-06-15' AS DATE);       -- 字符串转日期
SELECT CAST(123 AS CHAR);                -- 数字转字符串
SELECT CAST('3.14' AS DECIMAL(5,2));     -- 字符串转精确数值

-- CONVERT语法（功能类似，但可以指定字符集）
SELECT CONVERT('2025-06-15', DATE);
SELECT CONVERT('hello' USING utf8mb4);   -- 转换字符集

-- 常见场景：数字转字符串用于拼接
SELECT CONCAT(CAST(emp_id AS CHAR), '-', emp_name) AS code FROM employees;
```

## 11.5 条件函数：IF / CASE / COALESCE

条件函数让你在查询中实现分支逻辑——"如果满足条件A就做X，否则做Y"。这相当于编程语言中的if-else或switch-case语句：

```sql
-- IF(条件, 真值, 假值)：最简单的三元表达式
SELECT emp_name, salary,
    IF(salary > 12000, '高薪', '普通') AS salary_level
FROM employees;

-- CASE WHEN：多条件分支（SQL界的switch-case，但更强大）
SELECT emp_name, salary,
    CASE
        WHEN salary >= 15000 THEN '高级（15K+）'
        WHEN salary >= 12000 THEN '中级（12K-15K）'
        WHEN salary >= 10000 THEN '初级（10K-12K）'
        ELSE '入门（<10K）'
    END AS salary_grade
FROM employees;

-- CASE的等值匹配写法（更简洁，适合枚举值判断）
SELECT emp_name, department,
    CASE department
        WHEN '技术部' THEN '研发线'
        WHEN '市场部' THEN '营销线'
        WHEN '财务部' THEN '管理线'
        ELSE '其他'
    END AS business_line
FROM employees;
```

```sql
-- IFNULL/NULLIF/COALESCE：处理NULL值的三剑客
SELECT IFNULL(manager_id, 0) AS mgr FROM employees;       -- NULL替换为0
SELECT NULLIF(1, 1);  -- NULL（两值相等时返回NULL）
SELECT COALESCE(NULL, NULL, 'hello', 'world');             -- 'hello'（第一个非NULL值）

-- 实战：用CASE做行转列（Pivot），统计各部门各薪资段的人数
SELECT department,
    SUM(CASE WHEN salary >= 15000 THEN 1 ELSE 0 END) AS high_count,
    SUM(CASE WHEN salary >= 10000 AND salary < 15000 THEN 1 ELSE 0 END) AS mid_count,
    SUM(CASE WHEN salary < 10000 THEN 1 ELSE 0 END) AS low_count
FROM employees GROUP BY department;
```

> [!TIP] 提示
> COALESCE是处理NULL值的最佳实践。它比IFNULL更灵活——可以接受任意多个参数，返回第一个非NULL的值。在LEFT JOIN后处理可能为NULL的列时特别有用，比如 `COALESCE(o.order_count, 0)` 把没有订单的客户的订单数显示为0而不是NULL。

## 11.6 系统函数

系统函数让你可以获取MySQL服务器本身的信息以及上一次操作的状态。这些函数虽然看起来不起眼，但在调试问题、编写存储过程、记录操作日志以及应用程序和数据库交互时都发挥着重要作用。你可以把它们理解为数据库的"自我 introspection"能力——让数据库告诉你它现在的状态如何。

在实际的应用开发中，系统函数经常用于以下场景：在应用程序中确认刚插入的记录ID以便后续操作，检查当前连接的用户和数据库以确保环境正确，以及在数据迁移或版本升级时获取服务器的版本信息来执行兼容性逻辑。

```sql
-- 获取系统和会话信息
SELECT VERSION();     -- MySQL版本号（如'8.0.35'，用于兼容性判断）
SELECT DATABASE();    -- 当前连接的数据库名（确认你在操作正确的库）
SELECT USER();        -- 当前登录的用户名和主机（如'root@localhost'）
SELECT @@version_comment;  -- MySQL发行版信息（社区版、企业版等）
SELECT CONNECTION_ID();    -- 当前连接的ID（排查锁问题时很有用）

-- UUID：生成全局唯一标识符，适合做分布式系统的主键
SELECT UUID();              -- 字符串格式：'6ccd780c-baba-1026-9564-5b8c6f5b1e3e'
SELECT UUID_TO_BIN(UUID()); -- 二进制格式（16字节，比字符串节省空间，适合做主键）
SELECT UUID_SHORT();        -- 短UUID（64位整数，全局唯一且更紧凑）

-- 获取上一次操作的状态信息（在应用程序中经常用到）
SELECT LAST_INSERT_ID();  -- 上一次INSERT的自增ID
-- 注意：如果一次INSERT多行，返回的是第一行的自增ID，不是最后一行
SELECT ROW_COUNT();       -- 上一次UPDATE/DELETE/INSERT影响的行数
SELECT FOUND_ROWS();      -- 上一次SELECT匹配的总行数（配合SQL_CALC_FOUND_ROWS使用）
```

## 小结

MySQL的内置函数是你的SQL工具箱里的核心装备。字符串函数处理文本清洗和格式化（特别注意CHAR_LENGTH和LENGTH的区别），日期函数处理时间计算和格式化，数值函数处理数学运算，条件函数实现查询中的分支逻辑（CASE WHEN是最强大的），类型转换确保数据格式正确。重点掌握：用CHAR_LENGTH处理中文、用CASE WHEN处理多条件、用COALESCE处理NULL值。
