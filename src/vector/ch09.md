# 第9章：行列式——变换的"放大率"

## 故事引入

小王在调整配送区域的时候，发现一个问题：每次用矩阵变换之后，配送覆盖的面积都变了。

旋转 30°？面积不变，只是换了个方向。沿两个方向各放大 2 倍？面积变成了原来的 4 倍。投影到 x 轴？面积直接变成 0——整个二维区域被压成了一条线。

"这面积变化有没有一个数来衡量？"小王问。

有的。这个数叫**行列式**。

## 行列式的几何意义

对于一个 2×2 矩阵所代表的变换，**行列式**（determinant）衡量的是：变换前后，面积的缩放比例。

想象空间里有一个 1×1 的正方形（由 î 和 ĵ 张成）。经过矩阵变换后，î 和 ĵ 分别跑到了新位置，这个正方形变成了一个新的平行四边形。

这个平行四边形的面积，就是行列式的绝对值。

- det = 4：面积放大了 4 倍
- det = 0.5：面积缩小到原来的一半
- det = 0：面积变成 0——空间被"压扁"了
- det = -3：面积放大 3 倍，并且方向翻转了（镜像）

## 2×2 行列式的计算

对于矩阵 A = $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$，行列式的计算公式非常简单：

det(A) = ad - bc

就这么两个乘法一个减法。但别小看它，背后是整个面积变化的信息。

验证几个例子：

**单位矩阵** I = $\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$：det = 1×1 - 0×0 = 1。面积不变，符合预期。

**旋转矩阵** R = $\begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$：det = cos²θ + sin²θ = 1。旋转不改变面积，完美。

**缩放矩阵** S = $\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$：det = 2×3 - 0×0 = 6。x 方向 2 倍，y 方向 3 倍，面积变成 6 倍。合理。

## det = 0 意味着什么

行列式为 0，意味着变换把二维空间"压扁"成了一条线（甚至一个点）。面积从有变成了零。

这种情况发生在矩阵的两列**线性相关**的时候——两个基向量变换后跑到了同一条线上，一个变成了另一个的倍数。

比如 P = $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$（投影到 x 轴）：det = 1×0 - 0×0 = 0。

第二列是 (0, 0)，第一列是 (1, 0)，一个为零向量，当然线性相关。整个平面被拍扁到了 x 轴上。

小王把这叫"降维打击"——从二维降到一维，信息全丢了。

## det 为负：方向翻转

行列式不只看面积大小，还带一个**符号**。

det > 0：变换后，空间的"手性"没变（逆时针还是逆时针）
det < 0：变换后，空间被"翻了个面"（逆时针变成了顺时针）

比如镜像矩阵 M = $\begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix}$（沿 y 轴翻转）：

det = (-1)×1 - 0×0 = -1

面积没变（绝对值是 1），但方向反了——就像照镜子，左手变成了右手。

## 逆矩阵存在的条件

如果 det ≠ 0，变换是"可逆"的——你可以找到一个逆矩阵，把变换后的空间变回原样。

如果 det = 0，变换不可逆——信息已经丢了，没法恢复。你把一张纸压成一条线，怎么知道原来纸有多宽？

这跟解方程组直接相关：Ax = b 有唯一解的条件就是 det(A) ≠ 0。

小王总结："行列式非零，变换才能回头。"

## 类比：擀面杖

把行列式想象成擀面杖的"放大倍率"。

你有一块 1 平方分米的面团。擀完之后变成了 3 平方分米——行列式就是 3（det > 1，放大了）。

如果擀得更薄，变成了 0.5 平方分米——行列式是 0.5（det < 1，缩小了）。

如果你不是擀面，而是直接把面团压成了一条面条——行列式是 0（det = 0，降维了）。这条面条没法"反擀"回原来的面团形状，所以不可逆。

## 代码示例

```javascript
// 计算 2×2 矩阵的行列式
function determinant2x2(matrix) {
  const [a, b] = matrix[0];
  const [c, d] = matrix[1];
  return a * d - b * c;
}

// 测试几个变换矩阵
const rotation = [
  [Math.cos(Math.PI / 6), -Math.sin(Math.PI / 6)],
  [Math.sin(Math.PI / 6),  Math.cos(Math.PI / 6)]
];
console.log("旋转30°的行列式:", determinant2x2(rotation)); // 约 1

const scale = [[2, 0], [0, 3]];
console.log("缩放的行列式:", determinant2x2(scale)); // 6

const projection = [[1, 0], [0, 0]];
console.log("投影的行列式:", determinant2x2(projection)); // 0

// 判断矩阵是否可逆
function isInvertible(matrix) {
  return determinant2x2(matrix) !== 0;
}

console.log("旋转可逆吗?", isInvertible(rotation));     // true
console.log("投影可逆吗?", isInvertible(projection));   // false
```

## 小结

- 行列式衡量线性变换对**面积的缩放比例**
- 2×2 矩阵 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ 的行列式 = ad - bc
- det = 0：空间被压扁到低一维，**不可逆**
- det < 0：空间方向翻转（镜像效果）
- det ≠ 0 是逆矩阵存在的充要条件

## 练习题

**题1：** 计算以下矩阵的行列式，并判断是否可逆：

- (a) A = $\begin{pmatrix} 4 & 2 \\ 2 & 1 \end{pmatrix}$
- (b) B = $\begin{pmatrix} 3 & 1 \\ 0 & 5 \end{pmatrix}$

**题2：** 一个变换把 x 方向放大 3 倍，y 方向缩小到原来的 1/3。这个变换的行列式是多少？面积变了吗？

**题3：** 矩阵 A 的行列式是 2，矩阵 B 的行列式是 3。那么复合变换 AB 的行列式是多少？（提示：想想面积连续缩放的效果。）

## 练习题答案

**题1：**

- (a) det(A) = 4×1 - 2×2 = 4 - 4 = 0。**不可逆**。（两列线性相关：第二列是第一列的一半。）
- (b) det(B) = 3×5 - 1×0 = 15。**可逆**。

**题2：** 变换矩阵 S = $\begin{pmatrix} 3 & 0 \\ 0 & 1/3 \end{pmatrix}$，det = 3 × (1/3) - 0 = 1。行列式为 1，面积没变！x 方向拉长了，y 方向压扁了，刚好抵消。就像擀面——擀长了但擀薄了，总面积不变。

**题3：** det(AB) = det(A) × det(B) = 2 × 3 = 6。

这是行列式的一个重要性质：复合变换的面积缩放比例，等于各自缩放比例的乘积。先放大 2 倍，再放大 3 倍，总共放大 6 倍。直觉上完全合理。
