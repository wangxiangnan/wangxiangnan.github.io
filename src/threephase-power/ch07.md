# 第7章 电机铭牌与选型：读懂电机的"身份证"

小王接到师傅的电话："小王，搅拌机那台电机彻底烧了，你得去买台新的。铭牌照片发你了，照着上面的参数买就行。"小王打开手机一看，一张银色小标签上密密麻麻写满了字母和数字：Y2-132M-4、7.5kW、380V、15.6A、1440r/min、cosφ=0.85、IP55、F级……"师傅，这上面写的都是什么？我只认识7.5kW和380V。"

老张在电话那头笑了："铭牌就是电机的身份证，上面每一个参数都有含义。你不读懂铭牌，买回来的电机可能装不上、带不动、甚至烧掉。"小王这才意识到，原来看似简单的一张标签，里面藏着这么多学问。让我们帮他逐一破解这些"密码"。

## 7.1 铭牌参数全解读

每台正规电机出厂时都会在机壳上固定一块铭牌，上面标注了电机的主要技术参数。读懂这些参数，是正确选型和使用电机的基础。下面逐一讲解。

**型号**：如Y2-132M-4。Y2表示Y2系列三相异步电机（Y系列的第二次改型设计），132表示机座中心高度为132毫米（即从电机轴中心到机座底面的距离），M表示中等机座长度（L为长机座，S为短机座），4表示4极电机。型号告诉你这是什么系列、多大的电机、几极的。

**额定功率Pn**：电机在额定条件下能够持续输出的机械功率，单位kW。比如7.5kW表示电机额定输出7500瓦的机械功率。注意，这是输出功率，不是输入功率——电机从电网吸收的电功率比这个大，因为电机本身有效率问题。

**额定电压Un**：电机正常运行时定子绕组应施加的线电压，单位V。国内标准通常为380V（对应Y接或Δ接，视铭牌标注而定）。

**额定电流In**：电机在额定电压、额定功率下运行时，定子绕组的线电流，单位A。比如15.6A。这是电机正常工作的电流参考值，超过这个值就说明电机可能过载了。

**额定转速nn**：电机在额定电压、额定频率、额定负载下的转速，单位r/min。比如1440r/min，对应同步转速1500r/min（4极电机），转差率约4%。

**功率因数cosφ**：电机在额定运行时的功率因数，反映电机从电网吸收的有功功率占总视在功率的比例。cosφ=0.85表示有功功率占视在功率的85%，另外15%是无功功率（用于建立磁场的能量交换）。功率因数越高，电能的利用率越好。异步电机在轻载时功率因数会明显下降，所以电机不宜长期空载或轻载运行。

**效率η**：电机将输入的电能转换为机械能的效率。比如η=87%表示输入100瓦电能，输出87瓦机械能，其余13瓦变成了热量损耗（包括铜损、铁损、机械损耗等）。效率越高越省电，但高效率电机通常价格更高。

**绝缘等级**：表示电机绕组绝缘材料的耐热等级。常见的有B级（最高允许温度130°C）、F级（155°C）、H级（180°C）。绝缘等级越高，电机能承受的温度越高，寿命越长或允许的过载余量越大。F级是目前工业电机最常见的等级。

**防护等级IP**：用两位数字表示电机外壳对固体和液体的防护能力。第一位数字（0-6）表示防尘等级，第二位数字（0-8）表示防水等级。比如IP55表示防尘（不完全密封但灰尘进入量不影响运行）和防喷水。IP44适合室内干燥环境，IP55适合一般工业环境，IP65适合潮湿多尘环境。

**工作制**：标注电机允许的运行方式。S1为连续工作制（可长时间连续运行），S2为短时工作制（如30分钟），S3为断续工作制。大多数工业电机为S1。

| 参数 | 符号 | 示例 | 含义 |
| ------ | ------ | ------ | ------ |
| 额定功率 | Pn | 7.5kW | 输出机械功率 |
| 额定电压 | Un | 380V | 定子线电压 |
| 额定电流 | In | 15.6A | 定子线电流 |
| 额定转速 | nn | 1440r/min | 满载转速 |
| 功率因数 | cosφ | 0.85 | 有功/视在功率比 |
| 效率 | η | 87% | 输出/输入功率比 |

## 7.2 Y接与Δ接：电压的对应关系

铭牌上经常看到这样的标注："380V/220V，Y/Δ"。这到底是什么意思？

同一台电机的定子绕组有一个固定的额定相电压（即每相绕组能承受的电压），比如220V。但不同的接法下，绕组所承受的电压与线电压的关系不同：

Y接（星形接法）时，每相绕组承受的电压等于线电压除以√3（约1.732）。所以当线电压为380V时，每相绕组承受的电压为380/1.732≈220V。

Δ接（三角形接法）时，每相绕组直接承受线电压。所以当线电压为220V时，每相绕组承受的电压就是220V。

因此，"380V Y接 / 220V Δ接"的意思是：在380V的三相电源上用Y接，在220V的三相电源上用Δ接——两种情况下绕组承受的相电压都是220V，电机都能正常工作。

这个知识点非常重要。在我国，工业用电标准线电压为380V，所以额定相电压220V的电机在国内一律用Y接。如果这台电机要出口到某些线电压为220V的国家（如日本部分地区），就需要改用Δ接。接错了会怎样？380V电源用Δ接，绕组承受380V远超额定220V，绕组会迅速过热烧毁；220V电源用Y接，绕组只承受127V，电机出力不足。

## 7.3 电机选型原则

选电机不是功率越大越好，也不是转速越高越好，要根据实际需求综合考虑。

**功率匹配**：电机的额定功率应略大于负载所需功率，一般取1.1到1.2倍的余量。功率选大了，电机长期轻载运行，效率和功率因数都低，浪费电能；功率选小了，电机长期过载运行，温升过高，绝缘加速老化，缩短寿命甚至烧毁。小王那台7.5kW的搅拌机，实际负载大约6到7kW，7.5kW正好匹配。

**转速选择**：根据负载需要的转速选择电机的极数。大多数通用设备选4极电机（同步转速1500r/min），因为转速适中、价格合理、适用面广。需要高速运转的设备（如离心风机、小型水泵）选2极电机（3000r/min），需要大力矩低转速的设备（如球磨机、破碎机）选6极或8极电机。如果后续要用变频器调速，转速范围可以更灵活。

**环境条件**：根据安装环境选择合适的防护等级和绝缘等级。室内干燥清洁环境用IP44即可；一般车间环境用IP55；潮湿、多尘、户外环境用IP65或更高。有腐蚀性气体的环境需要特殊的防腐电机。

**安装方式**：电机的安装方式用字母表示，常见的有B3（卧式底脚安装）、B5（法兰安装）、B35（底脚加法兰安装）。要根据设备的安装空间选择合适的方式。

## 7.4 能效等级与特殊电机

近年来，电机的能效等级越来越受重视。国际电工委员会（IEC）制定了IEC 60034-30标准，将电机能效分为四个等级：

IE1（标准效率）：普通效率电机，目前许多国家已禁止单独销售。IE2（高效率）：比IE1效率提高约2-3个百分点，是目前我国的最低能效限定值。IE3（超高效率）：比IE2再提高1-2个百分点，是节能推荐等级。IE4（超超高效率）：目前最高等级，效率最高但价格也最高。

选择高能效电机虽然初始投资大，但在电机的整个使用寿命周期内（通常10-20年），节省的电费远超购买差价。对于长时间运行的设备，强烈建议选择IE3及以上等级。

**防爆电机**：在有易燃易爆气体或粉尘的环境中（如面粉厂、化工厂、油漆车间），普通电机运行时产生的电火花可能引发爆炸。防爆电机通过特殊设计（隔爆外壳、增安结构等），确保即使内部发生爆炸也不会引燃外部环境。防爆电机有严格的认证要求，选型时必须确认防爆等级与使用环境匹配。

**变频电机**：普通电机用变频器驱动时，低频运行会导致散热不良（因为电机自带的风扇转速随电机转速降低），高频运行时绝缘可能承受不住变频器输出的高频脉冲电压。变频专用电机针对这些问题做了优化：独立散热风扇、加强绝缘、优化磁路设计。如果电机需要长期在变频条件下运行，应选用变频电机。

## 7.5 常见错误与注意事项

**错误一：只看功率不看转速。** 两台都是7.5kW的电机，4极的额定力矩大约是49.7N·m，而2极的只有24.9N·m。如果负载需要大力矩，2极的7.5kW电机可能带不动。

**错误二：380V电源把电机接成Δ接。** 对于"380V Y接/220V Δ接"的电机，在380V电源下必须用Y接。如果误接成Δ接，每相绕组承受380V远超额定的220V，电流急剧增大，电机很快就会烧毁。这是初学者最常犯的接线错误。

**错误三：防护等级只看防水不看防尘。** IP等级的第一位数字（防尘）同样重要。在多尘环境（如面粉车间、木工车间）中，粉尘进入电机内部会堵塞散热通道、加速绝缘老化，严重时引起短路。

**错误四：不考虑工作制。** 如果设备需要频繁启停（如每小时启动几十次），即使每次运行时间很短，也不能选S1连续工作制的普通电机，因为频繁启动时的大电流会使电机过热。应选择适合断续工作制的电机或加大功率裕量。

## 本章小结

电机铭牌是电机的"身份证"，包含了功率、电压、电流、转速、功率因数、效率、绝缘等级、防护等级等关键参数。同一台电机在不同接法下对应不同的线电压（380V Y接/220V Δ接），接线必须与电源电压匹配。电机选型要综合考虑功率匹配、转速选择、环境条件和能效等级，功率不是越大越好，合适最重要。

## 练习题

**7.1** 一台电机铭牌标注"380V/220V，Y/Δ"，在我国380V三相电源下应该采用什么接法？如果误接为Δ接会发生什么？

**参考答案：** 应采用Y接。此时每相绕组承受380/1.732≈220V，正好是绕组额定电压。如果误接为Δ接，每相绕组直接承受380V线电压，远超额定的220V，绕组电流急剧增大，电机迅速过热烧毁。

**7.2** 一台电机铭牌标注额定功率5.5kW、效率85.5%、功率因数0.84。请计算电机额定运行时的输入电功率是多少？

**参考答案：** 输入功率 = 输出功率 / 效率 = 5.5kW / 0.855 ≈ 6.43kW。也就是说电机从电网吸收约6.43kW的电功率，其中5.5kW转化为机械功率输出，约0.93kW变成了电机内部损耗（热量）。

**7.3** 小王需要为奶茶店的输送带选电机，负载需要约3.8kW的驱动功率，连续运行。他应该选多大功率的电机？为什么不能选5.5kW或2.2kW的？

**参考答案：** 应选4kW或5.5kW的电机（取1.1-1.2倍余量：3.8×1.2≈4.56kW，可选5.5kW）。选2.2kW功率不够，电机会过载烧毁。选太大如11kW虽然能带动，但电机长期轻载运行效率低、功率因数差、浪费电能，而且大电机价格更高、启动电流更大。

**7.4** IP55和IP44防护等级的电机分别适用于什么环境？在面粉加工车间应该选哪种？

**参考答案：** IP44能防止大于1mm的固体进入和防溅水，适合室内干燥清洁环境。IP55能防尘（虽不完全密封但灰尘进入量不影响运行）和防喷水，适合一般工业环境。面粉加工车间粉尘多，应至少选IP55，最好选IP65以确保粉尘不会进入电机内部造成散热不良或短路。
