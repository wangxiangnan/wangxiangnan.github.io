## 1.1 为什么选DaVinci Resolve？

市面上剪辑软件一大堆：Premiere Pro、Final Cut Pro、剪映、必剪……为什么偏偏选DaVinci Resolve？让我们用"选餐厅"的比喻来聊聊：

**1）它是免费的米其林**

DaVinci Resolve分为免费版和付费版（Studio版，约295美元，一次性买断）。但免费版的功能已经强大到离谱——剪辑、调色、音频处理、特效，四大核心功能一个不少。很多付费软件收着月费才能做到的事，DaVinci Resolve免费版就能搞定。对小陈这种"偶尔剪剪Vlog"的上班族来说，简直是天降福利。

**2）调色界的天花板**

在影视行业，DaVinci Resolve的调色功能是公认的行业标准。好莱坞大片、Netflix剧集、独立电影……无数专业作品都在用它调色。你免费就能用到大师同款工具，这就像你在小区食堂吃饭，但厨师是米其林三星的。

**3）一个软件搞定全流程**

很多剪辑师的工作流是：用Premiere剪辑 → 用After Effects做特效 → 用Audition处理音频 → 再回到Premiere导出。而DaVinci Resolve把剪辑、调色、音频、特效全部整合在一个软件里，省去了反复导入导出的麻烦。

**4）它没那么"吃订阅"**

DaVinci Resolve是买断制（Studio版），不是订阅制。不用每个月交钱，买一次永久使用，而且免费版永远免费、不限时长、导出无水印。

**5）和剪映比，它强在哪？**

你可能在想："剪映也能剪视频，还更简单，为啥要学DaVinci？" 好问题。剪映确实上手快、模板多、适合发抖音，但它有几个局限：调色功能非常基础，导出画质和码率受限，项目文件不方便管理，而且它是手机端为主的设计思路。DaVinci Resolve则是"正经的桌面级剪辑软件"——更高的画质上限、更精确的控制、更专业的工作流。打个比方：剪映像便利店微波炉，加热即食很方便；DaVinci Resolve像一套专业厨房设备，能做更精致的菜。如果你的目标是"随便剪剪发个朋友圈"，剪映够用；但如果你想"认真学剪辑、做出有质感的作品"，DaVinci Resolve是更好的长期投资。

**6）跨平台支持**

不管你是Windows、Mac还是Linux用户，DaVinci Resolve都能用。而且同一个项目文件在不同系统上可以互通——比如你在公司Windows电脑上剪了一半，回家用Mac继续剪，完全没问题。

> 💡 **提示**：免费版能完成本教程所有操作。如果某个功能需要Studio版，我会明确标注"⚠️ 需要Studio版"，你完全不用担心踩坑。

## 1.3 界面导览：底部7个页面各自干什么

打开DaVinci Resolve，你会看到底部有一排图标，像是7个"房间的门"。每个房间负责不同的工作，我们一个一个认识：

| 页面 | 英文名 | 图标 | 干什么的 | 我们用不用 |
| ------ | -------- | ------ | --------- | ----------- |
| 媒体页 | Media | 📁 | 管理所有素材文件 | 偶尔用 |
| 快编页 | Cut | ✂️ | 快速粗剪，效率优先 | **重点使用** |
| 剪辑页 | Edit | 🎬 | 精确剪辑，逐帧控制 | **重点使用** |
| 调色页 | Color | 🎨 | 调色和色彩校正 | **重点使用** |
| Fairlight | Fairlight | 🔊 | 专业音频处理 | 了解即可 |
| Fusion | Fusion | ✨ | 高级视觉特效合成 | 了解即可 |
| 交付页 | Deliver | 📤 | 导出和渲染视频 | **重点使用** |

把这7个页面想象成一条**流水线**：素材进来（媒体页）→ 粗剪（快编页）→ 精剪（剪辑页）→ 调色（调色页）→ 处理声音（Fairlight）→ 加特效（Fusion）→ 导出（交付页）。

对于Vlog剪辑来说，我们主要在这4个房间之间穿梭：**快编页、剪辑页、调色页、交付页**。其他三个房间？路过看看就好，暂时不用进去。

> 💡 **提示**：用 `Ctrl + Shift + 数字键`（Mac：`Cmd + Shift + 数字键`）可以快速切换页面。比如 `Ctrl + Shift + 3` 跳到剪辑页，`Ctrl + Shift + 4` 跳到调色页。

## 1.4 项目设置：给Vlog配什么参数

小陈新建了一个项目，弹出一堆参数设置，他又懵了。别慌，Vlog常用的设置其实很简单：

**推荐设置（手机拍摄的Vlog）：**

| 参数 | 推荐值 | 为什么 |
| ------ | -------- | -------- |
| 时间线分辨率 | 1920×1080（1080p） | 手机拍摄够用，各平台兼容性最好 |
| 时间线帧率 | 30fps 或 60fps | 30fps适合日常Vlog，60fps适合运动/慢动作 |
| 色彩空间 | Rec.709 | 标准色彩空间，手机/电脑/电视都能正确显示 |

**如何设置：**

1. 新建项目后，点击右下角齿轮图标（项目设置 / Project Settings）
2. 在"Master Settings"（主设置）中：
   - Timeline resolution（时间线分辨率）：选择 `1920 x 1080 HD`
   - Timeline frame rate（时间线帧率）：选择 `30` 或 `60`
3. 点击"Save"（保存）

> 💡 **提示**：帧率（fps）就是你的视频每秒有多少张画面。24fps有"电影感"，30fps是日常视频标准，60fps画面更流畅。Vlog一般选30fps就行。如果你打算做慢动作效果，拍摄时用60fps，剪辑时放在30fps的时间线上，就能得到2倍慢动作。

## 1.5 导入素材：从手机到电脑

小陈的周末探店拍了20多条视频片段，全在手机里。怎么弄到DaVinci Resolve里？

**第一步：从手机传到电脑**

- **iPhone用户**：用数据线连接电脑，通过"照片"App或"图像捕捉"App导出视频
- **Android用户**：用数据线连接电脑，直接复制 `DCIM/Camera` 文件夹中的视频
- **通用方法**：用微信/QQ的"文件传输助手"（注意会压缩画质），或用百度网盘、iCloud等云服务

> 💡 **提示**：尽量用数据线传输原文件，避免画质被压缩。如果必须用无线传输，推荐用"Snapdrop"等局域网传输工具。

**第二步：在DaVinci Resolve中导入**

1. 进入**快编页**或**剪辑页**
2. 打开左上角的"媒体池"（Media Pool）面板
3. 方法一：直接把文件从电脑文件夹**拖进**媒体池
4. 方法二：菜单栏 `文件 > 导入 > 媒体`（`Ctrl + I` / `Cmd + I`）
5. 方法三：在媒体池空白处**右键 > 导入媒体**

**关于手机视频格式的小知识：**

不同手机拍出来的视频文件格式不太一样：

- **iPhone**：默认用HEVC（H.265）编码，文件扩展名是 `.MOV`。画质好、文件小，但有些老电脑解码会卡。可以在 `设置 > 相机 > 格式` 中切换为"兼容性最佳"（H.264编码）
- **Android**：通常用H.264编码，文件扩展名是 `.MP4`。兼容性最好，几乎所有设备都能直接播放

DaVinci Resolve对这两种格式都能直接导入处理，不需要提前转码。但如果你的素材导入后出现"黑屏只有声音"的情况（通常发生在某些Android手机的H.265素材上），可以用免费的"HandBrake"软件先把素材转成H.264格式再导入。

**媒体池管理小技巧：**

素材多了之后，建议在媒体池里创建"素材箱"（Bin）来分类——就像给文件夹建子文件夹一样：

- 📂 **原始素材**：放所有手机拍摄的原始视频
- 📂 **音乐**：放背景音乐文件
- 📂 **图片**：放封面图、Logo等
- 📂 **音效**：放各种音效素材

在媒体池中右键 → `新建素材箱`（New Bin），即可创建分类文件夹。

## 1.6 项目管理与数据库：你的所有项目在哪里

DaVinci Resolve的项目管理方式和其他软件不太一样。它用一个叫"数据库"（Database）的系统来管理所有项目。

**简单理解：**

- **数据库**（Database）= 一个"大仓库"，里面存放你所有的项目
- **项目**（Project）= 仓库里的一个"盒子"，每个盒子就是一个独立的剪辑工程

默认情况下，DaVinci Resolve在你电脑上创建一个本地数据库。你新建的所有项目都存在这个数据库里。

**常用操作：**

- **新建项目**：`文件 > 新建项目`（`Ctrl + N` / `Cmd + N`）
- **保存项目**：`Ctrl + S`（`Cmd + S`）——DaVinci Resolve其实会自动保存，但养成手动保存的习惯总没错
- **打开项目管理器**：`Shift + 1` 或点击菜单栏 `文件 > 项目管理器`（Project Manager），可以看到所有项目列表

> 💡 **提示**：如果你想备份项目或者把项目拷到另一台电脑上，可以用 `文件 > 导出项目`（Export Project），会生成一个 `.drp` 文件（DaVinci Resolve Project文件）。在别人电脑上 `导入项目` 就能继续编辑。

## 1.7 第一次打开的心理建设：别怕

最后，我想对每一个第一次打开DaVinci Resolve的朋友说——

**你不需要搞懂所有东西。**

这个软件有7个大页面、几百个按钮、上千个参数。即便是专业剪辑师，日常工作中也只用到20%的功能。我们学剪辑的目标不是"精通DaVinci Resolve"，而是"**用DaVinci Resolve讲好自己的故事**"。

就像你不需要会造汽车才能开车上班，不需要懂空气动力学才能骑自行车去买菜。工具是为你服务的，不是反过来。

**本教程的学习路线：**

```
快编页（快速上手）→ 剪辑页（精确控制）→ 转场特效 → 字幕文字 → 调色 → 导出
```

跟着这条路线走，每一章都建立在前一章的基础上，不会突然跳到高难度操作。小陈就是这样一步步学过来的，你也可以。

**新手上路清单：**

在你开始正式学习之前，确保你已经准备好了以下几件事：

- [x] DaVinci Resolve已安装并能正常打开
- [x] 电脑有至少16GB内存，不会动不动就卡死
- [x] 准备好了一些练习素材（手机随便拍的就行）
- [x] 心态调整完毕：不追求完美，先"做出来"再说

**关于"学不会"的焦虑：**

如果你在学习过程中遇到了搞不懂的操作，请记住三件事：

1. **搞不懂很正常**——DaVinci Resolve是一个专业软件，它的很多功能是给好莱坞调色师和特效师设计的。你用不到那些功能，看不懂也完全没问题。
2. **多看两遍还不懂就跳过**——剪辑是一个实践性很强的技能。很多时候，你先跳过去继续学，等做了几个视频回过头来，自然就懂了。
3. **做出来比做得好更重要**——你的第一条视频一定很粗糙，第十条会好很多，第一百条会让你自己都惊讶。关键是"开始做"，而不是"准备到完美才开始"。

> 💡 **提示**：如果某个操作你看了两遍还是不懂，跳过它，继续往下看。很多时候，学了后面的内容，前面的自然就懂了。剪辑是一个"用着用着就会了"的技能。
