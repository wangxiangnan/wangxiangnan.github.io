# 第8章：Stream——数据流的管道工

## 引言：水桶还是水管？

想象你要把一个游泳池的水搬到另一个游泳池。你有两个选择：

**方案A（水桶法）**：找一个超大的水桶，把所有水舀进去，然后一次性倒到另一个池子里。

- 问题：你需要一个跟游泳池一样大的水桶（内存）。

**方案B（水管法）**：接一根水管，让水从一个池子流到另一个池子。

- 优点：你只需要水管粗细的空间（很少的内存），水自己流过去。

Stream 就是方案B。它让数据像水一样"流"过你的程序，而不是一次性全部加载到内存里。

在 Node.js 中，Stream 无处不在：

- HTTP 请求/响应是 Stream
- 文件读写可以是 Stream
- TCP socket 是 Stream
- 进程的 stdin/stdout 是 Stream
- zlib 压缩/解压是 Stream

**如果你只学 Node.js 的一个概念，那就学 Stream。**

## 8.1 四种 Stream 类型

### Readable Stream（可读流）

数据的**源头**。你从它那里读取数据。

```javascript
import { createReadStream } from 'node:fs';

const readable = createReadStream('./big-file.txt', {
  encoding: 'utf8',
  highWaterMark: 64 * 1024, // 每次读 64KB（内部缓冲区大小）
});

readable.on('data', (chunk) => {
  console.log(`收到 ${chunk.length} 字节`);
});

readable.on('end', () => {
  console.log('读完了');
});

readable.on('error', (err) => {
  console.error('出错了', err);
});
```

现实中的可读流：

- `fs.createReadStream()` - 文件读取
- `http.IncomingMessage` - HTTP 请求体
- `process.stdin` - 标准输入
- `crypto.createHash()` 的输入端

### Writable Stream（可写流）

数据的**终点**。你往里面写数据。

```javascript
import { createWriteStream } from 'node:fs';

const writable = createWriteStream('./output.txt');

writable.write('第一行\n');
writable.write('第二行\n');
writable.write('第三行\n');
writable.end('最后一行\n'); // end 之后不能再 write

writable.on('finish', () => {
  console.log('全部写完了');
});
```

现实中的可写流：

- `fs.createWriteStream()` - 写文件
- `http.ServerResponse` - HTTP 响应
- `process.stdout` / `process.stderr` - 标准输出/错误
- TCP socket 的写入端

### Duplex Stream（双工流）

**既能读又能写**，但读和写是独立的（两条通道）。就像电话——你既能说话（写）也能听（读），但说和听走的是不同的线路。

```javascript
import { Duplex } from 'node:stream';

const duplex = new Duplex({
  read(size) {
    // 产生数据供消费者读取
    this.push('hello');
    this.push(null); // null 表示没有更多数据了
  },
  write(chunk, encoding, callback) {
    // 处理写入的数据
    console.log('收到写入:', chunk.toString());
    callback();
  },
});
```

现实中的双工流：

- TCP socket（`net.Socket`）
- WebSocket 连接

### Transform Stream（转换流）

Duplex 的特殊形式——**读和写是关联的**。你写入数据，它经过转换后可以被读出来。就像一台榨汁机：你塞进去水果（写入），出来的是果汁（读取）。

```javascript
import { Transform } from 'node:stream';

const upperCaseTransform = new Transform({
  transform(chunk, encoding, callback) {
    // 将输入转换为大写后输出
    const upper = chunk.toString().toUpperCase();
    callback(null, upper); // 第一个参数是 error，第二个是转换后的数据
  },
});

// 使用管道：stdin → 转大写 → stdout
process.stdin.pipe(upperCaseTransform).pipe(process.stdout);
```

现实中的转换流：

- `zlib.createGzip()` - 压缩
- `crypto.createCipheriv()` - 加密
- `csv-parser` 等各种解析器

## 8.2 Stream 的工作模式

### 流动模式（Flowing Mode）vs 暂停模式（Paused Mode）

可读流有两种工作状态：

**暂停模式**（默认）：你需要显式调用 `read()` 来获取数据

```javascript
readable.on('readable', () => {
  let chunk;
  while ((chunk = readable.read()) !== null) {
    console.log(`读取了 ${chunk.length} 字节`);
  }
});
```

**流动模式**：数据自动推送给你（通过 'data' 事件）

```javascript
// 监听 'data' 事件会自动切换到流动模式
readable.on('data', (chunk) => {
  console.log(chunk);
});

// 或者调用 resume()
readable.resume();
```

切换规则：

- 监听 `'data'` 事件 → 进入流动模式
- 调用 `.pipe()` → 进入流动模式
- 调用 `.pause()` → 回到暂停模式
- 移除所有 `'data'` 监听器 → 回到暂停模式

## 8.3 背压（Backpressure）：别把下游淹了

### 什么是背压？

想象一下：一根粗水管往一根细水管里灌水。粗水管每秒出10升水，细水管每秒只能通过1升。如果不做任何控制，水就溢出来了。

在 Stream 中：

- 可读流产生数据的速度 > 可写流消费数据的速度
- 数据会在内存中累积（缓冲区溢出）
- 最终导致内存暴涨甚至 OOM

### 背压机制怎么工作的？

```javascript
import { createReadStream, createWriteStream } from 'node:fs';

const readable = createReadStream('./source-1gb.bin');
const writable = createWriteStream('./dest.bin');

readable.on('data', (chunk) => {
  // write() 返回 false 表示"我写不过来了，先别给我了"
  const canContinue = writable.write(chunk);

  if (!canContinue) {
    // 暂停读取，等待可写流消化
    readable.pause();

    // 可写流缓冲区清空后会触发 'drain' 事件
    writable.once('drain', () => {
      readable.resume(); // 恢复读取
    });
  }
});

readable.on('end', () => {
  writable.end();
});
```

这段代码正确处理了背压。但每次都要手写这些逻辑很烦——所以有了 `pipe()` 和 `pipeline()`。

## 8.4 pipe() vs pipeline()

### pipe()：简洁但危险

```javascript
import { createReadStream, createWriteStream } from 'node:fs';

createReadStream('./input.txt')
  .pipe(createWriteStream('./output.txt'));
```

`pipe()` **自动处理背压**——它帮你做了上面那一大堆暂停/恢复的逻辑。

**但 pipe() 有个致命问题：错误处理不完善。**

```javascript
// ❌ pipe 的错误不会自动传播！
createReadStream('./不存在的文件.txt')
  .pipe(transformStream)
  .pipe(createWriteStream('./output.txt'));

// 如果 readable 出错，transformStream 和 writable 不会自动关闭
// 导致内存泄漏和文件描述符泄漏！
```

### pipeline()：安全的管道

```javascript
import { pipeline } from 'node:stream/promises';
import { createReadStream, createWriteStream } from 'node:fs';
import { createGzip } from 'node:zlib';

// pipeline 会正确处理错误传播和资源清理
try {
  await pipeline(
    createReadStream('./input.txt'),
    createGzip(),
    createWriteStream('./output.txt.gz')
  );
  console.log('压缩完成');
} catch (err) {
  console.error('管道出错：', err);
  // 所有流都会被自动销毁（destroy）
}
```

**为什么 pipeline() 更好？**

1. 错误自动传播：任何一个流出错，整个管道停止
2. 自动清理：出错时所有流都会被 `destroy()`
3. 支持 AbortSignal（可以取消）
4. 返回 Promise（pipeline from `stream/promises`）

```javascript
import { pipeline } from 'node:stream/promises';

// 使用 AbortController 取消管道
const controller = new AbortController();

setTimeout(() => controller.abort(), 5000); // 5秒后取消

try {
  await pipeline(
    createReadStream('./huge-file.dat'),
    createWriteStream('./copy.dat'),
    { signal: controller.signal }
  );
} catch (err) {
  if (err.code === 'ABORT_ERR') {
    console.log('操作被取消');
  }
}
```

**结论：永远用 `pipeline()`，忘了 `pipe()`。**

## 8.5 创建自定义 Stream

### 自定义 Readable

```javascript
import { Readable } from 'node:stream';

// 方法1：继承
class CounterStream extends Readable {
  current: number;
  max: number;

  constructor(max: number) {
    super({ objectMode: true }); // objectMode 允许推送非 Buffer 数据
    this.current = 0;
    this.max = max;
  }

  _read() {
    if (this.current < this.max) {
      this.push({ count: this.current++ });
    } else {
      this.push(null); // 没有更多数据了
    }
  }
}

const counter = new CounterStream(5);
counter.on('data', (data) => console.log(data));
// { count: 0 }
// { count: 1 }
// ...
// { count: 4 }
```

```javascript
// 方法2：Readable.from()（更简洁）
import { Readable } from 'node:stream';

// 从数组创建
const fromArray = Readable.from([1, 2, 3, 4, 5]);

// 从异步生成器创建（最优雅！）
async function* generateData() {
  for (let i = 0; i < 100; i++) {
    await new Promise(resolve => setTimeout(resolve, 100));
    yield `数据行 ${i}\n`;
  }
}

const fromGenerator = Readable.from(generateData());
```

### 自定义 Writable

```javascript
import { Writable } from 'node:stream';

class DatabaseWriter extends Writable {
  buffer: any[];
  batchSize: number;

  constructor(batchSize = 100) {
    super({ objectMode: true });
    this.buffer = [];
    this.batchSize = batchSize;
  }

  async _write(
    chunk: any,
    encoding: string,
    callback: (error?: Error | null) => void
  ) {
    this.buffer.push(chunk);

    if (this.buffer.length >= this.batchSize) {
      try {
        await this.flush();
        callback();
      } catch (err) {
        callback(err as Error);
      }
    } else {
      callback();
    }
  }

  async _final(callback: (error?: Error | null) => void) {
    // 流结束时刷新剩余数据
    try {
      if (this.buffer.length > 0) {
        await this.flush();
      }
      callback();
    } catch (err) {
      callback(err as Error);
    }
  }

  private async flush() {
    console.log(`批量写入 ${this.buffer.length} 条记录`);
    // 实际情况：await db.insertMany(this.buffer);
    this.buffer = [];
  }
}
```

### 自定义 Transform

```javascript
import { Transform } from 'node:stream';

// JSON 行解析器（NDJSON / JSON Lines）
class JsonLineParser extends Transform {
  private remainder: string = '';

  constructor() {
    super({
      readableObjectMode: true,  // 输出对象
      writableObjectMode: false, // 输入是 Buffer/string
    });
  }

  _transform(
    chunk: Buffer,
    encoding: string,
    callback: (error?: Error | null) => void
  ) {
    const data = this.remainder + chunk.toString();
    const lines = data.split('\n');

    // 最后一行可能不完整，保留到下次
    this.remainder = lines.pop() || '';

    for (const line of lines) {
      if (line.trim()) {
        try {
          this.push(JSON.parse(line));
        } catch (err) {
          // 跳过无法解析的行，或者可以 callback(err) 终止
          console.warn('无法解析:', line);
        }
      }
    }

    callback();
  }

  _flush(callback: (error?: Error | null) => void) {
    // 处理最后残留的数据
    if (this.remainder.trim()) {
      try {
        this.push(JSON.parse(this.remainder));
      } catch (err) {
        // 忽略
      }
    }
    callback();
  }
}
```

## 8.6 Stream 与异步迭代器

Node.js 中的 Readable Stream 实现了 `Symbol.asyncIterator`，这意味着你可以用 `for await...of` 来消费它！

```javascript
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';

// 逐行读取文件
const fileStream = createReadStream('./access.log', 'utf8');
const rl = createInterface({ input: fileStream });

let errorCount = 0;
for await (const line of rl) {
  if (line.includes(' 500 ')) {
    errorCount++;
  }
}
console.log(`共有 ${errorCount} 个 500 错误`);
```

```javascript
import { Readable } from 'node:stream';

// 任何 Readable 都可以 for await
const readable = Readable.from(['hello\n', 'world\n']);

for await (const chunk of readable) {
  process.stdout.write(chunk);
}
```

### 异步迭代器 vs 事件监听

```javascript
// 事件风格（旧）
stream.on('data', (chunk) => { /* ... */ });
stream.on('end', () => { /* ... */ });
stream.on('error', (err) => { /* ... */ });

// 异步迭代器风格（新，推荐）
try {
  for await (const chunk of stream) {
    // 处理 chunk
  }
  // 流结束
} catch (err) {
  // 错误处理
}
```

异步迭代器的优势：

- 自动处理背压
- 错误通过 try/catch 捕获
- 可以用 break 提前退出
- 代码更线性，更易读

## 8.7 实战案例

### 案例1：CSV 大文件逐行处理

```javascript
import { createReadStream } from 'node:fs';
import { pipeline } from 'node:stream/promises';
import { Transform } from 'node:stream';

// CSV 解析 Transform
class CsvParser extends Transform {
  private headers: string[] = [];
  private remainder: string = '';
  private isFirstLine = true;

  constructor() {
    super({ readableObjectMode: true });
  }

  _transform(chunk: Buffer, encoding: string, callback: Function) {
    const data = this.remainder + chunk.toString();
    const lines = data.split('\n');
    this.remainder = lines.pop() || '';

    for (const line of lines) {
      if (!line.trim()) continue;

      const fields = this.parseCsvLine(line);

      if (this.isFirstLine) {
        this.headers = fields;
        this.isFirstLine = false;
      } else {
        const obj: Record<string, string> = {};
        this.headers.forEach((h, i) => {
          obj[h] = fields[i] || '';
        });
        this.push(obj);
      }
    }
    callback();
  }

  _flush(callback: Function) {
    if (this.remainder.trim()) {
      const fields = this.parseCsvLine(this.remainder);
      const obj: Record<string, string> = {};
      this.headers.forEach((h, i) => {
        obj[h] = fields[i] || '';
      });
      this.push(obj);
    }
    callback();
  }

  private parseCsvLine(line: string): string[] {
    // 简化版 CSV 解析（不处理引号内的逗号）
    return line.split(',').map(f => f.trim().replace(/^"|"$/g, ''));
  }
}

// 数据处理 Transform
class DataProcessor extends Transform {
  private count = 0;
  private totalSales = 0;

  constructor() {
    super({ objectMode: true });
  }

  _transform(record: any, encoding: string, callback: Function) {
    this.count++;
    this.totalSales += parseFloat(record.amount || '0');

    // 每处理 10000 条打印进度
    if (this.count % 10000 === 0) {
      console.log(`已处理 ${this.count} 条记录...`);
    }

    // 只输出大额订单
    if (parseFloat(record.amount) > 1000) {
      this.push(JSON.stringify(record) + '\n');
    }

    callback();
  }

  _flush(callback: Function) {
    console.log(`\n处理完成！共 ${this.count} 条，总金额: ${this.totalSales}`);
    callback();
  }
}

// 组装管道
import { createWriteStream } from 'node:fs';

await pipeline(
  createReadStream('./sales-data.csv'),   // 可能是几个 GB 的文件
  new CsvParser(),                         // 解析 CSV
  new DataProcessor(),                     // 处理数据
  createWriteStream('./big-orders.jsonl')  // 输出结果
);

console.log('全部完成！');
```

### 案例2：HTTP 文件上传进度条

```javascript
import { createReadStream, statSync } from 'node:fs';
import { Transform } from 'node:stream';
import { pipeline } from 'node:stream/promises';

class ProgressTracker extends Transform {
  private transferred = 0;
  private total: number;
  private lastPercent = 0;

  constructor(totalSize: number) {
    super();
    this.total = totalSize;
  }

  _transform(chunk: Buffer, encoding: string, callback: Function) {
    this.transferred += chunk.length;
    const percent = Math.floor((this.transferred / this.total) * 100);

    if (percent !== this.lastPercent) {
      this.lastPercent = percent;
      const bar = '█'.repeat(percent / 2) + '░'.repeat(50 - percent / 2);
      process.stdout.write(`\r[${bar}] ${percent}% (${this.formatBytes(this.transferred)}/${this.formatBytes(this.total)})`);
    }

    this.push(chunk); // 数据原样传递
    callback();
  }

  _flush(callback: Function) {
    process.stdout.write('\n');
    callback();
  }

  private formatBytes(bytes: number): string {
    if (bytes < 1024) return `${bytes}B`;
    if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)}KB`;
    return `${(bytes / (1024 * 1024)).toFixed(1)}MB`;
  }
}

// 使用示例：上传文件到 HTTP 服务器
async function uploadFile(filePath: string, url: string) {
  const { size } = statSync(filePath);
  const progress = new ProgressTracker(size);

  const fileStream = createReadStream(filePath);

  // 这里用 fetch API（Node.js 18+）
  const response = await fetch(url, {
    method: 'PUT',
    body: fileStream.pipe(progress), // Readable 可以直接作为 fetch body
    headers: {
      'Content-Type': 'application/octet-stream',
      'Content-Length': size.toString(),
    },
    // @ts-ignore - duplex 需要显式设置
    duplex: 'half',
  });

  console.log('上传完成，状态码:', response.status);
}
```

### 案例3：数据压缩/解压

```javascript
import { createReadStream, createWriteStream } from 'node:fs';
import { pipeline } from 'node:stream/promises';
import { createGzip, createGunzip, createBrotliCompress } from 'node:zlib';

// Gzip 压缩
async function compress(input: string, output: string) {
  await pipeline(
    createReadStream(input),
    createGzip({ level: 9 }), // level 1-9, 9 = 最大压缩
    createWriteStream(output)
  );
  console.log(`压缩完成: ${input} → ${output}`);
}

// Gzip 解压
async function decompress(input: string, output: string) {
  await pipeline(
    createReadStream(input),
    createGunzip(),
    createWriteStream(output)
  );
  console.log(`解压完成: ${input} → ${output}`);
}

// Brotli 压缩（更好的压缩率，适合 Web）
async function brotliCompress(input: string, output: string) {
  await pipeline(
    createReadStream(input),
    createBrotliCompress(),
    createWriteStream(output)
  );
}

// 一行搞定：读取 → 解压 → 解析 → 压缩 → 写入
import { createGunzip } from 'node:zlib';
import { Transform } from 'node:stream';

await pipeline(
  createReadStream('./data.json.gz'),
  createGunzip(),
  new Transform({
    transform(chunk, enc, cb) {
      // 在这里处理解压后的数据
      cb(null, chunk.toString().toUpperCase());
    },
  }),
  createGzip(),
  createWriteStream('./processed.json.gz')
);
```

## 8.8 Web Streams API vs Node.js Streams

Node.js 18+ 同时支持两种 Stream API：

| 特性 | Node.js Streams | Web Streams |
| ------ | ---------------- | ------------- |
| 来源 | Node.js 原生 | Web 标准 (WHATWG) |
| 类名 | Readable/Writable/Transform | ReadableStream/WritableStream/TransformStream |
| 背压 | 通过 highWaterMark + drain | 通过 desiredSize + backpressure signal |
| 浏览器兼容 | ❌ | ✅ |
| 生态 | Node.js 生态丰富 | 跨平台（Deno、Browser、Cloudflare Workers） |

```javascript
// Web Streams API 示例
const readableStream = new ReadableStream({
  start(controller) {
    controller.enqueue('Hello');
    controller.enqueue(' World');
    controller.close();
  },
});

const transformStream = new TransformStream({
  transform(chunk, controller) {
    controller.enqueue(chunk.toUpperCase());
  },
});

const writableStream = new WritableStream({
  write(chunk) {
    console.log('输出:', chunk);
  },
});

// 管道连接
await readableStream
  .pipeThrough(transformStream)
  .pipeTo(writableStream);
```

```javascript
// Node.js Stream ↔ Web Stream 互转
import { Readable } from 'node:stream';

// Node Readable → Web ReadableStream
const nodeStream = Readable.from(['a', 'b', 'c']);
const webStream = Readable.toWeb(nodeStream);

// Web ReadableStream → Node Readable
const backToNode = Readable.fromWeb(webStream);
```

**选择建议**：

- 纯 Node.js 项目 → 用 Node.js Streams（生态更丰富）
- 需要跨平台（Deno/Browser/Edge）→ 用 Web Streams
- HTTP handler → `fetch` 内置使用 Web Streams

## 8.9 常见坑点

### 坑1：忘记处理 error 事件

```javascript
// ❌ 没有错误处理，错误会变成 uncaughtException 导致进程崩溃
createReadStream('./不存在.txt').pipe(createWriteStream('./out.txt'));

// ✅ 用 pipeline
import { pipeline } from 'node:stream/promises';
try {
  await pipeline(
    createReadStream('./不存在.txt'),
    createWriteStream('./out.txt')
  );
} catch (err) {
  console.error('安全捕获:', err.message);
}
```

### 坑2：objectMode 不匹配

```javascript
// ❌ 非 objectMode 的流不能 push 对象
const readable = new Readable({
  read() {
    this.push({ foo: 'bar' }); // TypeError!
  },
});

// ✅ 设置 objectMode
const readable = new Readable({
  objectMode: true,
  read() {
    this.push({ foo: 'bar' }); // OK
    this.push(null);
  },
});
```

### 坑3：不消费可读流导致内存泄漏

```javascript
// ❌ 创建了可读流但从不消费它
const stream = createReadStream('./file.txt');
// stream 的内部缓冲区会持续增长...

// ✅ 要么消费它，要么销毁它
stream.destroy();
// 或者
stream.resume(); // 丢弃所有数据
```

## 8.10 本章小结

Stream 是 Node.js 的核心设计理念——**小块数据流式处理**。

| 类型 | 作用 | 比喻 |
| ------ | ------ | ------ |
| Readable | 数据源 | 水龙头 |
| Writable | 数据终点 | 排水口 |
| Duplex | 双向通道 | 电话线 |
| Transform | 数据转换 | 净水器 |

**最佳实践**：

1. 用 `pipeline()` 连接流，别用 `.pipe()`
2. 大文件一定要用 Stream，别 `readFile`
3. 优先用 `for await...of` 消费可读流
4. 记得处理 error 事件
5. 理解背压机制，写高性能应用
