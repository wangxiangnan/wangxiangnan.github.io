# 第4章 Agent 架构全景 — 四大核心组件

> **本章目标**：理解 Agent 的四层架构，建立完整的系统心智模型  
> **关键概念**：Perception（感知）、Reasoning（推理）、Action（行动）、Memory（记忆）  
> **读完本章你将能够**：设计一个简单的 Agent 系统，理解各组件的职责和协作方式

## 4.1 开篇：Agent 就像一个微服务系统

如果你设计过一个微服务系统，你已经熟悉 Agent 的架构了：

```
微服务系统                          Agent 系统
──────────                        ──────────
API Gateway (接收请求)      →     Perception (感知层)
Business Logic (业务逻辑)   →     Reasoning (推理层)
Service Calls (调用其他服务) →     Action (行动层)
Database + Cache (存储)     →     Memory (记忆层)
```

核心区别：微服务的路由逻辑是**写死的**（if-else、switch-case），Agent 的路由逻辑是 **LLM 实时推理的**。

```
Perception（感知）→ Reasoning（推理）→ Action（行动）
                        ↕
                    Memory（记忆）
```

- **感知层**：接收和预处理输入（像 API Gateway + Middleware）
- **推理层**：分析问题，决定下一步（像 Controller + Service Logic）
- **行动层**：执行工具调用（像 RPC Client + HTTP Client）
- **记忆层**：存储上下文和知识（像 Redis Cache + Database）

> 程序员视角：Agent 就是一个**动态路由的微服务**，路由逻辑由 LLM 实时生成。

## 4.2 感知层（Perception）— Agent 的 "API Gateway"

感知层负责**接收输入、预处理、提取结构化信息**。就像 API Gateway 做请求验证、鉴权、日志一样。

### 核心职责

```python
perception_responsibilities = {
    "输入验证": "检查输入是否合法（空、太长、恶意内容）",
    "格式标准化": "统一不同来源的输入格式",
    "意图识别": "初步判断用户想做什么（分类）",
    "上下文提取": "提取有用的元数据（语言、长度、关键词）",
    "多模态处理": "处理文本、文件、图片等不同输入"
}
```

### 完整实现

```python
from dataclasses import dataclass, field
from typing import Optional
import re

@dataclass
class ProcessedInput:
    """标准化的输入结构 — 像 Request DTO"""
    original: str          # 原始输入
    type: str              # 输入类型：text/file/image
    context: dict          # 上下文信息
    text: str              # 处理后的文本
    meta: dict             # 元数据
    intent: str = "general"  # 意图分类

class Perception:
    """感知层 — 输入预处理和意图识别"""
    
    def __init__(self):
        self.intent_patterns = {
            "concept": ["什么是", "解释", "概念", "定义", "what is", "explain"],
            "troubleshoot": ["错误", "报错", "失败", "不工作", "error", "bug", "fix"],
            "compare": ["vs", "对比", "比较", "区别", "哪个好", "difference"],
            "howto": ["怎么做", "如何", "步骤", "教程", "how to", "tutorial"],
        }
    
    def process_text(self, text: str) -> ProcessedInput:
        """处理文本输入"""
        # 1. 验证
        if not text or len(text.strip()) == 0:
            raise ValueError("Empty input")
        if len(text) > 10000:
            text = text[:10000] + "...[truncated]"
        
        # 2. 意图识别
        intent = self._detect_intent(text)
        
        # 3. 提取元数据
        meta = {
            "length": len(text),
            "has_code": "```" in text or "def " in text,
            "has_error": bool(re.search(r"Error|Exception|Traceback", text)),
            "language": self._detect_language(text),
        }
        
        return ProcessedInput(
            original=text,
            type="text",
            context={"intent": intent},
            text=text.strip(),
            meta=meta,
            intent=intent
        )
    
    def process_file(self, path: str) -> ProcessedInput:
        """处理文件输入"""
        with open(path, encoding="utf-8") as f:
            content = f.read()
        
        ext = path.split(".")[-1]
        return ProcessedInput(
            original=path,
            type="file",
            context={"extension": ext, "path": path},
            text=content[:5000],  # 截断
            meta={"size": len(content), "extension": ext}
        )
    
    def _detect_intent(self, text: str) -> str:
        """简单的意图识别（实际用 LLM 或分类模型）"""
        text_lower = text.lower()
        scores = {}
        for intent, patterns in self.intent_patterns.items():
            scores[intent] = sum(1 for p in patterns if p in text_lower)
        
        best = max(scores, key=scores.get)
        return best if scores[best] > 0 else "general"
    
    def _detect_language(self, text: str) -> str:
        """简单的语言检测"""
        chinese_chars = len(re.findall(r'[\u4e00-\u9fff]', text))
        return "zh" if chinese_chars > len(text) * 0.1 else "en"

# 示例 2：错误排查

```

```
怎么解决？
""")

> ⚠️ **感知层的设计原则**：
>
> - **不要做推理**：感知层只负责预处理，推理交给推理层
> - **快速失败**：非法输入尽早拒绝，避免浪费 LLM token
> - **结构化输出**：输出统一的 DTO，方便下游处理

## 4.3 推理层（Reasoning）— Agent 的 "Controller"

推理层是 Agent 的**大脑**，负责分析问题、决定下一步。就像 Controller 处理业务逻辑，但路由不是写死的，而是 LLM 实时推理的。

### 核心职责

```python
reasoning_responsibilities = {
    "问题分析": "理解用户意图和上下文",
    "决策": "是直接回答，还是需要调用工具？",
    "规划": "如果需要工具，调哪个？参数是什么？",
    "评估": "工具返回的结果是否足够？是否需要继续？",
    "生成": "组织最终回答"
}
```

### 完整实现

```python
from dataclasses import dataclass
from typing import Optional, List

@dataclass
class ReasoningResult:
    """推理结果 — 像 Controller 的 Response"""
    thought: str                    # 思考过程
    decision: str                   # "direct_answer" | "use_tool" | "done"
    action: Optional[str] = None    # 工具名
    action_input: Optional[dict] = None  # 工具参数
    answer: Optional[str] = None    # 直接回答
    confidence: float = 0.0         # 置信度

class Reasoning:
    """LLM 驱动的决策引擎"""
    
    def __init__(self, llm_client):
        self.llm = llm_client
        self.max_retries = 3
    
    def reason(self, input_data: ProcessedInput, 
               available_tools: List[dict],
               conversation_history: List[dict] = None) -> ReasoningResult:
        """分析输入，决定下一步"""
        
        # 构建 Prompt
        tools_desc = "\n".join(
            f"- {t['name']}: {t['description']} (参数: {t.get('params', '无')})"
            for t in available_tools
        )
        
        history = ""
        if conversation_history:
            history = "\n".join(
                f"{m['role']}: {m['content']}" for m in conversation_history[-5:]
            )
        
        prompt = f"""分析用户的问题，决定是直接回答还是需要调用工具。

用户问题: {input_data.text}
意图分类: {input_data.intent}

可用工具:
{tools_desc}

输出格式：
如果需要工具:
Thought: [你的分析]
Action: [工具名]
Action Input: [参数，JSON格式]

如果可以直接回答:
Thought: [你的分析]
Answer: [你的回答]
"""
        
        # 调用 LLM
        response = self.llm.invoke(prompt)
        
        # 解析结果
        return self._parse_response(response)
    
    def _parse_response(self, response: str) -> ReasoningResult:
        """解析 LLM 的输出"""
        thought = ""
        
        # 提取 Thought
        if "Thought:" in response:
            thought = response.split("Thought:")[-1].split("\n")[0].strip()
        
        # 判断决策
        if "Action:" in response and "Action Input:" in response:
            action = response.split("Action:")[-1].split("\n")[0].strip()
            action_input_str = response.split("Action Input:")[-1].strip()
            
            # 尝试解析 JSON
            import json
            try:
                action_input = json.loads(action_input_str)
            except:
                action_input = {"query": action_input_str}
            
            return ReasoningResult(
                thought=thought,
                decision="use_tool",
                action=action,
                action_input=action_input,
                confidence=0.7
            )
        
        elif "Answer:" in response:
            answer = response.split("Answer:")[-1].strip()
            return ReasoningResult(
                thought=thought,
                decision="direct_answer",
                answer=answer,
                confidence=0.8
            )
        
        else:
            # 兜底：当作直接回答
            return ReasoningResult(
                thought="无法解析LLM输出，使用原始响应",
                decision="direct_answer",
                answer=response,
                confidence=0.5
            )
    
    def evaluate_tool_result(self, tool_name: str, result: str, 
                             original_question: str) -> ReasoningResult:
        """评估工具结果，决定是否需要继续"""
        prompt = f"""评估工具返回的结果是否足够回答用户的问题。

原始问题: {original_question}
工具: {tool_name}
结果: {result}

结果是否足够？
- 如果足够，输出: Thought: ... \nAnswer: [基于工具结果的回答]
- 如果不够，输出: Thought: ... \nAction: [下一个工具]
"""
        response = self.llm.invoke(prompt)
        return self._parse_response(response)

# 模拟 LLM 客户端

    {"name": "run_code", "description": "执行Python代码", "params": "code"},
]

# 概念问题 → 直接回答

    ProcessedInput("什么是装饰器?", "text", {}, "什么是装饰器?", {}, "concept"),

    ProcessedInput("Connection refused错误", "text", {}, "Connection refused错误", {}, "troubleshoot"),

> 💡 **推理层的关键设计**：
>
> - **可解析的输出格式**：LLM 输出必须能被程序解析（Thought/Action/Answer）
> - **兜底逻辑**：解析失败时有默认行为，不会崩溃
> - **评估循环**：工具结果不够时，可以继续调用其他工具

## 4.4 行动层（Action）— Agent 的 "RPC Client"

行动层负责**执行工具调用**。就像微服务之间的 RPC 调用 — 发起请求、处理响应、处理错误。

### 核心设计原则

```python
action_design_principles = {
    "封装": "每个工具是一个独立的函数/类，有明确的输入输出",
    "错误处理": "工具失败不能崩溃 Agent，要优雅降级",
    "超时控制": "每个工具有超时，防止无限等待",
    "沙箱": "危险操作（执行代码）要在隔离环境",
    "日志": "记录每次调用，方便调试"
}
```

### 完整实现

```python
from typing import Callable, Any
import time
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

class ToolResult:
    """工具执行结果"""
    def __init__(self, success: bool, result: Any = None, error: str = None):
        self.success = success
        self.result = result
        self.error = error
    
    def __str__(self):
        if self.success:
            return str(self.result)
        return f"ERROR: {self.error}"

class Action:
    """行动层 — 工具注册和执行"""
    
    def __init__(self, default_timeout: int = 30):
        self.tools = {}
        self.default_timeout = default_timeout
        self.call_history = []  # 记录调用历史
    
    def register(self, name: str, description: str, handler: Callable,
                 params_schema: dict = None, timeout: int = None):
        """注册工具"""
        self.tools[name] = {
            "description": description,
            "handler": handler,
            "params_schema": params_schema or {},
            "timeout": timeout or self.default_timeout
        }
        logger.info(f"Registered tool: {name}")
    
    def execute(self, name: str, params: dict) -> ToolResult:
        """执行工具"""
        # 1. 检查工具是否存在
        if name not in self.tools:
            return ToolResult(False, error=f"Tool '{name}' not found. "
                            f"Available: {list(self.tools.keys())}")
        
        tool = self.tools[name]
        start_time = time.time()
        
        try:
            # 2. 执行工具（带超时）
            result = tool["handler"](**params)
            elapsed = time.time() - start_time
            
            # 3. 记录调用
            self.call_history.append({
                "tool": name,
                "params": params,
                "result": str(result)[:200],
                "elapsed": elapsed,
                "success": True
            })
            
            logger.info(f"Tool '{name}' succeeded in {elapsed:.2f}s")
            return ToolResult(True, result=result)
            
        except TimeoutError:
            elapsed = time.time() - start_time
            self.call_history.append({
                "tool": name, "params": params,
                "elapsed": elapsed, "success": False, "error": "timeout"
            })
            return ToolResult(False, error=f"Tool '{name}' timed out after {tool['timeout']}s")
            
        except Exception as e:
            elapsed = time.time() - start_time
            self.call_history.append({
                "tool": name, "params": params,
                "elapsed": elapsed, "success": False, "error": str(e)
            })
            logger.error(f"Tool '{name}' failed: {e}")
            return ToolResult(False, error=str(e))
    
    def list_tools(self) -> list:
        """列出所有工具（给推理层用）"""
        return [
            {"name": name, "description": info["description"], 
             "params": info["params_schema"]}
            for name, info in self.tools.items()
        ]
    
    def get_stats(self) -> dict:
        """获取调用统计"""
        total = len(self.call_history)
        success = sum(1 for c in self.call_history if c["success"])
        return {"total": total, "success": success, "fail": total - success}

def create_code_runner():
    """执行 Python 代码工具"""
    def handler(code: str) -> str:
        import subprocess, tempfile, os
        # 安全检查（简化版）
        dangerous = ["os.system", "subprocess.call", "exec(", "eval("]
        if any(d in code for d in dangerous):
            return "ERROR: 检测到不安全代码，拒绝执行"
        
        with tempfile.NamedTemporaryFile(mode="w", suffix=".py", delete=False) as f:
            f.write(code)
            path = f.name
        
        try:
            result = subprocess.run(
                ["python", path], capture_output=True, text=True, timeout=30
            )
            output = result.stdout
            if result.stderr:
                output += f"\n[STDERR]\n{result.stderr}"
            return output or "(no output)"
        except subprocess.TimeoutExpired:
            return "ERROR: 执行超时（30s）"
        finally:
            os.unlink(path)
    
    return ("run_python", "执行 Python 代码（沙箱）", handler, {"code": "str"})

## 4.5 记忆层（Memory）— Agent 的 "Cache + Database"

记忆层是 Agent 最容易忽视但最重要的组件。没有记忆的 Agent 就像一个没有 session 的 HTTP 服务 — 每次请求都是全新的。

### 三种记忆类型

```
┌─────────────────────────────────────────────────┐
│  记忆类型          │  类比        │  生命周期   │
├─────────────────────────────────────────────────┤
│  短期记忆(Short)   │  Redis       │  会话级     │
│  长期记忆(Long)    │  PostgreSQL  │  永久       │
│  工作记忆(Work)    │  函数调用栈  │  任务级     │
└─────────────────────────────────────────────────┘
```

```python
from collections import deque
import time
import json

class ShortMemory:
    """短期记忆 — 像 Redis：快速、容量有限、会话级
    
    存储：当前对话的历史消息
    容量：约 6000 tokens（约 20 条消息）
    策略：超出时删除最旧的消息（FIFO）
    """
    def __init__(self, max_tokens: int = 6000):
        self.messages = deque(maxlen=20)
        self.token_count = 0
        self.max_tokens = max_tokens
    
    def add(self, role: str, content: str):
        """添加消息"""
        self.messages.append({"role": role, "content": content})
        self.token_count += len(content) // 3  # 粗略估算
    
    def get(self) -> list:
        """获取历史（自动裁剪）"""
        while self.token_count > self.max_tokens and len(self.messages) > 2:
            removed = self.messages.popleft()
            self.token_count -= len(removed["content"]) // 3
        return list(self.messages)
    
    def clear(self):
        """清空"""
        self.messages.clear()
        self.token_count = 0

class LongMemory:
    """长期记忆 — 像数据库：持久、大容量、需检索
    
    存储：用户偏好、知识库、历史总结
    容量：无限（外部存储）
    检索：关键词/语义搜索
    """
    def __init__(self, storage_path: str = "memory.json"):
        self.storage_path = storage_path
        self.knowledge_base = {}
        self._load()
    
    def store(self, key: str, value: str, metadata: dict = None):
        """存储知识"""
        self.knowledge_base[key] = {
            "value": value,
            "metadata": metadata or {},
            "timestamp": time.time()
        }
        self._save()
    
    def retrieve(self, query: str, top_k: int = 3) -> list:
        """检索相关知识（简化版，Part 2 用向量搜索）"""
        query_words = set(query.lower().split())
        results = []
        
        for key, data in self.knowledge_base.items():
            value = data["value"]
            # 简单的关键词匹配评分
            value_words = set(value.lower().split())
            overlap = len(query_words & value_words)
            score = overlap / max(len(query_words), 1)
            
            if score > 0:
                results.append({
                    "key": key, "value": value,
                    "score": score, "metadata": data["metadata"]
                })
        
        return sorted(results, key=lambda x: -x["score"])[:top_k]
    
    def _save(self):
        with open(self.storage_path, "w") as f:
            json.dump(self.knowledge_base, f, ensure_ascii=False)
    
    def _load(self):
        try:
            with open(self.storage_path) as f:
                self.knowledge_base = json.load(f)
        except (FileNotFoundError, json.JSONDecodeError):
            self.knowledge_base = {}

class WorkingMemory:
    """工作记忆 — 像函数调用栈：任务级临时数据
    
    存储：当前任务的思考过程和工具结果
    生命周期：一个任务开始时创建，结束时清除
    """
    def __init__(self):
        self.task = {}
        self.tool_results = []
        self.thoughts = []
    
    def start_task(self, task: str):
        """开始新任务"""
        self.task = {"description": task, "step": 0, "start_time": time.time()}
        self.tool_results = []
        self.thoughts = []
    
    def add_thought(self, thought: str):
        """记录思考"""
        self.thoughts.append(thought)
        self.task["step"] += 1
    
    def add_tool_result(self, tool_name: str, result: str):
        """记录工具结果"""
        self.tool_results.append({
            "tool": tool_name, "result": result,
            "timestamp": time.time()
        })
    
    def get_context(self) -> str:
        """获取当前工作上下文（给推理层用）"""
        context_parts = []
        if self.thoughts:
            context_parts.append("已分析:\n" + "\n".join(f"- {t}" for t in self.thoughts))
        if self.tool_results:
            context_parts.append("工具结果:\n" + "\n".join(
                f"- {r['tool']}: {r['result'][:100]}" for r in self.tool_results))
        return "\n\n".join(context_parts)
    
    def clear(self):
        """任务结束，清除"""
        self.task = {}
        self.tool_results = []
        self.thoughts = []

## 4.6 协作流程

```python
"""
User → [Perception] → [Memory加载] → [Reasoning] ─┐
                                                    │
      需工具 → [Action] → 结果回到Reasoning ────────┘
      不需 → [生成回答] → [Memory保存] → Response
"""

class SimpleAgent:
    def __init__(self, llm):
        self.llm = llm
        self.perception = Perception()
        self.reasoning = Reasoning(llm)
        self.action = Action()
        self.short = ShortMem()
        self.long = LongMem()
        self.work = WorkMem()
    
    def run(self, user_input):
        inp = self.perception.text(user_input)          # 1.感知
        ctx = self.short.get()                          # 2.记忆加载
        self.work.set(user_input)
        tools = [{"n":n,"d":t["d"]} for n,t in self.action.tools.items()]
        
        final = None
        for _ in range(5):                              # 3.推理+行动循环
            r = self.reasoning.reason(inp, tools)
            self.work.think(r.thought)
            if r.answer:
                final = r.answer; break
            elif r.action:
                tr = self.action.execute(r.action, r.action_input or {})
                self.work.tool(r.action, str(tr.get("result",tr.get("error"))))
                if tr["ok"]:                            # 更新输入继续推理
                    inp = ProcessedInput(inp.original, inp.type, inp.context,
                        f"{inp.text}\n工具结果:{tr['result']}", inp.meta)
        
        if not final: final = "抱歉，暂时无法回答。"
        self.short.add("user", user_input)              # 4.记忆保存
        self.short.add("assistant", final)
        self.work.clear()
        return final
```
