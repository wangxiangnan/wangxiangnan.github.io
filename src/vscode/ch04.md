# 第4章：高效编辑与导航技巧

> 新手和老手用 VSCode 最大的区别是什么？不是扩展数量，也不是主题好不好看，而是**键盘使用率**。老手可能一天都不摸一次鼠标——手指在键盘上飞舞，代码像流水一样出现。这一章，就是把你从"鼠标流"改造成"键盘流"。

## 4.1 多光标编辑

多光标（Multi-Cursor）是 VSCode 最让人上瘾的功能之一：一次输入，多处同时生效。

### 触发方式

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 选中下一个相同内容 | `Ctrl+D` | `⌘D` |
| 选中当前单词的所有出现 | `Ctrl+F2` | `⌘F2` |
| 选中所有匹配项 | `Ctrl+Shift+L` | `⇧⌘L` |
| 在点击处添加光标 | `Alt+Click` | `⌥Click` |
| 在上方/下方添加光标 | `Ctrl+Alt+↑/↓` | `⌥⌘↑/↓` |
| 在选中行的行尾各加一个光标 | `Shift+Alt+I` | `⇧⌥I` |
| 撤销上一个光标 | `Ctrl+U` | `⌘U` |
| 取消多光标 | `Esc` | `Esc` |

两个容易忽略的细节：

- **Linux 上"向下添加光标"默认是 `Shift+Alt+↓`**，因为 `Ctrl+Alt+↓` 常被桌面环境占用。显卡驱动（比如 NVIDIA）也可能抢走这组快捷键。
- **`Ctrl+D` 是"逐个添加"**，遇到不需要的匹配可以按 `Ctrl+K Ctrl+D` 跳过；**`Ctrl+Shift+L` 是"一次全选"**，适合确定没有误匹配的场景。

### 实战场景

**场景1：批量修改变量名**

```javascript
// 修改前：把所有的 userData 改成 user
const userData = fetchUser();
console.log(userData.name);
console.log(userData.email);
return userData;
```

1. 双击 `userData` 选中
2. 按 `Ctrl+Shift+L` 选中所有出现（或按 `Ctrl+D` 逐个添加）
3. 输入 `user`，所有位置同时修改

> 真正要重命名标识符，优先用 `F2`（重命名符号）：它能跨文件、能区分同名但不同作用域的变量，而多光标只是字面匹配。

**场景2：给多行批量加前缀**

```javascript
const users = [];
const config = {};
const handler = () => {};
```

1. 选中这三行
2. 按 `Shift+Alt+I`，每行行尾各出现一个光标
3. 按 `Home` 移到行首
4. 输入 `export `：

```javascript
export const users = [];
export const config = {};
export const handler = () => {};
```

**场景3：字段列表变成 TypeScript 接口**

```text
name
email
age
phone
```

1. `Ctrl+A` 全选
2. `Shift+Alt+I` 在每行行尾加光标
3. 输入 `: string;`

```typescript
name: string;
email: string;
age: string;
phone: string;
```

### 多光标的高级细节

**列选择**：按住 `Shift+Alt` 拖动鼠标（macOS 为 `⇧⌥`），可以框选一列。如果你把 `editor.multiCursorModifier` 改成了 `ctrlCmd`，列选择的修饰键会相应变成 `Shift+Ctrl/Cmd`。

**多光标粘贴**：复制 N 行文本，然后在 N 个光标处粘贴，VSCode 默认会把每一行分配给一个光标（`editor.multiCursorPaste` 的默认值 `spread`）。改成 `full` 则每个光标都粘贴完整内容。

```jsonc
{
  "editor.multiCursorModifier": "alt",   // alt 或 ctrlCmd
  "editor.multiCursorPaste": "spread"    // spread 或 full
}
```

## 4.2 代码折叠与大纲

### 折叠快捷键

| 操作 | 快捷键 |
| --- | --- |
| 折叠/展开当前区域 | `Ctrl+Shift+[` / `Ctrl+Shift+]` |
| 切换当前区域 | `Ctrl+K Ctrl+L` |
| 递归折叠/展开（含子区域） | `Ctrl+K Ctrl+[` / `Ctrl+K Ctrl+]` |
| 折叠/展开全部 | `Ctrl+K Ctrl+0` / `Ctrl+K Ctrl+J` |
| 折叠到第 N 级 | `Ctrl+K Ctrl+1` … `Ctrl+K Ctrl+9` |
| 折叠所有块注释 | `Ctrl+K Ctrl+/` |

在行号旁边的折叠箭头上 **`Shift+Click`**，可以一次性折叠或展开该区域及其内部所有子区域。

折叠区域默认按缩进计算；Markdown、HTML、CSS、LESS、SCSS、JSON 等语言有基于语法的折叠。想强制按缩进，把 `editor.foldingStrategy` 设为 `"indentation"`。

### 区域标记

用注释标记可以手工划分可折叠区域：

```javascript
// #region 数据获取
async function fetchUsers() { /* ... */ }
async function fetchPosts() { /* ... */ }
// #endregion

// #region 数据处理
function normalizeUser(user) { /* ... */ }
function validatePost(post) { /* ... */ }
// #endregion
```

不同语言的写法：

| 语言 | 标记 |
| --- | --- |
| JavaScript / TypeScript / Java | `// #region` … `// #endregion` |
| C / C++ | `// #region` 或 `#pragma region` |
| C# | `#region` … `#endregion` |
| Python | `# region` … `# endregion` |
| CSS / SCSS | `/* #region */` … `/* #endregion */` |
| HTML / XML | `<!-- #region -->` … `<!-- #endregion -->` |

> JS/TS 里还可以直接用内置片段：输入 `#region` 按 Tab 展开注释块。

### 大纲视图（Outline）

大纲视图在资源管理器侧边栏底部，展示当前文件的符号结构（变量、接口、类、函数等）。它和 `Ctrl+Shift+O` 使用同一套符号信息：语言扩展提供 LSP 符号，内置语言则用自带的解析器。

```
📄 outline.ts
├── Variables
│   ├── config: object          [Ln 1]
│   └── MAX_RETRIES: number     [Ln 5]
├── Interfaces
│   └── UserConfig              [Ln 8]
├── Classes
│   └── UserService             [Ln 15]
│       ├── fetchUser           [Ln 17]
│       ├── updateUser          [Ln 25]
│       └── deleteUser          [Ln 33]
└── Functions
    ├── initialize              [Ln 40]
    └── main                    [Ln 55]
```

文件很长时，大纲比滚动条更好用——它是"结构地图"，而滚动条只是"位置地图"。

## 4.3 面包屑与符号导航

### 面包屑（Breadcrumbs）

编辑器顶部显示当前文件路径和符号层级，点击任意一级都能下拉同级项快速跳转：

```
src > components > Button > Button.tsx > ButtonProps (interface)
```

```jsonc
{
  "breadcrumbs.enabled": true,
  "breadcrumbs.filePath": "on",      // on | off | last
  "breadcrumbs.symbolPath": "on",    // on | off | last
  "breadcrumbs.icons": true
}
```

### 符号搜索

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+O` | 当前文件的符号 |
| `Ctrl+T` | 工作区范围的符号 |

在"转到编辑器中的符号"里输入 `:`，符号会按类型分组（方法、变量、类、接口……），再输入名字就能过滤。

### 跳转与 Peek

| 操作 | 快捷键 |
| --- | --- |
| 转到定义 | `F12` |
| 速览定义（不离开当前文件） | `Alt+F12` |
| 查找所有引用 | `Shift+F12` |
| 转到实现 | `Ctrl+F12` |
| 跳到匹配的括号 | `Ctrl+Shift+\` |
| 转到行 | `Ctrl+G` |

`Ctrl+Click` 也能跳到定义，`Ctrl+Alt+Click` 会在侧边打开定义。"转到类型定义"没有默认快捷键，可以在命令面板里执行，或自己绑一个。Linux 上"速览定义"的默认键是 `Ctrl+Shift+F10`。

### 前进 / 后退

在定义、引用和不同文件之间跳来跳去之后，用导航历史回到原处：

| 平台 | 后退 | 前进 |
| --- | --- | --- |
| Windows | `Alt+←` | `Alt+→` |
| Linux | `Ctrl+Alt+-` | `Ctrl+Shift+-` |
| macOS | `Ctrl+-` | `Ctrl+Shift+-` |

`Ctrl+Tab` 可以在打开的编辑器之间切换，按住不放再按 `Tab` 可以往后选。

## 4.4 快速打开（Ctrl+P）

`Ctrl+P`（`⌘P`）是使用频率最高的命令之一，除了按文件名搜索，它还支持这些语法：

| 输入 | 作用 | 示例 |
| --- | --- | --- |
| `filename` | 按文件名搜索 | `Button.tsx` |
| `filename:line` | 打开并跳到指定行 | `App.tsx:42` |
| `filename@symbol` | 打开并跳到指定符号 | `utils.ts@fetchData` |
| `path/subpath` | 按路径搜索 | `components/Header` |
| `.ext` | 按扩展名过滤 | `.test.ts` |
| `?` | 查看帮助 | `?` |

组合示例：

```text
Ctrl+P → "utils:100"            → 跳到 utils.ts 第 100 行
Ctrl+P → "App@handleSubmit"     → 打开 App.tsx 并跳到 handleSubmit
Ctrl+P → ".test.ts"             → 列出所有测试文件
```

### 快速打开里的"魔法前缀"

同一个输入框，前缀不同，搜索对象就不同：

```text
>    命令（Ctrl+Shift+P 打开时已自动带上）
@    当前文件的符号
#    工作区范围的符号
:    当前文件的行号
```

所以 `Ctrl+Shift+P` 并不是另一个搜索框，它只是"带 `>` 的快速打开"。理解这一点，很多操作就顺了：比如先按 `Ctrl+P`，再输入 `#`，就能跨文件找符号。

## 4.5 代码片段（Snippets）

代码片段把常用代码模式模板化，输入前缀按 `Tab` 展开。完整的语法、变量转换和片段库组织方式在第 14 章展开，这里先掌握够用的部分。

### 内置片段

JavaScript / TypeScript 文件自带一批片段：

```text
log                 → console.log()
warn                → console.warn()
error               → console.error()
for / forof / forin → 各种循环
function            → 函数声明
async function      → 异步函数
import              → import 语句
newpromise          → new Promise
trycatch            → try-catch
ctor / class        → 构造函数 / 类
#region             → 区域注释
```

> TypeScript 还多了 `prop`、`ref`、`get`、`set`、`public method`、`private method` 等片段。这些是 VSCode 内置语言功能提供的，不需要额外装扩展。

### 自定义片段

命令面板执行 `Snippets: Configure Snippets`，选择语言（或新建全局片段文件）：

```jsonc
// typescript.json
{
  "Console Log with Label": {
    "prefix": "logl",
    "body": "console.log('${1:label}:', ${2:value});",
    "description": "带标签的 console.log"
  },
  "Try Catch Finally": {
    "prefix": "tcf",
    "body": [
      "try {",
      "  $1",
      "} catch (${2:error}) {",
      "  $3",
      "} finally {",
      "  $0",
      "}"
    ],
    "description": "try-catch-finally 块"
  }
}
```

### 常用变量

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `$1`、`$2`、`$0` | Tab 停止点，`$0` 是最后停留处 | — |
| `${1:default}` | 带默认值的停止点 | — |
| `${1\|a,b,c\|}` | 下拉选择 | 弹出 a/b/c |
| `$TM_FILENAME` | 当前文件名 | `utils.ts` |
| `$TM_FILENAME_BASE` | 不含后缀的文件名 | `utils` |
| `$TM_DIRECTORY` | 当前文件所在目录 | `src/utils` |
| `$TM_FILEPATH` | 完整路径 | — |
| `$RELATIVE_FILEPATH` | 相对于工作区的路径 | `src/utils.ts` |
| `$TM_SELECTED_TEXT` / `$CLIPBOARD` | 选中文本 / 剪贴板 | — |
| `$TM_LINE_NUMBER` | 当前行号 | `42` |
| `$CURRENT_YEAR` | 当前年份 | `2026` |
| `$CURRENT_MONTH` / `$CURRENT_DATE` | 两位月份 / 日期 | `01` / `15` |
| `$BLOCK_COMMENT_START` / `$BLOCK_COMMENT_END` | 块注释符 | `/*` / `*/` |

> 片段写好后放进 `.vscode/*.code-snippets` 随项目提交，或放在用户目录跨项目使用。团队共享、正则转换（transform）、多前缀触发等进阶用法见第 14 章。

## 4.6 Emmet：HTML/CSS 的缩写展开

Emmet 能把类似 CSS 选择器的缩写展开成完整标签结构：

```html
<!-- 输入后按 Tab 展开 -->
div.container>header>nav>ul>li*4>a{Menu $}

<!-- 展开为 -->
<div class="container">
  <header>
    <nav>
      <ul>
        <li><a href="">Menu 1</a></li>
        <li><a href="">Menu 2</a></li>
        <li><a href="">Menu 3</a></li>
        <li><a href="">Menu 4</a></li>
      </ul>
    </nav>
  </header>
</div>
```

```html
ul.nav>li.item$*3>a[href="#section$"]{Section $}

<!-- 展开为 -->
<ul class="nav">
  <li class="item1"><a href="#section1">Section 1</a></li>
  <li class="item2"><a href="#section2">Section 2</a></li>
  <li class="item3"><a href="#section3">Section 3</a></li>
</ul>
```

几个实用设置：

```jsonc
{
  // 让 Tab 直接展开 Emmet（不是 Emmet 缩写时 Tab 仍用于缩进）
  "emmet.triggerExpansionOnTab": true,

  // 在 JS/JSX 文件里启用 HTML 缩写
  "emmet.includeLanguages": {
    "javascript": "javascriptreact"
  },

  // 让 Emmet 建议排在补全列表顶部
  "emmet.showSuggestionsAsSnippets": true,
  "editor.snippetSuggestions": "top"
}
```

Emmet 也支持 CSS 缩写，例如在样式表里输入 `m10` 展开为 `margin: 10px;`。默认情况下缩写会出现在建议列表里，按 `Tab` 或 `Enter` 接受；上面的 `triggerExpansionOnTab` 只是让 Tab 更顺手。

## 4.7 宏与批量修改

### 为什么没有内置宏录制

VSCode 没有 Vim 那样的 `qa...q` 宏录制。原因不难猜：编辑器把操作都暴露成了**命令**，与其录键，不如直接组合命令。需要宏时，装扩展 `multi-command`：

```jsonc
// keybindings.json
[
  {
    "key": "ctrl+shift+m",
    "command": "extension.multiCommand.execute",
    "args": {
      "sequence": [
        "editor.action.insertLineAfter",
        "editor.action.commentLine",
        "cursorUp",
        "editor.action.copyLinesDownAction"
      ],
      "interval": 50
    }
  },
  {
    "key": "ctrl+shift+i",
    "command": "extension.multiCommand.execute",
    "args": {
      "sequence": [
        "editor.action.selectAll",
        "editor.action.formatDocument",
        "editor.action.organizeImports"
      ]
    },
    "when": "editorTextFocus"
  }
]
```

命令 ID 可以在快捷键编辑器（`Ctrl+K Ctrl+S`）里右键复制，或在 `keybindings.json` 的补全里找。

### 用任务做批量操作

跨文件的批量格式化、类型检查更适合交给任务（详见第 7 章）：

```jsonc
// .vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "格式化 src",
      "type": "shell",
      "command": "npx prettier --write \"src/**/*.{ts,tsx,css,json}\"",
      "group": "build",
      "problemMatcher": []
    },
    {
      "label": "类型检查",
      "type": "shell",
      "command": "npx tsc --noEmit",
      "group": "test",
      "problemMatcher": "$tsc"
    }
  ]
}
```

### 正则替换

`Ctrl+H`（macOS `⌘⌥F`）打开替换面板，点 `.*` 开启正则模式：

```text
// console.log → logger.debug
查找：console\.log\((.+?)\)
替换：logger.debug($1)

// camelCase → snake_case（替换后再执行一次"转换为小写"）
查找：([a-z])([A-Z])
替换：$1_$2

// 删除空行（含只有空白的行）
查找：^\s*\n
替换：（留空）

// Markdown 链接 → HTML 链接
查找：\[(.+?)\]\((.+?)\)
替换：<a href="$2">$1</a>
```

注意：单个正则很难覆盖所有 import 写法，跨文件替换前一定先用"查找全部"预览。更系统的搜索/替换技巧见第 8 章。

## 4.8 实战：效率翻倍的操作序列

### 场景1：重命名一个跨文件使用的符号

不要全局替换，用语义重命名：

1. 光标放到符号上，按 `F2`
2. 输入新名字，`Enter`
3. VSCode 会通过语言服务找出所有真实引用并一起改掉

全局替换（`Ctrl+Shift+H`）只适合改字符串、注释或跨语言的文本，用在标识符上容易误伤同名变量。

### 场景2：给一组声明批量加 `export`

```javascript
// 修改前
function loadConfig() {}
function saveConfig() {}
function resetConfig() {}
```

1. 选中三行
2. `Shift+Alt+I` → 行尾各一个光标
3. `Home` 到行首
4. 输入 `export `

```javascript
export function loadConfig() {}
export function saveConfig() {}
export function resetConfig() {}
```

### 场景3：用智能选择精确扩大选区

鼠标拖选长表达式很容易多选或少选，`Shift+Alt+→` 按语法层级逐级扩大选区：

```javascript
const result = data.filter(x => x.active).map(x => ({ id: x.id, name: x.name })).sort((a, b) => b.score - a.score);
```

1. 光标停在 `x.id` 里
2. 连续按 `Shift+Alt+→`：单词 → 属性访问 → 对象字面量 → 回调函数 → 整条链式调用
3. 需要缩小就按 `Shift+Alt+←`

选区到位后，复制、剪切或直接改都行——不用和鼠标较劲。

📋 **本章小结**

- 多光标的核心是 `Ctrl+D`（逐个）、`Ctrl+Shift+L`（全选）、`Shift+Alt+I`（行尾批量）；`Esc` 退出，`Ctrl+U` 撤销光标
- 修改标识符优先用 `F2` 重命名符号，多光标只做字面批量替换
- 折叠：`Ctrl+Shift+[`/`]` 管当前区域，`Ctrl+K Ctrl+0`/`J` 管全部；`#region` 可手工划分区域
- 导航三件套：`F12` 定义、`Alt+F12` 速览、`Shift+F12` 引用；`Alt+←/→` 回退与前进
- `Ctrl+Shift+O` 搜文件内符号（输入 `:` 分组），`Ctrl+T` 搜工作区符号
- `Ctrl+P` 支持 `文件:行号`、`文件@符号`、`#` 工作区符号等语法
- 内置片段在 JS/TS 里已够用；自定义片段、变量转换与团队共享见第 14 章
- Emmet 把选择器式缩写展开成 HTML/CSS；JSX 里要配 `emmet.includeLanguages`
- `multi-command` 扩展可把命令串成宏；批量跨文件操作交给任务或正则替换，复杂重构交给语言服务
