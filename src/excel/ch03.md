# 第3章：公式入门——让Excel帮你算账 🧮

*小王开始记账了，但他发现每天手动算营业额算到头秃——今天珍珠奶茶卖了32杯，每杯15元，红豆奶茶卖了28杯，每杯12元……一共卖了多少钱？一个月30天，天天这么算，脑子要炸了。小李笑着说："你傻啊，Excel最擅长的就是帮你算！"*

## 3.1 公式的等号规则：=是启动键

在Excel里写公式，第一条铁律：**所有公式必须以等号 `=` 开头。**

- 输入 `=5+3`，按回车 → 单元格显示 `8`
- 输入 `5+3`（没有等号），按回车 → 单元格显示 `5+3`（被当成文本了）

等号就像Excel的**启动信号**——"嘿，Excel，接下来我要输入一个计算，帮我算！"

> 💡 **提示**：如果输入公式时忘了写等号，也不用删了重输。在编辑栏开头加上 `=` 就行。另外，如果你输入了 `=` 但又不想让Excel计算，可以把公式前面加一个单引号，如 `'=5+3`，Excel会把它当文本处理。

## 3.2 四则运算：加减乘除

Excel支持基本的数学运算，符号如下：

| 运算 | 符号 | 示例 | 结果 |
| ------ | ------ | ------ | ------ |
| 加法 | `+` | `=5+3` | `8` |
| 减法 | `-` | `=10-3` | `7` |
| 乘法 | `*` | `=4*6` | `24` |
| 除法 | `/` | `=20/4` | `5` |
| 乘方 | `^` | `=2^3` | `8` |
| 括号 | `()` | `=(5+3)*2` | `16` |

**运算优先级**和数学课学的一样：

1. 括号 `()` 最优先
2. 乘方 `^`
3. 乘法 `*` 和除法 `/`
4. 加法 `+` 和减法 `-`

**奶茶店实例**

假设小王今天的销售数据如下：

| A | B | C | D |
| --- | --- | --- | --- |
| 商品 | 单价 | 数量 | 金额 |
| 珍珠奶茶 | 15 | 32 | =B2*C2 |
| 红豆奶茶 | 12 | 28 | =B3*C3 |
| 芒果冰沙 | 18 | 15 | =B4*C4 |

在D2输入 `=B2*C2`，按回车，显示 `480`。意思是"用B2的单价乘以C2的数量"。

注意这里我们用**单元格地址**（B2、C2）而不是具体数字。这样做的好处是：如果单价变了，只要修改B2的数字，D2的结果会自动更新！这就是公式比手动计算厉害的地方。

## 3.3 五大基础函数：SUM、AVERAGE、COUNT、MAX、MIN

函数是Excel预设好的"计算模板"，你只需要告诉它数据在哪里，它就能帮你算出结果。可以理解为：**公式是你自己列算式，函数是Excel帮你打包好的计算器。**

**① SUM —— 求和**

```
=SUM(A1:A10)
```

意思是"把A1到A10的所有数字加起来"。

奶茶店例子：在D5输入 `=SUM(D2:D4)`，就能算出今天三种奶茶的总营业额：480 + 336 + 270 = **1086元**。

**② AVERAGE —— 求平均值**

```
=AVERAGE(A1:A10)
```

意思是"算出A1到A10的平均数"。

比如 `=AVERAGE(C2:C4)` 算出三种奶茶的平均销量：(32+28+15)/3 ≈ **25杯**。

**③ COUNT —— 计数（只数数字）**

```
=COUNT(A1:A10)
```

意思是"A1到A10中有多少个单元格包含数字"。

如果你想知道今天有多少笔交易记录（有数字的单元格），就可以用COUNT。

> 💡 **提示**：COUNT只统计包含数字的单元格。如果要统计所有非空单元格（包括文字），用 `COUNTA`。

**④ MAX —— 最大值**

```
=MAX(A1:A10)
```

返回区域中的最大值。比如 `=MAX(D2:D4)` 返回 `480`（珍珠奶茶卖得最好！）。

**⑤ MIN —— 最小值**

```
=MIN(A1:A10)
```

返回区域中的最小值。比如 `=MIN(D2:D4)` 返回 `270`。

**快速输入函数的方法**

- 方法一：直接输入 `=SUM(`，Excel会提示函数名
- 方法二：点击编辑栏左边的 `fx` 按钮，搜索函数
- 方法三："公式"选项卡 → "自动求和"按钮（Σ）
- 方法四：快捷键 `Alt + =` 快速插入SUM

## 3.4 函数嵌套：函数里套函数

函数可以套在另一个函数里面使用，就像俄罗斯套娃一样。

**例子：四舍五入求平均值**

假设小王想算本周日均营业额，并保留两位小数：

```
=ROUND(AVERAGE(B2:B8), 2)
```

这个公式的执行顺序是：

1. 先算里面的 `AVERAGE(B2:B8)` → 假设结果是 `1256.789`
2. 再算外面的 `ROUND(..., 2)` → 结果变成 `1256.79`

**再举一个嵌套的例子**

找出本周日营业额最高的那一天，并显示"最高日营业额：XXX元"：

```
="最高日营业额：" & MAX(B2:B8) & "元"
```

这里 `&` 是文本连接符，用来把文字和计算结果拼在一起。如果B2到B8中最大值是1580，结果就显示为"最高日营业额：1580元"。

> 💡 **提示**：嵌套函数时注意括号的匹配。每一对函数都有自己的开括号 `(` 和闭括号 `)`。Excel会用不同颜色标记嵌套层级，帮你确认括号是否匹配。如果括号不匹配，按回车时Excel会提示错误。

## 3.5 公式的自动补全和错误值初识

**自动补全**

当你在单元格里输入 `=S`，Excel会自动弹出一个下拉列表，列出所有以S开头的函数。你可以继续输入缩小范围（比如输入 `=SU`），然后用 `Tab` 键补全函数名。非常方便！

**常见错误值**

写公式难免出错，别怕，Excel会用错误值告诉你哪里出了问题：

| 错误值 | 含义 | 常见原因 |
| -------- | ------ | ---------- |
| `#VALUE!` | 值类型错误 | 公式中用了文本参与计算，如 `=A1+B1`，但A1里是"珍珠奶茶" |
| `#DIV/0!` | 除以零 | 除法公式的分母为0或空，如 `=10/0` |
| `#NAME?` | 名称错误 | 函数名拼错了，如 `=SUMM(A1:A10)` |
| `#REF!` | 引用错误 | 公式引用的单元格被删除了 |
| `#N/A` | 找不到值 | 查找函数（如VLOOKUP）没找到匹配的值 |
| `#NUM!` | 数字错误 | 函数的参数不合理，如对负数开平方 |
| `#NULL!` | 空值错误 | 区域运算符使用不当（比较少见） |

> 💡 **提示**：看到错误值不要慌！点击出错的单元格，看编辑栏里的公式，对照上面的表格找原因。大部分错误都是小问题——拼写错误、引用了空单元格之类的。

## 3.6 实战：用公式计算奶茶店日营业额

好，让我们综合本章所学，帮小王做一份完整的日营业额计算表！

**原始数据（Sheet：日销售记录）**

| A | B | C | D |
| --- | --- | --- | --- |
| 商品名称 | 单价 | 销售数量 | 金额 |
| 珍珠奶茶 | 15 | 32 | |
| 红豆奶茶 | 12 | 28 | |
| 芒果冰沙 | 18 | 15 | |
| 抹茶拿铁 | 20 | 22 | |
| 椰汁西米露 | 16 | 18 | |
| 黑糖鲜奶 | 14 | 25 | |

**第一步：计算每种商品的金额**

在D2输入：`=B2*C2` → 得到 `480`
然后用填充柄向下拖到D7，自动填充公式：

| 商品 | 金额 |
| ------ | ------ |
| 珍珠奶茶 | 480 |
| 红豆奶茶 | 336 |
| 芒果冰沙 | 270 |
| 抹茶拿铁 | 440 |
| 椰汁西米露 | 288 |
| 黑糖鲜奶 | 350 |

**第二步：计算汇总数据**

在D9输入：`=SUM(D2:D7)` → 今日总营业额：**2164元**
在D10输入：`=AVERAGE(D2:D7)` → 平均每种商品营业额：**360.67元**
在D11输入：`=MAX(D2:D7)` → 最畅销商品金额：**480元**
在D12输入：`=MIN(D2:D7)` → 最低销售金额：**270元**
在D13输入：`=COUNT(D2:D7)` → 商品种类数：**6种**

**第三步：加上日期和标题**

- A1：`=TODAY()`（显示今天的日期）
- 合并A1到D1，跨列居中，输入标题"小王奶茶店日销售报表"

> 💡 **提示**：用 `TODAY()` 函数的好处是，每次打开文件时日期会自动更新。如果输入固定日期（如 `2024/1/15`），那它就永远是那个日期。

**完成！现在小王每天只需要更新B列（单价）和C列（数量），D列和汇总数据全部自动更新。** 这就是公式的力量——一次设置，永久受益。
