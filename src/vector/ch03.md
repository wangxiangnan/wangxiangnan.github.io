# 第3章：向量的加减法

## 故事引入

奶茶店运营了一个月，小王发现一个问题：骑手们的路线规划全靠脑子记，效率很低。

"你看，"小王指着地图跟骑手阿强说，"你从仓库出发，先到 A 小区送 3 单，再到 B 小区送 2 单。这两段路程加起来，就是你的总路线。"

阿强点点头："那如果我从 A 小区直接回仓库呢？是不是等于把刚才的路线'倒回去'？"

小王眼睛一亮："对！'往前走'就是加，'倒回去'就是减！"

就这样，小王在不知不觉中，发现了向量的加法和减法。

## 向量加法：首尾相接

向量的加法规则非常简单：**对应分量相加**。

$$
\vec{a} + \vec{b} = (a_1 + b_1,\; a_2 + b_2)
$$

举个例子：骑手从仓库出发，先沿向量 $\vec{a} = (3, 2)$ 到达 A 小区，再沿向量 $\vec{b} = (1, 4)$ 到达 B 小区。总位移：

$$
\vec{a} + \vec{b} = (3 + 1,\; 2 + 4) = (4, 6)
$$

几何上怎么理解？有两种经典画法：

**首尾相接法（三角形法则）**：把 $\vec{b}$ 的起点接到 $\vec{a}$ 的终点，然后从 $\vec{a}$ 的起点画一条线到 $\vec{b}$ 的终点。这条线就是 $\vec{a} + \vec{b}$。就像走路：先走第一段路，再走第二段路，总位移就是从起点到终点的直线。

**平行四边形法则**：把 $\vec{a}$ 和 $\vec{b}$ 的起点放在一起，以它们为邻边画一个平行四边形。从共同起点出发的那条对角线，就是 $\vec{a} + \vec{b}$。

两种方法结果一样，选哪个顺手用哪个。

## 向量减法：倒着走

向量减法也是对应分量相减：

$$
\vec{a} - \vec{b} = (a_1 - b_1,\; a_2 - b_2)
$$

几何意义是什么？$\vec{a} - \vec{b}$ 是从 $\vec{b}$ 的终点指向 $\vec{a}$ 的终点的向量（前提是两者起点相同）。

回到奶茶店的场景：如果 $\vec{a}$ 是从仓库到 A 小区的路线，那么 $-\vec{a}$ 就是从 A 小区返回仓库的路线——方向完全相反，大小不变。

所以 $\vec{a} - \vec{b}$ 可以理解为 $\vec{a} + (-\vec{b})$：先走 $\vec{a}$，再沿着 $\vec{b}$ 的反方向走一遍。

## 加法的运算律

向量加法满足一些很"乖"的性质：

**交换律**：$\vec{a} + \vec{b} = \vec{b} + \vec{a}$

先送 A 小区再送 B 小区，和先送 B 小区再送 A 小区，最终到达的位置一样。顺序不重要。

**结合律**：$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$

送三个小区，不管你怎么分组算，总位移都一样。

**加零不变**：$\vec{a} + \vec{0} = \vec{a}$

原地不动（零向量）加上去，等于没加。

## 数乘向量：放大缩小

有时候，骑手要跑的路线是某段路的"倍数"。比如从仓库到 A 小区是 $(3, 2)$，那从仓库到 A 小区再往前跑同样距离的两倍，就是 $3 \times (3, 2) = (9, 6)$。

数乘的规则：**用数字去乘向量的每个分量**。

$$
k \cdot \vec{v} = k \cdot (x, y) = (kx, ky)
$$

效果：

- $k > 1$：向量被拉长
- $0 < k < 1$：向量被缩短
- $k = -1$：向量方向反转，长度不变
- $k = 0$：变成零向量

数乘的几何直觉：想象把一段路程"放大 k 倍"或"缩小 k 倍"。方向要么不变（k 为正），要么反转（k 为负）。

## 归一化：用数乘得到单位向量

前面提到过，归一化就是"把向量除以它的模长"。现在用数乘的语言来说：

$$
\hat{v} = \frac{1}{|\vec{v}|} \cdot \vec{v}
$$

这就是用数乘 $\frac{1}{|\vec{v}|}$ 去缩放原向量，结果长度变成 1，方向不变。

比如骑手要沿 $(3, 4)$ 的方向走 10 公里，怎么走？先归一化得到方向 $(0.6, 0.8)$，再乘以 10：$10 \times (0.6, 0.8) = (6, 8)$。

这就是"先确定方向，再确定走多远"的思路。

## 一个接地气的类比

向量加法就像**拼接行程**——第一段路接第二段路，总位移就是答案。

数乘就像**把行程放大或缩小**——原本走 1 公里，放大 3 倍就走 3 公里；缩小一半就走 0.5 公里。如果是负数，就是掉头往回走。

## 代码示例：用 JavaScript 实现向量加法和数乘

```javascript
// 向量加法
function add(a, b) {
    return [a[0] + b[0], a[1] + b[1]];
}

// 向量减法
function subtract(a, b) {
    return [a[0] - b[0], a[1] - b[1]];
}

// 数乘
function scale(k, v) {
    return [k * v[0], k * v[1]];
}

// 试试看
const a = [3, 2];  // 仓库 → A 小区
const b = [1, 4];  // A 小区 → B 小区

console.log("总路线 a + b:", add(a, b));           // [4, 6]
console.log("从 b 终点回到 a 终点:", subtract(a, b)); // [2, -2]
console.log("路线放大 2 倍:", scale(2, a));          // [6, 4]
console.log("路线掉头:", scale(-1, a));               // [-3, -2]
```

## 小结

- **向量加法**：对应分量相加 $(a_1+b_1, a_2+b_2)$，几何上是"首尾相接"。
- **向量减法**：对应分量相减，几何上是"从终点指向终点"。
- **交换律**和**结合律**都成立，向量加法很"乖"。
- **数乘**：$k \cdot (x, y) = (kx, ky)$，效果是缩放向量。k 为正方向不变，k 为负方向反转。
- **归一化**：$\vec{v} / |\vec{v}|$ 得到单位向量，只保留方向信息。

## 练习题

**第 1 题**：已知 $\vec{a} = (2, 3)$，$\vec{b} = (4, -1)$，计算：

(a) $\vec{a} + \vec{b}$
(b) $\vec{a} - \vec{b}$
(c) $3\vec{a}$

**第 2 题**：骑手从仓库出发，先沿向量 $(5, 3)$ 到达 A 小区，再沿向量 $(-2, 4)$ 到达 B 小区。请问：

(a) 骑手相对于仓库的最终位置是什么？
(b) 如果骑手想直接飞回仓库，需要走什么向量？

**第 3 题**：验证向量加法交换律。已知 $\vec{a} = (1, 7)$，$\vec{b} = (3, -2)$，分别计算 $\vec{a} + \vec{b}$ 和 $\vec{b} + \vec{a}$，确认结果相同。

**第 4 题**：向量 $\vec{v} = (6, 8)$，请：

(a) 计算 $|\vec{v}|$
(b) 求 $\vec{v}$ 方向的单位向量
(c) 求与 $\vec{v}$ 同方向、长度为 20 的向量

---

## 练习题答案

**第 1 题答案**：

(a) $\vec{a} + \vec{b} = (2+4, 3+(-1)) = (6, 2)$

(b) $\vec{a} - \vec{b} = (2-4, 3-(-1)) = (-2, 4)$

(c) $3\vec{a} = 3 \times (2, 3) = (6, 9)$

**第 2 题答案**：

(a) 最终位置 = $(5, 3) + (-2, 4) = (3, 7)$。骑手在仓库东 3 个单位、北 7 个单位的位置。

(b) 飞回仓库 = $-(3, 7) = (-3, -7)$。从最终位置指向仓库原点。

**第 3 题答案**：

$\vec{a} + \vec{b} = (1+3, 7+(-2)) = (4, 5)$

$\vec{b} + \vec{a} = (3+1, (-2)+7) = (4, 5)$

结果相同，交换律成立。

**第 4 题答案**：

(a) $|\vec{v}| = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10$

(b) 单位向量 = $(6/10, 8/10) = (0.6, 0.8)$

(c) 长度为 20 的向量 = $20 \times (0.6, 0.8) = (12, 16)$

验证：$|(12, 16)| = \sqrt{144 + 256} = \sqrt{400} = 20$。正确。
