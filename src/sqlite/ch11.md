# 第11章：Flutter 集成（二）——Drift 类型安全 ORM

## 11.1 开场白：sqflite 用久了之后……

写了半年 sqflite 之后，你会发现自己重复三件事：

1. 每张表写一遍 `toMap()` 和 `fromMap()`——非常无聊。
2. SQL 字符串写错列名，运行时才炸——非常煎熬。
3. 每个查询手动 map 到 Dart 类型，`m['id'] as int?`、`DateTime.parse(m['x'] as String)`——非常繁琐。

有没有一种方案，让你像写 Dart 类一样写数据库表，编译期就发现 SQL 错误，`SELECT` 出来就是类型安全的 Dart 对象？

有，它叫 **drift**（前身叫 moor，2021 年改名）。

Drift 让你以 Dart 优先的方式定义数据库，用代码生成器把它转换成 SQLite 操作。**类型安全、编译期校验、响应式流、跨平台**四大天王齐备。

## 11.2 Drift 架构

```
Dart 代码：Table 类 + DriftDatabase 注解
       ↓
build_runner + drift_dev 代码生成
       ↓
生成 *.g.dart：类型安全的数据类 + Companion + Query API
       ↓
运行时：drift 库把 API 调用翻译成 SQL
       ↓
底层：sqflite（移动）/ sqlite3_ffi（桌面）/ wasm（Web）
```

**关键设计**：

- **Table 是 Dart 抽象类**，字段是"表达式"（column definition），编译期就有类型信息。
- **代码生成**：定义完表运行 `dart run build_runner build`，生成对应的 `TableName`、`TableNameData`、`TableNameCompanion` 类。
- **SQL 校验**：在 `.drift` 文件里写 SQL，drift_dev 会在编译期校验 SQL 语法和列名。

## 11.4 定义表：三种方式

### 方式 1：Dart 类（推荐新手）

```dart
// lib/database/tables.dart
import 'package:drift/drift.dart';

class Todos extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get title => text().withLength(min: 1, max: 200)();
  TextColumn get description => text().nullable()();
  BoolColumn get completed => boolean().withDefault(const Constant(false))();
  IntColumn get categoryId => integer().nullable()
      .references(Categories, #id, onDelete: KeyAction.setNull)();
  IntColumn get priority => integer().withDefault(const Constant(0))();
  DateTimeColumn get createdAt => dateTime().withDefault(currentDateAndTime)();
  DateTimeColumn get completedAt => dateTime().nullable()();
}

class Categories extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get name => text().unique()();
  TextColumn get colorHex => text().nullable()();
}
```

注意最后的 `()`——这不是拼写错误，drift 里每列定义都是"函数调用两次"（第一次返回 builder，第二次结束定义）。

### 方式 2：`.drift` SQL 文件（推荐熟练用户）

```sql
-- lib/database/schema.drift
CREATE TABLE todos (
  id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  description TEXT,
  completed INTEGER NOT NULL DEFAULT 0,
  category_id INTEGER REFERENCES categories(id) ON DELETE SET NULL,
  priority INTEGER NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  completed_at DATETIME
) STRICT;

CREATE TABLE categories (
  id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  color_hex TEXT
) STRICT;

CREATE INDEX idx_todo_completed ON todos(completed, created_at DESC);

-- 具名查询（会生成类型安全的 Dart 方法）
allActiveTodos:
  SELECT * FROM todos WHERE completed = 0 ORDER BY priority DESC, created_at DESC;

todoWithCategory:
  SELECT t.*, c.name AS category_name
  FROM todos t LEFT JOIN categories c ON c.id = t.category_id
  WHERE t.id = :id;
```

drift_dev 会**在编译期校验这些 SQL**，写错列名直接构建失败。

### 方式 3：混合模式

Dart 类定义表，`.drift` 文件写复杂 SQL：

```dart
@DriftDatabase(
  tables: [Todos, Categories],
  include: {'schema.drift'},        // 引入 SQL 文件里的 CREATE INDEX 和查询
)
class AppDatabase extends _$AppDatabase { ... }
```

## 11.5 DriftDatabase：数据库主类

```dart
// lib/database/app_database.dart
import 'package:drift/drift.dart';
import 'package:drift/native.dart';
import 'package:path_provider/path_provider.dart';
import 'package:path/path.dart' as p;
import 'dart:io';

import 'tables.dart';

part 'app_database.g.dart';        // 代码生成的文件

@DriftDatabase(tables: [Todos, Categories])
class AppDatabase extends _$AppDatabase {
  AppDatabase() : super(_openConnection());

  @override
  int get schemaVersion => 1;

  @override
  MigrationStrategy get migration => MigrationStrategy(
    onCreate: (Migrator m) async {
      await m.createAll();
    },
    onUpgrade: (Migrator m, int from, int to) async {
      // 后续版本升级
    },
    beforeOpen: (details) async {
      await customStatement('PRAGMA foreign_keys = ON');
    },
  );
}

LazyDatabase _openConnection() {
  return LazyDatabase(() async {
    final dir = await getApplicationDocumentsDirectory();
    final file = File(p.join(dir.path, 'todo_drift.db'));
    return NativeDatabase.createInBackground(file);
  });
}
```

**关键点**：

- `part 'app_database.g.dart'` 引入生成的文件。
- `_$AppDatabase` 是生成的基类。
- `NativeDatabase.createInBackground` 让数据库在**独立 isolate** 上运行，不阻塞 UI。这是 drift 相对 sqflite 的一大优势。

## 11.6 运行代码生成

```bash
dart run build_runner build
# 或者监听模式（改代码自动重新生成）
dart run build_runner watch --delete-conflicting-outputs
```

生成之后你会得到 `app_database.g.dart`，里面有：

- `Todo`（数据类，对应一行）
- `TodosCompanion`（用于 INSERT/UPDATE 的类，支持 `Value.absent()`）
- `$TodosTable`（表元数据）
- 一堆生成的 API

## 11.7 Companion 类：为什么需要它？

考虑这个场景：`INSERT INTO todo(title, priority) VALUES ('x', 5)`——`id` 让数据库自动生成，`created_at` 用默认值。

用普通的 `Todo` 数据类：`Todo(id: ???, title: 'x', ...)` 一堆字段要填。

Drift 生成的 `TodosCompanion` 让你只填要写入的字段：

```dart
await db.into(db.todos).insert(TodosCompanion.insert(
  title: 'x',
  priority: const Value(5),
));
// 或者
await db.into(db.todos).insert(TodosCompanion(
  title: const Value('x'),
  priority: const Value(5),
  // 其他字段自动是 Value.absent()，SQL 里不出现
));
```

`Value<T>` 有三种状态：`Value(x)`（有值）、`Value(null)`（值为 NULL）、`Value.absent()`（不出现在 SQL 里）。

**记忆窍门**：Data 类 = 一行完整数据（用于读）；Companion 类 = 部分字段（用于写）。

## 11.8 类型安全查询 API

```dart
// SELECT * FROM todos
final all = await db.select(db.todos).get();      // Future<List<Todo>>

// WHERE completed = 0 ORDER BY created_at DESC
final active = await (db.select(db.todos)
  ..where((t) => t.completed.equals(false))
  ..orderBy([(t) => OrderingTerm.desc(t.createdAt)])).get();

// LIMIT / OFFSET
final page = await (db.select(db.todos)
  ..limit(20, offset: 40)).get();

// INSERT
final id = await db.into(db.todos).insert(TodosCompanion.insert(
  title: '学 drift',
  priority: const Value(1),
));

// UPDATE
await (db.update(db.todos)..where((t) => t.id.equals(id)))
  .write(TodosCompanion(completed: const Value(true)));

// DELETE
await (db.delete(db.todos)..where((t) => t.id.equals(id))).go();
```

**表达式 API**：`t.title.like('%学%')`、`t.priority.isBetween(1, 5)`、`t.createdAt.isBiggerThan(fromDate)`……

**JOIN**：

```dart
final query = db.select(db.todos).join([
  leftOuterJoin(db.categories,
    db.categories.id.equalsExp(db.todos.categoryId)),
]);
final rows = await query.get();
for (final row in rows) {
  final todo = row.readTable(db.todos);
  final cat = row.readTableOrNull(db.categories);
  print('${todo.title} - ${cat?.name}');
}
```

**聚合**：

```dart
final count = db.todos.id.count();
final result = await (db.selectOnly(db.todos)
  ..addColumns([db.todos.categoryId, count])
  ..groupBy([db.todos.categoryId])).get();
for (final row in result) {
  print('${row.read(db.todos.categoryId)}: ${row.read(count)}');
}
```

## 11.9 自定义 SQL：@DriftAccessor + .drift 文件

有些查询用 API 表达太啰嗦，直接写 SQL 更清爽：

```sql
-- lib/database/todo_queries.drift
import 'tables.drift';

todosWithCategoryName:
  SELECT t.*, c.name AS category_name, c.color_hex
  FROM todos t
  LEFT JOIN categories c ON c.id = t.category_id
  WHERE (:categoryId IS NULL OR t.category_id = :categoryId)
  ORDER BY t.priority DESC, t.created_at DESC;

topPriorityTodos:
  SELECT * FROM todos WHERE priority >= :minPriority ORDER BY priority DESC LIMIT 10;
```

在 database 里 include：

```dart
@DriftDatabase(
  tables: [Todos, Categories],
  include: {'todo_queries.drift'},
)
class AppDatabase extends _$AppDatabase { ... }
```

代码生成器会生成对应的方法：

```dart
final todos = await db.todosWithCategoryName(categoryId: 3);
// 每行是 TodosWithCategoryNameResult 类型，包含所有字段
final top = await db.topPriorityTodos(minPriority: 5);
```

**编译期 SQL 校验**：写错 `SLECT` 或者列名 `titles`，构建直接失败。这是 drift 最大的杀器之一。

## 11.10 流式查询（Watch）——响应式 UI 的秘密武器

```dart
// 返回 Stream<List<Todo>>
final Stream<List<Todo>> stream = db.select(db.todos).watch();

// 每当 todos 表变化，stream 会发出新数据！
stream.listen((todos) {
  print('todos changed: ${todos.length}');
});
```

在 Flutter 里配合 `StreamBuilder`：

```dart
class TodoListPage extends StatelessWidget {
  final AppDatabase db;
  const TodoListPage(this.db);

  @override
  Widget build(BuildContext c) {
    return StreamBuilder<List<Todo>>(
      stream: db.select(db.todos).watch(),
      builder: (_, snap) {
        if (!snap.hasData) return const CircularProgressIndicator();
        final todos = snap.data!;
        return ListView.builder(
          itemCount: todos.length,
          itemBuilder: (_, i) => TodoTile(todo: todos[i]),
        );
      },
    );
  }
}
```

**背后原理**：drift 追踪每个查询涉及的表；表变化时，通知所有相关流。这是"数据变了，UI 自动刷"的自动化实现——完全不用手动 `setState`。

`.watch()` 也支持自定义 SQL：`db.todosWithCategoryName(categoryId: 3).watch()`。

## 11.11 迁移策略

```dart
@override
MigrationStrategy get migration => MigrationStrategy(
  onCreate: (m) => m.createAll(),

  onUpgrade: (m, from, to) async {
    if (from < 2) {
      await m.addColumn(todos, todos.priority);
    }
    if (from < 3) {
      await m.createTable(categories);
    }
  },

  beforeOpen: (details) async {
    if (details.wasCreated) {
      // 首次创建，插入种子数据
      await into(categories).insert(CategoriesCompanion.insert(name: '默认'));
    }
    await customStatement('PRAGMA foreign_keys = ON');
  },
);
```

**drift schema tool**：drift 提供了迁移测试工具，可以生成每个版本的 schema 快照，写测试验证升级正确：

```bash
dart run drift_dev schema dump lib/database/app_database.dart drift_schemas/
dart run drift_dev schema generate drift_schemas/ test/generated_migrations/
```

生成的测试模板能让你在单测里模拟"从 v1 升级到 v3"，验证数据保留正确。

## 11.14 完整案例：把第 10 章 Todo App 重写为 drift 版

### 表定义（Dart 类版）

```dart
// lib/database/tables.dart
import 'package:drift/drift.dart';

@DataClassName('Todo')
class Todos extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get title => text().withLength(min: 1, max: 200)();
  TextColumn get description => text().nullable()();
  BoolColumn get completed => boolean().withDefault(const Constant(false))();
  IntColumn get categoryId => integer().nullable()
      .references(Categories, #id, onDelete: KeyAction.setNull)();
  IntColumn get priority => integer().withDefault(const Constant(0))();
  DateTimeColumn get createdAt => dateTime().withDefault(currentDateAndTime)();
  DateTimeColumn get completedAt => dateTime().nullable()();
}

@DataClassName('Category')
class Categories extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get name => text().unique()();
  TextColumn get colorHex => text().nullable()();
}
```

### Database

```dart
// lib/database/app_database.dart
import 'package:drift/drift.dart';
import 'package:drift/native.dart';
import 'package:path_provider/path_provider.dart';
import 'package:path/path.dart' as p;
import 'dart:io';

import 'tables.dart';

part 'app_database.g.dart';

@DriftDatabase(tables: [Todos, Categories])
class AppDatabase extends _$AppDatabase {
  AppDatabase() : super(_open());

  @override int get schemaVersion => 1;

  @override
  MigrationStrategy get migration => MigrationStrategy(
    onCreate: (m) async {
      await m.createAll();
      await m.database.customStatement('''
        CREATE INDEX idx_todo_completed ON todos(completed, created_at DESC)
      ''');
    },
    beforeOpen: (_) => customStatement('PRAGMA foreign_keys = ON'),
  );

  // DAO 方法：全部类型安全
  Stream<List<Todo>> watchAllTodos() =>
    (select(todos)..orderBy([
      (t) => OrderingTerm.desc(t.priority),
      (t) => OrderingTerm.desc(t.createdAt),
    ])).watch();

  Stream<List<Todo>> watchByCategory(int? categoryId) {
    final q = select(todos);
    if (categoryId != null) {
      q.where((t) => t.categoryId.equals(categoryId));
    }
    q.orderBy([(t) => OrderingTerm.desc(t.createdAt)]);
    return q.watch();
  }

  Future<Todo> createTodo({
    required String title,
    String? description,
    int? categoryId,
    int priority = 0,
  }) async {
    final id = await into(todos).insert(TodosCompanion.insert(
      title: title,
      description: Value(description),
      categoryId: Value(categoryId),
      priority: Value(priority),
    ));
    return (select(todos)..where((t) => t.id.equals(id))).getSingle();
  }

  Future<void> toggleCompleted(int id) async {
    await transaction(() async {
      final todo = await (select(todos)..where((t) => t.id.equals(id)))
        .getSingle();
      await (update(todos)..where((t) => t.id.equals(id))).write(
        TodosCompanion(
          completed: Value(!todo.completed),
          completedAt: Value(todo.completed ? null : DateTime.now()),
        ),
      );
    });
  }

  Future<int> deleteTodo(int id) =>
    (delete(todos)..where((t) => t.id.equals(id))).go();

  Future<void> bulkInsert(List<TodosCompanion> items) async {
    await batch((b) {
      b.insertAll(todos, items);
    });
  }
}

LazyDatabase _open() {
  return LazyDatabase(() async {
    final dir = await getApplicationDocumentsDirectory();
    return NativeDatabase.createInBackground(
      File(p.join(dir.path, 'todo_drift.db')),
    );
  });
}
```

### UI（用 StreamBuilder）

```dart
class TodoListPage extends StatelessWidget {
  final AppDatabase db;
  const TodoListPage(this.db);

  @override Widget build(BuildContext c) {
    return Scaffold(
      appBar: AppBar(title: const Text('Todos (drift)')),
      body: StreamBuilder<List<Todo>>(
        stream: db.watchAllTodos(),
        builder: (_, snap) {
          if (!snap.hasData) return const Center(child: CircularProgressIndicator());
          final todos = snap.data!;
          if (todos.isEmpty) return const Center(child: Text('还没有 todo，加一个吧'));
          return ListView.builder(
            itemCount: todos.length,
            itemBuilder: (_, i) {
              final t = todos[i];
              return Dismissible(
                key: ValueKey(t.id),
                onDismissed: (_) => db.deleteTodo(t.id),
                child: CheckboxListTile(
                  value: t.completed,
                  onChanged: (_) => db.toggleCompleted(t.id),
                  title: Text(t.title,
                    style: TextStyle(decoration: t.completed
                      ? TextDecoration.lineThrough : null)),
                  subtitle: t.description == null
                    ? null : Text(t.description!),
                ),
              );
            },
          );
        },
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => db.createTodo(
          title: '任务 ${DateTime.now().millisecondsSinceEpoch}',
        ),
        child: const Icon(Icons.add),
      ),
    );
  }
}
```

**对比第 10 章的 sqflite 版本**：

- 少了 `Todo.toMap()` / `fromMap()`（生成的）
- 少了手动 `setState` 或 `_load()`（Stream 自动）
- 少了 `Map<String, Object?>` 里那些 `as int` 转换
- 编译期就能发现列名/类型错误

代码量减少 30%~50%，类型安全提升 100%。

## 11.15 常见坑点合集

**坑 1：忘了运行 build_runner**

改了 Table 定义没跑 `dart run build_runner build`，`_$AppDatabase` 不更新，编译报错。建议开个终端跑 `watch` 模式。

**坑 2：老 schema 快照没保存**

发布 v2 之后如果没保存 v1 的 schema，将来测迁移会很痛苦。**每次发版都要 dump schema 快照**（用 drift 的 schema tool）。

**坑 3：Companion 里忘了用 `Value(...)`**

```dart
// ❌ 编译错
TodosCompanion.insert(title: 'x', priority: 5);

// ✅ 
TodosCompanion.insert(title: 'x', priority: Value(5));
```

必填字段直接传值，可选/带默认值的字段需要包 `Value`。

**坑 4：`.drift` 文件的 SQL 校验太严**

drift_dev 的 SQL 校验器不认识某些 SQLite 特有语法（比如某些函数）。可以在 `build.yaml` 里放宽：

```yaml
targets:
  $default:
    builders:
      drift_dev:
        options:
          sqlite:
            version: "3.45"
          write_from_json_string_constructor: true
          skip_verification_code: false      # 严格模式
```

**坑 5：watch 太多导致性能问题**

每个 `.watch()` 都会订阅表变化。同一个页面开 20 个 watch，每次任何 todo 变化都要重跑 20 个查询——性能雪崩。**用 select 合并、用 selector 记忆化**。

**坑 6：跨 isolate 传 Database**

drift 的 `NativeDatabase.createInBackground` 已经内部帮你隔离了。**不要在应用代码里手动开 isolate 传 database**。真要多 isolate 共享，用 `DriftIsolate.spawn`（drift 官方 API）。

**坑 7：迁移里用了 Dart 表达式**

```dart
onUpgrade: (m, from, to) async {
  if (from < 2) {
    // ❌ 这里的 db 是老 schema，用 drift API 可能出错
    await into(users).insert(UsersCompanion.insert(...));
  }
}
```

迁移里最好用 `customStatement('...')` 或者 `m.database.customStatement` 写原生 SQL，避免用当前 schema 的 API 引用可能已经改变的表。

**坑 8：boolean 存储方式冲突**

drift 默认用 `INTEGER` 存 bool（0/1）。如果从别的库迁移过来数据里存的是 `'true'`/`'false'`，drift 读出来会报错。用 `TypeConverter` 定制。

## 11.16 sqflite vs drift 全方位对比

| 维度                 | sqflite                              | drift                                     |
| -------------------- | ------------------------------------ | ----------------------------------------- |
| 学习曲线             | 低（会 SQL 就行）                    | 中（要学 API + 代码生成）                 |
| 类型安全             | 无（Map<String, Object?>）           | 强（编译期 SQL 校验）                     |
| SQL 灵活度           | 100%（想写啥写啥）                   | 95%（自定义 SQL 也支持）                  |
| 代码量               | 多（toMap/fromMap 手写）             | 少（生成器搞定）                          |
| 响应式流             | 无（要自己封装）                     | 内置（`.watch()`）                        |
| Isolate 支持         | 手动                                 | 自动（createInBackground）                |
| 跨平台               | iOS/Android + FFI 扩展               | iOS/Android/Web/桌面 全平台               |
| 迁移工具             | 手写                                 | schema dump + 自动测试模板                |
| 依赖复杂度           | 低（几乎无生成）                     | 中（build_runner + drift_dev）            |
| 编译速度             | 快                                   | 中等（代码生成有开销）                    |
| 社区包               | 多（sqflite_sqlcipher 等）           | 少但精                                    |
| 官方支持             | Google Flutter 团队维护              | 社区维护但非常活跃                        |
| 加密支持             | sqflite_sqlcipher                    | 通过 SqfliteQueryExecutor 桥接            |

**什么时候选 sqflite？**

- 项目已经用了、稳定运行
- SQL 是团队强项，喜欢直接写
- 只做移动端
- 想最小依赖

**什么时候选 drift？**

- 新项目，尤其中大型
- 团队重视类型安全
- 需要跨平台（Web/桌面）
- 想要响应式 UI（配合 Riverpod/Bloc）
- 数据模型复杂，多张表 JOIN 频繁
- 团队里 Dart 熟手多、纯 SQL 熟手少

**我的建议**：

- **Demo/学习/极小 App**：sqflite 就够了。
- **正式生产项目**：优先 drift，未来收益远大于学习成本。
- **超大型项目（几十张表）**：drift 加类型安全，两年后维护会感谢自己。

## 11.17 本章小结

- Drift = 类型安全 ORM + 编译期 SQL 校验 + 代码生成。
- 三种表定义：Dart 类 / `.drift` 文件 / 混合模式。
- `Companion` 类用于写入，`Data` 类用于读取，`Value<T>` 三态（值/NULL/absent）。
- 类型安全查询 API 支持 SELECT/JOIN/GROUP BY/聚合，链式调用。
- `.drift` 文件里写复杂 SQL，编译期校验，生成类型安全方法。
- `.watch()` 是响应式 UI 的杀器，配合 StreamBuilder / Riverpod / Bloc 神来之笔。
- 迁移用 `MigrationStrategy` + schema dump 工具，测试完备。
- 跨平台：移动/桌面/Web 全支持。
- sqflite vs drift：小项目和喜欢裸写 SQL 用 sqflite，中大型和追求类型安全用 drift。
- **金句**：sqflite 是"我信你的 SQL"，drift 是"我帮你把 SQL 做对"。
