# 第13章：导出与分享——PPT的多种输出方式 📦

*路演前一天下午，投资人助理发来消息："林先生，麻烦把路演PPT提前发一份过来，我们团队想先看看。"小林心想这简单，直接把PPTX文件发了过去。五分钟后，对方回消息："林先生，您这个文件在我们电脑上打开，字体全变了，Logo也错位了……"小林一看截图，傻眼了——明明在自己电脑上那么好看的PPT，到了别人电脑上怎么就"毁容"了？老周路过瞟了一眼："你没嵌字体、没转PDF，就这样发PPTX？年轻人啊……"*

## 13.1 PPTX vs PPT：格式区别与兼容性

首先搞清楚PPT的两种文件格式：

| 特性 | .pptx | .ppt |
| ------ | ------- | ------ |
| 版本 | Office 2007及以后 | Office 97-2003 |
| 技术 | 基于XML | 二进制格式 |
| 文件体积 | 更小 | 更大 |
| 功能支持 | 支持所有新功能 | 不支持部分新功能 |
| 当前使用率 | 主流格式 | 基本淘汰 |

> 💡 **提示**：现在几乎没有人还在用 `.ppt` 格式了。但如果你需要把PPT发给一个使用很旧版Office的人（比如还在用Office 2003的……那得是多怀旧的人），可以通过 `文件 > 另存为` 选择 `.ppt` 格式保存。不过注意，新版功能（比如平滑切换、新图表类型）在旧格式中会丢失。

## 13.2 导出为PDF：最保险的分享方式

**PDF是分享PPT最安全的方式**，没有之一。

为什么？因为PDF会把你的PPT"冻结"成一个固定排版的文件：

- 字体不会变——因为PDF内嵌了字体
- 排版不会乱——因为PDF是固定布局
- 任何设备都能打开——手机、电脑、平板、甚至智能冰箱

**导出方法**：

方法一：`文件 > 另存为 > 选择"PDF"格式`

方法二：`文件 > 导出 > 创建PDF/XPS文档`

**PDF的注意事项**：

- 动画和切换效果会丢失——PDF是静态的
- 视频和音频不会播放
- 超链接可以保留（在导出选项中确认已勾选）

> 💡 **提示**：发送给不需要演示、只需要"看"的人（比如投资人预审、老板审批），一律用PDF。只有在需要现场演示的情况下才发送PPTX。记住老周的话："发PPTX是请别人帮你调试，发PDF才是给别人看。"

## 13.3 导出为视频：PPT变视频文件

PPT可以导出为视频文件（MP4），这是一个非常实用的功能：

- 把路演PPT录成视频发给不在场的投资人
- 把培训PPT变成教学视频上传到网课平台
- 把产品介绍PPT变成视频放在展会大屏上循环播放

**导出方法**：

1. `文件 > 导出 > 创建视频`
2. 选择视频质量：
   - **超高清（4K）**：适合大屏展示，文件较大
   - **全高清（1080p）**：日常推荐，画质好、文件适中
   - **高清（720p）**：网络分享推荐，文件较小
   - **标准（480p）**：仅用于低带宽场景
3. 设置每页停留时间（如果没有录制计时，默认每页5秒）
4. 点击"创建视频"，选择保存路径
5. 等待导出完成（右下角有进度条）

**如果录制过旁白**：

- 导出视频时会自动包含你录制的语音旁白
- 翻页时间也会按照你录制时的节奏来

> 💡 **提示**：导出视频前最好先"排练计时"或"录制幻灯片演示"，这样视频的节奏会自然流畅。否则每页固定5秒会显得很生硬。

## 13.4 导出为图片：逐页导出PNG/JPG

有时候你需要把PPT的每一页变成单独的图片，比如：

- 发到微信公众号推文里
- 插入到其他文档中
- 制作图片轮播

**导出方法**：

1. `文件 > 另存为`
2. 格式选择"PNG可移植网络图形"或"JPEG文件交换格式"
3. 点击保存时，PPT会问你"导出所有幻灯片还是仅当前幻灯片"
4. 选择"所有幻灯片"

导出后，你会得到一个文件夹，里面有以页码命名的图片文件（幻灯片1.png、幻灯片2.png……）。

**PNG vs JPG怎么选**：

| 格式 | 优点 | 缺点 | 适用场景 |
| ------ | ------ | ------ | --------- |
| PNG | 无损压缩、支持透明背景、文字清晰 | 文件较大 | 含文字的幻灯片、需要透明背景 |
| JPG | 文件小、通用性强 | 有损压缩、文字可能模糊 | 以图片为主的幻灯片、网络分享 |

> 💡 **提示**：如果PPT包含大量文字和图表，建议导出为PNG，文字会更清晰。如果主要是图片和背景，JPG就足够了。

## 13.5 打包成CD：确保字体和链接不丢失

当你要把PPT拷贝到U盘带到现场演示时，"打包成CD"功能能确保万无一失。

**打包内容**：

- PPTX文件本身
- 所有嵌入的字体文件
- 所有链接的外部文件（如嵌入的视频）

**操作方法**：

1. `文件 > 导出 > 将演示文稿打包成CD`
2. 点击"打包成CD"
3. 设置名称，选择保存位置
4. 在"选项"中确认勾选"嵌入的TrueType字体"和"链接的文件"
5. 完成打包

打包后会得到一个文件夹，包含PPT文件和所有关联资源。把这个文件夹整个拷贝到U盘里，在任何电脑上打开都不会出问题。

> 💡 **提示**：虽然这个功能叫"打包成CD"（这个名字暴露了它的历史），但实际上就是打包到一个文件夹中，跟CD没什么关系了。

## 13.6 云存储与在线分享：OneDrive集成

PowerPoint与微软OneDrive深度集成，提供了更现代的分享方式：

**保存到OneDrive**：

1. `文件 > 另存为 > OneDrive`
2. 保存后，点击右上角的"共享"按钮
3. 生成分享链接，设置权限（可查看/可编辑）

**在线协作**：

- 多人可以同时编辑同一个PPT（需要OneDrive或SharePoint）
- 可以看到其他人正在编辑哪一页（用不同颜色标注）
- 修改历史可以追溯和回退

**PowerPoint Online**：

- 即使没有安装Office，也可以在浏览器中使用 `office.com` 编辑PPT
- 功能比桌面版少，但基本的编辑和演示都支持
- 适合临时在别人电脑上修改PPT

> 💡 **提示**：使用云存储的好处是，你永远带着最新版的PPT。不怕U盘忘带、不怕文件版本搞混。路演前把PPT存到OneDrive，同时U盘里也留一份备份——双保险。

## 13.7 字体嵌入：换电脑不变形

字体问题是小林遇到的那个"惨案"的根本原因。你在自己电脑上用了一款漂亮的字体，但对方电脑上没有这个字体，PPT就会自动替换成默认字体——然后整个排版就崩了。

**字体嵌入方法**：

1. `文件 > 选项 > 保存`
2. 勾选 **"将字体嵌入文件"**
3. 选择嵌入模式：
   - **"仅嵌入演示文稿中使用的字符"**：文件较小，但别人编辑时可能缺字
   - **"嵌入所有字符"**：文件较大，但保证所有字符都可用
4. 点击确定，保存文件

**字体嵌入的注意事项**：

- 不是所有字体都允许嵌入——有些字体有版权限制，PPT会提示无法嵌入
- 嵌入字体会增大文件体积，尤其是"嵌入所有字符"模式
- 如果字体无法嵌入，可以考虑导出为PDF，PDF会自动处理字体问题

> 💡 **提示**：使用系统自带字体（如微软雅黑、Calibri）不需要嵌入，因为每台Windows电脑都有。只有当你使用了第三方字体（如思源黑体、阿里巴巴普惠体）时，才需要嵌入。

## 13.8 文件压缩：减小PPT体积的实用技巧

PPT文件太大是个常见问题，尤其是包含大量高清图片和视频的PPT。文件太大会导致：发送邮箱超限、U盘拷贝慢、上传下载耗时。

**压缩图片**：

1. 选中PPT中的任意一张图片
2. 顶部出现"图片格式"选项卡，点击 **"压缩图片"**
3. 选择分辨率：
   - **高保真**：保持原始质量
   - **HD（330 ppi）**：适合打印
   - **打印（220 ppi）**：适合大多数屏幕
   - **Web（150 ppi）**：适合屏幕浏览
   - **电子邮件（96 ppi）**：最小体积
4. 勾选"应用于此文件中的所有图片"
5. 点击确定

**其他减小体积的方法**：

| 方法 | 操作 | 效果 |
| ------ | ------ | ------ |
| 压缩图片 | 如上 | 可减小50-80%体积 |
| 压缩视频 | `文件 > 信息 > 压缩媒体` | 可减小60-90%体积 |
| 删除裁剪区域 | 图片压缩选项中勾选"删除图片的裁剪区域" | 删除不可见的裁剪部分 |
| 不嵌入字体 | 取消字体嵌入 | 减小2-10MB |
| 使用链接而非嵌入 | 视频用超链接而不是嵌入 | 大幅减小体积 |

> 💡 **提示**：压缩前先备份原文件。压缩是不可逆的——你压缩了图片质量后，原图就找不回来了。

## 13.9 实战：小林的路演PPT输出清单

经历了"字体惨案"之后，小林学会了根据场景选择合适的输出格式。以下是他的路演PPT输出清单：

| 用途 | 输出格式 | 设置要点 |
| ------ | --------- | --------- |
| 提前发给投资人预审 | PDF | 确保超链接可用，检查每页排版 |
| 路演现场演示 | PPTX（自带U盘+OneDrive备份） | 嵌入字体，打包所有链接文件 |
| 路演后发给投资人回顾 | PDF + 录制视频 | PDF方便快速浏览，视频还原演讲 |
| 社交媒体宣传 | 逐页PNG图片 | 高清导出，适当裁剪 |
| 公司内部存档 | PPTX原始文件 + 模板文件 | 保存未压缩原始版本 |

小林的操作步骤：

1. **先做最终检查**：逐页确认无错别字、动画正常、链接可用
2. **嵌入字体保存PPTX**：`文件 > 选项 > 保存 > 嵌入字体`
3. **导出PDF**：`文件 > 另存为 > PDF`，发送给投资人预审
4. **录制演示视频**：`录制幻灯片演示 > 导出为MP4（1080p）`
5. **打包到U盘**：`导出 > 打包成CD`，拷入U盘作为路演当天的备份
6. **同步到OneDrive**：上传到云端，生成分享链接作为备用

老周看了小林的操作，满意地点了点头："现在你可以放心地把PPT发给任何人、带到任何地方了。"

## 练习题

1. **基础题**：打开你的PPT，分别导出为PDF和PNG图片，对比两种格式的效果差异（文件大小、文字清晰度、打开速度）。

2. **进阶题**：录制一段3分钟的PPT演示视频（带旁白），导出为MP4格式。回看视频，检查语音和翻页是否同步。

3. **挑战题**：制作一个PPT的"完整输出方案"：包含嵌入字体的PPTX、PDF版本、关键页的PNG图片，并打包到U盘中。模拟你要把这个PPT同时发给3个不同的人（投资人、设计师朋友、公司内部存档），每个人需要什么格式？
