# 第10章：React Router — 让应用多起来

![第10章封面](./images/ch10.png)

## 引言：从"一页纸"到"一本书"

还记得你做的第一个 React 应用吗？所有内容都挤在一个页面上，就像把所有家当都塞进了一个房间——客厅、卧室、厨房、厕所全在一起。客人来了想看卧室？对不起，你得先路过厨房和厕所。

这显然不科学！现实中的网站都有多个页面：首页、产品列表、产品详情、关于我们……你访问的淘宝、知乎、B站，哪个不是这样？

但你可能会问："React 不是单页应用（SPA）吗？怎么做到多页面的效果？"

好问题！这就是本章的主角 —— **React Router** 要解决的问题。

> **比喻时间**：React Router 就像商场的导航牌。你在商场（SPA）里，想去耐克店（首页）就去一楼，想去星巴克（关于页）就去二楼。你始终在同一个商场里，但导航牌告诉你当前在哪个区域、该往哪走。没有导航牌？你就得在商场里瞎逛碰运气了。

---

## 10.1 为什么单页应用需要路由？

在传统的多页应用（MPA）中，每次点击链接，浏览器都会向服务器请求一个全新的 HTML 文件，整个页面都会刷新。这就像你每次换房间都要重新装修一遍。

而在单页应用（SPA）中，**页面不会真的刷新**。React 只是在同一个 HTML 页面上，根据 URL 的变化动态切换显示不同的组件。用户感觉自己在"翻页"，但其实页面从未真正加载过新文档。

那问题来了：**URL 变了，React 怎么知道该显示哪个组件？**

答案是：**路由（Routing）**。路由就是一一套规则，它告诉 React："当 URL 是 `/about` 的时候，显示 About 组件；当 URL 是 `/posts/123` 的时候，显示 ID 为 123 的文章详情。"

> [!TIP] 提示
> ：SPA 的优势是用户体验流畅（不用整页刷新），但缺点是需要客户端路由来管理页面切换。这就是 React Router 存在的意义。

## 10.2 安装 React Router

React Router 不是 React 自带的，需要单独安装。我们使用目前主流的 **v6 版本**：

```bash
# 在项目目录下执行
npm install react-router-dom
```

`react-router-dom` 是专门为浏览器环境设计的 React Router 包。如果你在做 React Native 应用，会用 `react-router-native`，但我们这里专注于 Web 开发。

## 10.3 基本配置：BrowserRouter、Routes、Route

让我们从一个最简单的例子开始，搭建一个有三个页面的应用：

```jsx
// src/App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';

// 首页组件
function Home() {
  return <h1>欢迎来到我的博客 🏠</h1>;
}

// 文章列表组件
function Posts() {
  return <h1>文章列表 📝</h1>;
}

// 关于页组件
function About() {
  return <h1>关于我 👤</h1>;
}

function App() {
  return (
    // BrowserRouter 包裹整个应用，提供路由功能
    <BrowserRouter>
      {/* Routes 是路由的容器，会匹配当前 URL */}
      <Routes>
        {/* 每个 Route 定义一个 URL 到组件的映射 */}
        <Route path="/" element={<Home />} />
        <Route path="/posts" element={<Posts />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

export default App;
```

**原理解析：**

- **`BrowserRouter`**：这是路由的"总指挥"。它监听浏览器的 URL 变化，并把当前 URL 信息传递给子组件。你可以把它想象成商场的中央控制系统。
- **`Routes`**：这是路由的"匹配器"。它会遍历里面的所有 `Route`，找到与当前 URL 匹配的那个。
- **`Route`**：这是路由的"映射规则"。`path` 是 URL 路径，`element` 是要渲染的组件。

> [!WARNING] 注意
> `BrowserRouter` 必须包裹在最外层，否则 `Routes` 和其他路由组件都无法工作。常见错误是把 `BrowserRouter` 放在了 `Routes` 的兄弟位置，导致路由完全失效。

## 10.4 导航组件：Link 和 NavLink

有了路由规则，用户怎么在页面之间跳转呢？直接用 `<a>` 标签？

**千万不要！** 用 `<a>` 标签会触发浏览器的完整页面刷新，SPA 的优势就全没了。React Router 提供了两个专用导航组件：

### Link — 基础导航

```jsx
import { Link } from 'react-router-dom';

function Navigation() {
  return (
    <nav>
      {/* Link 不会触发页面刷新，只是改变 URL 并切换组件 */}
      <Link to="/">首页</Link>
      <Link to="/posts">文章</Link>
      <Link to="/about">关于</Link>
    </nav>
  );
}
```

`Link` 渲染为一个 `<a>` 标签，但它拦截了点击事件，阻止了默认的页面跳转行为，取而代之的是用 JavaScript 修改 URL 并让 React Router 切换组件。

### NavLink — 带激活状态的导航

`NavLink` 是 `Link` 的增强版，它能自动判断当前 URL 是否匹配，并给匹配的链接添加特殊样式：

```jsx
import { NavLink } from 'react-router-dom';

function Navigation() {
  return (
    <nav style={{ display: 'flex', gap: '16px', padding: '16px' }}>
      {/* 
        NavLink 的 className 可以接收一个函数
        isActive 表示当前链接是否与 URL 匹配
      */}
      <NavLink 
        to="/" 
        className={({ isActive }) => 
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        首页
      </NavLink>
      <NavLink 
        to="/posts" 
        className={({ isActive }) => 
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        文章
      </NavLink>
      <NavLink 
        to="/about" 
        className={({ isActive }) => 
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        关于
      </NavLink>
    </nav>
  );
}
```

> [!TIP] 提示
> ：`NavLink` 非常适合做导航栏——用户一眼就能看出当前在哪个页面，就像商场导航地图上高亮显示"你在这里"一样。

## 10.5 嵌套路由与 Outlet

现实中的页面通常有公共的布局（比如导航栏、页脚），不同页面只是中间的内容区域不同。嵌套路由就是为此设计的。

```jsx
import { BrowserRouter, Routes, Route, Outlet, NavLink } from 'react-router-dom';

// 布局组件 — 包含公共的导航和页脚
function Layout() {
  return (
    <div>
      {/* 公共导航栏 */}
      <header style={{ background: '#333', color: '#fff', padding: '16px' }}>
        <nav style={{ display: 'flex', gap: '16px' }}>
          <NavLink to="/" style={({ isActive }) => ({ 
            color: isActive ? '#ffd700' : '#fff' 
          })}>首页</NavLink>
          <NavLink to="/posts" style={({ isActive }) => ({ 
            color: isActive ? '#ffd700' : '#fff' 
          })}>文章</NavLink>
          <NavLink to="/about" style={({ isActive }) => ({ 
            color: isActive ? '#ffd700' : '#fff' 
          })}>关于</NavLink>
        </nav>
      </header>

      {/* Outlet 是子路由的"出口"，子路由的组件会渲染在这里 */}
      <main style={{ padding: '24px', minHeight: '400px' }}>
        <Outlet />
      </main>

      {/* 公共页脚 */}
      <footer style={{ background: '#f0f0f0', padding: '16px', textAlign: 'center' }}>
        <p>© 2024 我的博客. All rights reserved.</p>
      </footer>
    </div>
  );
}

function Home() {
  return <h1>欢迎来到我的博客 🏠</h1>;
}

function Posts() {
  return <h1>文章列表 📝</h1>;
}

function About() {
  return <h1>关于我 👤</h1>;
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        {/* Layout 作为父路由，它的子路由会渲染在 Layout 的 Outlet 位置 */}
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />          {/* index 表示默认子路由 */}
          <Route path="posts" element={<Posts />} />   {/* 子路由路径不需要加 / */}
          <Route path="about" element={<About />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}

export default App;
```

**关键概念：**

- **`Outlet`**：这是嵌套路由的"插槽"。当 URL 匹配到某个子路由时，子路由的组件就会渲染在父组件的 `<Outlet />` 位置。
- **`index`**：当 URL 正好是父路由的路径（`/`）时，`index` 路由会作为默认子路由被渲染。
- **子路由的 path 不加 `/`**：子路由路径是相对于父路由的。`posts` 会匹配 `/posts`。

> **比喻**：`Outlet` 就像电视机——外壳（Layout）一直在，但换台（切换子路由）的时候，屏幕里播放的内容（子路由组件）会变。

## 10.6 动态路由参数：useParams

假设你有一个文章详情页，URL 是 `/posts/123`，其中 `123` 是文章的 ID。你不可能为每篇文章都写一个 Route 吧？这时候就需要**动态路由参数**。

```jsx
import { useParams, Link } from 'react-router-dom';

// 文章详情页
function PostDetail() {
  // useParams 可以获取 URL 中的动态参数
  const { id } = useParams();
  
  // 模拟根据 ID 获取文章数据
  const post = {
    id: id,
    title: `文章 #${id}`,
    content: `这是文章 #${id} 的内容。这是一篇非常精彩的文章...`
  };

  return (
    <div>
      <Link to="/posts">← 返回列表</Link>
      <h1>{post.title}</h1>
      <p>{post.content}</p>
    </div>
  );
}

// 文章列表页
function Posts() {
  // 模拟文章列表数据
  const posts = [
    { id: 1, title: '学习 React 的第一天' },
    { id: 2, title: 'Hooks 真好用' },
    { id: 3, title: 'React Router 入门' },
  ];

  return (
    <div>
      <h1>文章列表</h1>
      <ul>
        {posts.map(post => (
          <li key={post.id}>
            {/* 链接到文章详情页，:id 会被实际的文章 ID 替换 */}
            <Link to={`/posts/${post.id}`}>{post.title}</Link>
          </li>
        ))}
      </ul>
    </div>
  );
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="posts" element={<Posts />} />
          {/* :id 是动态参数，可以匹配任何值 */}
          <Route path="posts/:id" element={<PostDetail />} />
          <Route path="about" element={<About />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

**原理解析：**

- 在 Route 的 `path` 中，用 `:参数名` 定义动态部分。`posts/:id` 可以匹配 `posts/1`、`posts/hello`、`posts/anything`。
- 在组件中用 `useParams()` Hook 获取参数。返回一个对象，键名就是 `path` 中定义的参数名。

> [!TIP] 提示
> ：你可以有多个动态参数！比如 `/posts/:year/:month/:id` 也是完全合法的，`useParams` 会返回 `{ year, month, id }`。

## 10.7 编程式导航：useNavigate

有时候你想在代码中跳转页面，而不是让用户点击链接。比如：用户提交表单成功后自动跳转到列表页。

```jsx
import { useNavigate } from 'react-router-dom';
import { useState } from 'react';

function CreatePost() {
  const navigate = useNavigate(); // 获取导航函数
  const [title, setTitle] = useState('');
  const [content, setContent] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    
    // 模拟提交文章到服务器
    console.log('提交文章:', { title, content });
    
    // 提交成功后跳转到文章列表页
    navigate('/posts');
    
    // 其他导航方式：
    // navigate(-1)         — 返回上一页（等同于浏览器后退按钮）
    // navigate(1)          — 前进一页
    // navigate('/posts', { replace: true }) — 替换当前历史记录（不能后退回来）
  };

  return (
    <div>
      <h1>写新文章</h1>
      <form onSubmit={handleSubmit}>
        <div>
          <label>标题：</label>
          <input 
            value={title} 
            onChange={(e) => setTitle(e.target.value)}
            placeholder="请输入文章标题"
          />
        </div>
        <div>
          <label>内容：</label>
          <textarea 
            value={content} 
            onChange={(e) => setContent(e.target.value)}
            placeholder="请输入文章内容"
            rows={5}
          />
        </div>
        <button type="submit">发布文章</button>
      </form>
    </div>
  );
}
```

> **比喻**：`Link` 就像你自己走路去目的地，`useNavigate` 就像你打了个出租车——由代码决定什么时候出发、去哪里。

## 10.8 路由守卫：简单的登录检查

有些页面需要用户登录后才能访问（比如"个人中心"、"发布文章"）。React Router 本身没有内置路由守卫，但我们可以轻松实现一个：

```jsx
import { Navigate, useLocation } from 'react-router-dom';

// 模拟用户登录状态（实际项目中应该从 Context 或状态管理获取）
const fakeAuth = {
  isAuthenticated: false,
  login() { this.isAuthenticated = true; },
  logout() { this.isAuthenticated = false; },
};

// 路由守卫组件：检查是否登录，未登录则重定向到登录页
function RequireAuth({ children }) {
  const location = useLocation(); // 获取当前 URL 信息

  if (!fakeAuth.isAuthenticated) {
    // 未登录：重定向到登录页
    // state 中保存来源路径，登录后可以跳回来
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  // 已登录：正常渲染子组件
  return children;
}

// 登录页
function Login() {
  const navigate = useNavigate();
  const location = useLocation();
  
  // 获取来源路径（如果有的话）
  const from = location.state?.from?.pathname || '/';

  const handleLogin = () => {
    fakeAuth.login();
    navigate(from, { replace: true }); // 登录后跳回来源页
  };

  return (
    <div>
      <h1>登录</h1>
      <p>请先登录再访问该页面</p>
      <button onClick={handleLogin}>点击登录</button>
    </div>
  );
}

// 需要登录才能访问的页面
function Dashboard() {
  return (
    <div>
      <h1>个人中心（需要登录）</h1>
      <p>恭喜你，你已经登录了！这里是你的个人仪表盘。</p>
    </div>
  );
}

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="posts" element={<Posts />} />
          <Route path="posts/:id" element={<PostDetail />} />
          <Route path="login" element={<Login />} />
          {/* 用 RequireAuth 包裹需要登录的路由 */}
          <Route path="dashboard" element={
            <RequireAuth>
              <Dashboard />
            </RequireAuth>
          } />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

**原理解析：**

- `Navigate` 组件会立即重定向到指定路径，相当于"你到了门口但被保安拦住了，保安把你带到了另一个地方"。
- `useLocation` 可以获取当前 URL 信息，我们用它记住用户原本想去哪个页面。
- `state` 属性可以在路由跳转时传递额外数据（不会出现在 URL 中）。

## 10.9 404 页面

用户访问了一个不存在的路径怎么办？我们需要一个兜底的 404 页面：

```jsx
import { Link } from 'react-router-dom';

function NotFound() {
  return (
    <div style={{ textAlign: 'center', padding: '48px' }}>
      <h1 style={{ fontSize: '72px', margin: 0 }}>404</h1>
      <h2>哎呀，页面走丢了！🔍</h2>
      <p>你访问的页面不存在，可能链接有误或页面已被移除。</p>
      <Link to="/" style={{ 
        display: 'inline-block', 
        padding: '12px 24px', 
        background: '#007bff', 
        color: '#fff', 
        borderRadius: '4px',
        textDecoration: 'none'
      }}>
        回到首页
      </Link>
    </div>
  );
}

// 在 Routes 中添加 404 路由
function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="posts" element={<Posts />} />
          <Route path="posts/:id" element={<PostDetail />} />
          <Route path="about" element={<About />} />
          {/* path="*" 匹配任何路径，放在最后作为兜底 */}
          <Route path="*" element={<NotFound />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```

> [!TIP] 提示
> ：`path="*"` 是通配符，会匹配任何没有被其他 Route 捕获的路径。它必须放在 `Routes` 的最后面，因为 `Routes` 是按顺序匹配的。

## 10.10 实战：搭建多页面博客框架

让我们把本章学到的所有内容组合起来，搭建一个完整的多页面博客框架：

```jsx
// src/App.jsx
import { BrowserRouter, Routes, Route, Outlet, NavLink, Link, useParams, Navigate, useLocation, useNavigate } from 'react-router-dom';
import { useState } from 'react';

// ==================== 模拟数据 ====================
const blogPosts = [
  { id: 1, title: 'React 入门指南', date: '2024-01-15', summary: '从零开始学习 React，掌握核心概念。', category: '前端' },
  { id: 2, title: '深入理解 Hooks', date: '2024-02-20', summary: 'Hooks 是 React 最重要的特性之一。', category: 'React' },
  { id: 3, title: 'React Router 实战', date: '2024-03-10', summary: '学会用 React Router 构建多页面应用。', category: 'React' },
  { id: 4, title: 'CSS 模块化开发', date: '2024-04-05', summary: '在 React 中优雅地管理样式。', category: 'CSS' },
];

// ==================== 布局组件 ====================
function Layout() {
  const linkStyle = ({ isActive }) => ({
    color: isActive ? '#ffd700' : '#ccc',
    textDecoration: 'none',
    padding: '8px 16px',
    borderRadius: '4px',
    background: isActive ? 'rgba(255,215,0,0.1)' : 'transparent',
  });

  return (
    <div style={{ fontFamily: 'Arial, sans-serif' }}>
      <header style={{ background: '#1a1a2e', padding: '16px 24px' }}>
        <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
          <Link to="/" style={{ color: '#fff', textDecoration: 'none', fontSize: '24px', fontWeight: 'bold' }}>
            📚 我的技术博客
          </Link>
          <nav style={{ display: 'flex', gap: '8px' }}>
            <NavLink to="/" end style={linkStyle}>首页</NavLink>
            <NavLink to="/posts" style={linkStyle}>文章</NavLink>
            <NavLink to="/about" style={linkStyle}>关于</NavLink>
            <NavLink to="/dashboard" style={linkStyle}>个人中心</NavLink>
          </nav>
        </div>
      </header>

      <main style={{ maxWidth: '800px', margin: '0 auto', padding: '24px' }}>
        <Outlet />
      </main>

      <footer style={{ background: '#f8f9fa', padding: '24px', textAlign: 'center', marginTop: '48px' }}>
        <p style={{ color: '#666' }}>© 2024 我的技术博客 | 用 React 和 ❤️ 构建</p>
      </footer>
    </div>
  );
}

// ==================== 页面组件 ====================

// 首页
function HomePage() {
  return (
    <div>
      <section style={{ textAlign: 'center', padding: '48px 0' }}>
        <h1 style={{ fontSize: '36px' }}>欢迎来到我的技术博客 👋</h1>
        <p style={{ fontSize: '18px', color: '#666' }}>分享前端开发的心得与经验</p>
      </section>

      <section>
        <h2>最新文章</h2>
        {blogPosts.slice(0, 3).map(post => (
          <div key={post.id} style={{ 
            border: '1px solid #e0e0e0', 
            borderRadius: '8px', 
            padding: '16px', 
            marginBottom: '16px' 
          }}>
            <Link to={`/posts/${post.id}`} style={{ textDecoration: 'none', color: '#333' }}>
              <h3>{post.title}</h3>

function RequireAuth({ children }) {
```

## 本章小结

| 概念 | 作用 | 比喻 |
|------|------|------|
| BrowserRouter | 路由的总容器，监听 URL 变化 | 商场的中央控制系统 |
| Routes / Route | URL 到组件的映射规则 | 楼层指南牌 |
| Link / NavLink | 页面间导航（不刷新） | 商场内的扶梯 |
| Outlet | 嵌套路由的渲染出口 | 电视机的屏幕 |
| useParams | 获取 URL 中的动态参数 | 从门牌号找到房间 |
| useNavigate | 编程式页面跳转 | 打出租车去目的地 |
| Navigate | 立即重定向 | 保安拦住你并带你去别处 |
| path="*" | 通配符，兜底 404 | 商场的"其他"分类 |

**React Router 的核心思想**：在 SPA 中，通过 URL 映射到不同的组件，实现"多页面"的效果，而无需真正的页面刷新。
