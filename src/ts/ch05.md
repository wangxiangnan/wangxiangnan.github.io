# 第五章：函数类型

## 函数声明与箭头函数

```ts
function add(a: number, b: number): number {
  return a + b;
}

const multiply = (a: number, b: number): number => a * b;
```

TypeScript 会检查参数个数、参数类型和返回值类型。

## 可选参数和默认参数

```ts
function greet(name: string, greeting?: string): string {
  return `${greeting ?? "Hello"}, ${name}`;
}

function createUser(name: string, isAdmin: boolean = false) {
  return { name, isAdmin };
}
```

可选参数必须放在必需参数后面。默认参数会影响类型推断，TypeScript 会自动推断出 `isAdmin: boolean`。

## 函数类型表达式

函数本身也可以作为一种类型：

```ts
type MathOperation = (a: number, b: number) => number;

const add: MathOperation = (x, y) => x + y;
const subtract: MathOperation = (x, y) => x - y;
```

这种写法在回调函数、事件处理器、高阶函数中非常常见。

## 剩余参数和 this 类型

```ts
function sum(...numbers: number[]): number {
  return numbers.reduce((total, n) => total + n, 0);
}
```

对于需要明确 `this` 类型的函数（虽然现代 TS 中很少见）：

```ts
function clickHandler(this: HTMLButtonElement) {
  console.log(this.textContent);
}
```

## 函数重载

函数重载允许一个函数根据参数数量和类型，返回不同的结果类型。

```ts
function process(input: string): string;
function process(input: number): number;
function process(input: string | number): string | number {
  if (typeof input === "string") {
    return input.toUpperCase();
  }
  return input * 2;
}
```

注意：重载声明只提供类型信息，真正的实现签名必须兼容所有重载。

函数重载在需要为同一函数提供多种调用方式时很有用，但不要滥用，否则会增加代码复杂度。
