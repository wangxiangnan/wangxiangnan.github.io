# 第7章：基向量——空间的"积木"

> [!TIP] Part 3
> 走向线性代数

## 故事引入

小王的奶茶店生意越做越大，配送范围从一条街扩展到了整个城区。某天，新来的骑手小赵问小王："老板，这些配送地址我怎么记啊？太多了！"

小王想了想说："简单。你只需要知道两个数——从店出发，往东走多远，再往北走多远。比如'东3公里、北4公里'，就能定位任何一个配送点。"

小赵眼睛一亮："就靠这两个方向，就能说到哪儿就到哪儿？"

"没错。"小王喝了口奶茶，"这两个方向，就是所有地址的'基'——最基本的构建块。"

小赵还没完全听懂，但你已经快懂了。

## 标准基向量

在二维平面里，有两个最基础的向量：

- **î** = (1, 0)：沿 x 轴方向，走 1 个单位
- **ĵ** = (0, 1)：沿 y 轴方向，走 1 个单位

它们叫**标准基向量**。"基"这个字的意思就是"基础"——它们是整个坐标系的基石。

你可能会问：这俩有啥特别的？

特别之处在于：**平面上任何一个向量，都可以用它们"拼"出来。**

## 线性组合

比如向量 (3, 4)，拆开看：

(3, 4) = 3 × (1, 0) + 4 × (0, 1) = 3î + 4ĵ

这里的 3 和 4 叫**系数**。你把 î 拉长了 3 倍，ĵ 拉长了 4 倍，然后加在一起，就得到了 (3, 4)。

这种"拿几个向量，各自乘以系数，再加起来"的操作，有个正式名字叫**线性组合**：

c₁v₁ + c₂v₂ + ... + cₙvₙ

其中 c₁, c₂, ... 是系数（可以是任何实数），v₁, v₂, ... 是向量。

小王配送地址的"东3北4"，本质上就是 3î + 4ĵ——一个线性组合。

## 基向量不唯一

î 和 ĵ 是最常用的基，但不是唯一的选择。

假设小王换了一种描述方式：配送地址用"沿对角线方向走多远 + 沿另一条斜线方向走多远"来描述。只要这两个方向不平行（不共线），同样能覆盖整个平面。

比如选 v₁ = (1, 1) 和 v₂ = (1, -1) 作为基：

(3, 4) = c₁(1, 1) + c₂(1, -1)

解方程组：

- c₁ + c₂ = 3
- c₁ - c₂ = 4

得到 c₁ = 3.5，c₂ = -0.5。验证：3.5(1,1) + (-0.5)(1,-1) = (3.5-0.5, 3.5+0.5) = (3, 4)。完美。

所以，**基向量有无数种选法**，只要满足一个条件——它们不共线（不在同一条直线上）。

## 张成（Span）

一组基向量能"够到"的所有向量，叫它们的**张成空间**（Span）。

- 一个非零向量的张成：这条向量所在直线上的所有向量（一条线）
- 两个不共线向量的张成：整个二维平面
- 两个共线向量的张成：还是一条线（因为第二个向量帮不上忙）

小王如果只有"往东"这一个方向，那他的配送范围就只有一条线——东西走向的大街。加上"往北"之后，才能覆盖整个城区。这就是从"张成一条线"到"张成一个面"的飞跃。

## 线性相关 vs 线性独立

如果一组向量中，存在某个向量可以写成其他向量的线性组合，那它们就是**线性相关**的——里面有"冗余"。

比如 v₁ = (1, 0)、v₂ = (2, 0)。v₂ = 2v₁，v₂ 完全是 v₁ 的"翻版"，没有提供新方向。它们是线性相关的。

反过来，如果每个向量都提供了"不可替代"的新方向，就是**线性独立**的。

**基向量的要求：线性独立。** 一组基里面不能有"吃闲饭的"。

## 类比：调色盘

把基向量想象成调色盘里的基础色。

红、黄、蓝是三种基础色——它们互相独立（线性无关），混合在一起可以调出各种颜色（张成整个色彩空间）。

现在有人在调色盘里加了一个"深红"。但深红就是红色加深一点，跟红色共线，完全可以用红色调出来。这个"深红"就是线性相关的——它是多余的，没有扩展调色盘的能力。

基向量就是这个道理：每一个都要有自己不可替代的贡献。

## 小结

- **基向量**是构建空间的"积木"，标准基是 î = (1,0) 和 ĵ = (0,1)
- **线性组合**：c₁v₁ + c₂v₂ + ...，用基向量拼出任何向量
- **张成**：一组基向量能到达的所有向量的集合
- **基向量必须线性独立**：不能有冗余，每个都要"独一无二"
- 基的选法不唯一，只要线性独立就行

## 练习题

**题1：** 向量 (5, -2) 用标准基 î、ĵ 写成线性组合是什么？

**题2：** 判断以下两组向量是否线性独立：

- (a) v₁ = (2, 3)，v₂ = (4, 6)
- (b) v₁ = (1, 0)，v₂ = (0, 3)

**题3：** 向量 v₁ = (1, 2) 和 v₂ = (3, 1) 能否作为二维平面的一组基？为什么？如果能，把 (7, 8) 表示成它们的线性组合。

## 练习题答案

**题1：** (5, -2) = 5î - 2ĵ = 5(1, 0) + (-2)(0, 1)

**题2：**

- (a) v₂ = (4, 6) = 2 × (2, 3) = 2v₁。v₂ 是 v₁ 的倍数，**线性相关**。
- (b) v₁ = (1, 0)，v₂ = (0, 3)。它们分别沿 x 轴和 y 轴方向，不共线，**线性独立**。

**题3：** v₁ = (1, 2) 和 v₂ = (3, 1) 不共线（v₂ 不是 v₁ 的倍数），所以**可以作为一组基**。

设 (7, 8) = c₁(1, 2) + c₂(3, 1)：

- c₁ + 3c₂ = 7
- 2c₁ + c₂ = 8

由第二式得 c₂ = 8 - 2c₁，代入第一式：c₁ + 3(8 - 2c₁) = 7 → c₁ + 24 - 6c₁ = 7 → -5c₁ = -17 → c₁ = 17/5 = 3.4

c₂ = 8 - 2 × 3.4 = 8 - 6.8 = 1.2

验证：3.4(1, 2) + 1.2(3, 1) = (3.4 + 3.6, 6.8 + 1.2) = (7, 8)。正确。

所以 (7, 8) = 3.4v₁ + 1.2v₂。
