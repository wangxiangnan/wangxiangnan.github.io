# 第15章：主题、图标与界面定制

> "Any fool can write code that a computer can understand. Good programmers write code that humans can understand." — Martin Fowler

既然代码是给人看的，那看代码的"窗口"——也就是你的 VSCode 界面——当然也得让人看得舒服。一个精心定制的开发界面，不仅能减少视觉疲劳，还能让你更快地在代码海洋中定位信息。本章将把 VSCode 从一个"默认皮肤"的应用变成一件为你量身定制的艺术品。

## 主题系统：三层定制体系

VSCode 的主题系统分为三个独立的层次，就像 Web 开发中的 HTML、CSS 和图标字体：

| 层次 | 类型 | 作用 | 示例 |
| ------ | ------ | ------ | ------ |
| 第一层 | **颜色主题（Color Theme）** | 编辑器和 UI 的整体配色 | One Dark Pro, Dracula |
| 第二层 | **文件图标主题（File Icon Theme）** | 文件/文件夹的图标 | Material Icon Theme, vscode-icons |
| 第三层 | **产品图标主题（Product Icon Theme）** | VSCode 内置图标（侧边栏、面板等） | Codicons, Seti |

### 颜色主题推荐

```
# 深色系
- One Dark Pro        → Atom 经典配色，适合长时间编码
- GitHub Dark         → GitHub 官方深色主题
- Dracula Official    → 经典紫调暗色
- Tokyo Night         → 日系蓝紫色调，非常护眼
- Catppuccin          → 柔和、低对比度，适合敏感眼睛

# 浅色系
- GitHub Light        → 明亮清爽
- Bluloco Light       → 精致的浅色主题

# 高对比度
- High Contrast       → 内置高对比主题，适合演示和投影
```

安装方式：`Ctrl+K Ctrl+T`（`⌘+K ⌘+T`）打开主题快速切换面板。

### 文件图标主题

```
# 推荐
- Material Icon Theme  → 覆盖面最广，每种框架/语言都有专属图标
- vscode-icons         → 老牌图标主题
- Nomo Dark Icon Theme → 简约风格
```

## 颜色定制：workbench.colorCustomizations

### 查看可定制的颜色列表

在命令面板中搜索 `Developer: Generate Color Theme From Current Settings`，VSCode 会生成一份包含所有可定制颜色键的 JSON，供你参考和修改。

另一个方法：在 `settings.json` 中输入 `"workbench.colorCustomizations": {` 后，IntelliSense 会自动提示所有可用的颜色键。

## 编辑器 Token 颜色：代码着色

`workbench.colorCustomizations` 控制 UI 颜色，而 `editor.tokenColorCustomizations` 控制代码本身的颜色——关键字、字符串、注释、函数名等。

### 基本语法

```json
{
  "editor.tokenColorCustomizations": {
    "comments": "#565f89",
    "keywords": "#bb9af7",
    "strings": "#9ece6a",
    "numbers": "#ff9e64",
    "types": "#2ac3de",
    "functions": "#7aa2f7",
    "variables": "#c0caf5",
    
    "textMateRules": [
      {
        "scope": [
          "entity.name.function",
          "support.function"
        ],
        "settings": {
          "foreground": "#7aa2f7",
          "fontStyle": "bold"
        }
      },
      {
        "scope": [
          "variable.other.property",
          "variable.other.object.property"
        ],
        "settings": {
          "foreground": "#73daca"
        }
      },
      {
        "scope": [
          "keyword.control",
          "storage.type"
        ],
        "settings": {
          "foreground": "#bb9af7",
          "fontStyle": "italic"
        }
      },
      {
        "scope": "comment",
        "settings": {
          "foreground": "#565f89",
          "fontStyle": "italic"
        }
      },
      {
        "scope": "constant.language",
        "settings": {
          "foreground": "#ff9e64",
          "fontStyle": "bold"
        }
      }
    ]
  }
}
```

### 使用开发者工具查看 Token Scope

这是定制 Token 颜色的关键技巧：

1. 按 `Ctrl+Shift+P`（`⌘+Shift+P`）
2. 搜索 `Developer: Inspect Editor Tokens and Scopes`
3. 点击代码中的任意元素，底部面板会显示该元素的完整 scope 路径

例如，点击一个 React 组件名，你可能会看到：

```
entity.name.tag.component.tsx
meta.tag.component.tsx
```

用这些信息来精确配置 `textMateRules` 中的 `scope`。

### Semantic Highlighting

VSCode 还支持基于语义的语法高亮（不仅仅是文本匹配）。在 `settings.json` 中：

```json
{
  "editor.semanticTokenColorCustomizations": {
    "enabled": true,
    "rules": {
      "property.readonly": {
        "foreground": "#73daca",
        "fontStyle": "bold"
      },
      "variable.readonly": {
        "foreground": "#c0caf5"
      },
      "interface": {
        "foreground": "#2ac3de",
        "fontStyle": "italic"
      },
      "typeParameter": {
        "foreground": "#e0af68"
      },
      "*.decorator": {
        "foreground": "#bb9af7",
        "fontStyle": "bold"
      }
    }
  }
}
```

## 实用界面调整

### 侧边栏位置

如果你习惯文件树在右边（特别是宽屏显示器）：

```json
{
  "workbench.sideBar.location": "right"
}
```

或者用快捷键 `Ctrl+B`（`⌘+B`）切换侧边栏显示/隐藏，`Ctrl+Alt+B` 切换左右位置（需要自定义快捷键）。

### 面板位置

默认情况下，面板（终端、输出等）在底部。你可以把它移到侧边：

```json
{
  "workbench.panel.defaultLocation": "right",
  "workbench.panel.preferredPosition": "right"
}
```

### 活动栏精简

如果你不需要活动栏（最左侧的图标栏）：

```json
{
  "workbench.activityBar.location": "hidden"
}
```

或者把它变成顶部标签：

```json
{
  "workbench.activityBar.location": "top"
}
```

### 紧凑的界面模式

```json
{
  "window.density.editorTabHeight": "compact",
  "workbench.tree.indent": 12,
  "workbench.tree.renderIndentGuides": "onHover"
}
```

## 字体配置：细节决定体验

### 等宽编程字体推荐

```
JetBrains Mono     → JetBrains 出品，连字支持优秀，免费
Fira Code          → 最流行的编程连字字体，免费
Cascadia Code      → 微软出品，Windows Terminal 默认字体
Hack               → 经典编程字体，清晰易读
Iosevka            → 高度可定制，窄版设计，适合小屏幕
Maple Mono         → 圆润可爱的中文编程字体
```

### 字体配置

```json
{
  "editor.fontFamily": "'JetBrains Mono', 'Fira Code', 'Cascadia Code', Consolas, 'Courier New', monospace",
  "editor.fontSize": 14,
  "editor.fontWeight": "400",
  "editor.lineHeight": 22,
  "editor.letterSpacing": 0.5,
  "editor.fontLigatures": true
}
```

### 字体连字（Ligatures）

连字是指将 `=>`、`!=`、`>=` 等符号组合显示为特殊字形。例如 `=>` 显示为一个带箭头的连体字符，`!=` 显示为一个"不等号"。

```json
{
  "editor.fontLigatures": true
}
```

或者更精细地控制哪些连字启用：

```json
{
  "editor.fontLigatures": "'calt', 'ss01', 'ss02', 'ss03', 'ss05'"
}
```

> **注意：** 连字功能需要字体本身支持。JetBrains Mono、Fira Code、Cascadia Code 都支持连字。

### 字体大小分层

不同的代码区域使用不同大小，形成视觉层次：

```json
{
  "editor.fontSize": 14,
  "editor.minimap.scale": 1,
  "terminal.integrated.fontSize": 13,
  "debug.console.fontSize": 13,
  "markdown.preview.fontSize": 14,
  "scm.diffEditor.fontSize": 13
}
```

### 终端字体单独配置

```json
{
  "terminal.integrated.fontFamily": "'JetBrains Mono NF', 'Cascadia Code', Consolas",
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.lineHeight": 1.2,
  "terminal.integrated.letterSpacing": 0
}
```

> **提示：** 如果你使用 Powerlevel10k 或 Starship 等终端主题，需要安装对应的 Nerd Font 变体（如 `JetBrains Mono NF`），否则图标会显示为方块。

## 进阶：开发一个简单的颜色主题扩展

如果你想把自己的定制主题分享给其他人，或者上传到 VSCode 市场，就需要把它打包成一个扩展。

### 步骤 1：安装工具

```bash
npm install -g @vscode/vsce yo generator-code
```

### 步骤 2：创建主题项目

```bash
yo code
# 选择 "New Color Theme"
# 选择基础主题（如 Dark+）
# 填写主题名称和描述
```

### 步骤 3：编辑主题文件

生成的项目结构如下：

```
my-midnight-theme/
├── themes/
│   └── Midnight-Ocean-color-theme.json    # 主题颜色定义
├── package.json                           # 扩展元数据
├── CHANGELOG.md
└── vsc-extension-quickstart.md
```

**`themes/Midnight-Ocean-color-theme.json`：**

```json
{
  "name": "Midnight Ocean",
  "type": "dark",
  "semanticHighlighting": true,
  "semanticTokenColors": {
    "property.readonly": "#79c0ff",
    "interface": {
      "foreground": "#ffa657",
      "italic": true
    }
  },
  "colors": {
    "editor.background": "#0d1117",
    "editor.foreground": "#c9d1d9",
    "editor.lineHighlightBackground": "#161b2280",
    "editorCursor.foreground": "#58a6ff",
    "editor.selectionBackground": "#1f6feb40"
  },
  "tokenColors": [
    {
      "scope": ["keyword", "storage.type"],
      "settings": {
        "foreground": "#ff7b72",
        "fontStyle": "italic"
      }
    },
    {
      "scope": ["entity.name.function"],
      "settings": {
        "foreground": "#d2a8ff",
        "fontStyle": "bold"
      }
    }
  ]
}
```

### 步骤 4：本地测试

```bash
# 在主题项目目录下，按 F5 启动扩展开发主机
# 在新打开的 VSCode 窗口中测试你的主题
```

### 步骤 5：打包和发布

```bash
# 打包为 .vsix 文件
vsce package

# 安装到本地
code --install-extension my-midnight-theme-0.0.1.vsix

# 发布到 VSCode 市场（需要先创建 Azure DevOps 组织）
vsce publish
```

> **提示：** 发布到市场需要一个 Microsoft 账户和一个 Azure DevOps Personal Access Token。详细流程参考 [官方文档](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)。

---

📋 **本章小结**

- VSCode 主题分三层：颜色主题、文件图标主题、产品图标主题，可以独立搭配
- `workbench.colorCustomizations` 可以微调 UI 的每一个细节颜色
- `editor.tokenColorCustomizations` 控制代码的语法高亮颜色
- 支持 `[ThemeName]` 语法限定配置只在特定主题下生效
- 字体配置包括：等宽字体选择、连字（Ligatures）、不同区域的字号分层
- 使用 `yo code` + `vsce` 可以将定制主题打包发布为扩展
