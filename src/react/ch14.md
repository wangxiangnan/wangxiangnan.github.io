![第14章封面](./images/ch14.png)

## 引言：你的应用需要一个"服务员"

到目前为止，我们的 React 应用就像一个没有食材的餐厅——装修很漂亮（样式做好了），菜单很丰富（路由配好了），服务流程很顺畅（状态管理搞定了），但厨房里什么都没有，客人点什么都是空盘子。

数据从哪里来？在真实的应用中，数据通常存储在后端服务器上（数据库里），前端需要通过网络请求来获取这些数据。这个过程就叫做 **API 调用**。

> **比喻时间**：API 请求就像去餐厅点菜。你（前端）告诉服务员（fetch/axios）你要什么菜（URL + 参数），服务员去厨房（服务器）拿菜。有时候菜要等很久（loading 状态），有时候菜没了（error 状态），有时候上菜很快（成功获取数据）。你作为一个好服务员，需要在等菜的时候告诉客人"请稍等"（loading 提示），出问题了要礼貌地告知"抱歉，这道菜暂时没有了"（error 处理）。

## 14.1 fetch API 基础

浏览器原生提供了一个叫 `fetch` 的函数来发送网络请求。它不需要安装任何东西：

```jsx
// 最基本的 GET 请求
async function fetchExample() {
  // 1. 发送请求
  const response = await fetch('https://jsonplaceholder.typicode.com/users');
  
  // 2. 检查响应状态
  if (!response.ok) {
    throw new Error(`请求失败：${response.status}`);
  }
  
  // 3. 解析 JSON 数据
  const data = await response.json();
  
  console.log(data); // 用户列表数组
}

// fetch 返回的是一个 Promise
// 所以需要用 async/await 或 .then() 来处理
```

**fetch 的核心概念：**

- **URL**：你要请求的地址，就像餐厅的菜单编号
- **Response**：服务器的回应，包含状态码和数据
- **JSON**：最常用的数据格式，`response.json()` 把原始数据转换成 JavaScript 对象

## 14.2 在 useEffect 中获取数据

React 组件中获取数据的标准姿势是在 `useEffect` 中调用 fetch：

```jsx
import { useState, useEffect } from 'react';

function UserList() {
  // 三件套：数据、加载状态、错误状态
  const [users, setUsers] = useState([]);     // 数据
  const [loading, setLoading] = useState(true); // 加载中
  const [error, setError] = useState(null);      // 错误信息

  useEffect(() => {
    // 定义异步函数（useEffect 的回调不能直接是 async）
    const fetchUsers = async () => {
      try {
        setLoading(true);
        setError(null);
        
        const response = await fetch('https://jsonplaceholder.typicode.com/users');
        
        if (!response.ok) {
          throw new Error(`HTTP 错误: ${response.status}`);
        }
        
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false); // 不管成功失败，都要关闭 loading
      }
    };

    fetchUsers();
  }, []); // 空依赖数组：只在组件挂载时请求一次

  // 渲染三种状态
  if (loading) {
    return (
      <div style={{ padding: '24px', textAlign: 'center' }}>
        <div style={{ fontSize: '24px' }}>⏳</div>
        <p>正在加载用户列表...</p>
      </div>
    );
  }

  if (error) {
    return (
      <div style={{ padding: '24px', textAlign: 'center' }}>
        <div style={{ fontSize: '24px' }}>❌</div>
        <p style={{ color: 'red' }}>出错了：{error}</p>
      </div>
    );
  }

  return (
    <div style={{ padding: '24px' }}>
      <h1>用户列表 ({users.length} 人)</h1>
      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(250px, 1fr))', gap: '16px' }}>
        {users.map(user => (
          <div key={user.id} style={{
            border: '1px solid #e0e0e0',
            borderRadius: '12px',
            padding: '16px',
            background: '#fff',
          }}>
            <h3>{user.name}</h3>
            <p style={{ color: '#666' }}>📧 {user.email}</p>
            <p style={{ color: '#666' }}>📱 {user.phone}</p>
            <p style={{ color: '#666' }}>🏢 {user.company.name}</p>
          </div>
        ))}
      </div>
    </div>
  );
}

export default UserList;
```

> [!WARNING] 注意
> `useEffect` 的回调函数不能直接声明为 `async`！这是因为 `useEffect` 期望回调返回一个清理函数（或 undefined），而 `async` 函数返回的是 Promise。正确做法是在 `useEffect` 内部定义一个 async 函数然后调用它。

## 14.3 创建自定义 useFetch Hook

上一章我们已经做过一个 `useFetch`，这次做一个更完善的版本：

```jsx
// src/hooks/useFetch.js
import { useState, useEffect, useCallback } from 'react';

/**
 * useFetch — 通用数据请求 Hook
 * @param {string} url - 请求 URL
 * @param {object} options - fetch 选项
 * @returns {{ data, loading, error, refetch }}
 */
function useFetch(url, options = {}) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  const fetchData = useCallback(async () => {
    // URL 为空时不请求
    if (!url) {
      setLoading(false);
      return;
    }

    try {
      setLoading(true);
      setError(null);

      const response = await fetch(url, {
        headers: {
          'Content-Type': 'application/json',
          ...options.headers,
        },
        ...options,
      });

      if (!response.ok) {
        throw new Error(`请求失败 (${response.status}): ${response.statusText}`);
      }

      const result = await response.json();
      setData(result);
    } catch (err) {
      // 区分网络错误和其他错误
      if (err.name === 'AbortError') {
        setError('请求已取消');
      } else {
        setError(err.message || '未知错误');
      }
    } finally {
      setLoading(false);
    }
  }, [url, JSON.stringify(options)]);

  useEffect(() => {
    fetchData();
  }, [fetchData]);

  return { data, loading, error, refetch: fetchData };
}

export default useFetch;
```

使用它：

```jsx
import useFetch from './hooks/useFetch';

function PostList() {
  const { data: posts, loading, error, refetch } = useFetch(
    'https://jsonplaceholder.typicode.com/posts?_limit=10'
  );

  if (loading) return <p>⏳ 加载中...</p>;
  if (error) return <p>❌ {error} <button onClick={refetch}>重试</button></p>;

  return (
    <div>
      <h1>文章列表</h1>
      <button onClick={refetch}>🔄 刷新</button>
      {posts.map(post => (
        <div key={post.id}>
          <h3>{post.title}</h3>
          <p>{post.body}</p>
        </div>
      ))}
    </div>
  );
}
```

## 14.4 Axios 简介

虽然 `fetch` 是浏览器原生的，但很多开发者更喜欢用 **Axios** 这个第三方库。它提供了一些 `fetch` 没有的便利功能：

```bash
npm install axios
```

```jsx
import axios from 'axios';

// 创建一个配置好的 axios 实例（推荐做法）
const api = axios.create({
  baseURL: 'https://jsonplaceholder.typicode.com', // 基础 URL
  timeout: 10000, // 超时时间：10 秒
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器 —— 每次请求前自动添加 token
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('auth-token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器 —— 统一处理错误
api.interceptors.response.use(
  (response) => response.data, // 直接返回 data 部分
  (error) => {
    if (error.response?.status === 401) {
      // token 过期，跳转到登录页
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

export default api;
```

**Axios vs fetch 的区别：**

| 特性 | fetch | Axios |
|------|-------|-------|
| 安装 | 浏览器内置 | 需要 npm install |
| 自动 JSON 转换 | 需要 `response.json()` | 自动转换 |
| 拦截器 | 不支持 | 支持请求/响应拦截 |
| 超时控制 | 需要手动用 AbortController | 内置 timeout 选项 |
| 错误处理 | 只有网络错误才 reject | HTTP 4xx/5xx 也会 reject |
| 上传进度 | 不支持 | 支持 |

> [!TIP] 提示
> ：对于简单项目，`fetch` 完全够用。当你的项目需要统一的请求拦截（如自动附加 token）、响应拦截（如统一错误处理）时，Axios 是更好的选择。

## 14.5 POST / PUT / DELETE 请求

除了获取数据（GET），你还需要发送数据（POST）、更新数据（PUT/PATCH）和删除数据（DELETE）：

```jsx
import { useState } from 'react';

function CRUDExample() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(false);
  const [message, setMessage] = useState('');

  // ===== GET: 获取所有文章 =====
  const fetchPosts = async () => {
    setLoading(true);
    try {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts?_limit=5');
      const data = await response.json();
      setPosts(data);
      setMessage('✅ 文章列表加载成功');
    } catch (err) {
      setMessage('❌ 获取失败: ' + err.message);
    } finally {
      setLoading(false);
    }
  };

  // ===== POST: 创建新文章 =====
  const createPost = async () => {
    setLoading(true);
    try {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
        method: 'POST', // 请求方法
        headers: {
          'Content-Type': 'application/json', // 告诉服务器发送的是 JSON
        },
        body: JSON.stringify({
          title: '我的新文章',
          body: '这是文章内容，非常精彩！',
          userId: 1,
        }),
      });
      const data = await response.json();
      // 将新文章添加到列表开头
      setPosts([data, ...posts]);
      setMessage('✅ 文章创建成功！ID: ' + data.id);
    } catch (err) {
      setMessage('❌ 创建失败: ' + err.message);
    } finally {
      setLoading(false);
    }
  };

  // ===== PUT: 更新文章 =====
  const updatePost = async (id) => {
    setLoading(true);
    try {
      const response = await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`, {
        method: 'PUT', // PUT 表示完整替换
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          id: id,
          title: '更新后的标题 ✨',
          body: '这是更新后的文章内容。',
          userId: 1,
        }),
      });
      const data = await response.json();
      // 更新列表中对应的文章
      setPosts(posts.map(post => post.id === id ? data : post));
      setMessage(`✅ 文章 #${id} 更新成功！`);
    } catch (err) {
      setMessage('❌ 更新失败: ' + err.message);
    } finally {
      setLoading(false);
    }
  };

  // ===== DELETE: 删除文章 =====
  const deletePost = async (id) => {
    setLoading(true);
    try {
      await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`, {
        method: 'DELETE',
      });
      // 从列表中移除
      setPosts(posts.filter(post => post.id !== id));
      setMessage(`✅ 文章 #${id} 已删除`);
    } catch (err) {
      setMessage('❌ 删除失败: ' + err.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div style={{ padding: '24px', maxWidth: '800px', margin: '0 auto' }}>
      <h1>CRUD 操作示例</h1>

      {/* 操作按钮 */}
      <div style={{ display: 'flex', gap: '8px', marginBottom: '16px', flexWrap: 'wrap' }}>
        <button onClick={fetchPosts} disabled={loading} style={{ padding: '8px 16px' }}>
          📋 获取列表
        </button>
        <button onClick={createPost} disabled={loading} style={{ padding: '8px 16px', background: '#28a745', color: '#fff' }}>
          ➕ 创建文章
        </button>
      </div>

      {/* 状态消息 */}
      {message && (
        <div style={{ 
          padding: '12px', 
          borderRadius: '4px', 
          marginBottom: '16px',
          background: message.startsWith('✅') ? '#d4edda' : '#f8d7da',
          color: message.startsWith('✅') ? '#155724' : '#721c24',
        }}>
          {message}
        </div>
      )}

      {/* 加载中 */}
      {loading && <p>⏳ 处理中...</p>}

      {/* 文章列表 */}
      <div style={{ display: 'flex', flexDirection: 'column', gap: '12px' }}>
        {posts.map(post => (
          <div key={post.id} style={{
            border: '1px solid #e0e0e0',
            borderRadius: '8px',
            padding: '16px',
            display: 'flex',
            justifyContent: 'space-between',
            alignItems: 'flex-start',
          }}>
            <div style={{ flex: 1 }}>
              <h3 style={{ margin: '0 0 4px 0' }}>#{post.id} {post.title}</h3>
              <p style={{ margin: 0, color: '#666', fontSize: '14px' }}>
                {post.body?.substring(0, 80)}...
              </p>
            </div>
            <div style={{ display: 'flex', gap: '8px', flexShrink: 0 }}>
              <button 
                onClick={() => updatePost(post.id)}
                disabled={loading}
                style={{ padding: '4px 12px', background: '#ffc107', border: 'none', borderRadius: '4px', cursor: 'pointer' }}
              >
                ✏️ 编辑
              </button>
              <button 
                onClick={() => deletePost(post.id)}
                disabled={loading}
                style={{ padding: '4px 12px', background: '#dc3545', color: '#fff', border: 'none', borderRadius: '4px', cursor: 'pointer' }}
              >
                🗑️ 删除
              </button>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
}

export default CRUDExample;
```

> [!TIP] 提示
> ：HTTP 方法的记忆口诀 —— **GET** 获取（看菜单）、**POST** 创建（点新菜）、**PUT** 替换（换一道菜）、**PATCH** 部分更新（让厨师少放盐）、**DELETE** 删除（退菜）。

## 14.6 错误处理与用户友好提示

错误处理是前端开发中最容易被忽视但又最重要的部分之一：

```jsx
import { useState } from 'react';

// 一个友好的 Toast 提示组件
function Toast({ message, type = 'info', onClose }) {
  const colors = {
    success: { bg: '#d4edda', text: '#155724', border: '#c3e6cb' },
    error: { bg: '#f8d7da', text: '#721c24', border: '#f5c6cb' },
    warning: { bg: '#fff3cd', text: '#856404', border: '#ffeeba' },
    info: { bg: '#d1ecf1', text: '#0c5460', border: '#bee5eb' },
  };
  const color = colors[type];

  return (
    <div style={{
      position: 'fixed',
      top: '20px',
      right: '20px',
      padding: '12px 24px',
      background: color.bg,
      color: color.text,
      border: `1px solid ${color.border}`,
      borderRadius: '8px',
      boxShadow: '0 4px 12px rgba(0,0,0,0.15)',
      zIndex: 1000,
      display: 'flex',
      alignItems: 'center',
      gap: '12px',
    }}>
      <span>{message}</span>
      <button 
        onClick={onClose}
        style={{ background: 'none', border: 'none', color: color.text, cursor: 'pointer', fontSize: '18px' }}
      >
        ×
      </button>
    </div>
  );
}

// 带完善错误处理的表单
function ContactForm() {
  const [formData, setFormData] = useState({ name: '', email: '', message: '' });
  const [submitting, setSubmitting] = useState(false);
  const [toast, setToast] = useState(null);

  // 显示 Toast 并自动关闭
  const showToast = (message, type) => {
    setToast({ message, type });
    setTimeout(() => setToast(null), 3000); // 3秒后自动关闭
  };

  const handleSubmit = async (e) => {
    e.preventDefault();

    // 前端验证
    if (!formData.name.trim()) {
      showToast('请输入姓名', 'warning');
      return;
    }
    if (!formData.email.includes('@')) {
      showToast('请输入有效的邮箱地址', 'warning');
      return;
    }

    setSubmitting(true);
    try {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formData),
      });

      if (!response.ok) {
        throw new Error(`服务器错误 (${response.status})`);
      }

      showToast('🎉 提交成功！我们会尽快回复您。', 'success');
      setFormData({ name: '', email: '', message: '' }); // 清空表单
    } catch (err) {
      // 根据错误类型给出不同的提示
      if (err.message.includes('Failed to fetch')) {
        showToast('网络连接失败，请检查您的网络设置', 'error');
      } else {
        showToast(`提交失败：${err.message}`, 'error');
      }
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <div style={{ maxWidth: '500px', margin: '48px auto', padding: '24px' }}>
      {toast && <Toast {...toast} onClose={() => setToast(null)} />}
      
      <h1>联系我们</h1>
      <form onSubmit={handleSubmit}>
        <div style={{ marginBottom: '16px' }}>
          <label style={{ display: 'block', marginBottom: '4px' }}>姓名</label>
          <input
            type="text"
            value={formData.name}
            onChange={(e) => setFormData({ ...formData, name: e.target.value })}
            style={{ width: '100%', padding: '10px', borderRadius: '4px', border: '1px solid #ddd' }}
            placeholder="请输入姓名"
          />
        </div>
        <div style={{ marginBottom: '16px' }}>
          <label style={{ display: 'block', marginBottom: '4px' }}>邮箱</label>
          <input
            type="email"
            value={formData.email}
            onChange={(e) => setFormData({ ...formData, email: e.target.value })}
            style={{ width: '100%', padding: '10px', borderRadius: '4px', border: '1px solid #ddd' }}
            placeholder="请输入邮箱"
          />
        </div>
        <div style={{ marginBottom: '16px' }}>
          <label style={{ display: 'block', marginBottom: '4px' }}>留言</label>
          <textarea
            value={formData.message}
            onChange={(e) => setFormData({ ...formData, message: e.target.value })}
            style={{ width: '100%', padding: '10px', borderRadius: '4px', border: '1px solid #ddd' }}
            rows={4}
            placeholder="请输入留言内容"
          />
        </div>
        <button
          type="submit"
          disabled={submitting}
          style={{
            width: '100%',
            padding: '12px',
            background: submitting ? '#ccc' : '#007bff',
            color: '#fff',
            border: 'none',
            borderRadius: '4px',
            cursor: submitting ? 'not-allowed' : 'pointer',
            fontSize: '16px',
          }}
        >
          {submitting ? '⏳ 提交中...' : '发送'}
        </button>
      </form>
    </div>
  );
}

export default ContactForm;
```

## 14.7 React Query (TanStack Query) — 数据获取的"终极武器"

如果你觉得手动管理 loading、error、cache、refetch 太麻烦了，那 **React Query**（现在叫 TanStack Query）就是你的救星。它是一个专门为数据获取设计的状态管理库：

```bash
npm install @tanstack/react-query
```

```jsx
// src/main.jsx — 配置 React Query
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

// 创建 QueryClient 实例
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000, // 数据 5 分钟内视为新鲜
      retry: 2,                  // 失败后自动重试 2 次
      refetchOnWindowFocus: true, // 窗口重新获得焦点时自动刷新
    },
  },
});

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    {/* 用 QueryClientProvider 包裹应用 */}
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  </React.StrictMode>
);
```

```jsx
// 使用 React Query 获取数据
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

function PostManager() {
  const queryClient = useQueryClient();

  // ===== 使用 useQuery 获取数据 =====
  // 只需提供 key 和 fetch 函数，其余的全自动！
  const { 
    data: posts, 
    isLoading, 
    isError, 
    error,
    isFetching, // 后台刷新时为 true（数据仍可用）
    refetch,
  } = useQuery({
    queryKey: ['posts'], // 查询的唯一标识
    queryFn: async () => {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts?_limit=5');
      if (!response.ok) throw new Error('获取失败');
      return response.json();
    },
  });

  // ===== 使用 useMutation 修改数据 =====
  const createMutation = useMutation({
    mutationFn: async (newPost) => {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(newPost),
      });
      return response.json();
    },
    // 成功后自动刷新 posts 列表
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
  });

  const deleteMutation = useMutation({
    mutationFn: async (id) => {
      await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`, { method: 'DELETE' });
      return id;
    },
    // 乐观更新：先从列表中移除，如果服务器报错再恢复
    onMutate: async (id) => {
      await queryClient.cancelQueries({ queryKey: ['posts'] });
      const previous = queryClient.getQueryData(['posts']);
      queryClient.setQueryData(['posts'], old => old.filter(p => p.id !== id));
      return { previous };
    },
    onError: (err, id, context) => {
      // 出错时恢复之前的数据
      queryClient.setQueryData(['posts'], context.previous);
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
  });

  return (
    <div style={{ padding: '24px', maxWidth: '800px', margin: '0 auto' }}>
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: '16px' }}>
        <h1>React Query 示例</h1>
        <div style={{ display: 'flex', gap: '8px' }}>
          <button 
            onClick={() => createMutation.mutate({ title: '新文章', body: '内容...', userId: 1 })}
            disabled={createMutation.isPending}
            style={{ padding: '8px 16px', background: '#28a745', color: '#fff', border: 'none', borderRadius: '4px' }}
          >
            {createMutation.isPending ? '创建中...' : '➕ 创建'}
          </button>
          <button onClick={() => refetch()} disabled={isFetching}>
            {isFetching ? '刷新中...' : '🔄 刷新'}
          </button>
        </div>
      </div>

      {/* 后台刷新提示 */}
      {isFetching && !isLoading && (
        <div style={{ padding: '8px', background: '#fff3cd', borderRadius: '4px', marginBottom: '12px' }}>
          ⏳ 正在后台刷新...
        </div>
      )}

      {isLoading && <p>⏳ 首次加载中...</p>}
      {isError && <p style={{ color: 'red' }}>❌ {error.message}</p>}

      {posts?.map(post => (
        <div key={post.id} style={{
          border: '1px solid #e0e0e0',
          borderRadius: '8px',
          padding: '16px',
          marginBottom: '12px',
          display: 'flex',
          justifyContent: 'space-between',
        }}>
          <div>
            <h3>{post.title}</h3>
            <p style={{ color: '#666' }}>{post.body?.substring(0, 60)}...</p>
          </div>
          <button
            onClick={() => deleteMutation.mutate(post.id)}
            disabled={deleteMutation.isPending}
            style={{ padding: '4px 12px', background: '#dc3545', color: '#fff', border: 'none', borderRadius: '4px', alignSelf: 'center' }}
          >
            🗑️
          </button>
        </div>
      ))}
    </div>
  );
}

export default PostManager;
```

**React Query 的核心优势：**

1. **自动缓存**：相同 queryKey 的数据不会重复请求
2. **自动重试**：网络波动时自动重试失败的请求
3. **后台刷新**：用户切换到窗口时自动刷新数据
4. **乐观更新**：先更新 UI 再等服务器确认，出错时回滚
5. **分页/无限滚动**：内置支持
6. **devtools**：内置开发者工具，方便调试

> **恭喜！** React Query 是目前 React 生态中数据获取的最佳实践。很多大公司（如 Google、Netflix、Shopify）都在使用它。掌握 React Query 后，你的数据获取代码会变得更加简洁和健壮。

import { useState, useEffect, useCallback } from 'react';

// ==================== 自定义 Hooks ====================

// useFetch — 通用数据请求
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const fetchData = useCallback(async () => {
    if (!url) return;
    setLoading(true);
    setError(null);
    try {
      const response = await fetch(url);
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      const result = await response.json();
      setData(result);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }, [url]);

  useEffect(() => { fetchData(); }, [fetchData]);

  return { data, loading, error, refetch: fetchData, setData };
}

// ==================== Toast 组件 ====================

function Toast({ toasts, removeToast }) {
  return (
    <div style={{ position: 'fixed', top: '20px', right: '20px', zIndex: 1000 }}>
      {toasts.map(toast => (
        <div key={toast.id} style={{
          padding: '12px 20px',
          marginBottom: '8px',
          borderRadius: '8px',
          background: toast.type === 'success' ? '#d4edda' : toast.type === 'error' ? '#f8d7da' : '#fff3cd',
          color: toast.type === 'success' ? '#155724' : toast.type === 'error' ? '#721c24' : '#856404',
          boxShadow: '0 2px 8px rgba(0,0,0,0.15)',
          display: 'flex',
          justifyContent: 'space-between',
          alignItems: 'center',
          gap: '12px',
          minWidth: '250px',
        }}>
          <span>{toast.message}</span>
          <button onClick={() => removeToast(toast.id)} style={{ background: 'none', border: 'none', cursor: 'pointer', fontSize: '16px' }}>×</button>
        </div>
      ))}
    </div>
  );
}

// ==================== 主应用 ====================

function ArticleManager() {
  const [page, setPage] = useState(1);
  const [editingPost, setEditingPost] = useState(null);
  const [showForm, setShowForm] = useState(false);
  const [formData, setFormData] = useState({ title: '', body: '' });
  const [toasts, setToasts] = useState([]);
  const [actionLoading, setActionLoading] = useState(false);

  const POSTS_PER_PAGE = 6;

  // 获取文章列表
  const { data: posts, loading, error, refetch, setData: setPosts } = useFetch(
    `https://jsonplaceholder.typicode.com/posts?_limit=${POSTS_PER_PAGE}&_page=${page}`
  );

  // Toast 管理
  const addToast = (message, type = 'info') => {
    const id = Date.now();
    setToasts(prev => [...prev, { id, message, type }]);
    setTimeout(() => setToasts(prev => prev.filter(t => t.id !== id)), 3000);
  };

  const removeToast = (id) => {
    setToasts(prev => prev.filter(t => t.id !== id));
  };

  // 创建文章
  const handleCreate = async (e) => {
    e.preventDefault();
    if (!formData.title.trim() || !formData.body.trim()) {
      addToast('标题和内容不能为空', 'warning');
      return;
    }

    setActionLoading(true);
    try {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ ...formData, userId: 1 }),
      });
      const newPost = await response.json();
      if (posts) setPosts([newPost, ...posts]);
      setFormData({ title: '', body: '' });
      setShowForm(false);
      addToast('✅ 文章创建成功！', 'success');
    } catch (err) {
      addToast('❌ 创建失败: ' + err.message, 'error');
    } finally {
      setActionLoading(false);
    }
  };

  // 更新文章
  const handleUpdate = async (e) => {
    e.preventDefault();
    setActionLoading(true);
    try {
      const response = await fetch(`https://jsonplaceholder.typicode.com/posts/${editingPost.id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ ...editingPost, userId: 1 }),
      });
      const updated = await response.json();
      if (posts) setPosts(posts.map(p => p.id === updated.id ? updated : p));
      setEditingPost(null);
      addToast('✅ 文章更新成功！', 'success');
    } catch (err) {
      addToast('❌ 更新失败: ' + err.message, 'error');
    } finally {
      setActionLoading(false);
    }
  };

  // 删除文章
  const handleDelete = async (id) => {
    if (!window.confirm('确定要删除这篇文章吗？')) return;
    setActionLoading(true);
    try {
      await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`, { method: 'DELETE' });
      if (posts) setPosts(posts.filter(p => p.id !== id));
      addToast('✅ 文章已删除', 'success');
    } catch (err) {
      addToast('❌ 删除失败: ' + err.message, 'error');
    } finally {
      setActionLoading(false);
    }
  };

  return (
    <div style={{ fontFamily: 'Arial, sans-serif', background: '#f5f7fa', minHeight: '100vh' }}>
      <Toast toasts={toasts} removeToast={removeToast} />

      {/* 顶部 */}
      <header style={{ background: '#1a1a2e', color: '#fff', padding: '20px 24px' }}>
        <div style={{ maxWidth: '1000px', margin: '0 auto', display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
          <h1 style={{ margin: 0 }}>📝 文章管理系统</h1>
          <button 
            onClick={() => { setShowForm(true); setEditingPost(null); setFormData({ title: '', body: '' }); }}
            style={{ padding: '10px 20px', background: '#007bff', color: '#fff', border: 'none', borderRadius: '6px', cursor: 'pointer' }}
          >
            ➕ 新建文章
          </button>
        </div>
      </header>

      <main style={{ maxWidth: '1000px', margin: '0 auto', padding: '24px' }}>
        {/* 表单弹窗 */}
        {(showForm || editingPost) && (
          <div style={{
            background: '#fff',
            padding: '24px',
            borderRadius: '12px',
            marginBottom: '24px',
            boxShadow: '0 2px 12px rgba(0,0,0,0.1)',
          }}>
            <h2>{editingPost ? '编辑文章' : '新建文章'}</h2>
            <form onSubmit={editingPost ? handleUpdate : handleCreate}>
              <div style={{ marginBottom: '16px' }}>
                <label style={{ display: 'block', marginBottom: '4px', fontWeight: 'bold' }}>标题</label>
                <input
                  type="text"
                  value={editingPost ? editingPost.title : formData.title}
                  onChange={(e) => editingPost 
                    ? setEditingPost({ ...editingPost, title: e.target.value })
                    : setFormData({ ...formData, title: e.target.value })
                  }
                  style={{ width: '100%', padding: '10px', borderRadius: '6px', border: '1px solid #ddd' }}
                  placeholder="请输入标题"
                />
              </div>
              <div style={{ marginBottom: '16px' }}>
                <label style={{ display: 'block', marginBottom: '4px', fontWeight: 'bold' }}>内容</label>
                <textarea
                  value={editingPost ? editingPost.body : formData.body}
                  onChange={(e) => editingPost 
                    ? setEditingPost({ ...editingPost, body: e.target.value })
                    : setFormData({ ...formData, body: e.target.value })
                  }
                  style={{ width: '100%', padding: '10px', borderRadius: '6px', border: '1px solid #ddd' }}
                  rows={4}
                  placeholder="请输入内容"
                />
              </div>
              <div style={{ display: 'flex', gap: '12px' }}>
                <button 
                  type="submit"
                  disabled={actionLoading}
                  style={{ padding: '10px 24px', background: '#28a745', color: '#fff', border: 'none', borderRadius: '6px', cursor: 'pointer' }}
                >
                  {actionLoading ? '⏳ 处理中...' : (editingPost ? '💾 保存修改' : '✅ 创建文章')}
                </button>
                <button 
                  type="button"
                  onClick={() => { setShowForm(false); setEditingPost(null); }}
                  style={{ padding: '10px 24px', background: '#6c757d', color: '#fff', border: 'none', borderRadius: '6px', cursor: 'pointer' }}
                >
                  取消
                </button>
              </div>
            </form>
          </div>
        )}

        {/* 文章列表 */}
        {loading && (
          <div style={{ textAlign: 'center', padding: '48px' }}>
            <div style={{ fontSize: '32px' }}>⏳</div>
            <p>正在加载文章列表...</p>
          </div>
        )}

        {error && (
          <div style={{ textAlign: 'center', padding: '24px', background: '#f8d7da', borderRadius: '8px' }}>
            <p style={{ color: '#721c24' }}>❌ 加载失败: {error}</p>
            <button onClick={refetch} style={{ padding: '8px 16px' }}>重试</button>
          </div>
        )}

        {posts && (
          <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(300px, 1fr))', gap: '16px' }}>

              <div key={post.id} style={{
                background: '#fff',
                borderRadius: '12px',
                padding: '20px',
                boxShadow: '0 1px 4px rgba(0,0,0,0.08)',
                transition: 'box-shadow 0.2s',

                <h3 style={{ margin: '0 0 8px 0', textTransform: 'capitalize' }}>{post.title}</h3>
                <p style={{ color: '#666', fontSize: '14px', lineHeight: 1.6, margin: '0 0 16px 0' }}>
                  {post.body}
                </p>
                <div style={{ display: 'flex', gap: '8px', justifyContent: 'flex-end' }}>
                  <button
                    onClick={() => { setEditingPost(post); setShowForm(false); }}
                    disabled={actionLoading}
                    style={{ padding: '6px 14px', background: '#ffc107', border: 'none', borderRadius: '4px', cursor: 'pointer' }}
                  >
                    ✏️ 编辑
                  </button>
                  <button
                    onClick={() => handleDelete(post.id)}
                    disabled={actionLoading}
                    style={{ padding: '6px 14px', background: '#dc3545', color: '#fff', border: 'none', borderRadius: '4px', cursor: 'pointer' }}
                  >
                    🗑️ 删除
                  </button>
                </div>
              </div>
            ))}
          </div>
        )}

        {/* 分页 */}
        <div style={{ display: 'flex', justifyContent: 'center', gap: '8px', marginTop: '32px' }}>
          <button
            onClick={() => setPage(p => Math.max(1, p - 1))}
            disabled={page === 1 || loading}
            style={{ padding: '8px 16px', borderRadius: '4px', border: '1px solid #ddd', background: '#fff', cursor: page === 1 ? 'not-allowed' : 'pointer' }}

            ← 上一页

          <span style={{ padding: '8px 16px', background: '#007bff', color: '#fff', borderRadius: '4px' }}>
            第 {page} 页
          </span>
          <button
            onClick={() => setPage(p => p + 1)}
            disabled={loading}
            style={{ padding: '8px 16px', borderRadius: '4px', border: '1px solid #ddd', background: '#fff', cursor: 'pointer' }}
          >
            下一页 →
          </button>
        </div>
      </main>
    </div>
  );
}

## 本章小结

| 概念 | 作用 | 比喻 |
|------|------|------|
| fetch | 发送网络请求 | 告诉服务员你要什么菜 |
| useEffect + fetch | 在组件中获取数据 | 入座后自动点菜 |
| loading/error/data | 三种 UI 状态 | 等菜/菜没了/上菜了 |
| POST/PUT/DELETE | 创建/更新/删除数据 | 点新菜/换菜/退菜 |
| Axios | 增强版 fetch | 高级服务员（记住你的喜好） |
| React Query | 数据获取终极方案 | 智能管家（自动点菜、缓存、续菜） |

**数据获取的黄金法则：**

1. **永远显示 loading 状态** —— 不要让用户面对空白屏幕发呆
2. **永远处理 error 状态** —— 给用户友好的错误提示和重试按钮
3. **不要忽略 finally** —— 确保 loading 状态在任何情况下都能正确关闭
4. **大型项目考虑 React Query** —— 自动缓存、重试、后台刷新，省心省力
