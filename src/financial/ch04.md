# 第4章：五险一金——你工资条上最重要的数字 🏥

> [!TIP] Part 2：理解你的"隐形资产"
> *很多人只盯着银行卡余额，却忽略了自己其实还有一笔不小的"隐形资产"——每个月工资条上被扣掉的那些钱（五险一金），以及你可能即将开始的投资之路。接下来两章，帮你把这些"看不懂"的数字变成"看得明白"的资产。*

*小王最近招了一个全职店员，月薪4500元。他照着网上的教程给员工办了社保，但看着工资条上扣掉的那些项目——养老保险、医疗保险、失业保险、公积金……他自己也搞不清楚这些到底是干嘛的。"扣了快一千块，到手才三千多，员工也不太高兴。"他挠着头，"但这些钱到底去了哪？以后能拿回来吗？"更让他困惑的是：他自己作为个体户，到底要不要给自己交社保？*

> [!WARNING] 注意
> ⚠️ 本章内容仅为知识科普，不构成任何投资建议。投资有风险，决策需谨慎。

## 4.1 什么是五险一金？为什么每个月工资都要扣这么多

**五险一金**是中国职工社会保障体系的核心，由五个社会保险和一个住房公积金组成：

| 项目 | 简称 | 保什么 | 谁出钱 |
| ------ | ------ | -------- | -------- |
| 养老保险 | 养老 | 退休后领养老金 | 个人+单位 |
| 医疗保险 | 医保 | 看病报销 | 个人+单位 |
| 失业保险 | 失业 | 失业期间领失业金 | 个人+单位 |
| 工伤保险 | 工伤 | 工作中受伤/职业病 | 仅单位 |
| 生育保险 | 生育 | 生育医疗费+产假津贴 | 仅单位 |
| 住房公积金 | 公积金 | 买房/租房的专项资金 | 个人+单位 |

> 💡 **提示**：截至2026年，多地已将生育保险和医疗保险合并实施，但保障内容不变。你可能在工资条上只看到"四险一金"，别担心，生育保险的待遇并没有消失。

每月你工资条上扣掉的钱，其实去了两个地方：

- **个人缴纳部分**：从你工资里扣，进入你的个人账户（养老个人账户、医保个人账户、公积金个人账户）
- **单位缴纳部分**：老板额外掏的钱，进入统筹账户（大家一起用的"公共池子"）

所以你的实际用工成本远高于你的税前工资。一个月薪8000的员工，企业实际成本可能在1.1万以上。

## 4.2 养老保险：退休后你能拿多少钱

养老保险的基本原理很简单：**年轻时每月存一笔钱到一个"养老池子"，退休后每月从池子里领钱。**

中国的职工养老保险由两部分组成：

1. **个人账户**：你每月缴的`8%`进入这个账户，相当于强制储蓄，退休后按月返还
2. **统筹账户**：单位缴的`16%`进入这个池子，用于支付基础养老金

**领取养老金的条件**：达到法定退休年龄（截至2026年，男性逐步延迟至63-65岁，女性逐步延迟至55-58岁，具体视改革进度）且累计缴费满**15年**（未来可能逐步提高至20年）。

养老金怎么算？简化版公式：

> `每月养老金 = 基础养老金 + 个人账户养老金`

- **基础养老金** ≈ 退休时当地上年度社平工资 ×（1 + 你的平均缴费指数）÷ 2 × 缴费年限 × 1%
- **个人账户养老金** = 个人账户余额 ÷ 计发月数（60岁退休约139个月）

看不懂公式？没关系。核心规律是：**交得越多、交得越久、退休时当地社平工资越高，你领到的养老金就越多。**

> 💡 **提示**：15年只是最低缴费年限。缴满15年就不再缴了？退休后能领到的金额可能比你想象的少得多。条件允许的话，尽量持续缴纳。

## 4.3 医疗保险：看病报销的规则

医疗保险可能是五险一金中**使用频率最高**的一项。

职工医保的核心规则（截至2026年）：

**两个账户：**

- **个人账户**：你缴的`2%`进入这个账户，可以在药店买药、看门诊时刷卡支付
- **统筹账户**：单位缴的约`8%-10%`进入这个池子，用于住院报销

**报销规则（简化版）：**

| 项目 | 说明 |
| ------ | ------ |
| 起付线 | 看病费用超过一定金额才开始报销（各地不同，住院通常几百到一千多） |
| 报销比例 | 起付线以上的部分，医保报销`70%-90%`不等（医院等级越低，报销比例越高） |
| 封顶线 | 年度报销上限，通常为当地职工年平均工资的6倍左右 |
| 自费项目 | 某些进口药、特需病房等不在报销范围内 |

> 💡 **提示**：社区医院/一级医院的报销比例通常比三甲医院高10-20个百分点。小病先去社区医院看，不仅方便，还更省钱。

## 4.4 失业保险、工伤保险、生育保险：容易忽略的权益

**失业保险**：如果你非因个人意愿失业（比如被辞退、公司倒闭），且累计缴费满1年，可以领取失业保险金。截至2026年，大多数城市的失业金标准为当地最低工资的`70%-90%`，最长可领24个月。此外，领取失业金期间，医保由失业保险基金代缴。

**工伤保险**：完全由单位缴费。如果你在工作中受伤或患上职业病，工伤保险支付医疗费、伤残补助等。上下班途中遭遇非本人主要责任的交通事故，也算工伤。

**生育保险**：完全由单位缴费。覆盖产前检查、分娩费用的报销，以及产假期间的生育津贴（大致等于你产假前的工资水平）。截至2026年，大多数地区男方也可以享受陪产假期间的生育津贴。

> 💡 **提示**：很多人不知道失业保险的存在。如果你不幸被裁员，记得在离职后60天内到当地社保经办机构或通过线上渠道申请失业金——这是你应得的权益，不是"丢脸"的事。

## 4.5 住房公积金：可能是你最大的隐形福利

住房公积金是一种专项储蓄制度——你和单位每月各缴一笔钱进入你的公积金账户，这笔钱**全部归你个人所有**。

公积金最大的好处是：**单位缴的那部分相当于你的"隐形收入"。**

假设你月薪8000，公积金缴存比例为12%：

- 你缴 `8000 × 12% = 960` 元
- 单位也缴 `8000 × 12% = 960` 元
- 你的公积金账户每月增加 `1920` 元

一年下来，你的公积金账户里有`23,040`元——其中一半是你自己缴的，另一半是单位帮你缴的。这是实实在在的"白给的钱"。

公积金贷款利率也远低于商业贷款。截至2026年，首套住房公积金贷款利率约为`2.85%`（5年以上），而同期商业房贷利率约在`3.5%-4%`左右。几十年下来，能省下几十万利息。

## 4.6 公积金的正确使用：买房、租房、装修

公积金的使用范围其实比很多人以为的要广：

| 用途 | 说明 |
| ------ | ------ |
| **买房贷款** | 最核心用途，利率远低于商贷 |
| **租房提取** | 无房且租房的，可按当地规定定期提取（许多城市已支持线上办理） |
| **装修/翻建** | 部分地区支持用于自住住房的装修或翻建 |
| **偿还房贷** | 可按月提取用于偿还房贷本息 |
| **特殊情况提取** | 离职离开本市、退休、重大疾病等特殊情况可全额提取 |

> 💡 **提示**：如果你短期内不打算买房，公积金也不是"死钱"——很多城市支持按月提取公积金支付房租。具体额度和条件请咨询当地公积金管理中心。

## 4.7 缴费基数与比例：你的五险一金是怎么算的

五险一金的缴费金额取决于两个因素：**缴费基数**和**缴费比例**。

**缴费基数**通常是你上一年度的月平均工资。但有上下限：

- **下限**：当地上年度社平工资的`60%`（工资低于此数的，按下限缴）
- **上限**：当地上年度社平工资的`300%`（工资高于此数的，按上限缴）

截至2026年，各项保险的典型缴费比例如下（以多数城市的普遍水平为例，各地略有差异）：

| 项目 | 个人比例 | 单位比例 |
| ------ | --------- | --------- |
| 养老保险 | 8% | 16% |
| 医疗保险 | 2% | 8%-10% |
| 失业保险 | 0.3%-0.5% | 0.5%-0.8% |
| 工伤保险 | 不缴 | 0.2%-1.9%（按行业风险） |
| 生育保险 | 不缴（已并入医保） | 约0.5%-1%（各地不同） |
| 住房公积金 | 5%-12% | 5%-12% |

**举个例子**：小王给员工开4500元月薪，假设当地社保缴费基数下限为4200元（员工工资高于下限，按实际工资缴），公积金比例取7%：

| 项目 | 个人缴纳 | 单位缴纳 |
| ------ | --------- | --------- |
| 养老 8%/16% | 360 | 720 |
| 医保 2%/9% | 90 | 405 |
| 失业 0.5%/0.5% | 22.5 | 22.5 |
| 工伤 0%/0.4% | 0 | 18 |
| 公积金 7%/7% | 315 | 315 |
| **合计** | **787.5** | **1480.5** |

员工实际到手工资约 `4500 - 787.5 = 3712.5` 元，但加上公积金账户里的630元（个人+单位各315），员工实际获得的总价值是 `3712.5 + 630 = 4342.5` 元。而企业的实际用人成本是 `4500 + 1480.5 = 5980.5` 元。

## 4.8 灵活就业怎么办：自由职业者的社保选择

不是所有人都有"单位"帮你缴社保。自由职业者、个体户、灵活就业人员怎么办？

**选项一：以灵活就业身份参加职工社保**

- 可以缴纳养老保险和医疗保险（这两项最重要）
- 费用全部自己承担（相当于同时承担个人+单位部分，但养老可按20%缴而非24%）
- 待遇和职工社保相同

**选项二：参加城乡居民社保**

- 缴费更低，但待遇也更低
- 适合收入不稳定或暂无能力缴纳职工社保的人群
- 养老保险和医疗保险分别独立，可以只选其中一项

**选项三：商业保险补充**

- 无论选哪种社保，都建议补充一份商业医疗险和意外险
- 一年几百到一千多的保费，可以在社保报销之外多一层保障

> 💡 **提示**：灵活就业者最容易忽略的是养老保险。很多人觉得"退休还早"就一拖再拖，但养老保险需要累计缴费年限，越早开始越轻松。

## 4.9 实战：小王作为个体户给自己交社保的最优策略

小王是个体工商户，给自己交社保有几个选择。经过研究，他制定了这样的方案：

1. **以灵活就业身份缴纳职工养老+职工医保**：选最低缴费基数（当地社平工资的60%），每月约`1200-1500`元。虽然缴的少，但保证了最基本的保障和缴费年限的积累。
2. **补充一份商业医疗险**：一年约`600`元，弥补医保报销上限的不足。
3. **暂时不缴公积金**：个体户可以自愿缴纳公积金，但小王短期内没有买房计划，决定先把这笔钱用于建立紧急备用金。
4. **等店铺稳定后提高缴费基数**：当奶茶店月利润稳定在1.5万以上时，将缴费基数提高到实际收入水平，增加未来的养老金。

> 💡 **提示**：小王的选择是基于他当前的财务状况。每个人的情况不同，具体缴费策略建议咨询当地社保经办机构或专业理财顾问。政策可能随时间变化，请以最新规定为准。
