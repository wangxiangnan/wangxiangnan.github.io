# 第4章：高效编辑与导航技巧

> 你知道新手和老手使用VSCode最大的区别是什么吗？不是插件数量，不是主题好看程度，而是**键盘使用率**。老手可能一天都不会摸一次鼠标——他们的手指在键盘上飞舞，代码就像流水一样出现在屏幕上。这一章，就是要把你从"鼠标流"改造成"键盘流"。

## 多光标编辑：一次改多处

多光标（Multi-Cursor）是VSCode最让人上瘾的功能之一。一旦用习惯了，回到其他编辑器你会觉得浑身不舒服。

### 所有触发方式一览

```
触发方式                           说明
─────────────────────────────────────────────────────────
Ctrl+D (⌘+D)                    选中下一个相同的词
Ctrl+Shift+L (⌘+Shift+L)       选中所有相同的词
Alt+Click (Option+Click)         在点击位置添加光标
Ctrl+Alt+↑/↓ (⌘+Option+↑/↓)   在上方/下方添加光标
鼠标中键拖动                      在拖动路径上添加光标（需要配置）
Ctrl+Shift+K (⌘+Shift+K)       删除整行
```

### 实战场景演示

**场景1：批量修改变量名**

```javascript
// 修改前：把所有的 userData 改成 user
const userData = fetchUser();
console.log(userData.name);
console.log(userData.email);
return userData;

// 操作：
// 1. 选中第一个 userData
// 2. Ctrl+Shift+L 选中所有 userData
// 3. 直接输入 user，所有位置同时修改
```

**场景2：给多个属性加引号**

```javascript
// 修改前：
const obj = {
  name: 'Alice',
  age: 25,
  email: 'alice@example.com'
};

// 操作：用多光标在每行末尾添加逗号
// 1. 将光标放在第一行末尾
// 2. Ctrl+Alt+↓ 向下添加光标到每一行末尾
// 3. 输入逗号
```

**场景3：列表转代码**

```text
// 你有这样一段文本：
name
email
age
phone

// 想要变成：
const name = formData.name;
const email = formData.email;
const age = formData.age;
const phone = formData.phone;

// 操作：
// 1. Ctrl+Shift+L 选中所有行（或Alt+Click在每行开头添加光标）
// 2. Home 移动到行首
// 3. 输入 "const "
// 4. End 移动到行尾
// 5. Ctrl+Alt+→ 在每个光标后插入
// 或者用更聪明的方式：先Home输入"const "，然后Ctrl+→跳到单词后面输入" = formData."，
// 然后Shift+Home选择整行，Ctrl+C复制，再End粘贴...
```

### 多光标的高级技巧

```jsonc
// 设置多光标修饰键（默认Alt，可以改成Ctrl）
{
  "editor.multiCursorModifier": "ctrlCmd"
}
```

**多光标+选择操作**：

```
// 在每个光标处选择到行尾
Ctrl+Alt+↓ 添加多行光标 → Shift+End 每行选择到行尾

// 在每个光标处选择整个单词
Ctrl+Alt+↓ 添加多行光标 → Ctrl+D 选择每个光标处的单词

// 多光标+粘贴（每个光标粘贴剪贴板的不同行！）
// 复制4行文本 → 在4个光标处粘贴 → 每行自动分配一行
```

最后一条是VSCode的隐藏技能：**当你复制了N行文本，然后在N个光标处粘贴，VSCode会自动把每一行分配给一个光标**。这在做数据转换时极其有用。

## 代码片段（Snippets）

Snippets是代码模板的自动化——把常用的代码模式保存为片段，输入前缀就能展开。

### 内置Snippet的使用

很多语言自带丰富的Snippets：

```
// JavaScript/TypeScript常用Snippet前缀：
log   → console.log()
clg   → console.log()
warn  → console.warn()
err   → console.error()
for   → for循环
forof → for...of循环
forin → for...in循环
fun   → function声明
af    → arrow function
prom  → new Promise
then  → .then()
imp   → import语句
imn   → import无default
exp   → export default
```

### 创建自定义Snippet

`Ctrl+Shift+P` → `Snippets: Configure Snippets` → 选择语言或 `New Global Snippets file`。

```jsonc
// typescript.json - TypeScript代码片段
{
  "React Functional Component": {
    "prefix": "rfc",
    "body": [
      "import React from 'react';",
      "",
      "interface ${1:ComponentName}Props {",
      "  $2",
      "}",
      "",
      "const ${1:ComponentName}: React.FC<${1:ComponentName}Props> = ({$3}) => {",
      "  return (",
      "    <div>",
      "      $0",
      "    </div>",
      "  );",
      "};",
      "",
      "export default ${1:ComponentName};"
    ],
    "description": "创建一个React函数组件（带Props接口）"
  },

  "Express Route Handler": {
    "prefix": "expressroute",
    "body": [
      "import { Request, Response, NextFunction } from 'express';",
      "",
      "export const ${1:handlerName} = async (",
      "  req: Request,",
      "  res: Response,",
      "  next: NextFunction",
      "): Promise<void> => {",
      "  try {",
      "    $0",
      "  } catch (error) {",
      "    next(error);",
      "  }",
      "};"
    ],
    "description": "创建一个Express异步路由处理器"
  },

  "Console Log with Label": {
    "prefix": "logl",
    "body": "console.log('${1:label}:', ${2:value});",
    "description": "带标签的console.log"
  },

  "Try Catch Finally": {
    "prefix": "tcf",
    "body": [
      "try {",
      "  $1",
      "} catch (${2:error}) {",
      "  $3",
      "} finally {",
      "  $0",
      "}"
    ],
    "description": "try-catch-finally块"
  },

  "Date Formatting": {
    "prefix": "datetoday",
    "body": [
      "new Date().toISOString().split('T')[0]"
    ],
    "description": "获取今天的日期字符串 YYYY-MM-DD"
  }
}
```

### Snippet变量

Snippet支持丰富的内置变量：

```
变量                 说明                    示例
─────────────────────────────────────────────────────────────
$1, $2, $0         Tab停止点（按Tab跳转）
${1:default}       带默认值的Tab停止点
$TM_FILENAME       当前文件名               utils.ts
$TM_FILENAME_BASE  文件名（无后缀）          utils
$TM_DIRECTORY      当前目录名               src
$TM_FILEPATH       文件完整路径
$TM_LINE_NUMBER    当前行号
$CURRENT_YEAR      当前年份                 2025
$CURRENT_MONTH     当前月份                 01
$CURRENT_DATE      当前日期                 15
$BLOCK_COMMENT_START  块注释开始符           /*
$BLOCK_COMMENT_END    块注释结束符           */
${1|a,b,c|}        下拉选择                 弹出a/b/c选择
```

## 代码折叠和大纲视图

### 代码折叠

```
快捷键                              说明
──────────────────────────────────────────────────────
Ctrl+Shift+[ (⌘+Option+[)        折叠当前区域
Ctrl+Shift+] (⌘+Option+])        展开当前区域
Ctrl+K Ctrl+0                    折叠所有区域
Ctrl+K Ctrl+J                    展开所有区域
Ctrl+K Ctrl+1                    折叠到第1级
Ctrl+K Ctrl+2                    折叠到第2级
Ctrl+K Ctrl+[                    折叠所有子区域
Ctrl+K Ctrl+]                    展开所有子区域
Ctrl+K Ctrl+/                    折叠所有块注释
```

### 区域标记折叠

你可以用特殊注释标记可折叠区域：

```javascript
// #region 数据获取
async function fetchUsers() { /* ... */ }
async function fetchPosts() { /* ... */ }
async function fetchComments() { /* ... */ }
// #endregion

// #region 数据处理
function normalizeUser(user) { /* ... */ }
function validatePost(post) { /* ... */ }
// #endregion
```

不同语言的区域标记：

```javascript
// #region 和 // #endregion    — JavaScript/TypeScript/C/C++/Java
// #region 和 // #endregion    — C#
#region 和 #endregion          — Python（不带//）
<!-- #region --> 和 <!-- #endregion -->  — HTML
```

### 大纲视图（Outline）

大纲视图在侧边栏底部，展示当前文件的符号结构（函数、类、变量等）。它基于Language Server提供的符号信息。

```
📄 outline.ts
├── 🏷️ Variables
│   ├── config: object          [Ln 1]
│   └── MAX_RETRIES: number     [Ln 5]
├── 📦 Interfaces
│   └── UserConfig              [Ln 8]
├── 🧩 Classes
│   └── UserService             [Ln 15]
│       ├── fetchUser           [Ln 17]
│       ├── updateUser          [Ln 25]
│       └── deleteUser          [Ln 33]
└── 📋 Functions
    ├── initialize              [Ln 40]
    └── main                    [Ln 55]
```

## 面包屑导航和符号搜索

### 面包屑导航（Breadcrumbs）

编辑器顶部显示当前文件的路径和符号层级。点击可以快速跳转。

```
src > components > Button > Button.tsx > ButtonProps (interface)
```

```jsonc
// 面包屑相关设置
{
  "breadcrumbs.enabled": true,
  "breadcrumbs.filePath": "on",           // 显示文件路径
  "breadcrumbs.symbolPath": "on",         // 显示符号路径
  "breadcrumbs.icons": true               // 显示图标
}
```

### 符号搜索

```
快捷键                          说明
────────────────────────────────────────────────────
Ctrl+Shift+O (⌘+Shift+O)    当前文件的符号搜索
Ctrl+T (⌘+T)                工作区范围的符号搜索
```

在符号搜索中，你可以使用 `:` 按类型分组：

```
:methods     — 只看方法
:variables   — 只看变量
:classes     — 只看类
:interfaces  — 只看接口
```

## 快速打开（Ctrl+P）的高级用法

`Ctrl+P`（`⌘+P`）是VSCode中最高频的命令之一。除了基本的文件名搜索，它还支持很多高级语法：

```
输入格式                     说明                    示例
──────────────────────────────────────────────────────────────
filename                   按文件名搜索             Button.tsx
filename:line              打开文件并跳到指定行      App.tsx:42
filename@symbol            打开文件并跳到符号        utils.ts@fetchData
path/subpath               按路径搜索               components/Header
.ext                       按扩展名过滤             .test.ts
```

### 组合使用示例

```bash
# 打开 utils.ts 的第100行
Ctrl+P → 输入 "utils:100" → Enter

# 打开 App.tsx 并跳到 handleSubmit 函数
Ctrl+P → 输入 "App@handleSubmit" → Enter

# 在所有 .test.ts 文件中搜索
Ctrl+P → 输入 ".test.ts" → 浏览所有测试文件
```

### 命令面板中的其他"魔法前缀"

在命令面板 `Ctrl+Shift+P` 中，以下前缀有特殊含义：

```
>     命令搜索（默认，可以省略）
@     当前文件的符号搜索
#     工作区范围的符号搜索
:     按行号跳转（在当前文件中）
```

## 实战：效率翻倍的编辑操作序列

以下是一组常见场景的最优操作流程：

### 场景1：重构函数签名

```javascript
// 将 processUser(name, age, email, phone) 
// 改为 processUser(options: { name, age, email, phone })

// 操作步骤（全程键盘）：
// 1. Ctrl+Shift+O → 输入 "processUser" → Enter  (跳到函数定义)
// 2. Ctrl+Shift+K                                  (删除当前行)
// 3. 重新输入新签名
// 4. Ctrl+Shift+H                                  (全局替换函数调用)
// 5. 逐个审查替换结果
```

### 场景2：批量添加类型注解

```typescript
// 修改前：
const users = [];
const config = {};
const handler = () => {};

// 操作：
// 1. 在第一个 const 后面添加光标
// 2. Ctrl+Alt+↓ 在每个 const 后面添加光标
// 3. 同时输入类型注解

// 修改后：
const users: User[] = [];
const config: AppConfig = {};
const handler: RequestHandler = () => {};
```

### 场景3：快速提取并重构

```javascript
// 修改前：一行超长的链式调用
const result = data.filter(x => x.active).map(x => ({ id: x.id, name: x.name.toUpperCase(), score: x.score * 1.5 })).sort((a, b) => b.score - a.score);

// 操作：
// 1. 选中整行
// 2. Ctrl+Shift+P → "Transform to lowercase" (如果需要)
// 3. 使用多光标在 "." 前面分行
//    Alt+Click 在每个 .filter/.map/.sort 前面点击
//    Enter 换行 + 适当缩进
```

### 场景4：Emmet快速生成HTML

```html
<!-- 在HTML文件中输入以下Emmet缩写，按Tab展开 -->

div.container>header>nav>ul>li*4>a{Menu $}
<!-- 展开为 -->
<div class="container">
  <header>
    <nav>
      <ul>
        <li><a href="">Menu 1</a></li>
        <li><a href="">Menu 2</a></li>
        <li><a href="">Menu 3</a></li>
        <li><a href="">Menu 4</a></li>
      </ul>
    </nav>
  </header>
</div>

ul.nav>li.item$*5>a[href="#section$"]{Section $}
<!-- 展开为 -->
<ul class="nav">
  <li class="item1"><a href="#section1">Section 1</a></li>
  <li class="item2"><a href="#section2">Section 2</a></li>
  <li class="item3"><a href="#section3">Section 3</a></li>
  <li class="item4"><a href="#section4">Section 4</a></li>
  <li class="item5"><a href="#section5">Section 5</a></li>
</ul>
```

## 进阶：录制宏和批量操作

VSCode没有内置的宏录制功能（像Vim的 `qa...q` 那样），但可以通过插件实现。

### multi-command插件

安装 `multi-command` 插件后，可以在 `keybindings.json` 中定义宏：

```jsonc
// keybindings.json
[
  {
    "key": "ctrl+shift+m",
    "command": "extension.multiCommand.execute",
    "args": {
      "sequence": [
        "editor.action.insertLineAfter",
        "editor.action.commentLine",
        "cursorUp",
        "editor.action.copyLinesDownAction"
      ],
      "interval": 50
    }
  },
  {
    "key": "ctrl+shift+i",
    "command": "extension.multiCommand.execute",
    "args": {
      "sequence": [
        "editor.action.selectAll",
        "editor.action.formatDocument",
        "editor.action.organizeImports"
      ]
    },
    "when": "editorTextFocus"
  }
]
```

### 用Tasks实现批量操作

```jsonc
// .vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "批量格式化所有文件",
      "type": "shell",
      "command": "npx prettier --write \"src/**/*.{ts,tsx,css,json}\"",
      "group": "build",
      "problemMatcher": []
    },
    {
      "label": "检查所有TypeScript错误",
      "type": "shell",
      "command": "npx tsc --noEmit",
      "group": "test",
      "problemMatcher": "$tsc"
    }
  ]
}
```

### 正则表达式搜索替换

`Ctrl+H`（`⌘+Option+F`）打开替换面板，开启正则表达式模式：

```
// 将所有 console.log 替换为 logger.debug
搜索：console\.log\((.+?)\)
替换：logger.debug($1)

// 将 camelCase 变量名转为 snake_case
搜索：([a-z])([A-Z])
替换：$1_$2（然后转小写）

// 将 ES6 import 改为 require
搜索：import\s+\{(.+?)\}\s+from\s+['"](.+?)['"]
替换：const {$1} = require('$2')

// 删除所有空行
搜索：^\s*$\n
替换：（空）

// 将 Markdown 链接转为 HTML 链接
搜索：\[(.+?)\]\((.+?)\)
替换：<a href="$2">$1</a>
```

## 📋 本章小结

- **多光标编辑**是VSCode最强大的编辑功能，掌握所有触发方式能大幅提升效率
- **Snippets**让你把常用代码模式模板化，`$1`/`$0`等占位符实现智能跳转
- **代码折叠**和**大纲视图**帮助你在大型文件中快速导航
- **Ctrl+P** 支持 `文件名:行号`、`文件名@符号` 等高级语法
- **符号搜索**（`Ctrl+Shift+O` / `Ctrl+T`）实现跨文件/跨函数的快速跳转
- **正则表达式替换**是批量代码修改的终极武器
- 善用**Emmet**可以在写HTML时获得10倍速的编码体验
