## 引子：一句 `width: 100px` 到底占了多少物理像素？

在 CSS 里写下 `div { width: 100px }`，这个元素在老式显示器上占 100 个物理像素，在 iPhone 16 Pro Max 上却占 300 个物理像素——但两者看起来"一样大"。

这背后是一整套分工明确的体系：硬件负责发光（物理像素），厂商负责定汇率（DPR），浏览器负责呈现策略（viewport），开发者负责在逻辑世界里写代码（CSS 像素）。本教程用七章把这套体系逐层剥开。

## 全文脉络回顾

七章递进，一句话串起：**物理像素是地基（第 1 章），CSS 像素是抽象（第 2 章），DPR 是汇率（第 3 章），viewport 是画布策略（第 4 章），JS API 是验证手段（第 5 章），Windows 缩放是同构的桌面映射（第 6 章），1px 与高清图是落地的实战（第 7 章）。** 下次遇到适配问题，先定位它在哪一层，问题就解决了一半。

## 附录一：术语一句话定义

| 术语 | 一句话定义 |
|------|------------|
| 物理像素 | 屏幕上真实发光点，数量出厂固定，是一切渲染的终点 |
| CSS 像素 | Web 的逻辑像素，锚定 `1in = 96px`，开发者书写的唯一单位 |
| DPR | 1 个 CSS 像素对应多少个物理像素，厂商按"PPI ÷ 基准密度"取整定出 |
| 有效 DPR | 厂商基准 × 系统缩放 × 浏览器缩放；桌面动态变化，iOS Safari 固定 |
| PPI | 每英寸物理像素数，屏幕密度的准确度量 |
| DPI | 印刷墨点密度；Windows 里是缩放基准（96 = 100%）的历史旧称 |
| 基准密度 | 计算 DPR 的参考值：CSS/Windows 96、Android 160、Apple 163 |
| 布局视口 | CSS 排版的画布宽度，不写 viewport 默认 980 |
| 视觉视口 | 用户当前实际看到的区域，捏合缩放只改变它 |
| 理想视口 | 设备的 CSS 像素宽度（`screen.width`），布局视口的最佳取值 |
| dp | Android 密度无关单位，1dp = 1/160 英寸 = 0.6 CSS px |
| pt | iOS 逻辑单位，@3x 屏上 1pt = 3 物理像素 |
| 逻辑分辨率 | 物理分辨率 ÷ 系统缩放，桌面应用实际看到的"桌面大小" |
| srcset | 让浏览器按设备 DPR 自动挑选合适分辨率图片的 HTML 属性 |

> 用法：拿到设计稿或排查适配问题时，先在此表找到目标设备的 DPR 与 CSS 尺寸，再用[第 2 章](/pixels-viewport/ch02)、[第 3 章](/pixels-viewport/ch03)的公式推导。注意：PPI 列以官方标称为准，与"对角线名义尺寸"直接相除可能相差 1–2（如初代 iPhone 按公式算 165、官方标称 163），原因是宣传尺寸经过四舍五入——与[第 1 章 1.2 节](/pixels-viewport/ch01#_1-2-ppi-密度的度量) 6.9 vs 6.86 英寸是同一现象。

## 附录三：全文数据速查表

```
物理像素    屏幕发光点，出厂固定            iPhone 16 Pro Max: 1320×2868
PPI         每英寸物理像素数                √(1320²+2868²)÷6.86 ≈ 460
DPI         印刷术语；Windows 里指缩放基准   96 DPI = 100% 缩放
CSS 像素    逻辑单位，1in=96px 恒成立        坐标系 440×956 = 1320÷3 × 2868÷3
DPR         1 CSS px = DPR 个物理像素        厂商定：PPI÷基准(96/160/163)取整
有效 DPR    基准×系统缩放×浏览器缩放         桌面动态；iOS Safari 固定 3
布局视口    CSS 画布宽                       默认 980；device-width 后 440
视觉视口    用户所见区域                     捏合缩放改变，visualViewport 可读
理想视口    设备 CSS 宽度                    screen.width = 440 = iOS outerWidth
1px 问题    CSS 1px = 3 物理像素(@3x)        scaleY(1/DPR) 或 0.5px 方案
高清图      图物理宽 = CSS 宽 × DPR          srcset="2x.jpg 2x, 3x.jpg 3x"
跨平台换算  Android dp ↔ CSS px             1dp = 0.6 CSS px
```
