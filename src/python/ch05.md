# 第 5 章 条件判断

想象你每天早上出门前的决策过程：如果下雨，就带伞；如果不下雨但阴天，就带一件薄外套；如果晴天，就轻装出门。你的大脑无时无刻不在做"如果……就……否则……"的判断。编程中的条件判断，就是把这种人类天然的决策逻辑，翻译成计算机能理解的代码。

条件判断是程序从"顺序执行"走向"智能决策"的关键一步。在此之前，我们写的代码都是从第一行执行到最后一行，每行都会执行。但有了条件判断，程序就可以根据不同的情况走不同的路径——就像一个岔路口，你根据路标选择走哪条路。这个特性让程序能够处理各种复杂的现实场景：根据用户输入做出不同响应、根据数据状态选择不同的处理方式、根据权限控制用户的操作等等。

## 5.1 if 语句：最基本的条件分支

`if` 语句的语法非常接近自然语言：

```python
temperature = 35

if temperature > 30:
    print("太热了！开空调！")
```

如果条件（`temperature > 30`）为 `True`，就执行缩进的代码块；如果为 `False`，就跳过。就这么简单。

```python
age = 20

if age >= 18:
    print("你已成年，可以考驾照了。")
    print("恭喜你！")

print("这行不受 if 控制，总会执行。")
```

注意缩进的重要性：`print("恭喜你！")` 和上一行缩进相同，所以它们都在 `if` 块里。最后一行没有缩进，所以它不属于 `if`，无论条件是否成立都会执行。

## 5.2 if-else：二选一

当条件不满足时你也想执行某些代码，就用 `else`：

```python
number = int(input("请输入一个整数："))

if number % 2 == 0:
    print(f"{number} 是偶数")
else:
    print(f"{number} 是奇数")
```

`else` 不需要写条件——它代表"其他所有情况"。`if` 和 `else` 之间不存在第三种可能，必定走其中一条路。

```python
# 判断密码强度
password = input("请输入密码：")

if len(password) >= 8:
    print("密码长度合格")
else:
    print("密码太短了，至少需要 8 个字符")
```

## 5.3 if-elif-else：多条件分支

现实中很多决策不是"非黑即白"的，而是有多个选项。`elif`（else if 的缩写）让你可以写多个条件分支：

```python
score = 85

if score >= 90:
    grade = "A（优秀）"
elif score >= 80:
    grade = "B（良好）"
elif score >= 70:
    grade = "C（中等）"
elif score >= 60:
    grade = "D（及格）"
else:
    grade = "F（不及格）"

print(f"你的成绩等级是：{grade}")
```

**重要**：`elif` 的判断是**从上到下依次执行**的，一旦某个条件为 `True`，就执行对应的代码块并跳出整个 if-elif-else 结构，后面的条件不再检查。所以上面的代码中，`score = 85` 时，虽然它同时满足 `>= 70`、`>= 60`，但因为 `>= 80` 先被匹配到了，所以等级是 "B"。

这意味着条件的顺序很重要。如果你把 `>= 60` 放在最前面，那所有及格以上的分数都会被判定为 "D"——这显然不对。

```python
# 一个实用的例子：根据月份判断季节
month = int(input("请输入月份（1-12）："))

if month in [3, 4, 5]:
    season = "春天"
elif month in [6, 7, 8]:
    season = "夏天"
elif month in [9, 10, 11]:
    season = "秋天"
elif month in [12, 1, 2]:
    season = "冬天"
else:
    season = "未知（请输入 1-12）"

print(f"{month}月是{season}")
```

## 5.4 三元表达式：一行搞定简单条件

当你需要根据条件给变量赋不同的值时，三元表达式（也叫条件表达式）能让代码更简洁：

```python
age = 20

# 传统写法
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 三元表达式（一行搞定）
status = "成年" if age >= 18 else "未成年"
print(status)  # 成年
```

语法格式是：`值A if 条件 else 值B`——条件为真取值 A，否则取值 B。

```python
# 更多例子
x = 10
abs_x = x if x >= 0 else -x  # 求绝对值
print(abs_x)  # 10

# 判断奇偶
result = "偶数" if 7 % 2 == 0 else "奇数"
print(result)  # 奇数

# 用于函数参数
name = ""
print(f"你好，{name if name else '匿名用户'}！")
# 输出：你好，匿名用户！
```

三元表达式适合简单的二选一赋值。如果逻辑复杂（比如需要多行代码块），还是老老实实写 `if-else`，别硬挤成一行。

## 5.5 嵌套条件：条件中的条件

有时候，一个判断的结果还需要进一步判断。比如先判断是否是会员，再判断会员等级：

```python
is_member = True
points = 1500

if is_member:
    if points >= 2000:
        discount = 0.7  # 金卡会员打七折
        print("您是金卡会员")
    elif points >= 1000:
        discount = 0.8  # 银卡会员打八折
        print("您是银卡会员")
    else:
        discount = 0.9  # 普通会员打九折
        print("您是普通会员")
else:
    discount = 1.0  # 非会员无折扣
    print("您还不是会员")

price = 100
print(f"原价 {price} 元，折后 {price * discount} 元")
```

嵌套条件可以无限层（理论上），但超过 3 层就会很难读。如果你发现自己写了太多层嵌套，考虑用 `elif` 合并条件，或者把内层逻辑提取成函数（后面会学）。

## 5.6 match-case：Python 3.10 的模式匹配

Python 3.10 引入了 `match-case` 语句，类似于其他语言的 `switch-case`，但功能更强大。它不仅能匹配值，还能匹配模式：

```python
# 基本的值匹配
command = input("请输入命令：")

match command:
    case "start":
        print("启动程序")
    case "stop":
        print("停止程序")
    case "pause" | "suspend":  # 用 | 匹配多个值
        print("暂停程序")
    case _:  # 通配符，相当于 default
        print(f"未知命令：{command}")
```

```python
# 匹配更复杂的模式
def handle_response(response):
    match response:
        case {"status": 200, "data": data}:
            print(f"请求成功，数据：{data}")
        case {"status": 404}:
            print("页面未找到")
        case {"status": code} if code >= 500:
            print(f"服务器错误：{code}")
        case _:
            print("未知响应")

handle_response({"status": 200, "data": "Hello"})
handle_response({"status": 404})
handle_response({"status": 503})
```

`match-case` 在处理命令解析、状态机、API 响应等场景时特别有用。但注意它只在 Python 3.10 及以上版本可用。

## 5.7 常见条件模式：卫语句与扁平化

写条件判断时，有一种技巧叫做**卫语句（Guard Clause）**——先处理异常情况并提前返回，让主逻辑保持简洁。这比把所有逻辑都塞进一个巨大的 `if-else` 里要清晰得多：

```python
# 不好的写法：层层嵌套，主逻辑被包在深处
def process_order(order):
    if order is not None:
        if order["status"] == "pending":
            if order["amount"] > 0:
                # 处理订单的核心逻辑
                print(f"正在处理订单 #{order['id']}，金额：{order['amount']}")
            else:
                print("订单金额无效")
        else:
            print("订单状态不是 pending")
    else:
        print("订单为空")

# 好的写法：用卫语句提前退出
def process_order(order):
    if order is None:
        print("订单为空")
        return
    if order["status"] != "pending":
        print("订单状态不是 pending")
        return
    if order["amount"] <= 0:
        print("订单金额无效")
        return

    # 主逻辑一目了然，没有嵌套
    print(f"正在处理订单 #{order['id']}，金额：{order['amount']}")
```

```python
# 另一个常见模式：用字典代替一长串 if-elif
def get_discount_level(score):
    # 不用 if-elif，而是用字典映射
    levels = {
        range(90, 101): "金牌会员（8 折）",
        range(80, 90): "银牌会员（85 折）",
        range(60, 80): "铜牌会员（9 折）",
    }
    for score_range, level in levels.items():
        if score in score_range:
            return level
    return "普通会员（无折扣）"

print(get_discount_level(95))   # 金牌会员（8 折）
print(get_discount_level(75))   # 铜牌会员（9 折）
print(get_discount_level(50))   # 普通会员（无折扣）
```

卫语句的核心思想是"尽早退出"——先排除所有不该走的路，剩下的就是正确的路。这不仅让代码更扁平，还让你的思维更清晰。

## 5.8 条件判断的实战应用

让我们看几个更贴近实际的例子：

```python
# 示例 1：简单的登录验证
username = input("用户名：")
password = input("密码：")

if username == "admin" and password == "123456":
    print("登录成功！")
elif username == "admin":
    print("密码错误")

    print("用户不存在")
```

```python
# 示例 2：出租车计价器
# 起步价 13 元（3 公里内），超过 3 公里每公里 2.3 元
# 超过 15 公里加收 50% 空驶费
distance = float(input("请输入行驶距离（公里）："))

if distance <= 3:
    fare = 13
elif distance <= 15:
    fare = 13 + (distance - 3) * 2.3
else:

```

## 5.9 思考：如何测试你的条件逻辑

写完条件判断后，很多人觉得"跑一遍没问题就完事了"。但条件逻辑的 bug 往往藏在**边界情况**里——那些你没想到但确实可能发生的输入。

写条件代码时，问自己几个问题：

- **边界值**：如果条件是 `x >= 18`，当 `x = 18` 时走哪条路？`x = 17` 呢？`x = 0` 呢？
- **极端值**：如果输入是负数、超大数字、空字符串、`None` 会怎样？
- **类型不匹配**：如果预期是整数但用户输入了字符串呢？

```python
# 一个看似正确的成绩评级函数
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    elif score >= 60:
        return "D"
    else:
        return "F"

# 正常情况没问题
print(get_grade(85))  # B
print(get_grade(42))  # F

# 但是边界情况呢？
print(get_grade(100))  # A（正确）
print(get_grade(0))    # F（正确）
print(get_grade(-5))   # F（不合理！负分不应该是 F，应该是"输入错误"）
print(get_grade(150))  # A（不合理！超出范围了）

# 更健壮的版本
def get_grade_safe(score):
    if not isinstance(score, (int, float)):
        return "错误：成绩必须是数字"
    if score < 0 or score > 100:
        return "错误：成绩必须在 0-100 之间"

    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    elif score >= 60:
        return "D"
    else:
        return "F"

print(get_grade_safe(-5))    # 错误：成绩必须在 0-100 之间
print(get_grade_safe(150))   # 错误：成绩必须在 0-100 之间
print(get_grade_safe("85"))  # 错误：成绩必须是数字
```

注意第二个版本的思路：先用卫语句处理所有不合法的输入，确保后续的评级逻辑只在合法数据上执行。这种"防御性编程"的思维，会让你写出更健壮的代码。

## 5.10 小结

- `if` 语句是最基本的条件判断，条件为真时执行缩进的代码块。
- `if-elif-else` 用于多条件分支，从上到下匹配，命中即跳出。
- 三元表达式 `值A if 条件 else 值B` 适合简单的二选一赋值。
- 嵌套条件可以处理复杂逻辑，但不宜超过 3 层。
- `match-case`（Python 3.10+）提供了强大的模式匹配能力。
- 条件顺序很重要——把更具体的条件放在前面，更宽泛的条件放在后面。

## 5.13 常见错误与避坑

- **忘记冒号**：`if x > 5` 末尾必须有冒号 `:`，否则报 `SyntaxError`。
- **用 `=` 代替 `==`**：`if x = 5:` 是赋值，会报语法错误。比较必须用 `==`。
- **条件顺序错误**：在多条件分支中，Python 从上到下匹配。如果把 `>= 60` 放在 `>= 90` 前面，所有及格分数都会被判定为 "D" 以上。
- **嵌套缩进不对**：嵌套 `if` 时，内层代码块需要额外缩进。缩进混乱会导致逻辑错误（程序不报错，但结果不对），这种 bug 很难发现。
- **match-case 版本要求**：`match-case` 只在 Python 3.10+ 可用。如果你的环境是 Python 3.9 或更早版本，使用它会报 `SyntaxError`。用 `python --version` 检查你的版本。
