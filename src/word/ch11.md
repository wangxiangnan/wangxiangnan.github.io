# 第11章：长文档排版——商业计划书的终极挑战 📑

*投资人说："小王，给我发一份你们的商业计划书。"小王信心满满地打开Word，写了30页的内容，配了十几张图表。可是排版的时候，他崩溃了——封面莫名其妙出现了页码，目录的页码和正文对不上，第三章的图编号突然从"图3-1"跳到了"图3-5"，删一个空白页把后面的内容全弄乱了……他改了这里那里乱，改了那里这里乱，折腾了一整天，文档越搞越丑。最后他发了一个"纯文字无排版"的版本给投资人，内心默默祈祷对方不要在意格式。——当然，投资人很在意。*

*长文档排版是很多人的"终极噩梦"。但说实话，它并不难，只是需要理解几个核心概念。一旦你搞懂了"分节符""样式""域"这些概念，排版长文档就像搭积木一样有条理。这一章是全书最重要、最详细的一章，请耐心跟着学，我保证你学完之后会有"原来如此"的顿悟感。*

## 11.1 长文档的核心难题：页眉页脚不同、目录复杂、编号混乱

在动手之前，先搞清楚长文档排版为什么难。核心痛点就三个：

**痛点一：页面格式不统一**

- 封面不能有页眉页脚
- 目录的页码要用罗马数字（i, ii, iii……）
- 正文的页码要从1开始用阿拉伯数字（1, 2, 3……）
- 每一章的首页不要页眉

如果整个文档是一个"整体"，这些"不同页面不同格式"的需求根本做不到。所以需要把文档"切开"——这就是分节符的用途。

**痛点二：目录和编号**

- 30页的文档手动编目录？累死。
- 图表编号"图1-1""图1-2"……中间插一张图，后面的编号全要改？更累。
- 标题层级"第一章 > 1.1 > 1.1.1"手动维护？会疯。

这些都需要"自动化"——用样式和域来管理。

**痛点三：牵一发而动全身**

- 改了一处格式，后面全乱了
- 删了一个分页符，整篇文档的页码都错位了
- 加了一张图，目录就不对了

这些问题的根源都是——文档结构没有搭好。就像盖房子，地基没打好，装修怎么弄都不对。

## 11.2 分节符：让文档分成独立的"区域"

**什么是分节符？**

分节符就是把文档"切"成几个独立的区域（叫做"节"），每个区域可以有自己独立的页面设置。

打个比方：一本杂志，封面、目录、正文、广告——虽然都在同一本杂志里，但每一部分的页眉页脚、页码格式可能都不一样。分节符就是在这些部分之间"切一刀"。

**分节符的种类：**

| 类型 | 作用 | 常用场景 |
| ------ | ------ | --------- |
| **下一页** | 新节从下一页开始 | 最常用！章节之间分节 |
| **连续** | 新节从当前页继续 | 同一页内需要不同的栏数 |
| **偶数页** | 新节从下一个偶数页开始 | 书籍排版，章节从偶数页开始 |
| **奇数页** | 新节从下一个奇数页开始 | 书籍排版，章节从奇数页开始 |

**怎么插入分节符？**

`布局 > 分隔符 > 分节符 > 下一页`

> 💡 **提示**：分节符和分页符是不同的东西！分页符只是"从这里换一页"，不会创建新的节。分节符不仅换页，还创建了一个新的"独立区域"。如果你只是想换页，用 `Ctrl + Enter`（分页符）；如果你想让新页面有不同的页眉页脚或页码格式，用分节符。

**怎么看到分节符在哪？**

点击 `开始 > 显示/隐藏编辑标记`（就是那个 ¶ 按钮，快捷键 `Ctrl + Shift + 8`）。开启后，你能看到文档中所有的隐藏标记，分节符会显示为一条双虚线，上面写着"分节符（下一页）"。

> 💡 **提示**：养成一个好习惯——排版长文档时，始终开启"显示编辑标记"。这样你能清楚地看到分页符、分节符、空行等"隐形元素"，避免"不知道哪里多了个空白页"的困惑。

**小王的商业计划书需要这样分节：**

| 节号 | 内容 | 页面特点 |
| ------ | ------ | --------- |
| 第1节 | 封面 | 无页眉、无页脚、无页码 |
| 第2节 | 目录 | 无页眉，页脚用罗马数字（i, ii, iii） |
| 第3节 | 第一章：项目概述 | 有页眉，页码从1开始（阿拉伯数字） |
| 第4节 | 第二章：市场分析 | 有页眉，页码续前 |
| 第5节 | 第三章：财务规划 | 有页眉，页码续前 |
| 第6节 | 附录 | 有页眉，页码续前或重新编号 |

在每个部分之间插入"下一页"类型的分节符即可。

## 11.3 不同节设置不同的页眉页脚

这是长文档排版中最让人头疼、但也是最关键的一步。我们一步一步来。

**核心概念：链接到前一节**

默认情况下，每一节的页眉页脚会"链接"到上一节——也就是说，它会自动继承上一节的页眉页脚内容。如果你想让某一节有不一样的页眉页脚，必须先**断开链接**。

**实战操作：让封面没有页眉页脚**

1. 双击封面的页眉区域，进入页眉编辑模式
2. 在 `页眉和页脚` 工具栏中，找到 `链接到前一节` 按钮
3. 对于第一节（封面），这个按钮是灰色的（因为没有"前一节"可以链接），不用管
4. 双击封面页脚区域，确认没有内容就好

**实战操作：让目录用罗马数字页码**

1. 双击第2节（目录）的页脚区域，进入编辑模式
2. 点击 `链接到前一节`——**取消它！** 按钮不再高亮，说明第2节和第1节的页脚已经"脱钩"了
3. 现在你可以放心地设置第2节的页脚，不会影响封面
4. 点击 `页码 > 页面底端`，选一个页码样式
5. 点击 `页码 > 设置页码格式`
6. 在"编号格式"中选择"i, ii, iii, ……"
7. 在"起始页码"中选择"i"
8. 点击确定

**实战操作：让正文用阿拉伯数字、从1开始**

1. 双击第3节（正文第一章）的页脚区域
2. 点击 `链接到前一节`——**取消它！** 断开和第2节的链接
3. 插入页码
4. `页码 > 设置页码格式`
5. 编号格式选择"1, 2, 3, ……"
6. 起始页码填写"1"
7. 点击确定

**实战操作：让后续章节页码连续**

对于第4节、第5节……（后续章节），如果你想页码接着前一节继续编：

1. 双击页脚，取消"链接到前一节"（如果你想用不同的页眉内容）
2. 或者直接保持"链接到前一节"，页码会自动续上

> 💡 **提示**：页码编号不连续是长文档最常见的问题之一。90%的原因是"链接到前一节"没有正确处理。记住口诀：**换节先断链，页码格式单独设。**

**关于"每章首页不要页眉"的需求**

有些排版要求每一章的第一页不显示页眉（就像书的每一章首页通常是空白的页眉）。这个功能Word内置了：

1. 双击页眉进入编辑模式
2. 勾选 `页眉和页脚` 工具栏中的 `首页不同`
3. 这样每一节的首页会自动使用不同的页眉（你可以把它设为空）

注意：`首页不同`是按节生效的。如果你每一章是一个节，那每章首页都可以有不同的页眉。

## 11.4 奇偶页不同的页眉页脚

如果你要排版一本书或一本报告，通常会有这样的需求：

- 奇数页（右手页）的页眉显示章节标题，页码靠右
- 偶数页（左手页）的页眉显示书名，页码靠左

这在Word中也能实现：

1. 双击页眉进入编辑模式
2. 勾选 `奇偶页不同`
3. Word会区分"奇数页页眉"和"偶数页页眉"，你可以分别设置

> 💡 **提示**：`首页不同` 和 `奇偶页不同` 可以同时勾选。这样Word会区分三种页眉：首页、奇数页、偶数页。不过对于商业计划书这种文档，通常不需要这么复杂，`首页不同`就够用了。

## 11.5 长文档的目录结构：多级目录

**为什么不用手动打目录？**

手动打目录的问题很明显：

- 你写了30页，要自己列出每一章每一节的标题和页码
- 中间加了一段内容，后面所有页码都变了，你要手动改
- 格式很难对齐——标题和页码之间的"………"手动打很难看

Word可以自动生成目录，前提是——你要告诉Word哪些文字是"标题"。怎么告诉？用**样式**。

**第一步：给标题应用样式**

Word内置了"标题1""标题2""标题3"等样式。你需要：

- 章标题（如"第一章 项目概述"）→ 应用"标题1"样式
- 节标题（如"1.1 项目背景"）→ 应用"标题2"样式
- 小节标题（如"1.1.1 行业现状"）→ 应用"标题3"样式

操作方法很简单：选中标题文字，在 `开始` 选项卡的样式库中点击对应的样式即可。

> 💡 **提示**：不要用"手动加粗加大字号"来伪装标题！即使你把一行文字设置成了"黑体二号加粗"，Word依然不知道它是一个标题，只有应用了"标题X"样式，Word才能识别它。这是很多新手最常犯的错误。

**第二步：自定义多级列表编号**

如果你希望标题自动带有编号（1、1.1、1.1.1），需要设置多级列表：

1. 点击 `开始 > 多级列表`（在编号按钮旁边）
2. 选择"定义新的多级列表"
3. 在弹出的对话框中：
   - 级别1链接到"标题1"，编号格式设为"第1章"或"1"
   - 级别2链接到"标题2"，编号格式设为"1.1"
   - 级别3链接到"标题3"，编号格式设为"1.1.1"
4. 点击确定

设置好之后，每次你应用"标题1"样式，Word会自动编号为"第1章""第2章"……应用"标题2"样式，会自动编号为"1.1""1.2"……

> 💡 **提示**：多级列表的设置是长文档排版中最容易出错的地方之一。如果你发现编号乱了（比如第二章的节标题显示的是"2.1"却变成了"1.4"），不要手动改编号——选中该标题，右键选择"重新开始编号"或"继续编号"即可。

**第三步：插入自动目录**

标题都设置好后，把光标放在要插入目录的位置（通常在正文前面），然后：

`引用 > 目录 > 自动目录1`（或"自动目录2"）

Word会自动扫描文档中所有应用了"标题X"样式的文字，生成一份带页码的目录！

**第四步：更新目录**

如果你在插入目录后又修改了文档（加了内容、改了标题、页码变了），只需要：

右键点击目录 → `更新域` → 选择"只更新页码"或"更新整个目录"

> 💡 **提示**：Word不会自动更新目录！每次修改文档后，你必须手动右键更新。建议在定稿前最后一次更新目录，并检查一遍。如果改了标题文字，要选"更新整个目录"；如果只是内容增减导致页码变化，选"只更新页码"就行。

## 11.6 图表编号：自动编号"图1-1"、"表2-3"

商业计划书里通常会有很多图表，需要按"章-序号"的格式编号，比如"图1-1"表示第一章的第一张图，"图2-3"表示第二章的第三张表。

**手动编号的问题**：如果你在第一章中间插入了一张新图，后面的"图1-2""图1-3"……全都要手动改编号。

**自动编号的方法——使用题注功能：**

1. 选中图片或表格
2. `引用 > 插入题注`
3. 在"标签"中选择"图"或"表"（如果没有，点"新建标签"自己创建一个）
4. 点击"编号"，勾选"包含章节号"
5. 设置章节起始样式为"标题1"，分隔符选"-"
6. 确定后，题注会自动显示为"图1-1"

之后你再插入新图并添加题注时，Word会自动递增编号。如果在中间插入了一张图，后面的编号按 `Ctrl + A` 全选再按 `F9` 刷新即可。

> 💡 **提示**：`F9` 是刷新域代码的快捷键。Word中的目录、页码、题注编号等本质上都是"域"——一种自动计算的内容。当你发现任何编号、页码不对时，`Ctrl + A` 全选然后 `F9` 刷新，往往能解决大部分问题。

**交叉引用：在正文中提到图表**

你在正文中写"如图1-1所示"时，这个"图1-1"也可以用交叉引用自动插入：

`引用 > 交叉引用` → 引用类型选"图" → 引用内容选"只有标签和编号" → 选择对应的图

这样即使图编号变了，正文中的引用也会跟着自动更新。

## 11.7 封面页设计：不与正文混在一起

封面页是商业计划书的"门面"。但很多人把封面和正文放在同一个文档里时，总是遇到各种问题——封面多了个空白页、封面上出现了页码、封面的页边距和正文不一样……

**正确做法：**

1. 封面单独作为文档的**第一节**
2. 在封面和目录之间插入"下一页"类型的**分节符**
3. 封面这一节不设置页眉页脚
4. 如果封面的页边距和正文不同（比如封面需要更大的页边距），可以在第一节中单独设置 `布局 > 页边距`

**封面的内容要素**（以小王的商业计划书为例）：

```
【居中·大字】
茶里茶气
商业计划书

【居中·中字】
——打造Z世代新茶饮品牌

【居中·小字】
编制单位：茶里茶气餐饮管理有限公司
编制日期：2026年6月
联系人：王某某
联系电话：138****1234
```

> 💡 **提示**：封面不要用太花哨的设计。商业计划书的封面讲究的是**专业、简洁、信息明确**。项目名称、文档名称、编制信息，这三样就够了。如果确实需要设计感很强的封面，建议用PPT或设计软件做好后，作为图片插入到Word的第一页。

## 11.8 文档部件：快速插入预制内容块

Word有一个很好用但很少有人知道的功能——**文档部件**。它可以把一段常用的内容（包括文字、格式、图片）保存为一个"积木块"，以后一键插入。

**内置的文档部件：**

Word自带了一些现成的文档部件，比如：

- 标题页（多种设计好的封面模板）
- 页眉样式
- 页脚样式
- 文本框样式
- 公式样式

使用方式：`插入 > 文档部件 > 构建基块管理器`，可以浏览和插入所有内置部件。

也可以直接从 `插入 > 封面` 中选择一个设计好的封面模板插入。

**创建自己的文档部件：**

如果你经常需要插入同一段内容（比如公司的标准免责声明、常用的表格模板、固定的签名块），可以：

1. 先写好这段内容并排好版
2. 选中这段内容
3. `插入 > 文档部件 > 将所选内容保存到文档部件库`
4. 给它起个名字，选择保存位置
5. 以后在任何文档中，`插入 > 文档部件` 就能一键插入这段内容

> 💡 **提示**：文档部件保存在一个叫 `Building Blocks.dotx` 的模板文件中。如果你想把自定义部件分享给同事，需要把这个文件发给他们。文件位置通常在 `C:\Users\你的用户名\AppData\Roaming\Microsoft\Document Building Blocks\` 下。

## 11.9 实战：排版一份完整的奶茶店商业计划书

终于到了实战环节！让我们帮小王排版一份专业级的商业计划书。

**文档结构规划：**

```
封面（第1节）
  ↓ 分节符（下一页）
目录（第2节）
  ↓ 分节符（下一页）
第一章：项目概述（第3节）
  1.1 项目背景
  1.2 团队介绍
  ↓ 分节符（下一页）
第二章：市场分析（第4节）
  2.1 行业现状
  2.2 目标用户
  2.3 竞争分析
  ↓ 分节符（下一页）
第三章：产品与服务（第5节）
  3.1 产品线
  3.2 服务流程
  ↓ 分节符（下一页）
第四章：财务规划（第6节）
  4.1 成本结构
  4.2 盈利预测
  ↓ 分节符（下一页）
附录（第7节）
```

**排版步骤详解：**

**Step 1：搭建骨架**

1. 新建空白Word文档
2. 先用"正文"样式把所有内容写进去（不用管格式，只管内容）
3. 给所有章标题应用"标题1"样式
4. 给所有节标题应用"标题2"样式
5. 给所有小节标题应用"标题3"样式

**Step 2：插入分节符**

1. 在封面内容之后：`布局 > 分隔符 > 分节符（下一页）`
2. 在目录之后：同上
3. 在每一章之后：同上
4. 开启"显示编辑标记"确认分节符位置正确

**Step 3：设置页眉页脚**

1. 第1节（封面）：不设页眉页脚
2. 第2节（目录）：断开与前节链接 → 页脚设罗马数字页码（i, ii, iii）
3. 第3节（第一章）：断开与前节链接 → 页脚设阿拉伯数字页码（从1开始）→ 设置页眉内容为"茶里茶气·商业计划书"
4. 第4-7节：页码续前，页眉分别设为各章标题

**Step 4：设置多级列表**

1. 定义新的多级列表，将级别1/2/3分别链接到标题1/2/3
2. 检查所有标题的编号是否正确
3. 如有错误，右键调整

**Step 5：插入图表题注**

1. 对文中每张图：`引用 > 插入题注` → "图X-X"
2. 对文中每张表：`引用 > 插入题注` → "表X-X"
3. 在正文中用交叉引用提到图表

**Step 6：生成目录**

1. 光标放在第2节（目录页）
2. `引用 > 目录 > 自动目录`
3. 检查目录是否包含所有章节标题和正确的页码

**Step 7：设计封面**

1. 光标回到第1节
2. 可以使用 `插入 > 封面` 选择一个模板
3. 填入项目名称、编制信息等

**Step 8：最终检查**

1. `Ctrl + A` 全选，`F9` 刷新所有域
2. 逐页检查：封面→目录→正文→附录
3. 重点检查：页码是否连续、目录页码是否正确、图表编号是否正确
4. 导出为PDF，再次确认

> 💡 **提示**：最终提交给投资人或客户的商业计划书，强烈建议导出为PDF格式。PDF可以保证在任何设备上打开时格式一致，不会出现"你的Word版本不同导致排版错位"的尴尬。导出方式：`文件 > 另存为 > 选择PDF格式`。

**常见踩坑与解决方案：**

| 问题 | 原因 | 解决方案 |
| ------ | ------ | --------- |
| 封面出现页码 | 封面节没有断开页脚链接 | 双击封面页脚，删除页码，确认"链接到前一节"已关闭 |
| 目录页码全是1 | 插入目录后文档发生了变动 | 右键目录 → 更新域 → 更新整个目录 |
| 某章标题编号跳跃 | 多级列表编号不连续 | 右键该标题 → 继续编号 |
| 分节符删不掉 | 没有开启编辑标记 | 开启 ¶ 按钮，找到分节符位置，用Delete删除 |
| 图表编号不连续 | 新增图表后没刷新域 | `Ctrl + A` 全选，`F9` 刷新 |
| 页眉出现一条横线 | Word自动给页眉加了下边框线 | 选中页眉段落 → `开始 > 边框 > 无边框` |
| 空白页删不掉 | 有隐藏的分页符或分节符 | 开启编辑标记，找到多余的标记并删除 |

## 本章小结

| 知识点 | 核心要点 |
| -------- | --------- |
| 分节符 | 将文档分成独立的"节"，每节可有不同页面设置 |
| 页眉页脚 | 换节先断链（取消"链接到前一节"），再单独设置 |
| 页码格式 | 目录用罗马数字，正文用阿拉伯数字，通过分节实现 |
| 多级目录 | 先给标题应用样式，再用多级列表编号，最后自动生成目录 |
| 图表编号 | 用题注功能自动编号，`F9` 刷新 |
| 封面页 | 单独一节，不设页眉页脚 |
| 文档部件 | 保存常用内容块，一键插入 |
| 最终输出 | 导出PDF保证格式一致 |

## 练习题

1. **基础题**：创建一个包含封面、目录、两章正文的文档。封面不要页码，目录用罗马数字页码，正文从第1页开始用阿拉伯数字页码。生成自动目录。

2. **进阶题**：在上面的文档中，每章加入至少两张图片，用题注功能自动编号（图1-1、图1-2……），并在正文中用交叉引用提到这些图。

3. **挑战题**：排版一份完整的5000字以上的商业计划书（或课程论文），包含：封面页、目录、至少三章内容、图表编号、多级标题、正确的页眉页脚。导出为PDF并检查格式是否完美。
