# 第2章：向量的长相

## 故事引入

外卖业务上了轨道，小王准备给骑手们画一份配送地图。

他需要在地图上标出各个配送点的方位和距离。但问题来了：怎么把"往东3公里、往北4公里"这种描述，变成一个清晰、可量化的表达方式？

"我需要一种方式，把方向和距离写下来，而且一看就懂。"小王对着白板发呆。

这一章，就来解决这个实际问题——给向量"画个像"。

## 向量的坐标表示

前面说了，二维向量就是一对数：$(x, y)$。

在平面上怎么画呢？很简单：

1. 从原点 $(0, 0)$ 出发
2. 沿 x 轴（水平方向）走 $x$ 个单位
3. 沿 y 轴（竖直方向）走 $y$ 个单位
4. 画一个箭头，从原点指向终点

比如向量 $(3, 4)$：从原点出发，向右走 3，向上走 4，画个箭头。

这个箭头就是向量的"长相"。箭头的长度代表大小（距离），箭头的指向代表方向。

注意一个关键点：**向量只关心"走了多少、往哪走"，不关心你从哪出发。** 向量 $(3, 4)$ 可以从原点画，也可以从 $(1, 1)$ 画——只要长度和方向一样，就是同一个向量。就像快递单上的地址是固定的，不管快递员从哪个站点出发。

## 模长：向量有多"长"

向量的大小，数学上叫**模长**（也叫长度），记作 $|\vec{v}|$。

怎么算？初中数学派上用场了——**勾股定理**。

向量 $(x, y)$ 在平面上构成一个直角三角形：

- 水平边长度 = $x$
- 竖直边长度 = $y$
- 斜边长度 = 模长 $|\vec{v}|$

所以：

$$
|\vec{v}| = \sqrt{x^2 + y^2}
$$

拿小王的例子来说，向量 $(3, 4)$ 的模长：

$$
|\vec{v}| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5
$$

从店铺到配送点，直线距离 5 公里。3-4-5，经典的勾股数。

## 方向：向量朝哪指

知道了距离，还得知道方向。方向怎么量化？用**角度**。

向量与 x 轴正方向之间的夹角 $\theta$，可以用反正切函数算出来：

$$
\theta = \arctan\left(\frac{y}{x}\right)
$$

还是 $(3, 4)$ 这个例子：

$$
\theta = \arctan\left(\frac{4}{3}\right) \approx 53.13°
$$

意思是：这个向量指向东偏北约 53 度的方向。

注意：当 $x$ 为负数时，$\arctan$ 的结果需要调整（加 180°），因为计算器给出的角度可能落在错误的象限。编程时推荐用 `Math.atan2(y, x)` 而不是 `Math.atan(y/x)`，它会自动处理象限问题。

## 单位向量：方向指示器

有些时候，你只关心方向，不关心距离。这时候就需要**单位向量**——长度为 1 的向量。

单位向量就像一个"方向指示器"：它只告诉你"往哪走"，不告诉你"走多远"。

怎么把一个普通向量变成单位向量？除以它的模长就行了：

$$
\hat{v} = \frac{\vec{v}}{|\vec{v}|}
$$

比如 $(3, 4)$ 的单位向量：

$$
\hat{v} = \frac{(3, 4)}{5} = \left(\frac{3}{5}, \frac{4}{5}\right) = (0.6, 0.8)
$$

验证一下模长：$\sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64} = \sqrt{1} = 1$。完美。

单位向量通常用 $\hat{v}$（读作"v hat"）来表示，那个小帽子就是在说"我是单位向量"。

## 零向量：什么都没有

$(0, 0)$ 叫**零向量**，记作 $\vec{0}$。

它没有长度，也没有确定的方向。就像骑手原地不动——没走距离，也谈不上方向。

零向量在向量运算中扮演着类似"0"在普通算术中的角色，后面讲加法时会再遇到它。

## 一个接地气的类比

把向量的三个要素对应到日常导航：

| 向量概念 | 导航类比 |
| --- | --- |
| 坐标 $(x, y)$ | GPS 经纬度 |
| 模长 $ | \vec{v} | $ | 两点之间的直线距离 |
| 方向 $\theta$ | 指南针上的角度 |
| 单位向量 $\hat{v}$ | 只告诉你"往哪走"的路标 |
| 零向量 $\vec{0}$ | 原地不动 |

## 代码示例：用 JavaScript 计算模长

```javascript
// 计算向量的模长
function magnitude(v) {
    return Math.sqrt(v[0] * v[0] + v[1] * v[1]);
}

// 计算向量的方向（角度，单位：度）
function direction(v) {
    return Math.atan2(v[1], v[0]) * (180 / Math.PI);
}

// 求单位向量
function normalize(v) {
    const mag = magnitude(v);
    if (mag === 0) {
        throw new Error("零向量没有方向，无法归一化！");
    }
    return [v[0] / mag, v[1] / mag];
}

// 试试看
const v = [3, 4];
console.log("模长:", magnitude(v));         // 5
console.log("方向:", direction(v).toFixed(2), "°");  // 53.13°
console.log("单位向量:", normalize(v));       // [0.6, 0.8]
```

## 小结

- 向量 $(x, y)$ 在平面上画成一个从原点出发的箭头。
- **模长** $|\vec{v}| = \sqrt{x^2 + y^2}$，用勾股定理计算。
- **方向** $\theta = \arctan(y/x)$，编程时用 `atan2(y, x)` 更靠谱。
- **单位向量**长度为 1，只表示方向，等于原向量除以模长。
- **零向量** $(0, 0)$，没有大小也没有方向。

## 练习题

**第 1 题**：计算以下向量的模长：

(a) $(6, 8)$
(b) $(1, 1)$
(c) $(0, 5)$

**第 2 题**：向量 $(5, 5)$ 的方向是多少度？（精确到小数点后两位）

**第 3 题**：把向量 $(10, 0)$ 归一化，结果是什么？这个结果说明了什么？

---

## 练习题答案

**第 1 题答案**：

(a) $|(6, 8)| = \sqrt{36 + 64} = \sqrt{100} = 10$

(b) $|(1, 1)| = \sqrt{1 + 1} = \sqrt{2} \approx 1.414$

(c) $|(0, 5)| = \sqrt{0 + 25} = \sqrt{25} = 5$

**第 2 题答案**：

$\theta = \arctan(5/5) = \arctan(1) = 45.00°$

向量 $(5, 5)$ 指向东北方向，正好是 45 度。

**第 3 题答案**：

$(10, 0)$ 的模长是 10，归一化后得到 $(10/10, 0/10) = (1, 0)$。

这就是 x 轴正方向的单位向量。它说明：$(10, 0)$ 的方向就是"正东方向"，归一化后长度变为 1，方向不变。
