# 第2章：快编页——3分钟剪出第一条视频 ⚡

*周六下午，小陈在家附近的网红咖啡店拍了一堆素材：咖啡师拉花的特写、店内的氛围镜头、自己对着镜头说"这家店环境真不错"的自拍。回到家，他打开DaVinci Resolve，深吸一口气。*

*"上次打开剪辑页就被吓跑了，这次我先试试快编页吧。"*

*结果——3分钟后，他看着自己剪出来的第一条短视频，愣了三秒："等等，这就剪好了？也太快了吧？"*

*没错，快编页就是这么一个让你"还没准备好就已经剪完了"的神奇页面。*

## 2.1 快编页 vs 剪辑页：什么时候用哪个

DaVinci Resolve有两个剪辑页面，听起来很奇怪，其实它们各有用处：

| 对比项 | 快编页（Cut Page） | 剪辑页（Edit Page） |
| -------- | ------------------- | ------------------- |
| 设计目标 | 速度优先，快速出片 | 精度优先，精确控制 |
| 适合场景 | Vlog粗剪、短视频快剪 | 精细剪辑、多轨复杂编辑 |
| 时间线 | 双时间线设计（上方全局+下方细节） | 传统单时间线 |
| 操作方式 | 大量拖拽，操作简化 | 更多快捷键和精确控制 |
| 学习曲线 | 较低，新手友好 | 较高，但功能更全面 |

**什么时候用快编页？**

- 你想快速把素材拼在一起，看看整体效果
- 素材不多（10-20条以内），结构简单的Vlog
- 赶时间，想尽快导出分享

**什么时候用剪辑页？**

- 需要对画面做精确调整（精确到某一帧）
- 需要用到多轨道叠加、关键帧动画
- 素材多、结构复杂的长视频

**新手建议：** 先用快编页完成粗剪（搭好整体结构），再切到剪辑页做精修。但如果你只是剪一条简单的Vlog，快编页完全够用，不需要去剪辑页。

> 💡 **提示**：快编页和剪辑页操作的是同一个时间线，你在快编页做的所有修改，切到剪辑页都能看到。它们只是同一个东西的两种"视图"。

## 2.2 源素材浏览与标记入点出点

把素材导入媒体池后，在快编页的工作流程非常直观：

**快编页的"双时间线"设计：**

快编页有一个其他页面都没有的特色设计——它同时显示两条时间线：

- **上方时间线**（全局视图）：显示整条视频的缩略图全貌，你可以快速定位到视频的任意位置。就像一张地图的"鸟瞰视角"
- **下方时间线**（细节视图）：只显示当前区域附近的片段细节，方便你做精确操作。就像地图的"街景视角"

当你在下方时间线上操作时，上方时间线会用一个白色方框标出你当前的位置——让你始终知道自己在整条视频的什么地方。这个设计对新手非常友好，你永远都不会"迷失"在时间线里。

**浏览素材：**

1. 在快编页左上角，你会看到媒体池中的素材缩略图
2. 双击任意素材，它会在**源监视器**（Source Viewer，左侧画面窗口）中播放
3. 用鼠标在源监视器下方的时间条上拖动，可以快速浏览素材内容

**标记入点和出点：**

你的原始素材可能有30秒，但你只需要其中5秒最精彩的部分。这时候就需要"标记入点和出点"——简单说就是告诉软件"我只要从第X秒到第Y秒这一段"。

操作方法：

1. 在源监视器中播放素材，找到你想要的片段起点
2. 按 `I` 键标记**入点**（In Point）——就像在胶带上打了个起点标记
3. 继续播放，找到片段终点
4. 按 `O` 键标记**出点**（Out Point）

标记完成后，你会在源监视器的时间条上看到一段被高亮选中的区域——那就是你挑选出来的精华片段。

> 💡 **提示**：如果想清除入点/出点标记，按 `Alt + X`（Mac：`Option + X`）。如果想重新标记，直接再按 `I` 或 `O` 覆盖之前的标记就行。

## 2.3 拖入时间线：组建你的故事

标记好入点出点后，把素材放入时间线有三种方式：

**方式一：直接拖拽（最直观）**

- 从源监视器把画面直接拖到下方的时间线上

**方式二：使用按钮（快编页特色）**

- 源监视器下方有一排按钮：
  - **追加到时间线末尾**（Append）：把素材接到时间线最后面
  - **插入**（Insert）：在当前播放头位置插入，后面的素材自动后移
  - **覆盖**（Overwrite）：在当前播放头位置覆盖，替换掉原有内容

**方式三：直接从媒体池拖入**

- 如果不标记入点出点，直接把素材从媒体池拖到时间线上，整段素材会全部进入

**组建故事的建议顺序：**

把时间线想象成一条"故事跑道"——你的视频就是一列在这条跑道上跑的火车，每一节车厢就是一个镜头。按照你想讲故事的顺序，一个接一个地把镜头放上去：

1. 先放**开场镜头**（比如咖啡店外观）
2. 再放**主体内容**（咖啡师拉花、你品尝咖啡、环境特写）
3. 最后放**结尾镜头**（走出咖啡店、结束语）

## 2.4 基本剪切操作：分割、删除、移动片段

素材放上去之后，你大概率需要做一些修剪——某段太长了、某段位置不对、某段干脆不要了。

**分割片段（切断）：**

把播放头（时间线上的白色竖线）移到你想要切割的位置，然后：

- 按 `Ctrl + B`（Mac：`Cmd + B`）—— **刀片工具**，咔嚓一下把片段切成两段
- 或者按 `Ctrl + \`（Mac：`Cmd + \`）—— **剃刀工具**，效果类似

> 💡 **提示**：`Ctrl + B` 是最常用的快捷键之一，请牢记。它只在播放头的位置切一刀，不会删除任何东西。

**删除片段：**

1. 点击选中要删除的片段（选中后会有白色边框高亮）
2. 按 `Delete` 键删除——删除后，后面的片段会**自动补上来**（这叫"波纹删除" / Ripple Delete），不会留下空隙
3. 如果你想删除但**不自动补齐**（保留空隙），按 `Backspace` 键

**移动片段：**

- 直接拖拽片段到新位置
- 如果拖到两个片段之间，会自动"挤开"其他片段

**复制片段：**

- `Ctrl + C` 复制 → `Ctrl + V` 粘贴（Mac：`Cmd + C` → `Cmd + V`）

## 2.5 快速预览与回放控制

剪的过程中，你需要不断回放预览效果：

**基础回放：**

- `空格键`：播放 / 暂停
- `J`：倒放（按多次加速倒放）
- `K`：暂停
- `L`：正放（按多次加速正放）

> 💡 **提示**：`J-K-L` 是剪辑界的"黄金三键"，源自传统剪辑设备的操作习惯。很多专业剪辑师几乎不用空格键，而是全程用 JKL 来控制回放。新手可以先用空格键，等熟练了再过渡到JKL。

**跳转操作：**

- `Home`：跳到时间线开头
- `End`：跳到时间线结尾
- `↑` / `↓`（上下方向键）：跳到上一个/下一个编辑点（片段之间的接缝处）

**全屏预览：**

- `Ctrl + F`（Mac：`Cmd + F`）：全屏播放当前时间线

## 2.6 音频基础：调整音量、淡入淡出

视频不仅是画面，声音同样重要。快编页提供了基础的音频调整功能。

**调整片段音量：**

1. 选中时间线上的视频片段（视频和它自带的音频是连在一起的）
2. 在片段上方的音频波形区域，有一条白色横线——那是音量线
3. 上下拖动这条线，可以调高或调低音量

**添加淡入淡出：**

1. 选中片段后，把鼠标移到片段音频区域的左上角或右上角
2. 会出现一个白色的小三角标记（淡入手柄 / Fade Handle）
3. 向右拖动左上角的标记 → 音频淡入（声音从小到大）
4. 向左拖动右上角的标记 → 音频淡出（声音从大到小）

**添加背景音乐：**

1. 把音乐文件拖入媒体池
2. 再把音乐拖到时间线上——它会自动出现在**音频轨道**上（视频下方的轨道）
3. 通常要把背景音乐音量调低（大约在 -15dB 到 -20dB），让主要声音（比如说话声）能听清楚

> 💡 **提示**：一个简单但有效的Vlog音频策略是——原声（环境音+说话）保持正常音量，背景音乐降到 -18dB 左右。有人说话的时候音乐自动"让路"，没人说话的时候音乐"上来"。

**音量参考标准：**

不知道音量该调到多少？这里有几个参考值：

| 音频类型 | 推荐电平 | 听感 |
| --------- | --------- | ------ |
| 说话声/主音 | -6dB 到 -12dB | 清晰、舒适 |
| 背景音乐（有人说话时） | -18dB 到 -25dB | 能感受到但不会抢话 |
| 背景音乐（没人说话时） | -10dB 到 -15dB | 正常欣赏音量 |
| 环境音 | -12dB 到 -20dB | 有氛围感但不嘈杂 |

**新手常见音频错误：**

1. **背景音乐太响**：这是最常见的问题。你觉得音乐好听就开大了音量，结果说话声被盖住了。记住：Vlog的主角是人声（或画面），音乐是配角。
2. **完全不处理音频**：原始素材的音量可能忽大忽小（比如室外有风噪），不做任何调整就导出，观众听起来会很辛苦。
3. **音乐突然中断**：视频结束时音乐戛然而止，非常突兀。记得在结尾给音乐加一个2-3秒的淡出。

> 💡 **提示**：判断音频是否合适有一个"笨办法"——把音量调到你平时看视频的正常音量，然后闭上眼睛只听。如果背景音乐让你听不清说话内容，那就说明音乐太响了，需要再调低。

## 2.7 快速导出：一键分享你的第一条视频

剪完了！现在把视频导出成文件：

**方法一：快编页快速导出**

快编页右上角有一个"导出"区域，提供了简化的导出选项：

1. 选择预设格式（推荐选"H.264"或"H.265"）
2. 选择分辨率（1080p）
3. 点击"导出"按钮
4. 选择保存位置，等待渲染完成

**方法二：交付页导出（更多选项）**

1. 点击底部的"交付页"（Deliver）图标
2. 在左侧渲染设置中选择预设：
   - **YouTube预设**：适合上传YouTube/B站
   - **H.264 Master**：通用高质量MP4文件
3. 点击"添加到渲染队列"（Add to Render Queue）
4. 在右侧渲染队列中点击"全部渲染"（Render All）

**推荐导出参数：**

| 参数 | 推荐值 |
| ------ | -------- |
| 格式 | MP4 |
| 编码 | H.264 |
| 分辨率 | 1920×1080 |
| 帧率 | 与时间线一致（30fps） |
| 质量 | 自动/高质量（Automatic Best） |

渲染完成后，双击文件即可播放。恭喜你，你的第一条视频诞生了！🎉

## 2.8 实战：小陈用快编页3分钟剪出一条美食探店短视频

让我们跟着小陈完整走一遍流程。他的素材：

- 3段咖啡店外观和环境镜头
- 2段咖啡师拉花特写
- 1段自己对着镜头说话的自拍
- 1段品尝咖啡的反应

**步骤1：导入素材（30秒）**
把所有视频文件拖进媒体池。

**步骤2：浏览+标记（60秒）**
双击每段素材，快速浏览，用 `I` 和 `O` 标记出最精彩的5-8秒片段。不用纠结，选个差不多的就行。

**步骤3：拖入时间线（40秒）**
按照"外观 → 拉花特写 → 自拍说话 → 品尝反应 → 环境结尾"的顺序，依次把标记好的片段拖入时间线。

**步骤4：简单修剪（30秒）**
用 `Ctrl + B` 切掉多余的部分，按 `Delete` 删除不需要的片段。

**步骤5：加背景音乐（20秒）**
把一首轻快的Jazz音乐拖到音频轨道上，降低音量到 -18dB。

**步骤6：导出（等待渲染）**
快编页直接导出为H.264格式，1080p。

**总用时：大约3分钟（不含渲染等待时间）。**

小陈看着自己3分钟剪出来的视频，虽然还有些粗糙，但已经像模像样了。"原来剪视频也没那么难嘛！"他心想。

没错。快编页的意义就是让你**先做出一个能看的东西来**，建立信心。后面我们再慢慢学精细操作，让视频越来越好。
