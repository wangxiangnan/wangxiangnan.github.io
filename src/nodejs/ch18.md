# 第18章：认证与鉴权——JWT/OAuth2/Session

## 引言：门卫的艺术

想象你是一个高档俱乐部的门卫。你的工作分两部分：

1. **认证（Authentication）**："你是谁？" —— 验证来者的身份（查看身份证）
2. **鉴权（Authorization）**："你能干什么？" —— 验证来者的权限（VIP才能进VIP包间）

在Web开发中，这两件事是安全的基石。做得好，用户安心；做得不好，你的数据库可能某天早上就被掏空了。

本章我们将深入三大认证方案：Session/Cookie（传统方案）、JWT（现代方案）、OAuth2（第三方登录），并最终构建一套完整的用户认证系统。

## 18.1 Session + Cookie方案

### 18.1.1 工作原理

```
Session认证流程：
1. 用户提交用户名+密码
2. 服务器验证通过后，创建Session（存在服务器内存/Redis/数据库中）
3. 服务器把SessionID通过Set-Cookie返回给浏览器
4. 浏览器后续每次请求都自动带上Cookie中的SessionID
5. 服务器收到请求后，用SessionID查找对应的Session数据
6. 如果找到→已认证；找不到/过期→未认证

类比：你去酒店办理入住（登录），前台给你一张房卡（SessionID）。
之后你拿着房卡就能进你的房间（访问资源），不用每次都出示身份证。
房卡信息存在酒店系统里（服务器），丢了或过期了就要重新办理。
```

### 18.1.2 express-session实战

```typescript
import express from 'express';
import session from 'express-session';
import RedisStore from 'connect-redis';
import { createClient } from 'redis';
import crypto from 'node:crypto';

const app = express();
app.use(express.json());

// Redis客户端（生产环境）
const redisClient = createClient({ url: 'redis://localhost:6379' });
await redisClient.connect();

// Session配置
app.use(session({
  // Session存储（默认是MemoryStore，不适合生产！）
  store: new RedisStore({ client: redisClient }),

  // Session ID签名密钥
  secret: process.env.SESSION_SECRET || 'change-me-in-production',

  // Session名称（Cookie名）
  name: 'sid', // 默认是'connect.sid'，建议改掉

  // 是否每次请求都重新保存session
  resave: false,

  // 是否保存未初始化的session
  saveUninitialized: false,

  cookie: {
    httpOnly: true,     // JS无法读取（防XSS）
    secure: process.env.NODE_ENV === 'production', // HTTPS only
    sameSite: 'lax',    // CSRF防护
    maxAge: 24 * 60 * 60 * 1000, // 24小时
  },
}));

// 模拟用户数据库
const users = new Map([
  ['alice', { id: '1', username: 'alice', password: 'hashed_password_1', role: 'admin' }],
  ['bob', { id: '2', username: 'bob', password: 'hashed_password_2', role: 'user' }],
]);

// 登录
app.post('/login', (req, res) => {
  const { username, password } = req.body;
  const user = users.get(username);

  if (!user || user.password !== `hashed_${password}`) {
    return res.status(401).json({ error: 'Invalid credentials' });
  }

  // 登录成功，创建session
  req.session.userId = user.id;
  req.session.username = user.username;
  req.session.role = user.role;
  req.session.loginAt = Date.now();

  // regenerate session ID防止session fixation攻击
  req.session.regenerate((err) => {
    if (err) return res.status(500).json({ error: 'Session error' });
    req.session.userId = user.id;
    req.session.username = user.username;
    req.session.role = user.role;
    res.json({ message: 'Login successful', user: { id: user.id, username: user.username } });
  });
});

// 认证中间件
function requireAuth(req: express.Request, res: express.Response, next: express.NextFunction) {
  if (!req.session.userId) {
    return res.status(401).json({ error: 'Please login first' });
  }
  next();
}

// 鉴权中间件
function requireRole(...roles: string[]) {
  return (req: express.Request, res: express.Response, next: express.NextFunction) => {
    if (!roles.includes(req.session.role)) {
      return res.status(403).json({ error: 'Insufficient permissions' });
    }
    next();
  };
}

// 受保护的路由
app.get('/profile', requireAuth, (req, res) => {
  res.json({
    userId: req.session.userId,
    username: req.session.username,
    role: req.session.role,
  });
});

// 管理员路由
app.get('/admin', requireAuth, requireRole('admin'), (req, res) => {
  res.json({ message: 'Welcome, admin!' });
});

// 登出
app.post('/logout', (req, res) => {
  req.session.destroy((err) => {
    if (err) return res.status(500).json({ error: 'Logout failed' });
    res.clearCookie('sid');
    res.json({ message: 'Logged out' });
  });
});

app.listen(3000);
```

### 18.1.3 CSRF防护

```typescript
import express from 'express';
import crypto from 'node:crypto';

const app = express();

// CSRF Token中间件
function csrfProtection(req: express.Request, res: express.Response, next: express.NextFunction) {
  // GET请求不需要CSRF验证，但需要提供Token
  if (req.method === 'GET') {
    // 生成CSRF Token并存入session
    if (!req.session.csrfToken) {
      req.session.csrfToken = crypto.randomBytes(32).toString('hex');
    }
    res.locals.csrfToken = req.session.csrfToken;
    return next();
  }

  // 非GET请求需要验证CSRF Token
  const token = req.headers['x-csrf-token'] || req.body._csrf;
  if (!token || token !== req.session.csrfToken) {
    return res.status(403).json({ error: 'Invalid CSRF token' });
  }
  next();
}

app.use(csrfProtection);

// 获取CSRF Token的端点
app.get('/csrf-token', (req, res) => {
  res.json({ csrfToken: res.locals.csrfToken });
});

// 前端使用示例：
// 1. 先GET /csrf-token 获取token
// 2. 后续POST/PUT/DELETE请求带上 X-CSRF-Token header
```

## 18.2 JWT方案

### 18.2.1 JWT结构解析

JWT（JSON Web Token）由三部分组成，用点号分隔：

```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.    ← Header
eyJ1c2VySWQiOiIxIiwicm9sZSI6ImFkbWluIn0.  ← Payload
SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c  ← Signature

Header (Base64URL解码后):
{
  "alg": "HS256",    // 签名算法
  "typ": "JWT"       // 令牌类型
}

Payload (Base64URL解码后):
{
  "userId": "1",     // 自定义数据
  "role": "admin",
  "iat": 1234567890, // 签发时间
  "exp": 1234571490  // 过期时间
}

Signature:
HMAC-SHA256(
  base64UrlEncode(header) + "." + base64UrlEncode(payload),
  secret
)
```

**重要**：JWT的Header和Payload只是Base64编码（不是加密！），任何人都能解码看到内容。Signature的作用是**防篡改**，不是**防查看**。所以永远不要把敏感信息（密码、信用卡号）放在JWT里。

### 18.2.2 Access Token + Refresh Token

```typescript
import express from 'express';
import jwt from 'jsonwebtoken';
import crypto from 'node:crypto';

const app = express();
app.use(express.json());

// 配置
const ACCESS_TOKEN_SECRET = process.env.ACCESS_SECRET || 'access-secret';
const REFRESH_TOKEN_SECRET = process.env.REFRESH_SECRET || 'refresh-secret';
const ACCESS_TOKEN_EXPIRY = '15m';   // 短寿命
const REFRESH_TOKEN_EXPIRY = '7d';   // 长寿命

// 模拟数据
const users = new Map([
  ['1', { id: '1', username: 'alice', password: 'password123', role: 'admin' }],
]);

// Refresh Token存储（实际用Redis）
const refreshTokens = new Set<string>();

// 生成Token对
function generateTokens(userId: string, role: string) {
  const accessToken = jwt.sign(
    { userId, role },
    ACCESS_TOKEN_SECRET,
    { expiresIn: ACCESS_TOKEN_EXPIRY }
  );

  const refreshToken = jwt.sign(
    { userId, tokenId: crypto.randomUUID() },
    REFRESH_TOKEN_SECRET,
    { expiresIn: REFRESH_TOKEN_EXPIRY }
  );

  refreshTokens.add(refreshToken);

  return { accessToken, refreshToken };
}

// 登录
app.post('/auth/login', (req, res) => {
  const { username, password } = req.body;

  const user = Array.from(users.values()).find(
    (u) => u.username === username && u.password === password
  );

  if (!user) {
    return res.status(401).json({ error: 'Invalid credentials' });
  }

  const tokens = generateTokens(user.id, user.role);

  // Refresh Token放在httpOnly cookie中（最安全）
  res.cookie('refreshToken', tokens.refreshToken, {
    httpOnly: true,
    secure: true,
    sameSite: 'strict',
    maxAge: 7 * 24 * 60 * 60 * 1000,
    path: '/auth/refresh', // 只在refresh端点发送
  });

  res.json({
    accessToken: tokens.accessToken,
    expiresIn: 900, // 15分钟（秒）
  });
});

// Token刷新
app.post('/auth/refresh', (req, res) => {
  const refreshToken = req.cookies?.refreshToken || req.body.refreshToken;

  if (!refreshToken || !refreshTokens.has(refreshToken)) {
    return res.status(401).json({ error: 'Invalid refresh token' });
  }

  try {
    const payload = jwt.verify(refreshToken, REFRESH_TOKEN_SECRET) as any;

    // 旋转Refresh Token（用过的立即作废）
    refreshTokens.delete(refreshToken);

    const user = users.get(payload.userId);
    if (!user) {
      return res.status(401).json({ error: 'User not found' });
    }

    const newTokens = generateTokens(user.id, user.role);

    res.cookie('refreshToken', newTokens.refreshToken, {
      httpOnly: true,
      secure: true,
      sameSite: 'strict',
      maxAge: 7 * 24 * 60 * 60 * 1000,
      path: '/auth/refresh',
    });

    res.json({
      accessToken: newTokens.accessToken,
      expiresIn: 900,
    });
  } catch {
    // Refresh Token过期或无效
    refreshTokens.delete(refreshToken);
    res.status(401).json({ error: 'Token expired, please login again' });
  }
});

// Access Token验证中间件
function authenticateToken(req: express.Request, res: express.Response, next: express.NextFunction) {
  const authHeader = req.headers.authorization;
  const token = authHeader?.startsWith('Bearer ') ? authHeader.slice(7) : null;

  if (!token) {
    return res.status(401).json({ error: 'Access token required' });
  }

  try {
    const payload = jwt.verify(token, ACCESS_TOKEN_SECRET) as { userId: string; role: string };
    (req as any).user = payload;
    next();
  } catch (err: any) {
    if (err.name === 'TokenExpiredError') {
      return res.status(401).json({ error: 'Token expired', code: 'TOKEN_EXPIRED' });
    }
    res.status(401).json({ error: 'Invalid token' });
  }
}

// 受保护的路由
app.get('/api/profile', authenticateToken, (req, res) => {
  res.json({ user: (req as any).user });
});

// 登出（撤销Refresh Token）
app.post('/auth/logout', (req, res) => {
  const refreshToken = req.cookies?.refreshToken;
  if (refreshToken) {
    refreshTokens.delete(refreshToken);
  }
  res.clearCookie('refreshToken', { path: '/auth/refresh' });
  res.json({ message: 'Logged out' });
});

app.listen(3000);
```

### 18.2.3 JWT的优势与局限

```
优势：
✅ 无状态 → 服务器不需要存储session，天然支持分布式
✅ 跨域友好 → 放在Authorization header中，不受cookie的域限制
✅ 自包含 → Token本身携带用户信息，减少数据库查询
✅ 移动端友好 → 不依赖cookie机制

局限：
❌ 无法主动失效 → 签发后在过期前无法撤销（除非维护黑名单）
❌ Token体积大 → 比Session ID（一个UUID）大得多
❌ 安全风险 → 存在localStorage容易被XSS窃取
❌ 续期复杂 → 需要Refresh Token机制

最佳实践：
- Access Token短寿命（15分钟），Refresh Token长寿命（7天）
- Access Token存内存，Refresh Token存httpOnly cookie
- 实现Token旋转（每次refresh后旧token失效）
- 敏感操作要求重新认证
```

## 18.3 OAuth 2.0

### 18.3.1 四种授权模式

```
1. 授权码模式（Authorization Code）→ 最安全，服务端应用首选
   用户→应用→授权服务器→用户授权→授权码→应用→用code换token

2. 隐式模式（Implicit）→ 已废弃，不推荐
   用户→应用→授权服务器→直接返回token（不安全）

3. 密码模式（Resource Owner Password）→ 仅限受信任应用
   用户把账密直接给应用→应用用账密换token

4. 客户端凭证模式（Client Credentials）→ 服务间通信
   应用直接用自己的凭证换token，不涉及用户
```

### 18.3.2 实战：GitHub OAuth登录

```typescript
import express from 'express';
import crypto from 'node:crypto';

const app = express();

// GitHub OAuth配置
const GITHUB_CLIENT_ID = process.env.GITHUB_CLIENT_ID!;
const GITHUB_CLIENT_SECRET = process.env.GITHUB_CLIENT_SECRET!;
const CALLBACK_URL = 'http://localhost:3000/auth/github/callback';

// 步骤1：重定向用户到GitHub授权页
app.get('/auth/github', (req, res) => {
  const state = crypto.randomBytes(16).toString('hex');
  // 将state存入session防CSRF
  req.session.oauthState = state;

  const params = new URLSearchParams({
    client_id: GITHUB_CLIENT_ID,
    redirect_uri: CALLBACK_URL,
    scope: 'read:user user:email',
    state,
  });

  res.redirect(`https://github.com/login/oauth/authorize?${params}`);
});

// 步骤2：处理GitHub回调
app.get('/auth/github/callback', async (req, res) => {
  const { code, state } = req.query as { code: string; state: string };

  // 验证state防CSRF
  if (state !== req.session.oauthState) {
    return res.status(403).json({ error: 'Invalid state parameter' });
  }
  delete req.session.oauthState;

  try {
    // 步骤3：用授权码换取Access Token
    const tokenResponse = await fetch('https://github.com/login/oauth/access_token', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Accept': 'application/json',
      },
      body: JSON.stringify({
        client_id: GITHUB_CLIENT_ID,
        client_secret: GITHUB_CLIENT_SECRET,
        code,
        redirect_uri: CALLBACK_URL,
      }),
    });

    const tokenData = await tokenResponse.json() as any;
    const accessToken = tokenData.access_token;

    // 步骤4：用Access Token获取用户信息
    const userResponse = await fetch('https://api.github.com/user', {
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Accept': 'application/vnd.github.v3+json',
      },
    });

    const githubUser = await userResponse.json() as any;

    // 步骤5：查找或创建本地用户
    let user = await findUserByGithubId(githubUser.id);
    if (!user) {
      user = await createUser({
        githubId: githubUser.id,
        username: githubUser.login,
        email: githubUser.email,
        avatar: githubUser.avatar_url,
      });
    }

    // 步骤6：颁发自己的JWT
    const jwt = generateTokens(user.id, user.role);

    // 重定向到前端，带上token
    res.redirect(`http://localhost:5173/auth/callback?token=${jwt.accessToken}`);
  } catch (error) {
    console.error('OAuth error:', error);
    res.status(500).json({ error: 'OAuth authentication failed' });
  }
});

// 辅助函数（模拟）
async function findUserByGithubId(githubId: string) {
  return null; // 模拟
}
async function createUser(data: any) {
  return { id: crypto.randomUUID(), role: 'user', ...data };
}
function generateTokens(userId: string, role: string) {
  return { accessToken: 'mock-jwt-token' };
}

app.listen(3000);
```

## 18.4 Passport.js策略模式

Passport.js通过"策略"模式支持500+种认证方式：

```typescript
import express from 'express';
import passport from 'passport';
import { Strategy as LocalStrategy } from 'passport-local';
import { Strategy as JwtStrategy, ExtractJwt } from 'passport-jwt';
import { Strategy as GitHubStrategy } from 'passport-github2';

const app = express();

// 本地策略（用户名+密码）
passport.use(new LocalStrategy(
  { usernameField: 'email', passwordField: 'password' },
  async (email, password, done) => {
    try {
      const user = await findUserByEmail(email);
      if (!user) return done(null, false, { message: 'User not found' });

      const isValid = await verifyPassword(password, user.passwordHash);
      if (!isValid) return done(null, false, { message: 'Wrong password' });

      return done(null, user);
    } catch (error) {
      return done(error);
    }
  }
));

// JWT策略
passport.use(new JwtStrategy(
  {
    jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
    secretOrKey: 'jwt-secret',
  },
  async (payload, done) => {
    try {
      const user = await findUserById(payload.userId);
      if (!user) return done(null, false);
      return done(null, user);
    } catch (error) {
      return done(error);
    }
  }
));

// GitHub策略
passport.use(new GitHubStrategy(
  {
    clientID: process.env.GITHUB_CLIENT_ID!,
    clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    callbackURL: '/auth/github/callback',
  },
  async (accessToken: string, refreshToken: string, profile: any, done: any) => {
    try {
      let user = await findUserByGithubId(profile.id);
      if (!user) {
        user = await createUser({
          githubId: profile.id,
          username: profile.username,
          email: profile.emails?.[0]?.value,
        });
      }
      return done(null, user);
    } catch (error) {
      return done(error);
    }
  }
));

// 使用策略
app.post('/auth/login',
  passport.authenticate('local', { session: false }),
  (req, res) => {
    const token = generateJWT(req.user as any);
    res.json({ token });
  }
);

app.get('/api/protected',
  passport.authenticate('jwt', { session: false }),
  (req, res) => {
    res.json({ user: req.user });
  }
);

// 模拟函数
async function findUserByEmail(email: string) { return null; }
async function findUserById(id: string) { return null; }
async function findUserByGithubId(id: string) { return null; }
async function createUser(data: any) { return data; }
async function verifyPassword(p: string, h: string) { return true; }
function generateJWT(user: any) { return 'token'; }

app.listen(3000);
```

## 18.5 RBAC权限模型设计

```typescript
// RBAC (Role-Based Access Control) 实现

// 权限定义
const PERMISSIONS = {
  // 文章相关
  'post:create': '创建文章',
  'post:read': '查看文章',
  'post:update': '编辑文章',
  'post:delete': '删除文章',
  'post:publish': '发布文章',

  // 用户管理
  'user:list': '查看用户列表',
  'user:create': '创建用户',
  'user:update': '编辑用户',
  'user:delete': '删除用户',

  // 系统管理
  'system:settings': '系统设置',
  'system:logs': '查看日志',
} as const;

type Permission = keyof typeof PERMISSIONS;

// 角色定义
interface Role {
  name: string;
  permissions: Permission[];
  inherits?: string[]; // 角色继承
}

const ROLES: Record<string, Role> = {
  viewer: {
    name: '访客',
    permissions: ['post:read'],
  },
  author: {
    name: '作者',
    permissions: ['post:create', 'post:update'],
    inherits: ['viewer'], // 继承viewer的权限
  },
  editor: {
    name: '编辑',
    permissions: ['post:publish', 'post:delete'],
    inherits: ['author'], // 继承author的权限
  },
  admin: {
    name: '管理员',
    permissions: ['user:list', 'user:create', 'user:update', 'user:delete', 'system:settings', 'system:logs'],
    inherits: ['editor'],
  },
};

// 解析角色的所有权限（包含继承）
function resolvePermissions(roleName: string, visited = new Set<string>()): Permission[] {
  if (visited.has(roleName)) return []; // 防止循环继承
  visited.add(roleName);

  const role = ROLES[roleName];
  if (!role) return [];

  const permissions = [...role.permissions];

  if (role.inherits) {
    for (const parentRole of role.inherits) {
      permissions.push(...resolvePermissions(parentRole, visited));
    }
  }

  return [...new Set(permissions)]; // 去重
}

// 权限检查中间件
import express from 'express';

function requirePermission(...requiredPermissions: Permission[]) {
  return (req: express.Request, res: express.Response, next: express.NextFunction) => {
    const user = (req as any).user;
    if (!user) {
      return res.status(401).json({ error: 'Unauthorized' });
    }

    const userPermissions = resolvePermissions(user.role);
    const hasPermission = requiredPermissions.every(
      (perm) => userPermissions.includes(perm)
    );

    if (!hasPermission) {
      return res.status(403).json({
        error: 'Forbidden',
        required: requiredPermissions,
        userRole: user.role,
      });
    }

    next();
  };
}

// 使用
const app = express();

app.delete('/api/posts/:id',
  authenticateToken, // 先认证
  requirePermission('post:delete'), // 再鉴权
  async (req, res) => {
    // 有删除权限才能到这里
    res.json({ message: 'Post deleted' });
  }
);

app.get('/api/admin/users',
  authenticateToken,
  requirePermission('user:list'),
  async (req, res) => {
    res.json({ users: [] });
  }
);

function authenticateToken(req: any, res: any, next: any) { next(); }
```

## 18.6 实战：完整的用户认证系统

```typescript
import express from 'express';
import jwt from 'jsonwebtoken';
import bcrypt from 'bcrypt';
import crypto from 'node:crypto';

const app = express();
app.use(express.json());

// ============ 配置 ============
const config = {
  accessTokenSecret: process.env.JWT_ACCESS_SECRET || 'access-secret-key',
  refreshTokenSecret: process.env.JWT_REFRESH_SECRET || 'refresh-secret-key',
  accessTokenExpiry: '15m',
  refreshTokenExpiry: '7d',
  bcryptSaltRounds: 12,
};

// ============ 模拟数据库 ============
interface User {
  id: string;
  email: string;
  username: string;
  passwordHash: string;
  role: 'user' | 'admin';
  isActive: boolean;
  createdAt: Date;
}

interface RefreshTokenRecord {
  token: string;
  userId: string;
  expiresAt: Date;
  createdAt: Date;
}

const usersDB = new Map<string, User>();
const refreshTokensDB = new Map<string, RefreshTokenRecord>();

// ============ 工具函数 ============
function generateTokenPair(user: User) {
  const accessToken = jwt.sign(
    { userId: user.id, role: user.role, email: user.email },
    config.accessTokenSecret,
    { expiresIn: config.accessTokenExpiry }
  );

  const refreshToken = crypto.randomBytes(40).toString('hex');
  const expiresAt = new Date(Date.now() + 7 * 24 * 60 * 60 * 1000);

  refreshTokensDB.set(refreshToken, {
    token: refreshToken,
    userId: user.id,
    expiresAt,
    createdAt: new Date(),
  });

  return { accessToken, refreshToken, expiresIn: 900 };
}

// ============ 认证中间件 ============
interface AuthRequest extends express.Request {
  user?: { userId: string; role: string; email: string };
}

function authenticate(req: AuthRequest, res: express.Response, next: express.NextFunction) {
  const header = req.headers.authorization;
  if (!header?.startsWith('Bearer ')) {
    return res.status(401).json({ success: false, error: 'Missing authorization header' });
  }

  const token = header.slice(7);
  try {
    const payload = jwt.verify(token, config.accessTokenSecret) as any;
    req.user = payload;
    next();
  } catch (err: any) {
    if (err.name === 'TokenExpiredError') {
      return res.status(401).json({ success: false, error: 'Token expired', code: 'TOKEN_EXPIRED' });
    }
    return res.status(401).json({ success: false, error: 'Invalid token' });
  }
}

// ============ 路由 ============

// 注册
app.post('/auth/register', async (req, res) => {
  const { email, username, password } = req.body;

  // 验证
  if (!email || !username || !password) {
    return res.status(400).json({ success: false, error: 'All fields are required' });
  }
  if (password.length < 8) {
    return res.status(400).json({ success: false, error: 'Password must be at least 8 characters' });
  }

  // 检查重复
  const existing = Array.from(usersDB.values()).find((u) => u.email === email);
  if (existing) {
    return res.status(409).json({ success: false, error: 'Email already registered' });
  }

  // 创建用户
  const id = crypto.randomUUID();
  const passwordHash = await bcrypt.hash(password, config.bcryptSaltRounds);

  const user: User = {
    id,
    email,
    username,
    passwordHash,
    role: 'user',
    isActive: true,
    createdAt: new Date(),
  };

  usersDB.set(id, user);

  // 自动登录，返回tokens
  const tokens = generateTokenPair(user);

  res.status(201).json({
    success: true,
    data: {
      user: { id: user.id, email: user.email, username: user.username, role: user.role },
      ...tokens,
    },
  });
});

// 登录
app.post('/auth/login', async (req, res) => {
  const { email, password } = req.body;

  const user = Array.from(usersDB.values()).find((u) => u.email === email);
  if (!user) {
    return res.status(401).json({ success: false, error: 'Invalid email or password' });
  }

  if (!user.isActive) {
    return res.status(403).json({ success: false, error: 'Account is disabled' });
  }

  const isPasswordValid = await bcrypt.compare(password, user.passwordHash);
  if (!isPasswordValid) {
    return res.status(401).json({ success: false, error: 'Invalid email or password' });
  }

  const tokens = generateTokenPair(user);

  res.json({
    success: true,
    data: {
      user: { id: user.id, email: user.email, username: user.username, role: user.role },
      ...tokens,
    },
  });
});

// Token刷新
app.post('/auth/refresh', (req, res) => {
  const { refreshToken } = req.body;

  if (!refreshToken) {
    return res.status(400).json({ success: false, error: 'Refresh token required' });
  }

  const record = refreshTokensDB.get(refreshToken);
  if (!record) {
    return res.status(401).json({ success: false, error: 'Invalid refresh token' });
  }

  if (record.expiresAt < new Date()) {
    refreshTokensDB.delete(refreshToken);
    return res.status(401).json({ success: false, error: 'Refresh token expired' });
  }

  // 旋转token
  refreshTokensDB.delete(refreshToken);

  const user = usersDB.get(record.userId);
  if (!user || !user.isActive) {
    return res.status(401).json({ success: false, error: 'User not found or disabled' });
  }

  const tokens = generateTokenPair(user);

  res.json({ success: true, data: tokens });
});

// 获取当前用户信息
app.get('/auth/me', authenticate, (req: AuthRequest, res) => {
  const user = usersDB.get(req.user!.userId);
  if (!user) {
    return res.status(404).json({ success: false, error: 'User not found' });
  }

  res.json({
    success: true,
    data: {
      id: user.id,
      email: user.email,
      username: user.username,
      role: user.role,
      createdAt: user.createdAt,
    },
  });
});

// 修改密码
app.post('/auth/change-password', authenticate, async (req: AuthRequest, res) => {
  const { currentPassword, newPassword } = req.body;
  const user = usersDB.get(req.user!.userId)!;

  const isValid = await bcrypt.compare(currentPassword, user.passwordHash);
  if (!isValid) {
    return res.status(400).json({ success: false, error: 'Current password is incorrect' });
  }

  user.passwordHash = await bcrypt.hash(newPassword, config.bcryptSaltRounds);

  // 撤销所有refresh tokens
  for (const [key, record] of refreshTokensDB) {
    if (record.userId === user.id) {
      refreshTokensDB.delete(key);
    }
  }

  res.json({ success: true, message: 'Password changed, please login again' });
});

// 登出
app.post('/auth/logout', authenticate, (req: AuthRequest, res) => {
  const { refreshToken } = req.body;
  if (refreshToken) {
    refreshTokensDB.delete(refreshToken);
  }
  res.json({ success: true, message: 'Logged out' });
});

// 登出所有设备
app.post('/auth/logout-all', authenticate, (req: AuthRequest, res) => {
  for (const [key, record] of refreshTokensDB) {
    if (record.userId === req.user!.userId) {
      refreshTokensDB.delete(key);
    }
  }
  res.json({ success: true, message: 'Logged out from all devices' });
});

app.listen(3000, () => {
  console.log('Auth server running on http://localhost:3000');
});
```

## 18.7 常见坑点

1. **JWT存在localStorage**：容易被XSS攻击窃取。Access Token存内存变量，Refresh Token存httpOnly cookie。
2. **不验证JWT的算法**：要指定允许的算法 `{ algorithms: ['HS256'] }`，否则可能被 `alg: none` 攻击。
3. **密码明文存储**：永远使用bcrypt/argon2，永远不要用MD5/SHA-256。
4. **Session不设过期时间**：内存会持续增长直到OOM。
5. **OAuth state参数不验证**：导致CSRF攻击。
6. **Refresh Token不旋转**：泄露后一直可用直到过期。

```typescript
// 安全的JWT验证
const payload = jwt.verify(token, secret, {
  algorithms: ['HS256'], // 明确指定算法！
  issuer: 'my-app',     // 验证签发者
  audience: 'my-api',   // 验证受众
});

// 密码哈希（推荐bcrypt或argon2）
import bcrypt from 'bcrypt';

const hash = await bcrypt.hash('password123', 12); // 12轮加盐
const isMatch = await bcrypt.compare('password123', hash);
```

## 18.8 本章小结

| 方案 | 适用场景 | 优势 | 劣势 |
| ------ | --------- | ------ | ------ |
| Session+Cookie | 传统Web应用 | 可主动失效、安全 | 有状态、不适合分布式 |
| JWT | SPA、移动端、微服务 | 无状态、跨域 | 无法主动失效、Token大 |
| OAuth 2.0 | 第三方登录、API授权 | 不暴露密码、标准化 | 流程复杂 |

**黄金法则**：

- 认证不只是"能不能登录"的问题，是整个系统安全的基石
- 永远不要自己发明加密算法或认证协议
- 安全性和用户体验往往是跷跷板，找到适合你业务的平衡点
