## 1.1 Word是什么？和记事本、在线文档的区别

很多人觉得Word就是"高级版记事本"，这就好比觉得奶茶和白开水都是"喝的"——本质上没错，但体验天差地别。

我们来做个对比：

| 特性 | 记事本（Notepad） | Word | 在线文档（如腾讯文档） |
| ------ | ------------------ | ------ | --------------------- |
| 文字格式 | ❌ 纯文本，无格式 | ✅ 丰富的字体、颜色、大小 | ✅ 基本格式支持 |
| 排版能力 | ❌ 无 | ✅ 专业级排版 | ⚠️ 基础排版 |
| 插入元素 | ❌ 无 | ✅ 图片、表格、图表、目录等 | ⚠️ 部分支持 |
| 打印控制 | ❌ 几乎没有 | ✅ 精细的打印设置 | ⚠️ 基础设置 |
| 离线使用 | ✅ 随时可用 | ✅ 随时可用 | ❌ 需要网络 |
| 文件体积 | 极小 | 较小 | 无本地文件 |

**简单总结**：记事本适合记个电话号码，在线文档适合多人协作，而Word适合制作正式、专业、需要打印的文档——比如小王的员工手册、供应商合同、营销方案。

> 💡 **提示**：如果你之前一直用记事本写东西，切换到Word可能会觉得"按钮太多了"。别慌，80%的工作只需要20%的功能，我们这本教程就是帮你把那20%吃透。

## 1.2 界面导览：功能区、编辑区、状态栏、标尺

第一次打开Word，很多人会被密密麻麻的按钮吓到。别怕，Word的界面其实就像你的书桌，分成几个明确的区域：

**① 功能区（Ribbon）——你的"工具箱"**

Word顶部那一排排按钮，就是功能区。它按功能分成了多个选项卡：

- **开始**：最常用的功能都在这——字体、字号、加粗、对齐、样式
- **插入**：往文档里"塞东西"——图片、表格、页码、形状
- **设计**：文档整体风格——主题、页面背景
- **布局**：页面相关——纸张大小、页边距、分栏
- **引用**：学术功能——目录、脚注、引文
- **审阅**：校对和协作——拼写检查、批注、修订
- **视图**：调整显示方式——缩放、标尺、多窗口

就像小王的奶茶店操作台：左边放杯子，中间放茶底，右边放配料——每个区域各司其职，熟练之后闭着眼都能找到。

**② 编辑区——你的"白纸"**

中间那块白色区域就是编辑区，你所有的文字都在这里输入和显示。它模拟的就是一张纸的样子，所以你看到的排版效果基本就是打印出来的效果（这叫"所见即所得"）。

**③ 标尺——你的"刻度尺"**

编辑区上方和左侧有标尺（如果没看到，去 `视图 > 标尺` 打勾即可）。标尺上有几个重要的小滑块，用来控制缩进——后面排版章节会详细讲。现在先知道它存在就好。

**④ 状态栏——你的"仪表盘"**

Word最底部那条窄条就是状态栏，上面显示着：

- 当前页码 / 总页数
- 字数统计（写报告凑字数的时候特别有用，别说我没告诉你）
- 语言设置
- 视图切换按钮和缩放滑块

> 💡 **提示**：右键点击状态栏，可以自定义显示哪些信息。建议至少保留"页码""字数""缩放"这三项。

## 1.3 核心概念：文档、段落、字符——三个层级

这个概念非常重要，理解了它，后面的排版操作会变得顺理成章。

Word中的内容按**三个层级**组织：

```
文档（Document）
  └── 段落（Paragraph）
        └── 字符（Character）
```

- **字符**：最小单位，一个汉字、一个字母、一个标点都算一个字符。你设置的字体、字号、颜色，都是作用在字符上的。
- **段落**：从开头到按下 `Enter` 键为止的所有内容就是一个段落。你设置的对齐方式、行距、缩进，都是作用在段落上的。
- **文档**：整个文件就是一个文档，包含若干段落。页面设置（纸张大小、页边距等）作用在文档（或"节"）上。

**为什么要理解这个？** 因为很多人排版出问题，就是把层级搞混了。比如想调整某一行文字的大小，结果只选中了几个字——其他同行文字没变，看着更乱了。正确做法是想清楚：你要改的是字符级别（几个字的颜色）还是段落级别（整段文字的对齐）还是文档级别（整页的页边距）。

> 💡 **提示**：在Word里，"回车"（Enter）产生的叫**段落标记**（¶），它标志着一个段落的结束。这个标记不只是"换行"那么简单，它还保存着这个段落的所有格式信息。所以千万不要用"删掉段落标记再手动敲空格"的方式来合并段落——格式会丢光的！

## 1.4 新建、保存、打开文档

这三个操作看似简单，但有几个坑必须说清楚。

**新建文档**

- 方法一：`文件 > 新建 > 空白文档`
- 方法二：快捷键 `Ctrl + N`
- 方法三：启动Word时选择模板

> 💡 **提示**：Word自带很多模板（报告、简历、信函等），但初学者建议先用空白文档练手，等熟悉了格式设置后再用模板，否则模板里的格式你改不动会很崩溃。

**保存文档**

- 方法一：`文件 > 保存` 或 `文件 > 另存为`
- 方法二：快捷键 `Ctrl + S`（建议养成每10分钟按一次的习惯）
- 方法三：快速访问工具栏上的软盘图标

**关于 .docx 和 .doc 的区别**：

| 格式 | 说明 | 建议使用场景 |
| ------ | ------ | ------------ |
| .docx | Word 2007及以后的默认格式，文件更小、更安全 | ✅ 日常使用首选 |
| .doc | Word 97-2003的老格式，文件较大 | ⚠️ 仅在与老版本软件兼容时使用 |
| .pdf | 不可编辑的固定格式 | ✅ 发给别人看、打印时 |
| .txt | 纯文本，丢失所有格式 | ❌ 不推荐用于正式文档 |

> 💡 **提示**：小王的供应商发来一份 `.doc` 格式的合同模板，小王打开后应该第一时间 `另存为` `.docx` 格式，这样才能用上Word的新功能。别在老格式文件上花大力气排版——事倍功半。

**打开文档**

- 方法一：`文件 > 打开 > 浏览`
- 方法二：快捷键 `Ctrl + O`
- 方法三：直接双击 `.docx` 文件

## 1.5 视图模式：五种"看法"

Word提供了5种视图模式，位于 `视图` 选项卡，也可以在状态栏右下角快速切换：

**① 页面视图（默认，最常用）**
所见即所得，屏幕上显示什么样，打印出来就什么样。日常编辑99%的时间都在这个视图下。

**② 阅读视图**
把文档变成类似电子书的阅读模式，不能编辑，但阅读体验很好。适合审阅长文档。

**③ Web版式**
模拟网页的显示效果，没有分页概念。如果你要把Word文档转成网页内容，可以先用这个视图看看效果。

**④ 大纲视图**
只显示文档的标题层级结构，适合长文档的结构梳理。比如小王写了一份30页的奶茶店运营手册，用大纲视图可以快速调整章节顺序。

**⑤ 草稿视图**
去掉页眉页脚、页边距等装饰，只显示纯文字内容。适合专注写内容、不想被排版分心的时候。

> 💡 **提示**：对于初学者，记住一句话就够了——"日常用页面视图，看长文档用阅读视图"。其他视图等你遇到具体需求时再切换。

## 1.6 鼠标与键盘基本操作：选择文本的各种姿势

在Word里做任何操作之前，都要先"选中"目标。"先选中，再操作"是Word的黄金法则。以下是各种选择文本的技巧：

**鼠标选择**：

| 操作 | 方法 |
| ------ | ------ |
| 选中一个词 | 双击该词 |
| 选中一行 | 在行左侧空白处（选择栏）单击 |
| 选中一段 | 在段落左侧空白处双击，或在段落内三击 |
| 选中任意范围 | 按住鼠标左键拖动 |
| 选中不连续内容 | 先选中第一处，按住 `Ctrl` 再选其他处 |

**键盘选择**：

| 操作 | 快捷键 |
| ------ | -------- |
| 选中一个字符 | `Shift + ←` 或 `Shift + →` |
| 选中一行 | `Shift + Home`（到行首）/ `Shift + End`（到行尾） |
| 选中到文档开头 | `Ctrl + Shift + Home` |
| 选中到文档结尾 | `Ctrl + Shift + End` |
| 全选 | `Ctrl + A` |

> 💡 **提示**：选择栏是文档左侧一段看不见的"窄条区域"，把鼠标移到行首左侧，当光标变成向右上的箭头时，那个区域就是选择栏。善用选择栏能大幅提升选择效率。

小王第一次知道"双击选词、三击选段"的时候，激动地说："我以前都是拖半天才选中，手指都酸了！"——是的，技巧的力量就在于此。

## 练习题

1. **【基础】** 打开Word，找到功能区中"开始"选项卡，数一数里面有多少个功能分组（字体、段落……），试着把鼠标悬停在每个按钮上看看提示信息。

2. **【进阶】** 新建一个空白文档，随意输入三段文字，然后用鼠标和键盘分别练习：选中一个词、选中一行、选中一段、全选。每种操作至少练3遍。

3. **【挑战】** 把同一个文档分别保存为 `.docx` 和 `.doc` 格式，然后去文件夹里对比两个文件的大小，想想为什么 `.docx` 更小。（提示：.docx 本质上是一个压缩文件，你可以试试把后缀改成 .zip 然后打开看看里面是什么。）
