# 第1章：FFmpeg 是什么

>[TIP] Part 1: 从零认识 FFmpeg（基础概念篇）
> 在动手写任何命令之前，我们先把"内功"练好。这六章将带你建立完整的多媒体知识框架，让你不仅知道命令怎么写，更知道它背后在做什么。

你可能已经听说过 FFmpeg，也许你用过它转了一个视频格式，也许你只是好奇它为什么出现在这么多技术文章里。这一章，我们从零开始，认识这位视频处理界的"无名英雄"。

## 1.1 FFmpeg 的历史与命名

FFmpeg 这个名字本身就是一个"程序员式的双关语"。拆开来看：

- **FF** = Fast Forward（快进）
- **MPEG** = Moving Picture Experts Group（动态图像专家组，制定视频压缩标准的国际组织）

合在一起，FFmpeg 的意思是"快速处理 MPEG 视频的工具"——当然，它现在能做的事情远远超出了 MPEG 的范畴。

**关于创始人的传奇故事：**

FFmpeg 最早由法国程序员 **Fabrice Bellard** 于 2000 年创建。如果你没听过这个名字，那你可能不知道他同时还创建了 QEMU（著名的虚拟化工具）和 TCC（Tiny C Compiler，能在几秒内编译整个 Linux 内核的 C 编译器）。这个人被编程界称为"贝尔曼"——他写的代码密度和质量，让很多顶级程序员都自叹不如。

2004 年，Fabrice 将 FFmpeg 的维护权交给了 **Michael Niedermayer**，后者持续维护了 FFmpeg 长达近 20 年，将它从一个小工具发展成为整个多媒体行业的基石。

2011 年，FFmpeg 社区发生了一次著名的分裂（fork），一部分开发者创建了 **Libav** 项目，理由是项目管理风格的分歧。不过经过多年发展，FFmpeg 重新赢得了社区的主导地位，Libav 的大部分活跃开发者也已回归 FFmpeg 阵营。

## 1.2 它能做什么——视频界的瑞士军刀

如果把视频处理比作木工活，那么 FFmpeg 就是一整套工具箱——锯子、刨子、凿子、砂纸全都有。具体来说，它能做以下这些事情：

**格式转换（最常见的需求）**
把 MP4 转成 WebM、把 MOV 转成 MP4、把 AVI 转成 GIF……只要你能想到的格式，FFmpeg 几乎都能转。

**提取与合并**
从视频里单独抽出音频、把多段视频拼接成一段、把字幕烧录进视频画面。

**压缩与调整**
把 4K 视频压成 1080p、降低码率以减小文件体积、调整帧率让视频更流畅或更省流量。

**直播推流**
将摄像头或屏幕录制的内容推送到 YouTube、Twitch、Bilibili 等直播平台。

**截图与生成缩略图**
从视频的某个时间点截取一帧画面、批量生成视频缩略图。

**滤镜与特效**
加水印、加字幕、裁剪画面、旋转视频、调整色彩、添加淡入淡出效果……FFmpeg 内置了数百种滤镜。

**硬件加速**
利用 NVIDIA GPU、Intel QSV、AMD AMF 等硬件编码器来加速视频处理。

一句话总结：**FFmpeg 就是多媒体处理领域的"万能扳手"**，只要和音视频数据打交道，几乎都绕不开它。

## 1.3 谁在用 FFmpeg

你可能觉得自己没用过 FFmpeg，但实际上你每天都在用它——只是你不知道而已。

| 产品/平台 | 如何使用 FFmpeg |
| ----------- | ---------------- |
| **VLC 播放器** | 内置 FFmpeg 解码器，用于播放几乎所有视频格式 |
| **YouTube** | 后端用 FFmpeg 处理上传的视频、生成多分辨率版本 |
| **Bilibili** | 视频转码、直播推流后端大量依赖 FFmpeg |
| **OBS Studio** | 直播推流和录制功能底层调用 FFmpeg 的库 |
| **HandBrake** | 著名的视频转码工具，底层基于 FFmpeg 的 libavcodec |
| **FFmpeg** | 连 Chrome 和 Firefox 浏览器的 HTML5 视频播放，都用到了 FFmpeg 的解码组件 |
| **Blender** | 视频编辑模块依赖 FFmpeg 进行导入导出 |
| **Shotcut / DaVinci Resolve** | 专业视频剪辑软件，部分格式支持来自 FFmpeg |

可以这样说：**整个互联网的视频基础设施，有很大一部分建立在 FFmpeg 之上**。学会它，你就掌握了这个基础设施的核心工具。

## 1.5 命令行不可怕——给你一点信心

"命令行？我又不是黑客，为什么要用命令行？"

我理解你的顾虑。在这个到处都是图形界面的时代，黑底白字的命令行看起来确实有点"吓人"。但请相信：

1. **FFmpeg 的命令结构其实非常简单**——本质上就是"告诉它输入什么、想要什么输出"，就这么两件事。
2. **图形界面工具的底层都是 FFmpeg**——你用的 HandBrake、格式工厂，不过是在 FFmpeg 命令外套了个界面。直接学 FFmpeg，你拥有的控制力远超任何 GUI 工具。
3. **一旦掌握，效率极高**——批量处理 100 个视频？写一行命令搞定，不用点 100 次"开始转换"。
4. **这是可复用的知识**——FFmpeg 的概念和原理同样适用于理解其他视频处理工具。

## 本章小结

- FFmpeg 是 Fast Forward + MPEG 的缩写，由 Fabrice Bellard 创建，Michael Niedermayer 长期维护
- 它能做格式转换、提取合并、压缩调整、直播推流、滤镜特效等几乎所有视频处理工作
- YouTube、Bilibili、VLC、OBS 等主流产品都在底层使用 FFmpeg
- 本教程从零基础到流媒体推流，共 24 章分四个阶段
