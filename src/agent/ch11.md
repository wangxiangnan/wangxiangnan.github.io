# 第11章 Memory —— Agent的记忆系统

## 11.1 开篇：为什么 Agent 需要记忆？

在第8章中，我们提到过一个关键事实：**LLM 本身是无状态的**。每次调用时，它都不记得上一次对话说了什么。它就像一个极其聪明但患有短期失忆症的专家——每次见面都像第一次见面。

但用户的期望不是这样的：

```
用户: 什么是微服务？
AI: 微服务是一种将应用拆分为多个独立服务的架构风格。

用户: 它有什么优点？        <- "它"指的是微服务
AI: ???                    <- 没有记忆，不知道"它"是什么
```

记忆系统的本质是**管理上下文**——决定哪些信息应该保留在 LLM 的输入中，哪些可以被遗忘或归档。这就像你在管理一个缓存系统：空间（上下文窗口）有限，你需要智能地决定缓存什么、淘汰什么。

## 11.2 记忆类型分类

| 记忆类型 | 人类类比 | Agent 实现 | 存储内容 | 生命周期 |
| --------- | --------- | ----------- | --------- | --------- |
| 短期记忆 | 工作记忆 | 对话上下文 | 当前对话消息列表 | 单次会话 |
| 长期记忆 | 长期记忆 | 向量数据库 | 用户偏好、历史知识 | 跨会话 |
| 工作记忆 | 便签纸 | 任务状态 | 当前任务中间结果 | 当前任务 |

```
用户输入 -> [短期记忆(对话上下文)] -> Agent(LLM推理) <- [长期记忆(向量DB)]
                                      |
                                      v
                               [工作记忆(任务草稿)]
```

## 11.3 记忆策略实现

### 11.3.1 Buffer Memory：保存所有对话

最简单的方式——保存所有消息。

```python
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

class BufferMemory:
    """保存所有对话历史"""
    
    def __init__(self, system_prompt=""):
        self.system_prompt = system_prompt
        self.messages: list = []
    
    def add_user_message(self, content: str):
        self.messages.append(HumanMessage(content=content))
    
    def add_ai_message(self, content: str):
        self.messages.append(AIMessage(content=content))
    
    def get_messages(self) -> list:
        all_msgs = []
        if self.system_prompt:
            all_msgs.append(SystemMessage(content=self.system_prompt))
        all_msgs.extend(self.messages)
        return all_msgs

memory = BufferMemory("你是 DocMind。")
memory.add_user_message("什么是 Python？")
memory.add_ai_message("Python 是一种高级编程语言。")
memory.add_user_message("它有什么特点？")  # AI 能看到上下文
```

**优点**：简单、完整。**缺点**：消息无限增长，最终超出上下文窗口。

### 11.3.2 Window Memory：滑动窗口

只保留最近 K 轮对话。

```python
class WindowMemory:
    """滑动窗口记忆"""
    
    def __init__(self, k=5, system_prompt=""):
        self.k = k
        self.system_prompt = system_prompt
        self.messages: list = []
    
    def add_user_message(self, content: str):
        self.messages.append(HumanMessage(content=content))
    
    def add_ai_message(self, content: str):
        self.messages.append(AIMessage(content=content))
    
    def get_messages(self) -> list:
        max_msgs = self.k * 2  # K轮 = 2K条消息
        recent = self.messages[-max_msgs:] if len(self.messages) > max_msgs else self.messages
        all_msgs = []
        if self.system_prompt:
            all_msgs.append(SystemMessage(content=self.system_prompt))
        all_msgs.extend(recent)
        return all_msgs

memory = WindowMemory(k=3, system_prompt="你是 DocMind。")
# 模拟6轮对话后，前3轮会被丢弃
for i in range(6):
    memory.add_user_message(f"问题{i+1}")
    memory.add_ai_message(f"回答{i+1}")

msgs = memory.get_messages()
print(f"总存储: {len(memory.messages)}, LLM可见: {len(msgs) - 1}")
```

**优点**：token 可控。**缺点**：早期信息完全丢失。

### 11.3.3 Summary Memory：LLM 自动摘要

用 LLM 把旧对话压缩为摘要。

```python
from langchain_openai import ChatOpenAI

class SummaryMemory:
    """摘要记忆 — 用 LLM 压缩历史"""
    
    def __init__(self, system_prompt="", max_messages=10, llm=None):
        self.system_prompt = system_prompt
        self.max_messages = max_messages
        self.messages: list = []
        self.summary = ""
        self.llm = llm or ChatOpenAI(model="gpt-4o-mini", temperature=0)
    
    def add_user_message(self, content: str):
        self.messages.append(HumanMessage(content=content))
        self._maybe_summarize()
    
    def add_ai_message(self, content: str):
        self.messages.append(AIMessage(content=content))
        self._maybe_summarize()
    
    def _maybe_summarize(self):
        if len(self.messages) <= self.max_messages:
            return
        half = len(self.messages) // 2
        old_msgs = self.messages[:half]
        
        # 用 LLM 生成摘要
        conv_text = "\n".join(
            f"{'用户' if isinstance(m, HumanMessage) else 'AI'}: {m.content}"
            for m in old_msgs
        )
        prompt = (
            f"将以下对话压缩为简洁摘要，保留关键信息。\n"
            f"已有摘要：{self.summary or '无'}\n"
            f"新对话：\n{conv_text}\n"
            f"输出合并后的摘要："
        )
        response = self.llm.invoke([HumanMessage(content=prompt)])
        self.summary = response.content
        self.messages = self.messages[half:]
    
    def get_messages(self) -> list:
        all_msgs = []
        if self.system_prompt:
            all_msgs.append(SystemMessage(content=self.system_prompt))
        if self.summary:
            all_msgs.append(SystemMessage(content=f"之前的对话摘要：{self.summary}"))
        all_msgs.extend(self.messages)
        return all_msgs
```

**优点**：保留关键信息，控制 token。**缺点**：摘要过程消耗额外 API 调用，可能丢失细节。

### 11.3.4 策略对比

| 策略 | Token消耗 | 信息完整性 | 复杂度 | 适用场景 |
| ------ | ---------- | ----------- | -------- | --------- |
| Buffer | 无限增长 | 完整 | 低 | 短对话 |
| Window | 固定 | 丢失早期 | 低 | 中等长度对话 |
| Summary | 可控 | 保留关键 | 中 | 长对话 |
| Summary+Window | 可控 | 最佳平衡 | 高 | 生产环境推荐 |

## 11.4 向量记忆：用 Embedding 存储长期知识

对于跨会话的长期记忆，向量数据库是最佳选择：

```python
from langchain_chroma import Chroma
from langchain_openai import OpenAIEmbeddings
from langchain_core.documents import Document

class VectorMemory:
    """向量长期记忆"""
    
    def __init__(self, persist_dir="./data/memory"):
        self.embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
        self.vectorstore = Chroma(
            collection_name="long_term_memory",
            embedding_function=self.embeddings,
            persist_directory=persist_dir,
        )
    
    def remember(self, content: str, metadata: dict = None):
        """记住一条信息"""
        doc = Document(
            page_content=content,
            metadata=metadata or {"type": "memory"},
        )
        self.vectorstore.add_documents([doc])
    
    def recall(self, query: str, k: int = 3) -> list:
        """回忆相关信息"""
        return self.vectorstore.similarity_search(query, k=k)

# 使用
memory = VectorMemory()
memory.remember("用户偏好详细的回答", {"type": "preference"})
memory.remember("用户的项目是用 Python 写的", {"type": "project"})
memory.remember("用户对微服务架构感兴趣", {"type": "interest"})

# 在新会话中回忆
results = memory.recall("用户喜欢什么样的回答？")
for doc in results:
    print(f"  回忆: {doc.page_content}")
```

## 11.5 实战演练：DocMind 的对话记忆

```python
# src/memory/conversation.py
"""DocMind 对话记忆模块"""
from typing import Optional
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv

load_dotenv()

class DocMindMemory:
    """DocMind 的记忆管理器"""
    
    def __init__(self, system_prompt="", window_size=10, llm=None):
        self.system_prompt = system_prompt
        self.window_size = window_size
        self.messages: list = []
        self.summary = ""
        self.llm = llm or ChatOpenAI(model="gpt-4o-mini", temperature=0)
    
    def add_exchange(self, user_msg: str, ai_msg: str):
        """添加一轮对话"""
        self.messages.append(HumanMessage(content=user_msg))
        self.messages.append(AIMessage(content=ai_msg))
        self._maybe_summarize()
    
    def _maybe_summarize(self):
        """超出窗口时压缩旧消息"""
        max_msgs = self.window_size * 2
        if len(self.messages) <= max_msgs:
            return
        
        half = len(self.messages) // 2
        old = self.messages[:half]
        conv = "\n".join(
            f"{'用户' if isinstance(m, HumanMessage) else 'AI'}: {m.content}"
            for m in old
        )
        prompt = (
            f"压缩对话为摘要：\n已有：{self.summary or '无'}\n"
            f"新对话：\n{conv}\n输出合并摘要："
        )
        self.summary = self.llm.invoke([HumanMessage(content=prompt)]).content
        self.messages = self.messages[half:]
    
    def get_context(self) -> list:
        """获取当前上下文消息列表"""
        msgs = []
        if self.system_prompt:
            msgs.append(SystemMessage(content=self.system_prompt))
        if self.summary:
            msgs.append(SystemMessage(content=f"对话摘要：{self.summary}"))
        msgs.extend(self.messages)
        return msgs
    
    def get_stats(self) -> dict:
        return {
            "messages_in_window": len(self.messages),
            "has_summary": bool(self.summary),
            "summary_length": len(self.summary),
        }
```

## 11.6 记忆管理最佳实践

1. **短对话（<10轮）**：直接用 Buffer Memory，简单可靠。
2. **中等对话（10-50轮）**：用 Window Memory，设置合理的 k 值。
3. **长对话（50+轮）**：用 Summary + Window 混合策略。
4. **跨会话记忆**：用向量数据库存储关键信息（用户偏好、项目信息）。
5. **何时遗忘**：当对话主题明确转换时，可以主动清除旧上下文。

### 11.6.1 记忆策略选择的决策树

```
对话预计轮数？
├── < 10 轮 → Buffer Memory
│     理由：简单，不会超出上下文窗口
├── 10-50 轮 → Window Memory (k=5-10)
│     理由：token 可控，最近几轮信息最重要
├── 50+ 轮 → Summary + Window 混合
│     理由：长对话需要压缩，但不能完全丢失早期信息
└── 需要跨会话 → Vector Memory
      理由：向量检索可以找到最相关的历史信息
```

### 11.6.3 Token 消耗估算

在选择记忆策略时，了解 token 消耗很重要：

```python
def estimate_tokens(messages: list) -> int:
    """粗略估算消息列表的 token 数（中文约 1.5 字符/token）"""
    total_chars = sum(len(m.content) for m in messages)
    return int(total_chars / 1.5)

def memory_cost_analysis():
    """分析不同记忆策略的 token 消耗"""
    # 模拟 50 轮对话
    avg_msg_length = 200  # 每条消息平均 200 字符
    
    strategies = {
        "Buffer Memory": 50 * 2 * avg_msg_length,  # 所有消息
        "Window Memory (k=5)": 5 * 2 * avg_msg_length,  # 最近5轮
        "Window Memory (k=10)": 10 * 2 * avg_msg_length,  # 最近10轮
        "Summary + Window": 500 + 10 * 2 * avg_msg_length,  # 摘要 + 最近10轮
    }
    
    print("50轮对话的 Token 消耗估算（每条消息200字符）：\n")
    print(f"{'策略':<25} {'字符数':<10} {'预估Token':<10} {'成本等级'}")
    print("-" * 55)
    for name, chars in strategies.items():
        tokens = int(chars / 1.5)
        cost = "低" if tokens < 3000 else "中" if tokens < 8000 else "高"
        print(f"{name:<25} {chars:<10} {tokens:<10} {cost}")

memory_cost_analysis()
```

## 11.7 本章小结

1. **LLM 是无状态的** — 每次调用都需要你提供完整的上下文。
2. **三种记忆类型** — 短期（对话上下文）、长期（向量数据库）、工作（任务状态）。
3. **四种策略** — Buffer（全保留）、Window（滑动窗口）、Summary（自动摘要）、混合（推荐）。
4. **向量记忆** — 用 Embedding + 向量数据库实现跨会话的长期记忆。
