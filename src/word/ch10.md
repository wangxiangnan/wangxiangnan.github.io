# 第10章：修订与批注——多人协作的正确方式 👥

*"小王，供应商那边的合同我改了几处，你看看。"合伙人小李发来一份Word文档。小王打开一看——密密麻麻的合同条款，完全看不出来小李到底改了哪里。他只好从头到尾逐字对比，花了两个小时才发现：小李把"违约金5%"改成了"违约金3%"，还把付款周期从"月结"改成了"季结"。小王差点吐血："你就不能在改的地方标一下吗！"小李摊手："我标了啊，在我脑子里。"*

*这个场景是不是很熟悉？多人协作修改文档，如果不用正确的方式，简直就是一场灾难。好消息是，Word有一套非常完善的协作工具——修订与批注。学会了它，再也不会出现"你到底改了哪里"的灵魂拷问。*

## 10.1 为什么需要修订模式？告别"你到底改了哪里"

想象一下：你和同事一起写一份报告。同事改了十几处内容，然后发给你。你有两个选择：

- **不用修订**：你只能一行一行自己对比，看哪些地方变了。费时、费力、容易漏。
- **用修订模式**：同事的每一处修改都会被标记出来——删除的内容用红色删除线标出，新增的内容用彩色下划线标出。你一眼就能看到所有改动。

修订模式就像给文档装了一个"行车记录仪"，谁在什么时候改了什么，一清二楚。

> 💡 **提示**：修订模式不会改变你的编辑方式——你该怎么改就怎么改。它只是在后台默默"记录"你的每一次操作。

## 10.2 开启修订：追踪所有修改

开启修订超级简单：

`审阅 > 修订` ——点一下，按钮变亮，修订模式就开启了。

从此以后，你在这份文档中的所有操作都会被记录：

| 你的操作 | 修订的记录方式 |
| --------- | -------------- |
| 打字输入新内容 | 用彩色下划线标出 |
| 删除一段文字 | 用红色删除线标出（或显示在右侧气泡中） |
| 修改格式（比如加粗） | 在右侧气泡中显示格式变更 |
| 移动一段文字 | 原文位置标记删除，新位置标记新增 |

每个修改者会用不同的颜色标记，Word会自动分配颜色，并在文档边缘标注修改者的名字。

> 💡 **提示**：如果你不想让别人看到你修改时的用户名，可以在 `文件 > 选项 > 常规` 中修改"用户名"和"缩写"。不过建议在团队协作中使用真名，方便沟通。

## 10.3 修订的显示方式：所有标记、简单标记、无标记、原始

开启修订后，在 `审阅` 选项卡中有一个下拉菜单，控制修订的显示方式：

- **所有标记**：显示所有修订痕迹——删除线、下划线、侧边气泡，密密麻麻但信息最全。适合仔细审查每一处修改。

- **简单标记**：只在修改处显示一条红色竖线，点击竖线可以展开查看详细修改。这是最常用的模式——既能看到哪里有改动，又不会让文档看起来太乱。

- **无标记**：隐藏所有修订痕迹，显示的是"如果接受所有修订后"的最终效果。注意：修订还在，只是被隐藏了！

- **原始**：显示文档修改前的原始状态，就好像什么都没发生过一样。

> 💡 **提示**：千万不要以为切换到"无标记"就等于"修订已经消失了"。这只是隐藏显示而已。如果把文件发给别人，对方切换到"所有标记"还是能看到所有修改痕迹。所以发出去之前，一定要把需要接受的修订都接受掉！

## 10.4 接受与拒绝修订

审查完修改后，你需要对每一处修订做出"判决"——接受还是拒绝。

操作方法：

- 点击某处修订，然后选择 `审阅 > 接受` 或 `审阅 > 拒绝`
- 也可以用 `接受并移到下一处` / `拒绝并移到下一处`，逐个审查

如果你想一次性接受所有修订：`审阅 > 接受 > 接受所有修订`

> 💡 **提示**："接受所有修订"和"停止修订"是两码事！"接受"是把修改确认下来，"停止"只是不再追踪新的修改。正确的流程是：先接受/拒绝所有修订 → 再关闭修订模式。

小王和小李的合同审查流程应该是这样的：

1. 小李开启修订模式，修改合同
2. 小王打开合同，切换到"所有标记"查看
3. 小王逐条审查，同意的点"接受"，不同意的点"拒绝"
4. 全部处理完毕后，关闭修订模式

## 10.5 批注：添加评论而不改动正文

有时候你不想改动正文，只是想加一句评论，比如"这个价格是不是太高了？""这里需要补充数据来源"。这时候就要用**批注**。

添加批注的方法：

1. 选中你想评论的文字
2. `审阅 > 新建批注`（或者右键选择"新建批注"）
3. 在右侧弹出的批注框中输入你的评论

批注不会改动正文的任何内容，它只是"贴"在文档边缘的一张"便利贴"。

> 💡 **提示**：批注的快捷键是 `Ctrl + Alt + M`，比点菜单快多了。

## 10.6 回复批注与解决批注

批注最强大的地方在于——它可以变成对话。

别人加了一条批注"这里的价格要改一下"，你可以直接在那条批注下面点"回复"，写上"好的，改成多少？"。对方再回复"改成88元"。这样一段对话就完整地关联在了文档的具体位置上，比微信聊天记录还好找。

当问题处理完毕后，点击批注右上角的"解决"按钮，批注会变灰但不会消失——这表示"这个问题已经处理完了"。如果你想彻底清除，就点"删除批注"。

> 💡 **提示**：在长文档中，可以用 `审阅 > 下一条批注` 快速跳转到下一个待处理的批注，不用自己慢慢找。

## 10.7 比较文档：让Word自动找出两个版本的差异

回到小王和小李的故事。如果小李已经改完了合同但没有开修订模式怎么办？

别慌，Word有一个"比较文档"功能。

操作步骤：

1. 确保你有两个文件：修改前的原版（合同_原版.docx）和修改后的版本（合同_修改版.docx）
2. 打开Word，点击 `审阅 > 比较 > 比较`
3. 在弹出的对话框中，分别选择"原始文档"和"修订的文档"
4. 点击确定

Word会自动生成一个新文档，用修订标记的方式展示出两个版本之间的所有差异。效果就像小李开着修订模式修改的一样。

> 💡 **提示**：比较文档功能对于"别人已经改了但没开修订"的情况非常有用。建议你自己修改文档前先备份一份原版，万一忘了开修订，还能用比较功能找回差异。

## 10.8 合并文档：把多人的修改合并到一起

更复杂的场景：小李改了一份，另一个合伙人老张也改了一份，两个人的修改在不同的文件里。怎么办？

用"合并文档"功能：

1. `审阅 > 比较 > 合并`
2. 先选择原始文档和小李的修改版合并
3. 再把合并结果和老张的修改版合并

Word会把所有人的修改合并在一个文档里。如果有冲突（比如同一个地方两个人改的不一样），两处修改都会显示，由你决定接受哪个。

## 10.9 保护文档：限制编辑、设置密码

有时候你发给别人的文档，不想让对方乱改。比如你发一份"通知"给全体员工，只希望他们能看，不能改。

**限制编辑：**
`审阅 > 限制编辑`，可以设置：

- 只允许批注（不能改正文）
- 只允许填写表单
- 只允许修订（强制开启修订模式）
- 完全不允许修改（只读）

设置后点"是，启动强制保护"，可以设一个密码。没有密码的人无法取消保护。

**设置打开密码：**
`文件 > 信息 > 保护文档 > 用密码进行加密`

设了密码后，别人打开这个文件时必须输入密码。注意：这个密码如果忘了，是真的找不回来的，请务必记好。

> 💡 **提示**：Word的密码保护强度有限，专业工具可以破解。如果是特别机密的文件，建议配合文件加密工具使用，不要完全依赖Word的密码功能。

## 10.10 实战：小王和合伙人协作修改供应商合同

让我们用完整的工作流来演示小王和小李是怎么协作修改合同的：

**场景**：小王和茶叶供应商签年度采购合同，小李先审核了一遍并做了修改。

**步骤一：小李的修改流程**

1. 打开合同文件，点击 `审阅 > 修订` 开启修订模式
2. 逐条审阅合同条款，修改了付款周期、违约金比例、交货方式等5处内容
3. 在"独家供应"条款处加了一条批注："这条风险太大，建议改成'优先供应'"
4. 保存文件，发给小王

**步骤二：小王的审查流程**

1. 打开小李发来的文件，切换到"所有标记"显示方式
2. 逐条查看小李的5处修改：
   - 付款周期"月结"改"季结"——同意，点"接受"
   - 违约金"5%"改"3%"——不同意，点"拒绝"
   - 其余3处——分别做出接受/拒绝决定
3. 看到"独家供应"处的批注，回复："同意，改成优先供应，你来改一下措辞"

**步骤三：小李处理回复**

1. 收到小王回复后，修改"独家供应"为"优先供应"
2. 解决该批注
3. 确认所有修订都已处理后，关闭修订模式
4. 保存最终版本

**步骤四：定稿**

1. 小王最终检查一遍，确认没有任何未处理的修订和批注
2. 另存为PDF，发给供应商签字

整个过程，每一步修改都有据可查，沟通清晰明了，再也不用互相发微信问"你到底改了哪里"了。

## 本章小结

| 知识点 | 核心要点 |
| -------- | --------- |
| 开启修订 | `审阅 > 修订`，追踪所有修改 |
| 显示方式 | 所有标记/简单标记/无标记/原始 |
| 接受/拒绝修订 | 逐条审查，或一次性接受全部 |
| 批注 | `Ctrl + Alt + M`，添加不改动正文的评论 |
| 比较文档 | 自动对比两个版本的差异 |
| 合并文档 | 把多人的修改合并到一个文件中 |
| 保护文档 | 限制编辑、设置密码 |

## 练习题

1. **基础题**：打开一篇Word文档，开启修订模式，做3处文字修改和1处格式修改。然后切换到四种不同的显示方式，观察区别。

2. **进阶题**：将同一篇文档保存两份（A版和B版），分别在两个版本中做不同的修改（不开修订），然后用"比较文档"功能找出差异。

3. **挑战题**：找一位朋友，模拟真实的协作场景——一人先修改并加批注，另一人审查修订并回复批注，最终完成一份"合同"的协作修改。
