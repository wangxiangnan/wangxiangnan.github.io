# 第8章：字符串深度解析

## 为什么字符串这么"麻烦"？

从 Python/JS 转来的开发者第一次接触 Rust 字符串时通常会崩溃："为什么有两种字符串？""为什么不能 `s[0]`？""为什么拼接要这么麻烦？"

这一切的根源是：**Rust 认真对待 UTF-8 编码**。

Python 3 和 JS 的字符串在底层都做了大量工作来"假装"索引是简单的，Rust 选择让你面对真相。

## String vs &str

| 类型 | 本质 | 所有权 | 类比 |
|------|------|--------|------|
| `String` | 堆上分配的可增长字符串 | 拥有数据 | Python 的 `str` / Java 的 `String` |
| `&str` | 对 UTF-8 字节序列的引用（视图） | 借用 | C 的 `const char*`（但更安全） |

```rust
fn main() {
    // String：拥有所有权，可修改
    let mut owned = String::from("hello");
    owned.push_str(" world");

    // &str：借用视图，不可修改
    let greeting: &str = "hello world";  // 字符串字面量是 &str

    // String 可以自动转为 &str
    let view: &str = &owned;

    println!("owned: {owned}");
    println!("view: {view}");
}
```

## 创建字符串

```rust
fn main() {
    // 方式1：从字面量创建
    let s1 = String::from("hello");

    // 方式2：to_string()
    let s2 = "hello".to_string();

    // 方式3：空字符串
    let s3 = String::new();

    // 方式4：format! 宏
    let name = "Rust";
    let version = 2024;
    let s4 = format!("{name} {version} 真棒");

    // 方式5：从迭代器收集
    let chars = vec!['h', 'e', 'l', 'l', 'o'];
    let s5: String = chars.into_iter().collect();

    println!("{s1} | {s2} | {s3} | {s4} | {s5}");
}
```

## 字符串拼接

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = String::from(" world");

    // 方式1：+ 运算符（s1 被移动！）
    let s3 = s1 + &s2;
    // println!("{s1}");  // 编译错误！s1 已被移动
    println!("{s3}");

    // 方式2：format! 宏（推荐，不移动任何值）
    let a = String::from("foo");
    let b = String::from("bar");
    let c = format!("{a}-{b}");
    println!("a={a}, b={b}, c={c}"); // a 和 b 仍然可用

    // 方式3：push_str 和 push
    let mut s = String::from("hello");
    s.push_str(" world");  // 追加字符串
    s.push('!');            // 追加单个字符
    println!("{s}");
}
```

## UTF-8 编码与索引问题

**为什么不能 `s[0]`？**

```rust
fn main() {
    let s = String::from("hello");
    // let c = s[0];  // 编译错误！

    // 原因：Rust 字符串是 UTF-8 编码的字节序列
    // "hello" 的每个字符占 1 字节 → 看似可以索引
    // "你好" 的每个字符占 3 字节 → s[0] 是什么？第一个字节？第一个字符？

    let chinese = String::from("你好");
    println!("字节长度: {}", chinese.len());      // 6（不是2！）
    println!("字符数: {}", chinese.chars().count()); // 2

    // 如果你真的要按字节索引
    let bytes = chinese.as_bytes();
    println!("前3个字节: {:?}", &bytes[0..3]); // "你" 的 UTF-8 编码
}
```

> **Rust 的设计哲学**：与其给你错误的抽象（让你以为 `s[0]` 是 O(1) 操作），不如明确告诉你"这里不简单"，让你选择正确的方式来处理。

## 字符串遍历

```rust
fn main() {
    let s = String::from("你好World🌍");

    // 遍历字符
    println!("字符遍历:");
    for c in s.chars() {
        println!("  '{c}' (U+{:04X})", c as u32);
    }

    // 带索引遍历（索引是字符序号，不是字节序号）
    println!("带索引遍历:");
    for (i, c) in s.chars().enumerate() {
        println!("  [{i}] = '{c}'");
    }

    // 遍历字节
    println!("字节遍历:");
    for b in s.bytes() {
        print!("{b:02X} ");
    }
    println!();
}
```

## 字符串操作实用技巧

```rust
fn main() {
    let s = String::from("  Hello, Rust World!  ");

    // 去空白
    println!("'{}'", s.trim());
    println!("'{}'", s.trim_start());
    println!("'{}'", s.trim_end());

    // 分割
    let csv = "apple,banana,cherry";
    let fruits: Vec<&str> = csv.split(',').collect();
    println!("{:?}", fruits);

    // 替换
    let s2 = s.replace("Rust", "Python");
    println!("{s2}");

    // 查找
    let pos = s.find("Rust");
    println!("'Rust' 在位置: {:?}", pos);

    // 判断
    let s3 = "12345";
    println!("全是数字? {}", s3.chars().all(|c| c.is_ascii_digit()));
    println!("以 'Hello' 开头? {}", s.trim().starts_with("Hello"));

    // 大小写
    println!("{}", "hello".to_uppercase());
    println!("{}", "HELLO".to_lowercase());

    // 解析
    let num: i32 = "42".parse().unwrap();
    println!("解析数字: {num}");
}
```

## 常见陷阱

1. **用字节索引切中文字符串**：`&"你好"[0..1]` 会 panic，因为"你"占3个字节
2. **`len()` 返回字节数**：`"你好".len()` 是 6，不是 2
3. **+ 运算符移动左操作数**：`let s3 = s1 + &s2;` 之后 s1 不可用
4. **字符串字面量是 `&str`**：`"hello"` 的类型是 `&str` 不是 `String`，需要 `String::from()` 或 `.to_string()` 转换

## 小结

- `String` 拥有数据，`&str` 是视图
- Rust 字符串是 UTF-8 字节序列，不支持 O(1) 字符索引
- `format!` 是拼接字符串的最佳方式
- 用 `.chars()` 遍历字符，用 `.bytes()` 遍历字节
- `.len()` 返回字节长度，`.chars().count()` 返回字符数
