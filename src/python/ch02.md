# 第 2 章 第一个 Python 程序与基本语法

你第一次学骑自行车的时候，一定不是先背完了力学公式再上车的——而是先歪歪扭扭地骑两圈，摔几次，然后才慢慢找到平衡感。学编程也一样。这一章，我们不讲太多理论，直接动手写代码，在"做"的过程中感受 Python 的语法规则。

这一章覆盖的内容包括：如何输出和输入信息、如何写注释、Python 独特的缩进规则、变量的命名规范、字符串格式化，以及如何读懂错误信息。这些看似基础的东西，其实是你以后写所有程序都会用到的"底层技能"。就像学弹吉他时练的和弦转换——刚开始觉得枯燥，但一旦熟练了，你就自由了。

## 2.1 Hello, World! —— 编程界的仪式感

1978 年，Brian Kernighan 和 Dennis Ritchie 合著的经典教材《The C Programming Language》用了 "Hello, World" 作为第一个示例程序。从此，几乎所有编程教程都保留了这个传统——用一句 "Hello, World" 向世界宣告：我来了。这不仅仅是一个技术动作，更像是一种仪式：你正式踏入了编程的世界。四十多年来，无数程序员都是从这一行代码开始了自己的编程之旅，你也可以。

```python
print("Hello, World!")
```

就这一行。把它保存为 `hello.py`，在终端运行 `python hello.py`，屏幕上就会出现 `Hello, World!`。

`print()` 是 Python 的内置函数，作用是把它括号里的内容"打印"（输出）到屏幕上。你可以打印文字、数字、甚至计算结果。它是你调试程序时最常用的工具——当你不确定某段代码的执行结果时，加一行 `print()` 就能立刻看到答案。

```python
print("你好，世界")
print(42)
print(3.14)
print(2 + 3)  # 输出 5，Python 先算出结果再打印
```

注意：文字（字符串）必须用引号包裹（单引号 `'` 或双引号 `"` 都行），数字则不需要。如果你写了 `print(你好)`，Python 会报错，因为它会以为"你好"是一个变量名，但你还没定义它。

## 2.2 注释：写给未来的自己看的笔记

写代码时，你经常需要给代码加说明——不是为了给机器看，而是为了给人看。比如三个月后你回头看自己的代码，如果没有注释，你可能会疑惑："我当时为什么要写这行？"

```python
# 这是一条单行注释，Python 会完全忽略它
print("Hello")  # 也可以写在代码后面

# 计算圆的面积
# 公式：面积 = π × r²
radius = 5
area = 3.14159 * radius ** 2
print(area)
```

如果需要写多行注释，可以用三引号（虽然技术上这是字符串，但常被用作多行注释）：

```python
"""
这是一个多行注释。
可以写很多行。
Python 会忽略没有被使用的三引号字符串。
"""
print("继续写代码")
```

好的注释解释"为什么"，而不是"做了什么"。`# 将 x 加 1` 是废话注释，`# 加 1 是因为索引从 0 开始而用户输入从 1 开始` 才是有用的注释。

## 2.3 缩进：Python 的灵魂

这可能是 Python 和其他编程语言最大的区别。在 C、Java、JavaScript 等语言中，代码块用花括号 `{}` 来划分；而 Python 用**缩进**来表示代码的层级关系。

```python
# 正确：缩进一致
if True:
    print("条件为真")
    print("这行也在 if 块里")
print("这行不在 if 块里，因为缩进回来了")
```

```python
# 错误：缩进不一致会报错
if True:
    print("条件为真")
   print("缩进不对！")  # IndentationError
```

Python 对缩进的要求是严格的：同一个代码块里，所有行的缩进量必须一致。官方推荐用 **4 个空格**作为一级缩进。千万不要混用空格和 Tab，否则 Python 会报 `TabError`。现代编辑器（VS Code、PyCharm）会自动把 Tab 转成空格，帮你避免这个问题。

缩进不是负担，而是礼物——它强迫你把代码写得整齐。在其他语言中，新手经常写出这样的代码：

```java
// Java 中合法但丑陋的写法
if(x>0){
System.out.println("正数");
}else{
System.out.println("非正数");
}
```

在 Python 中，你不可能写出这种"视觉灾难"，因为缩进是语法的一部分，不缩进就跑不了。这个设计决策是 Guido van Rossum 深思熟虑的结果——他认为，好的代码就应该看起来像排版良好的文章，而不是一团乱麻。

在实际开发中，你还会遇到一些与缩进相关的"潜规则"。PEP 8（Python 官方编码规范）规定：用 4 个空格表示一级缩进，不要用 Tab。如果你用的是团队项目，保持一致的缩进风格比什么都重要。大多数现代编辑器都有"自动格式化"功能——保存文件时自动调整缩进和格式，帮你省去手动整理的麻烦。在 VS Code 中，你可以右键选择 "Format Document"；在 PyCharm 中，快捷键是 `Ctrl + Alt + L`。

## 2.4 变量：给数据贴标签

想象你搬到一个新小区，快递小哥不认识你。你在门口贴一个标签"张三的家"，以后快递看到标签就知道往哪送了。**变量**就是给数据贴的标签——你给它起个名字，以后用名字就能找到对应的数据。

```python
# 创建变量并赋值
name = "小明"
age = 18
height = 1.75
is_student = True

print(name)      # 输出：小明
print(age)       # 输出：18
```

等号 `=` 在编程中不是"等于"的意思，而是**赋值**——把右边的值"放进"左边这个标签对应的盒子里。

### 变量命名规则

Python 对变量名有明确要求：

- 只能包含字母、数字和下划线 `_`
- 不能以数字开头（`1st_name` 是非法的）
- 不能使用 Python 的保留关键字（如 `if`、`for`、`class`、`def` 等）
- 区分大小写（`Name` 和 `name` 是两个不同的变量）

```python
# 合法的变量名
user_name = "Alice"
_count = 10
MAX_SIZE = 100
firstName2 = "Bob"

# 非法的变量名
# 2nd_place = "Silver"   # 不能以数字开头
# my-var = 10            # 不能包含连字符
# class = "Python101"    # 不能使用关键字
```

### 命名风格

Python 社区有一个不成文的约定（PEP 8 编码规范）：

- **普通变量和函数名**用 `snake_case`（小写字母加下划线）：`user_name`、`total_price`
- **常量**用全大写加下划线：`MAX_RETRY = 3`、`PI = 3.14159`
- **类名**用 `PascalCase`（大驼峰）：`UserProfile`、`ShoppingCart`

好的变量名应该让人一看就知道它存的是什么。`x` 存一个用户年龄，不如直接叫 `age` 或 `user_age`。当然，数学公式里的 `x`、`y`、`i`、`j` 这种约定俗成的名字除外。

## 2.5 输入与输出：和程序对话

程序不是独角戏，它需要和用户互动。`print()` 负责"说"，`input()` 负责"听"。

```python
# 向用户问好
name = input("请输入你的名字：")
print("你好，" + name + "！欢迎学习 Python。")
```

运行这段代码时，程序会暂停，等待你输入内容并按回车。`input()` 会把你输入的内容作为**字符串**返回——即使你输入的是数字 `25`，它返回的也是字符串 `"25"`，而不是数字 `25`。这一点非常重要，很多新手在这里踩坑：

```python
age = input("请输入年龄：")
# 如果用户输入 25，age 的值是字符串 "25"
# 下面这行会报错！因为字符串不能和数字做加法
# print("明年你就" + age + 1 + "岁了")

# 正确做法：把字符串转换成整数
age_number = int(age)
print("明年你就", age_number + 1, "岁了")
```

注意 `print()` 用逗号分隔多个内容时，会自动在它们之间加空格。如果不想加空格，可以设置 `sep` 参数：

```python
print("2024", "01", "15", sep="-")  # 输出：2024-01-15
print("Hello", end="")
print("World")  # 输出：HelloWorld（不换行）
```

## 2.6 f-string：Python 最优雅的字符串格式化

当你需要把变量嵌入到字符串中时，f-string 是最方便的方式。在字符串前加一个 `f`，然后用花括号 `{}` 包裹变量名：

```python
name = "小红"
age = 20
city = "北京"

# f-string 格式化
print(f"我叫{name}，今年{age}岁，来自{city}。")
# 输出：我叫小红，今年20岁，来自北京。

# 花括号里可以放表达式
print(f"明年我就{age + 1}岁了。")
# 输出：明年我就21岁了。

# 控制数字格式
pi = 3.14159265
print(f"圆周率保留两位小数是 {pi:.2f}")
# 输出：圆周率保留两位小数是 3.14

# 对齐和填充
for item in ["苹果", "香蕉", "西瓜"]:
    print(f"|{item:<6}|")
# 输出（左对齐，宽度6）：
# |苹果    |
# |香蕉    |
# |西瓜    |
```

f-string 是 Python 3.6 引入的，如果你还在用老版本（虽然不太可能），也可以用 `.format()` 方法或 `%` 格式化，但强烈建议用 f-string——它更直观、更快。

## 2.7 转义字符与特殊符号

字符串中有些字符是"看不见"的，或者有特殊含义。为了在字符串中表示它们，Python 使用反斜杠 `\` 作为转义符：

```python
# 换行符 \n
print("第一行\n第二行\n第三行")

# 制表符 \t（Tab）
print("姓名\t年龄\t城市")
print("小明\t20\t北京")
print("小红\t22\t上海")

# 在字符串中包含引号
print("他说：\"编程真有趣！\"")   # 双引号字符串中包含双引号
print('她说：\'Python 太棒了！\'')  # 单引号字符串中包含单引号

# 反斜杠本身
print("Windows 路径：C:\\Users\\Documents")

# 原始字符串（r前缀），不处理转义，常用于正则表达式和文件路径
print(r"C:\Users\Documents")  # 原样输出，不转义
```

```python
# 实际应用：打印一个简单的表格
print("=" * 40)
print(f"{'商品名称':<12}{'单价':>8}{'数量':>8}{'小计':>10}")
print("-" * 40)
print(f"{'Python教程':<10}{59.9:>10.2f}{2:>8}{59.9*2:>10.2f}")
print(f"{'机械键盘':<10}{299.0:>10.2f}{1:>8}{299.0*1:>10.2f}")
print(f"{'显示器':<10}{1299.0:>10.2f}{1:>8}{1299.0*1:>10.2f}")
print("=" * 40)
total = 59.9 * 2 + 299.0 + 1299.0
print(f"{'总计':<10}{'':>18}{total:>10.2f}")
```

## 2.8 代码的组织：行与语句

Python 中每条语句通常占一行。如果你想在同一行写多条语句，可以用分号 `;` 分隔，但**不推荐**这么做，因为会降低可读性：

```python
# 可以但不推荐
x = 1; y = 2; z = x + y

# 推荐：每条语句一行
x = 1
y = 2
z = x + y
```

如果一行代码太长，可以用反斜杠 `\` 续行，或者用圆括号自动续行（推荐）：

```python
# 反斜杠续行
total = 1 + 2 + 3 + \
        4 + 5 + 6

# 圆括号续行（推荐，更不容易出错）
total = (1 + 2 + 3 +
         4 + 5 + 6)

# 长字符串也可以跨行
message = """这是
一段
多行文字"""
```

## 2.9 学会读懂错误信息

编程新手往往一看到红色报错就慌了神，但错误信息其实是你的朋友——它精确地告诉你出了什么问题、在哪里出问题。学会读错误信息，是自学编程最重要的技能之一。

Python 的错误信息（Traceback）结构是这样的：从下往上读。最下面一行是错误类型和描述，上面的行告诉你错误发生在哪个文件、哪一行。

```python
# 运行以下有 bug 的代码
name = "Alice"
age = "twenty"
print(f"{name} 明年 {age + 1} 岁")
```

你会看到类似这样的错误信息：

```
Traceback (most recent call last):
  File "demo.py", line 3, in <module>
    print(f"{name} 明年 {age + 1} 岁")
TypeError: can only concatenate str (not "int") to str
```

解读方法：

1. **最后一行**：`TypeError` 表示类型错误，"只能拼接字符串，不能拼接整数"。
2. **倒数第二行**：告诉你错误出在第 3 行，具体是哪行代码。
3. **上面的 File 行**：告诉你是在哪个文件里。

常见的错误类型有：

- `SyntaxError`：语法错误，代码写得不符合规则（比如漏了冒号、括号不匹配）。
- `NameError`：名字错误，使用了一个不存在的变量名。
- `TypeError`：类型错误，对不兼容的类型做了操作。
- `ValueError`：值错误，函数接收了类型正确但不合理的值（比如 `int("hello")`）。
- `IndentationError`：缩进错误，代码的缩进不正确。

养成一个好习惯：遇到报错，**先看最后一行的错误类型和描述**，通常就能定位问题。如果看不懂，把最后一行复制到搜索引擎里，大概率有人遇到过同样的问题。

## 2.10 小结

- `print()` 用于输出信息，`input()` 用于获取用户输入。
- 注释用 `#`（单行）或三引号（多行），目的是解释"为什么"。
- 缩进是 Python 语法的核心，用 4 个空格表示一级缩进，禁止混用空格和 Tab。
- 变量是给数据贴标签，命名遵循 PEP 8 规范（snake_case）。
- f-string 是最现代、最推荐的字符串格式化方式。
- 转义字符用 `\` 引导，如 `\n`（换行）、`\t`（制表符）；原始字符串 `r""` 可跳过转义。

## 2.13 常见错误与避坑

- **IndentationError**：缩进错误。检查是否混用了空格和 Tab，或者同一代码块的缩进不一致。在编辑器中设置"显示空白字符"可以帮助你看到问题。
- **input() 返回的是字符串**：如果需要做数学计算，必须用 `int()` 或 `float()` 转换。`int("abc")` 会报错 `ValueError`，确保用户输入的是合法数字。
- **忘记加引号**：`print(Hello)` 会报 `NameError`，因为 Python 把 `Hello` 当成变量名了。文字必须用引号包裹：`print("Hello")`。
- **f-string 忘记加 `f`**：`print("{name}")` 会原样输出 `{name}`，而不是变量值。必须在引号前加 `f`：`print(f"{name}")`。
- **中文括号和英文括号混用**：`print（"Hello"）` 会报错，因为中文的圆括号 `（）` 和英文的 `()` 不是同一个字符。写代码时请确保输入法处于英文模式。
