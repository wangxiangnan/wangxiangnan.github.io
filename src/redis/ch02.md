# 第2章：安装Redis与Node.js开发环境搭建

## 引言：磨刀不误砍柴工

写代码之前，你得先把"战场"搭好。就像厨师做菜之前要先磨刀、热锅、备好调料一样，我们这章要做的事情就是：装好 Redis，配好 Node.js，打通任督二脉，为后面的修炼做好准备。

别怕，整个过程比你想象的简单——尤其是有了 Docker 这个"一键安装包"之后。

## 2.1 安装 Redis

### 方式一：Docker（推荐，三秒搞定）

Docker 是最省心的方式，不管你用的是 Windows、macOS 还是 Linux：

```bash
# 拉取 Redis 7.x 镜像并启动
docker run -d \
  --name redis-tutorial \
  -p 6379:6379 \
  -v redis-data:/data \
  redis:7-alpine

# 验证是否启动成功
docker ps | grep redis
```

输出类似：

```
CONTAINER ID   IMAGE           COMMAND                  STATUS          PORTS                    NAMES
a1b2c3d4e5f6   redis:7-alpine  "docker-entrypoint.s…"   Up 5 seconds    0.0.0.0:6379->6379/tcp   redis-tutorial
```

> **Tip**：`-v redis-data:/data` 这行很重要！它把 Redis 的数据挂载到 Docker Volume，这样即使容器被删除，数据也不会丢失。就像给你的游戏存了档。

如果你要带密码启动：

```bash
docker run -d \
  --name redis-tutorial \
  -p 6379:6379 \
  -v redis-data:/data \
  redis:7-alpine \
  redis-server --requirepass "your-strong-password"
```

### 方式二：Linux 原生安装

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server

# CentOS/RHEL
sudo yum install -y epel-release
sudo yum install -y redis
sudo systemctl start redis
sudo systemctl enable redis
```

### 方式三：macOS 安装

```bash
# 使用 Homebrew
brew install redis
brew services start redis
```

### 方式四：Windows 安装

Windows 用户，强烈建议用 Docker 或 WSL2。如果你非要在 Windows 原生跑 Redis：

```bash
# 方式1：使用 WSL2（推荐）
wsl --install  # 安装 WSL2
# 然后在 WSL 里按照 Ubuntu 的方式安装 Redis

# 方式2：使用 Memurai（Redis 的 Windows 兼容替代品）
# 下载地址：https://www.memurai.com/
```

> **Warning**：微软官方的 Windows 版 Redis（基于 3.2 版本）已经多年不维护了，别用它！要么用 Docker，要么用 WSL2。

## 2.2 启动和配置 Redis 服务

Redis 的配置文件叫 `redis.conf`，Docker 方式下可以这样自定义：

```bash
# 先创建一个自定义配置文件
mkdir -p ~/redis-config
cat > ~/redis-config/redis.conf << 'EOF'
# 绑定地址（开发环境用 0.0.0.0，生产环境务必改为具体IP）
bind 0.0.0.0

# 端口
port 6379

# 密码（生产环境必须设置！）
requirepass myRedisPassword123

# 最大内存
maxmemory 256mb

# 内存淘汰策略
maxmemory-policy allkeys-lru

# 持久化 - RDB
save 900 1
save 300 10
save 60 10000

# 持久化 - AOF
appendonly yes
appendfsync everysec

# 日志级别
loglevel notice
EOF

# 用自定义配置启动 Redis
docker run -d \
  --name redis-tutorial \
  -p 6379:6379 \
  -v redis-data:/data \
  -v ~/redis-config/redis.conf:/usr/local/etc/redis/redis.conf \
  redis:7-alpine \
  redis-server /usr/local/etc/redis/redis.conf
```

## 2.3 redis-cli 基本操作

`redis-cli` 是 Redis 自带的命令行客户端，就像 MySQL 的 `mysql` 命令一样：

```bash
# 连接到 Redis（Docker 方式）
docker exec -it redis-tutorial redis-cli

# 如果设置了密码
docker exec -it redis-tutorial redis-cli -a "myRedisPassword123"
```

进入交互模式后：

```bash
# 测试连接
127.0.0.1:6379> PING
PONG

# 设置一个值
127.0.0.1:6379> SET greeting "Hello Redis!"
OK

# 获取值
127.0.0.1:6379> GET greeting
"Hello Redis!"

# 查看所有 Key
127.0.0.1:6379> KEYS *
1) "greeting"

# 删除 Key
127.0.0.1:6379> DEL greeting
(integer) 1

# 查看服务器信息
127.0.0.1:6379> INFO server

# 退出
127.0.0.1:6379> exit
```

> **Tip**：`KEYS *` 在生产环境中是禁忌！它会阻塞 Redis 直到遍历完所有 Key。如果需要查找 Key，请用 `SCAN` 命令代替。

## 2.4 Node.js 项目初始化

好了，Redis 服务端搞定了，现在来搭建我们的 Node.js 客户端：

```bash
# 创建项目目录
mkdir redis-tutorial && cd redis-tutorial

# 初始化 Node.js 项目
npm init -y

# 安装 ioredis（Redis 客户端库）
npm install ioredis

# 安装 nodemon（开发用，文件修改后自动重启）
npm install --save-dev nodemon
```

在 `package.json` 中添加开发脚本：

```json
{
  "scripts": {
    "dev": "nodemon index.js",
    "start": "node index.js"
  }
}
```

## 2.5 第一个 Redis 连接示例

创建 `index.js`，写下你的第一段 Redis 代码：

```js
const Redis = require('ioredis');

async function main() {
  // 创建 Redis 连接
  // 如果 Redis 在本机默认端口，可以简写为 new Redis()
  const redis = new Redis({
    host: '127.0.0.1',  // Redis 服务器地址
    port: 6379,          // Redis 端口
    // password: 'myRedisPassword123', // 如果设置了密码
    db: 0,               // 数据库编号（0-15）
  });

  // 监听连接事件
  redis.on('connect', () => {
    console.log('✅ 成功连接到 Redis！');
  });

  redis.on('error', (err) => {
    console.error('❌ Redis 连接出错：', err.message);
  });

  try {
    // SET：设置一个键值对
    await redis.set('hello', 'world');
    console.log('SET hello world => OK');

    // GET：获取值
    const value = await redis.get('hello');
    console.log(`GET hello => "${value}"`);

    // SETEX：设置带过期时间的值（单位：秒）
    await redis.setex('temp-key', 60, 'I will expire in 60 seconds');
    console.log('SETEX temp-key 60 => OK');

    // TTL：查看剩余生存时间
    const ttl = await redis.ttl('temp-key');
    console.log(`TTL temp-key => ${ttl} 秒`);

    // DEL：删除键
    const deleted = await redis.del('hello');
    console.log(`DEL hello => 删除了 ${deleted} 个键`);

    // 再次 GET（已删除，返回 null）
    const gone = await redis.get('hello');
    console.log(`GET hello (已删除) => ${gone}`);

    console.log('\n🎉 恭喜！你的第一段 Redis 代码运行成功！');
  } catch (err) {
    console.error('操作失败：', err);
  } finally {
    // 断开连接
    await redis.quit();
    console.log('🔌 已断开 Redis 连接');
  }
}

main();
```

运行：

```bash
node index.js
```

你应该看到类似输出：

```
✅ 成功连接到 Redis！
SET hello world => OK
GET hello => "world"
SETEX temp-key 60 => OK
TTL temp-key => 60 秒
DEL hello => 删除了 1 个键
GET hello (已删除) => null

🎉 恭喜！你的第一段 Redis 代码运行成功！
🔌 已断开 Redis 连接
```

## 2.6 连接配置详解

ioredis 的连接配置比你想象的丰富。来看一个完整的配置示例：

```js
const Redis = require('ioredis');

const redis = new Redis({
  // === 基本连接 ===
  host: '127.0.0.1',         // 主机地址
  port: 6379,                 // 端口号
  family: 4,                  // IP 版本：4 (IPv4) 或 6 (IPv6)

  // === 认证 ===
  password: 'my-password',    // 密码
  username: 'default',        // 用户名（Redis 6.0+ ACL）

  // === 数据库 ===
  db: 0,                      // 数据库编号（0-15，默认0）

  // === 连接行为 ===
  lazyConnect: false,         // true = 不立即连接，需要手动调 .connect()
  connectTimeout: 10000,      // 连接超时（毫秒）
  keepAlive: 0,               // TCP Keep-Alive（毫秒，0=禁用）

  // === 自动重连 ===
  maxRetriesPerRequest: 20,   // 每个命令最大重试次数
  retryStrategy(times) {      // 重连策略
    // times = 第几次重连
    if (times > 10) {
      return null; // 超过10次就放弃
    }
    const delay = Math.min(times * 200, 2000); // 指数退避，最大2秒
    return delay;
  },

  // === 离线队列 ===
  enableOfflineQueue: true,   // 连接建立前，命令是否排队
  enableReadyCheck: true,     // 是否检查 Redis 是否就绪

  // === 键前缀（ioredis 独有） ===
  keyPrefix: 'myapp:',        // 自动给所有 Key 加前缀
});

// 监听各种事件
redis.on('connect', () => console.log('已连接'));
redis.on('ready', () => console.log('已就绪'));
redis.on('close', () => console.log('连接已关闭'));
redis.on('reconnecting', (ms) => console.log(`${ms}ms 后重连...`));
redis.on('error', (err) => console.error('出错：', err.message));

module.exports = redis;
```

## 2.7 连接池和连接管理

在高并发的 Node.js 应用中，你可能需要管理多个 Redis 连接：

```js
const Redis = require('ioredis');

// 方案一：单例模式（推荐大多数场景）
// ioredis 内部已经做了连接复用，一个实例通常就够用
class RedisManager {
  constructor() {
    if (!RedisManager.instance) {
      RedisManager.instance = new Redis({
        host: '127.0.0.1',
        port: 6379,
        maxRetriesPerRequest: 3,
        retryStrategy(times) {
          return Math.min(times * 100, 3000);
        },
      });

      RedisManager.instance.on('error', (err) => {
        console.error('Redis 错误：', err.message);
      });
    }
    return RedisManager.instance;
  }

  getClient() {
    return RedisManager.instance;
  }

  async close() {
    if (RedisManager.instance) {
      await RedisManager.instance.quit();
      RedisManager.instance = null;
    }
  }
}

const manager = new RedisManager();
module.exports = manager;

// --- 使用方式 ---
// const manager = require('./redis-manager');
// const redis = manager.getClient();
// await redis.set('key', 'value');
```

```js
// 方案二：多连接实例（需要订阅/发布分离时使用）
const Redis = require('ioredis');

// 普通命令连接
const redis = new Redis();

// 订阅专用连接（订阅模式下不能执行其他命令）
const subscriber = new Redis();

// 发布可以用普通连接，也可以单独一个
const publisher = new Redis();

// 设置订阅
subscriber.subscribe('news', (err, count) => {
  console.log(`已订阅 ${count} 个频道`);
});

subscriber.on('message', (channel, message) => {
  console.log(`[${channel}] 收到消息：${message}`);
});

// 发布消息
setTimeout(async () => {
  await publisher.publish('news', 'Redis 教程发布了！');
}, 1000);

// 清理（3秒后取消订阅并关闭所有连接）
setTimeout(async () => {
  await subscriber.unsubscribe('news');
  await redis.quit();
  await subscriber.quit();
  await publisher.quit();
}, 4000);
```

> **Warning**：Node.js 进程退出前一定要调用 `redis.quit()` 或 `redis.disconnect()`，否则进程会挂起（因为还有活跃的 TCP 连接）。使用 `process.on('SIGINT', ...)` 来优雅关闭。

```js
// 优雅关闭的完整写法
process.on('SIGINT', async () => {
  console.log('\n收到退出信号，正在关闭...');
  await redis.quit();
  process.exit(0);
});

process.on('SIGTERM', async () => {
  await redis.quit();
  process.exit(0);
});
```

## 2.8 小结

> **搭环境 = 磨刀，磨好了刀，后面砍柴才快**

- Docker 是安装 Redis 最简单的方式：`docker run -d -p 6379:6379 redis:7-alpine`
- `redis-cli` 是调试利器，但生产环境别用 `KEYS *`
- ioredis 是 Node.js 最好的 Redis 客户端，功能丰富、API 优雅
- 单例模式 + 事件监听 + 优雅关闭 = 生产级别的连接管理
- 需要 Pub/Sub 时，记得用独立的订阅连接

## 2.9 练习题

1. **动手题**：用 Docker 启动一个 Redis 实例，设置密码为 `redis123`，最大内存为 `128mb`。

3. **探索题**：在 `redis-cli` 中执行 `INFO` 命令，阅读输出信息，找出你的 Redis 版本号、运行天数和内存使用量。
