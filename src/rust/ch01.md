Part I：基础入门

## 一场"意外"引发的思考

想象一下：你花了三天写了一个 Python 数据处理脚本，跑在生产环境里速度像蜗牛；你花了两周用 C++ 写了一个高性能服务，上线第一天就因为空指针崩溃了。

有没有一种语言，能同时给你"安全感"和"速度感"？

这就是 Rust 存在的原因。

## Rust 是什么？

Rust 是 Mozilla 发起、2015年正式发布 1.0 版本的系统编程语言。它的三大卖点：

| 卖点 | 说明 | 其他语言对比 |
| ------ | ------ | -------------- |
| **安全（Safety）** | 编译期杜绝空指针、悬垂引用、数据竞争 | C/C++靠程序员自觉 |
| **性能（Performance）** | 零成本抽象，与 C/C++ 比肩 | Python/JS望尘莫及 |
| **并发（Concurrency）** | 编译期防止数据竞争，无畏并发 | Java/C++靠锁和运行时检查 |

Rust 连续多年蝉联 Stack Overflow "最受喜爱编程语言"榜首——这不是偶然，是无数被段错误（segfault）折磨过的程序员用脚投票的结果。

## 谁在用 Rust？

- **Mozilla**：用 Rust 重写了 Firefox 的渲染引擎（Servo）
- **Linux 内核**：从 6.1 版本开始支持 Rust 驱动开发
- **Microsoft**：正在将 Windows 内核的部分组件用 Rust 重写
- **Cloudflare/ AWS**：高性能网络服务
- **Discord**：用 Rust 重写了 Go 的热点服务，延迟降低10倍

## rustup 安装与 cargo 工具链

Rust 的官方安装器叫 `rustup`，它同时管理 Rust 版本和工具链。

**Windows**：从 <https://rustup.rs> 下载安装程序，按提示操作。

**macOS / Linux**：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装完成后验证：

```bash
rustc --version    # 编译器版本
cargo --version    # 包管理器版本
rustup --version   # 工具链管理器版本
```

> **类比理解**：`rustup` 之于 Rust，就像 `nvm` 之于 Node.js，`pyenv` 之于 Python——它是一个版本管理器，让你能在不同 Rust 版本间切换。

## Hello World 详解

让我们用四种语言说"你好"，感受一下差异：

**Python：**

```python
print("Hello, World!")
```

**Java：**

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

**C：**

```c
#include <stdio.h>
int main() {
    printf("Hello, World!\n");
    return 0;
}
```

**Rust：**

```rust
fn main() {
    println!("Hello, World!");
}
```

Rust 的 `main` 函数是程序入口，`println!` 是宏（注意末尾的 `!`，这是宏的标志，不是"取反"），`{}` 是代码块。

## cargo 工作流

Rust 的项目管理和构建工具叫 `cargo`（货船），它帮你完成：创建项目、管理依赖、编译构建、运行测试。

```bash
# 创建新项目
cargo new hello_rust
cd hello_rust

# 项目结构
# hello_rust/
# ├── Cargo.toml    ← 项目配置文件（类似 package.json / pom.xml）
# └── src/
#     └── main.rs   ← 入口文件

# 编译
cargo build

# 编译+运行（一步到位）
cargo run

# 检查代码是否有编译错误（不生成二进制文件，速度快）
cargo check

# 发布构建（开启优化）
cargo build --release
```

`Cargo.toml` 文件长这样：

```toml
[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]
# 在这里添加第三方库
```

## 编辑器配置

推荐使用 **VS Code** + **rust-analyzer** 插件。

rust-analyzer 提供：

- 实时类型推断（在变量上方显示类型）
- 内联提示（参数名提示）
- 代码补全与重构
- 悬停文档

安装步骤：

1. VS Code 扩展商店搜索 `rust-analyzer` 安装
2. 如果有旧版 `rust` 插件，请先卸载（两者冲突）

> **小贴士**：rust-analyzer 的类型推断提示功能对初学者极为有用，它会直接在代码行内显示变量类型，省去你手动猜测类型的时间。

## 常见陷阱

1. **`println!` 的 `!` 不能省略**：漏掉 `!` 会报错，因为 `println` 是宏不是函数
2. **`main` 函数签名固定**：必须是 `fn main()`，不接受参数（初学者阶段）
3. **分号规则**：Rust 语句以分号结尾，表达式不加分号（这点在第3章详细讲解）

## 小结

本章你学到了：

- Rust 的核心价值：安全、性能、并发
- `rustup` 是版本管理器，`cargo` 是项目管理工具
- `fn main()` 是程序入口，`println!` 是打印宏
- `cargo new` 创建项目，`cargo run` 编译运行

3. 执行 `cargo build --release`，找到生成的可执行文件在哪个目录
4. 查阅 `Cargo.toml` 的文档，添加 `rand` 依赖（版本 "0.8"），然后执行 `cargo build`，观察发生了什么
5. 思考题：为什么 Rust 的 `println!` 要用宏而不是普通函数？（提示：想想参数数量的灵活性）
